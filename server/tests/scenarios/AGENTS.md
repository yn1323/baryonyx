## 3並列での独立性

[Vitest設定](../../vitest.config.ts) は、単体・結合・シナリオテストを合わせて最大3ファイルを並列実行する。
`pnpm test` とCIは同じ設定を使い、ファイル内のテストとシナリオの手順は順番に実行する。

- 並列に動く最大3ファイルの間で、シナリオを独立させる。各ファイルを単独で実行しても、他ファイルと任意の順序で実行しても成功させる。
- 各ファイルの `beforeAll` で専用のMiniflareと空のD1を用意し、マイグレーションを適用する。`afterAll` で破棄し、初期化に失敗した場合も後始末を行う。
- DBインスタンス、永続化先、セッション、変更可能な状態をファイル間で共有しない。他ファイルが作ったデータや実行順序に依存させない。
- 共通の初期化処理は `tests/support/` の生成関数を使う。生成済みMiniflareやDBを共通モジュールの変数へ保存しない。健康データAPIでは [createHealthScenario](../support/health-scenario.ts) を使う。
- ログイン、保存、取得など、前の結果を使う手順は一つのテスト内で順番に実行する。個々のテストも必要なデータを自分で用意し、別のテストの後処理に頼らない。
- `.concurrent` でファイル内のテストを追加並列化しない。独立したシナリオは別ファイルへ分ける。
- 固定の共有ポートや共有出力ファイルを使わない。外部の本人確認はテスト用に差し替え、Local・Preview・Dev・ProdのDBへ接続しない。

3は同時実行数の上限であり、ファイル数の上限ではない。
ファイルを増やしても、同時に実行される任意の組み合わせで独立性を保つ。
