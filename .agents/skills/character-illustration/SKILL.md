# キャラ設定からキャラクターイラストを作る

キャラクター制作で、背景付きのキャラクターイラスト（一枚絵）を作るときに使う。
[rpg-character-profile](../rpg-character-profile/SKILL.md) の設定と「イラストの構図」から依頼文を作り、Codex CLIの画像生成で1枚作る。
ドット絵のスプライトシートは [character-sprite-sheet](../character-sprite-sheet/SKILL.md) で作る。

## 呼び出し

- ユーザーがこのスキルを明示したときだけ使う。
- イラストやキャラクターの話題になっただけでは使わない。
- `agents/openai.yaml` の `allow_implicit_invocation: false` を保つ。

## Codexに渡すもの

| 渡すもの | 内容 |
|---|---|
| キャラ設定の全文 | rpg-character-profile の出力。修正があった場合は、最新の修正を統合した全文 |
| 依頼文 | 下の「依頼文の型」を、キャラ設定と「イラストの構図」から埋めたもの |
| スプライトシート（任意） | ユーザーが指定したときだけ添付する。服・色・装備をそろえるための見本 |

## 出力先

character-sprite-sheet と同じ `output/characters/<キャラID>/` に置く。
キャラIDは名前をローマ字にした小文字の英数字とハイフンにする（例：`rita-postol`）。

| ファイル | 内容 |
|---|---|
| `profile.md` | キャラ設定の全文。character-sprite-sheet で作ったものがあればそれを使う |
| `illustration-request.md` | 依頼文 |
| `illustration.png` | 生成されたイラスト（加工しない）。既にあれば `illustration-v2.png` のように別名にする |
| `illustration.codex-prompt.md` | Codexに実際に渡した全文 |
| `illustration.codex-reply.md` | Codexの返答（画像生成に使ったプロンプトの報告） |

## キャラ設定の探し方

次の順に探し、最初に見つかったものを使う。

1. ユーザーが指定したファイルや本文
2. 出力先の `profile.md`
3. この会話で rpg-character-profile が出した設定

どれもなければ、ユーザーに設定の全文を求める。
会話中の設定を使うときは、要約せず、最新の修正を統合した全文を `profile.md` に書き出す。
既存の `profile.md` と会話中の設定が食い違う場合は、どちらを使うかユーザーに確認する。
設定に「イラストの構図」がなければ、依頼文を作る前にユーザーに構図を相談する。

## 依頼文の型

下の固定文は変えずに使い、【】の中をキャラ設定から埋める。

- 「■タッチ」の塗りの固定文は、AIの描き込みすぎ（影の段数、光源、肌のつや）を防ぐためのもの。
- 絵柄・顔と体形の固定文は、アニメ風に寄りすぎないためのもの。
- 構図は「イラストの構図」の表から書き写す。光の【方向と色】は、表の「時間帯・光」から書き写す。
- ポーズ・表情には、口を開けた表情を書かない。笑顔は「口を閉じたまま微笑む」のように書く。
- 必ず守る特徴は、6項目を短い日本語1行に縮める。character-sprite-sheet の依頼文と同じ1行にする（例：`女性。オレンジのボブ。深緑の丸帽子、茶色の肩掛け鞄、短槍。`）。
- 最後の一文（スプライトシートに合わせる指示）は、スプライトシートを添付するときだけ入れる。

```
JRPGのキャラクターイラストを1枚作ってください。背景付きの一枚絵です。

■タッチ
絵柄：ゲームのキャラクター設定画風のイラスト。細く均一な線画と、影1段だけの平塗り。アニメや漫画の記号的な表現（大きな目、単純化した鼻と口、汗や効果線）は使わない。
顔と体形：顔の比率は現実の人に近づけ、目は小さめで、瞳のハイライトは小さく1つ。鼻と口は小さく自然に描く。口は閉じる。6〜7頭身で、手足は自然な長さ。
塗り：平塗り。影は1段で、境界ははっきりさせる。グラデーション、塗りむら、紙や絵の具の質感は使わない。
色：全体に彩度を抑えた、落ち着いた色。空や背景も鮮やかにしすぎない。
光：光源は1つ（【方向と色】）。リムライト、強い反射光、光の粒、レンズフレア、ブルームは入れない。
肌：基本の肌色と影色の2色だけで塗る。影は前髪の下、首、服の影が落ちる所だけ。膝、肘、指先、頬に赤みを入れない。肌にむら、斑点、白い光の点、つやを描かない。膝や脚の骨と筋肉の形を描き込まない。
線：細く均一な線。線の色は黒ではなく、各部の暗い同系色。
背景：人物と同じ線画と平塗りで描く。人物より彩度とコントラストを下げ、描き込みを減らす。
避けるもの：アニメ風、萌え絵、大きくきらきらした瞳、口を開けた笑顔、水彩のにじみ、写真のような写実、3D、厚塗り、グラデーション、過剰な描き込み、ドラマチックな照明、強い陰影。

■構図
画面：縦長（2:3）
場面・背景：【】
カメラ：【】
ポーズ・表情：【】

■キャラクター
【名前。年齢、性別、職業。体格】
衣装：【衣装】。配色は【主な配色】、差し色は【差し色】。
必ず守る特徴：【性別。髪色と髪型。特徴3点】
装備：【装備の左右と持ち方】

完成したドット絵のスプライトシートを添付した場合は、服・色・装備をそれに合わせてください。
```

画面の縦横比は、イラストの使い道が決まったらそれに合わせる。

## 手順

1. **材料をそろえる**：キャラ設定を上の順に探し、キャラIDを決めて `profile.md` を用意する。
2. **依頼文を作る**：型を埋めて `illustration-request.md` に保存し、ユーザーに見せる。ユーザーが生成まで依頼している場合はそのまま次へ進み、依頼文の相談だけを求めている場合は送らずに止める。
3. **Codexに依頼する**：

   ```bash
   python3 .agents/skills/shared/scripts/codex_image.py \
     --out-dir output/characters/<キャラID> --name illustration \
     --request output/characters/<キャラID>/illustration-request.md \
     --profile output/characters/<キャラID>/profile.md
   ```

   ユーザーがスプライトシートの添付を求めたときだけ、次の2つを足す。

   ```bash
     --image <スプライトシートのPNG> --image-role "キャラクターの服・色・装備の見本。ドット絵の画風やポーズは写さない"
   ```

   Codexの実行には数分かかるので、Bashのタイムアウトを最大にするか、バックグラウンドで実行する。
   モデルは `~/.codex/config.toml` の設定を使う。ユーザーがモデルを指定したときだけ `--model` を付ける。
4. **見せる**：保存された `illustration.png` を、ユーザーが画像を見られる方法で表示し（Claudeのデスクトップアプリでは `SendUserFile` の `display: "render"`）、ファイルの場所と画像サイズを伝える。
5. **止める**：生成物を加工しない。気に入らない場合は、同じ依頼文でもう一度生成するか、依頼文をどう直すかをユーザーに相談する。

## うまくいかないとき

| 症状 | 対応 |
|---|---|
| `生成画像が見つかりませんでした` | `illustration.codex-reply.md` でCodexの返答を読み、利用上限や拒否の理由をユーザーに伝える |
| 利用上限に達した | 返答にある再開時刻をユーザーに伝えて止める |
| 影や肌の描き込みが多い | 固定文は変えずに、構図（肌の広い面が大きく写らないか）を見直すことをユーザーに提案する |
