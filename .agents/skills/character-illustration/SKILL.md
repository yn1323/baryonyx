# キャラ設定からキャラクターイラストを作る

キャラクター制作で、背景付きのキャラクターイラスト（一枚絵）を作るときに使う。
[rpg-character-profile](../rpg-character-profile/SKILL.md) の設定と「イラストの構図」から依頼文を作り、Codex CLIの画像生成で1枚作る。
イラストは、そのキャラが戦闘・パーティ・性格のどれかで活躍した瞬間を切り抜いた、見せ場の一枚にする。
ドット絵のスプライトシートは [character-sprite-sheet](../character-sprite-sheet/SKILL.md) で作る。

## 呼び出し

- ユーザーがこのスキルを明示したときだけ使う。
- イラストやキャラクターの話題になっただけでは使わない。
- `agents/openai.yaml` の `allow_implicit_invocation: false` を保つ。

## Codexに渡すもの

| 渡すもの | 内容 |
|---|---|
| キャラ設定の全文 | rpg-character-profile の出力。修正があった場合は、最新の修正を統合した全文 |
| 依頼文 | 下の「依頼文の型」を、キャラ設定と「イラストの構図」から埋めたもの |
| スプライトシート（任意） | ユーザーが指定したときだけ添付する。服・色・装備をそろえるための見本 |

## 出力先

character-sprite-sheet と同じ `output/characters/<キャラID>/` に置く。
キャラIDは名前をローマ字にした小文字の英数字とハイフンにする（例：`rita-postol`）。

| ファイル | 内容 |
|---|---|
| `profile.md` | キャラ設定の全文。character-sprite-sheet で作ったものがあればそれを使う |
| `illustration-request.md` | 依頼文 |
| `illustration.png` | 生成されたイラスト（加工しない）。既にあれば `illustration-v2.png` のように別名にする |
| `illustration.codex-prompt.md` | Codexに実際に渡した全文 |
| `illustration.codex-reply.md` | Codexの返答（画像生成に使ったプロンプトの報告） |

## キャラ設定の探し方

次の順に探し、最初に見つかったものを使う。

1. ユーザーが指定したファイルや本文
2. 出力先の `profile.md`
3. この会話で rpg-character-profile が出した設定

どれもなければ、ユーザーに設定の全文を求める。
会話中の設定を使うときは、要約せず、最新の修正を統合した全文を `profile.md` に書き出す。
既存の `profile.md` と会話中の設定が食い違う場合は、どちらを使うかユーザーに確認する。
設定に「イラストの構図」がなければ、依頼文を作る前にユーザーに構図を相談する。
構図が活躍の瞬間になっていない場合（笑いの場面の再現、立っているだけの構図など）は、rpg-character-profile の「イラストの構図」の基準で構図の案を作り、ユーザーに確認してから `profile.md` を更新する。

## 依頼文の型

下の固定文は変えずに使い、【】の中をキャラ設定から埋める。

- 絵柄（画風や顔立ち、頭身）は指定せず、画像生成に任せる。
- 「■線」「■塗りと光」は、影を3段までに限り、濃い影を使う場所、肌の塗り、テカリの禁止を決めて、陰影の描き込みすぎを防ぐためのもの。
- 構図は「イラストの構図」の表から書き写す。光の【方向と色】は、表の「時間帯・光」から書き写す。
- ポーズは、動作を1つにし、手足と持ち物の位置を画面の左右で書く（例：「画面の左側の手で杖を持つ」）。本人から見た左右は書かない。振り返る、体をひねる、腕を体の後ろへ回す姿勢は書かない。
- 表情は口を閉じたものにし、目は開けて描く。糸目や閉じた目の笑顔のようなアニメ特有の表現は、「目を開けたまま、まぶたを少し下げて微笑む」のように言い換える。
- 眉間の深いしわ、にらむ目、歯を食いしばる顔は書かない。真剣な場面でも、「落ち着いた自信のある目で前を見る」のように表す。
- 必ず守る特徴は、6項目を短い日本語1行に縮める。character-sprite-sheet の依頼文と同じ1行にする（例：`女性。オレンジのボブ。深緑の丸帽子、茶色の肩掛け鞄、短槍。`）。
- 最後の一文は、Codexに渡すキャラ設定の全文（フレーバーテキストの出来事や、アニメーションの各コマの手の動きなど）が、場面とポーズに混ざらないようにするための固定文。変えずに入れる。

```
JRPGのキャラクターイラストを1枚作ってください。背景付きの一枚絵です。人物は1人だけ（敵や動物は1体まで）。文字は入れない。

■線
鉛筆やつけペンで描いたような、強弱のある手描きの線。輪郭は太めに、内側の線は細く少なめにする。顔の中の線は特に細く、少なくする。線の色は黒ではなく、各部の暗い同系色。

■塗りと光
光が当たる面、影、濃い影の3段で塗る。濃い影は、服の重なりや脇の下など、光が届かない狭い部分だけに使う。
影の境界は、面の向きが大きく変わる所ははっきり、なだらかな面ではやわらかくぼかす。
布、木、石、革には、塗りの筆跡がわずかに残る程度の質感を入れてよい。肌は明るい肌色と影色の2色で塗り、むら、斑点、赤み、つやを入れない。
髪、肌、金属、布、道具のどこにも、テカリ（白い光沢、光の筋、ハイライトの線）を入れない。
光源は1つ（【方向と色】）。リムライト、光の粒、レンズフレアは入れない。
色は彩度を抑えた落ち着いた色。背景は人物より淡く、描き込みを減らす。

■構図
画面：縦長（2:3）
人物の大きさ：人物（頭から足まで）が画面の高さの3分の2以上を占めるように、大きく描く。背景と小物は人物の周りに見える範囲で描く。
場面・背景：【】
カメラ：【】
ポーズ：【体の向き。手足の位置と持ち物を画面の左右で書く】
表情：【口を閉じた表情】

■キャラクター
【名前。年齢、性別、職業。体格】
衣装：【衣装】。配色は【主な配色】、差し色は【差し色】。
必ず守る特徴：【性別。髪色と髪型。特徴3点】

添付したキャラ設定は人物を理解するための資料です。場面とポーズは、この依頼文の「■構図」だけに従ってください。
```

画面の縦横比は、イラストの使い道が決まったらそれに合わせる。

## 手順

1. **材料をそろえる**：キャラ設定を上の順に探し、キャラIDを決めて `profile.md` を用意する。
2. **依頼文を作る**：型を埋めて `illustration-request.md` に保存し、ユーザーに見せる。ユーザーが生成まで依頼している場合はそのまま次へ進み、依頼文の相談だけを求めている場合は送らずに止める。
3. **Codexに依頼する**：リポジトリ直下で次の1行を実行する。WindowsのPowerShellとmacOSのターミナルのどちらでも同じコマンドで動く（行末の `\` での改行や `&&` はPowerShellで使えないため、1行のまま使う）。

   ```bash
   uv run --no-project python .agents/skills/shared/scripts/codex_image.py --out-dir output/characters/<キャラID> --name illustration --request output/characters/<キャラID>/illustration-request.md --profile output/characters/<キャラID>/profile.md --model gpt-6-astra
   ```

   ユーザーがスプライトシートの添付を求めたときだけ、同じ行の末尾に次の2つを足す。

   ```text
   --image <スプライトシートのPNG> --image-role "キャラクターの服・色・装備の見本。ドット絵の画風やポーズは写さない"
   ```

   Codexの実行には数分かかるので、Bashのタイムアウトを最大にするか、バックグラウンドで実行する。
   モデルは `--model` で必ず明示し、`~/.codex/config.toml` の設定に任せない。ユーザーが別のモデルを指定したときは、`gpt-6-astra` をその値に置き換える。
4. **見せる**：保存された `illustration.png` を、ユーザーが画像を見られる方法で表示し（Claudeのデスクトップアプリでは `SendUserFile` の `display: "render"`）、ファイルの場所と画像サイズを伝える。
5. **止める**：生成物を加工しない。気に入らない場合は、同じ依頼文でもう一度生成するか、依頼文をどう直すかをユーザーに相談する。

## うまくいかないとき

| 症状 | 対応 |
|---|---|
| `生成画像が見つかりませんでした` | `illustration.codex-reply.md` でCodexの返答を読み、利用上限や拒否の理由をユーザーに伝える |
| 利用上限に達した | 返答にある再開時刻をユーザーに伝えて止める |
| 影や肌の描き込みが多い | 固定文は変えずに、構図（肌の広い面が大きく写らないか）を見直すことをユーザーに提案する |
| 手や腕が反対に曲がる、左右が入れ替わる | ポーズの動作を減らし、手足の位置を画面の左右で書き直すことをユーザーに提案する |
| 見せ場がなく地味、またはフレーバーテキストの再現になる | rpg-character-profile の「イラストの構図」の基準で、活躍の瞬間の構図に直すことをユーザーに提案する |
