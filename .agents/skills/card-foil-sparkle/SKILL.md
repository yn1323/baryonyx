# カードのキラキラ（ホロ・ラメ）の作り方

レアカードのキラキラは、1つの光り方ではなく、役割の違う層を重ねて作る。
層を増やすほど豪華になるので、品質に合わせて層の数と強さを段階的に足し、上の品質ほど「当たりを引いた」と感じさせる。
このゲームでは、キラキラを☆（レア度）ではなく、1つずつ違う品質に結び付ける。
層の種類、出し方、作り方の一般的な技法と出典は [techniques.md](references/techniques.md) にある。
このゲームでの規則（品質ごとの層、置く場所、付ける対象）は、[カードのキラキラ](../../../doc/art/direction.md#カードのキラキラ)を正本にし、値をこのスキルへ写さない。

## 最初に確認すること

1. **正本の規則**：[カードのキラキラ](../../../doc/art/direction.md#カードのキラキラ)の、品質ごとの層と置く場所を読む。[エフェクトの描き方](../../../doc/art/direction.md#エフェクトの描き方)（計算で描く、滑らかな光の絵にする）にも従う。
2. **既存の部品**：[CardFoil](../../../client/Assets/Baryonyx/Shared/UI/Cards/CardFoil.cs)（重ねる層と値の渡し方）と、そのシェーダー `Baryonyx/UI/CardFoil` を使い回す。層を足すときは、このシェーダーに足し、別のシェーダーへ式を写さない。
3. **描画経路**：重ねる先のCanvasのRender Mode、カメラとBloom、絵と文字の重なり順（挿絵 → キラキラ → 帯・文字）を確かめる。`Screen Space - Overlay` にはBloomが掛からないため、にじみは式で描く。
4. **品質の出どころ**：キラキラの強さを決める品質が、データのどこにあるかを確かめる（スキルは [CardSkill](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkill.cs) の `Quality`、装備とボーナスは定義の上限と1つずつの倍率から求める）。品質ごとの見え方は [品質のデバッグルーム](../../../doc/features/screens.md#品質のデバッグルーム) で倍率を動かして確かめる。品質がまだない対象に推測で値を置かない。仮に置くときは、正本に「仮」と理由を書く。

## 進め方

1. **感じさせたいことを決める**：B・Cのカードは静かに、Sは「手に取って眺めたい」まで豪華に、と段階の差を言葉にする。全部の品質を同じ派手さにしない。
2. **層を選ぶ**：光の帯・ラメ・漂う光の粒・ホロの虹色・光のスポットから、品質ごとに足す層を正本の表で決める。主役は絵であり、キラキラは絵を引き立てる側に回す。豪華さの出し方は、[正本](../../../doc/art/direction.md#カードのキラキラ)の「白っぽさ」の規則に従う。
3. **時間を決める**：光の帯は数秒に1回横切る程度にし、ずっと光らせない（目が慣れて特別感が消える）。ラメは粒ごとに位相をずらして瞬かせ、全体が同時に明滅しないようにする。カードごとに乱数の種を変え、並んだカードが同時に光らないようにする。
4. **値の渡し方**：品質と乱数の種は、マテリアルを分けずに頂点の値（`RawImage.color` など）で1枚ずつ渡し、バッチを崩さない（[値の渡し方](../vfx-authoring/references/procedural-shapes.md)）。
5. **置く**：絵の上・帯や文字の下に重ね、絵の透明な所（下端のディザなど）には出さない。コスト・属性・説明文・キーワードの読みやすさを落とさない。画面ごとのカードの生成スクリプトで層を作り、手で置かない。
6. **白っぽさを抑える**：層は加算で重なるため、上の品質ほど挿絵が白くかすみ、絵の色が抜けやすい。抑えるときは、粒の芯の瞬きは残し、先に広く薄く効く層を弱める。挿絵全体に掛かるホロの虹色、粒の外側のにじみ、粒の密度の順に下げ、光の帯は細いまま強さだけを下げる。上の品質ほど層が多いという差は崩さない。
7. **確かめる**：品質S・A・Cを並べて、差が段階的に分かるかをコマで撮って見比べる（[コマの撮り方](../vfx-authoring/references/procedural-shapes.md#止めたコマを撮る)）。明るい絵と暗い絵の両方で読めるか、文字が読めるか、手札で透けた状態・暗くした状態でも破綻しないかを見る。明滅は[安全と読みやすさ](../vfx-authoring/SKILL.md#安全と読みやすさ)の基準内に収める。見た目を調整したときは、変更前のシェーダーを一時的に戻して同じ時刻のコマを撮り、変更前後を並べて比べる（撮り終えたら変更後へ戻す）。
8. **展示室と報告**：カードを出す画面の生成をし直し、[展示室](../../../doc/features/showcase.md)で変わったカードを確かめる。端末での負荷と見え方は未確認として報告に残す。

## 見直すときの問い

- 品質が1つ上がるごとに、層が増えるか強くなるのが見て分かるか。
- 文字・コスト・属性アイコン・説明文が、キラキラで読みにくくなっていないか。
- 光の帯やラメが、全カードで同時に光っていないか（位相がずれているか）。
- 一様に明滅しているだけになっていないか（帯は流れ、ラメは瞬き、虹色はゆっくりずれる、と動き方が違うか）。
- 絵の透明な所や枠の外にはみ出していないか。
- 暗くしたカード（エネルギー不足）では、キラキラも一緒に暗くなるか。
- 品質Sで、挿絵が白くかすまず、絵の色が残っているか。
