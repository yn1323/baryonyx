# カードのキラキラ（ホロ・ラメ）の作り方

レアカードのキラキラは、1つの光り方ではなく、役割の違う層を重ねて作る。
層を増やすほど豪華になるので、レア度に合わせて層の数と強さを段階的に足し、上のレア度ほど「当たりを引いた」と感じさせる。
層の種類、出し方、作り方の一般的な技法と出典は [techniques.md](references/techniques.md) にある。
このゲームでの規則（レア度ごとの層、置く場所、仮のレア度）は、[カードのキラキラ](../../../doc/art/direction.md#カードのキラキラ)を正本にし、値をこのスキルへ写さない。

## 最初に確認すること

1. **正本の規則**：[カードのキラキラ](../../../doc/art/direction.md#カードのキラキラ)の、レア度ごとの層と置く場所を読む。[エフェクトの描き方](../../../doc/art/direction.md#エフェクトの描き方)（計算で描く、滑らかな光の絵にする）にも従う。
2. **既存の部品**：[CardFoil](../../../client/Assets/Baryonyx/Shared/UI/Cards/CardFoil.cs)（重ねる層と値の渡し方）と、そのシェーダー `Baryonyx/UI/CardFoil` を使い回す。層を足すときは、このシェーダーに足し、別のシェーダーへ式を写さない。
3. **描画経路**：重ねる先のCanvasのRender Mode、カメラとBloom、絵と文字の重なり順（挿絵 → キラキラ → 帯・文字）を確かめる。`Screen Space - Overlay` にはBloomが掛からないため、にじみは式で描く。
4. **レア度の出どころ**：キラキラの強さを決めるレア度が、データのどこにあるかを確かめる（スキルは [CardSkill](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkill.cs) の `Rarity`）。レア度が未決の対象に推測で値を置かない。仮に置くときは、正本に「仮」と理由を書く。

## 進め方

1. **感じさせたいことを決める**：☆の低いカードは静かに、☆5は「手に取って眺めたい」まで豪華に、と段階の差を言葉にする。全レア度を同じ派手さにしない。
2. **層を選ぶ**：光の帯・ラメ・漂う光の粒・ホロの虹色・光のスポットから、レア度ごとに足す層を正本の表で決める。主役は絵であり、キラキラは絵を引き立てる側に回す。
3. **時間を決める**：光の帯は数秒に1回横切る程度にし、ずっと光らせない（目が慣れて特別感が消える）。ラメは粒ごとに位相をずらして瞬かせ、全体が同時に明滅しないようにする。カードごとに乱数の種を変え、並んだカードが同時に光らないようにする。
4. **値の渡し方**：レア度と乱数の種は、マテリアルを分けずに頂点の値（`RawImage.color` など）で1枚ずつ渡し、バッチを崩さない（[値の渡し方](../vfx-authoring/references/procedural-shapes.md)）。
5. **置く**：絵の上・帯や文字の下に重ね、絵の透明な所（下端のディザなど）には出さない。コスト・属性・説明文・キーワードの読みやすさを落とさない。画面ごとのカードの生成スクリプトで層を作り、手で置かない。
6. **確かめる**：☆1〜☆5を並べて、差が段階的に分かるかをコマで撮って見比べる（[コマの撮り方](../vfx-authoring/references/procedural-shapes.md#止めたコマを撮る)）。明るい絵と暗い絵の両方で読めるか、文字が読めるか、手札で透けた状態・暗くした状態でも破綻しないかを見る。明滅は[安全と読みやすさ](../vfx-authoring/SKILL.md#安全と読みやすさ)の基準内に収める。
7. **展示室と報告**：カードを出す画面の生成をし直し、[展示室](../../../doc/features/showcase.md)で変わったカードを確かめる。端末での負荷と見え方は未確認として報告に残す。

## 見直すときの問い

- ☆が1つ上がるごとに、層が増えるか強くなるのが見て分かるか。
- 文字・コスト・属性アイコン・説明文が、キラキラで読みにくくなっていないか。
- 光の帯やラメが、全カードで同時に光っていないか（位相がずれているか）。
- 一様に明滅しているだけになっていないか（帯は流れ、ラメは瞬き、虹色はゆっくりずれる、と動き方が違うか）。
- 絵の透明な所や枠の外にはみ出していないか。
- 暗くしたカード（エネルギー不足）では、キラキラも一緒に暗くなるか。
