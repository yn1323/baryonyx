# ドット絵の画風の固定文（日本語）。Codex CLI・ChatGPTの画像生成の依頼文に入れる。
# 正本：doc/art/direction.md の「ドット絵の制作規格」。正本を変えたら、同じ変更でこのファイルを直す。
# 「#」で始まる行は説明であり、依頼文には入れない。「[名前]」の行は部品の区切りで、次の区切りまでの1行がその部品である。
# 部品の組み合わせ方は .agents/skills/pixel-art-standards/SKILL.md の「指示文に入れる規格」にある。
# 組み合わせた文は `python3 .agents/skills/shared/scripts/pixel_style.py ja <部品名>...` で出力できる。

[touch]
スーファミ後期〜GBAのRPGのドット絵。はっきりした四角いドットで描き、1ドットを1色で塗る。

[light]
光源は左上。輪郭はセルアウトにする。背景と接する外周に輪郭を描き、影側は暗く、光が当たる左上側は接する部分の色に合わせて明るくする。腕と胴の境目などの内側の線は、外周より明るく、その場所の色より2段暗い色で描く。

[colors]
色数は32色以内。陰影は段を分けて塗り、色の境目にディザ（2色の市松模様）を入れる。アンチエイリアスは輪郭の内側にだけ、中間色を1ドット単位で置く。背景側へのぼかしや滑らかなグラデーションは使わない。

[detail]
しわや細部まで多めに描き込む。

[character]
彩度と明るさを高めにした鮮やかな色。目は点や短い線で描く。

[background]
中間色の多い落ち着いた色。輪郭は弱めにし、キャラより目立たせない。
