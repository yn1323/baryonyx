## 2. まず押さえる専門用語

| 用語 | 意味 | 指示の使い方 |
|---|---|---|
| Layering／レイヤリング | 役割の異なる描画を重ねる | 本体・光・霧・粒・歪みを独立させる |
| Core／コア | 主役となる明るい芯 | 細く鮮明にし、画面全体を白くしない |
| Halo／ハロー | 芯の周囲に広がる淡い光 | コアより広く、低い強度で重ねる |
| Hard／Soft Edge | 硬い輪郭／柔らかい輪郭 | 斬撃本体は硬く、周囲の光や霧は柔らかく |
| Emission／発光 | シェーダーが出力する発光色 | 明るさをHDRで調整する。実ライトとは別 |
| Bloom／ブルーム | 明るい部分のにじみ | 光の広がりに使う。霧の形の代わりにはならない |
| Additive／加算合成 | 背景に色を足す | 光、火花、放電など。重なりすぎると白飛びする |
| Alpha Blending | 透明度で背景と混ぜる | 煙、毒霧、暗いモヤ、液体など |
| Premultiplied Alpha | RGBにαを事前に掛ける方式 | 素材・シェーダー・ブレンド設定を一致させる |
| Mask／マスク | 見える範囲・濃さを制御する値 | 中心・外周・まだら模様を個別に制御する |
| Falloff／フォールオフ | 距離などに応じた減衰 | 外周へ滑らかに薄くする |
| Wisps／ウィスプ | 細くたなびく煙・魔力の筋 | 一様な丸い雲を避け、流れを持つ細い霧を足す |
| Turbulence／乱流 | 不規則な渦や揺らぎ | 大きなうねりと小さな揺れを重ねる |
| Curl Noise | 渦を持つノイズの流れ | 粒子を滑らかに巻き上げる。単なる位置乱数とは違う |
| UV Distortion | 画像を読む座標の歪み | 炎や霧の模様自体をうねらせる |
| UV Scroll／Panning | 画像座標の移動 | 流れる炎、電流、光の筋を表す |
| Dissolve／Erosion | マスクを使って形を侵食・消失させる | 全体一様のフェードだけで終わらせない |
| Flipbook | 連続画像の再生 | 炎・煙・爆発の形そのものを変化させる |
| Trail／Ribbon | 動いた軌跡の帯 | 剣、矢、魔力の尾。幅や透明度を長さ方向に変える |
| Taper／テーパー | 先細り | 軌跡の尾や雷の枝を細くする |
| Fresnel／フレネル | 視線角度による反射率の変化 | 氷や結界の縁を強調。単独では屈折にならない |
| Refraction／屈折 | 透過した背景が曲がって見える表現 | 水・氷の厚み。画面空間で近似する方法もある |
| Specular Highlight | 光源を反射した鋭い光 | 氷・水・金属の表面に硬さを出す |
| Normal Map | 表面の法線方向を変える画像 | 面の凹凸・微細な反射・屈折の揺れを作る |
| Distortion | 背景などの歪み | 熱波、衝撃、空間魔法。UV Distortionと対象を区別する |
| Anticipation／Impact／Dissipation | 予兆／衝撃のピーク／消散 | 時間のメリハリを設計する |
| Secondary Motion | 主動作に続く副次的な動き | 命中後の破片、煙、火花、波紋 |
| Controlled Randomness | 意図した範囲内のランダム性 | 方向・シルエットは維持して寿命・幅・間隔を変える |

「Core」「Halo」「Wisps」「Slash Arc」などは表現の説明語。すべてがUnityの同名コンポーネントやShader Graphノードとして存在するわけではない。

## 3. 使う機能・素材の選び方

| 要素 | 主な担当 | 向くもの |
|---|---|---|
| C# | 制御、生成、タイミング、パラメーター設定 | Prefab構築、攻撃と着弾の同期、粒子やメッシュの生成 |
| Particle System／Shuriken | 粒・煙・火花などの発生と移動 | 細かな飛散、軌跡、煙、補助レイヤー |
| VFX Graph | GPU中心の視覚効果の構成 | 多数の粒子や複雑な流れ。対応環境を確認して選ぶ |
| HLSL／Shader Graph | ピクセルごとの色・透過・歪み | 発光、濃淡、流れ、Dissolve、氷・水の質感 |
| TrailRenderer／LineRenderer／専用メッシュ | 線や帯の形状 | 剣の軌跡、雷、ビーム、魔力の流れ |
| メッシュ | 明確な立体形状 | 氷柱、岩、矢、結界、円錐、衝撃波 |
| コード生成テクスチャ／バッファ | 計算結果の再利用 | ノイズ、密度、法線、亀裂をC#／GPUで生成。外部画像は読み込まない |
| ポストプロセス・ライト | 周囲とのなじみ・画面への影響 | Bloom、局所的な照明、色調整 |

今回の実装は、形・濃淡・材質もコードで生成する。C#で粒を動かすだけにせず、プロシージャルノイズ、距離関数、解析的なマスク、頂点変形、生成メッシュ、必要ならボリューム描画を組み合わせる。Flipbookは用語として説明するが、外部Flipbookの採用はしない。連続フレームを使う場合もコードから生成し、通常は連続時間の関数を直接評価する。詳細は第10章。
