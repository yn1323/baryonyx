# RPGの技・属性別レシピ

章番号は元のガイド「RPG戦闘VFX：専門用語・計算式・Claudeへの指示ガイド」（2026-10-26）の番号である。第1章・第7章・第8章は [SKILL.md](../SKILL.md)、第2〜3章は [glossary.md](glossary.md)、第4章（F1〜F12）は [formulas.md](formulas.md)、第5章は [recipes.md](recipes.md)、第6章は [prompts.md](prompts.md)、第9章は [sources.md](sources.md)、第10章（P1〜P6）は [procedural.md](procedural.md)、第11章は [lessons.md](lessons.md) にある。[S1] などの記号は [sources.md](sources.md) の資料を指す。
このゲームで作った技の経験（斬撃に霧を置かない、落雷の光り直し、昇る線と地割れなど）は [lessons.md](lessons.md) を先に読む。

ここからは制作上の提案。各項目の「指示例」は、Claudeへ渡す技ごとの追記として使える。

## 01 炎

- 用語：Turbulence、Curl Noise、Domain Warping、Procedural Density、Embers、Heat Distortion。
- 層：明るい炎の芯／薄い炎の舌／煙／火の粉／弱い熱歪み。色だけでなく形と速度を変える。
- 式・機能：F3・F4・F5と第10章P2・P3・P5。3Dノイズの密度場と上昇する流れで形を作る。薄い炎は手続き的な板・メッシュでも作れるが、厚い炎や煙は密度積分を検討。外部Flipbookは使わない。[S2][P-S1][P-S2]
- 指示例：「大きな炎の巻き上がりと細かな揺らぎを別スケールで作る。炎先端は分裂・侵食して消す。煙はα合成、火の粉と発光層は加算を候補にし、全体を同時に膨張・消滅させない。」

## 02 氷

- 用語：Refraction、Fresnel、Specular、Roughness Variation、Cracks、Frost Mist。
- 層：面を持つ氷柱／内部の色の濃淡／霜・亀裂／砕けた破片／冷気。
- 式・機能：F10・F12。生成メッシュと、コードから生成する法線・粗さ・霜・亀裂。第10章P4・P6。氷全体を発光させるとガラス状の硬さが失われやすい。
- 指示例：「青い不透明な塊ではなく、透明部・曇り・鋭い反射を混在させる。屈折は弱く、エッジの反射は明瞭に。破片はサイズと回転を変え、冷気だけを柔らかく流す。」

## 03 雷

- 用語：Branching、Jitter、Flicker、Electrical Arc、Emissive Core。
- 層：主放電／細い分岐／淡いハロー／着弾フラッシュ／火花。
- 式・機能：F2・F7・F11。LineRendererまたはリボン・専用メッシュ。線分上の点へ、線の進行方向と直交する変位を加える。根元と命中点は固定する。
- 指示例：「主線は太く、枝は先細り。短時間の形状保持と不規則な更新で放電感を作る。常時同じ明るさのジグザグ線にせず、短い閃光と消散を重ねる。」参考分解は[S7]。

## 04 水

- 用語：Refraction、Specular Highlight、Flow Map、Foam、Droplets、Ripples。
- 層：まとまった水の本体／反射／薄い縁／泡／大小の飛沫／着弾の波紋。
- 式・機能：F6・F9・F10・F12。生成水流メッシュ、波の勾配から求める法線、曲率や流速に基づく泡マスク、球状の液滴。流れの方向はベクトル場として数式定義し、外部Flow Mapは使わない。
- 指示例：「青い煙として作らず、連続した液体の塊と、そこから分離する液滴を作る。着弾で大きな飛沫、遅れて細かな滴、さらに波紋を出す。屈折と鋭い反射を調整する。」

## 05 風

- 用語：Vortex、Ribbon、Flow Field、Turbulence、Air Distortion。
- 層：薄い弧状の流れ／微粒子／葉・砂／弱い背景歪み。
- 式・機能：F7・F8。流れを示す帯と、同じ流れに乗る粒子を組み合わせる。
- 指示例：「白い不透明な輪を重ねるだけにせず、見える筋と透明な空間を交互に作る。大きな巻き流れは統一し、その中の細い筋だけ揺らす。」

## 06 土・岩

- 用語：Ground Eruption、Fracture、Debris、Dust Plume、Ballistic Motion。
- 層：地面の亀裂／大きな岩／小破片／粉塵／着地時の土煙。
- 式・機能：F6。立体メッシュとライティング、破片の回転、粉塵のα合成。
- 指示例：「大岩は遅く重く、小片は速く飛ばす。地面の予兆から順番に隆起し、岩が出た後も粉塵が残る。全破片へ同じ初速・大きさ・寿命を使わない。」

## 07 光・聖

- 用語：Radial Rays、Halo、Emission、Bloom、Light Shafts。
- 層：明るい中心／細い放射線／淡い光の面／ゆっくり広がる輪／微粒子。
- 式・機能：F2・F9・F11。光線の本数・長さ・幅を変える。
- 指示例：「中心のピークと周辺の柔らかい光を分ける。白い円で覆わず、線の隙間と背景の透けを残す。必要なら周囲を照らすライトも別に使う。」Bloomの設定は[S8]。

## 08 闇

- 用語：Vortex、Inward Flow、Dark Core、Distortion、Noise Erosion。
- 層：暗い本体／吸い込まれる霧／紫などの細い縁光／消える粒子。
- 式・機能：F1・F5・F8・F10。暗い本体はα合成など、縁光は加算を候補にする。
- 指示例：「暗い霧と発光を別レイヤーにし、中心へ引かれる流れを作る。黒い円を置くだけにせず、縁を崩して内部の動きを見せる。加算だけで暗闇を作ろうとしない。」

## 09 毒・酸

- 用語：Wisps、Turbulence、Bubbles、Viscous Drips、Noise Erosion。
- 層：滞留する毒霧／濃い液体／泡／粘る液滴／接触部の反応。
- 式・機能：F4・F5・F6。煙・液体・泡で異なるマテリアルと速度を使う。
- 指示例：「緑の発光煙だけにせず、暗く濃い部分と透ける霧を混ぜる。泡の膨張・破裂と、遅い液滴を足す。酸なら接触箇所に局所的な腐食や蒸気を付ける。」液体としての毒の制作例は[S9]。

## 10 自然・植物

- 用語：Growth Animation、Spline、Vertex Animation、Leaf Flutter、Spores。
- 層：根や蔓の成長／葉／花びら／胞子や光。
- 式・機能：曲線上の位置p(u)、F3・F8。メッシュの先端方向へ段階的に伸長。
- 指示例：「全体を均等に拡大せず、根元から先端へ成長させる。蔓本体は明確に、葉の揺れと胞子は遅れて続く。植物の実体と魔法の発光を分ける。」

## 11 剣・斧の斬撃

- 用語：Slash Arc、Weapon Trail、Ribbon Mesh、Taper、Directional Dissolve。
- 層：切れ味を見せる芯／薄い幅広の帯／火花／命中地点の短い閃光。
- 式・機能：F2・F5・F7。刃の根元と先端の履歴からリボンを構築。画面上の弧の面積と武器速度に合わせる。
- 指示例：「刃の動きに沿う弧状の帯を作り、先頭は鋭く、尾は薄く崩す。芯・ハロー・細いウィスプを分け、斬撃全体を均一にぼかさない。」武器軌跡の作者解説は[S10]。

## 12 槍・刺突

- 用語：Thrust Streak、Directional Stretch、Piercing Trail、Impact Flash。
- 層：前方へ伸びる細い軌跡／先端の閃光／小さな放射状の火花／必要なら背後へ抜ける光。
- 式・機能：F6・F7。方向dに沿うp=p0+d*distance、横幅は細く保つ。
- 指示例：「横へ払う斬撃の弧を使わず、突き方向に細長い形で加速感を出す。先端だけを強くし、貫通演出と通常命中を分ける。」

## 13 弓矢・投擲

- 用語：Projectile、Ballistic Arc、Trail、Homing、Impact Burst。
- 層：矢などの本体／控えめな飛翔軌跡／命中火花／破片や属性効果。
- 式・機能：F6・F7。放物運動は物理弾道、ベジェは見た目の誘導軌道。どちらを使うか明示する。
- 指示例：「本体が見える太さを保ち、尾が矢より主張しすぎないようにする。発射・飛翔・命中の3段階を分け、軌跡は途中で突然切らず古い尾から消す。」

## 14 打撃・体当たり

- 用語：Impact Burst、Shockwave、Dust Burst、Directional Debris、Hit Stop。
- 層：接触点の短い閃光／衝撃の輪／飛散物／遅れて立つ粉塵。
- 式・機能：F3・F6・F9。相手から離れる方向へ飛ばす。Hit Stopは描画素材ではなく戦闘全体の短い停止演出。
- 指示例：「接触した位置と瞬間へピークを合わせる。衝突方向に偏った破片と、地面を広がる粉塵で重量感を作る。画面揺れは必要に応じて独立制御する。」

## 15 爆発・衝撃波

- 用語：Flash、Fireball、Shockwave、Debris、Smoke Plume、Secondary Explosion。
- 層：非常に短いフラッシュ／膨張する炎／衝撃波／速い破片／遅い煙。
- 式・機能：F3・F6・F9。炎と煙に異なる速度曲線を使う。膨張するノイズ密度場とプロシージャル破片で構成し、外部Flipbookは使わない。
- 指示例：「一つの球を拡大するだけにせず、閃光→急膨張→破片→煙の順でエネルギーを落とす。副爆発は主爆発より弱く、時刻をずらす。」

## 16 ビーム・砲撃

- 用語：Beam Core、Outer Glow、Charge-up、UV Scroll、Endpoint Impact。
- 層：発射口の溜め／細い高輝度の芯／外側の流れ／終点の持続衝突／消える残光。
- 式・機能：F2・F3・F4。始点と終点を結ぶメッシュやLineRenderer。幅の時間変化を制御する。
- 指示例：「均一な棒ではなく、芯と外層を分け、電流や光の筋を進行方向へ流す。着弾点の反応を別に作り、停止時は芯を先に消し外層を残す。」

## 17 重力・空間

- 用語：Vortex、Attraction Field、Radial Distortion、Compression、Orbital Motion。
- 層：中心へ引かれる粒／軌道を回る破片／背景歪み／圧縮と解放の衝撃。
- 式・機能：F8・F10。見た目用の引力なら `acceleration = strength * normalize(center-p) / max(distance*distance, minRadius*minRadius)`。中心近くの発散を制限する。
- 指示例：「粒を中心へ直進させるだけでなく、旋回しながら収束させる。歪みは中心へ向かう流れに合わせ、圧縮の後に短く解放する。」

## 18 音・振動

- 用語：Wavefront、Concentric Rings、Oscillation、Interference。
- 層：進む波面／薄い同心円／局所的な空気の歪み／反応する微粒子。
- 式・機能：F9。表現用の波は `wave = sin(k*r - omega*t)*exp(-attenuation*r)`。輪の範囲でマスクし、画面全体を波打たせない。
- 指示例：「輪を等間隔で置くだけでなく、発生の強弱と減衰を作る。音の波と衝撃の爆発で、速度・明るさ・持続を区別する。」

## 19 回復・蘇生

- 用語：Spiral Motion、Soft Glow、Pulsing、Sparkles、Reformation。
- 層：足元の薄い光／上昇する帯／小さな輝き／身体を包む淡いハロー。
- 式・機能：F2・F3・F8・F11。蘇生は形成・再集合を追加する。
- 指示例：「攻撃の瞬間的な閃光より穏やかに立ち上げる。粒を全て等速上昇させず、帯・微粒子・ハローの速度を分ける。足元から身体へ順番に届く光で回復を見せる。」段階構成の作例は[S11]。

## 20 強化・チャージ

- 用語：Aura、Charge-up、Energy Accumulation、Pulse、Weapon Imbue。
- 層：集まる粒子／身体や武器沿いの光／周期的な弱い脈動／完了時の解放。
- 式・機能：F3・F8・F11。溜めの強さqに対し、発光を `I = Imin + (Imax-Imin)*pow(q,power)` のように増加。
- 指示例：「最初から最大強度にせず、集まる量・密度・脈動を段階的に上げる。強化完了の一度きりの光と、強化中の持続オーラを分ける。」

## 21 盾・結界

- 用語：Fresnel Rim、Impact Ripple、Hex Pattern、Crack Propagation、Shield Dissolve。
- 層：薄い膜／縁の反射・発光／微細な模様／被弾点から広がる波紋／破壊時の亀裂。
- 式・機能：F9・F10。波紋の距離は平面・球面など形状に合わせる。単純なワールド距離は曲面上の正確な距離ではない。
- 指示例：「常時は背景を見せ、被弾した場所だけ一時的に濃くする。被弾のたび全体が同じ点滅をするのではなく、接触点から波を広げる。」作例は[S12]。

## 22 呪い・吸収

- 用語：Tether、Energy Drain、Inward Flow、Orbiting Runes、Dissolve。
- 層：対象上の紋様／まとわりつく霧／対象から術者へ流れる筋／到着時の反応。
- 式・機能：F5・F6・F8。二次ベジェ等で流れを接続し、術者・対象の移動へ追従。
- 指示例：「吸収の方向を対象→術者で一貫させる。紋様は遅く、吸われる粒子は速くする。呪いは滞留、吸収は移動という違いを作る。」

## 23 状態異常

- 用語：Status Loop、Orbit、Petrification、Surface Mask、Localized Arcs。
- 例：睡眠＝遅い浮遊、麻痺＝局所的な短い放電、混乱＝不安定な周回、石化＝表面を進む硬化マスク。
- 式・機能：F3・F5・F8・F11。ループの開始・維持・解除を分ける。
- 指示例：「色替えだけで区別せず、動きの意味を変える。通常攻撃や敵予告を読めるように主な表示位置を固定し、必要な状態だけを持続表示する。」

## 24 高速移動・瞬間移動

- 用語：Afterimage、Motion Streak、Dissolve／Reassemble、Departure／Arrival Burst。
- 層：出発点の短い反応／移動方向の筋／段階的に薄くなる残像／到着点の収束。
- 式・機能：F3・F5・F7。残像の古さaに対して `opacity = exp(-decay*a)`。
- 指示例：「残像は同じ濃さで並べず、古いものから薄くする。瞬間移動は出発と到着の演出を同期し、歩行の軌跡とは分ける。」

## 25 召喚・魔法陣

- 用語：Radial Reveal、Polar Coordinates、Portal、Particle Assembly、Runic Ring。
- 層：外周リング／順に現れる紋様／門や光柱／集まる粒子／召喚物の形成。
- 式・機能：極座標 `r=length(p)`、`angle=atan2(p.y,p.x)` を用いて円周方向の表示を制御。F3・F5・F8。
- 指示例：「全パーツを同時に出さず、外周→紋様→中央→召喚物の順で展開する。装飾の回転速度と明るさを分け、召喚完了後に余韻だけを残す。」

## 25種類を画像なしで実装する場合の対応表

| 技・属性 | 主な代替技術 |
|---|---|
| 炎 | 上昇する3D fBm密度＋Domain Warping、生成火花、必要なら密度積分 |
| 氷 | 生成メッシュ＋Voronoi境界＋計算法線＋反射・屈折・吸収 |
| 雷 | 固定端点を持つ分岐ポリライン＋幅カーブ＋距離によるハロー |
| 水 | 生成曲面＋複数波＋微分法線＋球状液滴＋解析的な泡と波紋 |
| 風 | 生成リボン＋螺旋・渦のベクトル場＋低密度ノイズ |
| 土・岩 | 破砕風の生成メッシュ＋放物運動＋ノイズ密度の粉塵 |
| 光・聖 | 放射状の距離マスク＋細い光線メッシュ＋HDR発光 |
| 闇 | 暗い密度場＋吸引するベクトル場＋手続き的な縁光 |
| 毒・酸 | 低速の密度流＋生成球の泡＋液滴メッシュ＋侵食マスク |
| 自然・植物 | スプラインに沿う管状メッシュ＋葉の生成＋頂点揺れ |
| 剣・斧 | 刃の根元と先端からリボン生成＋先細り＋距離ハロー |
| 槍・刺突 | 方向に伸びる生成メッシュ＋先端の解析的フラッシュ |
| 弓矢・投擲 | コード生成の矢・投射物＋弾道計算＋先細りの帯 |
| 打撃・体当たり | 放射線・リングのマスク＋方向性のある破片と粉塵 |
| 爆発 | 膨張する密度場＋発光・吸収＋生成破片＋衝撃リング |
| ビーム・砲撃 | 管／帯メッシュ＋距離コア＋流れるノイズ＋端点衝撃 |
| 重力・空間 | 解析的引力場＋螺旋軌道＋画面空間の歪み |
| 音・振動 | 減衰する波動関数＋伝播する円環マスク |
| 回復・蘇生 | 螺旋の生成帯＋解析的な輝点＋時間カーブ |
| 強化・チャージ | 収束する粒子軌道＋距離ハロー＋段階的な脈動 |
| 盾・結界 | 生成ドーム＋Fresnel＋数式の格子＋被弾波紋 |
| 呪い・吸収 | 手続き的紋様＋ベジェ沿いの帯＋暗い密度ノイズ |
| 状態異常 | 周回軌道・局所放電・表面の進行マスクを効果別に生成 |
| 高速移動・瞬間移動 | 生成ストリーク＋Dissolve。外部残像画像は使わない |
| 召喚・魔法陣 | 極座標の円環・線分・多角形＋生成メッシュの段階表示 |

高速移動でキャラクターの残像自体が必要なら、既存キャラクターの描画を複製・再描画するか確認する。この資料の「外部画像なし」はVFX素材の新規画像依存を禁止するもので、既存キャラクターの表示方法を変更する指示ではない。
