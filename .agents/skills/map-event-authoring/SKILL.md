# 地図のマスの出来事を足す・変える・消す

入れ子の地図のマスの出来事は、種類・窓・台の絵・配置・値段・サーバーのマスの表・地図エディター・テスト・文書にまたがる。
一緒に直す所の一覧の正本は[出来事を足す・変える・消すとき](../../../doc/features/world-atlas/square-events.md#出来事を足す変える消すとき)であり、このスキルには写さない。
出来事の中身と置き方の決まりは[入れ子の地図](../../../doc/features/world-atlas.md)の各節、地図エディターの操作は[地図エディター](../../../doc/features/screens/debug-rooms.md#地図エディター)にある。

## 使う場面

- 出来事の種類を足す・消す・名前を変えるとき
- 賭けのような遊び方を足す・消すとき
- マスの設定の項目（戦闘の敵・Lv・強さ、拾い物の物と数など）を足す・消すとき
- どのマスに何を置くかを変えるとき（1マスなら地図エディターか `place_events.py set`、端末で決めた配置なら `place_events.py apply` で足りる）
- APKの地図エディターで「コピー」したJSONを貼られ、配置へ反映するとき（[地図エディター](../../../doc/features/screens/debug-rooms.md#地図エディター)の「端末で決めた配置を反映する」）
- 地図エディターを直すとき、出来事にかかわる差分をレビューするとき

## 手順

1. **何が変わるかを書き出す**：種類・遊び方・設定のどれを、足すのか、変えるのか、消すのかを並べる。設定なら、どの種類の設定で、配置のJSONの項目名と書き方（空のときの意味も）を決める。
2. **正本の一覧を上から当てる**：[出来事を足す・変える・消すとき](../../../doc/features/world-atlas/square-events.md#出来事を足す変える消すとき)の表の行ごとに、直す所があるかを確かめ、作業の一覧にする。当てはまらない行は、理由を一言添えて外す。
3. **地図エディターを必ず直す**：正本の表の「地図エディター」の行を、足した物にも消した物にも当てる。消した種類や設定のボタン・欄・説明を残さない。
4. **配置を直す**：正本の表の「配置と値段」の行に従う。世界地図は手で決めた地図（[マスに置いた出来事](../../../doc/features/world-atlas/square-events.md#マスに置いた出来事)）なので、決まりで置き直さず、[マスの付け替え](../../../doc/features/world-atlas/square-events.md#マスの付け替え)の方法で1マスずつ直す。
5. **作り直す**：開いているシーンを保存して別のシーンへ移ってから、地図と地図エディターを作り直す（正本の表の下の手順）。
6. **確かめる**：下の「確かめること」を行う。
7. **記録する**：仕様の該当する節と、地図エディターの操作の表を同じ変更で直し、変更と判断の記録にユーザーの言葉と決めたことを書く。
8. **報告する**：直した所、確かめたこと、確かめていないこと（端末での見え方、戦闘の勝率など）を分けて書く。

## 確かめること

- [ ] 正本の表の行を、すべて直したか、外した理由を書いた。
- [ ] 地図エディターで、足した種類を置け、足した設定を変えられ、保存したものが配置のJSONに残る。消した種類や設定は出ない。
- [ ] 地図エディターの「試す」で、足した・変えた出来事の窓が開く。
- [ ] 世界地図に全種類が残っている（`WorldAtlasLayoutTests`）。
- [ ] 正本の表のテストを、関係するクラスに絞って流した（[作業中に実行するPlayModeテスト](../../../doc/rules/client-testing.md#作業中に実行するplaymodeテスト)）。
- [ ] 地図エディターを撮影し、ボタン・欄・一覧が重ならずに並んでいる。
- [ ] 戦闘の強さが変わったなら、自動対戦で測り直したか、測っていないことを報告に書いた。
- [ ] 値段が変わったなら、サーバーのマスの表を作り直し、`server/` の world-atlas のテストを流した。
