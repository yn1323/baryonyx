# 地面・遠景・マテリアル・テクスチャの作り方

3Dの舞台の「物」と「材質」の作り方と、作業でつまずいた点をまとめる。
置く物の密度の決め方は [set-dressing.md](set-dressing.md) に分ける。
値と配置の正本は[3Dの舞台の仕様](../../../../doc/art/hd2d-stage.md)、部品と実装の対応は仕様の[実装との対応](../../../../doc/art/hd2d-stage.md#実装との対応)とし、ここには写さない。
カメラ・光・レンズと色・炎は [hd2d-lighting-vfx の3Dの舞台](../../hd2d-lighting-vfx/references/hd2d-3d-stage.md) に従う。
対象はUnity `6000.6.0f1`、URP `17.6.0`（Universal Renderer）である。

## 舞台の組み方

- **UVを世界の長さで決める**：床・壁・箱は「1枚のタイルが何m」で頂点のUVを作る。マテリアルのタイル数を面ごとに変えずに済み、どの面でもドットの大きさがそろう。
- **板の横向きは法線と上向きの外積で決める**：最初の実装では書き割りと壁の絵が左右反転した。横の向きは、法線（水平にしたもの）と上向きの順の外積 `Cross(normal, up)` で作る。外積の順を逆にすると反転する。
- **舞台は生成のたびに作り直す**：舞台のPrefabとマテリアル・Profile・法線マップはコード（`StageSetAssets`・`StageDressing`）が作り直す。Inspectorで変えた値は次の生成で消えるため、決めた値はコードへ書く。メッシュはまとめたアセットごと作り直すため、古い配置のメッシュは残らない。
- **シーンの舞台を替えるときは置き換える**：シーンへ舞台を置く処理が「なければ置く」だけだと、別の舞台へ替えても古い舞台が残る。置いてあるPrefabの元（`PrefabUtility.GetCorrespondingObjectFromSource`）が違えば消して置き直す。
- **床を分ける**：モバイルの描画（Forward）は、1つの物を照らす追加のライトが4つまでである。大きな床を1枚にすると、松明の光が一部しか届かない。床を数m角に分け、近くのライトをそれぞれ受けさせる。まとめて描く草の房と汚しも同じ理由で区画に分ける。
- **キャラが立つ床を高さ0にする**：周りの地面は少し下げる。キャラの接地影は床のすぐ上にあり、キャラが立つ床を周りより上げたとき、影が床に埋もれた。地面の汚しと足元の陰は、床より少し上で接地影より下に置く（[小物と汚し](../../../../doc/art/hd2d-stage.md#小物と汚し)）。
- **遠景は描いた絵か、少し自分で光らせる**：空・遠い山並み・遠い荒野は、光も霧も受けない描いた遠景にし、時間帯の色を絵に描き込む。光を受けるマテリアルにすると、主光源の向きで暗くなり、霧で色が消える。カメラを向く近めの遠景（森の奥）は光を受けるマテリアルにし、テクスチャ自体を弱い自己発光にも使う。
- **書き割りで奥行きを足す**：崩れた柱や木を切り抜きの板にして、キャラと遠景の間や画面の端に置く。カメラが動くと遠景とずれ、奥行きが伝わる。端で切れた絵は、切れた側が画面の外へ出る向き（必要なら左右反転）に置く。
- **ドットの細かさをキャラに合わせる**：キャラが立つ奥行きで、舞台の1ドットがキャラの1ドットに近くなるよう、タイルの長さと1枚絵の大きさを決める（[配置を計算で決める](../../hd2d-lighting-vfx/references/hd2d-3d-stage.md#配置を計算で決める)）。粗いと、キャラの手前の地面だけが大きなドットのモザイクに見える。

## マテリアルの選び方

| 物 | マテリアル | 気を付けること |
|---|---|---|
| 地面・壁・段・箱 | Simple Lit（鏡面なし）と法線マップ | タイルはRepeat。法線マップは絵の明るさから作る |
| 切り抜きの書き割り・小物 | Simple Litの切り抜きと法線マップ（縁を丸める） | 裏も描く（Cull Off）。影を落とす |
| 草・シダ・茂み・枝葉・細い枯れ枝 | 草と葉のシェーダー（`Baryonyx/HD2D/Stage Foliage`） | 法線マップは付けない。揺れの大きさを物ごとに決める |
| 地面の汚し | Simple Litの切り抜き | 影を落とさない。90度単位で回す |
| 足元の陰 | 接地影のシェーダーの、薄く広いマテリアル | 半透明で舞台のレンズの後に描くため、ぼける距離には付けない |
| 空・遠い山並み・荒野 | 描いた遠景（`Baryonyx/HD2D/Painted Distance`） | 星と月は白より明るくしてBloomで光らせる |
| カメラを向く近めの遠景 | Simple Litと弱い自己発光 | 奥から差す主光源を受けないため |
| 炎・火の粉・光の筋・門の光 | 計算で描くシェーダー | hd2d-lighting-vfx に従う |

- 色（`_BaseColor`）は、1より小さくして奥へ下げ（下から見上げる枝葉、キャラを目立たせる明るい石舞台）、1より大きくして暗く描かれた絵を持ち上げる（影の中の木箱）。
- 1つのテクスチャを光の違う場所で使い分けるときは、マテリアルを分けて色だけ変える（広間の壁と柱など）。

## テクスチャの作り方

正本の規格は[3Dの舞台の仕様のテクスチャ](../../../../doc/art/hd2d-stage.md#テクスチャ)と[ドット絵の制作規格](../../../../doc/art/direction.md#ドット絵の制作規格)に従う。
生成と変換は [pixel-art-standards](../../pixel-art-standards/SKILL.md) と一緒に使う。

1. **物ごとに大きさを決める**：置く大きさ（m）と、1mあたりのドット数を先に決める。ドット数はキャラが立つ奥行きのドットの細かさから決め、草の葉や剣の刃のような1〜2ドットの細い線を持つ物だけ1.5〜2倍にする。細い線は、地面と同じ細かさでは半分以上が透明の画素に負けて消え、かたまりに見えた。
2. **依頼文を作る**：[stage_requests.py](../scripts/stage_requests.py) に物の説明（見る向き、縦横比、下端が地面に接するか、物の中身）と、昼か夜か、切り抜き・汚し・タイル・1枚絵・描いた遠景のどれかを渡す。固定の段落（ドット絵の規格、3Dのテクスチャとしての条件、背景の透過など）はスクリプトが付ける。光を受ける物は昼間の自然な明るさで描かせ、夜や夕暮れの色はゲームの光で付ける。描いた遠景だけは時間帯の色で描かせる。
3. **生成する**：書き出された `run_all.sh` で並行生成する（[codex_image.py](../../shared/scripts/codex_image.py)、人物を描かないため `--profile` なし、6〜8並列で1枚2〜3分）。生成画像は `output/`（Git対象外）に置く。
4. **並べて見る**：生成画像を縮小して1枚に並べ、依頼どおりの物か、マゼンタに中間色が混ざっていないかを見る。
5. **縮める**：[fit_textures.py](../scripts/fit_textures.py) で、物の範囲の縦横比を測って寸法を決め、[stage_texture.py](../../hd2d-lighting-vfx/scripts/stage_texture.py) で面積平均して格子を作り直し、32色へ減らす。夜空のように暗い色が大半を占める絵は、`--bright-colors 8 --bright-threshold 200` で明るい画素（月・星）の色を別に確保する。マゼンタのにじみが縁に残る絵（砂ぼこりのように縁がまばらな物）は、縮める前に削る画素数（`erode`）を増やす。
6. **拡大して確かめる**：変換後の絵を最近傍で拡大して並べ、細い線が残っているか、タイルの継ぎ目、マゼンタのにじみを見る。つぶれた物は、1mあたりのドット数を上げてやり直す。
7. **検査して `.aseprite` にする**：pixel-art-standards の検査スクリプト（`--kind background`）で検査し、`png_to_aseprite.lua` で舞台のフォルダーへ `.aseprite` にする。macOSのAsepriteは `/Applications/Aseprite.app/Contents/MacOS/aseprite` にある。拡張機能（pixellab）の読み込みエラーが毎回表示されるが、変換には影響しない。
8. **記録する**：使った依頼文と変換の指定（`conversions.json`）を `client/ArtSource/Stages/prompts.json` に追記する。

## 法線マップ

- 絵から計算する（`Hd2dRelief.Normals`）。明るいドットを高く、暗いドットを低くするため、石の目地や葉のすき間が沈む。隣り合う2ドットの差で傾きを求めるため、ディザの市松模様は打ち消し合い、ざらつきにならない。
- 切り抜きは、透明な縁から内側3ドットで丸く盛り上げる。カメラを向く板でも、横から当たる松明の光で縁の片側が明るくなり、厚みが出る。
- Simple Litは法線マップの強さ（`_BumpScale`）を無視する（URP 17.6の `SimpleLit.shader` が `BUMP_SCALE_NOT_SUPPORTED` を定義する）。強さは画像に焼き込み、`ReliefMap` の引数で決める。石や木は強め、草地や落ち葉は弱めにする。
- 法線マップは接線の向きで凹凸を回すため、メッシュに接線が必要である。コードで作るメッシュは `RecalculateTangents` を呼ぶ（`MeshStore.Add` が呼ぶ）。
- 1ドット1法線のまま、Point・ミップマップなし・非圧縮で読み込む。圧縮やミップマップを使うと、ドットごとの凹凸がにじむ。
- 物を草と葉のシェーダーへ移すなどで使わなくなった法線マップは残る。作り直したあとは、マテリアルから参照されない `〈名前〉Normal.png` を消す。
- 暗く見える物の原因を切り分けるときは、法線マップを外したマテリアルを一時的に貼って撮り比べる。影の木箱は、外しても同じ暗さだったため、原因は影と絵の色だと分かった。

## 草と葉のシェーダー

- `Simple Lit` の板は、表から当たる光しか受けない。月や松明が草の房の奥にあるTopでは、房が黒い塊に見えた。葉は薄く光を透かすため、草と葉のシェーダーで裏からの光も弱めて受け、環境光は板の向きと真上の間の向きで受ける。
- 裏から見えた面は、`SV_IsFrontFace` で法線を反転する。
- 風の揺れは、色・影・深度の3つのパスで同じ式を使う。式が違うと、影や舞台のレンズの深度が見た目の位置とずれる。垂れ下がる枝葉は、下端を揺らす。
- 揺れはPlay Mode中の `_Time` で動く。確かめるときは、カメラの揺れ（`Hd2dStageCamera.SwayRadius`）を実行中だけ0にして、数秒あけた2枚の同じ範囲の差を、動かない物（岩）と比べる。カメラが揺れたままでは、動かない岩も同じだけ変わって見えた。

## つまずいた点

- **Simple Litの鏡面反射で床が白っぽくなる**：Simple Litの `_SpecularHighlights` は、0が鏡面あり、1が鏡面なしである。0のままだと、月明かりが床全体で照り返して白く霞んだ。
- **コードで付けたキーワードが消える**：URPはマテリアルを読み込み直すときに、プロパティからキーワードを決め直す。Emissionは `globalIlluminationFlags` に `RealtimeEmissive` がないと `_EMISSION` が外れる。法線マップも `_BumpMap` のテクスチャと `_NORMALMAP` を一緒に設定する。キーワードだけでなく、元になるプロパティとフラグを設定する。
- **マテリアルに古い値が残っていた**：マテリアルを作り直す処理が、指定した値だけを設定していた。シェーダーの値の意味を変えたとき、前のシェーダーの値が残った。値の意味を変えたら全部の値を設定し直し、別のシェーダーへ替えるときはキーワードを消す。
- **夜空の月が平らな灰色になった**：暗い青が画面の大半を占める夜空を32色に減らすと、明るい色が暗い色に吸われ、月の模様が消えて灰色の円になった。明るい画素から別に8色を選ぶ指定を変換スクリプトに加えた。
- **手前の草が写っていなかった**：ホームの手前の茂みを、画面の下端が地面と交わる距離より手前に置いていたため、画面の下の外にあった。置く前に画面の位置を計算する。
- **手前の大木が大きすぎた**：画面の縁を飾るつもりでカメラの近くに置いた大木は、近すぎて画面の両脇を覆った。縁はカメラから少し離した木と、上端の枝葉で飾る。
- **小さい物がかたまりに見えた**：草の房・枯れ枝・剣を地面と同じ細かさに縮めると、細い線が消えて色のかたまりになった。細い物は細かくする。
- **奥の物が写らなかった**：戦闘の背景で、額縁の大物の奥の組を描いた遠景の板より奥に置き、板に隠れて写らなかった。描いた遠景の奥行きを確かめ、その手前に置く（[戦闘の背景](../../../../doc/art/hd2d-stage.md#戦闘の背景)）。
- **作り直しが実行されていなかった**：Unity CLIの `eval_file` で舞台を作り直すと、5秒を超える処理は応答待ちが切れてエラーが返る。たいていは処理が続いて終わるが、再コンパイルの直後に投げた1回は実行されず、古いPrefabのまま撮影していた。処理の最後に印のファイルを書かせて終わりを待ち、作り直した後はPrefabの更新時刻か値を確かめてから撮る。
- **床の模様の上の汚しがしみに見えた**：古城の絨毯の上に割れた床石の汚しを敷くと、明るい色のしみに見えた。模様のある床では、汚しを床の外だけに置く。
