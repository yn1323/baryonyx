# 小物と汚しで密度を上げる

地面と背景だけの舞台は、光とレンズを整えても平らに見える。
このファイルは、小物・草の房・地面の汚し・足元の陰をどれだけ、どこに置くか（ごちゃごちゃ具合）の決め方と、置き方の手順・注意をまとめる。
物と材質の作り方は [stage-building.md](stage-building.md)、画面ごとに置いた物と置き方の決まりの正本は[3Dの舞台の仕様の小物と汚し](../../../../doc/art/hd2d-stage.md#小物と汚し)とする。

## ごちゃごちゃ具合の決め方

仕様の[小物と汚し](../../../../doc/art/hd2d-stage.md#小物と汚し)にあるとおり、オクトパストラベラーはドット絵のゲームに見えるぎりぎりの密度で絵を作った。
一方で、レベルアートの構図では、主役を明るく見せ、描き込みの多い所と空いた所を分け、物の大きさを変えて単調さを避けるとされる（[Composition in level design](https://www.gamedeveloper.com/design/composition-in-level-design)）。
この2つを合わせ、「休ませる所以外は描き込む」を基本にする。

- **休ませる所を先に決める**：キャラの足元の周り、技の演出が出る所、文字の後ろ、手前のUIの下には、背の高い物を置かず、地面の汚しや割れ目の小さな草だけにする。今の画面での範囲（足元から離す距離、空ける場所）は仕様の小物と汚しの置き方の決まりに従う。
- **それ以外の平らな所をなくす**：停止中の画面を見渡し、地面と背景だけの平らな面が画面の1/6ほど続く所があれば、何かを足す候補にする。
- **大・中・小・面を重ねる**：額縁になる大物（木・崖・岩の尖塔、5〜13m）、小物（0.6〜3m）、草の房や小石（0.3〜0.9m）、地面の汚し（1〜2m）の4段階を用意し、1つの場所に3段階以上を重ねる。例えば、大木の根元（大）に荷物（中）を置き、草の房（小）を添え、落ち葉（面）を敷く。
- **かたまりで置く**：小物を1つずつ散らさず、中の物1つに小の物2〜3つと面1つを寄せたかたまりで置き、かたまりの間を空ける。空いた間が休ませる所になる。
- **その場で起きたことを見せる**：場所ごとに、誰が何をしたかが分かる小物を1〜2種類置く（野営の荷物と薪、戦いの跡の骨と武器、門を守る古い像）。時間帯と土地に合わない物は置かない。
- **主役より目立たせない**：小物はキャラより明るさと彩度を抑える。主役（キャラ・焚き火・門）に光を集め、周りの小物は影や中間の明るさに置く。開けた所に彩度の高い汚しを置くと、しみに見える。
- **繰り返しを崩す**：同じ絵は、大きさ（2〜3割）・左右反転・90度回転で変え、等間隔に並べない。箱形の物は少し回す。散らす位置は乱数の種を固定して作る。
- **地面に食い込ませる**：立つ物には、足元に草の房を2〜3本添え、柔らかい陰を敷き、下端を数cm地面に沈める。地面に置いた板の下端がまっすぐな線で見えると、作り物に見える。

### 画面の帯ごとの置き場

見下ろしのカメラでは、画面の高さで奥行きとぼけ方が決まる。
帯ごとに置く物を変える。

| 帯 | ぼけ方 | 置く物 |
|---|---|---|
| 画面の下端の近く | 手前のぼけが最も強い | 地面の汚しだけ。背の高い物は、ぼけた暗い帯になる |
| キャラの足元の帯 | くっきり | 足元を空け、帯の左右の端に小物のかたまりと草の房 |
| キャラの奥から地面の端まで | 奥ほどぼける | 小物の主な置き場。その場で起きたことを見せる物をここに置く |
| 地面の端と遠景の境目 | ぼける | 茂み・草・書き割りで、地面と遠景の境目の直線を隠す |
| 画面の左右と上の縁 | 手前はぼける | 大物で額縁を作る（木、崖、垂れた枝葉） |

## 置き方の手順

1. **空いている場所を画面の座標で探す**：停止中のシーンを撮り、キャラ・既存の物・手前のUIのない領域を画面の座標で拾う。手前のUIはPlay Modeで `capture_game_view --source screen` を撮って確かめる。[stage_view.py](../scripts/stage_view.py) の `ground` で、その領域の地面の位置を求める。
2. **キャラの足元を測る**：停止中に `Hd2dUiBillboard.RefreshAll()` を呼び、各キャラの `ContactRenderer.bounds.center`（足元）と `VisualRenderer.bounds`（絵の範囲）を読む。`stage_view.py` の `box` で絵の画面の範囲を求め、小物がキャラの絵に重ならないかを確かめる。ただし、板の範囲は絵の余白を含むため、実際の絵より大きい。
3. **物の一覧を作る**：[ごちゃごちゃ具合の決め方](#ごちゃごちゃ具合の決め方)に沿って、場所ごとに大・中・小・面の物と、その場で起きたことを見せる物を選ぶ。物ごとに、大きさ（m）、作り方（板・箱・まとめた草・汚し）、マテリアルを決める（[マテリアルの選び方](stage-building.md#マテリアルの選び方)）。
4. **テクスチャを作る**：[テクスチャの作り方](stage-building.md#テクスチャの作り方)に従う。
5. **置く**：板の大きさは絵の縦横比から決める（幅か高さのどちらかを決める）。箱は原点で作ってから回して置く。草の房は数m四方ごとに1つのメッシュへまとめ、散らす範囲・間隔・除外の条件と乱数の種を決める。
6. **撮って直す**：[撮影での点検](#撮影での点検)の項目で確かめ、気になる所を元の解像度で切り出して前後を並べる。
7. **足元を避けているかをテストにする**：シーンを開いてキャラの足元を読み、小物と草の房が足元から離れていることをEditModeテストで確かめる。UIの配置が変わったときに気付ける。

## 作り方ごとの注意

- **小物は板と箱を使い分ける**：形が複雑な物（荷物、像、がれき）はカメラを向く切り抜きの板にする。法線マップで縁が丸く光るため、板でも厚みが出る。面の向きで明暗が分かれる箱形の物（木箱）は箱にする。
- **草の房はまとめて描く**：1本ずつ板にすると描く回数が増える。区画に分けるのは、モバイルの描画で1つの物を照らす追加のライトが4つまでだからである。
- **地面の汚しは90度単位で回す**：任意の角度で回すと、汚しのドットの格子が地面の格子とずれる。左右反転と90度の回転だけで変化を付ける。
- **足元の陰を付ける距離は仕様に従う**：陰は半透明で、舞台のレンズがぼかしたあとに描かれるため、付ける距離を舞台ごとに絞る（[小物と汚し](../../../../doc/art/hd2d-stage.md#小物と汚し)）。新しい舞台では、ぼけ始める距離を舞台のレンズの値から求めて決める。
- **主光源の影を確かめる**：大きな木や崖は、離れた所まで影を落とす。置く前に、主光源の向きと木や崖の高さから影の落ちる範囲を見積もり、撮影で暗く見えたら、影の中かどうかを先に疑う。日なたへ移すか、色で持ち上げる。
- **暗い物は光の近くに置く**：夜の舞台では、暗い色の物は逆光で背景に溶ける。点光源の近くに置き、火の光で照らす。
- **手前のUIの下は撮影で確かめる**：停止中の撮影には手前のUIが写らない。置き場所を決めたら、Play Modeで手前のUIごと撮り、隠れている物を空いた所へ移す。戦闘の手札・ボタン、Topのタイトルの周りの決まりは仕様に従う。

## 撮影での点検

停止中のGameビュー（カメラ）と、Play Modeの画面（手前のUIを含む）の両方で撮る。

- キャラと主役（焚き火・門）が、周りの小物より先に目に入るか。キャラの頭の上や体に小物が重なっていないか
- 地面と背景だけの平らな面が残っていないか。休ませる所は空いているか
- 小物が黒い塊や平らな色に見えていないか（主光源の影、裏からの光、暗く描かれた絵）
- 草の房の細い葉、剣の刃などの細い線が残っているか
- 地面に置いた板の下端がまっすぐな線で見えていないか。足元に草と陰があるか
- 地面の汚しが、しみや四角い縁に見えていないか。タイルの繰り返しが目立たないか
- ぼけた遠くに、くっきりした線（足元の陰）が浮いていないか
- 手前のUI・タイトルの文字・HPバーと重なっていないか
- 16:9以外の画面比率で、画面の端の物が切れて不自然になっていないか
