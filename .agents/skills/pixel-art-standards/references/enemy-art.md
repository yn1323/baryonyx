# 敵の絵の一括試作

敵の絵には専用の生成スキルがない。
2026-10-19に敵50体をまとめて試作したときの手順を、次に同じ作業をするときのために残す。
寸法・色数・画風は[ドット絵の制作規格](../../../../doc/art/direction.md#ドット絵の制作規格)に従い、[pixel-art-standards](../SKILL.md) と一緒に使う。

## そのときの道具

道具は、Gitの対象外の `output/enemies/` にだけある。
50体の一覧と設計値を直書きした使い捨ての道具で、フォルダーを消すとなくなる。
残っていれば、敵を足すときに写して使う。なければ、下の手順のとおりに作り直す。

| ファイル | 内容 |
|---|---|
| `roster.py` | 50体の一覧（名前、地域、大きさの区分、生まれ方と外見、配色、必ず残す特徴、弱点）と依頼文の型。敵ごとのフォルダーに `request.md` を書き出す |
| `run.sh` | 並列数とIDを受け取り、[codex_image.py](../../shared/scripts/codex_image.py) で1体1枚を生成する。`enemy.png` があるIDは飛ばす |
| `contact.py` | 生成した絵を並べた一覧のシートを作る |
| `spec.py`・`spec.json` | 英語のID、型、Lv100のステータスの設計表 |
| `to_sprite.py` | 生成画像を規格の大きさのPNGにする（手順5） |
| `agent-brief.md`・`common_skills.py`・`extract_usage.py`・`merge_usage.py`・`update_existing_skills.py` | 敵と技の定義の文書を書いた道具。サブエージェントへの指示と、共通技の「使う敵」の表の一括更新 |

## 手順

1. **画風見本を作る**：既存の敵の `.aseprite` を書き出したPNG（2026-10-19は ForestGuardian の128×128）を添える。`--image-role` には、タッチ（ドットの大きさ、塗り、描き込み、セルアウトの輪郭）だけを参考にし、形・ポーズ・苔などの題材は写さないと書く。この指定で、見本の形が混ざることはなかった。
2. **依頼文を書く**：1体1枚にし、次の順に書く。
   - 「■ドット絵の規格」：[指示文に入れる規格](../SKILL.md#指示文に入れる規格)の「キャラ・敵」の部品
   - 「■大きさ」：敵の大きさの区分（小・中・大）と、その寸法相当の粗さで体を画像いっぱいに描くこと。寸法は[画面と寸法](../../../../doc/art/direction.md#画面と寸法)の敵に合わせる
   - 「■魔物」：生まれ方と外見、配色
   - 「■ドット絵で必ず残す特徴」
   - 「■構図」：攻撃していない身構えた姿を1体、やや斜めの左向き。背景は単色の中間の灰色で、地面・影・枠・文字は描かない
   - 最後に「タッチは添付の画像を参考にして」
3. **生成する**：codex_image.py を並列で呼ぶ。2026-10-19は6並列で1体約1分、50体とも1回で成功し、利用上限には当たらなかった。
4. **一覧で見せて選んでもらう**：一覧のシートを作り、ユーザーに見せる。
5. **規格の大きさにする**：生成画像（1254×1254の「ドット絵風のイラスト」）の背景を四辺からの塗りつぶしで抜き、本体を切り出して長辺を規格の大きさに面積平均（BOX）で縮め、32色に減らして、左右中央・下ぞろえで置く。格子を復元する方法ではない。結果を[検査スクリプト](../SKILL.md#検査スクリプト)の `--kind enemy-small`・`enemy-medium`・`enemy-large` で確かめる。
6. **`.aseprite` にする**：[PNGから変換する](../SKILL.md#pngから変換する)に従う。置き場所とファイル名は、絵を読む [BattleEnemyLooksAssets](../../../../client/Assets/Baryonyx/Features/Combat/Editor/BattleEnemyLooksAssets.cs) の `EnemyArtFolder` と `ArtName` に合わせる。
7. **ゲームと文書にそろえる**：敵の定義は[敵の定義](../../../../doc/catalog/enemies/README.md)の書き方に従う。絵を読む生成（`Baryonyx > Combat > Create Enemy Looks`、`Baryonyx > Library > Create Screen Assets`）を実行し、展示室で確かめる。
