# RPGキャラ設定

人物としての魅力と、後で絵にできる具体性を備えたキャラ設定を日本語で作る。
このスキルの成果物は、設定文、動作設計、イラストの構図。画像の依頼文づくりと生成は含めない。
次の工程では、この設定の全文を材料に、[character-sprite-sheet](../character-sprite-sheet/SKILL.md) で全動作のドット絵スプライトシートを、[character-illustration](../character-illustration/SKILL.md) で背景付きのキャラクターイラストを、Codex CLIで作る（[キャラ制作の共通手順](../shared/character-pipeline.md)）。
モーションは、そのスプライトシートを下書きにして、ユーザーが手作業で仕上げる。
イラストのポーズと表情の規則は、この文書の「イラストの構図」を正本とし、character-illustration はそれに合わせて依頼文を書く。
ユーザーの最新の指定を優先し、既存キャラの変更は依頼された範囲にとどめる。

## 入力と範囲

名前、職業、種族、性別、外見、性格、既存設定など、与えられた材料から作成する。
「おまかせ」「1人作って」の場合は、足りない項目を創作して完成させる。
新規作成は指定がなければ1人。既存設定の編集では空白を勝手に改変の許可と解釈しない。
他キャラの情報が提供されている場合は、色・形・人物像の重複を避け、関係性に生かす。
他チャットを読む依頼がある場合は、利用可能なタスク閲覧ツールを使う。閲覧できない内容を読んだ扱いにしない。

「スプライト制作条件」と「戦闘スキル案」は標準出力に含めない。
解像度・頭身・画風・視点・キャンバス設定などの共通制作指示を別名で復活させない。
これらは次の工程のスキルの依頼文が持つ。
スキル名・効果・威力・倍率・ダウン値・クールダウンなどの性能案も追加しない。
職業や「回復役」「盾を使う」といった概念的な役割、動きに必要な装備設定は含める。
攻撃系・補助系のアニメーションは、戦闘スキルの性能を決めずに設計できる。
ユーザーがこれらの追加を明示的に求めた場合は、その範囲で応じる。

## 新規作成時の出力

完成した設定を一つの文書にまとめる。説明用の前置きや同内容のまとめを重ねない。
見出し相当の短いラベル、短い段落、比較しやすい表を使う。1人の設定は次の順序を基本とする。

| 項目 | 内容 |
|---|---|
| 二つ名・名前 | 職業の説明だけでなく、人物の印象が伝わるもの |
| キャラクターの核 | 仲間にしたくなる理由、本人が求めるもの、性格の面白い矛盾を1〜2文で |
| フレーバーテキスト | 具体的な出来事と会話で見せ、最後にオチをつける短文 |
| 基本設定・外見 | 年齢、性別、種族、職業、概念的な役割、体格、髪色・長さ・髪型、衣装、主な配色 |
| ドット絵で必ず残す特徴 | 下記の6項目を明記した表と、省略できる細部 |
| 経歴・目的・性格 | 冒険する理由、得意なこと、弱点、仲間への接し方。既知の仲間がいれば関係性も |
| 装備と持ち方 | 武器を持たない基本姿勢の両手の位置、戦闘態勢と攻撃での武器の左右の持ち手と構え方、武器以外の装備の位置、見た目を固定する条件 |
| 動きの個性 | 姿勢、重心、動きの速さ・大きさ、衣装や尾などの揺れ |
| アニメーション設計 | 下記6種類のフレーム数、各コマの動き、接続・保持・発生位置 |
| 台詞 | 加入、日常、得意な行動、苦戦、勝利などから3〜5場面。性格と口調を揃える |
| イラストの構図 | 下記の表。キャラが活躍した瞬間を切り抜いた、背景付きのキャラクターイラストの場面、光、カメラ、ポーズ、構図の型 |

設定の最後に、ドット絵は character-sprite-sheet、イラストは character-illustration で作れることを1行で添える。

修正依頼ではこの全文を毎回再出力せず、依頼された部分だけを更新する。
全文の再提示を求められたときは、各部分の最新の修正を統合する。

## 必ず残す外見は6項目

「性別・髪型・髪色」を基本情報として明記し、それとは別に識別特徴を3点選ぶ。
表の項目は「性別／髪型／髪色／特徴①／特徴②／特徴③」とする。
髪がないキャラなどは「なし」と明記し、6項目を埋めるために髪を追加しない。

この表は、小さな立ち姿でも残すものを絞るための欄である。各欄は15字前後の短い名詞句にし、文にしない。
髪型の欄には、輪郭に効く長さと形だけを書く（例：`肩甲骨まで届く高いポニーテール`）。
前髪の切り方や分け方は、輪郭を大きく変える場合だけ書く。

特徴3点は、輪郭、大きな衣装の色面、武器以外の代表的な装備、耳や尾などから選ぶ。
武器は基本姿勢に描かないため、特徴3点に入れない。
1つの特徴には物を1つだけ入れ、「色＋物」に、輪郭に効く形容を1つまで添える。
左右・向き・付け方、小さな部品（鍔、軸、帯、ボタン、留め具など）、素材や質感は書かない。
これらは「省略できる細部」や「装備と持ち方」に書く。
髪や性別を3点の枠で重複計上しない。瞳の色や刺繍など、細部だけに識別を頼らない。
種族に不可欠な耳・尾などは優先し、本数や形を装備・外見の記述とも一致させる。
基本外見と6項目の表で、色・髪の長さ・装備を食い違わせない。

| 欄 | 詳しすぎる例 | 書き方の例 |
|---|---|---|
| 髪型 | 後頭部の高い位置で結んだ、肩甲骨に届くポニーテール。前髪は眉の上で真っすぐ切りそろえる | 肩甲骨まで届く高いポニーテール |
| 特徴 | 藍色の上衣と、裾が大きく広がる黒い袴風のズボン。白い帯で上下を区切る | 裾の広がる黒い袴 |
| 特徴 | 右肩から左腰へ斜めに背負った白い巻物。両端の赤い軸が肩と腰から突き出る | 斜めに背負った白い巻物 |
| 特徴 | 腰に結んだ赤い長布。端が膝まで垂れ、先に金の房飾りが付く | 膝まで垂れる赤い腰布 |

右の例で削った「藍色の上衣」「白い帯」「赤い軸」「金の房飾り」は「省略できる細部」へ、「右肩から左腰」は「装備と持ち方」へ移す。

[ドット絵の制作規格](../../../doc/art/direction.md#画面と寸法)の味方キャラの、小さな立ち姿で見分けられることを内部の判断基準とし、形を増やしすぎない。
このサイズを説明する制作条件の節は出力しない。別の用途が明示されればそちらを優先する。
省略できる細部は設定には残してよいが、描画必須の6項目と区別する。

## フレーバーテキストの笑い

標準は、真面目な人物紹介より一段くだけた、はっきりオチのあるコメディ。
小さな出来事、本人の妙な理屈、短い掛け合い、意外な結果で人物を見せる。
「実はお茶目」「仲間から愛されている」と説明するだけで済ませない。
しんみりした余韻や教訓で締めず、最後の一文まで笑いにつなげる。
長さはおよそ100〜200字を目安とし、オチを成立させるために調整する。

笑いの強さの参考：

> 「無茶は駄目よ」
> そう言って仲間を休ませたエルナは、崖に生えた薬草を採りに登った。
> 「落ちたらどうする！」
> 「安心して！　骨折に効くやつだから！」
> 薬草の効能は、その日のうちに確かめられた。

この人物・台詞・骨折の筋を使い回さない。几帳面さ、食い意地、見栄、勘違い、
妙なこだわりなど、そのキャラ固有の性格から笑いを作る。
全員を無能や事故を起こす人にせず、得意分野の魅力も設定全体で残す。

## 装備から動作へつなげる

武器（剣・槍・杖・弓など攻撃に使う道具。盾も含める）は、戦闘態勢と攻撃のコマだけに描く。
基本姿勢・待機・歩行・戦闘不能・勝利では武器を持たせず、鞘に収めた武器や背負った武器も描かない。
基本姿勢から戦闘態勢へは絵を切り替えるだけとし、武器を取り出す・しまう途中のコマは作らない。

左右は本人を基準に統一する。武器、盾、本などを同時に扱える持ち方を決める。
両手が塞がっているキャラが手を掲げるなら、何を収納・持ち替えするかを動作に含める。
武器以外の装備は全コマで消さない。戦闘態勢と攻撃のコマ間で、武器を消したり、手を入れ替えたり、手を増やしたりしない。
設定上の小物を全部アニメーションで使う必要はない。
種族・体格・性格に合わせて動かし、全キャラに杖・詠唱・ケープを付けない。

## アニメーションの標準6種類

ユーザーから別指定がなければ、次のフレーム数を使用する。
アニメーションはユーザーが手作業で仕上げるため、コマ数を最小限にしている。
全動作の起点として、武器を持たずに静止して立つ「基本姿勢」を1コマ設計する。基本姿勢はアニメーションのコマ数には数えない。
武器を構えた姿勢は「戦闘態勢」の1コマとし、攻撃は戦闘態勢から始めて戦闘態勢へ戻す。
F1からFNは、動作を始める前の姿勢（基本姿勢、戦闘態勢、前の動作の最後のコマ）の次のコマから数える。
被弾はアニメーションを作らず、Unity側で基本姿勢を点滅させながら数px後ろへ動かして表す予定なので、設計しない。
スキルや補助の専用の動作は、ユーザーが求めた場合だけ、その範囲で追加する。

| 動作 | フレーム数 | 再生・接続 |
|---|---:|---|
| 待機 | 2 | 体は基本姿勢のまま動かさず、髪・服の裾・布などの揺れだけが違う2コマを交互に切り替える |
| 歩行 | 4 | ループ。方向ごとに必要 |
| 戦闘態勢 | 1 | 武器を構えた姿勢を保持。攻撃の前後に表示する |
| 攻撃 | 3〜4 | 戦闘態勢から1回再生して戦闘態勢へ戻る |
| 戦闘不能 | 1 | 最終コマを保持 |
| 勝利 | 1 | 最終コマを保持 |

武器を描くのは戦闘態勢と攻撃だけとし、基本姿勢・待機・歩行・戦闘不能・勝利には描かない。

各1方向の合計は6種類・12〜13フレーム。これは各動作のコマ枠数の合計であり、
重複姿勢を除いた固有画像数や、全方向を含む総数とは区別する。
方向数が指定されていなければ、勝手に4方向・8方向へ増やさない。

出力するアニメーション表の列は「動作／フレーム数／各コマの動き／接続・保持・発生位置」。
表の先頭に基本姿勢の行を置く（フレーム数は1、合計には含めない）。
各行にF1からFNまで、具体的な姿勢を順番に短く書く。全コマを省略しない。
一つのコマに複数の連続動作を詰めず、隣接するコマで動作の段階が伝わるようにする。
動作名と枚数だけの一般表を最終成果物にしない。毎回そのキャラの装備と個性に合わせる。

保持時間は新しいコマとして数えない。追加コマを標準に勝手に加えない。
待機・歩行は最終から先頭へつなぎ、ループを閉じるためのコマを無断追加しない。
待機の2コマは、体・顔・装備の位置を基本姿勢から変えず、揺れる部分だけを変える。
長い髪があれば髪を揺らし、短髪なら毛先・服の裾・マントや飾り布などを揺らす。
歩行4コマは、左右の足の接地と、両足が交差する中間姿勢を交互に置く。

戦闘態勢は、武器を構えて、いつでも攻撃に移れる姿勢の1コマにする。
体の向きは基本姿勢と同じにし、重心の落とし方や足の開き方でそのキャラらしい構えにする。
各コマの動きの欄には、武器の左右の持ち手と構え方を書く。

攻撃のコマ数は、キャラの動きの個性に合わせて3か4から選ぶ。
3コマは予備動作・打撃や放出・戻り、4コマは予備動作・打撃や放出・反動・戻りを基本とする。
F1は戦闘態勢から動き出す姿勢にし、最終コマから戦闘態勢へ自然につながる姿勢にする。
武器の持ち手は、戦闘態勢と同じにする。

戦闘不能は倒れた姿勢の1コマで止め、立たせない。武器は描かず、武器以外の装備は消さない。
勝利は、武器を持たずに、そのキャラの性格が伝わる決めポーズの1コマにする。

動作の補助情報として、打撃や弾の放出に対応するコマを示す。
飛び道具の放出コマを命中コマと決めつけない。具体的なダメージ・回復量は決めない。
秒数やFPSは一律に追加しない。
新しい戦闘ルールやシステム仕様をここで確定させない。

## イラストの構図

背景付きのキャラクターイラスト（一枚絵）の構図を、性格・経歴・得意なことから決める。
そのキャラが活躍した瞬間を切り抜いた、見せ場の一枚にする。
見た人が頼もしさやかっこよさを感じ、同時にそのキャラらしさも伝わる場面を選ぶ。
立っているだけの紹介の構図、風景の中で見た目を見せるだけの構図、笑いの場面を再現しただけの構図にしない。

- 場面は、次のどれかで活躍が決まる一瞬（直前・最中・直後）を選ぶ。
  - 戦闘：得意な戦い方や行動が決まった瞬間
  - パーティ：仲間を守る、助ける、導くなど、パーティを救った瞬間
  - 性格：こだわり、信念、癖が、ここぞという場面で良い方向に働いた瞬間
- フレーバーテキストの出来事や弱点を、そのまま場面にしない。性格や癖は、活躍の理由や手段として生かす。
- 何が起きているか、何を守った・成し遂げたかは、敵の攻撃の跡、守られた仲間の持ち物、崩れかけた足場など、周りの手がかり2〜3個で伝える。文字では説明しない。
- 人物は1人だけにする。仲間がいる場面でも、仲間は画面の外に置くか、持ち物や痕跡だけで表す。
- 敵や動物は1体まで入れてよい。人物の体や持ち物と重ねたり触れさせたりしない（手足や形が崩れやすいため）。攻撃を受け止める場面は、敵を画面の外に置き、炎や衝撃などの効果だけを持ち物に当てて表す。

次の項目を表で書く。

| 項目 | 内容 |
|---|---|
| 場面・背景 | どの活躍の一瞬か。場所と、状況や成果を伝える手がかり2〜3個 |
| 時間帯・光 | 光源は1つ。方向と色を書く |
| カメラ | 距離（全身・膝上・胸から上）と角度（あおり・見下ろし・正面・斜め） |
| ポーズ | 体の向きと、活躍を表す動作1つ。手足と持ち物の位置を画面の左右で書く。持ち物は「装備と持ち方」と一致させる |
| 表情 | 口を閉じた表情。真剣さや自信など、活躍の瞬間に合うもの。眉間の深いしわ、にらむ目、歯を食いしばる顔にしない |
| 活躍と性格の結び付き | 何の活躍か、なぜこのキャラらしい活躍なのかを1文で |
| 構図の型 | 距離／角度／動き（静・動）／場所（屋内・街・自然など）／時間帯 |

カメラの距離は、人物が画面の高さの3分の2以上を占める範囲で選ぶ。場面全体を引きで見せて人物が小さくなる構図にしない。状況を伝える手がかりは、人物の周りに見える範囲に置く。
強いあおりで脚を大きく写すなど、肌の広い面が大きく写る構図は避ける（AIが肌の陰影を描き込みすぎるため）。

ポーズは、AIが手足を崩さず描けるよう単純にする。
- 動作は1つに絞る。振り返る、体をひねる、腕を体の後ろへ回す姿勢は避ける。
- 両手は体の前か横に置き、1つの手に1つの役割だけを持たせる。
- 左右は画面から見た向きで書く（例：「画面の左側の手で杖を持つ」）。本人から見た左右と混ぜない。
- 糸目や閉じた目の笑顔のようなアニメ特有の顔の表現は使わない。表情は、目を開けたまま「まぶたを少し下げて、口を閉じたまま微笑む」のように書く。

他キャラの情報が提供されている場合は、構図の型の5軸のうち3軸以上が同じになる組み合わせを避ける。
提供されていない場合は、他キャラとの重複を確認していないことを一言添える。

## 出力前の確認

外見6項目、装備の左右、各動作の手と持ち物、台詞の口調が一致しているか確認する。
6項目の各欄が15字前後の短い名詞句で、1つの特徴に物が1つだけになっているか確認する。
武器が6項目に入っておらず、戦闘態勢と攻撃のコマだけに描かれているか確認する。
フレーバーに具体的な笑いとオチがあるか、説明だけの真面目な紹介へ戻っていないか確認する。
動作は6種類、各FNまで記載し、標準合計が12〜13（攻撃のコマ数による）であることを確認する。
ユーザーが枚数を変更した場合は新しい指定を使って合計を再計算する。
制作条件、画像生成の依頼文、戦闘スキルの性能を付け足していないか確認する。
イラストの場面が活躍の瞬間になっていて、フレーバーテキストや弱点の再現になっていないか確認する。
構図の型を書き、他キャラの情報があれば重複を確認したか確認する。
