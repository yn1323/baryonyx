# HD-2D技法の一覧と採用方針

調査日は2026-09-23（H.は2026-10-02以降）。
HD-2Dを構成する技法を、必要な前提ごとに分けて一覧にする。
各技法の「このプロジェクトでの扱い」は、ユーザーと合意した決定として[アート方針の描いた2D背景のHD-2D演出](../../../../doc/art/direction.md#描いた2d背景のhd-2d演出)（3Dの舞台は[3Dの舞台](../../../../doc/art/hd2d-stage.md)）を正本とし、ここには写さない。
A.〜E.とG.は描いた2D背景の技法で、このスキルが扱う。3Dの舞台の技法（F.・H.）の作り方は [hd2d-stage-set](../../hd2d-stage-set/SKILL.md) が扱う。

## A. 今の画面構造のまま重ねられる技法

`ScreenSpaceOverlay` のuGUIに、計算で描く板（画像を貼らないImage・RawImageと専用のシェーダー）や粒子を重ねる方式で、2D Rendererやポストプロセスを必要としない。
`Shared/VFX/HD2D/` の部品として汎用化しやすい。

| 技法 | 内容 | 難易度 | 汎用化 |
| --- | --- | --- | --- |
| 光芒 | 画面外から斜めに差す光の筋と、床の光だまり、筋の中で瞬く塵の粒。柔らかい帯に隙間を抜けた筋と流れる塵の濃淡を重ね、塵の粒は帯の中でだけ光らせる | 中 | 高 |
| 環境粒子 | 画面全体の塵と四芒星のきらめき | 低 | 高 |
| 霞・霧 | 奥の空間の青い霞と、床すれすれを流れる霧。5段のfBmを2回ゆがめた座標で読み、濃さで色を変え、切れ端の縁を明るく、折り目に暗い筋を入れる。縁は霧の濃淡に沿って崩す | 中 | 高 |
| 揺らぐ光と照り返し | 白い芯と色の付いたハローを別の板にして不規則に揺らし、壁と床へ弱い照り返しを置く | 低 | 高 |
| 点から出る粒子 | 指定した点・範囲から指定方向へ出る粒子。火の粉（丸く光る頭と、進む向きの反対へ速さに応じて伸びる細い尾）、魔法、報酬時のキラキラ | 低〜中 | 高 |

## B. ポストプロセスを使う技法

背景をカメラを通すCanvas（`Screen Space - Camera`）へ分け、タイトルと操作は `ScreenSpaceOverlay` に残す構成が前提となる。
`ScreenSpaceOverlay` のUIにはカメラのポストプロセスがかからないためである。

| 技法 | 内容 | 難易度 |
| --- | --- | --- |
| Bloom | 一定より明るいピクセルを抜き出してぼかし、元画像に足す。元の絵はくっきり残る | 中 |
| Vignette | 画面端を暗くして中央へ視線を集める | 中 |
| Color Adjustments | 色温度、明暗、彩度を揃える | 中 |
| 疑似ティルトシフト | 奥行き情報を使わず、画面の上下を位置でぼかしてミニチュア感を出す | 中〜高 |

BloomとティルトシフトはA群の技法と混同しやすいため、区別を明記する。
Bloomは明るさで対象を選んで光を足す。ティルトシフトは画面上の位置で対象を選び、絵そのものをぼかす。

## C. 背景を複数レイヤーに分ける技法

背景を遠景・中景・手前の画像に分けて描くことが前提となる。

| 技法 | 内容 |
| --- | --- |
| パララックス | 手前のレイヤーほど大きく動かす |
| 手前のシルエット | 画面端に暗い柱や草を置き、覗き込んでいる感じを出す |
| レイヤーごとの霞 | 遠いレイヤーほど青く薄くする（空気遠近法） |
| 光芒の前後関係 | 光芒を柱の後ろへ通す |

レイヤーを `SpriteRenderer` で並べる場合は、D群の2D Rendererへの切り替えと同時に判断すると、作り直しが一度で済む。

## D. 2D Rendererと法線マップを使う技法

URPの2D Rendererへの切り替えが前提となる。
現在の `Mobile_Renderer` は全シーン共通のUniversal Rendererであり、切り替えは全画面へ影響する。

| 段階 | 内容 | 難易度 |
| --- | --- | --- |
| 描画の切り替え | 2D Rendererへ変え、背景を `SpriteRenderer` へ移す | 中 |
| 2D Light（法線マップなし） | ライトの範囲内の明るさと色を変える。凹凸は光に反応しない | 低〜中 |
| 法線マップ | 各ピクセルの面の向きを持たせ、凹凸を光に反応させる | 高 |
| Shadow Caster 2D | 2D Lightが遮られた範囲を暗くする | 中 |

## E. キャラクターの影と陰影

キャラクターの影は、地面や壁に「落ちる影」と、キャラクター自身の「陰影」に分けて扱う。
いずれも法線マップや2D Rendererなしで、今のuGUIのまま作れる。

| 技法 | 内容 | 難易度 |
| --- | --- | --- |
| 丸影 | 足元に黒い楕円を置く | 低 |
| 疑似の投影影 | キャラ画像を黒く半透明にし、足元を支点に傾けて伸ばす。光源の位置から向きと長さを計算できる。アニメーションはキャラ画像と共有するため、コマごとの追加作業はない | 低〜中 |
| 暖色グラデーション | 光源側を暖色に、反対側を暗くするグラデーションを重ねる | 低〜中 |
| リムライト | 光源側の輪郭だけを細く光らせる | 中 |

## F. 3D空間にドット絵を置く技法

地形や建物を簡単な3Dで作り、キャラクターを板（ビルボード）に貼ったドット絵にする構成が前提となる。
HD-2Dの元の作品に最も近い構成である。

| 技法 | 内容 |
|---|---|
| 被写界深度・ティルトシフト | 奥行き情報を使い、距離に応じてぼかす |
| ボリュメトリックな霧・光 | 空間の中に光と霧があり、キャラクターがその中を通れる |
| 水面の反射・揺らぎ | 水面にキャラクターや光源が映る |
| カメラワーク | 回り込み、寄り、引きで箱庭を覗く感じを出す |
| SSAO | 接地面や隅を自然に暗くする |

2026-09-23の見送りから2026-10-02の採用までの経緯は、[アート方針の描いた2D背景のHD-2D演出](../../../../doc/art/direction.md#描いた2d背景のhd-2d演出)にある。

## G. 仕組みを足して作る技法

| 技法 | 内容 | 前提 |
|---|---|---|
| 天候 | 雨、雪、舞う葉を画面ごとに切り替える | A群の粒子 |
| 時間帯 | 朝、夕、夜で色調を切り替える | B群のColor Adjustments |
| 演出用の画面遷移 | 光が強まってからフェードするなど | A群またはB群 |
