## 設定を足す・変えるとき

1. 本文で新しい設定を出したら、同じ変更で該当するファイルの節に書き足し、「初出」に章へのリンクを添える。
2. 新しい用語は、この索引の用語索引に五十音順で加える。
3. ゲームの仕組みに理屈を与えたら、[ゲームとの対応](game-mapping.md)に行を加える。
4. 謎を置いたら[伏線と未決](threads.md)に加え、答えを決めたら該当する節へ移して一覧から消す。
5. 設定を変えたら、その設定が出てくる章を[目次](../story/README.md#章の一覧)の「主に明かす設定」で探し、本文も合わせて直す。
