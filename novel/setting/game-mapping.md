# ゲームとの対応

[設定の索引](README.md)

ゲームの仕組みが、小説の世界でどう説明されるかの対応表である。
ゲームの仕様が変わったら、この表と該当する設定を見直す。
ゲーム側の正本は `doc/` にあり、小説の設定はゲームの仕様を決めない。

## 歩数と資源

| ゲームの仕組み | ゲームの正本 | 小説での理屈 | 設定 |
|---|---|---|---|
| 現実の歩数がゲームの力になる | [ゲーム概要](../../doc/game/overview.md) | 地球の足音が境を越えてルーンになる | [足音が落ちる仕組み](world.md#足音が落ちる仕組み) |
| ACT（読みはアクト、1歩＝1ACT） | [用語集](../../doc/game/glossary.md) | 古王国の単位アクト。石碑のルーン文字ᚨᚲᛏ。自分の足で動いた、ひとつの行い | [ACT](world.md#act) |
| ルーン（1ACT＝1ルーン） | [ルーン経済](../../doc/features/economy.md) | 足音の結晶。古語で「ささやき」 | [ルーン](world.md#ルーン) |
| ルーンは販売しない | [課金](../../doc/features/monetization.md) | 足結びのルーンは歩き手が願った相手にしか使えず、売り買いできない | [ルーン](world.md#ルーン) |
| 1日の区切りは朝4時 | [ACTボーナス](../../doc/features/step-bonus.md) | 継ぎ目の刻。二つの世界の一日が縫い合わされる | [継ぎ目の刻](world.md#継ぎ目の刻) |
| ACTボーナス（段階ごとの枠に入れておき、届くと翌朝4時まで効く） | [ACTボーナス](../../doc/features/step-bonus.md) | 灯し台に差した灯し札が、足音で灯る | [灯し札と灯し台](world.md#灯し札と灯し台) |
| ボーナスのランクS〜E、同じ物は1つだけ | [ACTボーナス](../../doc/features/step-bonus.md#ボーナスの入手とランク) | 灯りの強さの六つの格。弱いほうは灰になる | [灯し札と灯し台](world.md#灯し札と灯し台) |
| 「5,000ACT分運動したことにする」チケット（ルーンは増えない） | [課金](../../doc/features/monetization.md) | 雨宿り札。鳴子で足音をまねる | [灯し札と灯し台](world.md#灯し札と灯し台) |
| 歩かない日のペナルティはない | [ゲーム概要](../../doc/game/overview.md) | 足結びは切れず、歩かない日を責める者はいない | [歩き手と足結び](world.md#歩き手と足結び) |
| 自転車などもACTへ換算する予定 | [用語集](../../doc/game/glossary.md) | 歩き以外の動きの重さは、古王国の記録に断片だけがある | [ACT](world.md#act) |
