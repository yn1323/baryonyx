# 世界観の小説

「てくてくダンジョン」の世界を想像するための小説と、その設定を置く。
小説の題は『一万歩目の門』である。

## 位置づけ

ここにある小説と設定は、世界観を膨らませるための試案である。
ゲームの仕様と確定設定の正本は [doc/](../doc/README.md) にあり、この小説はゲームの仕様を決めない。
ゲームの[世界設定](../doc/game/world.md)は、地域・人物・組織の名称や歴史を未決としている。
小説で作った名前や歴史を、ゲームの確定設定として `doc/` に登録しない。
採用するときは、ユーザーが決めてから `doc/` の該当する文書へ反映する。

小説は、ゲームの現時点の仕様（ACT、ルーン、朝4時の区切り、ACTボーナス、カードバトル、分岐ルートの冒険、ルーン復活など）に矛盾しないように書いている。
仕様との対応は[ゲームとの対応](setting/game-mapping.md)にまとめている。

## 構成

```text
novel/
├── README.md        この文書。位置づけと続きの書き方
├── story/           小説の本文
│   ├── README.md    目次、章ごとのあらすじと明かす設定、時系列、文体
│   └── 00-〜08-     序章から終章まで
└── setting/         設定
    ├── README.md    設定の索引。疑問から引く表と用語索引
    └── *.md         分野ごとの設定、ゲームとの対応、伏線と未決
```

## 読み方

物語として読むときは、[目次](story/README.md)から序章へ進む。
世界の仕組みを調べるときは、[設定の索引](setting/README.md)の「疑問から引く」表から探す。

## 続きを書くとき

1. [設定の索引](setting/README.md)と[目次](story/README.md)を読み、今の設定と、どの章で何を明かしたかを確かめる。
2. 題材は[伏線と未決](setting/threads.md)から選ぶ。ゲームの仕様が変わっていれば、[ゲームとの対応](setting/game-mapping.md)の正本のリンク先で最新の仕様を確かめる。
3. 本文は `story/` に、章の番号を続けたファイル名で書く。文体は[目次の文体の決まり](story/README.md#文体の決まり)に従う。
4. 書いたら、同じ変更で設定と目次を更新する（[設定を足す・変えるとき](setting/README.md#設定を足す変えるとき)）。
