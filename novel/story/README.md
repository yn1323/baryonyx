# 一万歩目の門　目次

[小説の入口](../README.md) ／ [設定の索引](../setting/README.md)

地球の三枝遥が、夜の散歩の一万歩目でヴィアトリアへ落ち、四人の一行と迷い路を歩いたあと、歩き手として地球へ戻るまでの物語である。
語り手は三枝遥で、一人称は「私」、会話の中では「わたし」と言う。

## 文体の決まり

- 一人称「私」のだ・である調で、語り手の見たこと・聞いたことだけを書く。
- ヴィアトリアの言葉を先に書き、私が地球のゲームの言葉に置き換える場面を短く添える（位→レベル、息→エネルギーなど）。置き換えの一覧は[戦いの設定](../setting/battle.md)にある。
- 説明は人物の台詞と場面で出し、地の文の解説を続けすぎない。
- 登場人物を代名詞（彼・彼女）で呼ばず、名前で呼ぶ。
- 文書の書き方は、リポジトリの[文章規範](../../.agents/skills/japanese-tech-writing/SKILL.md)の整形（一文ごとの改行、ダッシュを使わない）に従う。
