# 3Dの舞台（HD-2D）

[アート索引](README.md) / 根拠：[アート方針](direction.md)

2026-10-02、ユーザーの依頼で、Top・Home・戦闘画面のモック（BattleInspect）を、3Dの地面と背景にドット絵のキャラを立たせ、3Dの光と影で見せるHD-2Dの構成へ移した。
同日、続く依頼で、Homeを昼の森の野営地に変え、舞台ごとのレンズ（被写界深度）と色調、カメラの動きを加え、停止中のシーンでもHD-2Dで見えるようにした。
さらに同日、TopとBattleInspectも、Homeと時間帯と色が重ならない屋外（星空の夜の山の門、夕暮れの高原の環状列石）に変えた。
2026-10-03には、3つの舞台に小物・草の房・地面の汚しを足して密度を上げ、光を受ける面に法線マップを付けた。
同日、続く依頼で、戦闘の背景を10種類足し、`Battle.unity` で選べるようにした（[戦闘の背景](#戦闘の背景)）。
この文書は、その構成・カメラ・光・ポストプロセス・テクスチャ・描く順番の値の正本である。
作業の進め方とつまずいた点は、[hd2d-lighting-vfx](../../.agents/skills/hd2d-lighting-vfx/SKILL.md)スキルの[3Dの舞台にドット絵を立たせる](../../.agents/skills/hd2d-lighting-vfx/references/hd2d-3d-stage.md)に記す。
地面・遠景・小物・草・汚しとそのマテリアル・テクスチャの作り方、密度の決め方は、[hd2d-stage-set](../../.agents/skills/hd2d-stage-set/SKILL.md)スキルに記す。

## 確定している方針

| 項目 | 方針 |
|---|---|
| 地面と背景 | 3Dの床・壁・柱・段・遠景の板に、ドット絵のテクスチャを貼る。マップの移動はしないため、マテリアルはURPの `Simple Lit`（鏡面反射なし）にとどめる |
| キャラ | UIで配置した味方・敵・焚き火の薪を、UIの位置から地面の足元を求めて3Dに立たせる。カメラの面と平行な板で描き、薄っぺらく見せない |
| 影 | 主光源（または焚き火）の向きに立てた影の板で、地面に輪郭の影を落とす。足元には楕円の接地影を敷く |
| 手前のUI | HUD、手札、枠、ボタン、カードの挿絵、HPバー、敵の弱点は、従来どおり2Dで手前に描く |
| 時間帯 | 画面ごとに時間帯と色を分ける。Topは星空の夜（深い青）、Homeは昼の森（緑）、戦闘は夕暮れ（橙〜赤紫） |
| 光（夜・夕暮れ） | 冷色の月明かり、または低い暖色の太陽を主光源にし、暖色の点光源（松明・かがり火）を対比させる。点光源は炎のように揺らす |
| 光（昼） | 暖色の太陽を主光源にし、環境光を空・木々・地面の3色のグラデーションにして、日陰を青緑に寄せる。木漏れ日の斑、木々のすき間から差す光の筋、光の中を漂う塵を加える |
| 空気 | 線形の霧で遠くを空気の色に寄せる |
| 空と遠景 | 空、遠い山並み、遠い荒野は、光を受けず霧もかけない描いた遠景（`Baryonyx/HD2D/Painted Distance`）にし、時間帯の色を絵に描き込む。星と月は白より明るくしてBloomで光らせ、星は瞬かせる |
| レンズと色 | 舞台ごとのポストプロセス（[レンズと色](#レンズと色ポストプロセス)）。キャラの奥行きにピントを合わせ、手前と奥の舞台をぼかす。明るさが白を超える光だけをBloomでにじませ、周辺を暗くし、影を寒色・光を暖色に寄せる |
| カメラの動き | 入力を待つ間はゆっくり揺らし、画面を開いたときにすべり込む（[カメラの動き](#カメラの動き)） |
| 停止中の表示 | 3Dの舞台のカメラがあるシーンは、停止中もキャラを3Dに立たせ、HD-2Dで表示する。保存される状態は変えない |
| 2Dの見た目 | 3Dの舞台を置かない場所（展示室で画面のPrefabを単体で見るときなど）では、従来の2Dの背景のまま表示する |
| 小物と汚し | キャラの周りに、その場で人や獣が過ごした跡が分かる小物を置き、草の房と地面の汚しで繰り返すタイルを崩す（[小物と汚し](#小物と汚し)）。キャラの足元と手前のUIを避け、戦闘は石舞台の中央を空ける |
| 面の凹凸 | 光を受ける床・壁・板には、絵から計算した法線マップを付ける。松明や低い日差しが、石の目地や樹皮の凹凸、切り抜きの縁の丸みを浮かせる |
| 草と葉 | 草・シダ・茂み・枝葉は、裏から当たる光を透かして受け（`Baryonyx/HD2D/Stage Foliage`）、穂先や垂れた枝先を風でゆっくり揺らす |

オクトパストラベラーの開発者は、背景を3Dモデルにテクスチャを貼る作り方で作り、テクスチャの解像度は細かすぎると写実的に、粗すぎるとドット感が強すぎるため感覚で釣り合わせたと述べている（[参考資料](../../.agents/skills/hd2d-lighting-vfx/references/research-sources.md#hd-2dの3dステージ)）。
本作も、テクスチャを背景用の細かめのドットで描き、遠近で拡縮することを受け入れる（[例外](direction.md#例外)）。

| Exploration | Battleと同じ舞台の一式から、冒険の行き先の背景を選ぶ（[冒険の画面](../features/screens.md#冒険の画面)） | BattleInspectと同じ | 背景ごと | Battleと同じ。味方の位置に4人、敵の位置に遺跡の門を立てる |

カメラの位置・角度・画角、環境光と霧の色・距離は、[StageSetAssets](../../client/Assets/Baryonyx/Shared/Art/Stages/Editor/StageSetAssets.cs) の `TopView`・`HomeView`・`BattleView`・`StarlitEnvironment`・`GladeEnvironment`・`DuskEnvironment` が持つ。
最初に使った広間（`DungeonHallStage`）と森の遺跡（`ForestRuinsStage`）は、舞台として残している（今はどの画面でも使わない）。
戦闘のカメラは、キャラの足元が画面の高さの約3〜7割に並び、地面の端（遠景の根元）が約7割に来るように決めた。
これより上の帯に崩れたアーチと森の遠景が見える。
Homeのカメラは、4人の足元（画面の高さの24〜28%）が約10m先に立ち、その奥に空き地・テント・丸太、約75%の高さに森の根元が来るように決めた。
画面の上端は手前の枝葉がふさぎ、ジオラマの箱の中をのぞく構図にする。
画面の下端は約3.4m先で地面と交わる。カメラの手前（画面の下端の近く）には茂みなどの物を置かず、4人の足元から下の地面だけを、下へ行くほどぼかす。手前の物は画面の下端の地面とほぼ同じ距離にあって最も強くぼけ、色も地面より暗いため、画面の下にぼけた暗い帯として現れ、そこから急にぼけたように見えた。
Topは、中央のタイトルの奥に門を置き、満月を門の三角の飾り石の背後（画面の高さの約80〜97%）に昇らせる。左右の崖が枠になり、その外に雪の山並みと星空が見える。
戦闘は、地面の端（約70%）より上に、遠いメサと夕焼けの空が見える。前列の足元（画面の高さの約30%）より手前、手札の下の地面は、手前のぼけとして下へ行くほどぼかす。緑の敵が背景に埋もれず、加算の光の演出が映えるよう、明るすぎない夕暮れにした。演出中は従来どおり画面を暗くする。

## キャラの立たせ方

[Hd2dUiBillboard](../../client/Assets/Baryonyx/Shared/VFX/HD2D/Runtime/Hd2dUiBillboard.cs) を、UIのキャラの絵（`RawImage` または `Image`）に付ける。
3Dの舞台のカメラ（[Hd2dStageCamera](../../client/Assets/Baryonyx/Shared/VFX/HD2D/Runtime/Hd2dStageCamera.cs)）が同じシーンにあるとき、停止中もPlay Mode中も3Dで描く。

| 項目 | 内容 |
|---|---|
| 足元 | UIの足元の影（楕円）の中心。影がなければ絵の下端の中央 |
| 位置と大きさ | 足元の地面の点から、UIの絵の4隅を同じ見た目の位置・大きさになるよう写す。キャラが前へ出る・揺れる・倒れて消えるといったUIの動きがそのまま写る |
| UIの絵と影 | 描画だけを止め、RectTransformは残す。タップの判定や配置はUIのまま |
| 光 | 環境光・主光源・点光源を受ける。自分で光る絵と、焚き火の薪（そばの焚き火の光を受けると橙一色になる）は `Lit` をオフにし、元の色のまま描く |
| 光源からの影 | 地面に垂直な影の板を、影を落とす光（`Hd2dStageCamera.KeyLight`）へ向けて立てる。どの画面も主光源（Homeは太陽） |
| 接地影 | UIの足元の影の範囲を地面に写した楕円。濃さは `ContactShadowStrength`（既定0.8） |
| 発光・透け | UIの絵の色、親の `CanvasGroup` の透明度、マテリアルの `_FlashAmount`・`_FlashColor` を写す |

## 停止中の表示

停止中のシーンでも、3Dの舞台のカメラ・キャラの板・2Dのときだけの部品が動き、Gameビューにキャラが3Dに立つ。
シーンやPrefabに保存される状態は変えない。

| 部品 | 停止中の扱い |
|---|---|
| キャラの板・影の板・接地影 | `HideFlags.HideAndDontSave` で作り、保存しない。毎フレームの描画の前に、Gameビューの大きさとUIの配置へ合わせ直す |
| UIのキャラの絵 | `CanvasRenderer.cull` で描画だけを止める（保存されない値） |
| 2Dのときだけの部品 | 無効にせず、保存されない `CanvasGroup`（透明度0）を付けて消し、レンダラーは `forceRenderingOff` で止める。霧・光・火の粉が後から作る絵や、マスクの中の絵もまとめて消える。Play Mode中は従来どおり無効にする |
| 舞台の粒子（火の粉・光の粒・蛍・砂ぼこり） | 舞台のPrefabの [Hd2dParticlePreview](../../client/Assets/Baryonyx/Shared/VFX/HD2D/Runtime/Hd2dParticlePreview.cs) が、開いたときに8秒分先に進めて表示する（Unityは選んだ粒子しか停止中に動かさない）。メニュー `Baryonyx > HD-2D > Animate Stage While Stopped` をオンにしたときだけ、Unityが手前にある間、Editorの時計で毎秒30回ほど進める |
| 戦闘の舞台のCanvas | シーンを作るときに、シーンのカメラを `StageCanvas` の `worldCamera` に設定する。停止中もカメラで描き、HPバーや弱点がPlay Mode中と同じく舞台の手前に、ポストプロセスを通して描かれる |
| カメラ | 動かさない（揺れ・すべり込み・UIに合わせた移動はPlay Mode中だけ） |

Enter Play Mode Optionsでシーンの再読み込みを省くと、停止中に一度 `Awake` した部品は、Play Modeに入っても `Awake` が呼ばれない。
そのため、部品の登録は `OnEnable` で行う。

## Sceneタブでの表示

3Dの舞台のカメラがあるシーン（Top・Home・BattleInspect）を開くと、[Hd2dSceneViewSync](../../client/Assets/Baryonyx/Shared/VFX/HD2D/Editor/Hd2dSceneViewSync.cs) がSceneタブをゲームと同じ見た目にする。
Sceneタブを動かしたあとは、メニュー `Baryonyx > HD-2D > Scene View Through Stage Camera` で戻せる。

| 設定 | 内容 |
|---|---|
| 視点 | 舞台のカメラの位置・向き・画角・描く距離にそろえる |
| 描画 | 霧、ポストプロセス、粒子、レンズフレアを表示し、グリッドは消す |
| 停止中の動き | 舞台を描き直し続けるとEditorが重くなるため、標準では止める。メニュー `Baryonyx > HD-2D > Animate Stage While Stopped` をオンにすると、Always Refreshで炎・星・光の筋・粒子を動かす。選択は利用者ごとの `UserSettings` に保存する |
| 手前のUI（Screen Space - Overlay） | Sceneタブでだけ隠す（`SceneVisibilityManager`）。Unityは手前のUIをSceneタブの原点に幅1920単位の板として描き、56mほどの舞台を覆ってしまうため。Gameタブでは表示され、Hierarchyの目のアイコンで再表示できる |
| カメラで描くCanvas（戦闘の舞台、Topの塵） | Sceneタブでも表示する。カメラの手前に置かれるため、視点をそろえるとゲームと同じ位置に見える |

## カメラの動き

| 動き | 内容 |
|---|---|
| ゆっくりした揺れ | 入力を待つ間、カメラだけを小さな円で動かす（`SwayRadius`・`SwayPeriod`）。手前と奥が視差でずれ、止まった絵に見せない |
| すべり込み | Play Modeの開始時に、休みの位置からずらした所（`IntroOffset`）から、最後がゆっくりになる3乗の曲線で戻る（`IntroSeconds`） |
| UIに合わせた移動 | 戦闘のカメラは、UIの `StageDrift`（円運動）と `Stage`（揺れ）の動きを、奥行き16mで同じ距離だけ動くようにカメラの平行移動へ置き換える |

キャラは休みの位置のカメラから求めた地面に立つため、どの動きでもキャラは地面の上で滑らず、手前の地面と奥の遠景は視差でずれる。
戦闘ではキャラとHPバーが一緒に動く。

## レンズと色（ポストプロセス）

舞台ごとのVolume Profile（`<舞台>Look.asset`）を、[StageSetAssets](../../client/Assets/Baryonyx/Shared/Art/Stages/Editor/StageSetAssets.cs) の `BuildLooks` が作る。

### 舞台のレンズ

[Hd2dStageFocus](../../client/Assets/Baryonyx/Shared/VFX/HD2D/Runtime/Hd2dStageFocus.cs)（Volumeの項目 `Baryonyx/HD-2D Stage Focus`）は、不透明の舞台だけを、カメラからの距離に応じた半径でぼかす被写界深度である。
半透明の列（キャラの板・演出・舞台のUI）を描く前に描くため、キャラ・HPバー・演出は常にくっきり残る。
URPの被写界深度は最後にかかるため、深度を書かないUIを奥の地面と同じだけぼかしてしまう。

| 項目 | 内容 |
|---|---|
| ぼかし方 | 半分の解像度で横・縦の順にぼかし、元の解像度で、その点のぼけの大きさに応じてくっきりした絵と混ぜる |
| 手前のにじみ | 各点は自分のぼけの半径まで広がる。手前の物のぼけは、くっきりした奥へ柔らかくかかる。奥の物のぼけは、それより手前でくっきりした物にかからない |
| 半径 | 画面の高さ1080pxを基準に、手前と奥で別に決める。手前の物はドットが大きく写るため、手前を大きくする |
| 増え方 | くっきりした範囲の端から最大のぼけに届く距離まで、始まりと終わりがゆるやかな曲線（smoothstep）で増やす。半径が小さい所（4px以下）は、元の解像度のまま、その点の半径の円の中を混ぜてぼかし、半径2.5〜5pxの間で半分の解像度のぼけへ移す。半分の解像度のぼけは、半径によらずドットの輪郭がすでに柔らかいため、くっきりした絵と混ぜる割合だけを変えると、混ぜる割合が半分を超える細い帯で急にぼけ始めたように見えた |

| 舞台 | ピント（m） | くっきりした幅の半分（m） | 手前・奥で最大のぼけに届く距離（m） | 手前・奥の最大の半径（px） |
|---|---|---|---|---|
| `ForestGladeLook` | 10.6（`HomeView` の4人の奥行き。足元は9.7〜10.3m） | 0.9 | 4.2・11 | 20・7（画面の下端で約10px） |
| `StarlitGateLook` | 14（道と段） | 5 | 4・14 | 12・3（星が読めるよう奥は弱く） |
| `DuskHighlandLook` | 18.2（両陣営の足元13.6〜23mの中ほど） | 4.7 | 3.8・9 | 12・5 |

### Bloom・色調・周辺減光

| 舞台 | Bloom | 色調 | 周辺減光 |
|---|---|---|---|
| `ForestGladeLook` | しきい値0.95、強さ0.75、広がり0.72、暖色の色味 | 露出+0.1、コントラスト16、彩度14、色温度+6。影を青（0.4, 0.48, 0.58）、光を暖色（0.62, 0.55, 0.44）に寄せる | 0.34（暗い緑） |
| `StarlitGateLook` | しきい値0.85、強さ1.3、広がり0.7 | コントラスト14、彩度6。影を青（0.4, 0.45, 0.62）、光を暖色（0.62, 0.54, 0.42）に寄せる | 0.38（紺） |
| `DuskHighlandLook` | なし（`BattlePostProcess` のしきい値1のBloomを使う） | コントラスト12、彩度8。影を青紫（0.42, 0.42, 0.6）、光を橙（0.64, 0.52, 0.4）に寄せる | 0.34（暗い紫） |

使っていない広間と森の遺跡の舞台にも、それぞれの `DungeonHallLook`・`ForestRuinsLook` を残している。

色調はURPの `Color Adjustments`・`White Balance`・`Split Toning`、周辺減光は `Vignette` を使う。
トーンマッピングは使わない（Overlayでない舞台のUIの色が変わるため）。

| 1 | 3Dの舞台（不透明・切り抜き） |
| 1.5 | 舞台のレンズ（`Hd2dStageFocus`。半透明の列の直前） |
| 2 | 光の筋・光の粒・炎・火の粉、舞台のCanvasのうち順番0の部分（戦闘の画面上下の暗幕、演出中の暗幕、キャラの奥の演出 `VfxBack`） |
| 3 | 足元の金の輪（入れ子のCanvas、順番5） |

## 小物と汚し

オクトパストラベラーの開発者は、大きな画面ではスプライトが寂しく見えたためタイルの種類と色を増やし、ドット絵のゲームに見えるぎりぎりの密度で絵を作ったと述べている（[参考資料](../../.agents/skills/hd2d-lighting-vfx/references/research-sources.md#hd-2dのライティングカメラポストプロセス2回目)）。
2026-10-03、ユーザーの依頼で、3つの舞台に次の4種類の物を足した。

| 種類 | 作り方 | 狙い |
|---|---|---|
| 小物 | 切り抜きの板（`Flat`）と、Homeの木箱だけは箱（`Box`）。法線マップ付きの `Simple Lit` | 野営の荷物、古い像、戦いの跡など、その場所で起きたことを見せる |
| 草の房 | 草用のシェーダーの切り抜きの板を、数m四方ごとに1つのメッシュへまとめる（`Boards`）。草地に散らし、小物と木の足元にも2〜3本ずつ添える | 小物を地面に置いた板ではなく、草の中から生えた物に見せる |
| 地面の汚し | 地面から0.4cm上に寝かせた切り抜きの板（`Decals`）。回転は90度単位にとどめ、地面のドットの格子とそろえる | 落ち葉・苔・砂で、繰り返すタイルの模様を崩す |
| 足元の陰 | 地面に立つ切り抜きの板の足元に敷く柔らかい楕円（`Shades`、接地影のシェーダー）。幅は板の0.75倍、奥行きは幅の0.35倍（0.5〜1.6m） | 空の光が遮られる足元を暗くし、板が地面に線で接して見えないようにする |

| 画面 | 小物 | 草の房・汚し |
|---|---|---|
| Home | テントの横に木箱3つ（上の1つは傾ける）、奥の丸太の前に樽と麻袋と寝袋、右奥に薪の山と斧の刺さった切り株、空き地の縁に切り株と苔むした岩、木の根元と茂みの前にシダとキノコ、焚き火の下に石を並べた炉 | 空き地の外の草地に草の房、空き地の周りに落ち葉 |
| Top | 門の台の左右に騎士の石像、手前の松明の外側に裾の裂けた旗（松明の火で照らす）、道の両脇に崩れた石垣・がれき・3本の石碑 | 道の両端に沿って草の房と苔、草地にも草の房と苔 |
| 戦闘 | 石舞台の奥の縁に獣の骨・地面に刺さった古い剣と槍・ケルン、右の縁に砂岩のがれきと枯れた低木、左の縁に砂岩のがれき | 石舞台の外と石の割れ目に枯れ草、縁に吹き寄せた砂 |

置き方の決まりは次のとおりである。

- 小物・草の房は、キャラの足元から0.8m以上離す。足元はシーンのUIの配置から求めた値（Homeの4人と焚き火、戦闘の7体）を使い、EditModeテストで確かめる。地面の汚しと足元の陰は、焚き火の炉のように足元にあってよい。
- 手前のUIに隠れる場所には置かない。戦闘の手札・コスト・ターン終了のボタンの下、Topのタイトルの文字の後ろには、背の高い物を置かない。
- 戦闘は、キャラと演出を読みやすくするため、石舞台の中央には割れ目の小さな枯れ草だけを置く。砂は風が落とす縁と立石の周りにだけ敷く。中央に置いた橙の砂は、塗料のしみに見えた。
- 足元の陰は、くっきり見える距離の物にだけ付ける（Homeは奥行き13m、Topは20m、戦闘は18mまで）。陰は半透明で、舞台のレンズがぼかしたあとに描くため、遠くでは、ぼけた地面の上にくっきりした細い線として残った。
- 小物は、主光源の影に入らない場所を選ぶ。Homeの奥の帯（奥行き約11.6〜14m）は左の大木の枝葉の影に入り、木箱が黒い箱に見えた。暗い色で描かれた木箱と荷物は、マテリアルの色で明るくした（色の成分ごとに、木箱は1.35〜1.75倍、荷物は1.12〜1.3倍）。

## 戦闘の背景

2026-10-03、ユーザーの依頼で、冒険の行き先として必要になりそうな場所を10か所選び、戦闘の背景として作った。
場所の名前と行き先の構成はまだ決まっていない（[探索する場所の定義](../catalog/stages/README.md)）。
ここでは、王道ファンタジーのRPGでよく行く場所を、序盤の草原から終盤の古城まで、時間帯と主な色が重ならないように選んだ。

戦闘シーン `Battle.unity` は、BattleInspectと同じ戦闘画面に、夕暮れの高原と下の10種類の舞台を置く。
シーンの `BattleStages` の [BattleStageSelector](../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleStageSelector.cs) の `Stage`（Inspectorでは日本語の名前のドロップダウン）で、表示する背景を選ぶ。
選んだ舞台だけを有効にし、その舞台の環境光・霧・カメラの背景色、レンズと色調（`StageLookVolume` のProfile）、キャラの影を向ける主光源を切り替える。
停止中のシーンでも選んだ時点で切り替わり、Play Mode中にコードから `Apply` を呼んでも切り替わる。
シーンを作り直すと、草原の街道を選んだ状態になる。

| 奥の物 | 柵・岩・墓石・甲冑などを、左右の端と奥の縁の4か所に、大きさと左右反転を変えて置く |
| その場で起きたことを見せる物 | 奥の縁の中央に1つ（壊れた荷車、祠、トロッコ、難破船、竜の頭骨、天使の像など） |

| 地面の汚し | 床の縁と地面に散らす。古城は絨毯の上に置かない |
| 光源の物 | 坑道と墓地はランタンの柱、古城は鉄の燭台を、夕暮れの高原のかがり火と同じ奥の左右（x=±7.2m、奥行き15.2m）に置く |

置き方の決まりは次のとおりである。

- 描いた遠景（奥行き17.6m）より奥に置いた物は、遠景の板に隠れて写らない。奥の物は17.3m以内に置く。最初に額縁の大物の奥の組を17.8〜17.9mに置き、写らなかった。
- 夜と屋内の舞台（坑道・水晶の洞窟・霧の沼地・夜の墓地・古城・火山）は、手前からの影のない弱い補助光を当てる。坑道と古城は、画面外の左右に暖色の点光源を置いて両陣営を照らす。暗いままでは、キャラより先に床の暗さが目に付いた。
- 場所の色が強い舞台でも、主光源と補助光は中立に近い色にする。火山で赤橙の主光源と赤い環境光を当てると、緑の敵が茶色に見え、キャラの色が読めなくなった。赤は溶岩・空・点光源に任せる。
- 暗く描かれた床（坑道の板、古城の絨毯）は、マテリアルの色で1.15〜1.3倍に明るくする。
- 地面の汚しは、模様のある床の上に置かない。古城の絨毯の上の割れた床石は、しみに見えた。
- 夕暮れの高原と同じく、小物・草の房はキャラの足元から0.8m以上離す。BattleシーンのEditModeテストで、全部の舞台について確かめる。

### 光芒と光だまり

2026-10-03、ユーザーの「ライティングが足りない、もっとHD-2Dっぽく光を当て、光芒を作る」との指摘を受け、10種類の舞台に光芒と光だまりを足した。
HD-2Dの開発者は、点光源でキャラと物に影を落とし、光と影でドット絵の環境に光がどう当たるかを見せることを重視したと述べている（[参考資料](../../.agents/skills/hd2d-lighting-vfx/references/research-sources.md#hd-2dの光芒と光だまり3回目)）。
舞台ごとに光の向きと色を1つ決め、空気の中の光の筋（光芒）と、その光が落ちた地面の柔らかい光（光だまり）を対にして置く。
光芒は `Baryonyx/HD2D/Light Beam` の板、光だまりは `Baryonyx/HD2D/Glow Particle` を地面に寝かせた加算の板で、マテリアルは舞台ごとに色と強さを変えて作る（`<接頭辞><名前>.mat`）。

| 舞台 | 光芒（強さ） | 光だまり（強さ） | ほかの光 |
|---|---|---|---|
| 草原の街道 | 太陽の向きに、木々の上と雲のすき間から3本（0.85） | 光芒の落ちる所（0.3） | 雲の影（太陽のクッキーに斑のマスクを34mごとに敷く） |
| 朝霧の森 | 太陽の向きに、幹の間から5本（0.9） | 光芒の落ちる所（0.4） | 木漏れ日（12mごと） |
| 坑道 | 天井の割れ目から冷色の2本（0.75） | 光芒の落ちる所（0.3）、ランタンの足元（0.5） | 天井の光の下に冷色の点光源 |
| 水晶の洞窟 | 天井の割れ目から3本（1） | 光芒の落ちる所（0.45）、水晶の周りに水色と紫（0.55） | |
| 海辺の岩場 | 太陽の向きに、入道雲のすき間から幅の広い3本（0.6） | 光芒の落ちる所（0.25） | 雲の影（40mごと） |
| 霧の沼地 | 霧のすき間から4本（0.6） | 光芒の落ちる所（0.3）、鬼火の下に緑（0.5） | |
| 雪原 | 太陽の向きに、雲のすき間から3本（0.7） | 光芒の落ちる所（0.22） | |
| 火山 | 溶岩から立ち上る熱の柱3本（0.45、高さ4.5m） | 溶岩の割れ目の周りに橙（0.6） | 点光源のある所に溶岩の割れ目を置く |
| 夜の墓地 | 月の側から斜めに3本（0.6） | 光芒の落ちる所（0.35）、街灯の足元（0.5） | |
| 古城の大広間 | ステンドグラスから青・金・赤の3本（1） | 光芒の落ちる所に同じ色（0.3）、燭台の足元（0.55） | |

置き方の決まりは次のとおである。

- 光芒の板も、描いた遠景（奥行き17.6m）より奥では遠景に隠れる。奥から手前へ差す光（月、窓、天井の割れ目）は、光の向きと始まりの高さから上端の位置を計算し、17.4m以内に収める。
- 奥から手前へ差す光は、左右にも傾ける（光の進む向きのxを0.4〜0.45）。手前へまっすぐ差す光は画面で縦の柱に見え、光の筋に見えなかった。
- 光芒の板は地面の近くで消えるため、光が地面に届いたことは光だまりで見せる。光だまりは光芒の幅の約2倍に広げ、強さを0.22〜0.45に抑える。色の付いた小さく強い光だまりは、キャラの足元でしみに見えた。
- 昼の明るい地面では、加算の光芒が埋もれる。昼の舞台は夜の舞台より強くし、空や木の幹を背にして見せる。
- 光芒はキャラの板より先に描くため、キャラの前を通る位置に置いてよい。

カメラの揺れとすべり込み、点光源の揺らぎは、Play Modeで確認する。

## 未決事項

| 項目 | 状態 |
|---|---|
| Android端末での負荷（影・Bloom・舞台のレンズ・点光源の数） | 未確認。発熱やフレーム落ちがあれば、舞台のレンズの半径、Bloom、影の解像度の順に下げる |
| 行き先カードの場所の名前 | Homeの行き先カードは「森の遺跡」の絵と名前のまま。戦闘の舞台（夕暮れの高原）と合わせるかは未定 |
| 使っていない舞台 | 広間と森の遺跡は、ダンジョンの中や森の遺跡の場面に使えるよう残している。使わないと決めたら削除する |
| 案内人の画面（酒場・装備・神殿・旅の案内所）の3D化 | 今回の対象外。2Dのまま |
| 探索・マップ移動の舞台 | 移動しない前提で作った。移動を加えるときは、床の分割や光の数を見直す |
| 戦闘の背景とゲームの行き先の対応 | 場所の名前・行き先・敵の構成が未決のため、背景はInspectorで選ぶだけで、どの戦闘でどれを使うかは決めていない |
| Battleシーンの読み込みの重さ | 11種類の舞台を1つのシーンに置き、選んでいない舞台は無効にしている。無効でもテクスチャとメッシュは読み込まれる。Android端末でのメモリと読み込み時間は未確認。実際の戦闘で使うときは、選んだ舞台だけを読み込む作りに改める |
| BattleとBattleInspectの関係 | BattleはBattleInspectと同じ戦闘画面のPrefabを使う。Homeの行き先カードは今もBattleInspectを開く |

## 変更と判断の記録

- 2026-10-03：ユーザーの「ライティングが足りない」との指摘を受け、10種類の戦闘の背景に、光芒と光だまり、草原と浜の雲の影を足した（[光芒と光だまり](#光芒と光だまり)）。HD-2Dの照明の資料をWebで調べ直し、画面空間のボリュームライトはスマートフォンの負荷から採らず、板の光芒と地面の光だまりで光の当たる場所を見せることにした。撮影で見つけた次の問題を直した。窓と月の光芒の上端が描いた遠景の奥に出て隠れた（落ちる位置と向きを計算して手前へ収めた）。手前へ差す光芒が縦の柱に見えた（左右にも傾けた）。昼の草原と浜で光芒が地面の明るさに埋もれた（強くした）。
- 2026-10-03：ユーザーの依頼で、戦闘の背景を10種類（草原の街道、朝霧の森、坑道、水晶の洞窟、海辺の岩場、霧の沼地、雪原、火山、夜の墓地、古城の大広間）作り、`Battle.unity` でInspectorから選べるようにした（[戦闘の背景](#戦闘の背景)）。テクスチャ89枚はCodex CLIで生成した。舞台ごとに作り方を変えず、夕暮れの高原で確かめた配置（床・遠景・額縁・奥の物・小物）を共通の決まりにした。撮影で見つけた次の問題を直した。奥の額縁の大物を描いた遠景より奥に置いて写っていなかった（遠景の手前へ移した）。古城の絨毯の上の割れた床石がしみに見えた（絨毯の外だけに置いた）。坑道と古城の床が暗く、キャラより先に暗さが目に付いた（床の色を明るくし、画面外の左右に暖色の点光源を置いた）。火山の赤い光で緑の敵が茶色に見えた（主光源と環境光を中立に近づけた）。
- 2026-10-03：ユーザーの依頼で、Top・Home・BattleInspectの舞台に、HD-2Dらしい密度とリアルな見え方を求めて、小物・草の房・地面の汚し・足元の陰を足した（[小物と汚し](#小物と汚し)）。テクスチャ23枚はCodex CLIで生成した。光を受ける面には絵から計算した法線マップを付け、草と葉は裏からの光を透かして風で揺れるシェーダーにした。細い葉や刃は、地面と同じドットの細かさでは縮小でつぶれたため、細かくした。撮影で見つけた次の問題を直した。遠くの木の足元の陰がぼけた地面の上に細い線として残った（距離で絞った）。Homeの奥の木箱が大木の葉の影で黒い箱に見えた（日なたへ移し、暗く描かれた色を明るくした）。Topの旗が暗い崖に溶けた（手前の松明の外側へ移した）。戦闘の手前の小物が手札とボタンに隠れ、石舞台の中央の砂が橙のしみに見えた（空いた縁へ移した）。
- 2026-10-03：ユーザーの判断で、Topの3Dの舞台の上に重ねていた2Dの霧（`TopHd2dFog`）を外した。3Dの舞台の距離の霧と役目が重なり、画面に平らに貼った帯は、カメラの揺れやすべり込みがあっても奥行きに沿わない。奥の霞（`DeepHaze`）は、前の背景の通路の位置に合わせたものだった。
- 2026-10-03：ユーザーの指摘で、HomeとBattleInspectの手前のぼけを段階的にした。画面の行ごとのくっきり度（隣り合う画素の色の差の平均）を測ると、Homeは画面の下から200pxから180pxの20pxで半分以下に落ちていた。原因は3つあった。ぼけの半径が足元の下の短い帯で一気に増えていたこと、半径が小さい所で、くっきりした絵と半分の解像度の柔らかい絵を混ぜる割合だけを変えていたこと、手前の茂みが最も強くぼけて暗い帯になっていたことである。ぼけの増え方をゆるやかな曲線にし、小さい半径は元の解像度でその半径だけぼかすようにし、Homeは最大のぼけを弱めて画面の下端まで増え続けるようにし、手前の茂みを外した。くっきり度は200pxかけて少しずつ下がるようになった。茂みの画像の透明な部分は深度に書かれておらず、原因ではなかった（茂みの距離だけにピントを合わせて撮って確かめた）。戦闘は増え方がHomeの確定値とほぼ同じ傾きだったため、くっきりした範囲と最大のぼけに届く距離だけを直した。
- 2026-10-02：ユーザーの指摘で、手前のぼけを強めた。Homeの手前の茂みは画面の下の外に置いていて写っていなかったため、画面の下端が地面と交わる距離から位置を決め直し、くっきりした範囲を4人の足元からにした。戦闘は、くっきりした範囲を前列の足元からにし、手札の下の地面をぼかした。
- 2026-10-02：ユーザーの指摘で、停止中とPlay Mode中の見た目の違いと、Sceneタブで何も見えない問題を直した。停止中にHomeの2Dの霧と光が見えていた（霧のマスクが描画の止め方を毎フレーム戻していた）ため、保存しない `CanvasGroup` で消すようにした。舞台の粒子を停止中も動かし、戦闘の舞台のCanvasにシーンのカメラを設定した。Sceneタブは、手前のUIが原点に巨大な板として描かれて舞台を覆っていたため、シーンを開いたときに舞台のカメラから見る設定にし、手前のUIをSceneタブでだけ隠すようにした。
- 2026-10-02：ユーザーの依頼で、TopとBattleInspectも、Homeと重ならない屋外に変えた。Topは星空の夜の山の門、戦闘は夕暮れの高原の環状列石にし、Homeの昼（緑）と時間帯と色を分けた。空と遠景は光を受けない描いた遠景にし、月を門の背後に昇らせた。月の逆光で真っ黒になる崖と門には、影のない弱い補助光を当てた。夜空の減色で月が平らな灰色になったため、明るい画素の色を別に確保する変換を加えた。Topの広間の天井から差していた2Dの光芒は外した。
- 2026-10-02：ユーザーの依頼で、Homeを昼の森の野営地に変え、停止中もHD-2Dで表示するようにした。オクトパストラベラーの開発者の発言（被写界深度による奥行き、ライティングでのウソ、入力待ちのカメラの揺れ、エフェクトと同時に置く点光源）と、HD-2Dの再現例（被写界深度・Bloom・周辺減光・色調補正の組み合わせ）を調べ、舞台ごとのレンズと色調、木漏れ日・光の筋・漂う塵、カメラの揺れとすべり込みを加えた。URPの被写界深度は深度を書かない舞台のUIまでぼかすため、半透明の列の前に舞台だけをぼかす処理を作った。Home・Topは共通の `Hd2dPostProcess` から舞台ごとのProfileへ移し、`Hd2dPostProcess` のBloomは2Dの背景向けの値（しきい値0.4）に戻した。
- 2026-10-02：ユーザーの依頼で、Top・Home・BattleInspectを3Dの舞台に移した。カメラと光はオクトパストラベラーの資料を参考に、望遠寄りの見下ろし、冷色の主光源と暖色の点光源の対比、霧、Bloomで構成した。主光源ははじめ奥から当てたが、キャラの影がHPバーの下に隠れたため、左上から当てて影をキャラの右へ落とすようにした。
