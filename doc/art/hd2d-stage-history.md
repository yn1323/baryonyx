# 3Dの舞台（HD-2D）の変更と判断の記録

[3Dの舞台（HD-2D）](hd2d-stage.md)


- 2026-10-26：ユーザーの「更新したVFXの作り方で、全シーンのHD-2Dの表現を作り直す」との依頼で、3Dの舞台の常設の光と空気を、外部の画像を使わず、現象から決めた層に分けて計算で描き直した（[光と炎](hd2d-stage.md#光と炎)、[霧と煙](hd2d-stage.md#霧と煙)）。光芒は一様な縞で揺れる帯から、塵の濃淡が風で流れる帯・光に沿った筋・帯の外のにじみ・帯の中でだけ光る塵の粒に分けた。光だまりは光の粒と同じ丸い光の式から、縁の崩れたまだらな光の専用のシェーダーに分けた。光の粒は芯とにじみを別の幅にし、粒ごとに位相をずらして明滅させ、火の粉・塵・蛍・雪で明滅と透け方を変えた。炎には外側の薄い炎の舌を足し、煙は炎の板ではなく別の粒で炎の数倍の高さまで昇らせた（2026-10-03に炎の板の上端に描いた煙が見えなかったため）。霧は、現実に霧が生じる沼・朝の森・雪原・夜の墓地にだけ、地面を這う霧として置いた。火山の熱の柱（下向きの光芒）は、光芒は熱の現象と合わないため、溶岩に照らされて昇る噴気に替えた。熱のゆらぎ（屈折）は、舞台のカメラとスマートフォン用のURP設定が描いた画面の写しを作らないため描かなかった。木漏れ日のマスクはPNGから、コードと種から作る生成テクスチャに替え、葉のすき間が落とす太陽の丸い像を加え、草原と浜の雲の影は専用のマスクにしてPlay中に風で流すようにした。
- 2026-10-05：画面ごとの構成の表にあった「Exploration（Battleと同じ舞台から行き先の背景を選ぶ）」を外した。探索は2026-10-04に、3Dの舞台を使わない森を見下ろす地図へ作り替えている（[冒険の画面](../features/screens/adventure.md#冒険の画面)）。作業の進め方を記したスキルへのリンクを、3Dの舞台をまとめた hd2d-stage-set に替えた。
- 2026-10-03：ユーザーの「ライティングが足りない」との指摘を受け、10種類の戦闘の背景に、光芒と光だまり、草原と浜の雲の影を足した（[光芒と光だまり](hd2d-stage.md#光芒と光だまり)）。HD-2Dの照明の資料をWebで調べ直し、画面空間のボリュームライトはスマートフォンの負荷から採らず、板の光芒と地面の光だまりで光の当たる場所を見せることにした。撮影で見つけた次の問題を直した。窓と月の光芒の上端が描いた遠景の奥に出て隠れた（落ちる位置と向きを計算して手前へ収めた）。手前へ差す光芒が縦の柱に見えた（左右にも傾けた）。昼の草原と浜で光芒が地面の明るさに埋もれた（強くした）。
- 2026-10-03：ユーザーの依頼で、戦闘の背景を10種類（草原の街道、朝霧の森、坑道、水晶の洞窟、海辺の岩場、霧の沼地、雪原、火山、夜の墓地、古城の大広間）作り、`Battle.unity` でInspectorから選べるようにした（[戦闘の背景](hd2d-stage.md#戦闘の背景)）。テクスチャ89枚はCodex CLIで生成した。舞台ごとに作り方を変えず、夕暮れの高原で確かめた配置（床・遠景・額縁・奥の物・小物）を共通の決まりにした。撮影で見つけた次の問題を直した。奥の額縁の大物を描いた遠景より奥に置いて写っていなかった（遠景の手前へ移した）。古城の絨毯の上の割れた床石がしみに見えた（絨毯の外だけに置いた）。坑道と古城の床が暗く、キャラより先に暗さが目に付いた（床の色を明るくし、画面外の左右に暖色の点光源を置いた）。火山の赤い光で緑の敵が茶色に見えた（主光源と環境光を中立に近づけた）。
- 2026-10-03：ユーザーの依頼で、Top・Home・BattleInspectの舞台に、HD-2Dらしい密度とリアルな見え方を求めて、小物・草の房・地面の汚し・足元の陰を足した（[小物と汚し](hd2d-stage.md#小物と汚し)）。テクスチャ23枚はCodex CLIで生成した。光を受ける面には絵から計算した法線マップを付け、草と葉は裏からの光を透かして風で揺れるシェーダーにした。細い葉や刃は、地面と同じドットの細かさでは縮小でつぶれたため、細かくした。撮影で見つけた次の問題を直した。遠くの木の足元の陰がぼけた地面の上に細い線として残った（距離で絞った）。Homeの奥の木箱が大木の葉の影で黒い箱に見えた（日なたへ移し、暗く描かれた色を明るくした）。Topの旗が暗い崖に溶けた（手前の松明の外側へ移した）。戦闘の手前の小物が手札とボタンに隠れ、石舞台の中央の砂が橙のしみに見えた（空いた縁へ移した）。
- 2026-10-03：ユーザーの判断で、Topの3Dの舞台の上に重ねていた2Dの霧（`TopHd2dFog`）を外した。3Dの舞台の距離の霧と役目が重なり、画面に平らに貼った帯は、カメラの揺れやすべり込みがあっても奥行きに沿わない。奥の霞（`DeepHaze`）は、前の背景の通路の位置に合わせたものだった。
- 2026-10-03：ユーザーの指摘で、HomeとBattleInspectの手前のぼけを段階的にした。画面の行ごとのくっきり度（隣り合う画素の色の差の平均）を測ると、Homeは画面の下から200pxから180pxの20pxで半分以下に落ちていた。原因は3つあった。ぼけの半径が足元の下の短い帯で一気に増えていたこと、半径が小さい所で、くっきりした絵と半分の解像度の柔らかい絵を混ぜる割合だけを変えていたこと、手前の茂みが最も強くぼけて暗い帯になっていたことである。ぼけの増え方をゆるやかな曲線にし、小さい半径は元の解像度でその半径だけぼかすようにし、Homeは最大のぼけを弱めて画面の下端まで増え続けるようにし、手前の茂みを外した。くっきり度は200pxかけて少しずつ下がるようになった。茂みの画像の透明な部分は深度に書かれておらず、原因ではなかった（茂みの距離だけにピントを合わせて撮って確かめた）。戦闘は増え方がHomeの確定値とほぼ同じ傾きだったため、くっきりした範囲と最大のぼけに届く距離だけを直した。
- 2026-10-02：ユーザーの指摘で、手前のぼけを強めた。Homeの手前の茂みは画面の下の外に置いていて写っていなかったため、画面の下端が地面と交わる距離から位置を決め直し、くっきりした範囲を4人の足元からにした。戦闘は、くっきりした範囲を前列の足元からにし、手札の下の地面をぼかした。
- 2026-10-02：ユーザーの指摘で、停止中とPlay Mode中の見た目の違いと、Sceneタブで何も見えない問題を直した。停止中にHomeの2Dの霧と光が見えていた（霧のマスクが描画の止め方を毎フレーム戻していた）ため、保存しない `CanvasGroup` で消すようにした。舞台の粒子を停止中も動かし、戦闘の舞台のCanvasにシーンのカメラを設定した。Sceneタブは、手前のUIが原点に巨大な板として描かれて舞台を覆っていたため、シーンを開いたときに舞台のカメラから見る設定にし、手前のUIをSceneタブでだけ隠すようにした。
- 2026-10-02：ユーザーの依頼で、TopとBattleInspectも、Homeと重ならない屋外に変えた。Topは星空の夜の山の門、戦闘は夕暮れの高原の環状列石にし、Homeの昼（緑）と時間帯と色を分けた。空と遠景は光を受けない描いた遠景にし、月を門の背後に昇らせた。月の逆光で真っ黒になる崖と門には、影のない弱い補助光を当てた。夜空の減色で月が平らな灰色になったため、明るい画素の色を別に確保する変換を加えた。Topの広間の天井から差していた2Dの光芒は外した。
- 2026-10-02：ユーザーの依頼で、Homeを昼の森の野営地に変え、停止中もHD-2Dで表示するようにした。オクトパストラベラーの開発者の発言（被写界深度による奥行き、ライティングでのウソ、入力待ちのカメラの揺れ、エフェクトと同時に置く点光源）と、HD-2Dの再現例（被写界深度・Bloom・周辺減光・色調補正の組み合わせ）を調べ、舞台ごとのレンズと色調、木漏れ日・光の筋・漂う塵、カメラの揺れとすべり込みを加えた。URPの被写界深度は深度を書かない舞台のUIまでぼかすため、半透明の列の前に舞台だけをぼかす処理を作った。Home・Topは共通の `Hd2dPostProcess` から舞台ごとのProfileへ移し、`Hd2dPostProcess` のBloomは2Dの背景向けの値（しきい値0.4）に戻した。
- 2026-10-02：ユーザーの依頼で、Top・Home・BattleInspectを3Dの舞台に移した。カメラと光はオクトパストラベラーの資料を参考に、望遠寄りの見下ろし、冷色の主光源と暖色の点光源の対比、霧、Bloomで構成した。主光源ははじめ奥から当てたが、キャラの影がHPバーの下に隠れたため、左上から当てて影をキャラの右へ落とすようにした。
