# 3Dの舞台：戦闘の背景

[3Dの舞台（HD-2D）](../hd2d-stage.md) / 根拠：[アート方針](../direction.md)

## 戦闘の背景

2026-10-03、ユーザーの依頼で、冒険の行き先として必要になりそうな場所を10か所選び、戦闘の背景として作った。
場所の名前と行き先の構成はまだ決まっていない（[探索する場所の定義](../../catalog/stages/README.md)）。
ここでは、王道ファンタジーのRPGでよく行く場所を、序盤の草原から終盤の古城まで、時間帯と主な色が重ならないように選んだ。

戦闘シーン `Battle.unity` は、BattleLabと同じ戦闘画面に、夕暮れの高原と下の10種類の舞台を置く。
シーンの `BattleStages` の [BattleStageSelector](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleStageSelector.cs) の `Stage`（Inspectorでは日本語の名前のドロップダウン）で、表示する背景を選ぶ。
選んだ舞台だけを有効にし、その舞台の環境光・霧・カメラの背景色、レンズと色調（`StageLookVolume` のProfile）、キャラの影を向ける主光源を切り替える。
停止中のシーンでも選んだ時点で切り替わり、Play Mode中にコードから `Apply` を呼んでも切り替わる。
シーンを作り直すと、草原の街道を選んだ状態になる。

|---|---|---|---|

10種類の舞台は、同じ配置の決まりで組み立てる（[BattleStageSets](../../../client/Assets/Baryonyx/Shared/Art/Stages/Editor/BattleStageSets.cs)）。
カメラはBattleLabと同じで、キャラは夕暮れの高原と同じ地面の位置に立つ。

| 物 | 置き方 |
|---|---|
| 床 | 両陣営が立つ17m四方の1枚絵（草原は土の広場、坑道は板張りの床、古城は赤い絨毯など）を高さ0に敷き、周りの地面のタイル（1枚3m）を3cm下げる |
| 遠景 | 描いた遠景（19.2m×8m）を3枚並べ、中央を左右反転する。奥行き17.6m、2.4m沈める（夕暮れの高原と同じ） |
| 額縁の大物 | 木・崖・柱などを奥の左右の角に2組（奥行き15.6〜17.3m）。画面の上端で切れる |
| 奥の物 | 柵・岩・墓石・甲冑などを、左右の端と奥の縁の4か所に、大きさと左右反転を変えて置く |
| その場で起きたことを見せる物 | 奥の縁の中央に1つ（壊れた荷車、祠、トロッコ、難破船、竜の頭骨、天使の像など） |
| 小物 | 奥の縁と手前の左右の角、左右の端に5つ。手札とボタンの下には背の高い物を置かない |
| 草の房 | 床の外に散らし、草の生える舞台は床の割れ目にも短い房を置く。立つ物の足元にも添える |
| 地面の汚し | 床の縁と地面に散らす。古城は絨毯の上に置かない |
| 光源の物 | 坑道と墓地はランタンの柱、古城は鉄の燭台を、夕暮れの高原のかがり火と同じ奥の左右（x=±7.2m、奥行き15.2m）に置く |

置き方の決まりは次のとおりである。

- 描いた遠景（奥行き17.6m）より奥に置いた物は、遠景の板に隠れて写らない。奥の物は17.3m以内に置く。最初に額縁の大物の奥の組を17.8〜17.9mに置き、写らなかった。
- 夜と屋内の舞台（坑道・水晶の洞窟・霧の沼地・夜の墓地・古城・火山）の暗がりは、黒く沈めずに青で表す。環境光の空・周り・地面、色調の影の色、周辺減光の色を青へ寄せ、周辺減光の強さは0.3〜0.34にする（[暗がりの色](light-fire.md#光と炎)）。坑道の茶色い闇や古城の黒い床の手前は、灯りの届かない所が黒くつぶれて見えた。
- 夜と屋内の舞台（坑道・水晶の洞窟・霧の沼地・夜の墓地・古城・火山）は、手前からの影のない弱い補助光を当てる。坑道と古城は、画面外の左右に暖色の点光源を置いて両陣営を照らす。暗いままでは、キャラより先に床の暗さが目に付いた。
- 場所の色が強い舞台でも、主光源と補助光は中立に近い色にする。火山で赤橙の主光源と赤い環境光を当てると、緑の敵が茶色に見え、キャラの色が読めなくなった。赤は溶岩・空・点光源に任せる。
- 暗く描かれた床（坑道の板、古城の絨毯）は、マテリアルの色で1.15〜1.3倍に明るくする。
- 地面の汚しは、模様のある床の上に置かない。古城の絨毯の上の割れた床石は、しみに見えた。
- 夕暮れの高原と同じく、小物・草の房はキャラの足元から0.8m以上離す。BattleシーンのEditModeテストで、全部の舞台について確かめる。

### 光芒と光だまり

2026-10-03、ユーザーの「ライティングが足りない、もっとHD-2Dっぽく光を当て、光芒を作る」との指摘を受け、10種類の舞台に光芒と光だまりを足した。
HD-2Dの開発者は、点光源でキャラと物に影を落とし、光と影でドット絵の環境に光がどう当たるかを見せることを重視したと述べている（[参考資料](../../../.agents/skills/shared/hd2d-research-sources.md#hd-2dの光芒と光だまり3回目)）。
舞台ごとに光の向きと色を1つ決め、空気の中の光の筋（光芒）と、その光が落ちた地面の柔らかい光（光だまり）を対にして置く。
光芒は `Baryonyx/HD2D/Light Beam` の板、光だまりは `Baryonyx/HD2D/Light Pool` を地面に寝かせた加算の板で、マテリアルは舞台ごとに色と強さを変えて作る（`<接頭辞><名前>.mat`）。
どちらも画像を使わず計算で描く。層の分け方は[光と炎](light-fire.md#光と炎)にある。

| 舞台 | 光芒（強さ） | 光だまり（強さ） | ほかの光 |
|---|---|---|---|
| 草原の街道 | 太陽の向きに、木々の上と雲のすき間から3本（1.55） | 光芒の落ちる所（0.5） | 雲の影（太陽のクッキーに雲の影のマスクを34mごとに敷き、Play中は風で流す） |
| 朝霧の森 | 太陽の向きに、幹の間から5本（1.65） | 光芒の落ちる所（0.66） | 木漏れ日（12mごと） |
| 坑道 | 天井の割れ目から冷色の2本（1.4） | 光芒の落ちる所（0.5）、ランタンの足元（0.95） | 天井の光の下に冷色の点光源 |
| 水晶の洞窟 | 天井の割れ目から3本（1.85） | 光芒の落ちる所（0.75）、水晶の周りに水色と紫（1.3） | |
| 海辺の岩場 | 太陽の向きに、入道雲のすき間から幅の広い3本（1.1） | 光芒の落ちる所（0.42） | 雲の影（40mごと。Play中は風で流す） |
| 霧の沼地 | 霧のすき間から4本（1.1） | 光芒の落ちる所（0.5）、鬼火の下に緑（1.2） | |
| 雪原 | 太陽の向きに、雲のすき間から3本（1.25） | 光芒の落ちる所（0.36） | |
| 火山 | なし（奥の3つの割れ目から噴気が昇る。[霧と煙](#霧と煙)） | 溶岩の割れ目の周りに橙（1.45） | 点光源のある所に溶岩の割れ目を置く |
| 夜の墓地 | 月の側から斜めに3本（1.1） | 光芒の落ちる所（0.6）、街灯の足元（0.95） | |
| 古城の大広間 | ステンドグラスから青・金・赤の3本（1.6） | 光芒の落ちる所に同じ色（0.5）、かがり火の足元（1.1、幅5.5m） | |

強さは2026-11-11に、ユーザーの「ライティングが弱い、もっと強く」との指摘で上げた（光芒は約1.8倍、光芒の落ちる所は約1.7倍、灯り・水晶・鬼火・溶岩の周りは約1.9〜2.4倍）。
舞台の点光源（ランタン・街灯・水晶・鬼火・溶岩・かがり火、画面外の左右の灯り）も、同じときに強さを約4倍、届く範囲を約1.75倍にした。

置き方の決まりは次のとおりである。

- 光芒の板も、描いた遠景（奥行き17.6m）より奥では遠景に隠れる。奥から手前へ差す光（月、窓、天井の割れ目）は、光の向きと始まりの高さから上端の位置を計算し、17.4m以内に収める。
- 太陽の向きに差す光芒は、太陽の方位のまま、見下ろし60度まで立てる（`StageSetAssets.ShaftTravel`）。低い太陽（朝霧の森は34度）の向きそのままでは、光芒が画面を斜めに横切って寝て見え、上から降りてくる光に見えなかった（2026-11-11、ユーザーの指摘）。影は太陽の向きのままにする（ライティングでのウソ）。
- 1つの舞台の光芒は、幅をそろえない。葉や雲のすき間の大きさは一つずつ違うため、0.6〜0.8mの細い筋、1〜2mの筋、2.6〜4.2mの太い帯を混ぜる。幅が1.2〜1.9mにそろっていると、同じ板を並べたように見えた（同じ日の指摘）。光だまりの広さも光芒の幅に合わせて変える。
- 奥から手前へ差す光は、左右にも傾ける（光の進む向きのxを0.4〜0.45）。手前へまっすぐ差す光は画面で縦の柱に見え、光の筋に見えなかった。
- 光芒の板は地面の近くで消えるため、光が地面に届いたことは光だまりで見せる。光だまりは光芒の幅の約2倍に広げ、光芒の落ちる所の強さを0.36〜0.75に収める。色の付いた小さく強い光だまりは、キャラの足元でしみに見えた。灯り・水晶・鬼火・溶岩の周りの光だまりは、光源のそばにあって何の光かが分かるため、0.95〜1.45まで強くしてよい。
- 昼の明るい地面では、加算の光芒が埋もれる。昼の舞台は夜の舞台より強くし、空や木の幹を背にして見せる。
- 光芒はキャラの板より先に描くため、キャラの前を通る位置に置いてよい。

### 霧と煙

2026-10-26、VFXの作り方の更新に合わせ、炎と溶岩には別の粒で煙と噴気を昇らせた。
煙と噴気は `Baryonyx/HD2D/Stage Smoke` で、画像を使わず計算で描く。
距離の線形の霧（`RenderSettings`）は、どの舞台でも遠くを空気の色に寄せる役のまま残す。

地面を這う霧（`Baryonyx/HD2D/Stage Mist`）は、2026-10-30に全ての舞台から外し、シェーダーと舞台ごとのマテリアルも消した。
ミストラ遺跡（朝霧の森）の戦闘がめちゃめちゃ重いとユーザーが指摘したためである。
霧は戦闘の場に重なる大きな板を3枚と奥に立てた板を2〜3枚重ね、1画素ごとに2回ゆがめた5段のfBmを読んでいたため、画面のほぼ全体で重い計算が重なっていた。
同じ霧を置いていた霧の沼地・雪原・夜の墓地からも外した。

| 舞台 | 現象 | 描くもの |
|---|---|---|
| 火山 | 割れ目から昇る火山ガスと灰。低い所は溶岩に下から照らされる | 噴気（奥の3つの割れ目） |
| 古城の大広間・夕暮れの高原 | 燭台・かがり火の煙が炎の上に昇り、下から照らされる | 煙（炎ごとに1つ） |

置き方の決まりは次のとおりである。

- 霧が生じる舞台でも、画面に重なる半透明の霧の板は置かない。空気の色は距離の線形の霧の色と距離で出す。
- 火山の手前の割れ目（奥行き2.2m）からは噴気を出さない。両陣営の前に昇り、キャラを覆う。
- 熱のゆらぎ（背景の屈折）は描かない。屈折には描いた画面の写し（Opaque Texture）が要るが、スマートフォン用のURP設定と舞台のカメラはそれを作らない設定のためである。
