## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 分類 | 道具・素材のどちらか（[アイテム](../../features/items.md)）。ほかの分類を設けるかは未決 |
| レア度 | 個別値は未決。☆1〜☆5で見つかりやすさを表す（[入手](../../features/items.md#入手)） |
| カードとしての効果・対象・コスト・効果量 | 個別値は未決。戦闘ではスキルと同じくデッキのカードになり、使っても持っている量は減らない（[戦闘での使い方](../../features/items.md#戦闘での使い方)） |
| 入手先（落とす敵・宝箱） | 個別値は未決。今の行き先ごとの一覧は[冒険のドロップ](../../features/drops.md#行き先ごとの一覧)（正本はサーバーの drops.ts）にある |
| 合成での用途・売却・所持上限 | 合成の材料は[レシピの一覧](../../features/synthesis.md#レシピの一覧)、売る値段は[商会の売る](../../features/screens/shop.md#売る)にある。所持上限は未決 |
| 大きさ・形状・材質・色・模様・発光 | 未決 |
| 世界内の由来・使用時の扱い | 未決 |
| アイコンと詳細絵で維持する特徴 | 未決 |
