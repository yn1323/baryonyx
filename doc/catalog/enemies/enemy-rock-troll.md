# 岩肌トロル

[敵の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

洞窟に棲む、大きいボスの敵である。
2026-10-19の時点で、まだどの行き先にも出ない。
敵の種類のIDと弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)（`RockTroll`）とする。
この文書は、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
ステータス・技・行動は未実装で、絵は[ライブラリ](../../features/library.md)と[展示室](../../features/showcase.md)で表示するだけである。
2026-10-20から、グラシエラ氷窟（`glaciera-cave`、Lv18）の最奥の主として、冒険の戦闘に出る（[行き先と敵](../../features/stage-progression.md#行き先と敵)）。
戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「肩石投げ」だけを物攻で物理として（味方の物防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。
ほかの技と行動パターンは未実装である。

### ステータス

| Lv | HP | 物攻 | 物防 | 属攻 | 属防 | 速度 | 会心 | 幸運 |
|---|---|---|---|---|---|---|---|---|
| 100（定義の値） | 18700 | 2470 | 1100 | 910 | 800 | 790 | 390 | 700 |

型は力押しの `bruiser` とした。
石柱を振り回す怪力として、物攻を試作の大の敵の中でも高い組（2470）にした。
岩の肌で物防も高いが、全身を金属で覆う真鍮の番人ほどではない。
魔法を使わないため属攻は低い。岩肌の再生は失ったHPの割合で回復するため、属攻を使わない。
重い体で速度は遅く、しぶとい体として幸運を高めにした。
すべて仮の値である。
技の括弧内の値は防御で減らす前の威力で、受ける味方の物防（物理の技）または属防（魔法の技）で減る（[ダメージと防御](../../features/combat.md#ダメージと防御)）。

## 行動パターン

前半と後半で選び方を変える。
後半への切り替えが、この敵の[激化](../../features/combat.md#防御と敵の激化)である。

**前半**（激化まで）

- 1ターン目は肩石投げを使い、以後は打ち砕き、地響き、肩石投げ、身を固めるの順にくり返す。
- 順番を1周するごとに、次の2ターンを渾身の一撃の溜めと渾身の一撃にする。
- HPが7割以下のときは、3ターンに1回、順番の代わりに岩肌の再生を使う。飛ばした順番は次のターンへ送る。
- 自分のほかに立っている敵がいないときは、順番の代わりに仲間を呼ぶを使い、大耳コウモリを1体呼ぶ。1回の戦闘で2回までとする。

**激化の切り替え**

- 6ターン目、またはHPが半分以下になった直後の行動の、早いほうで1回だけ切り替える。切り替えの行動では、肩の岩を叩き割って吠え、岩肌の再生を使う。

**後半**（激化のあと）

- 4ターンを1組として、「選ぶ・選ぶ・溜め・洞窟崩し」をくり返す。
- 選ぶターンは、打ち砕き・地響き・肩石投げから選び、同じ技を2回続けない。仲間を呼ぶの割り込みは、選ぶターンにだけ入れる。怒って傷を顧みないため、岩肌の再生は使わない。
- 溜めのターンは、身を固めると洞窟崩しの溜めを同時に行い、予告に防御と溜め（大技まであと1ターン）を並べる。洞窟崩しのあとは絡みつきでカードのコストが上がるため、プレイヤーは溜めのターンにエネルギーを使い切るか、次のターンへ手札を残すかを選ぶ。

予告に大技までのターン数を出す作りは、[戦闘中の情報の優先順位](../../features/combat.md#戦闘中の情報の優先順位)の「予告では、特に激化ターンの大技を見せる」に合わせた。

### 激化の見せ方

切り替えの行動で、肩の岩を拳で叩き割り、天井を仰いで吠える演出を出す。画面を短く揺らし、天井から細かい砂と小石を落とす。
激化のあいだは、黄色い目の光が強まり、岩肌の継ぎ目に薄い赤の揺らぎを重ねる。揺らぎは予告と弱点のアイコンを隠さない明るさに抑える。
撃破の演出は、戦闘画面のモックのボスの撃破（長く重く崩れる）を使う（[戦闘画面の見た目モック](../../features/screens.md#戦闘画面の見た目モック)）。

|---|---|
| 数値 | ステータス、行動の割合と回数制限、激化の条件と倍率は仮。[戦闘の未決事項](../../features/combat.md#未決事項)の数値が決まったら見直す |
| 出現する場所とLv | 洞窟のどの行き先・マスに、どの敵と組んで、どのLvで出すか（[ステージの定義](../stages/README.md)） |
| 速度・会心・幸運 | 速度は、味方の合計と比べる方法（[ターン順](../../features/combat.md#ターン順)）が決まったら尺度を合わせ直す。会心と幸運は、使い道（[候補](../../features/party.md#ステータスの項目)）が決まったら見直す |
| 飛び散る攻撃・失ったHPの割合での回復・全体の絡みつき | 新しい仕組みの決まり（[肩石投げ](../enemy-skills/enemy-skill-rock-troll-boulder-toss.md)、[岩肌の再生](../enemy-skills/enemy-skill-rock-troll-regrow.md)、[洞窟崩し](../enemy-skills/enemy-skill-rock-troll-cave-in.md)） |
| 呼び出し | 呼んだ敵の立ち位置と行動順への入れ方（[仲間を呼ぶ](../enemy-skills/enemy-skill-call-ally.md)） |
| 弱点の数 | 1体に複数の弱点を持たせるか（[弱点の開示](../../features/combat.md#弱点の開示)の未決） |
| 実装 | 冒険の戦闘では、ステータスと技1つ（肩石投げ）だけを使う。ほかの技と行動パターンは未実装。実装するときは[敵の挙動デバッグルーム](../../features/screens.md#敵の挙動デバッグルーム)の行動も増やす |
