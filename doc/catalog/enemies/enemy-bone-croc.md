# 骨背の大ワニ

[敵の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

沼に棲む、大きな敵（ボス級）である。
前半は引き裂きで出血を負わせ、呼び寄せた吸血大ヒルを丸のみにして傷を癒し、後半は血の匂いで出血した味方を狙い、予告つきの大技で沼へ引きずり込む。
この文書は、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
2026-10-19の時点で、画像と敵の種類・弱点だけを実装しており、HP・技・行動は未実装である。

型は bruiser（力で押す型）とした。
大きな顎の力で、物攻を森の守り手（1940）より高くし、HPも守り手より多くした。
うろこの厚い体で物防は高いが、岩の体の守り手には及ばない。
魔法を使わないため属攻は低く、属防は物防よりやや低い。
水の中ではない陸の戦いでは動きが重く、速度は沼の5体の中で最も遅い。
長い年月を生き延びた体として、幸運を高めにした。

## 行動パターン

前半と後半で選び方を変える。
後半への切り替えが、この敵の[激化](../../features/combat.md#防御と敵の激化)である。

**前半**（血の匂いまで）

- 1ターン目はかみつきを使い、以後はかみつき、引き裂き、身を固める、なぎ払いの順にくり返す。
- 自分のHPが最大HPの70%以下で、自分以外の敵がいるときは、順番の代わりに丸のみを使う。3ターンに1回までとし、飛ばした順番は次のターンへ送る。
- 自分のほかに立っている敵がいないときは、順番の代わりに仲間を呼ぶを使い、吸血大ヒルを1体呼ぶ。1回の戦闘で2回までとする。

**血の匂い**

- 6ターン目、またはHPが半分以下になった直後の行動の、早いほうで1回だけ使う。

**後半**（血の匂いのあと）

- 4ターンを1組として、「選ぶ・選ぶ・溜め・死の回転」をくり返す。
- 選ぶターンは、かみつき・引き裂き・なぎ払いから選び、同じ技を2回続けない。出血している味方がいないときは引き裂きを選ぶ。丸のみと仲間を呼ぶの割り込みは、選ぶターンにだけ入れる。
- 溜めのターンは、身を固めると死の回転の溜めを同時に行い、予告に防御と溜め（大技まであと1ターン）と標的を並べる。標的は、出血している味方のうちHPの割合が最も低い味方とし、出血している味方がいなければHPの割合が最も低い味方とする。

予告に大技までのターン数と標的を出す作りは、[戦闘中の情報の優先順位](../../features/combat.md#戦闘中の情報の優先順位)の「予告では、特に激化ターンの大技を見せる」に合わせた。

### 激化の見せ方

激化は、[血の匂い](../enemy-skills/enemy-skill-bone-croc-blood-scent.md)の演出で見せる。
後半のあいだは、黄色い目が赤みを帯び、背中の骨のとげの列に沿って薄い赤の揺らぎがときどき走る。
揺らぎは予告と弱点のアイコンを隠さない明るさに抑える。
撃破の演出は、ボスの撃破（長く重く崩れる）を使う（[戦闘画面の見た目モック](../../features/screens/battle.md#戦闘画面の見た目モック)）。
