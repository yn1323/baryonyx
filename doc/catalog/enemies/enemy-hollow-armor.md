# 古王国の空鎧

[敵の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

遺跡に出る雑魚のうち、中くらいの大きさで、仲間の盾になる敵である。
弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)、サーバーで記録できる敵のIDは [catalog.ts](../../../server/src/features/combat/catalog.ts) の `ENEMY_IDS` とする。
この文書は、生息する地域、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
2026-10-19の時点で、画像と弱点だけをクライアントに取り込んでおり、どの行き先にも出ない。HP・技・行動は未実装である。
2026-10-20から、アルマジャ王墓（`almaja-tomb`、Lv26）の中くらいの敵・月影の墓所（`moonshade-graveyard`、Lv30）の中くらいの敵として、冒険の戦闘に出る（[行き先と敵](../../features/stage-progression.md#行き先と敵)）。
戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「空ろの鎧ばらし」だけを物攻で物理として（味方の物防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。
ほかの技と行動パターンは未実装である。

守り型の値である。
厚い板金と盾で刃と打撃を受けるため、HPと物防を高くした。
中の霧は魔法に乱されやすいため、属防は物防より低い。
錆びた剣でも兵の腕前は残っているため、物攻は中の敵の並みにした。

## 行動パターン

- 1ターン目は、仲間がいれば番兵の盾、いなければ力を溜めるを使う。
- 2ターン目からは、斬りつけ（50%）、打ち砕き（30%）、力を溜める（20%）から選ぶ。同じ技を3回続けず、力を溜めた次のターンは斬りつけか打ち砕きを使う。
- 仲間がいて、HPが半分以下の仲間がいるときは、順番の代わりに番兵の盾を使う。3ターンに1回までとする。
- HPが半分以下になった直後の行動で、空ろの鎧ばらしを使う。1回の戦闘で1回までとする。
- 激化：5ターン目以降は継ぎ目からもれる霧が濃くなり、斬りつけの威力が1.3倍（1326）、打ち砕きの防御ダウンが3ターンになる。予告の数字もこれに合わせて変える。

### 激化の見せ方

5ターン目の行動の前に、兜の隙間から紫の霧が勢いよく噴き出し、剣を床に打ち付ける演出を短く出す。
激化のあいだは、継ぎ目からもれる霧を濃くし、ゆっくり揺らめかせる。
霧は予告と弱点のアイコンを隠さない濃さに抑える。
