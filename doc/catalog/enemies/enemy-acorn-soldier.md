# どんぐり兵

[敵の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

森に出る雑魚のうち、小さな体で物理の攻めが強い敵である。
弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)、サーバーで記録できる敵のIDは [catalog.ts](../../../server/src/features/combat/catalog.ts) の `ENEMY_IDS` とする。
この文書は、生息する地域、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
2026-10-19の時点で、画像と弱点だけをクライアントに取り込んでおり、どの行き先にも出ない。HP・技・行動は未実装である。
2026-10-20から、ミストラ遺跡（`forest-ruins`、Lv10）の小さな敵として、冒険の戦闘に出る（[行き先と敵](../../features/stage-progression.md#行き先と敵)）。
戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「どんぐりつぶて」だけを物攻で物理として（味方の物防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。
ほかの技と行動パターンは未実装である。

力押し型の値である。
石の穂先の槍で突くため、物攻を小さな敵の中で高くした。
殻は硬いが体が小さいため、HPと物防は小の範囲にとどめた。
魔法を使わないため、属攻は低い。
すべて仮の値である。
技の括弧内の値は、Lv100で防御で減らす前の威力である。

## 行動パターン

- 1ターン目は、二段突きを使う。
- 2ターン目からは、二段突き（50%）、どんぐりつぶて（30%）、身を固める（20%）から選ぶ。同じ技を3回続けず、どんぐりつぶては2回続けない。
- HPが半分以下になったら、次の行動を身を固めるにする。1回の戦闘で2回までとする。
- 激化：5ターン目以降は帽子の兜を深くかぶり直し、二段突きの威力が1.3倍（811を2回）、どんぐりつぶてが4回になる。予告の数字もこれに合わせて変える。

### 激化の見せ方

5ターン目の行動の前に、帽子の兜を両手で押し下げ、槍を立てて小さく跳ねる演出を短く出す。
激化のあいだは、殻のつやを一段明るくし、槍の穂先がときどき光る。
光は予告と弱点のアイコンを隠さない明るさに抑える。
