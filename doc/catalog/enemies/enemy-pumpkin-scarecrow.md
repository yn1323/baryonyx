# かぼちゃ頭の案山子

[敵の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

街道に出る雑魚のうち、中くらいの大きさの敵である。
弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)、サーバーで記録できる敵のIDは [catalog.ts](../../../server/src/features/combat/catalog.ts) の `ENEMY_IDS` とする。
この文書は、生息する地域、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
2026-10-19の時点で、画像と弱点だけをクライアントに取り込んでおり、どの行き先にも出ない。HP・技・行動は未実装である。
2026-10-20から、港町ポルトリア（`port-portoria`、Lv14）の中くらいの敵・月影の墓所（`moonshade-graveyard`、Lv30）の中くらいの敵として、冒険の戦闘に出る（[行き先と敵](../../features/stage-progression.md#行き先と敵)）。
戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「畑の見張り番」だけを物攻で物理として（味方の物防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。
ほかの技と行動パターンは未実装である。

釣り合い型の値である。
藁を詰めた体は叩かれても衝撃を散らし、詰め直せば元に戻るため、HPを中の敵の真ん中にした。
仲間を守るため先に狙われやすい役のため、物防も真ん中に置いた。

すべて仮の値である。

## 行動パターン

- 1ターン目は、にらみつけを使う。
- 2ターン目からは、たいあたり（50%）、種つぶて（30%）、力を溜める（20%）から選ぶ。同じ技を3回続けず、力を溜めるの次はたいあたりにする。
- 仲間がいて、見張りが切れているときは、2ターン目と、以後4ターンごとに、通常の選び方の代わりに畑の見張り番を使う。仲間がいないときは使わない。
- にらみつけは、前に使ってから4ターンたったら使う。
- 激化：5ターン目以降はかぼちゃの頭の中に火がともったように光り、たいあたりと種つぶての威力が1.3倍（1560・624）になる。予告の数字もこれに合わせて変える。

### 激化の見せ方

5ターン目の行動の前に、くり抜いた目と口の奥が橙に灯り、頭の藁が逆立つ演出を短く出す。
激化のあいだは、目と口の灯りがろうそくのようにゆらぐ。
炎が弱点の敵のため、灯りは燃えている火ではなく内側の光として描き、予告と弱点のアイコンを隠さない明るさに抑える。
