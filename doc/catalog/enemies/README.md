# 敵の定義

[データ索引](../README.md) / [関連仕様](../../features/combat.md)

個別内容と決定状態は、下の索引から各定義を参照する。
画像対象テンプレートを使う。
IDの接頭辞は `enemy-`、メタデータの `category` は `enemies` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 分類・役割・出現ステージID | 未決 |
| ステータス・属性・耐性・状態異常への反応 | 未決 |
| HP・ダウンゲージ最大値 | 個別値は未決。[ダウンの共通ルール](../../features/combat.md#ダウンの名称と基本ルール)に従う |
| 弱点属性・弱点武器 | 個別設定は未決。[弱点の共通ルール](../../features/combat.md#敵の弱点属性と弱点武器)に従う |
| 攻撃・スキルID・AI・行動条件・行動予告 | 未決 |
| 体格・輪郭・部位・移動方法・材質・配色 | 未決 |
| 性格・知性・習性・生息地・行動原理 | 未決 |
| 通常・攻撃予告・攻撃・被弾・ダウン中・敗北の姿 | 個別設定は未決 |
| 雑魚・ボス・亜種の関係と意図した違い | 未決 |
| 報酬テーブルID | 未決 |

体格や部位の記述は外見の定義に使う。
[部位別HP・部位別ダウンゲージは採用しない](../../features/combat.md#敵の弱点属性と弱点武器)。

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
