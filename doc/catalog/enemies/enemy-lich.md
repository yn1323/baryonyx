# 死霊の魔導師

[敵の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

墓地の奥に現れる、ボス（大）の敵である。
弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)、サーバーで記録できる敵のIDは [catalog.ts](../../../server/src/features/combat/catalog.ts) の `ENEMY_IDS` とする。

2026-10-19の時点で、画像と弱点だけをクライアントに取り込んでおり、どの行き先にも出ない。HP・技・行動は未実装である。

戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「王冠の覚醒」だけを属攻で魔法として（味方の属防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。

## 行動パターン

前半と後半で選び方を変える。
後半への切り替えが、この敵の[激化](../../features/combat.md#防御と敵の激化)である。

**前半**（王冠の覚醒まで）

- 1ターン目はにらみつけを使い、以後は氷のつぶて、冷たい息、朽ちの呪い、身を固めるの順にくり返す。
- 朽ちの呪いは、防御のカードを最後に使った味方を狙う。まだだれも使っていなければ、物防の最も高い味方を狙う。
- 自分のほかに立っている敵がいないときは、順番の代わりに仲間を呼ぶを使い、骸骨兵を1体呼ぶ。1回の戦闘で2回までとする。

**王冠の覚醒**

- 6ターン目、またはHPが半分以下になった直後の行動の、早いほうで1回だけ使う。

**後半**（王冠の覚醒のあと）

- 5ターンを1組として、「選ぶ・選ぶ・詠唱・詠唱・葬送の詠唱」をくり返す。
- 選ぶターンは、氷のつぶて（全体へ広げて1170）・冷たい息・朽ちの呪い（全体へ広げる）・にらみつけ（全体へ広げる）から選び、同じ技を2回続けない。にらみつけは1組に1回までとする。仲間を呼ぶの割り込みは、選ぶターンにだけ入れる。
- 詠唱のターンは、予告に溜め（大技まであと2ターン、あと1ターン）を出す。プレイヤーは、炎か打で詠唱を崩すか、防御で受けるかを選ぶ。
- 詠唱が崩れたターンの次は、選ぶターンからやり直す。

後半は、朽ちの呪いが味方全体に広がるため、防御だけで葬送の詠唱を受けきるのが難しくなる。
弱点の炎・打で詠唱を崩す答えに、プレイヤーを向かわせる作りにした。
予告に大技までのターン数を出す作りは、[戦闘中の情報の優先順位](../../features/combat.md#戦闘中の情報の優先順位)の「予告では、特に激化ターンの大技を見せる」に合わせた。

### 激化の見せ方

激化は、[王冠の覚醒](../enemy-skills/enemy-skill-lich-crown-awaken.md)の演出で見せる。
目覚めたあとは、王冠の宝石と目が緑に灯り続け、杖の先の渦が速く回る。
撃破の演出は、ローブが崩れ落ちて骨が散り、最後に王冠だけが床に落ちて転がる形にする。
