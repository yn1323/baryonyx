# 骸骨兵

[敵の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

墓地に出る雑魚のうち、中くらいの大きさの敵である。
弱点の実行上の正本は [CombatEnemies](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)、サーバーで記録できる敵のIDは [catalog.ts](../../../server/src/features/combat/catalog.ts) の `ENEMY_IDS` とする。
この文書は、生息する地域、ステータス、使う技と行動パターン、外見と性格の設定を持つ。
技の効果と演出は[敵の技の定義](../enemy-skills/README.md)に置く。
2026-10-19の時点で、画像と弱点だけをクライアントに取り込んでおり、どの行き先にも出ない。HP・技・行動は未実装である。
2026-10-20から、月影の墓所（`moonshade-graveyard`、Lv30）の中くらいの敵として、冒険の戦闘に出る（[行き先と敵](../../features/stage-progression.md#行き先と敵)）。
戦闘では、下のLv100のステータスに出るLvの成長率を掛けて使い、技は「斬りつけ」だけを物攻で物理として（味方の物防で受ける）使う（[CombatEnemyStats](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyStats.cs)）。
ほかの技と行動パターンは未実装である。

## 行動パターン

- 1ターン目は、斬りつけを使う。
- 2ターン目からは、斬りつけ（40%）、打ち砕き（30%）、身を固める（30%）から選ぶ。同じ技を3回続けず、身を固めるは2回続けない。
- 4ターン目と、以後4ターンごとに、通常の選び方の代わりに力を溜めるを使う。次の行動は斬りつけにする。
- HPが0になったとき、組み直しを使っていなければ骨の山になり、次の自分の行動で組み直しを使う。骨の山のあいだに打の攻撃を受けると、組み直さずに倒れる。
- 激化：組み直したあと、または5ターン目以降の早いほうから、斬りつけと打ち砕きの威力が1.3倍（1560・936）になる。予告の数字もこれに合わせて変える。

### 激化の見せ方

激化の始まりに、目のくぼみの橙の光が強まり、顎を2回鳴らす演出を短く出す。
組み直しで激化したときは、組み直しの演出の最後にこれを続ける。
激化のあいだは、骨の継ぎ目にかすかな橙の光の筋を残す。
光は予告と弱点のアイコンを隠さない明るさに抑える。
