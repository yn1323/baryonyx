### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：斉射でも矢は同時に刺さらない。本体が見える太さを保ち、尾を主張させず、発射・飛翔・命中を分ける（弓矢のレシピ）。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.30 | 予兆 | 5本の矢が空へ上がる | 手前 |
| 0.30〜0.57 | 発動 | 1回目の斉射。矢ごとに0.16〜0.27秒で刺さり、刺さった点が光る | 手前・床 |
| 0.54 | 発動 | ダメージ。土ぼこりが左右へ這う。揺れ | 床の奥と手前 |
| 0.66〜0.93 | 発動 | 2回目の斉射 | 手前・床 |
| 0.93〜1.30 | 余韻 | 土ぼこりが沈む | 床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 土ぼこり | 床を這う低い煙 | 通常合成 | 約0.6秒 |
| 矢 | 白い芯を持つ矢 | 加算 | 0.16〜0.27秒 |
| 尾 | 矢の後ろに残る小さな粒 | 加算。薄い | 0.12〜0.25秒 |
| 命中の光 | 刺さった点の小さな光と床のちらつき | 加算 | 0.1〜0.24秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：アローレイン・毒 | 枝2：アローレイン・豪 |
|---|---|---|
| ID | `ArrowRain.1` | `ArrowRain.2` |
| 枝の方向 | 自ら毒を撒いて次の雨を強くする | 矢の数を増やす |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | 貫 | 貫 |
| コスト | 2（元と同じ） | 3（元は2） |
| 説明文 | 敵全体に物攻の45%ダメージ×2。毒がある敵には1.5倍。60%で毒を1つ重ねる。 | 敵全体に物攻の45%ダメージ×3。毒がある敵には1.5倍。連携（毒針）：先に敵全体へ毒を2つ重ねる。 |
| 効果（行う順） | 敵全体に物攻の45%ダメージ×2<br>毒がある敵には1.5倍<br>60%で毒を1つ重ねる | 敵全体に物攻の45%ダメージ×3<br>毒がある敵には1.5倍<br>連携（毒針）：先に敵全体へ毒を2つ重ねる |
| 挿絵のモチーフ | 紫の煙を引いて降る矢 | 空を埋める矢の雨 |
| 演出 | 元の演出に、毒の緑の光の溜めと当たりを重ねる。相手から毒の霧の粒が立ちのぼる | 元の演出に、鋼の青の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
| 挿絵 | `CardArrowRain1.aseprite` | `CardArrowRain2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
