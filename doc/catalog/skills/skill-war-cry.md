### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 大きな声の圧で、床の塵が外へ押し出される。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.30 | 予備動作 | 0.1秒おきに3回、塵が使い手の足元から外へ広く走り、小さく揺れる | 床 |
| 0.30〜 | 発生 | 味方ごとに橙の光の柱、上向きの矢印、火花 | 奥・手前 |
| 〜+0.45 | 余韻 | 柱と矢印が削れる | 奥・手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 塵 | 床を外へ走る低い塵 | 通常の合成 | 0.45〜0.75秒 |
| 光の柱 | 味方の奥に昇る柱 | 加算 | 0.8秒 |
| 上向きの矢印 | 金の矢印 | 加算 | 0.8秒 |
| 火花 | 上へ散る火花 | 加算 | 0.1〜0.4秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：鬨の声・猛 | 枝2：鬨の声・陣 |
|---|---|---|
| ID | `WarCry.1` | `WarCry.2` |
| 枝の方向 | 士気でエネルギーを生む | 攻めながら陣を固める |
| 種類・対象 | 強化・味方全体 | 強化・味方全体 |
| 属性 | なし | なし |
| コスト | 1（元と同じ） | 1（元と同じ） |
| 説明文 | 味方全体の攻撃力を2ターン25%上げる。エネルギー+1。初手。消滅。 | 味方全体の攻撃力を2ターン20%上げる。味方全体にブロック物防の20%。初手。 |
| 効果（行う順） | 味方全体の攻撃力を2ターン25%上げる<br>エネルギー+1<br>初手<br>消滅 | 味方全体の攻撃力を2ターン20%上げる<br>味方全体にブロック物防の20%<br>初手 |
| 挿絵のモチーフ | 掲げた軍旗と赤い気炎 | 並んだ盾と旗 |
| 演出 | 元の演出に、深紅の光の溜めと当たりを重ねる。相手から火の粉が舞い上がる | 元の演出に、金の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる |
| 挿絵 | `CardWarCry1.aseprite` | `CardWarCry2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
