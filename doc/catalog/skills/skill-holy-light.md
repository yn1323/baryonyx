### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で見直し、光源から敵への光の柱を、1枚の柱から4層（敵の奥ににじみと塵で見える本体、敵の手前に届いた瞬間だけの白い芯と金の残像）に分けた。
それ以外の流れ（光源、床の光だまり、照らし、味方への光）は変えていない。

| 光の層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| にじみ（敵の奥） | 光線の約2倍の幅の柔らかい金の光 | 加算。薄い | 最も長く、本体の約1.4倍 |
| 本体（敵の奥） | 塵で見える光の柱。中ほどが明るく、塵の粒がきらめく | 加算 | 届いたときに最も明るく、削れて消える |
| 芯（敵の手前） | 幅3分の1の白く熱い線 | 加算。最も明るい | 届いた瞬間だけ（約0.05秒で減衰） |
| 残像（敵の手前） | 細い金の筋 | 加算 | 芯が消えたあとに残り、途切れながら最後に消える |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ホーリーライト・浄 | 枝2：ホーリーライト・陽 |
|---|---|---|
| ID | `HolyLight.1` | `HolyLight.2` |
| 枝の方向 | 光で仲間も清める | 光の温もりを残す |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | なし | なし |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 敵全体に属攻の70%ダメージ。味方全体のHPを属攻の30%回復し、状態異常を消す。 | 敵全体に属攻の70%ダメージ。味方全体を、2ターンの間、毎ターン属攻の20%回復する。 |
| 効果（行う順） | 敵全体に属攻の70%ダメージ<br>味方全体のHPを属攻の30%回復し、状態異常を消す | 敵全体に属攻の70%ダメージ<br>味方全体を、2ターンの間、毎ターン属攻の20%回復する |
| 挿絵のモチーフ | 降り注ぐ白い光の雨 | 地平から昇る太陽 |
| 演出 | 元の演出に、朝の白金の光の溜めと当たりを重ねる。相手の足元から光の粒が立ちのぼり、柔らかい光で照らす | 元の演出に、温かい金の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く |
| 挿絵 | `CardHolyLight1.aseprite` | `CardHolyLight2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
