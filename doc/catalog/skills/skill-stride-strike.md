### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 踏み込むたびに、足元の塵が後ろへ跳ねる。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.36 | 予備動作 | 足跡が0.06秒おきに6歩灯り、塵が後ろへ跳ねる | 床 |
| 0.36〜0.48 | 発生 | 金の筋が敵へ走る | 手前 |
| 0.48 | 発生 | 金の光の弾け、横向きの輪、ヒットストップ | 手前 |
| 0.53〜1.4 | 余韻 | 足跡から光の粒が昇り、足跡が消える | 床・手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 足跡 | 床に寝た光と小さな輪 | 加算 | 1.1秒 |
| 塵 | 足跡ごとの低い土ぼこり | 通常の合成 | 0.5〜0.7秒 |
| 金の筋 | 走る光の筋 | 加算 | 0.12秒 |
| 光の粒 | 昇るきらめき | 加算 | 0.5〜0.9秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：健脚の一撃・駆 | 枝2：健脚の一撃・踏 |
|---|---|---|
| ID | `StrideStrike.1` | `StrideStrike.2` |
| 枝の方向 | 駆け抜けて次の手へつなぐ | 踏み鳴らして全体を揺らす |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵全体 |
| 属性 | 打 | 打 |
| コスト | 1（元と同じ） | 2（元は1） |
| 説明文 | 敵1体に物攻の130%ダメージ。歩み。カードを1枚引く。 | 敵全体に物攻の100%ダメージ。歩み。 |
| 効果（行う順） | 敵1体に物攻の130%ダメージ<br>歩み<br>カードを1枚引く | 敵全体に物攻の100%ダメージ<br>歩み |
| 挿絵のモチーフ | 土煙を上げて駆ける足跡 | 地面を踏み鳴らす大きな足と波紋 |
| 演出 | 元の演出に、金の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる | 元の演出に、土の橙の光の溜めと当たりを重ねる。足元に大きな土煙の輪が広がり、画面が揺れる |
| 挿絵 | `CardStrideStrike1.aseprite` | `CardStrideStrike2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
