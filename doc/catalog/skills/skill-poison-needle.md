### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：毒のガスは空気より重く、立ち昇らずに沈んで低く這う。暗く濃い部分と透ける部分を混ぜ、泡を足す（毒・酸のレシピ）。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.30 | 予兆 | 針が0.06秒おきに3本飛ぶ。尾に小さな緑の粒 | 手前 |
| 0.30 | 発動 | 当たりの白熱した光。ダメージ | 手前 |
| 0.30〜1.00 | 余韻 | ガスが敵から転がり落ちて沈み、床を左右へ這う。泡が昇ってはじける。緑の光が揺らぐ | 床の奥と手前 |
| 1.00〜1.50 | 余韻 | ガスが縁から削れて消える | 床の奥と手前 |

| ガスの層 | 役割と形 | 透け方 | 動き |
|---|---|---|---|
| 暗い本体（敵の奥） | 床に寝た広く平たいガス | 濃く覆い、縁と薄いところは奥が透ける | 左右へゆっくり這い、縁から削れる |
| 盛り上がり（敵の手前） | 敵から転がり落ちる塊 | 中くらいに覆う | 空気より重く、膨らみながら沈む |
| 切れ端（敵の手前） | 床を速く走る細い切れ端 | 薄く、ほとんどが穴 | 速い |
| 中の光（敵の奥） | ガスの中にぼんやり灯る緑の斑 | 加算 | ところどころで灯って消える |

毒が後から働くとき（`StatusTick`）は、使ったときのガスを出し直さず、体から泡が湧き、重いしずくが垂れ、中の緑の光が揺らぐだけにする。

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：毒針・蝕 | 枝2：毒針・散 |
|---|---|---|
| ID | `PoisonNeedle.1` | `PoisonNeedle.2` |
| 枝の方向 | 毒を深く重ねる | 毒を全体へ撒く |
| 種類・対象 | 弱体・敵単体 | 弱体・敵ランダム |
| 属性 | 貫 | 貫 |
| コスト | 1（元と同じ） | 1（元と同じ） |
| 説明文 | 敵1体に物攻の50%ダメージ。毒がある敵には1.5倍。毒を4つ重ねる。捨てたとき：ランダムな敵に毒を2つ重ねる。 | ランダムな敵に物攻の30%ダメージ×3。敵全体に毒を1つ重ねる。捨てたとき：敵全体に毒を1つ重ねる。 |
| 効果（行う順） | 敵1体に物攻の50%ダメージ<br>毒がある敵には1.5倍<br>毒を4つ重ねる<br>捨てたとき：ランダムな敵に毒を2つ重ねる | ランダムな敵に物攻の30%ダメージ×3<br>敵全体に毒を1つ重ねる<br>捨てたとき：敵全体に毒を1つ重ねる |
| 挿絵のモチーフ | 紫の雫が滴る長い針 | 扇状に飛ぶ3本の毒針 |
| 演出 | 元の演出に、毒の緑の光の溜めと当たりを重ねる。相手から毒の霧の粒が立ちのぼる | 元の演出に、紫の光の溜めと当たりを重ねる。細い風の筋が相手を横切り、足元の塵が風下へ払われる（毒を風で全体へ撒く） |
| 挿絵 | `CardPoisonNeedle1.aseprite` | `CardPoisonNeedle2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
