### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 炎は上ほど速く昇り、先端が裂けて消える。熱い所ほど白く、冷えるにつれ黄・橙・赤・暗い色になる。
- 炎の上には煤の煙が立ち、炎が消えたあとも昇り続ける。火の粉は空気に止められてから漂い昇る。
- 炎は周りを揺らぐ光で照らし、床には焦げ跡が残る。
- 火災旋風は回転する炎の柱で、周りの空気と火の粉を巻き込み、上に煤の柱を立てる。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 炎の溜め | 床・奥と手前 |
| 0.40〜0.55 | 発生 | 火の渦が2本立ち上がる（2本目は0.08秒遅れ、細く低い）。床が熱を帯び、閃光 | 奥・床 |
| 0.52〜 | 発生 | 0.12秒おきに各敵が巻き込まれ、手前に炎がまとわりつく | 手前 |
| 0.40〜1.50 | 発生 | 渦がすれ違いながら走り、身をよじって太さが揺れる。0.08秒ごとに上から煤と火の粉 | 奥・手前 |
| 1.00〜3.0 | 余韻 | 渦が細くなって削れる。煤が昇って残り、焦げ跡が削れる | 奥・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 煤 | 渦の上からちぎれて昇る暗い煙 | 通常の合成で7割程度 | 1〜1.6秒ずつ、走るあいだ次々に |
| 炎の柱 | 密度で描く炎 | 乗算済みアルファ | 1.1秒。後半に細くなって削れる |
| 熱い空気の渦 | 横から見た渦の薄い筋 | 加算。4割 | 0.45〜1.1秒 |
| 火の粉 | 渦から回りながら吹き上がる粒 | 加算 | 0.5〜1.2秒ずつ |
| 床 | 揺らぐ光だまりと広い焦げ跡 | 加算・通常の合成 | 光だまり1.5秒、焦げ跡2.2秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ファイアストーム・烈 | 枝2：ファイアストーム・渦 |
|---|---|---|
| ID | `FireStorm.1` | `FireStorm.2` |
| 枝の方向 | やけどの敵を強く焼く | 炎を2度巻きつける |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | 炎 | 炎 |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 敵全体に属攻の90%ダメージ。やけど中の敵には1.5倍。60%でやけど2ターン。 | 敵全体に属攻の55%ダメージ×2。60%でやけど2ターン。 |
| 効果（行う順） | 敵全体に属攻の90%ダメージ<br>やけど中の敵には1.5倍<br>60%でやけど2ターン | 敵全体に属攻の55%ダメージ×2<br>60%でやけど2ターン |
| 挿絵のモチーフ | 赤黒い炎の竜巻 | 2重に巻く炎の渦 |
| 演出 | 元の演出に、深紅の光の溜めと当たりを重ねる。相手から火の粉が舞い上がる | 元の演出に、炎の橙の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
| 挿絵 | `CardFireStorm1.aseprite` | `CardFireStorm2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
