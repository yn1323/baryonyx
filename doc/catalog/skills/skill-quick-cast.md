### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：回転と拍が速まって一点へ詰まり、最後に一度だけ放たれる（強化・チャージのレシピ）。魔法陣は床に寝かせ、照らすのは足元から。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.46 | 予兆 | 床の魔法陣が回転を速める（角度は時間の2乗）。輪が0.00・0.15・0.26秒に縮み始め、寿命は0.42・0.30・0.20秒。光の粒が胸へ集まる。足元から照らす | 床（奥）・手前 |
| 0.46 | 発動 | 胸に白い光が0.12秒。足元に光だまりが一瞬広がり、きらめき | 手前・床 |
| 0.46〜1.16 | 余韻 | 下向きの矢印が沈んで削れる。魔法陣が縁から削れる | 手前・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 魔法陣（床） | 回転が速まる陣。床に寝かせる | 加算 | 0.95秒。0.57秒から削れる |
| 縮む輪 | 外から胸へ縮む輪。1つごとに早く短く | 加算 | 0.20〜0.42秒 |
| 光の粒 | 胸へ集まる粒 | 加算 | 約0.42秒 |
| 芯と矢印 | 白い光（芯）と、沈む矢印 | 加算。芯だけ白く明るい | 芯0.12秒、矢印0.7秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：詠唱短縮・速 | 枝2：詠唱短縮・瞬 |
|---|---|---|
| ID | `QuickCast.1` | `QuickCast.2` |
| 枝の方向 | 詠唱を縮めて次の呪文を呼ぶ | 縮めた詠唱を取っておく |
| 種類・対象 | 支援・次のカード | 支援・次のカード |
| 属性 | なし | なし |
| コスト | 0（元と同じ） | 0（元と同じ） |
| 説明文 | 次に使う炎・氷・雷カードのコストを0にする。カードを1枚引く。霧散。 | 次に使う炎・氷・雷カードのコストを0にする。保持。 |
| 効果（行う順） | 次に使う炎・氷・雷カードのコストを0にする<br>カードを1枚引く<br>霧散 | 次に使う炎・氷・雷カードのコストを0にする<br>保持 |
| 挿絵のモチーフ | 速くめくれる魔導書のページ | 砂時計を貫く光 |
| 演出 | 元の演出に、魔力の紫の光の溜めと当たりを重ねる。使い手の頭上で星が瞬き、光の粒が使い手へ集まる | 元の演出に、金の光の溜めと当たりを重ねる。胸の前に光の盾が立ち、足元の輪の中を細い光の線が昇る |
| 挿絵 | `CardQuickCast1.aseprite` | `CardQuickCast2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
