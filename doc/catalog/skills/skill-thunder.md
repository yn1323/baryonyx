### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
稲妻は[雷雲](skill-thundercloud.md#演出の時間設計)と同じ4層の稲妻を、雲なしで画面の上から落とす。それまでは光るたびに違う形の稲妻を出していた。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 落雷は、枝分かれしながら段を刻んで降りる先駆放電が地面につながった瞬間に、その通り道が強く光り（主放電）、間を置いて同じ通り道が光り直す（[米国気象局](https://www.weather.gov/mlb/what_is_lightning)）。ゲームでは光り直しを約0.1秒おきに延ばす。
- 落ちた点では土が飛び、焦げ跡が残る。雷鳴は鋭い音のあと転がるように続く。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 空が暗くなり、使い手が帯電する | 背景の幕・手前 |
| 0.40〜0.52 | 予備動作 | 1体目の上から、薄紫の先駆放電が段を刻んで降りる | 手前 |
| 0.52 | 発生 | 主放電。白い芯、画面の閃光（この1回だけ）。場のキャラ全員と床の広い光だまり。火花、土ぼこり、焦げ跡、ヒットストップ、下向きの揺れ | 手前・床・画面全体 |
| 0.62・0.72 | 発生 | 同じ通り道が光り直し、弱くなる。そのたびにキャラと床が照らされる | 手前・床 |
| 0.69〜 | 発生 | 次の敵へ、0.29秒おきに同じ順で落ちる | 手前 |
| 〜+1.0 | 余韻 | 紫の残像が途切れて消え、焦げ跡から細い煙が昇り、雷鳴が転がる | 手前・床の奥 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| にじみ | 通り道と枝の周りの光った空気 | 加算 | 先駆放電から約0.57秒 |
| 残像 | 目に残る細い紫の筋 | 加算 | 主放電から約0.75秒。途切れながら消える |
| 通り道と枝 | 先駆放電と、主放電の通り道と枝分かれ | 加算 | 約0.52秒 |
| 芯 | 白く熱い細い線。主の通り道だけ | 加算。最も明るい | 放電の瞬間だけ |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：サンダー・痺 | 枝2：サンダー・落雷 |
|---|---|---|
| ID | `Thunder.1` | `Thunder.2` |
| 枝の方向 | 弱点の敵を痺れさせる | 雷を1体に束ねて落とす |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵単体 |
| 属性 | 雷 | 雷 |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 敵全体に属攻の90%ダメージ。麻痺中の敵には1.5倍。弱点を突いた敵を60%で麻痺1ターン。 | 敵1体に属攻の220%ダメージ。麻痺中の敵には1.5倍。 |
| 効果（行う順） | 敵全体に属攻の90%ダメージ<br>麻痺中の敵には1.5倍<br>弱点を突いた敵を60%で麻痺1ターン | 敵1体に属攻の220%ダメージ<br>麻痺中の敵には1.5倍 |
| 挿絵のモチーフ | 細かく枝分かれして降る稲妻 | 1本に束ねた太い雷の柱 |
| 演出 | 元の演出に、雷の黄の光の溜めと当たりを重ねる。当たった所で小さな稲妻の火花が弾ける | 元の演出に、雷の色の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く |
| 挿絵 | `CardThunder1.aseprite` | `CardThunder2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
