### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：浄化は上からの光と、追い出されて消える穢れで見せる。穢れは昇りながら削れて消え、居座らない。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.35 | 予兆 | 広い光が上から降り、きらめきが落ち始める | 奥と手前 |
| 0.35〜0.50 | 発動 | 味方ごとに暗い靄が昇り、床に澄んだ輪 | 味方の奥・床 |
| 0.50〜1.60 | 余韻 | 靄が削れて消え、光が消える | 奥と手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 降りる光（パーティの奥） | 幅の広い柔らかな水色の光。白い芯は持たせない | 加算。薄い | 約1.6秒 |
| 穢れ（味方の奥） | 暗い紫の靄。昇りながら削れる | 通常合成。約5割 | 0.6〜0.9秒 |
| きらめき | 光の中を落ちる粒 | 加算 | 0.9〜1.3秒 |
| 残り（パーティの手前と床） | 細い水色の残像、床の澄んだ輪、体の淡い光 | 加算 | 0.6〜1.8秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：浄化の光・聖 | 枝2：浄化の光・巡 |
|---|---|---|
| ID | `Purify.1` | `Purify.2` |
| 枝の方向 | 清めたあとを守る | 清めて次の手を巡らせる |
| 種類・対象 | 回復・味方全体 | 回復・味方全体 |
| 属性 | なし | なし |
| コスト | 0（元と同じ） | 0（元と同じ） |
| 説明文 | 味方全体の状態異常を消し、HPを属攻の25%回復。受けるダメージを1ターン15%減らす。霧散。 | 味方全体の状態異常を消し、HPを属攻の25%回復。カードを1枚引く。霧散。 |
| 効果（行う順） | 味方全体の状態異常を消し、HPを属攻の25%回復<br>受けるダメージを1ターン15%減らす<br>霧散 | 味方全体の状態異常を消し、HPを属攻の25%回復<br>カードを1枚引く<br>霧散 |
| 挿絵のモチーフ | 白い光の柱と舞う羽 | 円を描いて巡る光の帯 |
| 演出 | 元の演出に、朝の白金の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる | 元の演出に、若葉の緑の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
| 挿絵 | `CardPurify1.aseprite` | `CardPurify2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
