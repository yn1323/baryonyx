### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 誓いは現実の現象ではないため、使い手から敵へ届く「挑発の波」として、向きと届く順番を見せる。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 立ち上るオーラ | 奥・手前 |
| 0.40 | 発生 | 使い手の奥に赤金の紋が立ち、足元の輪と光だまり | 奥・床 |
| 0.60〜1.20 | 発生 | 赤い波が敵へ転がり、敵を赤く照らす | 手前 |
| 1.20〜1.70 | 余韻 | 紋と波が削れて消える | 奥・手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 紋 | 赤金の盾の紋 | 加算 | 0.9秒 |
| 輪と光だまり | 床に寝た輪と光 | 加算 | 0.5〜0.8秒 |
| 赤い波 | 縦長の輪 | 加算 | 0.6秒 |
| 赤い光 | 敵への色乗せ | 加算 | 0.6秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：守護の誓い・不動 | 枝2：守護の誓い・報復 |
|---|---|---|
| ID | `GuardianOath.1` | `GuardianOath.2` |
| 枝の方向 | 引きつけた攻撃に耐え抜く | 引きつけた攻撃を返す |
| 種類・対象 | 防御・自分 | 防御・自分 |
| 属性 | なし | なし |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 自分にブロック物防の90%。2ターン、敵の攻撃を引きつけ、受けるダメージを25%減らす。保持。 | 自分にブロック物防の70%。2ターン、敵の攻撃を引きつける。次に受ける単体攻撃を1回はね返す。保持。 |
| 効果（行う順） | 自分にブロック物防の90%<br>2ターン、敵の攻撃を引きつけ、受けるダメージを25%減らす<br>保持 | 自分にブロック物防の70%<br>2ターン、敵の攻撃を引きつける<br>次に受ける単体攻撃を1回はね返す<br>保持 |
| 挿絵のモチーフ | 地に突き立てた大盾と鎖 | 棘の生えた盾 |
| 演出 | 元の演出に、鋼の青の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる | 元の演出に、星の淡い青の光の溜めと当たりを重ねる。使い手の頭上で星が瞬き、光の粒が使い手へ集まる |
| 挿絵 | `CardGuardianOath1.aseprite` | `CardGuardianOath2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
