### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 上から強い光が近づくと、床の光だまりが育つ。
- 重い物が叩きつけられると、床は細い割れ目で割れ、岩は大きいほど遅く、土煙は後に残る。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.50 | 予備動作 | 頭上に金の光が集まる。床の光だまりが育つ | 手前・床 |
| 0.50〜0.58 | 発生 | 光の柱が上から叩きつけられる。芯は0.25秒だけ | 奥・手前 |
| 0.58 | 発生 | 床が割れ、閃光、ヒットストップ0.16秒、スロー、寄り、岩、土ぼこり | 画面全体・床 |
| 0.58〜2.2 | 余韻 | 柱が細くなって削れ、土煙が昇り、割れ目が閉じる | 奥・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 床の光だまり | 縦を潰した柔らかい光 | 加算 | 0〜0.62秒で育つ |
| 光の柱 | 塵で見える光の柱（奥）と、細い白い芯（手前） | 加算 | 柱0.75秒、芯0.25秒 |
| 割れ目 | 床を破片に割る細い溝 | 通常の合成。影で見える | 1.6秒 |
| 岩と土煙 | 大小の岩と、奥の土煙 | 通常の合成 | 岩0.4〜1.05秒、土煙0.8〜1.4秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ギガントインパクト・要塞 | 枝2：ギガントインパクト・衝 |
|---|---|---|
| ID | `GiantImpact.1` | `GiantImpact.2` |
| 枝の方向 | 自分で構えを作ってから打つ | 衝撃を周りにも広げる |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵単体 |
| 属性 | 打 | 打 |
| コスト | 3（元と同じ） | 3（元と同じ） |
| 説明文 | 自分にブロック物防の60%。敵1体に物攻の360%ダメージ。自分にブロックがあれば1.5倍。眠り札。 | 敵1体に物攻の300%、さらに敵全体に物攻の60%ダメージ。自分にブロックがあれば1.5倍。眠り札。 |
| 効果（行う順） | 自分にブロック物防の60%<br>敵1体に物攻の360%ダメージ<br>自分にブロックがあれば1.5倍<br>眠り札 | 敵1体に物攻の300%、さらに敵全体に物攻の60%ダメージ<br>自分にブロックがあれば1.5倍<br>眠り札 |
| 挿絵のモチーフ | 大盾ごと叩きつける巨大な拳 | 着弾点から全方位へ走る衝撃の輪 |
| 演出 | 元の演出に、守りの青の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる | 元の演出に、金の光の溜めと当たりを重ねる。足元に大きな土煙の輪が広がり、画面が揺れる |
| 挿絵 | `CardGiantImpact1.aseprite` | `CardGiantImpact2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
