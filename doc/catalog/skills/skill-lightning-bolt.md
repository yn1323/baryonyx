### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：稲妻は先駆放電がつながった通り道が光り、同じ通り道が間を置いて光り直す（[米国気象局](https://www.weather.gov/mlb/what_is_lightning)）。光り直すたびに違う形の線を出さない。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.14 | 予兆 | 手元に光がたまる | 手前 |
| 0.14〜0.22 | 予兆 | 先駆放電が段を刻んで敵へ伸びる（薄い） | 手前 |
| 0.22 | 発動 | 主放電。芯が白く光る。通り道に沿って場が照らされ、床に光だまり。ダメージ | 手前・床 |
| 0.32・0.42 | 発動 | 同じ通り道が弱まりながら光り直す | 手前・床 |
| 0.42〜1.10 | 余韻 | 残像が途切れて消え、敵の周りを放電が走る | 手前 |

| 稲妻の層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| にじみ | 通り道と枝の周りの光った空気。白みがかった黄 | 加算。先駆放電のあいだは薄く、放電ごとに明るくなる | 最も長く、放電の前後を包む |
| 残像 | 目に残る細い筋。濃い黄 | 加算。最後の放電のあと約0.3秒で薄れる | 途切れながら最後に消える |
| 通り道と枝 | 白に近い通り道と枝分かれ。先駆放電もこの層 | 加算 | 放電の少し前から少し後 |
| 芯 | 白く熱い細い線。主の通り道だけ | 加算。最も明るく、Bloomでにじむ | 放電の瞬間だけ。光り直しも同じ通り道 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ライトニングボルト・痺 | 枝2：ライトニングボルト・迅 |
|---|---|---|
| ID | `LightningBolt.1` | `LightningBolt.2` |
| 枝の方向 | 痺れた敵を強く打つ | 一瞬で撃って次の手へ |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵単体 |
| 属性 | 雷 | 雷 |
| コスト | 1（元と同じ） | 1（元と同じ） |
| 説明文 | 敵1体に属攻の100%ダメージ。麻痺中の敵には1.5倍。60%で麻痺1ターン。合体（アイスランス）。 | 敵1体に属攻の90%ダメージ。60%で麻痺1ターン。カードを1枚引く。合体（アイスランス）。 |
| 効果（行う順） | 敵1体に属攻の100%ダメージ<br>麻痺中の敵には1.5倍<br>60%で麻痺1ターン<br>合体（アイスランス） | 敵1体に属攻の90%ダメージ<br>60%で麻痺1ターン<br>カードを1枚引く<br>合体（アイスランス） |

| 演出 | 元の演出に、雷の黄の光の溜めと当たりを重ねる。当たった所で小さな稲妻の火花が弾ける | 元の演出に、雷の色の光の溜めと当たりを重ねる。使い手の頭上で星が瞬き、光の粒が使い手へ集まる |
| 挿絵 | `CardLightningBolt1.aseprite` | `CardLightningBolt2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
