### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 石や乾いた土は、力の掛かった点から細い割れ目が一瞬で一段ずつ伸びて割れる。割れ目は影で見え、光らない。
- 割れて飛ぶ岩は、大きいものほど遅く重く、小さい破片は速く遠くへ飛ぶ。土煙は岩が落ちたあとも残る。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 使い手の足元の床が細い割れ目で割れる（地鳴り） | 床 |
| 0.40 | 発生 | 床を打つ衝撃。土ぼこりが外へ走り、ヒットストップ | 床 |
| 0.40〜0.60 | 発生 | 割れ目が0.05秒おきに4段で敵へ走る。段ごとに小石が跳ね、小さく揺れる | 床 |
| 0.60〜 | 発生 | 各敵の足元が割れ、大小の岩と破片、土ぼこりの衝撃。揺れ | 奥・手前・床 |
| 0.70〜2.0 | 余韻 | 土煙が昇って残り、割れ目が外側から閉じる | 奥・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 割れ目 | 床を破片に割る細い溝（画面で1〜2.5画素）。奥の壁が少し明るい | 通常の合成。影で見える | 1.3〜1.5秒。外側から閉じる |
| 大きな岩 | 暗い茶の大きな破片 | 通常の合成 | 0.7〜1.05秒。ゆっくり回る |
| 小さな破片 | 速く高く飛ぶ小片 | 通常の合成 | 0.4〜0.8秒。速く回る |
| 土煙 | 奥に噴き上がる陰影のある煙 | 通常の合成で7割程度 | 0.9〜1.4秒。岩より長い |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：大地割り・崩 | 枝2：大地割り・岩陣 |
|---|---|---|
| ID | `EarthSplitter.1` | `EarthSplitter.2` |
| 枝の方向 | 崩してから割る1枚で完結させる | 割れ目から岩の壁を起こす |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | 打 | 打 |
| コスト | 3（元は2） | 2（元と同じ） |
| 説明文 | 敵全体に防御ダウン2ターン。敵全体に物攻の110%ダメージ。防御ダウン中の敵には1.5倍。 | 敵全体に物攻の100%ダメージ。防御ダウン中の敵には1.5倍。味方全体にブロック物防の20%。 |
| 効果（行う順） | 敵全体に防御ダウン2ターン<br>敵全体に物攻の110%ダメージ<br>防御ダウン中の敵には1.5倍 | 敵全体に物攻の100%ダメージ<br>防御ダウン中の敵には1.5倍<br>味方全体にブロック物防の20% |
| 挿絵のモチーフ | 深く割れた地面と崩れる岩 | 割れ目からせり上がる岩の壁 |
| 演出 | 元の演出に、土の橙の光の溜めと当たりを重ねる。足元に大きな土煙の輪が広がり、画面が揺れる | 元の演出に、金の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる |
| 挿絵 | `CardEarthSplitter1.aseprite` | `CardEarthSplitter2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
