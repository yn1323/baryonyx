### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：見抜く光は、体の表面をなぞる細い走査線として描く。帯1枚にせず、白い芯と色のにじみを分ける。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.18 | 予兆 | 矢が飛ぶ | 手前 |
| 0.18 | 発動 | 当たりの光。ダメージ。目の魔法陣が開く | 手前 |
| 0.18〜0.63 | 発動 | 走査線が上から下へなぞる。芯が先に消え、にじみが残る | 敵の奥と手前 |
| 0.63〜1.08 | 余韻 | 魔法陣が回りながら削れる | 手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 走査のにじみ（敵の奥） | 幅の広い青緑の帯 | 加算。薄い | 0.7秒 |
| 走査の芯（敵の手前） | 細い白い線 | 加算。明るい | 0.5秒 |
| 魔法の目 | 頭上の魔法陣 | 加算 | 0.9秒 |
| 照らし | 敵に落ちる青緑の光 | 色乗せ | 0.7秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：看破の矢・射抜 | 枝2：看破の矢・千里眼 |
|---|---|---|
| ID | `InsightArrow.1` | `InsightArrow.2` |
| 枝の方向 | 見抜いた隙を広げる | 全員の弱点を一度に見抜く |
| 種類・対象 | 弱体・敵単体 | 弱体・敵全体 |
| 属性 | 貫 | 貫 |
| コスト | 1（元と同じ） | 2（元は1） |
| 説明文 | 敵1体に物攻の90%ダメージ。その敵の弱点をすべて見抜き、60%で防御ダウン2ターン。初手。 | 敵全体に物攻の50%ダメージ。敵全体の弱点をすべて見抜く。初手。 |
| 効果（行う順） | 敵1体に物攻の90%ダメージ<br>その敵の弱点をすべて見抜き、60%で防御ダウン2ターン<br>初手 | 敵全体に物攻の50%ダメージ<br>敵全体の弱点をすべて見抜く<br>初手 |
| 挿絵のモチーフ | 的の中心に刺さる光る矢と眼の紋 | 空に開く大きな眼と降る矢 |
| 演出 | 元の演出に、青緑の光の溜めと当たりを重ねる。使い手の頭上で星が瞬き、光の粒が使い手へ集まる | 元の演出に、星の淡い青の光の溜めと当たりを重ねる。当たった相手の上で光の点が順に瞬き、細い光の線でつながる |
| 挿絵 | `CardInsightArrow1.aseprite` | `CardInsightArrow2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
