### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
アイスランスは2026-10-22に作り込んだ版を残し、砕けたあとに沈んで這う冷気だけを足した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 氷は透けて硬く、縁と面で光を返す。凍る床は板が外へパキパキと広がる。
- 割れると角ばった破片になって落ち、光る。氷で冷やされた空気は重く、沈んで床を這う。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 背景が深い夜に沈み、氷の前触れ（床を這う冷気） | 床 |
| 0.40〜0.56 | 発生 | 透ける氷の槍が真っすぐ速く飛ぶ | 手前 |
| 0.56 | 発生 | 冷たい閃光。床が氷の板になって広がり、氷柱が奥の列から手前の列へ生える。細かい氷の粒、床の光だまり | 奥・手前・床 |
| 0.96〜1.16 | 発生 | 氷柱にひびが走って震える | 奥・手前 |
| 1.06〜2.4 | 余韻 | 冷やされた空気が沈んで床を左右へ這う | 奥・手前の床 |
| 1.16 | 発生 | 一斉に砕ける。きらめき、光の破片、透けた氷のかけら、ダイヤモンドダスト | 手前 |
| 1.16〜2.9 | 余韻 | かけらと粒が落ち、床の氷が板ごとに削れる | 手前・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 冷気 | 床すれすれの低い霧。沈んで左右へ広がる | 通常の合成で3割程度 | 1.06〜2.4秒 |
| 床の氷 | 透ける氷の板とひび | 乗算済みアルファ | 0.56〜2.2秒 |
| 槍と氷柱 | 透ける硬い氷。縁と稜線が明るい | 乗算済みアルファ | 槍0.16秒、氷柱0.56〜1.22秒 |
| 光 | 冷たい閃光、きらめき、床の光だまり、キャラへの青い光 | 加算 | 0.16〜1.6秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：アイスランス・穿 | 枝2：アイスランス・霜 |
|---|---|---|
| ID | `Ice.1` | `Ice.2` |
| 枝の方向 | 凍えた敵を深く貫く | 刺さった所から霜を広げる |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵単体 |
| 属性 | 氷 | 氷 |
| コスト | 1（元と同じ） | 2（元は1） |
| 説明文 | 敵1体に属攻の110%ダメージ。凍え中の敵には1.5倍。60%で凍え2ターン。合体（ライトニングボルト）。 | 敵1体に属攻の120%ダメージ。敵全体に60%で凍え2ターン。合体（ライトニングボルト）。 |
| 効果（行う順） | 敵1体に属攻の110%ダメージ<br>凍え中の敵には1.5倍<br>60%で凍え2ターン<br>合体（ライトニングボルト） | 敵1体に属攻の120%ダメージ<br>敵全体に60%で凍え2ターン<br>合体（ライトニングボルト） |
| 挿絵のモチーフ | 先の鋭い長い氷の槍 | 槍が刺さった所から広がる霜の輪 |
| 演出 | 元の演出に、氷の水色の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く | 元の演出に、星の淡い青の光の溜めと当たりを重ねる。相手の足元に霜の輪が広がり、氷のかけらが舞う |
| 挿絵 | `CardIce1.aseprite` | `CardIce2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
