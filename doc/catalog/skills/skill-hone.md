### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 砥石に当てた刃からは、橙の火花が下へ散る。研いだ刃は縁に光が走る。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.30 | 予備動作 | 刃の根元から橙の火花が下へ散り続ける | 手前 |
| 0.20〜0.60 | 発生 | 刃の縁を光の線が根元から先へ走る | 手前 |
| 0.32 | 発生 | 先端のきらめき。使い手が照らされる。下向きの矢印が沈む | 手前 |
| 0.32〜0.70 | 余韻 | 矢印が削れ、火花が落ちきる | 手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 火花 | 重さで落ちる橙の細い筋 | 加算 | 0.15〜0.35秒ずつ、0.3秒にわたる |
| 刃の縁の線 | 塵で見える光の線 | 加算 | 0.4秒 |
| きらめき | 4本の光 | 加算。最も明るい | 0.45秒 |
| 下向きの矢印 | コストが下がる印 | 加算 | 0.7秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：研ぎ澄ます・冴 | 枝2：研ぎ澄ます・刃 |
|---|---|---|
| ID | `Hone.1` | `Hone.2` |
| 枝の方向 | 研いだ刃で次の手を引き寄せる | 斬だけでなく打と貫も研ぐ |
| 種類・対象 | 支援・次のカード | 支援・次のカード |
| 属性 | 斬 | 斬 |
| コスト | 0（元と同じ） | 0（元と同じ） |
| 説明文 | 次に使う斬カードの威力+50%。カードを2枚引き、手札を1枚捨てる。霧散。 | 次に使う斬・打・貫カードの威力+50%。カードを1枚引く。霧散。 |
| 効果（行う順） | 次に使う斬カードの威力+50%<br>カードを2枚引き、手札を1枚捨てる<br>霧散 | 次に使う斬・打・貫カードの威力+50%<br>カードを1枚引く<br>霧散 |
| 挿絵のモチーフ | 研ぎ石と青く光る刃 | 剣・槌・槍の刃先がそろって光る |
| 演出 | 元の演出に、青緑の光の溜めと当たりを重ねる。使い手の頭上で星が瞬き、光の粒が使い手へ集まる | 元の演出に、鋼の青の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く |
| 挿絵 | `CardHone1.aseprite` | `CardHone2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
