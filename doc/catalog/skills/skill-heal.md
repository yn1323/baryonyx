### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 回復は現実にない現象のため、光が足元から体へ順に届く流れで見せる。光の柱は塵が光を返して見える。
- 攻撃の閃光より穏やかに立ち上げ、上昇の速さを層ごとに変える。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.24 | 予備動作 | 緑の魔法陣と集まる光の粒 | 床・手前 |
| 0.24〜0.40 | 発生 | 足元の光だまりと床の輪が広がる | 床 |
| 0.24〜0.54 | 発生 | 奥の光の柱が0.3秒かけて立つ。手前の細い柱は0.08秒遅れる | 奥・手前 |
| 0.38 | 発生 | 回復。遅い光の粒と速いきらめきが昇り始める | 手前 |
| 0.50〜1.40 | 余韻 | 体を柔らかい光が包む。柱が縁から削れる | 奥 |
| 〜2.3 | 余韻 | 光の粒が昇りきって消える | 手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 光だまり | 床に寝た柔らかい光と輪 | 加算 | 0.24〜1.4秒 |
| 光の柱 | 塵で見える光の柱。奥は太く、手前は細く薄い | 加算。手前は35% | 奥1.15秒、手前0.8秒 |
| 光の粒ときらめき | 遅く昇る小さな粒と、速く昇って回るきらめき | 加算 | 粒0.9〜1.5秒、きらめき0.5〜0.9秒 |
| 体を包む光 | 体の奥の柔らかい光 | 加算。45%まで | 0.50〜1.40秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ヒール・癒 | 枝2：ヒール・円 |
|---|---|---|
| ID | `Heal.1` | `Heal.2` |
| 枝の方向 | 傷とともに状態異常も癒やす | 癒やしを全員に広げる |
| 種類・対象 | 回復・味方単体 | 回復・味方全体 |
| 属性 | なし | なし |
| コスト | 1（元と同じ） | 1（元と同じ） |
| 説明文 | 味方1体のHPを属攻の90%回復し、状態異常を消す。 | 味方全体のHPを属攻の45%回復する。 |
| 効果（行う順） | 味方1体のHPを属攻の90%回復し、状態異常を消す | 味方全体のHPを属攻の45%回復する |
| 挿絵のモチーフ | 手のひらの上の澄んだ光の雫 | 輪になって広がる若葉色の光 |
| 演出 | 元の演出に、若葉の緑の光の溜めと当たりを重ねる。相手の足元から光の粒が立ちのぼり、柔らかい光で照らす | 元の演出に、花の桃色の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
| 挿絵 | `CardHeal1.aseprite` | `CardHeal2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
