### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
ブリザードは2026-10-23に作り込んだ版を変えず、層と時間を書き残した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 強い風の吹雪では、雪が床すれすれを蛇行しながら流れ、上を薄い雪のベールが横切り、雪片が手前ほど大きく速く流れる。霧は居座らない。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.45 | 予備動作 | 背景が深い夜に沈み、氷の前触れ | 床 |
| 0.45〜2.35 | 発生 | 左から強い風。床すれすれの雪の流れ3本と、あらゆる奥行きの雪片 | 奥・手前 |
| 0.75〜 | 発生 | 敵ごとに0.08秒おきに床が凍り、風上へ傾いた樹氷が生える。青い光 | 奥・手前・床 |
| 1.35 | 発生 | 一斉に砕け、破片と粒が風下へ吹き飛ぶ | 手前 |
| 〜2.5 | 余韻 | 風が弱まって消える | 奥・手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 雪の流れ | 床すれすれを蛇行する細い流れ。帯はその場にあり、模様が流れる | 乗算済みアルファ。奥は9割、手前は2〜4割 | 1.9秒 |
| 雪片 | 奥は小さく暗く遅く、手前は大きくぼけて速い | 加算 | 0.5〜1.9秒ずつ |
| 樹氷と床の氷 | 透ける硬い氷 | 乗算済みアルファ | 0.75〜1.41秒 |
| 破片と光 | 吹き飛ぶ破片と粒、青い光 | 加算・乗算済みアルファ | 0.35〜0.9秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ブリザード・凍 | 枝2：ブリザード・氷壁 |
|---|---|---|
| ID | `Blizzard.1` | `Blizzard.2` |
| 枝の方向 | 凍えた敵を強く打つ | 吹雪の中に氷の壁を立てる |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | 氷 | 氷 |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 敵全体に属攻の80%ダメージ。凍え中の敵には1.5倍。60%で凍え2ターン。眠り札。 | 敵全体に属攻の70%ダメージ。60%で凍え2ターン。味方全体にブロック物防の20%。眠り札。 |
| 効果（行う順） | 敵全体に属攻の80%ダメージ<br>凍え中の敵には1.5倍<br>60%で凍え2ターン<br>眠り札 | 敵全体に属攻の70%ダメージ<br>60%で凍え2ターン<br>味方全体にブロック物防の20%<br>眠り札 |
| 挿絵のモチーフ | 渦を巻く吹雪と凍りつく大地 | 吹雪の中にそびえる氷の壁 |
| 演出 | 元の演出に、氷の水色の光の溜めと当たりを重ねる。相手の足元に霜の輪が広がり、氷のかけらが舞う | 元の演出に、鋼の青の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる |
| 挿絵 | `CardBlizzard1.aseprite` | `CardBlizzard2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
