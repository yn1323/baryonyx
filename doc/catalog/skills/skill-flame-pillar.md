### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
フレイムピラーを炎の技の代表として先に作り直し、ほかの炎の技へ広げた。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- 炎は上ほど速く昇り、先端が裂けて消える。熱い所ほど白く、冷えるにつれ黄・橙・赤・暗い色になる。
- 炎の上には煤の煙が立ち、炎が消えたあとも昇り続ける。火の粉は空気に止められてから漂い昇る。
- 炎は周りを揺らぐ光で照らし、床には焦げ跡が残る。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.40 | 予備動作 | 魔法陣が開いて速く回る。床が暗い赤から明るく熱を帯び、火の粉が跳ねて落ち、細い煙が昇る。敵が下から薄く照らされる | 床・奥と手前 |
| 0.40〜0.50 | 発生 | 火柱が0.1秒で噴き上がる。根元の白熱の芯。ダメージ、ヒットストップ、上向きの揺れ | 奥・手前 |
| 0.40〜0.85 | 発生 | 炎の舌が敵の手前を舐め上がる。火柱が膨らむ。床の光だまりが揺らぐ | 手前・床 |
| 0.52〜1.50 | 発生〜余韻 | 火柱が細くなりながら上から削れ、冷えて赤くなる。上から千切れた炎の塊が昇る | 奥 |
| 0.52〜2.50 | 余韻 | 煤が火柱の上から昇って残る。火の粉が漂い冷える。焦げ跡が縁から削れる | 奥・手前・床 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 煤 | 陰影のある暗い煙。初めは下から照らされた茶色、昇るにつれ灰色 | 通常の合成で7割程度。光る層の奥 | 0.52〜2.5秒。最も長い |
| 火柱の本体 | 密度で描く炎。上ほど速く流れ、縁が裂ける。冷えた先端に薄い煤の覆い | 乗算済みアルファ。光を足し、煤だけ奥を覆う | 0.40〜1.50秒。0.25秒で膨らみ、後半に細くなって上から削れる |
| 芯 | 根元の細い白熱の噴流 | 加算。最も明るい | 0.40〜0.72秒 |
| 炎の舌 | 敵の手前を舐め上がる細い炎 | 加算 | 0.25〜0.5秒ずつ、0.9秒にわたる |
| 火の粉 | 小さな橙の粒 | 加算。1を超える明るさ | 0.6〜1.6秒ずつ |
| 床 | 揺らぐ光だまりと焦げ跡 | 光だまりは加算、焦げ跡は通常の合成 | 光だまり約1.3秒、焦げ跡2秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：フレイムピラー・業火 | 枝2：フレイムピラー・連柱 |
|---|---|---|
| ID | `FlamePillar.1` | `FlamePillar.2` |
| 枝の方向 | 焼いてから柱を立てる1枚で完結させる | 柱を2体に立てる |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵ランダム |
| 属性 | 炎 | 炎 |
| コスト | 3（元は2） | 2（元と同じ） |
| 説明文 | 敵1体にやけど2ターン。敵1体に属攻の220%ダメージ。やけど中の敵には1.5倍。 | 敵1体に属攻の120%ダメージ×2。1回ごとに別の敵へ移る。やけど中の敵には1.5倍。 |
| 効果（行う順） | 敵1体にやけど2ターン<br>敵1体に属攻の220%ダメージ<br>やけど中の敵には1.5倍 | 敵1体に属攻の120%ダメージ×2<br>1回ごとに別の敵へ移る<br>やけど中の敵には1.5倍 |
| 挿絵のモチーフ | 渦巻く太い炎の柱 | 並んで立つ2本の炎の柱 |
| 演出 | 元の演出に、炎の橙の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く | 元の演出に、金の光の溜めと当たりを重ねる。当たった相手の上で光の点が順に瞬き、つながるように見える |
| 挿絵 | `CardFlamePillar1.aseprite` | `CardFlamePillar2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
