### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：結界は薄い膜と縁の光（盾・結界のレシピ）。プロテクトより格を上げ、上からの光で始めて大きさ・長さを足す。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.22 | 予兆 | 使い手の足元に魔法陣 | 床 |
| 0.22〜0.40 | 予兆 | 細い金の光が味方へ降りる | 味方の奥と手前 |
| 0.40 | 発動 | 膜が張られ、盾の紋が光る。輪、光だまり、照らす | 全体 |
| 0.40〜2.00 | 余韻 | 昇る線が消え、膜が削れて消える | 味方の奥と手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 膜（奥） | 縁が明るく（Fresnel）、細かい六角の模様のある金の薄い膜。縁から内へ波紋が1回走り、六角ごとに削れて消える | 乗算済み。少しだけ奥を覆い、光を足す | 1.6秒 |
| 縁（手前） | 同じ膜を手前に薄く重ね、縁だけが読める | 約4割 | 1.6秒 |
| 盾の紋 | 手前で光る大きな紋 | 加算。明るい | 0.6秒 |
| 昇る線と塵 | 膜の中を昇る線、降りる塵 | 加算 | 0.6〜1.4秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：ディバインシールド・聖域 | 枝2：ディバインシールド・祝福 |
|---|---|---|
| ID | `DivineShield.1` | `DivineShield.2` |
| 枝の方向 | 守りを全員に広げる | 守りに癒やしを添える |
| 種類・対象 | 防御・味方全体 | 防御・味方単体 |
| 属性 | なし | なし |
| コスト | 3（元は2） | 2（元と同じ） |
| 説明文 | 味方全体は、次のターンまでダメージを受けない。消滅。 | 味方1体は、次のターンまでダメージを受けない。HPを属攻の50%回復。消滅。 |
| 効果（行う順） | 味方全体は、次のターンまでダメージを受けない<br>消滅 | 味方1体は、次のターンまでダメージを受けない<br>HPを属攻の50%回復<br>消滅 |
| 挿絵のモチーフ | 全員を包む光のドーム | 盾に咲く金の花 |
| 演出 | 元の演出に、金の光の溜めと当たりを重ねる。相手の足元に光の盾の輪が立ち、光の粒がせり上がる | 元の演出に、花の桃色の光の溜めと当たりを重ねる。相手の足元から光の粒が立ちのぼり、柔らかい光で照らす |
| 挿絵 | `CardDivineShield1.aseprite` | `CardDivineShield2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
