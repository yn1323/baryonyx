### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md) の改訂に合わせ、現象を書き出して層と時間を見直した。
時刻は、カードを使ってからの秒数である（カットインは含めない）。

現実の現象は、次のように見える。

- つむじ風そのものは透明で、巻き上げた土ぼこりと砂利で形が見える。
- 刃が当たると金属の火花が飛ぶ。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.16 | 予備動作 | 剣先がきらめき、使い手の足元の塵が外へ走る | 手前・床 |
| 0.16〜0.28 | 予備動作 | 端の敵の手前でつむじ風が立ち上がる | 奥 |
| 0.16〜0.78 | 発生 | つむじ風が敵の列を走り抜ける。0.06秒ごとに土ぼこりと砂利が巻き上がる。届いた敵を2本の弧が斬り、火花と赤い滴 | 奥・手前 |
| 0.78〜1.10 | 余韻 | 風が削れて消え、葉が舞い、塵が落ちる | 手前 |

| 層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| 土ぼこり | 巻き上げられた塵の塊。陰影のある煙 | 通常の合成で5割程度 | 0.5〜0.8秒ずつ、走るあいだ次々に出る |
| つむじ風 | 横から見た渦の薄い筋 | 加算。明るさ0.6倍で薄い | 走り抜ける0.97秒。後半から削れる |
| 砂利 | 回りながら跳ねて落ちる小さな破片 | 通常の合成 | 0.4〜0.7秒 |
| 刃の弧（4層） | 同じ種の1本の弧を、にじみ・残像・本体・芯の4枚に分ける。にじみは広く柔らかい色の光、残像は内側の細い筋、本体は筋と縁、芯は白い前縁の線 | 加算。芯が最も明るく、にじみは6割まで | にじみ0〜0.36秒、残像0.04〜0.5秒（途切れて消える）、本体0〜0.26秒、芯0〜0.12秒 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：旋風斬・裂 | 枝2：旋風斬・嵐 |
|---|---|---|
| ID | `Whirlwind.1` | `Whirlwind.2` |
| 枝の方向 | 出血の敵を深く斬る | 2回転して斬る |
| 種類・対象 | 攻撃・敵全体 | 攻撃・敵全体 |
| 属性 | 斬 | 斬 |
| コスト | 2（元と同じ） | 2（元と同じ） |
| 説明文 | 敵全体に物攻の80%ダメージ。出血中の敵には1.5倍。60%で出血2ターン。 | 敵全体に物攻の50%ダメージ×2。60%で出血2ターン。 |
| 効果（行う順） | 敵全体に物攻の80%ダメージ<br>出血中の敵には1.5倍<br>60%で出血2ターン | 敵全体に物攻の50%ダメージ×2<br>60%で出血2ターン |
| 挿絵のモチーフ | 赤い筋を引く竜巻 | 2重に巻く旋風 |
| 演出 | 元の演出に、深紅の光の溜めと当たりを重ねる。当たった所から花びらのような粒が散り、ゆっくり落ちる | 元の演出に、鋼の青の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
| 挿絵 | `CardWhirlwind1.aseprite` | `CardWhirlwind2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
