### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：影は光ではなく、暗い本体と細い縁光で描く（闇のレシピ）。黒い円を置かず、重いガスとして床を這わせ、縁だけが光る。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.16 | 予兆 | 暗い刃が足元へ飛ぶ | 手前 |
| 0.16 | 発動 | 刺さった点に白紫の光が0.12秒。割れ目が開く。ダメージ | 手前・床 |
| 0.16〜0.55 | 余韻 | 影の糸が次々に立ち昇る（1本0.22〜0.36秒）。影のガスが床を這う | 敵の奥と手前 |
| 0.55〜1.45 | 余韻 | ガスと割れ目が削れ、紫の光だまりが消える | 床 |

| ガスの層 | 役割と形 | 透け方 | 動き |
|---|---|---|---|
| 暗い本体（床の奥） | 床に寝た広く平たいガス | 濃く覆い、縁と薄いところは奥が透ける | 左右へゆっくり這い、縁から削れる |
| 盛り上がり（床の手前） | 刺さった点から転がり落ちる塊 | 中くらいに覆う | 空気より重く、膨らみながら沈む |
| 切れ端（床の手前） | 床を速く走る細い切れ端 | 薄く、ほとんどが穴 | 速い |
| 中の光（床の奥） | ガスの中にぼんやり灯る紫の斑 | 加算 | ところどころで灯って消える |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

|---|---|---|
| ID | `ShadowStitch.1` | `ShadowStitch.2` |
| 枝の方向 | 影ごと縛りつける | 縫い止めて次の手へ走る |
| 種類・対象 | 弱体・敵単体 | 弱体・敵単体 |
| 属性 | 貫 | 貫 |
| コスト | 1（元と同じ） | 1（元と同じ） |
| 説明文 | 敵1体に物攻の80%ダメージ。その敵の行動順を1つ遅らせ、60%で麻痺1ターン。捨てたとき：ランダムな敵の行動順を1つ遅らせる。 | 敵1体に物攻の80%ダメージ。その敵の行動順を1つ遅らせる。カードを1枚引く。捨てたとき：ランダムな敵の行動順を1つ遅らせる。 |
| 効果（行う順） | 敵1体に物攻の80%ダメージ<br>その敵の行動順を1つ遅らせ、60%で麻痺1ターン<br>捨てたとき：ランダムな敵の行動順を1つ遅らせる | 敵1体に物攻の80%ダメージ<br>その敵の行動順を1つ遅らせる<br>カードを1枚引く<br>捨てたとき：ランダムな敵の行動順を1つ遅らせる |
| 挿絵のモチーフ | 影に打ち込まれた黒い楔と鎖 | 影の中を走る針の軌跡 |
| 演出 | 元の演出に、紫の光の溜めと当たりを重ねる。当たった相手の上で光の点が順に瞬き、つながるように見える | 元の演出に、魔力の紫の光の溜めと当たりを重ねる。風の筋が相手を横切って流れる |
