### 演出の時間設計

2026-10-26、[vfx-authoring](../../../.agents/skills/vfx-authoring/SKILL.md)の作り方で作り直した。現象を書き出し、予兆・発動・余韻の3拍で層ごとに出現・ピーク・消失をずらし、主役を役割と透け方の違う4つ前後の層に分けた。
時刻はカード演出の開始（カットインの後）からの秒数で、表の上の層ほど奥に描く。

現象：稲妻の通り道と光り直し（[米国気象局](https://www.weather.gov/mlb/what_is_lightning)）。雷雲の技と分けるため、雲は出さず、空に槍が形を成してから落ちる。

| 時刻（秒） | 拍 | 動き | 置く層 |
|---|---|---|---|
| 0.00〜0.45 | 予兆 | 使い手が帯電し、空が夜になる | 画面全体・手前 |
| 0.45〜1.00 | 予兆 | 光の粒が頭上へ集まり、槍（短い通り道）が6回光り直しながら明るくなる。上から場を照らす | 手前・奥 |
| 1.00〜1.04 | 予兆 | 槍から先駆放電が降りる | 手前 |
| 1.04 | 発動 | 主放電。閃光、暗転が0.1秒解ける、ヒットストップ、揺れ、寄せ、焦げ跡、土ぼこり | 全体 |
| 1.14・1.24 | 発動 | 同じ通り道が光り直す | 手前・床 |
| 1.24〜 | 発動 | 床を低く走る稲妻が他の敵へ順に落ちる（1回光り直す） | 手前・床 |
| 〜+0.8 | 余韻 | 残像が消え、雷鳴の揺れが転がる | 全体 |

| 稲妻の層 | 役割と形 | 透け方 | 時間 |
|---|---|---|---|
| にじみ | 通り道と枝の周りの光った空気。白みがかった黄 | 加算。先駆放電のあいだは薄く、放電ごとに明るくなる | 最も長く、放電の前後を包む |
| 残像 | 目に残る細い筋。濃い黄 | 加算。最後の放電のあと約0.3秒で薄れる | 途切れながら最後に消える |
| 通り道と枝 | 白に近い通り道と枝分かれ。先駆放電もこの層 | 加算 | 放電の少し前から少し後 |
| 芯 | 白く熱い細い線。主の通り道だけ | 加算。最も明るく、Bloomでにじむ | 放電の瞬間だけ。光り直しも同じ通り道 |

## 覚醒版

この1枚が[覚醒](../../features/skill-awakening.md)して進む、2つの枝の段階である（2026-10-24、仮）。
覚醒は1段だけで、進んだ1枚は元に戻らない。倍率・品質・倍率の上限・レア度は元のスキルのものを引き継ぐ。

| 項目 | 枝1：雷神の槍・神鳴 | 枝2：雷神の槍・轟 |
|---|---|---|
| ID | `ThunderSpear.1` | `ThunderSpear.2` |
| 枝の方向 | 痺れた敵を貫く | 手札2枚を雷に変えて重くする |
| 種類・対象 | 攻撃・敵単体 | 攻撃・敵単体 |
| 属性 | 雷 | 雷 |
| コスト | 3（元と同じ） | 3（元と同じ） |
| 説明文 | 手札を1枚捨てる。敵1体に属攻の360%ダメージ。麻痺中の敵には1.5倍。さらに敵全体に属攻の60%ダメージ。 | 手札を2枚捨てる。敵1体に属攻の420%、さらに敵全体に属攻の80%ダメージ。敵全体に60%で麻痺1ターン。 |
| 効果（行う順） | 手札を1枚捨てる<br>敵1体に属攻の360%ダメージ<br>麻痺中の敵には1.5倍<br>さらに敵全体に属攻の60%ダメージ | 手札を2枚捨てる<br>敵1体に属攻の420%、さらに敵全体に属攻の80%ダメージ<br>敵全体に60%で麻痺1ターン |
| 挿絵のモチーフ | 雷をまとう大槍と神の紋 | 地を割る雷の槍と轟く衝撃 |
| 演出 | 元の演出に、雷の黄の光の溜めと当たりを重ねる。当たった所に白熱した芯の閃光と光の十字が開く | 元の演出に、雷の色の光の溜めと当たりを重ねる。足元に大きな土煙の輪が広がり、画面が揺れる |
| 挿絵 | `CardThunderSpear1.aseprite` | `CardThunderSpear2.aseprite` |

演出は、元のスキルの演出に、段階の色の光で覚醒した段階の溜めと当たりの層を重ね、段階ごとのしるしを付ける（[演出](../../features/skill-awakening.md#演出)）。
