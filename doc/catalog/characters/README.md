## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 役割・固定職業ID・加入方法 | 未決 |
| 固有アクティブスキルID・固有パッシブID | 未決 |
| 基礎ステータス・成長・装備可能武器種・防具種 | 未決 |
| 年齢感・体格・頭身・輪郭・顔・髪・目 | 未決 |
| 衣装・素材・装飾・装備・主色・差し色 | 未決 |
| 価値観・欲求・弱点・葛藤・得意不得意 | 未決 |
| 行動の癖・口調・対人距離・仲間との関係 | 未決 |
| 経歴・所属・物語上の役割 | 未決 |
| 戦闘ドット絵とイラストで維持する特徴 | 未決 |

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
