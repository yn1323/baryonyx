## 確定した設定

なし（すべて仮設定）。

## 絆

同じキャラが被るたびに1段上がり、6段が上限である（[キャラが被ったとき](../../features/monetization.md#キャラが被ったとき)）。
効果は全キャラ共通の仮の値で、本番の効果はキャラごとに考える。

| 段 | 手に入れた数 | 効果（仮・合計） |
|---|---|---|
| 0 | 1体目 | なし |
| 1 | 2体目 | 全ステータス+2% |
| 2 | 3体目 | 全ステータス+4% |
| 3 | 4体目 | 全ステータス+6% |
| 4 | 5体目 | 全ステータス+8% |
| 5 | 6体目 | 全ステータス+10% |
| 6（上限） | 7体目 | 全ステータス+12% |

8体目からは、かけらに変える。
