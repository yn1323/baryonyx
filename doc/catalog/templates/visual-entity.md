# 画像対象の記入テンプレート

[データ索引](../README.md)

コピー先では `type: visual-entity` とし、ID・ファイル名・分類・名称・日付・状態を更新する。
このテンプレートへのリンクはコピー先から参照できる相対パスに直す。
各欄は未決から始め、対象に該当しない項目は「対象外」と理由を記す。
記入を始めた案は「候補」、一部が合意された案は「一部確定」、対象の採用と内容が合意された案は「確定」とする。
