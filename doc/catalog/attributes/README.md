## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 属性名・魔法と物理の分類 | 魔法は炎・氷・雷、物理は斬・打・貫で確定。[属性と弱点](../../features/combat/rules.md#属性と弱点)に従う |
| 弱点に一致したときの補正 | 確定。[属性と弱点](../../features/combat/rules.md#属性と弱点)に従う |
| 物理属性ごとのクセ | 未決。候補は[戦闘仕様の未決事項](../../features/combat/implementation.md#未決事項)を参照する |
| 装備できるキャラの組み合わせ | 未決 |
| 色・記号・表示名・アイコンの要否 | 未決 |

耐性（軽減・無効）と、属性同士の相性表は設けない。
