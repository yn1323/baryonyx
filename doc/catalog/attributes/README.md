# 属性の定義

[データ索引](../README.md) / [関連仕様](../../features/combat.md)

個別内容と決定状態は、下の索引から各定義を参照する。
画像化の要否は個別に決め、画像が必要なら画像対象テンプレートを使う。
IDの接頭辞は `attribute-`、メタデータの `category` は `attributes` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 属性名・魔法と物理の分類 | 魔法は炎・氷・雷、物理は斬・打・貫で確定。[属性と弱点](../../features/combat.md#属性と弱点)に従う |
| 弱点に一致したときの補正 | 1.5倍で確定。[属性と弱点](../../features/combat.md#属性と弱点)に従う |
| 物理属性ごとのクセ | 未決。候補は[戦闘仕様の未決事項](../../features/combat.md#未決事項)を参照する |
| 装備できるキャラの組み合わせ | 未決 |
| 色・記号・表示名・アイコンの要否 | 未決 |

耐性（軽減・無効）と、属性同士の相性表は設けない。

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
