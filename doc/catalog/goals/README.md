## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 対象運動・指標・単位 | 未決 |
| 入力範囲・期間・時間帯・頻度 | 未決 |
| 判定に使うデータ・達成条件 | 未決 |
| 難易度係数・報酬テーブルID | 未決 |
| 変更・取消・再設定・重複の制約 | 未決 |
| 表示名・説明文・未達成と達成時の案内 | 未決 |

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
