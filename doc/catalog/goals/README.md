# 運動目標の定義

[データ索引](../README.md) / [関連仕様](../../features/goals.md)

個別内容と決定状態は、下の索引から各定義を参照する。
定義テンプレートを使う。
IDの接頭辞は `goal-`、メタデータの `category` は `goals` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 目標枠・対象運動・指標・単位 | 選択可能な組み合わせは[目標仕様](../../features/goals.md#設定の流れと判定基準)に従う。個別設定は未決 |
| 目標量・期間・時間帯 | 日次・週次の枠と期間は[目標仕様](../../features/goals.md#集計期間)に従う。数値候補は仮設定 |
| 判定に使うデータ・達成条件 | [集計仕様](../../features/goals.md#運動実績の集計)に従う。具体的なデータ対応と境界処理は未決 |
| 難易度倍率・継続倍率・報酬テーブルID | 継続の評価対象は[目標仕様](../../features/goals.md#継続倍率に使う実績)に従う。係数・上限・報酬は未決 |
| 条件変更の適用時点・変更予約・枠ごとの履歴 | [編集・削除・再設定](../../features/goals.md#編集削除再設定)に従う。具体的な保存形式は未決 |
| 表示名・説明文・進捗・過去の条件・対象実績・適用倍率 | [表示要件](../../features/goals.md#進捗と履歴の表示)に従う。個別の表現は未決 |

[選択肢の数値](../../features/goals.md#目標量の選択肢と調整幅)は仮設定であり、採用済みの個別目標として登録しない。
日次・週次の継続履歴は目標枠に残し、個別条件の変更によってリセットする定義を作らない。

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
