# 世界の人物・地域・組織の定義

[データ索引](../README.md) / [世界設定](../../game/world.md)

個別内容と決定状態は、下の索引から各定義を参照する。
画像化の要否は個別に決め、画像が必要なら画像対象テンプレートを使う。
IDの接頭辞は `world-`、メタデータの `category` は `world` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 人物・地域・組織などの種別 | 未決 |
| 名称・別名・歴史・文化・関係ID | 未決 |
| 物語上の役割・主人公との関係 | 未決 |
| 外見・建築・地形・紋章・配色・モチーフ | 未決 |
| 人物なら性格・価値観・口調・行動原理 | 未決 |
| 画像化する用途と他の定義との差 | 未決 |

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
