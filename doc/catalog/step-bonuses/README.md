# UPTボーナスの定義

[データ索引](../README.md) / [関連仕様](../../features/step-bonus.md)

個別内容と決定状態は、下の索引から各定義を参照する。
画像化の要否は個別に決め、画像が必要なら画像対象テンプレートを使う。
IDの接頭辞は `step-bonus-`、メタデータの `category` は `step-bonuses` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 表示名・カテゴリ（ドロップ系・探索系・戦闘系など） | 個別設定は未決。カテゴリで整理する方針は[UPTボーナスの設計方針](../../features/step-bonus.md#設計方針)に従う |
| 枠ごとの効果量 | ランクの効果量に枠の倍率を掛ける（[日次のUPTボーナス](../../features/step-bonus.md#日次のuptボーナス)）。段階のUPTは[候補](../../features/step-bonus.md#候補)であり、確定値として転記しない |
| 効果・対象 | 未決。中身の採用候補は[UPTボーナスの候補](../../features/step-bonus.md#候補)を参照する |
| ランクごとの効果量・入手先 | 個別値は未決。ランク（S〜E）ごとに効果量を固定し、冒険でも手に入る予定（[ボーナスの入手とランク](../../features/step-bonus.md#ボーナスの入手とランク)）。仮設定は[ランクと効果量](../../features/step-bonus.md#ランクと効果量) |
| 日次・週次の区分 | 週次ボーナスの採否と条件は未決 |
| 重ねがけ | 有効になった枠のボーナスは重ねて効く。同じボーナスを複数の枠に入れることはできない |
| 表示文・アイコン | 未決 |

有効期間は[1日の区切りと有効期間](../../features/step-bonus.md#1日の区切りと有効期間)に従い、個別データごとに変えない。

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
