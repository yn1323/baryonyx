# レア度の定義

[データ索引](../README.md) / [関連仕様](../../features/inventory.md#レア度)

個別内容と決定状態は、下の索引から各定義を参照する。
画像化の要否は個別に決め、画像が必要なら画像対象テンプレートを使う。
IDの接頭辞は `rarity-`、メタデータの `category` は `rarities` とする。

## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 適用対象 | 武器・防具・アクセサリー・スキル・アイテム・ACTボーナス（[レア度](../../features/inventory.md#レア度)）。キャラに付けるかは未決 |
| 段階・並び順・名称 | ☆1〜☆5の5段階で、☆5がもっとも珍しい（[レア度](../../features/inventory.md#レア度)）。ACTボーナスは、ランクのEをなくしてD〜Sを☆1〜☆5に当てた（[レア度と効果量](../../features/step-bonus.md#レア度と効果量)） |
| 性能・Affix数・数値幅・倍率の幅との関係 | 未決（[持ち物の分類の未決事項](../../features/inventory.md#未決事項)） |
| 表示色・枠・演出の要否 | 未決 |
| 抽選率の定義元へのリンク | 未決 |

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
