# 絡め取り

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

沖の大ダコの固有技。吸盤の付いた触手で味方1人を捕らえ、離すまで締め上げ続ける。

| 実装・ゲームマスタの場所 | 未実装 |

[根縛り](enemy-skill-root-bind.md)の絡みつきはカードのコストを上げるが、この技の捕縛は、締めつけのダメージを重ねる。
大ダコの弱点の斬で触手を断てば解けるため、味方は「捕まった仲間を助けるために斬る」選択を持つ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぬるり、締めあげる |
| 本体の動き | 体を標的の側へ傾け、触手を1本だけ長く伸ばす |
| 溜め | 触手の吸盤が並んで白く光り、先が標的へ向く |
| 発生 | 触手が標的に2重に巻きつき、締まる瞬間に標的を短く縦に縮める |
| 余韻 | 捕縛のあいだ、標的の周りに赤紫の触手の輪が薄く残る。締めつけのたびに輪が一瞬締まる。斬で解けるときは、輪が途中で切れて落ちる。輪は標的のHPと状態の表示を隠さない |
| 色 | 赤紫、白、濃い紫 |
| 格 | 中 |
