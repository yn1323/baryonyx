# 頁の詠唱

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

浮遊する魔導書の固有技。持ち主が最後に唱えかけた呪文を読み上げ、2ターン後に味方全体へ雷を落とす。

| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵50体を試作し、文書カタログ・クライアント・サーバーにそろえる）で、[浮遊する魔導書](../enemies/enemy-floating-grimoire.md)の技として作った |

| 実装・ゲームマスタの場所 | 未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぱらぱら、ひたひた迫る |
| 本体の動き | 表紙を少し上へ傾け、頁を速くめくる |
| 溜め | 味方全体の頭上に、水色の光る文字が輪になって並ぶ。ターンが進むごとに、輪の文字が明るくなる。輪は味方のHPと状態の表示を隠さない |
| 発生 | 輪の文字が一斉に稲妻に変わり、味方全体へ落ちる |
| 余韻 | 文字の欠片が細かい光の粒になって降り、消える。揺れは短く1回 |
| 色 | 水色、白、淡い黄 |
| 格 | 中 |
