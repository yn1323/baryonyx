# 洞窟崩し

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

岩肌トロルの固有技。石柱で天井を突き崩し、落石で一行を埋める。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | どどど、崩れる |
| 本体の動き | 溜めのターンに石柱を高く掲げるように絵を上へ伸ばし、使うターンに大きく振り下ろす |
| 溜め | 溜めのターンに、天井から細かい砂と小石が落ち始め、トロルの体の縁が赤く光り続ける |
| 発生 | 石柱が天井を突く衝撃の輪が画面の上に出て、大小の岩が味方全体へ降り注ぐ。画面を大きく揺らす |
| 余韻 | 味方の足元に岩のかけらが積もり、絡みつきのあいだ残る。かけらは味方のHPと状態の表示を隠さない |
| 色 | 灰茶、灰青、赤、白 |
| 格 | 大 |
