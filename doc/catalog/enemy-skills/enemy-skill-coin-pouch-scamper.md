# すたこら逃げ

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

金貨袋の固有技。金貨を抱えたまま短い足で一目散に駆け出し、戦闘から逃げ去る。

## 識別情報と根拠

| 役割・説明 | 自分の逃走。倒す前に逃げられると落とし物を得られない |
| 関連する仕様・個別ID | 使う敵：[金貨袋](../enemies/enemy-coin-pouch.md)。[敵の行動の仮設定](../../features/combat-enemy-behavior.md) |
| 実装・ゲームマスタの場所 | 未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | すたこら、ちゃりんちゃりん |
| 本体の動き | 絵を右（味方と反対の側）へ反転させ、小刻みに跳ねながら画面の右端へ素早く移動して消える |
| 溜め | 予告のターンに、袋が小刻みに震えて足踏みする |
| 発生 | 走り出す瞬間に、足元に土ぼこりの粒が出て、金貨が数枚こぼれる |
| 余韻 | こぼれた金貨が床で光ってから消える。立ち位置は空く |
| 色 | 金、こげ茶、土色 |
| 格 | 小 |

こぼれた金貨は見た目だけで、拾えない。
