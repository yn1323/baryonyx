# 白霧の大息吹

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

霧の竜の固有技で、激化のあとに使う大技。胸いっぱいに霧を吸い込み、真っ白な息で一帯を凍らせて覆い隠す。

[冷たい息](enemy-skill-frost-breath.md)とは、威力の大きさだけでなく、凍えの代わりに引くカードを減らす点で効果が違う。
霧で手元が見えなくなり、次のターンに打てる手が減る。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ごおっ、真っ白 |
| 本体の動き | 溜めのターンに首を大きく後ろへ反らし、胸を膨らませる。使うターンに首を前へ突き出す |
| 溜め | 溜めのターンに、周りの霧が竜の口へ吸い込まれる流れが続き、口の奥が白く光る |
| 発生 | 口から白い霧の奔流が味方全体へ吹きつけ、画面の味方の側を短く白く覆う。霜の結晶が味方の足元に広がる。画面を短く揺らす |
| 余韻 | 白い覆いがゆっくり晴れ、霜の粒が漂って消える。次の味方ターンの初めに、山札の上に霧がかかって1枚分が引かれない様子を短く見せる |
| 色 | 白、水色、青灰 |
| 格 | 大 |

白く覆う時間は短くし、晴れたあとに受けたダメージの数字を読み取れるようにする。
