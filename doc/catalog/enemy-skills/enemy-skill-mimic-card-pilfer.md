# 欲張りな舌

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

人食い宝箱の固有技。長い舌を伸ばして、冒険者の手札を1枚かすめ取る。

| 項目 | 内容 |

| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵50体を試作し、文書カタログ・クライアント・サーバーにそろえる）で、[人食い宝箱](../enemies/enemy-chest-mimic.md)の技として作った |
| 役割・説明 | 単体への小さなダメージと、手札を減らす妨害 |
| 関連する仕様・個別ID | 使う敵：[人食い宝箱](../enemies/enemy-chest-mimic.md)。[敵の行動の仮設定](../../features/combat-enemy-behavior.md) |
| 実装・ゲームマスタの場所 | 未実装 |

奪ったカードは消さずに山札の一番下へ戻す。作った当時は捨て札がなく、手札を手動で捨てる操作もなかったため、カードを失わない置き場として山札の一番下を選んだ。2026-10-25に捨て札を設けた（[手札](../../features/combat.md#手札)）が、この技の戻し先は山札の一番下のままとする（仮）。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぺろり、ひったくる |
| 本体の動き | 体を前に傾け、絵を少し横へ伸ばす |
| 溜め | 舌の先が左右にゆらゆら揺れる（舌の動きは演出の線で描く） |
| 発生 | 赤い舌の線が標的へ素早く伸びて巻きつき、カードの形の光を1枚くわえて引き戻す。手札からは奪われたカードが抜け、山札の位置へ飛ぶ |
| 余韻 | 引き戻した光が箱の中へ吸い込まれ、金貨の粒が短くきらめく。標的のHPと手札の表示を隠さない |
| 色 | 赤、金 |
| 格 | 小 |
