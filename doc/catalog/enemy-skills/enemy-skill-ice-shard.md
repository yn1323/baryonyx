# 氷のつぶて

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

共通技。とがった氷の欠片を味方1人へ撃ち込む魔法の攻撃である。

| 役割・説明 | 単体への魔法・氷の攻撃と凍え |
| 関連する仕様・個別ID | 使う敵：[朝露ぷるん](../enemies/enemy-dew-slime.md)、[浮遊する魔導書](../enemies/enemy-floating-grimoire.md)、[地底湖の盲魚人](../enemies/enemy-blind-fishman.md)、[つらら尾の狐](../enemies/enemy-icicle-fox.md)、[死霊の魔導師](../enemies/enemy-lich.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぱきっと冷たい、硬い |
| 本体の動き | 体の周りに冷気が白く漂う |
| 溜め | 体の前に、氷の欠片が3つ集まって並ぶ |
| 発生 | 氷の欠片がまっすぐ標的へ飛び、当たって砕ける |
| 余韻 | 標的の足元に霜が広がり、ゆっくり消える |
| 色 | 水色、白、薄い青 |
| 格 | 小 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [朝露ぷるん](../enemies/enemy-dew-slime.md) | 双葉の先から、冷えた朝露が凍った水色の小さな氷粒になって飛ぶ |
| [浮遊する魔導書](../enemies/enemy-floating-grimoire.md) | 氷のつぶてを水色の光る文字の形にし、頁からこぼれて凍りながら飛ぶ形にする |
| [地底湖の盲魚人](../enemies/enemy-blind-fishman.md) | つぶてを水しぶきが凍った水色の粒にし、薄紫のひれの一振りから飛ぶ形にする |
| [つらら尾の狐](../enemies/enemy-icicle-fox.md) | 尾のつららの先で冷気を固め、細い水色の氷の欠片を撃ち出す |
| [死霊の魔導師](../enemies/enemy-lich.md) | 杖の先の緑の渦から、緑の粒をまとった青白い氷の棘を撃ち出す |
