# 地中からの突き上げ

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

鉱石喰いモグラの固有技。地中を掘り進み、標的の足元から爪で突き上げる。ブロックの下から来るため、盾では防げない。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ずぼっ、下から |
| 本体の動き | 絵を下へ沈めて消し（地中に潜る）、突き上げたあと元の位置に浮かび上がる |
| 溜め | 敵の立ち位置から標的の足元へ、床の下を進む土の盛り上がりの線が走る |
