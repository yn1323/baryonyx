# 空ろの鎧ばらし

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

古王国の空鎧の固有技。中身のない鎧を部品ごとにばらして宙に浮かせ、攻撃を隙間に素通りさせる。そのあと、霧で部品を引き寄せて組み直す。

[水晶角の照り返し](enemy-skill-crystal-horn-glint.md)は単体攻撃を1回はね返すが、この技は1ターンの間すべてのダメージを受けず、はね返さない。
代わりに次の行動を失うため、プレイヤーはそのターンをほかの敵へ向け、組み直しのターンに空鎧を叩ける。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | がらん、ふわり |
| 本体の動き | 兜・胴・腕・脚の部品が少しずつ離れて宙に浮き、隙間から紫の霧が見える |
| 溜め | 継ぎ目の霧が一瞬強く噴き出す |
| 発生 | 部品が離れた位置で止まり、ゆっくり上下に揺れる。攻撃は隙間を抜け、ダメージの数字の代わりに「無効」を出す |
| 余韻 | 組み直しのターンに、霧が糸のように部品を引き寄せ、がしゃんと元の姿に戻る |
| 色 | 鉄色、紫 |
| 格 | 中 |
