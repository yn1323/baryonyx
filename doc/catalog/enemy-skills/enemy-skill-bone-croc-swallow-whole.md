# 丸のみ

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

骨背の大ワニの固有技。そばにいる弱った魔物を丸のみにして、その命で自分の傷を癒す。

## 識別情報と根拠

| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵50体を試作し、文書カタログ・クライアント・サーバーにそろえる）で、[骨背の大ワニ](../enemies/enemy-bone-croc.md)の技として作った |
| 役割・説明 | 仲間を1体倒して、その残りHPで自分を回復する |
| 関連する仕様・個別ID | 使う敵：[骨背の大ワニ](../enemies/enemy-bone-croc.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |
| 実装・ゲームマスタの場所 | 未実装 |

予告でのみ込む敵が見えるため、プレイヤーは先にその敵を倒して回復を防ぐか、残りHPを削って回復を小さくするかを選ぶ。
仲間を呼ぶで呼んだ吸血大ヒルを、あとでのみ込む流れになる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ばくっ、ごくり |
| 本体の動き | のみ込む敵の側へ大きく口を突き出し、戻りながら喉の位置を一度ふくらませる |
| 溜め | 黄色い目がのみ込む敵へ向き、口がゆっくり開く |

| 余韻 | ワニの腹の位置が一度明るく光り、泥水のしずくが落ちる |

| 格 | 中 |
