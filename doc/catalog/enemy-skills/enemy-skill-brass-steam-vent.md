# 蒸気の排気

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

真鍮の番人の固有技。関節の弁を開けて熱い蒸気を噴き出し、体に付いた状態異常を吹き飛ばす。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | しゅうっ、熱い |
| 本体の動き | 体を一度縮めてから、ぶるっと震わせる |
| 溜め | 関節の歯車の回りが止まり、継ぎ目が赤く熱を帯びる |
| 発生 | 肩・肘・膝の継ぎ目から白い蒸気が勢いよく噴き出し、付いていた状態のアイコンを蒸気が吹き消す。体の縁に白い薄い膜（ブロック）が張る |
| 余韻 | 蒸気がゆっくり上へ流れて晴れる |
| 色 | 白、淡い灰、真鍮の金 |
| 格 | 小 |
