# 狩りの狂乱

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

砂鮫の固有技。獲物の気配に我を忘れ、休む間もなく続けて襲いかかるようになる。

| 役割・説明 | 激化の合図。1回の行動の番に技を2つ使うようにし、行動パターンを後半へ切り替える |

予告に2つ並ぶため、プレイヤーは1ターンで受けるダメージの合計を読んで守りを決める。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | がちがち、止まらない |
| 本体の動き | 口を開け閉めするように、絵を上下へ小刻みに3回揺らす |
| 溜め | 体からこぼれる砂の粒が増え、速く落ちる |
| 発生 | 小さな橙の目が赤く光り、体の縁に砂色の速い揺らぎが走る |
| 余韻 | 後半のあいだ、体からこぼれる砂の粒を通常より多くし、目の赤みを残す |
| 色 | 赤、砂色、白 |
| 格 | 大 |
