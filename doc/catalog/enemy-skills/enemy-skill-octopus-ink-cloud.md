# 墨吐き

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

沖の大ダコの固有技。真っ黒な墨を吐いて相手の目をくらまし、次の動きを読ませない。

| 実装・ゲームマスタの場所 | 未実装 |

味方全体に麻痺1を付けるだけなら[金切り声](enemy-skill-screech.md)と同じであり、この技は予告を伏せることで別の技にした。
大技の溜めを伏せないのは、[戦闘中の情報の優先順位](../../features/combat.md#戦闘中の情報の優先順位)の「予告では、特に激化ターンの大技を見せる」を守るためである。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぶわっ、もやもや |
| 本体の動き | 頭を後ろへ反らして膨らませ、勢いよく前へ縮める |
| 溜め | 頭が丸く膨らみ、肌の色が一段濃くなる |
| 発生 | 口元から黒紫の墨の雲が味方の側へ広がり、味方全体を一瞬覆う |
| 余韻 | 墨の雲は薄れながら画面の下へ沈む。予告を伏せているあいだ、大ダコの予告のアイコンの上に、小さな墨のしみを重ねて「？」を出す |
| 色 | 黒紫、濃い紺、赤紫 |
| 格 | 中 |

墨の雲は、味方のHP・状態と、敵の弱点のアイコンを長く隠さないよう、1秒ほどで薄れさせる。
