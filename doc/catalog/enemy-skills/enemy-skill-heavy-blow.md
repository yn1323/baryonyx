# 渾身の一撃

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

共通技。1ターン溜めてから、味方1人へ全力の一撃を叩き込む大技である。

## 識別情報と根拠

| 項目 | 内容 |
|---|---|
| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵を50体に増やし、文書カタログ・クライアント・サーバーにそろえる）で、既存の共通技では足りない攻撃の型として作った |
| 役割・説明 | 単体への大きな物理・打の攻撃。溜めの間に守りを固めさせる |
| 関連する仕様・個別ID | 使う敵：[岩肌トロル](../enemies/enemy-rock-troll.md)。[敵の行動の仮設定](../../features/combat-enemy-behavior.md) |
| 実装・ゲームマスタの場所 | 未実装 |

なし（すべて候補）。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ずしん、重い |
| 本体の動き | 溜めのターンに体を大きく後ろへ引き、使うターンに標的へ大きく踏み込む |
| 溜め | 溜めのターンに、体の縁が赤く光り続ける |
| 発生 | 標的に大きな衝撃の輪と、放射状の線が出る。画面を短く揺らす |
| 余韻 | 衝撃の輪の跡に砂ぼこりが残り、ゆっくり晴れる |
| 色 | 赤、橙、白 |
| 格 | 中 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [岩肌トロル](../enemies/enemy-rock-troll.md) | 溜めの光を赤にし、石柱の形の灰茶の影が標的へ振り下ろされる形にする |
