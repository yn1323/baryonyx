# 熱風の羽ばたき

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

炎尾の鳥の固有技。火口の熱い風を羽ばたきで巻き起こし、自分と仲間を風に乗せる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ばさっ、熱い風 |
| 本体の動き | 翼を大きく2回打ち下ろし、絵を少し上下させる |
| 溜め | 翼の下に熱の揺らぎが集まる |
| 発生 | 敵の足元から上へ、橙の熱い風の筋が渦を巻いて昇り、敵それぞれの縁が一度だけ明るく光る |
| 余韻 | 細かな火の粉が上へ昇って消える |
| 色 | 橙、黄、薄い灰 |
| 格 | 小 |
