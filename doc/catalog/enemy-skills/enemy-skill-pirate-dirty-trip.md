# 卑怯な足払い

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

骸骨海賊の固有技。甲板での喧嘩仕込みの汚い手で足を払い、相手の体勢を崩して、次の動きを鈍らせる。

エネルギーは味方全体で共有する資源のため、標的は1人でも、次のターンに使えるカードが味方全体で減る。
[根縛り](enemy-skill-root-bind.md)の絡みつきは1人のカードのコストを上げるが、この技はエネルギーそのものを減らす。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | すかっ、つんのめる |
| 本体の動き | 標的へ素早く滑り寄り、体を低く沈めて骨の脚で足元を払い、元の位置へ跳び戻る |
| 溜め | 帽子のつばの下で、赤い目が細く光る |
| 発生 | 標的の足元に短い横の弧と土ぼこりが出て、標的を前へ傾けて揺らす |
| 余韻 | 画面のエネルギーの表示の横に、欠けた小さな印を出し、次の味方ターンの初めに1つ分が灰色のまま埋まらない様子を見せる |
| 色 | 紺、赤、土色 |
| 格 | 小 |
