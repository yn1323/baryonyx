# 王冠の覚醒

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

死霊の魔導師の固有技で、激化の合図になる。錆びた王冠に宿る古王国の魔力が目覚め、1人へ向けた呪文が広間全体へ広がるようになる。

[刻印の目覚め](enemy-skill-sigil-awaken.md)は攻撃力を上げて激化する。
この技は、技の数も威力の倍率も変えず、当たる範囲を広げて激化する。
予告も、広げたあとの「全体攻撃」「全体の弱体」として出す。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぞわり、目覚める |
| 本体の動き | 杖を床へ突き立て、体をわずかに浮かせて上へ伸びる |
| 溜め | 王冠の宝石が1つずつ緑に灯り、ローブの裾が下から吹き上がるように広がる |
| 発生 | 王冠から緑の光の輪が2重に広がり、味方の側の床いっぱいまで届いて消える。目の光が強まる。画面の端を短く暗くする |
| 余韻 | 王冠の緑の灯りと、杖の渦の速い回転が戦闘の終わりまで残る。広げた技を使うたびに、杖の先から緑の光の輪が味方全体へ広がってから、技の演出が全員に出る |
| 色 | 緑、金、紫 |
| 格 | 大 |

暗くするのは画面の端だけにとどめ、味方のHPと敵の予告・弱点のアイコンは暗くしない。
