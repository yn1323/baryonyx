# 毒針

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

共通技。針・牙・とげから毒を流し込む物理の攻撃である。

## 識別情報と根拠

| 項目 | 内容 |
|---|---|
| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵を50体に増やし、文書カタログ・クライアント・サーバーにそろえる）で、既存の共通技では足りない攻撃の型として作った |
| 役割・説明 | 単体への物理・貫の攻撃と毒 |
| 関連する仕様・個別ID | 使う敵：[砂サソリ](../enemies/enemy-sand-scorpion.md)、[クラゲの亡霊](../enemies/enemy-ghost-jelly.md)。[敵の行動の仮設定](../../features/combat-enemy-behavior.md) |
| 実装・ゲームマスタの場所 | 未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ちくり、じわじわ |
| 本体の動き | 体をすくめてから、針の先を標的へ突き出す |
| 溜め | 針の先に、使う敵の毒の色のしずくが光る |
| 発生 | 標的に小さな刺し傷の光が出て、毒の色の泡が2〜3個浮く |
| 余韻 | 泡がはじけて消える |
| 色 | 使う敵の毒の色（紫・黄緑・青など）と白 |
| 格 | 小 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [砂サソリ](../enemies/enemy-sand-scorpion.md) | 尾の先の毒針が青く光って刺さり、毒の粒も紫ではなく青にする。 |
| [クラゲの亡霊](../enemies/enemy-ghost-jelly.md) | 桃色の細い触手が伸びて刺し、刺した点に薄紫と桃色の刺胞の粒が散る |
