# 鴉のものまね

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

墓守りの大鴉の固有技。鴉は物音や声をまねるのがうまい。直前に見た冒険者の技を、ランタンの灯りと羽ばたきでそっくりまねて返す。

まねるのは区分・属性と標的だけで、カードの状態や追加の効果はまねない。
魔法のカードをまねると属攻（1200）で返るため、魔法で攻めた直後ほど痛い。
プレイヤーは、最後に使うカードを物理の軽い攻撃にして、返しを弱める選択を持つ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | くるり、そっくり |
| 本体の動き | 首をかしげてから、まねたカードを使った味方の方へ体を向け、翼を大きく打つ |
| 溜め | 赤い目がまばたきし、ランタンの灯りの色が、まねるカードの属性の色（炎は橙、氷は水色、雷は黄、物理は白）に変わる |
| 発生 | まねたカードの演出の形を、小さく暗い色で真似た形（黒い羽根の粒をまぜる）で標的に出す |
| 余韻 | 黒い羽根の粒が数枚舞い落ち、ランタンの灯りが元の黄色へ戻る |
| 色 | 黒、濃紺、まねた属性の色 |
| 格 | 小 |

まねた演出は元のカードより小さく短くし、味方のカードの演出と見間違えないようにする。
