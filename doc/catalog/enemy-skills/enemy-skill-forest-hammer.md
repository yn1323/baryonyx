# 森羅の鉄槌

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

森の守り手の固有技。森全体の重さを両腕に込め、広間ごと叩き割る大技である。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | 圧倒的、重い |
| 本体の動き | 溜めのターンは、絵がわずかに浮き上がり、周りに木の葉と小石が浮かび、刻印が速く明滅する。発生のターンは、絵を大きく後ろへ引き上げてから前へ叩きつける |
| 溜め | 画面全体を少し暗くし、守り手だけを刻印の光で下から照らす |
| 発生 | 叩きつけた点から大きな衝撃波の輪と、根と岩の波が味方の列へ走る。白い閃光を2〜3コマ出し、強い縦揺れとヒットストップを入れる |
| 余韻 | 土煙が床を這い、木の葉が舞い落ち、味方の足元に残った割れた床の光の跡が消える |
| 色 | 淡い金、土の茶、白 |
| 格 | 大。敵の技で最も長く派手にする |
