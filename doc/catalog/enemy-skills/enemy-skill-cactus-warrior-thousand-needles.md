# 針千本

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

サボテン戦士の固有技。全身のとげを一斉に撃ち出し、鎧の隙間まで細い針を通す。

物防の高い味方ほど、ほかの攻撃との差で痛く感じる技である。
ブロックでは防げるため、プレイヤーは物防に頼らず、ブロックで受けるかを選ぶ。

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ちくちくちく、ぷすぷす |
| 本体の動き | 体を縦に縮めてから、一気に元の大きさへ伸びる |
| 溜め | 全身のとげが外へ少し伸び、黄色く光る |
| 発生 | 黄色い細い針の線が十数本、扇形に広がって標的へ集まり、標的を小刻みに揺らす |
| 余韻 | 標的の体の縁に短い針の線が数本残り、すぐ消える |
| 色 | 黄色、明るい緑、白 |
