# 壺の吸い込み

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

割れ壺の番の固有技。口を大きく開いて中の闇へ風を引き込み、相手がまとった力を呑み込んでから噛みつく。

| 実装・ゲームマスタの場所 | 未実装 |

既存の共通技・固有技に、味方の強化を消す技はない。
強化を消してからダメージを与えるため、プロテクトや無敵でこの技のダメージは防げない。
プレイヤーは、強化を付ける順番と、壺を先に倒すかを考える。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ずずっ、ごくん |
| 本体の動き | 口を大きく開いたまま、絵を後ろへ少し傾けて吸い込む。呑み込んだ瞬間に縦に少し縮む |
| 溜め | 口の奥の闇が渦を巻く |
| 発生 | 標的の状態のアイコンから色の粒がはがれ、細い流れになって壺の口へ吸い込まれる。続けて牙の跡の線を標的に出し、ダメージの数字を出す |
| 余韻 | 壺の割れ目から、吸い込んだ色の粒が一瞬だけ光ってもれ、消える |
| 色 | 黒紫、吸い込んだ強化の色 |
| 格 | 小 |
