# 霜の鎧毛

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

霜の大猿人の固有技。長毛を霜で凍らせて鎧に変え、本気で暴れ始める。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぴしぴし、凍てつく |
| 本体の動き | 両腕を振り上げて胸を張り、体を一度大きく震わせる |
| 溜め | 体の周りに白い吹雪の粒が渦を巻いて集まる |
| 発生 | 長毛の先から順に白く凍り、全身の毛の縁が氷の照り返しで光る。画面を短く揺らす |
| 余韻 | 戦闘の終わりまで、凍った毛の先から霜の粒がときどき落ちる。粒は予告と弱点のアイコンを隠さない量に抑える |
| 色 | 白、水色、薄い青 |
| 格 | 大（激化の合図） |
