# 迷い路の霧

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

霧の竜の固有技で、激化の合図になる。迷い路の最奥の止まった霧を呼び寄せ、戦いの場を冷えた霧で満たす。

[刻印の目覚め](enemy-skill-sigil-awaken.md)は攻撃力を上げ、[王冠の覚醒](enemy-skill-lich-crown-awaken.md)は行動の回数を増やして激化する。
この技は、行動のたびの継続ダメージで激化し、戦いを長引かせるほど不利になる形にした。
[激化](../../../novel/setting/battle.md#激化)の「戦いが長引くと、その場の巡りが止まり、澱が濃くなる」を、竜が自分で呼び寄せる形で表した。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | しん、止まる |
| 本体の動き | 翼を大きく広げて空を仰ぎ、長く吠える |
| 溜め | 画面の四方の端から、白い霧が中央へ向かって流れ込む |
| 発生 | 霧が一瞬止まり、画面全体の色が少しだけ青白くなる。竜の目の水色の光が強まる |
| 余韻 | 戦闘の終わりまで、画面の下の端に白い霧の帯を薄く流し続ける。竜が行動するたびに、帯から霧の粒が味方全体へ立ちのぼり、小さなダメージの数字を出す |
| 色 | 白、青白、水色 |
| 格 | 大 |

霧の帯と画面の色の変化は、味方のHP・状態と、敵の予告・弱点のアイコンを隠さない薄さに抑える。
