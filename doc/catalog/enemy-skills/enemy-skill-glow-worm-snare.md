# 光の釣り糸

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

ツチボタルの固有技。背中の光で誘い、天井から垂らした糸で、最初に動いた獲物を絡め取る。

| 役割・説明 | 次の味方のターンの最初の行動を重くする罠 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ゆらゆら、ねばっ |
| 本体の動き | 体を上へ反らし、背中の玉を順に灯す |
| 溜め | 背中の玉が頭から尾へ順に光る |
| 発生 | 味方の頭上から、青緑に光るしずくを付けた細い糸が何本も垂れ下がる |
| 余韻 | 糸は次の味方のターンまで揺れて残り、最初にカードを使った味方に巻きついて絡みつきに変わる。糸は味方のHPと状態の表示を隠さない |
| 色 | 青緑、淡い黄緑、白 |
| 格 | 小 |
