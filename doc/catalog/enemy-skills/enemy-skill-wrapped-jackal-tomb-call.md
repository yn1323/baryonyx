# 墓守の呼び覚まし

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

包帯の山犬の固有技。死者を墓へ導く番犬の声で、倒れた仲間をもう一度起き上がらせる。

共通技の仲間を呼ぶ（新しい敵を加える）とは、倒した敵を起こし直す点で分けた。
プレイヤーは、仲間より先に山犬を倒すか、起き上がりを覚悟で弱い敵から減らすかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | うおーん、よみがえる |
| 本体の動き | 頭を上げて縦に少し伸び、遠吠えのように震える |
| 溜め | 青い目の光が強まり、倒れた敵の立ち位置の床に青い円が浮かぶ |
| 発生 | 円の中から黄ばんだ包帯の帯が渦を巻いて立ち上がり、ほどけると、倒れた敵の絵が下から上へ現れる |
| 余韻 | 起き上がった敵の周りに、黄ばんだ砂の粒が少し落ちる |
| 色 | 青、包帯の黄ばんだ白、金 |
| 格 | 中 |
