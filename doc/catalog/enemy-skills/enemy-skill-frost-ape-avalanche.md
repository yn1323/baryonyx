# 雪崩おとし

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

霜の大猿人の固有技。山の斜面の雪を叩き崩し、雪崩ごと味方全体へ落とす大技。

雪に埋もれて動きにくくなった様子を、根縛りと同じ絡みつき（カードのコストが上がる）で表す。根縛りは単体だが、この技は味方全体に付ける。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | どどど、埋まる |
| 本体の動き | 溜めのターンに両腕を頭上で組み、体を後ろへ大きく反らす。使うターンに両腕を振り下ろして前へ倒れ込む |
| 溜め | 溜めのターンに、画面の上端に白い雪けむりが少しずつ溜まり、雪の粒がこぼれる |
| 発生 | 画面の上から白い雪の塊の帯が味方全体へなだれ落ち、味方を順に白く覆う。画面を大きく揺らす |
| 余韻 | 絡みつきのあいだ、味方の足元に積もった雪が薄く残り、解けるときに細かな粒になって消える。雪は味方のHPと状態の表示を隠さない |
| 色 | 白、水色、薄い灰 |
| 格 | 大 |
