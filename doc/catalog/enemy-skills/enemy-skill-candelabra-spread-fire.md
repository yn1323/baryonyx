# 延焼

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

呪いの燭台の固有技。三つの炎から火の粉をまき散らし、一行に付いたやけどを燃え広がらせる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぱちぱち、燃え広がる |
| 本体の動き | 三つの炎を大きく揺らし、絵を左右に小さく振る |
| 溜め | 三つの炎の先から、青白い火の粉が上へ噴き上がる |
| 発生 | 火の粉が弧を描いて味方全体へ降り、やけどの付いた味方では、やけどのアイコンの周りの火が一回り大きくなる |
| 余韻 | 火の粉が床で小さくはぜて消える。味方のHPと状態の表示を隠さない |
| 色 | 青白、水色、白 |
| 格 | 小 |
