# 泥の継ぎ当て

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

泥人形の固有技。自分の体の泥をちぎって仲間の傷に塗り込み、傷を埋めてやる。

森の守り手の森の恵み（自分以外の敵全体を回復）とは、1体だけを回復し、その分自分のHPを削る点で分けた。
泥人形を先に倒すか、泥人形が自分を削るのを待って仲間を倒すかを、プレイヤーが選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぺたり、塗り込む |
| 本体の動き | 腕を標的の側へ伸ばし、絵を縦に少し縮める（体の泥が減ったように見せる） |
| 溜め | 腕の先に泥のかたまりが集まる |
| 発生 | 泥のかたまりが弧を描いて標的へ飛び、標的の体の縁に貼りついて黄土色の光になって染み込む。標的に回復の数字、泥人形に減ったHPの数字を出す |
| 余韻 | 標的の足元に泥のしずくが少し落ちて消える |
| 色 | 黄土、焦げ茶、回復の淡い緑 |
| 格 | 小 |
