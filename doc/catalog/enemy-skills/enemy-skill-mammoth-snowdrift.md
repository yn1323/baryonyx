# 降り積もる雪

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

雪原のマンモスの固有技。背に雪が降り積もり続け、止まった冬の重みをまとう。

身を固める（1回のブロック）と違い、戦闘の終わりまで毎回ブロックを得る。後半の雪山のしかかりは、残っているブロックが多いほど重くなる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | しんしん、重い |
| 本体の動き | 立ち止まって鼻を高く上げ、体を少し沈める |
| 溜め | 画面の上から、マンモスの上にだけ細かな雪が降り始める |
| 発生 | 背の雪が一段厚くなり、体の縁に白い膜（ブロック）が張る。画面を短く揺らす |
| 余韻 | 戦闘の終わりまで背の上に細かな雪が降り続け、ブロックを得るたびに背の雪の縁が明るくなる。雪は予告と弱点のアイコンを隠さない量に抑える |
| 色 | 白、水色 |
| 格 | 大（激化の合図） |
