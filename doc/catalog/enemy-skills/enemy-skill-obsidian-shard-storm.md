# 黒曜の破片嵐

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

黒曜石の巨像の固有技。体中の鋭い結晶を一斉に飛ばし、味方全体を切り裂く大技。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | しゃきん、降りそそぐ |
| 本体の動き | 溜めのターンに体を丸めて結晶を逆立てる。使うターンに両腕を広げて体を開く |
| 溜め | 溜めのターンに、肩と腕の結晶が紫に光り、ひびの溶岩の光が結晶の根元へ集まる |
