# 死の回転

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

骨背の大ワニの固有技。味方1人にかみついたまま体ごと回り、沼の底へ引きずり込む大技である。

共通技の渾身の一撃（打・単体180%）より威力を下げ、代わりに行動を1回休ませる。
溜めのターンに標的を見せるため、プレイヤーは標的の味方を守るか、休む前にその味方のカードを使い切るかを選べる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぐるん、ずぶずぶ |
| 本体の動き | 溜めのターンに体を低く沈め、口をゆっくり大きく開ける。使うターンに標的へ大きく突き出し、絵を左右に2回すばやく傾けて回転を表す |
| 溜め | 溜めのターンに、標的の足元に暗い緑の渦が浮かび、ゆっくり回り続ける |
| 発生 | 標的に上下から閉じる大きな顎の白い線が出て、渦が速く回りながら標的を下へ数ドット沈める。画面を短く揺らす |
| 余韻 | 泥水のしぶきが落ち、標的は凍結のあいだ、足元に薄い泥の輪を残す。輪はHPと状態の表示を隠さない |
| 色 | 暗い緑、泥色、白 |
| 格 | 大 |
