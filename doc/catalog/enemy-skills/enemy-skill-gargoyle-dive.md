# 屋根からの急降下

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

石のガーゴイルの固有技。石の翼で高く舞い上がり、次のターンに獲物めがけて全身の重さごと落ちてくる。

[渾身の一撃](enemy-skill-heavy-blow.md)は溜めの間も単体攻撃を受けるが、この技は溜めの間、単体攻撃が当たらない。
威力は渾身の一撃より低い代わりに、溜めのターンに削られない。
プレイヤーは、全体攻撃で宙のガーゴイルを削るか、標的の味方の防御を固めるかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ばさっ、ずしん |
| 本体の動き | 1ターン目：翼を打ち下ろして、絵ごと画面の上端の外へ飛び去る。立ち位置には石の影だけが残る。2ターン目：上から標的の頭上へまっすぐ落ちてくる |
| 溜め | 1ターン目の間、標的の足元に小さな影が浮かび、少しずつ大きくなる |
| 発生 | 落ちた瞬間に、標的を大きく揺らし、床に放射状のひびの線と砂ぼこりを出して、ダメージの数字を出す |
| 余韻 | 砂ぼこりが横へ流れて消え、ガーゴイルは翼をたたんで元の立ち位置へ跳び戻る |
| 色 | 灰色、黄色、砂の茶色 |
| 格 | 中 |
