# 燃えるうろこ

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

火とかげの固有技。うろこを赤く熱し、触れた者を焼き返す。

ダメージを返すのではなく、やけどを付けて返す。プレイヤーは、この2ターンを魔法の攻撃に切り替えるか、やけどを受けて殴るかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | じりじり、熱い |
| 本体の動き | 体を低く伏せ、色を赤く明るくする |
| 溜め | 背のたてがみの炎が、うろこの上へ流れ落ちる |
| 発生 | 全身のうろこの縁が橙に光り、体の周りに陽炎の揺らぎが立つ |
| 余韻 | 揺らぎは続くあいだ薄く残る。焼き返すときは、攻撃した味方に小さな火の粉が飛ぶ |
| 色 | 赤、橙、黄 |
| 格 | 小 |
