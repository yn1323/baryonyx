# 葬送の詠唱

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

死霊の魔導師の固有技で、激化のあとに使う大技。2ターンかけて古王国の葬送の呪文を唱え、生者を死者の列へ送る冷気を広間に満たす。

[森羅の鉄槌](enemy-skill-forest-hammer.md)や[渾身の一撃](enemy-skill-heavy-blow.md)は、溜めの間に守りを固めて受ける大技である。
この技は、溜めを2ターンに延ばし、弱点（炎・打）で崩すという別の答えを持たせた。
崩す答えを持たない編成でも、2ターンあれば防御で備えられる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | 低い詠唱、しんしんと凍る |
| 本体の動き | 詠唱の2ターンは杖を高く掲げ、体を小さく上下に揺らし続ける。発動のターンに杖を前へ振り下ろす |
| 溜め | 1ターン目は足元に緑の魔法陣が浮かび、外側の輪が回り始める。2ターン目は内側の輪も回り、陣の縁から白い冷気が立ちのぼる。炎か打を受けるたびに、陣の文字が一部欠ける |
| 発生 | 味方の側の床から、青白い墓碑の形の光が並んで立ち上がり、冷気の波が味方全体を通り抜ける。画面を短く揺らす |
| 余韻 | 霜の粒が上から静かに降り、墓碑の光が床へ沈んで消える |
| 色 | 青白、緑、紫 |
| 格 | 大 |

不発になったときは、魔法陣が割れて緑の欠片になって散り、魔導師が一瞬よろめく。
崩れまでの残りは、魔法陣の欠け具合と、予告の横の小さな目盛りで見せる。
