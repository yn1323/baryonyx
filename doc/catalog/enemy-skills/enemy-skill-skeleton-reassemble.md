# 組み直し

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

骸骨兵の固有技。崩れて骨の山になっても、骨が寄り集まって組み上がり、もう一度立ち上がる。

## 識別情報と根拠

| 役割・説明 | 倒れたあとの自分の復活。崩れている間に弱点の打で砕けば止められる |
| 関連する仕様・個別ID | 使う敵：[骸骨兵](../enemies/enemy-skeleton-soldier.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |
| 実装・ゲームマスタの場所 | 未実装 |

回復の量を属攻ではなく最大HPの割合にしたのは、倒れる前の状態に関係なく、組み直したあとの手ごたえを一定にするためである。
骨の山は打以外の攻撃を受けても砕けず、ダメージも受けない。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | からから、カタカタ |
| 本体の動き | HPが0になると、絵が縦に潰れて下へ崩れ、骨の山の形（絵を下へ寄せて横に広げ、暗くしたもの）になる。組み直すときは、下から上へ伸びて元の形に戻る |
| 溜め | 骨の山のあいだ、骨が小さく震え、目の位置の橙の光が点滅する |
| 発生 | 骨の欠片の粒が周りから吸い寄せられ、下から順に組み上がる。最後に目の光が灯り、顎を1回鳴らす |
| 余韻 | 継ぎ目に橙の光の筋が残り、土ぼこりの粒が足元に落ちる |
| 色 | 黄ばんだ白、橙、土色 |
| 格 | 中 |

骨の山のあいだも、弱点のアイコンと予告（回復）を出し、打で砕けることを読み取れるようにする。
