# 舌のかすめ取り

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

沼のカエル王の固有技。長い舌を伸ばして味方を打ち、その味方に付いた強化を1つ奪って自分のものにする。

カエルが舌で虫をかすめ取る習性と、他人の物を自分の物とみなす王の性格から作った。
[壺の吸い込み](enemy-skill-urn-gulp.md)（強化をすべて消す）とは、1つだけ奪って自分のものにする点で分けた。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぺちん、かすめ取る |
| 本体の動き | 体をわずかに前へ傾け、すぐ元へ戻る |
| 溜め | 口元が一瞬ふくらむ |
| 発生 | 口から標的まで桃色の太い線（舌）が一直線に伸び、標的を短く揺らす。奪った強化があれば、そのアイコンが舌に貼りついて王のもとへ戻る |
| 余韻 | 奪った強化のアイコンが王の頭上で小さく光ってから、状態の表示に収まる |
| 色 | 桃色、白、奪った強化の色 |
| 格 | 小 |
