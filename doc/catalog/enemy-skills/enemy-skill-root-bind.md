# 根縛り

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

森の守り手の固有技。床下に張った根で、侵入者を捕らえて締めつける。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | からみつく、締めつける |
| 本体の動き | 体を前に傾け、腕を床へ押し付けるように沈む |
| 溜め | 守り手の足元から味方の側へ、床の下を何かが進むような盛り上がりの線が走る |
| 発生 | 標的の足元から根が3〜4本、らせん状に伸びて巻きつく。締まる瞬間に標的を短く揺らす |
| 余韻 | 根は絡みつきが続くあいだ薄く残り、解けるときに木屑の粒になって散る。残った根は標的のHPと状態の表示を隠さない |
| 色 | 根の茶、苔の黄緑 |
| 格 | 中 |
