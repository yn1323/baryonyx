# 八腕の乱れ打ち

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

沖の大ダコの固有技で、激化のあとに使う大技。八本の触手を同時に振るい、味方1人に2本ずつ、岩場ごと叩きつける。

1人あたりの威力（物攻の120%）は[森羅の鉄槌](enemy-skill-forest-hammer.md)（140%）より小さいが、2回に分けて当たる。
1回目でブロックが削られ、2回目がそのまま通りやすいため、薄いブロックを全員に張るより、厚いブロックやプロテクトが効く。
[地響き](enemy-skill-tremor.md)は全体に1回だけ当たる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ばしばしばし、怒涛 |
| 本体の動き | 溜めのターンに触手をすべて高く持ち上げて体を大きく見せ、使うターンに体を細かく前後へ揺らし続ける |
| 溜め | 溜めのターンに、8本の触手の先が順に赤く光り、吸盤が白く明滅する |
| 発生 | 味方1人ずつの上から、触手の形の赤紫の弧が2本、少しずらして振り下ろされ、小さな衝撃の輪と水しぶきの粒が出る。8本が短い間隔で続き、最後の1本で画面を短く揺らす |
| 余韻 | 水しぶきの粒が床に落ち、触手がゆっくり元の高さへ戻る |
| 色 | 赤紫、白、水色 |
| 格 | 大 |

2回の当たりは、どの味方がどれだけ受けたかを読み取れるよう、1回ごとに受けたダメージの数字を標的の上へ出す。
