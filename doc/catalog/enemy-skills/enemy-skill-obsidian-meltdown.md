# 溶岩のあふれ

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

黒曜石の巨像の固有技。体のひびを開いて溶岩をあふれさせ、守りを捨てて燃え上がる。

刻印の目覚めや霜の鎧毛と同じく激化の合図だが、守りを下げる代わりに攻めを強める。激化のあとは硬さが下がり、弱点の氷・打で崩しやすくなる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ごうっ、あふれる |
| 本体の動き | 両腕を広げて胸を反らし、体を一度大きくふくらませる |
| 溜め | 全身のひびの光が明るく太くなり、低くうなるように明滅する |
| 発生 | ひびから溶岩が噴き出して体の縁を流れ落ち、体の周りに橙の光の輪が広がる。画面を短く揺らす |
| 余韻 | 戦闘の終わりまで、ひびの光が明るく脈打ち、体の縁から溶岩のしずくが垂れる。光は予告と弱点のアイコンを隠さない明るさに抑える |
| 色 | 橙、黄、黒、紫 |
| 格 | 大（激化の合図） |
