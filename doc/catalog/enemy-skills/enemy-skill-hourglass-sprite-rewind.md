# 時の巻き戻し

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

砂時計の精の固有技。体の砂を逆さに流して自分の時間を巻き戻し、受けた傷をなかったことにする。

回復の量が決まっている傷ふさぎや朝露すすりとは、直前の1巡に受けたダメージだけを戻す点で分けた。
予告を見たプレイヤーは、このターンの攻撃をほかの敵へ回すか、戻せる量を超える大きなダメージで一気に倒すかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | さらさら、くるりと戻る |
| 本体の動き | 絵を左右に1回ずつ小さく傾け、最後に一瞬だけ上下を逆さにしてから戻す |
| 溜め | 体の中の青い砂が、下から上へ速く流れ始める |
| 発生 | 体の周りに時計の針のような細い金の線が2本現れ、左回りに1周する。HPのゲージが右から左へ戻るように伸びる |
| 余韻 | 青い砂の粒が数粒、上へ昇って消える |
| 色 | 青、金、白 |
| 格 | 小 |
