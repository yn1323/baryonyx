# すり抜け

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

クラゲの亡霊の固有技。亡霊の体を揺らがせ、刃や拳を素通りさせる。

ブロック（[身を固める](enemy-skill-brace.md)）は決まった量を先に引き、カードの無敵はすべてのダメージを止める。
この技は、量に関係なく物理の攻撃だけを止め、魔法は止めない。
味方に「魔法で崩す」という答えを示すための守りである。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ゆらり、透ける |
| 本体の動き | 絵の不透明度を下げ、横方向へゆっくり波打たせる |
| 溜め | なし（すぐ揺らぐ） |
| 発生 | 傘の縁から薄紫の波紋が1つ広がり、体全体が一段透ける |
| 余韻 | すり抜けが続くあいだ、体の輪郭に沿って細い波線が上へ流れ続ける。物理の攻撃が当たったときは、攻撃の形が体を素通りして後ろへ抜け、「すり抜け」の文字を出す |
| 色 | 薄紫、白、淡い桃色 |
| 格 | 小 |

透けても、弱点と予告のアイコン、HPの表示は普段の濃さで出す。
