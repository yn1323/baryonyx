# 胞子の芽吹き

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

毒胞子オオダケの固有技。胞子袋を震わせて合図を送り、相手が吸い込んだ胞子を体の中で一斉に芽吹かせる。

| 実装・ゲームマスタの場所 | 未実装 |

[胞子ばらまき](enemy-skill-spore-burst.md)は新しく毒を付けるが、この技は毒を付けず、すでに付いた毒だけを増やす。
毒を早く消した味方には効かないため、プレイヤーは毒を消すか、受けて倒しきるかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | むずむず、ぽこぽこ |
| 本体の動き | 傘を少し持ち上げ、左右の胞子袋を2回ふくらませて縮める |
| 溜め | 胞子袋の斑点が順に明るくなる |
| 発生 | 毒が付いている味方の体から、黄緑の小さな芽が2〜3本ぽこぽこと伸び、毒の数字が増える |
| 余韻 | 芽がしおれて胞子の粒になり、上へ漂って消える。芽はHPと状態の表示を隠さない |
| 色 | 黄緑、紫 |
| 格 | 中 |
