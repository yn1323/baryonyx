# 霧隠れ

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

霧の竜の固有技。体の端を霧にほどいて輪郭をぼかし、狙いを定めた攻撃をかわしやすくする。

カードのプロテクト（受けるダメージ-25%）はすべての攻撃に効くが、この技は単体攻撃にだけ大きく効く。
プレイヤーに、全体攻撃へ切り替える答えを残すための守りである。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | もや、ぼやける |
| 本体の動き | 翼を体に引き寄せ、絵の輪郭を左右にわずかにずらして重ね、ぶれたように見せる |
| 溜め | 体の周りの霧の渦が速くなる |
| 発生 | 白い霧が体を包むように広がり、体の端が霧の粒にほどける |
| 余韻 | 霧隠れのあいだ、体の縁に白い霧の粒がまとわりつき続ける。単体攻撃が当たると、攻撃の形の半分が霧に吸われてかき消える |
| 色 | 白、青灰、水色 |
| 格 | 中 |

霧は、竜の弱点と予告のアイコン、HPの表示を隠さない薄さに抑える。
