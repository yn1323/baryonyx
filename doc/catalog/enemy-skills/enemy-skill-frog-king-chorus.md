# 沼の大合唱

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

沼のカエル王の固有技。喉袋をふくらませて雷雨を呼ぶ歌を鳴き、家来が多いほど大きな雷を落とす。

共通技の放電（全体50%と麻痺）とは、状態を付けない代わりに、家来を先に倒すと弱まる点で分けた。
プレイヤーは、王を先に狙うか、取り巻きを先に減らして合唱を弱めるかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ゲコゲコ、ごろごろ |
| 本体の動き | 喉の位置を何度か横にふくらませ、最後に大きく縦へ伸びる |
| 溜め | 王と立っている敵の頭上に、小さな音符の形の光が1つずつ浮かび、上へ昇って画面の上に灰色の雲を作る |
| 発生 | 雲から味方1人ごとに細い雷が落ちる。雷の太さは敵の数で変える |
| 余韻 | 雨粒の短い線が少しだけ降り、雲が薄れて消える |
| 色 | 黄緑、白、雷の淡い黄 |
| 格 | 中 |
