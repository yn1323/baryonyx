# つらら刺し

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

つらら尾の狐の固有技。凍えて動きの鈍った獲物を、尾のつららで地面へ縫い止める。

冷たい息や氷のつぶてで付けた凍えを、凍結へ深める技である。プレイヤーは、凍えた味方がいる間はこの技を警戒し、凍えを解くか、狙われる味方を守るかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | 突き刺す、凍りつく |
| 本体の動き | 体を沈めてから小さく跳ね、尾を前へ振り下ろす |
| 溜め | 一本の尾のつららが長く伸び、先が白く光る |
| 発生 | つららが標的の足元へ斜めに突き刺さり、足元から氷の板が標的の体の下半分を包むように伸びる |
| 余韻 | 凍結のあいだ、標的の足元に氷の板が薄く残る。氷は標的のHPと状態の表示を隠さない |
| 色 | 水色、白、薄い青 |
| 格 | 中 |
