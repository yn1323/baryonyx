# 迷い火の誘い

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

鬼火の固有技。霧の中で揺らめいて味方の目を惑わせ、狙った相手とは別の相手へ手を向けさせる。

道の霧に灯って旅人を迷わせるという、鬼火の言い伝えから作った。
敵が1体だけのときは、敵を狙うカードには影響しない。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ゆらゆら、ぼんやり |
| 本体の動き | 左右に2回ゆっくり揺れ、薄くなってから元の明るさへ戻る |
| 溜め | 体の周りの小さな炎の粒が、輪になってゆっくり回る |
| 発生 | 輪の粒が細い尾を引いて標的へ流れ、標的の頭上で小さな緑の灯が3つ、ばらばらに回り始める |
| 余韻 | 惑いのあいだは、標的の頭上で緑の灯がゆっくり回り続ける。灯は標的のHPと状態の表示を隠さない |
| 色 | 黄緑、白、暗い緑 |
| 格 | 小 |
