# 種つぶて

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

かぼちゃ頭の案山子の固有技。かぼちゃの頭に詰まった硬い種を、口から勢いよく吹き散らす。

共通技の全体の物理攻撃は、打の[地響き](enemy-skill-tremor.md)と斬の[なぎ払い](enemy-skill-sweep.md)であり、貫の全体攻撃はない。
細かな粒を浴びせる攻め方として、ほかの全体攻撃より威力を低くした。
