# ふさがらない噛み傷

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

吸血大ヒルの固有技。輪になった歯で噛みつき、血を固まらせない唾を傷に流し込む。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | がぶり、じくじく |
| 本体の動き | 体を縮めてから、口を先にして標的のほうへ伸びる |
| 溜め | 口の輪が開き、歯の並びが白く光る |
| 発生 | 標的に歯の輪の形の噛み跡が出て、赤い小さな粒がにじむ |
| 余韻 | 傷口のあいだ、標的の状態の表示の横に小さな赤い輪の印を出す。回復を受けたときは、回復の光が輪の印で半分ほど消えて見えるようにする |
| 色 | 赤黒、桃色、白 |
| 格 | 小 |
