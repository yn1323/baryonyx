# 水晶角の照り返し

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

水晶角うさぎの固有技。額の水晶の角にルーンの光を宿し、向けられた攻撃を1回だけ照り返す。

既存の共通技・固有技に、敵に反射を付ける技はない。
全体攻撃ははね返さないため、プレイヤーは全体攻撃で照り返しを避けるか、弱いカードで先に照り返しを使わせるかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | きらり、ぴしっ |
| 本体の動き | 耳を立て、頭を少し上げて角を前へ向ける |
| 溜め | 角の根元から先へ、薄紫の光の線が1本走る |
| 発生 | 角の先が強く光り、体の前に薄紫の六角形の光の板が1枚浮かぶ |
| 余韻 | 光の板は照り返しが残るあいだ薄く残る。はね返すときは板が割れ、光の筋が攻撃した味方へ戻る |
| 色 | 薄紫、白 |
| 格 | 小 |
