# 畑の見張り番

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

かぼちゃ頭の案山子の固有技。畑を荒らす鳥を追い払っていたころのように、仲間に手を出した者へ藁の腕を振り下ろす。

ほかの敵の反撃の技（[とげのとぐろ](enemy-skill-thorn-coil.md)など）は自分を攻撃した味方へ返すが、この技は仲間を攻撃した味方へ返す。
案山子そのものへの攻撃と、全体攻撃には反撃しない。
プレイヤーは、先に案山子を倒すか、全体攻撃で仲間ごと削るかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぎろり、見張る |
| 本体の動き | 背を伸ばして両腕を左右へ広げ、かぼちゃの頭をゆっくり左右へ振る |
| 溜め | なし（すぐ見張りに立つ） |
| 発生 | くり抜いた目の奥が一瞬光り、仲間の敵それぞれの足元に麦わら色の小さな輪が浮かぶ |
| 余韻 | 見張りのあいだ、案山子の頭上に小さな目の印を出し続ける。反撃のときは、案山子が標的へ傾いて藁の腕を振り下ろし、藁くずの粒が散る |
| 色 | 麦わらの黄色、橙、青 |
| 格 | 小 |
