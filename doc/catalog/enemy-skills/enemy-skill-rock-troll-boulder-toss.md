# 肩石投げ

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

岩肌トロルの固有技。肩に埋まった岩をもぎ取って投げつけ、砕けた破片を周りへ飛ばす。

| 感覚の言葉 | ぶん、ばらっ |
