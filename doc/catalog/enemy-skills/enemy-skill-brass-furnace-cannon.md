# 蒼炉の砲撃

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

真鍮の番人の固有技。炉の青い炎を胸から撃ち出して味方全体を焼く。撃った反動で、自分の体も傷む。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ごおっ、焼き払う |
| 本体の動き | 溜めのターンに体を後ろへ引いて沈め、使うターンに胸を前へ突き出す |
| 溜め | 溜めのターンに、胸の炉の光が渦を巻いて小さく絞られ、体の縁が青く光り続ける |
| 発生 | 炉から太い青い炎の帯が左へ放たれ、味方全体をなめる。画面を揺らす。撃ったあと、番人の継ぎ目から火花が散り、反動のダメージの数字を出す |
| 余韻 | 青い火の粉と熱の揺らぎが床に残り、ゆっくり消える |
| 色 | 青、水色、白 |
| 格 | 大 |
