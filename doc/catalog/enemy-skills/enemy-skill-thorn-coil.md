# とげのとぐろ

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

いばら蛇の固有技。とぐろを固く巻いてとげを外へ逆立て、触れた者を傷つける。

[身を固める](enemy-skill-brace.md)のブロックより少ない代わりに、ブロックを削りにくる攻撃へダメージを返す。
プレイヤーは、ブロックを魔法やまとめた一撃で一度に割るか、ほかの敵を先に狙うかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぎしぎし、ちくり |
| 本体の動き | 鎌首を下げてとぐろの中へ縮め、絵を少し横へ縮める |
| 溜め | 蔓がきしむように、とぐろの輪郭が細かく震える |
| 発生 | 全身のとげが外へ一段伸び、体の縁に沿って茶色の薄い殻（ブロック）が張る |
| 余韻 | ブロックがある間、とげの先がときどき光る。反撃のときは、攻撃した味方の体に細い赤い引っかき傷が2本走る |
| 色 | 茶色、深緑、赤 |
| 格 | 小 |
