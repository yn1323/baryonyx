# 朽ちの呪い

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

死霊の魔導師の固有技。生者の構えた守りを、墓の土のように内側から朽ちさせる呪いを掛ける。

[打ち砕き](enemy-skill-shatter.md)の防御ダウンは受けるダメージを増やすが、この技はブロックの張りやすさを下げる。
ブロックをすでに持っている分は消さない。
状態を付けるのが主目的の技のため、基本確率は高くする案（[状態異常の付与率の仮設定](../../features/combat.md#状態異常の付与率の仮設定)）。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | じわり、朽ちる |
| 本体の動き | 骨の手を標的へ差し出し、指をゆっくり握り込む |
| 溜め | 杖の渦から、細い緑の煙が1筋、標的へ伸びる |
| 発生 | 標的の足元に緑の輪が浮かび、ひびの入った盾の形の模様が輪の内側に浮かんで崩れる |
| 余韻 | 呪いのあいだ、標的のHPの表示の横に、欠けた盾の形の小さな印を出す。標的がブロックを得るときは、ブロックの膜が半分崩れて緑の粒になる |
| 色 | くすんだ緑、灰、紫 |
| 格 | 小 |
