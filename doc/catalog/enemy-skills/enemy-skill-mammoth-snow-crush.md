# 雪山のしかかり

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

雪原のマンモスの固有技。雪を積もらせた巨体ごと前脚を上げてのしかかり、味方全体を押しつぶす大技。

威力を物攻ではなく、物防と残っているブロックで決める技である。プレイヤーは、溜めのターンにブロックを削れば大技を軽くできる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ずずん、押しつぶす |
| 本体の動き | 溜めのターンに前脚を高く上げて後ろへ反り、使うターンに前へ大きく倒れ込む |
| 溜め | 溜めのターンに、背の雪が盛り上がって白く光る |
| 発生 | 味方全体の上に巨体の影が落ち、雪の塊が叩きつけられて白い衝撃の輪が広がる。画面を大きく揺らす |
| 余韻 | 雪けむりが味方の足元から晴れ、背の雪が平らに戻る |
| 色 | 白、赤茶、水色 |
| 格 | 大 |
