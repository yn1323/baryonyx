# 火の尾羽落とし

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

炎尾の鳥の固有技。燃える尾羽を1枚、味方の足元へ落とす。尾羽は次の味方ターンの始めに燃え上がる。

カードの爆炎の刻印（次の味方ターンの開始時に爆発する）に近い、時間差の攻撃である。予告を見た味方は、尾羽が落ちる前のターンに防御を固めて備える。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ひらり、ぼっ |
| 本体の動き | 宙で体をひねり、尾を振る |
| 溜め | なし（すぐ落とす） |
| 発生 | 尾羽の炎から1枚の羽が離れ、ひらひらと味方の側の床へ落ちて、小さく燃え続ける |
| 余韻 | 次の味方ターンの開始時に、羽が大きく燃え上がって炎の柱が味方全体を包み、火の粉になって消える。燃え上がるまで、羽は味方の表示を隠さない床の手前に置く |
| 色 | 橙、黄、白の芯 |
| 格 | 中 |
