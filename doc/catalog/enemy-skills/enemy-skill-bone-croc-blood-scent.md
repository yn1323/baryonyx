# 血の匂い

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

骨背の大ワニの固有技。水に流れた血の匂いをかぎつけ、傷を負った獲物だけを執拗に狙い始める。

森の守り手の刻印の目覚め（攻撃力アップと切り替え）とは、強まる相手が出血した味方に限られる点で分けた。
出血を治すか、出血した味方を守るかで、プレイヤーが後半の被害を減らせる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | くんくん、ぎらり |
| 本体の動き | 鼻先を上げて2回小さく持ち上げ、そのあと体を低く沈める |
| 溜め | 出血している味方から、細い赤い煙の筋がワニの鼻先へ流れる |
| 発生 | 黄色い目が赤みを帯びて強く光り、背中の骨のとげの列に沿って赤い光が頭から尾へ走る |
| 余韻 | 後半のあいだ、目の赤みが残り、出血している味方の足元に小さな赤い波紋を出し続ける。波紋は標的のHPと状態の表示を隠さない |
| 色 | 赤、目の黄、骨の白 |
| 格 | 大 |
