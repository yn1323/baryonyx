# 波紋聞き

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

地底湖の盲魚人の固有技。目の代わりに水と空気の震えを聞き、いちばん多く動いた者を銛で突く。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | しん、ずぶり |
| 本体の動き | 頭を傾けて聞き入るように止まり、次に大きく前へ踏み込む |
| 溜め | 足元から水色の波紋の輪が味方の側へ広がり、標的の足元で輪が重なって止まる |
| 発生 | 骨の銛の形の白い線が一直線に標的を貫き、水しぶきが散る |
| 余韻 | しずくが落ちて床に小さな波紋を作り、消える |
| 色 | 水色、白、骨の白 |
| 格 | 中 |
