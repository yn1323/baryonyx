# 耳ざとい身かわし

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

大耳コウモリの固有技。大きな耳で、大きく振りかぶる重い攻撃の音を先に聞きつけ、ひらりとかわす。

大きく振りかぶる重いカードほど音が大きく、耳で先に聞きつけられる。コストの低いカードで崩せる。共通技の身を固める（ブロックでダメージを減らす）とは、条件に合うカードをまるごと外す点で違う。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ぴくり、ひらり |
| 本体の動き | 大きな耳をぴんと立て、絵を少し上へ浮かせる |
| 溜め | なし |
| 発生 | 耳の周りに、音を聞く小さな弧の線が2〜3重に広がる。体の周りに薄い紫の残像の輪が付く |
| 余韻 | かわしたときは、絵を素早く横へずらして元に戻し、残像を1つ残して消す。ダメージの数字の代わりに「かわした」を出す |
| 色 | 紫、白 |
| 格 | 小 |
