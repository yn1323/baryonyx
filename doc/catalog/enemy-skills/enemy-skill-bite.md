# かみつき

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

共通技。牙を持つ獣の基本の攻撃である。

## 識別情報と根拠

| 項目 | 内容 |
|---|---|
| 定義の根拠・決定日・参照元 | 2026-10-04、ユーザーの依頼（敵の技を増やし、共通化できるものも入れる）で、[苔むした狼](../enemies/enemy-moss-wolf.md)の技を共通技として作った |
| 役割・説明 | 単体への基本の物理攻撃 |
| 関連する仕様・個別ID | 使う敵：[苔むした狼](../enemies/enemy-moss-wolf.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |
| 実装・ゲームマスタの場所 | 戦闘画面のモックで、苔むした狼の攻撃として名前と単体攻撃だけを使っている（[BattleInspectAssets](../../../client/Assets/Baryonyx/Features/Combat/Editor/BattleInspectAssets.cs)の `Skill`）。ほかの効果と演出は未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | 鋭い、荒々しい |
| 本体の動き | 体を少し後ろへ引いて沈め、前へ跳んで戻る |
| 溜め | 体を沈め、目に光が点る |
| 発生 | 標的の上下から、閉じる2本の牙の弧（白い芯、赤い縁）を出す。短いヒットストップを入れる |
| 余韻 | 牙の弧が赤い残光になり、細りながら消える |
| 色 | 白、赤。目の光は使う敵の目の色 |
| 格 | 小 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [苔むした狼](../enemies/enemy-moss-wolf.md) | 目の光は黄緑 |
