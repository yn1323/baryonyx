# 吸い取り

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

共通技。牙・口・管で、味方1人の体力を吸い取る攻撃である。

## 識別情報と根拠

| 項目 | 内容 |
|---|---|
| 定義の根拠・決定日・参照元 | 2026-10-19、ユーザーの依頼（敵を50体に増やし、文書カタログ・クライアント・サーバーにそろえる）で、既存の共通技では足りない攻撃の型として作った |
| 役割・説明 | 単体への物理・貫の攻撃と、与えたダメージでの回復 |
| 関連する仕様・個別ID | 使う敵：[蜜吸い花](../enemies/enemy-nectar-bloom.md)、[大耳コウモリ](../enemies/enemy-big-eared-bat.md)、[吸血大ヒル](../enemies/enemy-blood-leech.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |
| 実装・ゲームマスタの場所 | 未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ちゅう、引き寄せる |
| 本体の動き | 標的へ身を乗り出し、体の色が少し濃くなる |
| 溜め | 口の位置が暗く光る |
| 発生 | 標的に刺さる光が出て、赤い光の粒が標的から敵の体へ流れ込む |
| 余韻 | 敵の体が一度だけ明るく光る |
| 色 | 赤、暗い赤、白 |
| 格 | 小 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [蜜吸い花](../enemies/enemy-nectar-bloom.md) | 桃色の花の奥の牙でかみつき、桃色の蜜の粒が花へ吸い込まれる |
| [大耳コウモリ](../enemies/enemy-big-eared-bat.md) | 吸い取る光を暗い赤にし、標的から細い赤い筋が牙へ流れ込む形にする |
| [吸血大ヒル](../enemies/enemy-blood-leech.md) | 輪になった歯の丸い口で吸いつき、赤い粒が橙の縞の体へ流れ込む。 |
