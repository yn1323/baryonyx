# 岩肌の再生

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

岩肌トロルの固有技。傷口に洞窟の岩が育ち、すぐに塞がる。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | みしみし、塞がる |
| 本体の動き | 体を丸めて縮め、ゆっくり元に戻す |
| 溜め | 岩肌のひびの縁が淡く光る |
| 発生 | ひびの上に小さな岩の欠片が寄り集まって塞がり、回復の数字を出す |
| 余韻 | 塞がった所から細かい砂がこぼれる。揺れは使わない |
| 色 | 灰青、灰茶、淡い緑 |
| 格 | 小 |
