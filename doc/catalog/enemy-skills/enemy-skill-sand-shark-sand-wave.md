# 砂の大波

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

砂鮫の固有技。砂の下から一気に跳ね上がり、巻き上げた砂の大波で味方全体を呑み込む大技である。

森の守り手の森羅の鉄槌（全体140%と防御ダウン）とは、受けたあとの味方の攻撃を弱める（麻痺）点で分けた。
大技のあとに反撃しにくくなるため、プレイヤーは溜めのターンに守りを固めるか、麻痺を消す手段を残しておくかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ざばあっ、ずしん |
| 本体の動き | 溜めのターンに絵を砂の中へ半分まで沈め、背びれで円を描くように左右へ動かす。使うターンに絵を上へ大きく跳ね上げ、落ちながら左へ傾ける |
| 溜め | 溜めのターンに、味方の側の床に砂の大きな渦が浮かび、ゆっくり回り続ける |
| 発生 | 画面の右から左へ、砂の厚い波の形が味方全体を横切る。波が通るときに画面を大きく揺らす |
| 余韻 | 砂の粒が雨のように落ちて、ゆっくり晴れる。麻痺のあいだは、味方の目の高さに砂の粒が少し漂う。粒はHPと状態の表示を隠さない |
| 色 | 砂色、黄土、白 |
| 格 | 大 |
