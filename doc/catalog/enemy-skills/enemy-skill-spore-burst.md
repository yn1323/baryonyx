# 胞子ばらまき

[敵の技の定義](README.md) / [関連仕様](../../features/combat.md#敵の行動の仮設定)

共通技。体に生えた苔やきのこから胞子を飛ばし、味方全体を毒にする。

## 識別情報と根拠

| 項目 | 内容 |
|---|---|
| 定義の根拠・決定日・参照元 | 2026-10-04、ユーザーの依頼（敵の技を増やし、共通化できるものも入れる）で、[苔スライム](../enemies/enemy-moss-slime.md)の技を共通技として作った |
| 役割・説明 | 味方全体に毒を重ね、長い戦闘でじわじわ削る |
| 関連する仕様・個別ID | 使う敵：[苔スライム](../enemies/enemy-moss-slime.md)。[敵の行動の仮設定](../../features/combat.md#敵の行動の仮設定) |
| 実装・ゲームマスタの場所 | 未実装 |

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | むずむず、ふわっと広がる |
| 本体の動き | 小刻みに震える（絵の幅を細かく伸び縮みさせる） |
| 溜め | 体に生えた物の上に、光の粒が集まってふくらむ |
| 発生 | 粒が山なりに飛び、味方全員の頭上で薄い雲になってゆっくり降る |
| 余韻 | 粒が味方の足元に積もり、くすんだ色に光ってから消える |
| 色 | 使う敵に生えている物の色。毒々しい紫は使わず、胞子の色で毒を表す |
| 格 | 小 |

使う敵ごとの見た目の違いは、次のとおりである。

| 敵 | 色・材質・形の違い |
|---|---|
| [苔スライム](../enemies/enemy-moss-slime.md) | 苔の黄緑とくすんだ黄。粒は背中の苔から出る |
