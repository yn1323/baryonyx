# 放電

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

共通技。体にためた雷を、味方全体へ一度に放つ魔法の攻撃である。

## 識別情報と根拠

| 項目 | 内容 |

| 役割・説明 | 全体への魔法・雷の攻撃と麻痺 |
| 関連する仕様・個別ID | 使う敵：なし（今の敵は使わない）。[敵の行動の仮設定](../../features/combat-enemy-behavior.md) |
| 実装・ゲームマスタの場所 | 未実装 |
