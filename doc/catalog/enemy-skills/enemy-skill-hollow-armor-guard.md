# 番兵の盾

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

古王国の空鎧の固有技。盾を構えて仲間の前に立ち、仲間へ向けられた攻撃を自分の鎧で受ける。

[身を固める](enemy-skill-brace.md)より自分のブロックは少ない代わりに、弱った仲間を守る。
全体攻撃は引き受けないため、プレイヤーは全体攻撃で仲間をまとめて削るか、先に空鎧を崩すかを選ぶ。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | がしゃん、立ちはだかる |
| 本体の動き | 盾を前へ突き出すように絵を少し前へ出し、構えたまま止まる |
| 溜め | 継ぎ目の紫の霧が盾のほうへ流れ集まる |
| 発生 | 盾の金の紋章が光り、空鎧から仲間それぞれへ、紫の細い鎖のような線が伸びて消える。体の縁に鉄色の薄い膜（ブロック）が張る |
| 余韻 | 引き受けている間、空鎧の足元に紫の小さな紋章が浮かぶ。仲間への攻撃が向きを変えるときは、鎖の線が一瞬見える |
| 色 | 鉄色、金、紫 |
| 格 | 小 |
