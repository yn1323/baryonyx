# 甘い蜜の香り

[敵の技の定義](README.md) / [関連仕様](../../features/combat-enemy-behavior.md)

蜜吸い花の固有技。花を大きく開いて甘い香りを漂わせ、うっとりした相手に身構えを解かせる。

次のターンの攻撃と組み合わせて、プレイヤーに防御の備えを促す前触れの技である。

## 演出

| 項目 | 内容 |
|---|---|
| 感覚の言葉 | ふわり、とろん |
| 本体の動き | 花弁を外へ大きく開き、絵をゆっくり縦に少し伸ばす |
| 溜め | 花芯の黄色が明るくなり、桃色の小さな粒がにじみ出る |
| 発生 | 桃色の薄いもやが、波打つ帯になって味方の側へゆっくり流れ、味方全員をなでるように通り過ぎる |
| 余韻 | 味方それぞれの頭上に、桃色の小さな花びらが1枚ずつ舞い落ちて消える。もやは標的と状態の表示を隠さない薄さにする |
| 色 | 桃色、黄色 |
| 格 | 小 |
