## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 場所の名前・地域ID・解放条件・推奨の強さ | 個別設定は未決 |
| 部屋・入口・分岐・次の場所とのつながり | 個別構造は未決。[部屋単位の探索](../../features/stage-progression.md#部屋単位の探索と操作)に従う |
| 敵の傾向・弱点・狙える報酬・未探索情報 | 開示範囲と個別設定は未決。[選ぶための情報](../../features/stage-progression.md#行き先を選ぶ情報)に従う |
| 敵ID・ボスID・戦闘構成 | 未決 |
| 野営地・中継地点・再出発先 | 未確定の候補。個別配置と解放条件も未決 |
| 勝敗・撤退・時間制限の有無 | 未決 |
| 報酬テーブルID・採用する場合の変異条件 | 未決 |
| 地形・建築・植生・天候・時刻・背景の奥行き | 未決 |
| 主色・光源・材質・ランドマーク・空気感 | 未決 |
| カメラ・足場・前景・敵味方の視認性 | 未決 |
| 同じ地域のステージと区別する特徴 | 未決 |

IDと配置は維持し、プレイヤーに示す場所の名前・選択情報は[探索仕様](../../features/stage-progression.md)に従う。
共通背景と扉・階段・宝箱などの差分は[アセット構成の方針](../../features/stage-progression.md#アセットを増やしすぎない構成)を参照する。

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
