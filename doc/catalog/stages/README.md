## 記入する項目

| 項目 | 初期の扱い |
|---|---|
| 地域ID・解放条件・推奨の強さ | 未決 |
| 戦闘構造・ウェーブ・敵ID・ボスID | 未決 |
| 勝敗・撤退・時間制限の有無 | 未決 |
| 報酬テーブルID・危険度・変異条件 | 未決 |
| 地形・建築・植生・天候・時刻・背景の奥行き | 未決 |
| 主色・光源・材質・ランドマーク・空気感 | 未決 |
| カメラ・足場・前景・敵味方の視認性 | 未決 |
| 同じ地域のステージと区別する特徴 | 未決 |

## 追加方法

[画像対象テンプレート](../templates/visual-entity.md)または[定義テンプレート](../templates/definition.md)をこの分類にコピーし、1対象1ファイルで記入する。
既存名・ID・画像の有無を確認し、未決欄を推測で埋めない。
追加後は[索引を再生成](../../tools/README.md)する。
