# ゲーム概要の変更と判断の記録

[ゲーム概要](overview.md)


- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、戦闘のエネルギーを「ターンごとに増える」から毎ターン決まった量に直し、実装との対応に編成・商会・神殿・ライブラリと冒険の世界地図を足した（根拠：combat.md のエネルギーとコスト、SceneNames.cs の画面）。あわせて、変更と判断の記録をこのファイルへ移した。
- 2026-10-24：ユーザーの指示「ACTボーナスという概念をすべて削除して。物事を複雑にしている」により、[ACTボーナス](../archive/step-bonus.md)を基本体験とコアループから外した。
- 2026-09-14：ユーザーの指定により正式名を「よくばり冒険団」に決定した。RPGとパーティの冒険を伝えやすく、「よくばり」が装備集め・育成・報酬と結びつくため。端末上のアプリ名、画面のブランド表記、設定案内へ反映し、内部名とApplication IDは維持する。
- 2026-09-14：ユーザーの再指定により正式名を「てくてくダンジョン」へ変更した。端末上のアプリ名と画面のブランド表記を更新し、内部名とApplication IDは維持する。
- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、情報を見て探索し、進捗を持ち越すコアループへ更新した。1戦2〜4分の一律目安を戦闘種別ごとの仮目標へ置き換え、15分の連続プレイを要求しないことを明記した。探索、戦闘、MVP、初回体験、用語集へ反映する。
- 2026-09-27：ユーザーが提示した[企画見直し](redesign-2026-09-27.md)により、ターン制のカードバトル、分岐ルートの冒険と冒険終了、歩数ボーナス、ルーンを販売しない方針へコアループを更新した。「同じ序盤のやり直しを減らす」を、序盤を作業にしない工夫の検討へ改めた。対象外の一覧から、エネルギーで置き換わった共通スキルゲージ・必殺技専用ゲージと、職業の扱いが[確認待ち](../features/party.md#確認待ち)になった転職を外した。方針が変わった主な経緯は[見直しの記録](redesign-2026-09-27.md#方針が変わった主な経緯)と各仕様の変更記録に記す。
- 2026-10-04：ユーザーの決定により、1回の冒険の長さを15〜20分の目安とし、最初のダンジョンを道中8マス、深いダンジョンを道中10〜12マスとした。マスの数はダンジョンごとのサーバーの設定値で、戦闘の長さの目安（[戦闘の長さ](../features/combat/rules.md#戦闘の長さ)）から見積もった。
- 2026-10-05：文書の整理で、冒険の長さとマスの数の写しを外して[冒険の道とマスの数](../features/stage-progression/run.md#冒険の道とマスの数)へのリンクにし、実装との対応を今の実装範囲に合わせて直した。
- 2026-10-06：ユーザーの指示により、アイテム（道具・素材）もデッキのカードになり、冒険で獲得する物に加わったため、戦闘の説明とコアループの獲得物を改めた（[アイテム](../features/items.md)）。同日、固有スキルもデッキに入ることになり、戦闘の説明に加えた（[固有スキル](../features/combat/rules.md#固有スキル)）。
