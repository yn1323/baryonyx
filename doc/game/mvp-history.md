# MVPと企画の判断基準の変更と判断の記録

[MVPと企画の判断基準](mvp.md)


- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、実装との対応の「旧戦闘の計算がコードに残る」を2026-10-26の削除に直し、探索の分岐UIを反映済みに、BGMの方向性の参照先を効果音とBGMに直した（根拠：commit 572ac9ec での CombatEncounter・CombatPrototype・CombatModel の削除、stage-progression.md の地図の作り直し、sound.md）。あわせて、変更と判断の記録をこのファイルへ移した。
- 2026-10-05：文書の整理で、ゲーム概要の未決事項と重なる2行（対象ユーザー・利用場面、短い初回プレイの操作と区切り）を外し、概要へのリンクにした。操作試作の記録は `doc/archive/` へ移した。

- 2026-09-27：ユーザーが提示した[企画見直し](redesign-2026-09-27.md)で戦闘をカードバトルへ変更したため、リアルタイム戦闘の試作範囲・検証する3場面・品質基準を現行の基準から外し、カードバトルの試作範囲と評価基準を未決とした。対象とする運動データは歩数だけになった。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| 最初の戦闘試作では、ボスの大技予告、ダウン、スロー、キャストタイム、個別クールダウンを中心に検証する。4人、各キャラのアクティブスキル2つ、固有パッシブ1つ程度、数種類の通常敵、ボス1体、少数の装備効果 | 旧戦闘の試作範囲として使わない。カードバトルの試作範囲は未決 |
| 検証する3場面（通常戦で少ない介入でも手応えがあるか、初回ボスで温存・ダウン・防護を判断できるか、強化後の再挑戦で成長を実感できるか） | 旧戦闘の評価場面として使わない |
| 品質基準（クールダウン完了のたびに全スキルを押す作業にしない、ダウンを必須にしない、キャスト後も落ち着いて攻められる、標的・濃淡・予告・ダウン表示を隠さない、無料での再挑戦を普通に選べる） | 旧戦闘の基準として使わない。情報を演出で隠さない方針は[戦闘中の情報の優先順位](../features/combat/rules.md#戦闘中の情報の優先順位)に引き継ぐ |

- 2026-09-19：ワイヤーの試用後も楽しさを判断できないというユーザー評価を受け、探索の分かりやすさと冒険を続ける動機を評価課題として追加した。参照会話で挙がった制作項目も記録し、未合意の順序・工数や15分の連続プレイを要件として確定しない。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、最初の戦闘試作、3つの検証場面、5つの品質基準を反映した。キャスト・ダウン・温存の手応えを検証するための範囲であり、ゲーム全体のMVPや完成版の数値は確定しない。戦闘とパーティの仕様からこの試作範囲を参照する。
