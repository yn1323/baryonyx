# ゲーム概要

[企画索引](README.md) / 根拠：[初期企画](brief.md)

「てくてくダンジョン」は、現実の運動が異世界側の力になる健康×ハクスラRPGである。

## 確定している方針

| 項目 | 方針 |
|---|---|
| 正式ゲーム名・アプリ表示名 | てくてくダンジョン |
| 内部コードネーム・リポジトリ名 | `baryonyx` |
| 対象 | Android先行のスマートフォンRPG |
| 基本体験 | 現実で動く → ルーンを得る → RPGで戦う・育てる → さらに運動する |
| コアループ | 運動 → ルーン獲得 → ステージ選択 → 戦闘 → 装備・素材獲得 → キャラクター・装備強化 → より高難度へ |
| 戦闘時間の目安 | 1戦2〜4分 |
| セッション時間の目安 | 15分程度 |
| 運動の位置づけ | 運動しないと遊べないゲームにはせず、運動と目標達成で成長しやすくする |
| 課金の位置づけ | 課金しないと進めない設計にはしない |

## 今回採用しない方針

街発展・街づくりは、いったん入れない。
転職、必殺技専用ゲージ、スタミナ・挑戦回数制限など、機能ごとの対象外は[各機能仕様](../features/README.md)に記す。

## 実装との対応

現在の起動経路は[健康データのローカル表示](../features/health-data.md)である。
この企画のコアループ全体が実装済みであることは意味しない。
アプリ表示名は[Player Settingsの `productName`](../../client/ProjectSettings/ProjectSettings.asset)で管理し、健康データ画面のブランド表記にも使う。
AndroidのApplication IDとAPKファイル名は[既存のビルド設定](../rules/client-android-testing.md)を維持する。
