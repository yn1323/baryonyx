# ゲーム概要

[企画索引](README.md) / [探索と進行](../features/stage-progression.md) / [戦闘システム](../features/combat.md)

「てくてくダンジョン」は、現実の運動が異世界側の力になる健康×ハクスラRPGである。
[初期企画](brief.md)と、2026-09-15にユーザーが提示した探索・進行・戦闘仕様を基にする。
個々のルールと数値は[仕様の確度](../features/README.md#仕様の確度)を区別して読む。

## 確定している方針

| 項目 | 方針 |
|---|---|
| 正式ゲーム名・アプリ表示名 | てくてくダンジョン |
| 内部コードネーム・リポジトリ名 | `baryonyx` |
| 対象 | Android先行のスマートフォンRPG |
| 基本体験 | 現実で動く → ルーンを得る → RPGで戦う・育てる → さらに運動する |
| 運動の位置づけ | 運動しないと遊べないゲームにはせず、運動と目標達成で成長しやすくする |
| 課金の位置づけ | 課金しないと進めない設計にはしない |

4人パーティで情報を見ながら進路を選び、ダンジョンを探索する。
戦闘は通常攻撃が自動、スキルが手動のセミオートとする。
敵をダウンさせて攻撃チャンスを作り、仲間の追撃や高威力スキルで爽快感を得る方向とする。
追撃の詳細は[戦闘仕様](../features/combat.md#追撃と連携の範囲)で未確定・保留として扱う。

## 設計方針

### 優先するプレイヤー体験

「短時間でも進展がある」「自分の一手が効く」「育成で以前より楽になる」「失敗しても成果を失わない」を優先する。
装備と育成で強くなり、以前勝てなかった敵の撃破や未踏の深部への到達につながる体験を目指す。
放置を主目的にせず、プレイヤーの判断が戦況を変えるゲームにする。

待ち時間、同じ序盤のやり直し、損失への不安、過剰な操作を減らす。
戦闘での判断や攻略の歯ごたえは残す。

### コアループ

```text
運動でルーンを得る／前回の装備・報酬を確認する
    ↓
必要に応じて育成・装備・編成を見直す
    ↓
探索を再開し、敵・報酬・未探索の情報から行き先を選ぶ
    ↓
戦闘・発見・お宝獲得
    ↓
先へ進む／別の道へ／装備を掘る／中断する
```

ルーンの受け取りや強化を毎戦必須の操作にはしない。
運動していない日も遊べる。
運動しない日のペナルティは設けず、運動で得たルーンが育成・強化を後押しして、以前勝てなかった相手の攻略につながるようにする。
ルーンの用途と経済数値は[ルーン経済](../features/economy.md)、冒険の継続方法は[探索と進行](../features/stage-progression.md)で管理する。

### 短いプレイの積み重ね

従来の「1セッション15分」は想定例であり、15分の連続プレイを要求しない。
短い冒険でも進捗を持ち越して再開できる形にする。
戦闘時間は、[通常敵・強敵・ボスごとの仮目標](../features/combat.md#戦闘時間の仮目標)として管理する。

## 今回採用しない方針

街発展・街づくりは、いったん入れない。
依頼、転職、共通スキルゲージ、必殺技専用ゲージ、スタミナ・挑戦回数制限など、機能ごとの対象外は[各機能仕様](../features/README.md)に記す。

## 実装との対応

現在の起動経路は[健康データのローカル表示](../features/health-data.md)である。
この企画のコアループ全体が実装済みであることは意味しない。
アプリ表示名は[Player Settingsの `productName`](../../client/ProjectSettings/ProjectSettings.asset)で管理し、健康データ画面のブランド表記にも使う。
AndroidのApplication IDとAPKファイル名は[既存のビルド設定](../rules/client-android-testing.md)を維持する。

- 2026-09-14：ユーザーの指定により正式名を「よくばり冒険団」に決定した。RPGとパーティの冒険を伝えやすく、「よくばり」が装備集め・育成・報酬と結びつくため。端末上のアプリ名、画面のブランド表記、設定案内へ反映し、内部名とApplication IDは維持する。
- 2026-09-14：ユーザーの再指定により正式名を「てくてくダンジョン」へ変更した。端末上のアプリ名と画面のブランド表記を更新し、内部名とApplication IDは維持する。
- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、情報を見て探索し、進捗を持ち越すコアループへ更新した。1戦2〜4分の一律目安を戦闘種別ごとの仮目標へ置き換え、15分の連続プレイを要求しないことを明記した。探索、戦闘、MVP、初回体験、用語集へ反映する。
