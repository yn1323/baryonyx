# ゲーム概要

[企画索引](README.md) / [探索と進行](../features/stage-progression.md) / [戦闘システム](../features/combat.md)

「てくてくダンジョン」は、現実の歩数が運動量「UPT」として異世界側の力になる健康×ハクスラRPGである。
[初期企画](brief.md)と2026-09-15のユーザー提示仕様を基に、2026-09-27の[企画見直し](redesign-2026-09-27.md)で戦闘・運動連動・ダンジョン・課金を大きく変更した。
個々のルールと数値は[仕様の確度](../features/README.md#仕様の確度)を区別して読む。

## 確定している方針

| 項目 | 方針 |
|---|---|
| 正式ゲーム名・アプリ表示名 | てくてくダンジョン |
| 内部コードネーム・リポジトリ名 | `baryonyx` |
| 対象 | Android先行のスマートフォンRPG |
| 基本体験 | 現実で歩く → ルーンとUPTボーナスを得る → RPGで戦う・育てる → さらに歩く |
| 運動の位置づけ | 運動しないと遊べないゲームにはせず、歩くほど成長しやすく、冒険を有利にする。対象は当面、歩数だけとする |
| 課金の位置づけ | 課金しないと進めない設計にはしない。ルーンは販売しない |

4人パーティで、Slay the Spireのような分岐ルートを選びながらダンジョンを進み、深奥のボスを目指す。
戦闘はターン制のカードバトルとし、4人のカードスキルを合わせたデッキと、ターンごとに増えるエネルギーで戦う。
負けると冒険は終わって次は1階からになるが、獲得した装備・スキルなどは残る。
詳細は[戦闘](../features/combat.md)と[探索と進行](../features/stage-progression.md)を正本とする。

## 設計方針

### 優先するプレイヤー体験

「短時間でも進展がある」「自分の一手が効く」「育成で以前より楽になる」「負けても獲得した装備・スキルを失わない」を優先する。
装備と育成で強くなり、以前勝てなかった敵の撃破や、より深い階への到達につながる体験を目指す。
放置を主目的にせず、プレイヤーの判断が戦況を変えるゲームにする。

待ち時間、損失への不安、過剰な操作を減らす。
負けると1階からやり直すため、序盤の階が作業にならない工夫を検討する（工夫は[未決](../features/stage-progression.md#未決事項)）。
戦闘での判断や攻略の歯ごたえは残す。

### コアループ

```text
歩いてルーンを得る／枠に入れたUPTボーナスを有効にする
    ↓
ルーンでレベルアップする／装備・カードスキル・編成を見直す
    ↓
冒険に出て、分岐ルートから行き先を選ぶ
    ↓
カードバトル・スキルと装備の獲得
    ↓
深奥のボスを目指して先へ進む／部屋の区切りで中断する
    ↓
負けたら冒険終了（獲得物は残る）、またはルーンで復活して続ける
```

ルーンの受け取りや強化を毎戦必須の操作にはしない。
運動していない日も遊べる。
歩かない日のペナルティは設けず、歩いて得たルーンと[UPTボーナス](../features/step-bonus.md)が育成と冒険を後押しする。
ルーンの用途と経済数値は[ルーン経済](../features/economy.md)、冒険の進め方は[探索と進行](../features/stage-progression.md)で管理する。

### 短いプレイの積み重ね

従来の「1セッション15分」は想定例であり、15分の連続プレイを要求しない。
冒険は部屋の区切りで中断し、次回は続きから再開できる。
1回の冒険の長さの目安は未決である（候補：15〜20分で深奥のボスまで）。

## 今回採用しない方針

街発展・街づくりは、いったん入れない。
依頼、スタミナ・挑戦回数制限など、機能ごとの対象外は[各機能仕様](../features/README.md)に記す。

## 実装との対応

現在の起動経路は、Top・Homeと[起動時の歩数の同期](../features/startup-sync.md)である。
この企画のコアループ全体が実装済みであることは意味しない。
アプリ表示名は[Player Settingsの `productName`](../../client/ProjectSettings/ProjectSettings.asset)で管理し、健康データ画面のブランド表記にも使う。
AndroidのApplication IDとAPKファイル名は[既存のビルド設定](../rules/client-android-testing.md)を維持する。

## 変更と判断の記録

- 2026-09-14：ユーザーの指定により正式名を「よくばり冒険団」に決定した。RPGとパーティの冒険を伝えやすく、「よくばり」が装備集め・育成・報酬と結びつくため。端末上のアプリ名、画面のブランド表記、設定案内へ反映し、内部名とApplication IDは維持する。
- 2026-09-14：ユーザーの再指定により正式名を「てくてくダンジョン」へ変更した。端末上のアプリ名と画面のブランド表記を更新し、内部名とApplication IDは維持する。
- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、情報を見て探索し、進捗を持ち越すコアループへ更新した。1戦2〜4分の一律目安を戦闘種別ごとの仮目標へ置き換え、15分の連続プレイを要求しないことを明記した。探索、戦闘、MVP、初回体験、用語集へ反映する。
- 2026-09-27：ユーザーが提示した[企画見直し](redesign-2026-09-27.md)により、ターン制のカードバトル、分岐ルートの冒険と冒険終了、歩数ボーナス、ルーンを販売しない方針へコアループを更新した。「同じ序盤のやり直しを減らす」を、序盤を作業にしない工夫の検討へ改めた。対象外の一覧から、エネルギーで置き換わった共通スキルゲージ・必殺技専用ゲージと、職業の扱いが[確認待ち](../features/party.md#確認待ち)になった転職を外した。方針が変わった主な経緯は[見直しの記録](redesign-2026-09-27.md#方針が変わった主な経緯)と各仕様の変更記録に記す。
