# ゲーム企画の索引

[全体索引](../README.md) → ゲーム企画

ゲーム全体の企画、世界、用語、MVPと、企画の入力の記録を置く。
システムごとのルールは[機能索引](../features/README.md)、個別のキャラ・敵・装備は[データ索引](../catalog/README.md)にある。

| 文書 | 内容 |
|---|---|
| [ゲーム概要](overview.md) | ゲームの目的、コアループ、優先するプレイヤー体験、未決事項 |
| [世界設定](world.md) | 現実と異世界の関係、主人公の目的 |
| [用語集](glossary.md) | 用語の意味と、定義している文書 |
| [MVPと企画の判断基準](mvp.md) | 最初に作る範囲、検証する価値、判断を記録する形式 |
| [初期企画の記録](brief.md) | 2026-09-13時点にユーザーが最初に提示した企画 |
| [2026-09-27の企画見直しの記録](redesign-2026-09-27.md) | 戦闘・運動連動・ダンジョン・課金を変えたときの入力と経緯 |

初期企画と企画見直しの記録は、その時点の入力を保存する資料である。
後から決まったことは各仕様へ反映し、記録は書き換えない（[正本と変更の記録](../rules/documentation-policy.md#正本と変更の記録)）。
