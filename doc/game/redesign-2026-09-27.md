# 2026-09-27の企画見直しの記録

[企画索引](README.md)

2026-09-27に開発者（ユーザー）とClaude（chat）で検討し、ユーザーが提示した企画見直しの決定事項を保存する記録である。
戦闘・運動連動・ダンジョン・課金の既存仕様を、この内容で上書きした。
反映先は各仕様の「変更と判断の記録」に記し、以後の仕様変更は各仕様で管理する。
この記録を書き換えて、後から決まった内容を過去の合意にしない。

資料の確度は「確定／設計方針／未決」で書かれている。
「未決」「候補」とした内容は、各仕様でも確定として扱わない。

## 1. 戦闘システム

### 戦闘システムの確定事項

- **ターン制のカードバトル**にする（Slay the Spire を参考）。リアルタイムのセミオート戦闘、キャラ選択時のスロー、キャストタイムは廃止。
- **ターン順**：味方パーティの合計すばやさと、敵のすばやさで決める。差が大きい場合は連続ターン（例：味方が2ターン連続）になる。
- **エネルギー**：初期3。毎ターン最大値が1増え、上限は9（シャドウバース方式）。各カードにコストがあり、使うとその分消費する。
- **手札**：持ち越し式（シャドウバース方式）。毎ターン、手札上限に満たない分だけ補充する。手動でカードを捨てられる。
- **カードの種類**：攻撃、バフ、デバフ、回復、エネルギーコスト軽減、数ターン持続する攻撃など。対象は単体と全体がある。
- **序盤は仕込みカード**で準備し、終盤に高コストの大技を使う流れにする。
- **威力**：攻撃・回復・装備は固定値を持たない。「装備したキャラのステータス〇〇の〇％」で決まる。
- **属性**：魔法は炎・氷・雷、物理は斬・打・貫。
  - キャラごとに装備できる属性が異なる。
  - 属性はカード効果の対象にもなる（例：手札の斬属性カードのコストを全て1下げる）。
  - 属性は敵の弱点にも影響する。
- **弱点**：一致で1.5倍。敵の弱点は常に画面に表示する。**耐性は設けない**。
- **ダウンは廃止**。敵の激しい攻撃は、防御を上げるなどして防ぐ。
- **敵の激化**：「〇ターン以降」のように、ターン経過で敵の攻撃を激しくしていく。
- **固有スキル**：いつでも使える枠。エネルギーを消費し、クールターンもある。
- **ダンジョン内で戦闘をまたいだエネルギーの持ち越しはしない**。

### 戦闘システムの設計方針

- カードの威力・回復量は、**装備画面の時点で実数値を表示**する（例：243ダメージ）。付け替え時は差分（例：243 → 281 ▲38）を表示する。戦闘中はバフや弱点を反映した現在値を表示する。
- 固有スキルはコスト軽め（1〜2程度）・効果控えめとし、クールターンで連打を防ぐ。残りクールターンをボタンに表示する。
- 弱点ヒット時はダメージ数字の色・大きさを変えて強調する。
- 敵の次の行動（特に激化ターンの大技）は予告として見せる。

### 戦闘システムの未決事項

- すばやさによる連続ターンの**しきい値**（TODO）。
- 手札の上限枚数。
- 手動で捨てる行為の制限（候補：1ターン1枚まで／エネルギー消費）。
- 防御の具体的な形式（候補：Slay the Spire 式の「ブロック」＝そのターンだけ有効な盾）。
- 物理属性ごとのクセ（候補：斬＝全体・連続、打＝一撃が重い、貫＝ブロックを一部無視）。
- 1ターンに使えるカード枚数の制限の有無、エネルギー以外の制約。

## 2. キャラクター・パーティ

### キャラクター・パーティの確定事項

- パーティは4人。
- 各キャラの構成：レベル、固有のステータス、パッシブスキル×2、固有スキル×2、装備（武器・防具）、カードスキル×3。
  - デッキは4人×3枚＝12枚。
- レベルアップでステータス上昇、パッシブ・固有スキルを解放する。レベルアップにはルーンを使う。
- 装備は基本的にどのキャラでも付けられる。カードスキルは、キャラごとに装備できる属性が異なる。

## 3. 運動連動

### 運動連動の確定事項

- **ルーン**：1歩＝1ルーンの変換は継続。**課金では販売しない**。1万歩を超えてもルーンは得られる。
- **運動目標（日次・週次の目標設定機能）は廃止**。下記の歩数ボーナスが目標の役割を担う。
- **対象は歩数のみ**。ランニング・サイクリング（距離・時間）は当面扱わない。Health Connect の権限も歩数のみとする。
- **日次の歩数ボーナス**
  - その日の歩数が段階に到達するたびに、ボーナスを1つ選ぶ。選んだボーナスは重ねて効かせられる。
  - 段階は上に行くほど必要歩数が大きくなる（傾斜）。最大は1万歩前後。
  - ボーナスごとに、解放に必要な歩数を設定・表示する。
  - **ランダム提示はしない**。全候補から選べる（欲しいボーナスを狙って歩けるようにする）。
  - 1日の区切りは**朝4時**。「朝4時から今までの歩数」で判定する。
  - 同じ日の中で段階が上がれば、追加で選べる。
  - 選んだボーナスは、全て**翌日の切り替え時刻（朝4時）まで有効**。
  - 歩数はホームで同期したときに反映する。
- **歩数で威力が変わるカード**を入れる（デッキに入れるかはプレイヤーの任意）。
- ホーム画面の見た目を歩数で変える演出はしない。

### 運動連動の設計方針

- 歩数ボーナスは「ボーナスのみ」とし、歩かない日のペナルティにしない。
- 未解放のボーナスも鍵付きで一覧に表示し、ホームに「あと〇歩で『〇〇』解放」を出す。
- ボーナスはカテゴリ（ドロップ系・探索系・戦闘系など）で整理する。
- 「いつものセット」を保存して、ワンタップで前回と同じ構成を選べるようにする（候補）。

### 運動連動の未決事項

- ボーナスの中身。採用候補：ドロップ率アップ（レア度アップを含む）、探索でより詳細な情報が見える（宝箱の中身、次の部屋の敵、敵が激化するターンなど）。
- 段階の具体的な歩数（候補：1,000／2,000／3,000／5,000／8,000）。参考：日本人の平均は約6,300歩/日、国の推奨は成人8,000歩/日。
- ルーン変換の日付区切り（現状0時）を、ボーナスと同じ朝4時にそろえるか。ホームの「今日の歩数」表示の区切り。
- **週次ボーナス**：歩数を消費せず、過去1週間の実績条件で解放し、1週間有効にする方向。数個の特別なボーナスに限り、タブを分ける。条件値は未決（候補：1週間で合計5万歩／8,000歩以上の日が3日）。導入時期も未決（日次だけで遊んでから判断する案あり）。

## 4. ダンジョン

### ダンジョンの確定事項

- Slay the Spire のような**分岐ルート**を選んで進む。リスクを取って強敵などに挑み、スキル・装備を獲得する。キャラのステータス〇％アップなどを重ね、深奥のボスを倒す。
- **負けたら冒険終了**。次は1階からやり直す。
- 負けても、それまでに**獲得したもの（装備・スキルなど）は保持**する。失うのは「その先のボスの報酬などを得る機会」で、これをリスクとする。
- **ルーンを使えば復活して、続きから再開**できる。
- 戦闘単位の「無料再戦」は廃止（負けたら冒険終了のため）。※開発者に最終確認

### ダンジョンの設計方針

- 復活画面では帰還も普通の選択肢として並べ、カウントダウンで急かさない。
- 部屋の区切りで中断・再開できる。

### ダンジョンの未決事項

- 冒険中に得たステータス〇％アップが、その冒険限定か永続か。
- 復活の回数制限・コスト（候補：2回目以降はコスト上昇、または1回まで）。
- 1回の冒険の長さの目安（候補：15〜20分で深奥のボスまで）。
- マップの規模・ノードの種類・部屋単位の探索画面との関係。
- 序盤の階が作業化しないための工夫（候補：序盤の敵を早く終わらせる、倍速）。

## 5. 課金

### 課金の確定事項

- ルーンは販売しない。
- 「5,000歩歩いたことにする」チケットを販売する予定（旧称：ズル休みチケット）。
  - **ルーンは増えない**。その日の歩数ボーナスだけが得られる。
  - Health Connect には書き込まない（ゲーム内だけの扱い）。

### 課金の未決事項

- チケットの5,000歩の扱い：実際の歩数への**上乗せ型**か、5,000歩未満を5,000歩として扱う**底上げ型**か。
- 名称（候補：おやすみ券、雨の日チケット）。
- 1日の使用上限、週次ボーナスの条件に算入するか、無料配布の有無。
- 召喚（ガチャ）の方式・確率・天井。

### 法務メモ（要専門家確認）

- コンプガチャ（特定の組み合わせを揃えると別アイテム）は景品表示法で禁止。
- 表示確率と実確率の不一致は景品表示法違反（優良誤認）になりうる。確率は Google Play ポリシーに従い購入場所の近くに表示する。
- ルーンを課金で得られないため、召喚は無償通貨のみのガチャになる。
- 販売するチケット自体が資金決済法の前払式支払手段に当たるかは確認が必要。

## 方針が変わった主な経緯

| 過去の案 | 現在の扱い |
|---|---|
| リアルタイムのセミオート戦闘（キャラ選択でスロー） | ターン制カードバトル |
| スキルごとのクールダウンのみ | エネルギー（3から毎ターン+1、上限9）＋カードコスト。固有スキルのみクールターンあり |
| ダウン／ダウン値／ダウン中 | 廃止。防御で受ける |
| 日次・週次の運動目標（目標枠、難易度倍率、継続倍率） | 廃止。歩数の段階ボーナスに置き換え |
| ランニング・サイクリング・距離・運動時間の利用 | 当面は歩数のみ |
| 毎回1階から潜り直す形は採用しない | 負けたら冒険終了し1階から。獲得物は保持 |
| 無料再戦＋ルーン復活 | ルーン復活のみ |
| ルーン購入を収益化の候補とする | ルーンは販売しない |
