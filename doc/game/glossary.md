# 用語集

[企画索引](README.md)

定義の入口を短く記す。
計算式・数値・詳しい制約は定義元だけで管理する。

| 用語 | 意味・現時点の扱い | 定義元 |
|---|---|---|
| ACT | ゲーム内の運動量の共通単位。読みは「アクト」で、画面では「ACT」と書く。歩数を換算して得る。自転車の距離などを扱う場合もACTへ換算する。旧称はワット・UPT | [運動データとルーン換算](../features/exercise-rewards.md#ゲーム共通の単位act) |
| ルーン | ACTから換算して得る主軸資源。レベルアップ・ルーン復活・召喚・商会での購入と強化・街道のマスを開くことに使う。販売しない。経済数値は未決 | [ルーン経済](../features/economy.md) |
| ACTボーナス | 段階ごとの枠に前もって入れておき、その日のACTが段階に届くと翌朝4時まで効くボーナス。2026-10-24に廃止した。旧称は歩数ボーナス・ワットボーナス・UPTボーナス | [ACTボーナス（記録）](../archive/step-bonus.md) |
| ACTログインボーナス | 運動目標とは別に用意するとしていた運動量による報酬。旧称は歩数ログインボーナス・ワットログインボーナス・UPTログインボーナス。扱いは確認待ち | [ルーン経済の確認待ち](../features/economy.md#確認待ち) |
| 編成 | Homeの左下から開く案内人の画面。パーティ・装備・育成・スキルを扱う。旧称は酒場。コード上の名前は `Tavern`、シーンは `Pub` | [案内人がいる画面](../features/screens/guide.md#編成商会神殿旅の案内所の画面) |
| 商会 | Homeの左下から開く案内人の画面。装備・スキル・素材の売り買い、合成、品質強化、スキル覚醒を扱う。旧称は装備の画面（その前は工房）。コード上の名前は `Workshop`、シーンは `Shop` | [商会](../features/screens/shop.md#商会) |
| 神殿 | Homeの左下から開く案内人の画面。ルーンでキャラ・装備・アイテムを召喚する。コード上の名前とシーンは `Temple` | [神殿](../features/screens/temple.md#神殿)・[召喚](../features/monetization.md#召喚) |
| ライブラリ | 手に入れた物・遭遇した敵・日々の歩数を見返す、見るだけの画面。シーンは `Library` | [ライブラリ](../features/library.md) |
| 旅の案内所 | 世界地図の右下から開く、ダンジョンの行き先を選ぶ画面。見出しは「ダンジョン一覧」。コード上の名前とシーンは `TravelOffice` | [案内人がいる画面](../features/screens/guide.md#編成商会神殿旅の案内所の画面) |
| 冒険 | 街道とダンジョンの2つの遊び方をまとめた呼び方。ダンジョンでは、1階から深奥のボスを目指す1回の挑戦を指す。負けると終了し、次は1階から。獲得物は残る | [探索と進行](../features/stage-progression/run.md#分岐ルートを選んで進む冒険) |
| マス | 冒険の分岐ルートで行き先に選ぶ探索の単位。1階ごとに1マスを通る。旧称は部屋 | [探索と進行](../features/stage-progression/run.md#冒険の道とマスの数) |
| ダンジョン | 解放した街にあり、冒険の道を毎回ランダムに作って、物を集めて育てるために何度も挑む行き先。これまでの行き先のすべて | [街道とダンジョン](../features/stage-progression/destinations.md#街道とダンジョン) |
| 街道 | 世界地図に並んだ固定のマスを1つずつクリアして新しい街を解放していく遊び方と、その地図。クリアしたマスは残る。街に着くと、その街にあるダンジョンが解放される。旧称はワールドマップの道 | [街道とダンジョン](../features/stage-progression/destinations.md#街道とダンジョン) |
| 入れ子の地図・世界地図・エリアマップ | 冒険していないときにHomeの行き先カードから開く地図。世界地図の地域のマスに止まると、その地域の細かい地図（エリアマップ）へ入る。シーンは `World` | [入れ子の地図](../features/world-atlas.md) |
| クリア | ダンジョンの最奥の主を倒して冒険を終えること。5回目まで回数ごとの報酬がある | [ダンジョンのクリア回数の報酬](../features/stage-progression/destinations.md#ダンジョンのクリア回数の報酬) |
| 限界突破・かけら | キャラが被ったときに手に入る突破のしるしで上げる段階が限界突破（コードでは `bond`、旧称は絆）。上限を超えた分は全キャラ共通のかけらになり、神殿の交換所で使う | [キャラが被ったとき](../features/monetization.md#キャラが被ったとき)・[突破](../features/screens/adventurers.md#突破) |
| 野営地・中継地点 | 帰還後の再出発地点の旧候補。1階からやり直す冒険との関係は確認待ち | [探索の確認待ち](../features/stage-progression/status.md#確認待ち) |
| ルーン復活 | ルーンを消費して復活し、冒険を続きから再開する選択。戦闘単位の無料再戦は廃止（最終確認待ち） | [敗北とルーン復活](../features/combat/rules.md#敗北とルーン復活) |
| 戦闘後の強化 | ダンジョンで戦闘に勝つたびに選ぶ、その冒険のあいだだけ効く仲間の強化 | [戦闘後の強化](../features/stage-progression/boons.md#戦闘後の強化) |
| カードバトル | 4人の固有スキル・スキル・アイテムを合わせたデッキで戦う、ターン制の戦闘 | [戦闘](../features/combat.md) |
| デッキ・手札 | デッキは4人の固有スキル・スキル・アイテムを合わせたカードの束。手札は毎ターン山札から引き、ターンの終わりに保持のカード以外は捨て札へ流れる（2026-10-25に、次のターンへ持ち越す形から改めた）。枚数・引く数・上限は定義元で決める | [戦闘](../features/combat/rules.md#手札) |
| 捨て札・流れる・捨てる | 捨て札は、使ったカードと手札から外れたカードの置き場。山札が尽きると、捨て札だけを切り混ぜて山札に戻す。ターンの終わりに手札が捨て札へ行くことを流れる、カードの効果で手札を捨て札へ送ることを捨てるという | [戦闘](../features/combat/rules.md#手札) |
| エネルギー | カード（固有スキルを含む）に払う戦闘中の資源。味方のターンの始めに決まった量に戻り、戦闘をまたいで持ち越さない（2026-10-25に、ターンごとに最大値が増える形から改めた） | [戦闘](../features/combat/rules.md#エネルギーとコスト) |
| コスト | カードを使うときに消費するエネルギーの量 | [戦闘](../features/combat/rules.md#エネルギーとコスト) |
| スキル | キャラ1人に3つあるカスタムスキルの枠に入れる、カード型の技。戦闘ではデッキのカードになる。手に入れるたびに1枚ずつ持ち、1枚ごとに倍率が違う。キャラごとに装備できる属性が異なる。固有スキル・パッシブスキルとは別に数える。旧称はカードスキル | [キャラクターの構成](../features/party.md#キャラクターの構成)・[持っているスキル](../features/party.md#持っているスキル) |
| 固有スキル | キャラ1人に3つ。レベルアップで解放する。そのキャラ専用のカードで外せず、カスタムスキルと同じくデッキに入る | [戦闘](../features/combat/rules.md#固有スキル) |
| 覚醒 | 固有スキルや持っているスキルの1枚が、冒険の中や商会で次の段階のカードに変わること。固有スキルは7つの段階のツリーで、取得した段階はずっと残り、編成でどれを使うか選ぶ。スキルは2つの枝の1段で、その1枚だけが変わる。旧称は進化 | [固有スキルの覚醒](../features/skill-evolution.md)・[カスタムスキルの覚醒](../features/skill-awakening.md) |
| 強化・品質強化 | 商会で強化素材とルーンを使って持ち物を強くすること。品質強化は磨き石で倍率を上げ、覚醒は覚醒の欠片で固有スキルとスキルを進める | [商会の強化](../features/enhancement.md) |
| 強化素材（磨き石・覚醒の欠片） | 強化に使う、個数で数える持ち物。磨き石は1種類で、品質が上がるほど1段階に使う数が増える。戦闘のカードにはならず、商会では売らない | [強化素材](../features/enhancement.md#強化素材) |
| カスタムスキル | キャラ1人に3つある、スキルかアイテムを1つずつ入れる枠と、そこに入れたカード。固有スキルと合わせてデッキに入る（1人の枚数は定義元）。旧称はスキル・アイテムの枠 | [キャラクターの構成](../features/party.md#キャラクターの構成) |
| パッシブスキル | キャラ1人に2つ。レベルアップで解放し、戦闘中に操作なしで働く。個別の効果は仮設定 | [パッシブスキル](../features/passives.md)・[パッシブ定義](../catalog/passives/README.md) |
| ステータス | HP・物攻・物防・属攻・属防・速度・会心・幸運の8つ。味方のキャラと敵が同じ項目を持つ | [ステータスの項目](../features/party.md#ステータスの項目) |
| 速度 | 味方パーティの合計と敵の値を比べて、ターン順と連続ターンを決めるステータス。旧称はすばやさ | [ターン順](../features/combat/rules.md#ターン順) |
| 属性 | 魔法の炎・氷・雷と、物理の斬・打・貫 | [属性と弱点](../features/combat/rules.md#属性と弱点) |
| 弱点 | 敵ごとの属性。一致するとダメージが増える。初めは伏せ、味方が突くと開示し、以後はその種類の敵で常に表示する。耐性は設けない | [属性と弱点](../features/combat/rules.md#属性と弱点)・[弱点の開示](../features/combat/rules.md#弱点の開示) |
| 激化 | 「〇ターン以降」のように、ターン経過で敵の攻撃が激しくなること | [防御と敵の激化](../features/combat/rules.md#防御と敵の激化) |
| 付与率 | 状態異常が付く確率。カードや技の基本確率に、使い手と相手の幸運の差による補正を足して決める。ダメージは確率によらず必ず当たる | [状態異常のかかりやすさ](../features/combat/rules.md#状態異常のかかりやすさ) |
| デイリー変異 | その日の全ユーザー共通条件として検討中の仕組み | [日付とデイリー変異](../features/daily-rules.md) |
| Affix | 装備にランダム付与する効果。個別設計は未決 | [装備](../features/equipment.md) |
| 持ち物 | 冒険や商会で手に入れて持っておく物。武器・防具・アクセサリー・スキル・アイテム・強化素材に分ける | [持ち物の分類](../features/inventory.md) |
| 装備 | 武器・防具・アクセサリーをまとめた呼び名。キャラに付け、1つずつ品質と倍率を持つ | [装備](../features/equipment.md) |
| アクセサリー | 武器・防具と同じくキャラに付ける装備。1人に最大3つで、1つ目は初めから開き、残りはレベルアップで開く。付けたキャラのステータスの底上げなどの効果を持つ | [アクセサリー](../features/equipment.md#アクセサリー) |
| アイテム | 道具・素材など、冒険で敵のドロップや宝箱から見つかる持ち物。種類ごとに個数で数える。スキルと共有するカスタムスキルの枠に入れ、戦闘ではデッキのカードになる。使っても持っている量は減らない | [アイテム](../features/items.md) |
| 道具・素材 | アイテムの種類。素材は狼の牙のように敵から取れる物。どちらも戦闘で使え、合成の材料になる | [アイテム](../features/items.md) |
| レア度 | 持ち物の種類ごとの珍しさ。☆1〜☆5で表し、☆5がもっとも手に入りにくい。強さは表さない。別名はレアリティ。廃止したACTボーナスでは旧称をランク（S〜E）とした | [レア度](../features/inventory.md#レア度) |
| 品質 | スキル・装備の1つずつの強さ。種類ごとの倍率の幅の中の位置で、S・A・B・Cの4段階で表す。英語はQuality | [品質](../features/inventory.md#品質) |
| 倍率 | スキル・装備が1つずつ持つ値。×1.00から種類ごとの上限までの間で決まり、高さを品質で表す | [品質](../features/inventory.md#品質) |
| 合成 | 素材・道具・武器・防具・アクセサリー・スキルを材料に、より良い物を作ること。商会で行う | [合成](../features/synthesis.md) |
| Health Connect | Androidの健康データ取得元。求める権限は歩数の読み取りだけとする | [取得の企画](../features/exercise-rewards.md)・[現行実装](../features/health-data.md) |
| セッション | 一続きのプレイ。15分は想定例で、連続プレイの要求時間ではない。認証・運動セッションとは区別する | [ゲーム概要](overview.md) |
| ハクスラ | 周回と装備厳選で強化・構成を楽しむ本作の方向性 | [装備](../features/equipment.md) |
| HD-2D寄り | 本作の画面表現の方向。Top・Home・戦闘画面は3Dの地面と背景にドット絵のキャラを立たせる3Dの舞台で描く。ほかの画面の描画方式は未決 | [アート方針](../art/direction.md)・[3Dの舞台](../art/hd2d-stage.md) |

新語は名称・意味・定義元を追加する。
別名を使う場合は同じ行に記し、同じ仕組みを別の用語として重複定義しない。
