# 用語集

[企画索引](README.md)

定義の入口を短く記す。
計算式・数値・詳しい制約は定義元だけで管理する。

| 用語 | 意味・現時点の扱い | 定義元 |
|---|---|---|
| ルーン | 現実活動から得る主軸資源。育成を後押しし、任意の戦闘復活にも使う。経済数値は未決 | [ルーン経済](../features/economy.md) |
| 運動目標 | 日次・週次各1枠の任意の活動条件 | [目標](../features/goals.md) |
| 目標枠 | 条件を編集・削除・再設定しても継続履歴を保持する日次・週次の単位 | [目標の編集](../features/goals.md#編集削除再設定) |
| 目標の難易度倍率 | 目標量・期間・時間帯などの条件から決める倍率。計算式は未決 | [難易度](../features/goals.md#目標条件の難易度) |
| 継続倍率 | 日次・週次それぞれの直近の達成実績から決める倍率 | [継続実績](../features/goals.md#継続倍率に使う実績) |
| 歩数ログインボーナス | 目標とは別に用意する歩数による報酬。具体的な条件・量は未決 | [ルーン経済](../features/economy.md#目標報酬と歩数ログインボーナス) |
| 部屋 | 入口を選んで進む探索の単位 | [探索と進行](../features/stage-progression.md) |
| 野営地・中継地点 | 帰還後の再出発地点の候補。採否と解放条件は未確定 | [再出発の候補](../features/stage-progression.md#中断再出発周回の候補) |
| デイリー変異 | その日の全ユーザー共通条件として検討中の仕組み | [日付とデイリー変異](../features/daily-rules.md) |
| Affix | 装備にランダム付与する効果。個別設計は未決 | [装備](../features/equipment.md) |
| パッシブ | キャラなどが持つ効果。個別の発動条件は未決 | [パッシブ定義](../catalog/passives/README.md) |
| アクティブスキル | プレイヤーが操作して使う戦闘能力 | [戦闘](../features/combat.md) |
| クールダウン | 使用したスキルが再使用可能になるまでの個別の待ち時間 | [戦闘](../features/combat.md#アクティブスキルと個別クールダウン) |
| キャストタイム | スキル使用確定から最初の効果発生までの内部時間。演出全体の長さとは分ける | [戦闘](../features/combat.md#キャストタイムの定義) |
| ダウン | 敵のダウン残量をゼロにして、行動停止と被HPダメージ増加を生む仕組み・成立 | [戦闘](../features/combat.md#ダウンの名称と基本ルール) |
| ダウン値 | 攻撃・スキルが敵のダウン残量を削る性能 | [戦闘](../features/combat.md#ダウンの名称と基本ルール) |
| ダウン中 | ダウンが成立している状態 | [戦闘](../features/combat.md#ダウンの名称と基本ルール) |
| ダウンゲージ・ダウンリング | ゲージは敵側残量の内部の呼び方。リングはその表示 | [戦闘UI](../features/combat.md#hpバーとダウンリング) |
| 追撃 | 一部キャラ・装備の技やパッシブとして追加する方向の行動。詳細は保留 | [戦闘](../features/combat.md#追撃と連携の範囲) |
| 無料再戦・ルーン復活 | 戦闘を最初からやり直す選択と、削った敵HP・ダウン残量を維持して続ける選択 | [再戦と復活](../features/combat.md#無料再戦とルーン復活) |
| Health Connect | Androidの健康データ取得元 | [取得の企画](../features/exercise-rewards.md)・[現行実装](../features/health-data.md) |
| MET | 簡略な活動強度補正の発想として参照する概念。換算式は未決 | [運動報酬](../features/exercise-rewards.md) |
| セッション | 一続きのプレイ。15分は想定例で、連続プレイの要求時間ではない。認証・運動セッションとは区別する | [ゲーム概要](overview.md) |
| ハクスラ | 周回と装備厳選で強化・構成を楽しむ本作の方向性 | [装備](../features/equipment.md) |
| HD-2D寄り | 本作の画面表現の方向。描画方式・具体規格は未決 | [アート方針](../art/direction.md) |

新語は名称・意味・定義元を追加する。
別名を使う場合は同じ行に記し、同じ仕組みを別の用語として重複定義しない。

## 変更と判断の記録

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、ダウン、キャスト、再戦などの定義元を追加した。共通スキルゲージと危険度選択を現行用語から外し、旧案は各正本の変更記録で扱う。セッションの15分は想定例として記す。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、目標枠・難易度倍率・継続倍率・歩数ログインボーナスの定義元を追加した。具体的な倍率と報酬量は各正本の仮設定・未決事項を参照する。
