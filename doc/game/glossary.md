# 用語集

[企画索引](README.md)

定義の入口を短く記す。
計算式・数値・詳しい制約は定義元だけで管理する。

| 用語 | 意味・現時点の扱い | 定義元 |
|---|---|---|
| ACT | ゲーム内の運動量の共通単位。読みは「アクト」で、画面では「ACT」と書く。歩数を換算して得る。自転車の距離などを扱う場合もACTへ換算する。旧称はワット・UPT | [運動データとルーン換算](../features/exercise-rewards.md#ゲーム共通の単位act) |
| ルーン | ACTから換算して得る主軸資源。レベルアップとルーン復活に使う。販売しない。経済数値は未決 | [ルーン経済](../features/economy.md) |
| ACTボーナス | 段階ごとの枠に前もって入れておき、その日のACTが段階に届くと翌朝4時まで効くボーナス。2026-10-24に廃止した。旧称は歩数ボーナス・ワットボーナス・UPTボーナス | [ACTボーナス（記録）](../archive/step-bonus.md) |
| ACTログインボーナス | 運動目標とは別に用意するとしていた運動量による報酬。旧称は歩数ログインボーナス・ワットログインボーナス・UPTログインボーナス。扱いは確認待ち | [ルーン経済の確認待ち](../features/economy.md#確認待ち) |
| 編成 | Homeの左下から開く案内人の画面。パーティ・装備・育成・スキルを扱う。旧称は酒場。コード上の名前は `Tavern`、シーンは `Pub` | [案内人がいる画面](../features/screens/guide.md#編成商会神殿旅の案内所の画面) |
| 商会 | Homeの左下から開く案内人の画面。装備・スキル・素材の売り買いと合成を扱う。旧称は装備の画面（その前は工房）。コード上の名前は `Workshop`、シーンは `Shop` | [商会](../features/screens/shop.md#商会) |
| 冒険 | 街道とダンジョンの2つの遊び方をまとめた呼び方。ダンジョンでは、1階から深奥のボスを目指す1回の挑戦を指す。負けると終了し、次は1階から。獲得物は残る | [探索と進行](../features/stage-progression.md#分岐ルートを選んで進む冒険) |
| マス | 冒険の分岐ルートで行き先に選ぶ探索の単位。1階ごとに1マスを通る。旧称は部屋 | [探索と進行](../features/stage-progression.md#冒険の道とマスの数) |
| ダンジョン | 解放した街にあり、冒険の道を毎回ランダムに作って、物を集めて育てるために何度も挑む行き先。これまでの行き先のすべて | [街道とダンジョン](../features/stage-progression.md#街道とダンジョン) |
| 街道 | 世界地図に並んだ固定のマスを1つずつクリアして新しい街を解放していく遊び方と、その地図。クリアしたマスは残る。街に着くと、その街にあるダンジョンが解放される。旧称はワールドマップの道 | [街道とダンジョン](../features/stage-progression.md#街道とダンジョン) |
| クリア | ダンジョンの最奥の主を倒して冒険を終えること。5回目まで回数ごとの報酬がある | [ダンジョンのクリア回数の報酬](../features/stage-progression.md#ダンジョンのクリア回数の報酬) |
| 絆・かけら | キャラが被ったときに上がる段階が絆。上限を超えた分は全キャラ共通のかけらになり、神殿の交換所で使う | [キャラが被ったとき](../features/monetization.md#キャラが被ったとき) |
| 野営地・中継地点 | 帰還後の再出発地点の旧候補。1階からやり直す冒険との関係は確認待ち | [探索の確認待ち](../features/stage-progression.md#確認待ち) |
| ルーン復活 | ルーンを消費して復活し、冒険を続きから再開する選択。戦闘単位の無料再戦は廃止（最終確認待ち） | [敗北とルーン復活](../features/combat.md#敗北とルーン復活) |
| カードバトル | 4人の固有スキル・スキル・アイテムを合わせたデッキで戦う、ターン制の戦闘 | [戦闘](../features/combat.md) |
| デッキ・手札 | デッキは4人の固有スキル・スキル・アイテムを合わせたカードの束。手札は次のターンへ持ち越す。枚数・引く数・上限は定義元で決める | [戦闘](../features/combat.md#手札) |
| エネルギー | カード（固有スキルを含む）に払う戦闘中の資源。ターンごとに最大値が増え、戦闘をまたいで持ち越さない | [戦闘](../features/combat.md#エネルギーとコスト) |
| コスト | カードを使うときに消費するエネルギーの量 | [戦闘](../features/combat.md#エネルギーとコスト) |
| スキル | キャラ1人に2つあるカスタムスキルの枠に入れる、カード型の技。戦闘ではデッキのカードになる。手に入れるたびに1枚ずつ持ち、1枚ごとに倍率が違う。キャラごとに装備できる属性が異なる。固有スキル・パッシブスキルとは別に数える。旧称はカードスキル | [キャラクターの構成](../features/party.md#キャラクターの構成)・[持っているスキル](../features/party.md#持っているスキル) |
| 固有スキル | キャラ1人に2つ。そのキャラ専用のカードで外せず、カスタムスキルと同じくデッキに入る | [戦闘](../features/combat.md#固有スキル) |
| 覚醒 | 固有スキルが冒険の中や商会で、7つの段階を持つツリーの次の段階のカードに変わること。取得した段階はずっと残り、編成でどれを使うか選ぶ。旧称は進化 | [固有スキルの覚醒](../features/skill-evolution.md) |
| 強化・品質強化 | 商会で強化素材とルーンを使って持ち物を強くすること。品質強化は磨き石で倍率を上げ、覚醒は覚醒の欠片で固有スキルを進める | [商会の強化](../features/enhancement.md) |
| 強化素材（磨き石・覚醒の欠片） | 強化に使う、個数で数える持ち物。磨き石は色で上げ幅が変わる。戦闘のカードにはならず、商会では売らない | [強化素材](../features/enhancement.md#強化素材) |
| カスタムスキル | キャラ1人に2つある、スキルかアイテムを1つずつ入れる枠と、そこに入れたカード。固有スキル2枚と合わせた1人4枚がデッキに入る。旧称はスキル・アイテムの枠 | [キャラクターの構成](../features/party.md#キャラクターの構成) |
| パッシブスキル | キャラ1人に2つ。レベルアップで解放し、戦闘中に操作なしで働く。個別の効果は仮設定 | [パッシブスキル](../features/passives.md)・[パッシブ定義](../catalog/passives/README.md) |
| ステータス | HP・物攻・物防・属攻・属防・速度・会心・幸運の8つ。味方のキャラと敵が同じ項目を持つ | [ステータスの項目](../features/party.md#ステータスの項目) |
| 速度 | 味方パーティの合計と敵の値を比べて、ターン順と連続ターンを決めるステータス。旧称はすばやさ | [ターン順](../features/combat.md#ターン順) |
| 属性 | 魔法の炎・氷・雷と、物理の斬・打・貫 | [属性と弱点](../features/combat.md#属性と弱点) |
| 弱点 | 敵ごとの属性。一致するとダメージが増える。初めは伏せ、味方が突くと開示し、以後はその種類の敵で常に表示する。耐性は設けない | [属性と弱点](../features/combat.md#属性と弱点)・[弱点の開示](../features/combat.md#弱点の開示) |
| 激化 | 「〇ターン以降」のように、ターン経過で敵の攻撃が激しくなること | [防御と敵の激化](../features/combat.md#防御と敵の激化) |
| 付与率 | 状態異常が付く確率。カードや技の基本確率に、使い手と相手の幸運の差による補正を足して決める。ダメージは確率によらず必ず当たる | [状態異常のかかりやすさ](../features/combat.md#状態異常のかかりやすさ) |
| デイリー変異 | その日の全ユーザー共通条件として検討中の仕組み | [日付とデイリー変異](../features/daily-rules.md) |
| Affix | 装備にランダム付与する効果。個別設計は未決 | [装備](../features/equipment.md) |
| 持ち物 | 冒険や商会で手に入れて持っておく物。武器・防具・アクセサリー・スキル・アイテム・強化素材に分ける | [持ち物の分類](../features/inventory.md) |
| 装備 | 武器・防具・アクセサリーをまとめた呼び名。キャラに付け、1つずつ品質と倍率を持つ | [装備](../features/equipment.md) |
| アクセサリー | 武器・防具と同じくキャラに付ける装備。1人に最大3つで、初めは0枠からレベルアップで枠が開く。付けたキャラのステータスの底上げなどの効果を持つ | [アクセサリー](../features/equipment.md#アクセサリー) |
| アイテム | 道具・素材など、冒険で敵のドロップや宝箱から見つかる持ち物。種類ごとに個数で数える。スキルと共有する2つの枠に入れ、戦闘ではデッキのカードになる。使っても持っている量は減らない | [アイテム](../features/items.md) |
| 道具・素材 | アイテムの種類。素材は狼の牙のように敵から取れる物。どちらも戦闘で使え、合成の材料になる | [アイテム](../features/items.md) |
| レア度 | 持ち物の種類ごとの珍しさ。☆1〜☆5で表し、☆5がもっとも手に入りにくい。強さは表さない。別名はレアリティ。廃止したACTボーナスでは旧称をランク（S〜E）とした | [レア度](../features/inventory.md#レア度) |
| 品質 | スキル・装備の1つずつの強さ。種類ごとの倍率の幅の中の位置で、S・A・B・Cの4段階で表す。英語はQuality | [品質](../features/inventory.md#品質) |
| 倍率 | スキル・装備が1つずつ持つ値。×1.00から種類ごとの上限までの間で決まり、高さを品質で表す | [品質](../features/inventory.md#品質) |
| 合成 | 素材・道具・武器・防具・アクセサリー・スキルを材料に、より良い物を作ること。商会で行う | [合成](../features/synthesis.md) |
| Health Connect | Androidの健康データ取得元。求める権限は歩数の読み取りだけとする | [取得の企画](../features/exercise-rewards.md)・[現行実装](../features/health-data.md) |
| セッション | 一続きのプレイ。15分は想定例で、連続プレイの要求時間ではない。認証・運動セッションとは区別する | [ゲーム概要](overview.md) |
| ハクスラ | 周回と装備厳選で強化・構成を楽しむ本作の方向性 | [装備](../features/equipment.md) |
| HD-2D寄り | 本作の画面表現の方向。描画方式・具体規格は未決 | [アート方針](../art/direction.md) |

新語は名称・意味・定義元を追加する。
別名を使う場合は同じ行に記し、同じ仕組みを別の用語として重複定義しない。

## 変更と判断の記録

- 2026-10-24：ユーザーの指示で、ACTボーナスを廃止し、「5,000ACT分運動したことにする」チケットの販売予定を取りやめたため、チケットの行を削除し、ACTボーナスを廃止した用語として残した。
- 2026-10-23：ユーザーとの相談で決めた街道・ダンジョンのクリア回数の報酬・キャラが被ったときの扱いに合わせ、ダンジョン・街道・クリア・絆とかけらを加えた。

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位「ワット」を追加し、単位としての「歩」を使わないことにした。今後、自転車の距離なども同じ単位で扱うためである。歩数ボーナス・歩数ログインボーナス・チケットの名称をワットへ改め、旧称を同じ行に記した。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、ダウン、キャスト、再戦などの定義元を追加した。共通スキルゲージと危険度選択を現行用語から外し、旧案は各正本の変更記録で扱う。セッションの15分は想定例として記す。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、目標枠・難易度倍率・継続倍率・歩数ログインボーナスの定義元を追加した。具体的な倍率と報酬量は各正本の仮設定・未決事項を参照する。

- 2026-09-19：ダウンリングを現行用語から外し、濃淡・状態変化による表示へ参照を揃えた。

- 2026-09-27：[企画見直し](redesign-2026-09-27.md)に合わせ、カードバトル（デッキ、手札、エネルギー、コスト、カードスキル、固有スキル、クールターン、すばやさ、属性、弱点、激化）、冒険、歩数ボーナス、チケットの定義元を追加した。廃止した運動目標・目標枠・難易度倍率・継続倍率、アクティブスキル・クールダウン・キャストタイム・ダウン・ダウン値・ダウン中・ダウンゲージ・追撃・無料再戦を現行用語から外した。MET（活動強度の補正）は歩数だけを扱うため外した。旧案は各正本の変更記録で扱う。

- 2026-09-28：ユーザーの指示により、ゲーム内の運動量の単位の名前を「ワット」から「UPT」へ改めた。ワットとルーンなどの用語が分かりにくいという検討を受けた判断である。自転車・ランニングの距離などもUPTへ換算する方針は変えない。1歩＝1UPT、1UPT＝1ルーンとし、換算量は変えない。ワットボーナス・ワットログインボーナス・チケットの名称をUPTへ改め、旧称を同じ行に記した。ルーンの名前は変えない。

- 2026-09-29：ユーザーの指示により、弱点の定義を「常に表示」から「初めは伏せ、味方が突くと開示し、以後はその種類の敵で常に表示」へ改めた（[弱点の開示](../features/combat.md#弱点の開示)）。

- 2026-09-29：UPTの略さない形を確認したところ、ユーザーの指示により「UPT」そのものを正式な名称とした。

- 2026-10-04：ユーザーの指示により、UPTボーナスの定義を「段階に届くたびに1つ選ぶ」から「段階ごとの枠に前もって入れておく」へ改めた（[UPTボーナス](../archive/step-bonus.md#日次のactボーナス)）。

- 2026-10-04：ユーザーの指示により、「カードスキル」の呼び名を「スキル」に改め、旧称として残した。カード型であることは定義に書き、戦闘の手札・山札としては引き続き「カード」と呼ぶ。あわせて、装備する枚数を[キャラクターの構成](../features/party.md#キャラクターの構成)に合わせて3枚から4枚に直した。

- 2026-10-04：ユーザーの指示により、ステータスの項目をHP・物攻・物防・属攻・属防・速度・会心・幸運の8つとし、味方と敵で同じにした（[ステータスの項目](../features/party.md#ステータスの項目)）。ターン順を決めるステータスの名前を「すばやさ」から「速度」に改め、旧称として残した。

- 2026-10-04：探索を森を見下ろす地図で進む形へ改めたことに合わせ、「部屋」の定義を、入口を選ぶ単位から、分岐ルートで行き先に選ぶ単位へ改めた（[探索とダンジョンの進行](../features/stage-progression.md#ダンジョン内の見た目による行き先選択)）。

- 2026-10-04：ユーザーの決定で状態異常に確率を設けたため、付与率を加えた（[状態異常のかかりやすさ](../features/combat.md#状態異常のかかりやすさ)）。

- 2026-10-04：ユーザーの指示により、ゲーム内の運動量の単位の名前を「UPT」から「ACT」（読みはアクト）へ改めた。UPTは「うんどーポイント」の略として付けた名前で、響きを見直した。画面の表記は「ACT」とする。換算は1歩＝1ACT、1ACT＝1ルーンで変えない。UPTボーナス・UPTログインボーナス・チケットの名称をACTへ改め、旧称を同じ行に記した。

- 2026-10-05：文書の整理で、定義元にある数値の写し（デッキの枚数と引く数、エネルギーの増え方、弱点の倍率、ACTとルーンの換算）を外し、定義元へのリンクだけにした。同日の画面名の変更に合わせ、編成（旧称：酒場）と商会（旧称：装備の画面）を加えた。

- 2026-10-06：ユーザーの指示により、持ち物・装備・アクセサリー・アイテム・道具・素材・レア度・倍率・合成を加えた（[持ち物の分類](../features/inventory.md)）。ACTボーナスのランクをレア度（☆）にそろえ、旧称として残した。アイテムもデッキのカードになるため、カードバトルとデッキの定義を改めた。同日、固有スキルもデッキのカードになり、1人の4枚が固有スキル2枚とスキル・アイテムの2枠になったため、スキル・固有スキル・エネルギー・コストの定義を改め、クールターンを外した（[固有スキル](../features/combat.md#固有スキル)）。

- 2026-10-19：ユーザーの指示により、品質を加え、レア度を種類ごとの珍しさとして強さと切り離した。倍率の定義を品質に合わせた（[品質](../features/inventory.md#品質)）。

- 2026-10-21：ユーザーの依頼「今までは部屋って言い方してたけど、マスって言い方で統一したい」により、探索の単位の呼び方を「部屋」から「マス」に改め、「部屋」を旧称として残した（[冒険の道とマスの数](../features/stage-progression.md#冒険の道とマスの数)）。
