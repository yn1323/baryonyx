# 用語集

[企画索引](README.md)

定義の入口を短く記す。
計算式・数値・詳しい制約は定義元だけで管理する。

| 用語 | 意味・現時点の扱い | 定義元 |
|---|---|---|
| ワット | ゲーム内の運動量の共通単位。歩数は1歩＝1ワットで換算する。自転車の距離などを扱う場合もワットへ換算する。実際の電力の単位ではない | [運動データとルーン換算](../features/exercise-rewards.md#ゲーム共通の単位ワット) |
| ルーン | ワットから1ワット1ルーンで得る主軸資源。レベルアップとルーン復活に使う。販売しない。経済数値は未決 | [ルーン経済](../features/economy.md) |
| ワットボーナス | その日のワットが段階に届くたびに1つ選び、翌朝4時まで効くボーナス。運動目標の役割を担う。旧称は歩数ボーナス | [ワットボーナス](../features/step-bonus.md) |
| 週次ボーナス | 過去1週間の実績条件で解放し、1週間有効にする方向の特別なボーナス。採否と条件は未決 | [ワットボーナス](../features/step-bonus.md#未決事項) |
| 「5,000ワット分運動したことにする」チケット | 販売予定の商品。その日のワットボーナスだけを得られ、ルーンは増えない。旧称はズル休みチケット・「5,000歩歩いたことにする」チケット、名称は未決 | [課金](../features/monetization.md#5000ワット分運動したことにするチケット) |
| ワットログインボーナス | 運動目標とは別に用意するとしていた運動量による報酬。旧称は歩数ログインボーナス。ワットボーナスとの関係は確認待ち | [ルーン経済の確認待ち](../features/economy.md#確認待ち) |
| 冒険 | 1階から深奥のボスを目指す1回の挑戦。負けると終了し、次は1階から。獲得物は残る | [探索と進行](../features/stage-progression.md#分岐ルートを選んで進む冒険) |
| 部屋 | 入口を選んで進む探索の単位 | [探索と進行](../features/stage-progression.md) |
| 野営地・中継地点 | 帰還後の再出発地点の旧候補。1階からやり直す冒険との関係は確認待ち | [探索の確認待ち](../features/stage-progression.md#確認待ち) |
| ルーン復活 | ルーンを消費して復活し、冒険を続きから再開する選択。戦闘単位の無料再戦は廃止（最終確認待ち） | [敗北とルーン復活](../features/combat.md#敗北とルーン復活) |
| カードバトル | 4人のカードスキルを合わせたデッキで戦う、ターン制の戦闘 | [戦闘](../features/combat.md) |
| デッキ・手札 | デッキは4人×カードスキル3枚＝12枚。手札は次のターンへ持ち越し、上限まで補充する | [戦闘](../features/combat.md#手札) |
| エネルギー | カードと固有スキルに払う戦闘中の資源。初期3、毎ターン最大値+1、上限9。戦闘をまたいで持ち越さない | [戦闘](../features/combat.md#エネルギーとコスト) |
| コスト | カード・固有スキルを使うときに消費するエネルギーの量 | [戦闘](../features/combat.md#エネルギーとコスト) |
| カードスキル | キャラ1人に3枚装備するカード。キャラごとに装備できる属性が異なる | [キャラクターの構成](../features/party.md#キャラクターの構成) |
| 固有スキル | キャラ1人に2つ。手札とは別の枠からいつでも使え、エネルギーとクールターンを持つ | [戦闘](../features/combat.md#固有スキル) |
| クールターン | 固有スキルを再使用できるまでのターン数 | [戦闘](../features/combat.md#固有スキル) |
| パッシブスキル | キャラ1人に2つ。レベルアップで解放する。個別の発動条件は未決 | [キャラクターの構成](../features/party.md#キャラクターの構成)・[パッシブ定義](../catalog/passives/README.md) |
| すばやさ | 味方パーティの合計と敵の値を比べて、ターン順と連続ターンを決めるステータス | [ターン順](../features/combat.md#ターン順) |
| 属性 | 魔法の炎・氷・雷と、物理の斬・打・貫 | [属性と弱点](../features/combat.md#属性と弱点) |
| 弱点 | 敵ごとの属性。一致するとダメージ1.5倍。常に表示し、耐性は設けない | [属性と弱点](../features/combat.md#属性と弱点) |
| 激化 | 「〇ターン以降」のように、ターン経過で敵の攻撃が激しくなること | [防御と敵の激化](../features/combat.md#防御と敵の激化) |
| デイリー変異 | その日の全ユーザー共通条件として検討中の仕組み | [日付とデイリー変異](../features/daily-rules.md) |
| Affix | 装備にランダム付与する効果。個別設計は未決 | [装備](../features/equipment.md) |
| Health Connect | Androidの健康データ取得元。求める権限は歩数の読み取りだけとする | [取得の企画](../features/exercise-rewards.md)・[現行実装](../features/health-data.md) |
| セッション | 一続きのプレイ。15分は想定例で、連続プレイの要求時間ではない。認証・運動セッションとは区別する | [ゲーム概要](overview.md) |
| ハクスラ | 周回と装備厳選で強化・構成を楽しむ本作の方向性 | [装備](../features/equipment.md) |
| HD-2D寄り | 本作の画面表現の方向。描画方式・具体規格は未決 | [アート方針](../art/direction.md) |

新語は名称・意味・定義元を追加する。
別名を使う場合は同じ行に記し、同じ仕組みを別の用語として重複定義しない。

## 変更と判断の記録

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位「ワット」を追加し、単位としての「歩」を使わないことにした。今後、自転車の距離なども同じ単位で扱うためである。歩数ボーナス・歩数ログインボーナス・チケットの名称をワットへ改め、旧称を同じ行に記した。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、ダウン、キャスト、再戦などの定義元を追加した。共通スキルゲージと危険度選択を現行用語から外し、旧案は各正本の変更記録で扱う。セッションの15分は想定例として記す。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、目標枠・難易度倍率・継続倍率・歩数ログインボーナスの定義元を追加した。具体的な倍率と報酬量は各正本の仮設定・未決事項を参照する。

- 2026-09-19：ダウンリングを現行用語から外し、濃淡・状態変化による表示へ参照を揃えた。

- 2026-09-27：[企画見直し](redesign-2026-09-27.md)に合わせ、カードバトル（デッキ、手札、エネルギー、コスト、カードスキル、固有スキル、クールターン、すばやさ、属性、弱点、激化）、冒険、歩数ボーナス、チケットの定義元を追加した。廃止した運動目標・目標枠・難易度倍率・継続倍率、アクティブスキル・クールダウン・キャストタイム・ダウン・ダウン値・ダウン中・ダウンゲージ・追撃・無料再戦を現行用語から外した。MET（活動強度の補正）は歩数だけを扱うため外した。旧案は各正本の変更記録で扱う。
