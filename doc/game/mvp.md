## 確定している方針

ゲーム全体のMVPと初回リリース範囲は未決である。
企画全体の機能一覧を、そのまま最初のリリース範囲と扱わない。

2026-09-27の[企画見直し](redesign-2026-09-27.md)で戦闘をターン制のカードバトルへ変更したため、これらを[変更と判断の記録](mvp-history.md)へ移した。
カードバトルの試作範囲と評価基準は未決である。

## ワイヤー後の体験評価

2026-09-19の[ユーザー評価](../archive/game-wireframe.md#2026-09-19のユーザー評価と残った課題)では、ワクワク感と楽しさの中心をまだ判断できていない。
探索の改善要求は[ダンジョン内の見た目による行き先選択](../features/stage-progression/run.md#ダンジョン内の見た目による行き先選択)に反映する。
グラフィックの追加によって面白さも解決すると確定せず、次の観点で体験を評価する。

| 評価すること | 確かめる内容 |
|---|---|
| 現在地と行き先の分かりやすさ | 自分たちがどこにいて、どの入口へ進めるかを画面から読み取れるか |
| 進路を選ぶ理由 | 見た目と短いヒントから先を想像し、行きたい入口を選べるか |
| 進んだ実感 | 選んだ入口への移動と次のマスの表示で、場所が変わったことが分かるか |
| 冒険を続ける動機 | 先が気になる、獲得物を使いたい、強くなって再挑戦したいと感じられるか |

仮の絵と簡単な演出で短い一連の体験を作る案は、会話で挙がった検証方法の候補とする。
最初に試す場面、必要な戦闘・報酬の実装範囲、合格とする評価方法は未決である。

## 参照会話で挙がった制作項目

「企画ワイヤー作成案」の会話では、ユーザーが次の項目を作業量の検討対象として挙げていた。
ワイヤー以外の着手順・工数・完成条件は未確定であり、この一覧を実装済みや一括の実装指示として扱わない。

| 制作項目 | 現在の扱い・参照先 |
|---|---|
| 主要画面のワイヤー | [実装と評価課題](../archive/game-wireframe.md) |
| 15分のプレイフロー | 短い一連の体験を設計する項目。15分は検討用の目安で、[連続プレイの要求時間にはしない](overview.md#短いプレイの積み重ね)。具体的な流れは未決 |
| Unityでの戦闘Vertical Slice | カードバトルの試作範囲を決めてから、実際の戦闘の手応えを確かめる |
| SE・VFX・画面揺れなどの戦闘演出 | [爽快感と入力の手応え](../features/combat/rules.md#爽快感と入力の手応え)に従い、具体的な制作範囲を決める |
| 探索の分岐UI | [ダンジョン内の見た目による行き先選択](../features/stage-progression/run.md#ダンジョン内の見た目による行き先選択)に反映済み（2026-10-04に地図で分岐ルートを選ぶ形に決め、2026-10-21に作り直した） |
| 装備・育成UI | [装備](../features/equipment.md)・[育成](../features/progression.md)に従う。カードの威力はステータスの割合で書く（[カードの数値の見せ方](../features/combat/cards.md#カードの数値の見せ方)） |
| BGMの方向性 | [効果音とBGM](../rules/sound.md)で具体化する |
| 最終UIデザイン | [画面仕様](../features/screens.md)と試用時の評価を基に決める |
| キャラ量産 | [個別対象の制作と比較](../art/direction.md#個別対象の制作と比較)に従う。制作数・時期は未決 |

## 判断を記録する形式

範囲を決めたら、対象・対象外・理由・受入条件・対応する仕様へのリンクを記す。
計測を採用する場合は、収集項目・目的・保存期間・利用者への説明も決める。
このページへの項目追加だけでは、計測や機能の採用を決定しない。
