# MVPと企画の判断基準

[企画索引](README.md) / 根拠：[初期企画](brief.md)

## 確定している方針

MVPの実装範囲は未決である。
企画全体の機能一覧を、そのまま最初のリリース範囲と扱わない。

## 決定する項目

| 項目 | 状態 |
|---|---|
| 最初に検証する体験とゲームの勝ち筋 | 未決 |
| 対象ユーザー・利用場面 | 未決 |
| 対象とする運動種別・データ | 未決 |
| ルーン・目標の最小実装 | 未決 |
| キャラ・職業・スキル・敵・装備の数 | 未決 |
| ステージ数、ボス、危険度の範囲 | 未決 |
| セーブ・認証・サーバー対応範囲 | 未決 |
| 課金・ガチャを含めるか | 未決 |
| 初回15分で体験できる操作 | 未決 |
| 運動データがない状態での開始・継続 | 未決 |
| 完了条件、観察する行動、評価方法・数値 | 未決 |
| 実装順、後回しにする項目 | 未決 |

## 判断を記録する形式

範囲を決めたら、対象・対象外・理由・受入条件・対応する仕様へのリンクを記す。
計測を採用する場合は、収集項目・目的・保存期間・利用者への説明も決める。
このページへの項目追加だけでは、計測や機能の採用を決定しない。
