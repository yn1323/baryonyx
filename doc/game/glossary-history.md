# 用語集の変更と判断の記録

[用語集](glossary.md)


- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、カスタムスキルと固有スキルの数（各3つ）、覚醒（持っているスキルも覚醒する）、ルーンの用途、商会の扱う物、絆から限界突破への呼び名、アクセサリーの最初の枠、HD-2D寄りの描画方式を直し、手札とエネルギーの数値の写しを外した。神殿・ライブラリ・旅の案内所・入れ子の地図・戦闘後の強化を加えた（根拠：party/catalog.ts の CARD_SLOT_COUNT、TrainingAssets.cs の UniqueUnlockLevels、AccessorySlots.cs、WorkshopScreenAssets.cs、SceneNames.cs、monetization.md のキャラが被ったとき、skill-awakening.md）。あわせて、変更と判断の記録をこのファイルへ移した。
- 2026-10-24：ユーザーの指示で、ACTボーナスを廃止し、「5,000ACT分運動したことにする」チケットの販売予定を取りやめたため、チケットの行を削除し、ACTボーナスを廃止した用語として残した。
- 2026-10-23：ユーザーとの相談で決めた街道・ダンジョンのクリア回数の報酬・キャラが被ったときの扱いに合わせ、ダンジョン・街道・クリア・絆とかけらを加えた。

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位「ワット」を追加し、単位としての「歩」を使わないことにした。今後、自転車の距離なども同じ単位で扱うためである。歩数ボーナス・歩数ログインボーナス・チケットの名称をワットへ改め、旧称を同じ行に記した。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、ダウン、キャスト、再戦などの定義元を追加した。共通スキルゲージと危険度選択を現行用語から外し、旧案は各正本の変更記録で扱う。セッションの15分は想定例として記す。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、目標枠・難易度倍率・継続倍率・歩数ログインボーナスの定義元を追加した。具体的な倍率と報酬量は各正本の仮設定・未決事項を参照する。

- 2026-09-19：ダウンリングを現行用語から外し、濃淡・状態変化による表示へ参照を揃えた。

- 2026-09-27：[企画見直し](redesign-2026-09-27.md)に合わせ、カードバトル（デッキ、手札、エネルギー、コスト、カードスキル、固有スキル、クールターン、すばやさ、属性、弱点、激化）、冒険、歩数ボーナス、チケットの定義元を追加した。廃止した運動目標・目標枠・難易度倍率・継続倍率、アクティブスキル・クールダウン・キャストタイム・ダウン・ダウン値・ダウン中・ダウンゲージ・追撃・無料再戦を現行用語から外した。MET（活動強度の補正）は歩数だけを扱うため外した。旧案は各正本の変更記録で扱う。

- 2026-09-28：ユーザーの指示により、ゲーム内の運動量の単位の名前を「ワット」から「UPT」へ改めた。ワットとルーンなどの用語が分かりにくいという検討を受けた判断である。自転車・ランニングの距離などもUPTへ換算する方針は変えない。1歩＝1UPT、1UPT＝1ルーンとし、換算量は変えない。ワットボーナス・ワットログインボーナス・チケットの名称をUPTへ改め、旧称を同じ行に記した。ルーンの名前は変えない。

- 2026-09-29：ユーザーの指示により、弱点の定義を「常に表示」から「初めは伏せ、味方が突くと開示し、以後はその種類の敵で常に表示」へ改めた（[弱点の開示](../features/combat/rules.md#弱点の開示)）。

- 2026-09-29：UPTの略さない形を確認したところ、ユーザーの指示により「UPT」そのものを正式な名称とした。

- 2026-10-04：ユーザーの指示により、UPTボーナスの定義を「段階に届くたびに1つ選ぶ」から「段階ごとの枠に前もって入れておく」へ改めた（[UPTボーナス](../archive/step-bonus.md#日次のactボーナス)）。

- 2026-10-04：ユーザーの指示により、「カードスキル」の呼び名を「スキル」に改め、旧称として残した。カード型であることは定義に書き、戦闘の手札・山札としては引き続き「カード」と呼ぶ。あわせて、装備する枚数を[キャラクターの構成](../features/party.md#キャラクターの構成)に合わせて3枚から4枚に直した。

- 2026-10-04：ユーザーの指示により、ステータスの項目をHP・物攻・物防・属攻・属防・速度・会心・幸運の8つとし、味方と敵で同じにした（[ステータスの項目](../features/party.md#ステータスの項目)）。ターン順を決めるステータスの名前を「すばやさ」から「速度」に改め、旧称として残した。

- 2026-10-04：探索を森を見下ろす地図で進む形へ改めたことに合わせ、「部屋」の定義を、入口を選ぶ単位から、分岐ルートで行き先に選ぶ単位へ改めた（[探索とダンジョンの進行](../features/stage-progression/run.md#ダンジョン内の見た目による行き先選択)）。

- 2026-10-04：ユーザーの決定で状態異常に確率を設けたため、付与率を加えた（[状態異常のかかりやすさ](../features/combat/rules.md#状態異常のかかりやすさ)）。

- 2026-10-04：ユーザーの指示により、ゲーム内の運動量の単位の名前を「UPT」から「ACT」（読みはアクト）へ改めた。UPTは「うんどーポイント」の略として付けた名前で、響きを見直した。画面の表記は「ACT」とする。換算は1歩＝1ACT、1ACT＝1ルーンで変えない。UPTボーナス・UPTログインボーナス・チケットの名称をACTへ改め、旧称を同じ行に記した。

- 2026-10-05：文書の整理で、定義元にある数値の写し（デッキの枚数と引く数、エネルギーの増え方、弱点の倍率、ACTとルーンの換算）を外し、定義元へのリンクだけにした。同日の画面名の変更に合わせ、編成（旧称：酒場）と商会（旧称：装備の画面）を加えた。

- 2026-10-06：ユーザーの指示により、持ち物・装備・アクセサリー・アイテム・道具・素材・レア度・倍率・合成を加えた（[持ち物の分類](../features/inventory.md)）。ACTボーナスのランクをレア度（☆）にそろえ、旧称として残した。アイテムもデッキのカードになるため、カードバトルとデッキの定義を改めた。同日、固有スキルもデッキのカードになり、1人の4枚が固有スキル2枚とスキル・アイテムの2枠になったため、スキル・固有スキル・エネルギー・コストの定義を改め、クールターンを外した（[固有スキル](../features/combat/rules.md#固有スキル)）。

- 2026-10-19：ユーザーの指示により、品質を加え、レア度を種類ごとの珍しさとして強さと切り離した。倍率の定義を品質に合わせた（[品質](../features/inventory.md#品質)）。

- 2026-10-21：ユーザーの依頼「今までは部屋って言い方してたけど、マスって言い方で統一したい」により、探索の単位の呼び方を「部屋」から「マス」に改め、「部屋」を旧称として残した（[冒険の道とマスの数](../features/stage-progression/run.md#冒険の道とマスの数)）。
