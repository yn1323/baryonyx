# 文書作業の入口

[文書索引](README.md)から対象分野を選び、対応する仕様と参照先だけを読む。
文書の配置・記述形式・更新方法は[文書管理方針](rules/documentation-policy.md)を適用する。

- 企画の決定は各仕様の「確定している方針」を参照する。「候補」「未決」を採用済みの仕様へ変えない。
- 仕様追加の依頼では、[既存仕様との矛盾を扱う手順](rules/documentation-policy.md#仕様追加時の矛盾の扱い)に従う。
- 現行動作は仕様内の実装へのリンクから確認する。企画の確定と実装完了を混同しない。
- 個別データの追加は[データ索引](catalog/README.md)から対象分類とテンプレートを選ぶ。
- 画像化する対象は[外見・性格の比較索引](art/visual-index.md)で既存案を確認する。
- 生成索引の更新と検査は[文書検査](tools/README.md)に従う。生成領域を手編集しない。
