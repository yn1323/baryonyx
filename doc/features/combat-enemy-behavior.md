# 敵の行動の仮設定

[戦闘システム](combat.md) / [敵の定義](../catalog/enemies/README.md) / [敵の技の定義](../catalog/enemy-skills/README.md)

[戦闘システム](combat.md)の「仮設定」にあった節を、2026-10-25に文書が約60KBを超えたため分けた（[文書の大きさと分け方](../rules/documentation-policy.md#文書の大きさと分け方)）。本文は移す前のままである。

2026-10-04、ユーザーの依頼で、戦闘画面のモックの敵3体に、ステータス・技・行動パターン・演出の設定を作った。
技の数は敵の大きさに合わせ、小の苔スライムに3つ、中の苔むした狼に5つ、大の森の守り手に8つとし、攻撃のほかに防御・強化・弱体・回復・呼び出しを混ぜた。
1体ごとの内容は[敵の定義](../catalog/enemies/README.md)に、技は[敵の技の定義](../catalog/enemy-skills/README.md)に1技1ファイルで記録した。
技は、複数の敵で使い回す共通技（12個。うち4個は今の3体では使わない）と、1体だけが持つ固有技（8個）に分けた（[共通技と固有技](../catalog/enemy-skills/README.md#共通技と固有技)）。
敵のステータスは味方と同じ8つの項目をLv100の値で定め、出現する場所ごとにLvを決める（[レベルとステータス](progression.md#レベルとステータス)）。
森の遺跡の3体はLv10とし、HPと攻撃が今のモックの値とほぼ同じになるようにした。
モックで使えるのは各敵の単体攻撃1種類だけで、ほかの技とステータスは未実装である。

2026-10-19、ユーザーの依頼で、Codex CLIの画像生成で試作した50体を[敵の定義](../catalog/enemies/README.md)に加え、[CombatEnemies](../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemies.cs)とサーバーの `ENEMY_IDS` にそろえた。
50体のLv100のステータスは、大きさ（小・中・大）ごとの基準値に、体の作りに合わせた型（守りの硬い型・力の強い型・速い型・魔法の型・釣り合いの型）の倍率を掛けた仮の値である。
既存の共通技では足りない攻撃の型を補うため、共通技を13個加えた（斬りつけ、二段突き、毒針、火の玉、氷のつぶて、傷ふさぎ、打ち砕き、にらみつけ、吸い取り、放電、金切り声、渾身の一撃、なぎ払い）。
50体はまだどの行き先にも出ず、出現する行き先とLv、ステータスと技の実装は未決である。ライブラリと展示室には名前と絵が載り、ライブラリでは開示した弱点も出る。

敵の技では、カードにない次の仕組みを使う。
どれも候補であり、実装するときに[未決事項](combat.md#未決事項)の数値と合わせて決める。

| 仕組み | 使う技 | 候補と決めること |
|---|---|---|
| 味方に付く毒・出血・やけど | 胞子ばらまき、引き裂き、火の息 | 量は、付けた敵のステータスではなく、付いた味方の最大HPの割合で決める案（毒は重なった数×3%、出血はカードを使うたびに4%、やけどは味方のターンの開始時に4%）。カードの状態と同じく付けた側のステータスで決めると、ステータスの低い雑魚の毒がほとんど効かず、味方が育つほど差が広がるためである |
| 味方に付く防御ダウン | 森羅の鉄槌 | カードの防御ダウン（受けるダメージ+25%）と同じ効果にする案 |
| 敵に付く強化 | 遠吠え、森の恵み、刻印の目覚め | 攻撃力アップとリジェネをカードと同じ効果で敵にも付ける。モックの敵は強化を持たない |
| 絡みつき | 根縛り | 新しい状態。その味方のカードのコストを1ターンの間1上げる案。カードを使えなくする案は、捨てる手段のない手札を塞ぐため採らない（[手札](combat.md#手札)） |
| 敵のブロック | 草陰に伏せる、身を固める | 味方のブロックと同じく受けたダメージから先に引く。消えるタイミング（敵の次の行動の前か）は未決 |
| 呼び出し | 仲間を呼ぶ | 戦闘の途中で敵を加える。呼ばれた敵のLvは、呼んだ敵と同じにする案。立ち位置、行動順への入れ方、呼んだ敵を倒す必要があるかは未決 |
| 大技までのターン数の予告 | 森羅の鉄槌 | 溜めのターンに「大技まであと1ターン」を予告に出す。モックは予告を出していない |

2026-10-22、同じ依頼で、冒険の戦闘の敵が、[敵の定義](../catalog/enemies/README.md)に書いた技と行動パターンで動くようにした（作り方は、ユーザーが「文書の技と行動パターン」を選んだ）。
53体の技と行動パターンの実行上の正本は [CombatEnemyBehaviors](../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEnemyBehaviors.cs)（行き先ごとのファイルに分けた）、技の選び方は [EnemyBrain](../../client/Assets/Baryonyx/Features/Combat/Runtime/EnemyBrain.cs) にある。
技の威力は、出現するLvの物攻・属攻・物防に技の割合を掛け、部屋の攻撃の倍率（[行き先と敵](stage-progression.md#行き先と敵)）を掛けて求める。

| 戦闘でできること | 入れた形 |
|---|---|
| 攻撃 | 味方単体（ランダム）・HPの割合が最も低い味方・ブロックの最も多い味方・味方全体・1回ごとにランダムな味方への攻撃。複数回の攻撃と、狙った味方のほかへも当てる攻撃。物防で減らさない、ブロックを無視する、ブロックを消してから当てる、与えたダメージで回復する、使ったあと自分のHPが減る |
| 敵の守りと強化 | ブロック（その敵の次の行動の前に消える）、回復、リジェネ（味方のターンの始めに回復する）、攻撃力アップ（カードと同じ25%）、プロテクト（受けるダメージ-25%）、次の攻撃の技の威力アップ。自分だけ、自分以外の敵、自分と仲間、HPの割合が最も低い仲間に付ける |
| 溜め | 大技の前に1〜2回の行動を溜めに使い、溜めの行動では同時に身を固めることもある。溜めた敵の上に「力を溜めている」「あと〇ターン」と2行で出し、大技が当たるまで敵の絵を暖色に明滅させる |
| 行動パターン | 1回目の技（仲間がいないときの別の技を含む）、順番に回す技、割合で選ぶ技、同じ技を続けてよい回数、条件で割り込む技とその次の技（自分のHP、ほかの敵のHP、仲間の有無、味方のHP、味方のブロック）、使う間隔と回数の上限、激化するターンと威力・回数の変化、後半への切り替え（決まったターンか、HPが半分以下になったときの早いほう）と後半の組み（「選ぶ・選ぶ・大技」など）、単体の技を全体へ広げる、1回の番に2つの技を使う |

割合で選ぶ技のうち、攻撃しない技（身を固める・力を溜める・状態を付けるなど）は、書いた重みの4割で選ぶ（2026-10-24、ユーザーの「もっとガシガシ攻撃してきてほしい」による仮の値。[EnemyBrain](../../client/Assets/Baryonyx/Features/Combat/Runtime/EnemyBrain.cs) の `QuietWeightPercent`）。
1回目の技、順番に回す技、条件で割り込む技は、書いたとおりに使う。

激化と後半への切り替えでは、敵の上に「激化！」と出して、敵を震わせる。
通常の戦闘は3〜4ターンで終わるため、5ターン目からの激化は、主に強い魔物と最奥の間で起きる。
通常の敵に激化を付けるかの[未決](combat.md#未決事項)は残す。

溜めの知らせは、ユーザーが「大技の溜めだけ知らせる」を選んだ形である。
2026-09-29の決定（[戦闘画面の見た目モック](screens/battle.md#戦闘画面の見た目モック)）どおり、敵の頭上に次の行動を常に出す予告は出さない。

次の効果は戦闘にまだないため、入れていない。
攻撃を伴う技は攻撃だけを残し、それ以外の効果だけの技は選ばない。

- 味方に付く状態（毒・出血・やけど・凍え・凍結・麻痺・防御ダウン・絡みつき・呪い・惑い・傷口・捕縛）、エネルギーや引くカードを減らす効果、カードや強化を奪う効果
- 仲間を呼ぶ、逃げる、倒れた仲間や自分の復活、仲間を倒して回復する
- 敵自身の回避・無敵・反射・霧隠れ・見張り、速度アップ、状態異常を消す効果
- 詠唱を炎や打で崩す仕組み、次の味方ターンの始めに遅れて当たる攻撃
- 戦闘から見えない条件（受けた攻撃の回数、味方の状態異常や強化、前の味方ターンに使われたカード、空いた立ち位置）による割り込み

このため、波紋聞き・つらら刺し・壺の吸い込み・時の巻き戻し・鴉のものまね・燃えるうろこは、使う条件が見えず、今は使われない。
文書と違う形に寄せた技（「失ったHPの20%を回復」を最大HPの10%の回復に、2ターンの詠唱を2回の溜めに、など）は、データのコメントに書いた。
これらの効果を足すときは、データのコメントを手がかりに、その技と行動パターンを文書どおりに戻す。
