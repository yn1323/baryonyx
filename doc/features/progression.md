# 育成と強化

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)、[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

## 確定している方針

キャラクター・装備を強化し、以前勝てなかった敵の撃破や、より深い階への到達につなげる。
必要に応じて育成・装備・編成を見直す流れは[コアループ](../game/overview.md#コアループ)、進展を見せる方法は[成長の記録](stage-progression.md#成長の記録)で管理する。

### レベルアップ

キャラはルーンを使ってレベルアップする。
レベルアップでステータスが上がり、パッシブスキルと固有スキルを解放する（[キャラクターの構成](party.md#キャラクターの構成)）。

### 冒険で得た強化の保持

冒険で獲得した装備・スキルなどは、負けて冒険が終わっても保持する（[冒険の終了と獲得物の保持](stage-progression.md#冒険の終了と獲得物の保持)）。
冒険中に得たステータス〇％アップが、その冒険限定か永続かは未決である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| レベルの上限、成長するステータス、必要ルーン | 未決 |
| パッシブスキル・固有スキルを解放するレベル | 未決 |
| 装備・カードスキルの育成手段・必要資源・成功条件 | 未決 |
| 冒険中のステータス〇％アップの持続 | その冒険限定か永続か |
| 合成・進化・限界突破などを採用するか | 未決 |
| 重複キャラ・装備の用途 | 未決 |
| 育成のやり直し・資源返却の有無 | 未決 |
| 強化前後の表示と誤操作への対応 | カードの威力は装備画面で実数値と差分を表示する（[カードの数値の見せ方](combat.md#カードの数値の見せ方)）。レベルアップの表示は未決 |
| 想定成長速度、序盤・中盤・高難度の到達基準 | 未決 |

## 変更と判断の記録

- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、ルーンによるレベルアップと、レベルアップでのステータス上昇・パッシブスキル・固有スキルの解放を確定事項にした。冒険で得た装備・スキルを負けても保持することを反映し、冒険中のステータス上昇の持続は未決に分けた。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、育成の目的を強敵への再挑戦と探索の進展へ具体化した。毎戦の強化は要求せず、探索記録とゲーム概要を参照する。育成費用や成長曲線は今回確定しない。
