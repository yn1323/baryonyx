# 育成と強化

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

キャラクター・装備を強化し、より高難度へ挑むコアループとする。
ルーンを成長要素に使う方向である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| レベル・経験値・成長ステータス・上限を採用する範囲 | 未決 |
| キャラと装備の育成手段・必要資源・成功条件 | 未決 |
| スキル・パッシブの強化・解放 | 未決 |
| 合成・進化・限界突破などを採用するか | 未決 |
| 重複キャラ・装備の用途 | 未決 |
| 育成のやり直し・資源返却の有無 | 未決 |
| 強化前後の表示と誤操作への対応 | 未決 |
| 想定成長速度、序盤・中盤・高難度の到達基準 | 未決 |
