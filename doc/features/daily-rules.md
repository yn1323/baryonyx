# 日付の区切りとデイリー変異

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

[運動目標の集計期間](goals.md#集計期間)は、日次と週次それぞれの区切りが確定している。
時間帯を指定しても目標期間そのものは変えず、基準タイムゾーンは未決である。
継続倍率の期間入れ替えと締め切りまでの猶予は[倍率の反映タイミング](goals.md#倍率の反映タイミング)に従う。
デイリー変異の採用と、目標以外の日付ルールは引き続き未決とする。

## 候補と例

全ユーザー共通で、その日の特殊条件を変える仕組みを検討する。
敵攻撃力上昇、特定属性強化、回復量低下は候補の例である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 目標の基準タイムゾーンと、目標以外の1日・週の区切り | 未決。目標期間の区切りは[目標仕様](goals.md#集計期間)で確定 |
| 端末時計・旅行・タイムゾーン変更への対応 | 未決 |
| 運動日付・目標期間・ゲーム更新時刻の関係 | 未決 |
| 目標の期間境界と遅延訂正 | 時間帯をまたぐ記録の集計方法、同期遅延の猶予・訂正範囲、締め切りまで倍率低下を猶予する厳密な手順は未決 |
| 変異の採否、条件数、選出方法、配信元 | 未決 |
| 条件の数値、組み合わせ、報酬補正 | 未決 |
| 更新時に戦闘中・オフラインだった場合 | 未決 |
| 告知方法、予定の公開、変更履歴 | 未決 |
