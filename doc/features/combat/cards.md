# 戦闘システム：カード

[戦闘システム](../combat.md)

## 設計方針

### カードの数値の見せ方

カードの説明文は、威力・回復量・ブロックを、使い手のステータスの割合（例：属攻の100%）で書く（2026-10-18、ユーザー指示）。
割合・回数・持続ターン・確率・コストは、そのカードの[品質](../inventory.md#品質)の倍率を掛けた後の値で書く（例：属攻の137%）（2026-10-19）。
使い手のLvのステータス、今日のACT、相手の防御、バフ、弱点は入れず、どの画面でも、誰が付けても同じ文にする。
[ACTで威力が変わるカード](#スキルの仮設定)は、割合に今日のACTの分を足さず、説明文の「今日のACTが多いほど強い」で伝える。
実際のダメージと回復量は、戦闘中にステータス・ACT・[防御](rules.md#ダメージと防御)・弱点を反映して求め、浮かぶ数字で見せる。
未開示の弱点でも、一致すれば1.5倍になる。
装備やLvで威力がどれだけ伸びたかの見せ方は[未決](implementation.md#未決事項)とする。
定義の説明文（`CardSkill.Text`）には数を書かず、威力のある効果の順に `{0}`・`{1}` を置く。割合は `CardRules.Describe` が入れる。

### カードの説明文に書くこと

カードの説明文には、実際の戦闘に関わる情報だけを書く（2026-10-18、ユーザー指示）。
書くのは、対象、ダメージ・回復量・ブロックの[ステータスの割合](#カードの数値の見せ方)、回数、付ける状態と持続ターン、効く条件と変わる量、エネルギー・コスト・手札・行動順への働きである。
「炎の玉で」「氷の槍で貫き」「雷を落とし」のような、技の見た目や演出を表す言葉は書かない。
見た目は挿絵と[戦闘の演出](rules.md#爽快感と入力の手応え)で伝える。
同じ効果のカードは、属性や参照するステータスが違っても同じ言い回しにする（例：「敵1体に属攻の100%ダメージ。」）。
何度も当たる攻撃は、「ダメージを5回」ではなく「ダメージ×5」と、量のすぐ後ろに×と回数を付けて書く（2026-10-18、ユーザー指示。例：「ランダムな敵に物攻の45%ダメージ×7。」）。
説明文は、カードの説明文の欄（4行）に収める。

### カードのキーワード

カードの効果を増やしても説明文の欄に収まるよう、状態や条件の名前（凍え・やけど・ブロック・弱点など）を**キーワード**として1語で書き、意味はカードの外に出す（2026-10-18、ユーザーの依頼で試作。Slay the Spire・Hearthstoneと同じ方式）。
カードの説明文では、キーワードを水色の下線付きの文字にする。
戦闘中にカードを押して上げている間だけ、カードの横（敵に使うカードは左、味方に使うカードは右）にキーワードごとの説明札を出す（[戦闘画面の見た目モック](../screens/battle.md#戦闘画面の見た目モック)）。

キーワードにするのは、複数のカードで使う語に限る。
Blizzardは、カードの文で新しいプレイヤーが最も離れる原因はキーワードだとして、1枚だけで使う効果をキーワードにしない方針をとっている（[Rise of Shadows Q&A](https://us.forums.blizzard.com/en/hearthstone/t/rise-of-shadows-q-a-april-22-2019/4056?page=12)）。
1枚にしかない効果は、ふつうの文で書く。

説明文の定義では、キーワードを `[凍え]` のように角かっこで囲む。
試作では、説明文にある語に印を付けた。
状態と条件のキーワードと説明の一覧は仮で、[CardKeywords](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardKeywords.cs) を正本とする。

2026-10-25に、カードの動きを表す次のキーワードを決めた（ユーザー決定）。呼び名は仮で、あとで決める。
説明は [CardKeywords](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardKeywords.cs) にあり、カードの動きは [BattleInspectView.Piles](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.Piles.cs) が処理する。

| キーワード | 意味 |
|---|---|
| [消滅] | 使うと、その戦闘から除く。持ち主が倒れてから復活すると、山札へ戻る |
| [保持] | ターンの終わりに流れず、手札に残る |
| [霧散] | ターンの終わりに手札にあると、流れる代わりにその戦闘から除く |
| [初手] | 戦闘の開始時の手札に必ず入る |
| [捨てる] | 効果で手札を捨て札へ送る。「捨てたとき：」と書いた効果は、効果で捨てたときだけ働く |
| [眠り札] | 流れるか捨てられるたびに1段目覚め、1段ごとに効果量（威力・回復量・ブロック）が50%増える。3段まで目覚め、使うと眠りに戻る（段数と増え方は仮） |
| [歩み] | 今日のACTが多いほど効果量が増える（今日のACT1,000ごとに+10%、上限+100%） |
| [合体]X | 手札にXとそろうと、2枚が1枚の合体カードに変わる（[合体カード](#コストと威力の目安)） |
| [連携]X | 同じターンにXを先に使っていると、追加の効果が出る |

組み合わせの決まりを次のようにする（2026-10-25、ユーザー決定）。

- 1枚に[保持]と[霧散]を両方付けない。効果で[保持]を付けるときも、[霧散]のカードは対象にしない。
- [合体]と[連携]の組は2枚までとし、3枚以上の組は作らない。合体か連携か（どの時点で発動するか）は、カードごとに決める。

説明札が積み重なる見え方を確かめるため、効果を5つ持つ試作のカード「蛇牙の連撃」（ルカ・貫・攻撃・敵単体・コスト2）を作った（2026-10-18、ユーザーの依頼）。
敵1体に物攻の45%のダメージを2回与え、それぞれ60%で出血2ターン・毒2つ・防御ダウン2ターンを付け、弱点を突くとエネルギーが1増える。
説明文は「敵1体に〇ダメージ×2。60%で出血・毒・防御ダウン。弱点でエネルギー+1。」で、キーワードは4つである。初めは「出血・毒・防御ダウンを付ける。弱点を突くとエネルギー+1。」と書いたが、説明文の欄（4行）に収まらなかったため縮めた。
これは[スキルの仮設定](#スキルの仮設定)の50枚に数えず、戦闘画面のモックの山札だけで使う（`CardSkills.Prototypes`）。
挿絵は急所突きのものを借り、演出は専用のものがないため斬り払いの演出で代える。

## 仮設定

### スキルの仮設定

2026-10-03、ユーザーの依頼で、スキルを50枚作った。
1枚ごとの意図・演出・挿絵は[技・カードの定義](../../catalog/skills/README.md)に記録し、効果と数値の実行上の正本は [CardSkills](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkills.cs) に置く。
2026-10-25に、エネルギー3固定のルールに合わせて、50枚と覚醒版のコスト・効果・説明文を[技・カードの定義](../../catalog/skills/README.md)の上で作り直した（ユーザーの依頼「毎回3エネルギーになるので、コストと効果を全部刷新する」）。効果と数値の実行上の正本は [CardSkills](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkills.cs)・[CardSkillAwakenings](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkillAwakenings.cs) である（[計画](../../plans/2026-10-25-fixed-energy-cards.md)）。
キャラごとに装備できる属性は未決のため、使い手は戦闘画面のモックの4人に仮に割り当てた。

| 項目 | 仮設定 |
|---|---|
| 枚数と使い手 | 50枚。アリア13枚、トーマ13枚、ルカ13枚、ミナ11枚 |
| 属性 | 斬5枚、打6枚、貫6枚、炎7枚、氷5枚、雷6枚、属性なし15枚 |
| 種類 | 攻撃28枚、回復5枚、防御5枚、強化3枚、弱体4枚、支援5枚。カードには「攻撃・敵単体」のように種類と対象を並べて書く |
| 対象 | 敵単体、敵全体、敵ランダム（当たるたびに敵を選び直すもの、当てた敵から別の敵へ跳ねるもの）、味方単体、味方全体、自分、人以外（手札・山札・エネルギー・次のカード） |
| 連続攻撃の途中で倒れた敵 | 倒れた敵は、そのカードの最後の当たりまで場に残り、カードが終わってから崩れて消える。敵ランダムの残りの当たりは、倒れた敵を狙わず、立っている敵から選び直す（跳ねるものは、直前に当てた敵を避ける）。敵単体・敵全体の残りの当たりは選び直さない（2026-10-29、ユーザーの依頼。倒れた敵がすぐ消えて残りの当たりが空を打つのが不自然だった） |
| コスト | 0〜3。0が6枚、1が22枚、2が16枚、3が6枚（2026-10-25、エネルギー3固定に合わせて作り直した）。基本は1〜2とし、0は手札とエネルギーを整える支援と小さな火種、3はそのターンのエネルギーをすべて使う大技にした。それまでは0〜9で、9はメテオだけだった（2026-10-20） |
| 威力 | 使い手のステータスの割合。物理の打撃は物攻、魔法と回復は属攻、ブロックと盾の打撃は物防を使う（[ステータスの項目](../party.md#ステータスの項目)）。2026-10-04に、それまで仮に使っていたちから・まりょく・まもりを、この3つに置き換えた |
| 条件で強くなるカード | 弱点を突いたとき、敵の状態（やけど・凍え・毒・出血・麻痺・防御ダウン）、HPが半分以下の敵、使い手にブロックがあるときに、威力が上がるカードがある。状態を付けるカードと威力が上がるカードを別のカードに分け、組み合わせて使う楽しさを作る（2026-10-19、例：鎧砕きの防御ダウン→大地割り、旋風斬の出血→斬り払い）。[手札](rules.md#手札)の方針に合わせ、使う条件は付けない |
| ACTで効き目が変わるカード（[歩み]） | 健脚の一撃と万歩の祈り（覚醒版を含む）、固有スキルの裁きの光・天照。今日のACT1,000ごとに効果量を10%上げ、上限は100%とする |
| 重複を避ける基準 | 属性・対象・行う効果（種類・相手・状態・回数・条件）の組み合わせが同じカードを作らない。同じ効果で威力とコストだけが違うカードも作らない。固有スキルの覚醒の段階も含めて、EditModeテストの `CardSkillAwakeningsTests` で検査する |
| 挿絵 | 1枚ずつ別のモチーフを描く。最初の6枚は戦闘画面のモックの挿絵を使い、残りの44枚はCodex CLIの画像生成で作った（[戦闘画面の見た目モック](../screens/battle.md#戦闘画面の見た目モック)） |
| 演出 | 1枚ずつ別の演出にする。どれも溜め・発生・余韻の3拍で組み立て、画像を貼らずに形をシェーダーで計算して描く（[スキルの演出と背景](../screens/battle-effects.md#スキルの演出と背景)） |
| カットイン | 大技の8枚（居合一閃・シャドウスナイプ・リザレクション・千刃乱舞・雷神の槍・ギガントインパクト・絶対零度・メテオ）。2026-10-25にコストが0〜3になったため、コストではなくカードで決める。それまではコスト5以上の8枚で、2026-10-20のコストの見直しでブリザードと雷雲はコスト4になり、カットインを出さなくなった。[長い演出で毎回操作を止めない](rules.md#爽快感と入力の手応え)ため、大技に絞った |

### コストと威力の目安

2026-10-25に、エネルギー3固定に合わせて作り直したカードの目安である（仮。実装したあとの[戦闘の自動対戦](../../rules/client-testing.md#戦闘の自動対戦)で見直す）。
1ターンに使うカードは2〜3枚になる。
作り直す前の後半のターン（エネルギー7〜8）に1ターンで与えていたダメージと同じくらいになるよう、1エネルギーあたりの威力を上げた。

| コスト | 敵単体 | 敵全体 | 回復 | ブロック | 役割 |
|---|---|---|---|---|---|
| 0 | 40%前後、または手札・エネルギーの働きだけ | なし | 全体20〜25% | なし | 手札とエネルギーを整える。[霧散]や[消滅]を付けることが多い |
| 1 | 130〜150% | 75〜100% | 単体100%・全体45〜50% | 自分70%・全体35% | 毎ターンの基本 |
| 2 | 220〜300% | 100〜150% | 全体80% | 自分90〜130% | 主力。条件で1.5倍になるカードは低めにする |
| 3 | 380〜450% | 200〜250% | 復活 | 全体の無敵 | そのターンのエネルギーをすべて使う大技。[保持]・[眠り札]・[消滅]で重さを補う |

- 割合は品質C（×1.00）の値で、敵単体と敵全体は使い手のステータスの割合、ブロックは物防の割合である。
- [消滅]のカードは、1戦闘に1回しか使えない分、同じコストのカードより強くしてよい。
- [霧散]のカードは、そのターンに使わないと消える分、軽くするか強くしてよい。
- [保持]のカードは、使う時を選べる分、同じコストのカードと同じか少し弱くする。

合体カードは、[合体]の2枚が手札にそろうと現れ、その戦闘の中だけ使える。

| 合体カード | 元の2枚 | 使い手 | 属性 | 種類・対象 | コスト | 説明文 |
|---|---|---|---|---|---|---|
| 炎の斬り払い | 斬り払い＋フレイムエンチャント | アリア（斬り払いの使い手） | 炎 | 攻撃・敵単体 | 1 | 敵1体に物攻の250%の炎属性ダメージ。60%で[やけど]3ターン。[消滅]。 |
| 氷雷の槍 | アイスランス＋ライトニングボルト | トーマ（アイスランスの使い手） | 氷 | 攻撃・敵単体 | 1 | 敵1体に属攻の200%ダメージ。60%で[凍え]2ターンと[麻痺]1ターン。[消滅]。 |

合体カードは、元の2枚のうち斬り払い・アイスランス（合体カードが挿絵を借りるカード）の使い手が使う（仮。`CardSkills.Fusions` の使い手）。
合体カードの持ち主（どちらかが倒れたときに消えるか）は[未決](implementation.md#未決事項)とする。

### カードの状態の仮設定

カードが付ける状態と、その効果を次のように仮に定める。
持続ターンは味方ターンの開始ごとに1減り、0で消える。
味方ターンの開始時に働く状態は、やけど、毒、リジェネの順に、同じ状態の付いた敵と味方の全員へ同時に働く（2026-10-29、ユーザーの依頼。それまでは1人ずつ順に働いた）。リジェネは敵と味方を一緒に回復する。爆炎の刻印と雷雲は、これまでどおり1つずつ働く。
凍結と反射は使われるまで、毒は重なった数が尽きるまで残る。
[防御](rules.md#防御と敵の激化)は、候補のSlay the Spire式のブロックを仮に使い、受けたダメージをブロックから先に引く。
ブロックはターンをまたいで残り、付いた味方の最大HPまで貯まる（超えた分は付かない）。戦闘の終わりと、全滅からの復活で消える（2026-10-21、ユーザー指示）。
ただし、味方のターンの始めに、残っているブロックは半分（端数は切り捨て）になり、減った分を「ブロック -〇」と出す（2026-10-22、ユーザー指示）。
毎ターン同じ量を張り続けても、張る量の約2倍で頭打ちになる。
半分という割合は仮の値で、[CardRules](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardRules.cs) の `BlockKeptPercent` にある。

| 状態 | 付けるカード | 効果 |
|---|---|---|
| 出血 | 旋風斬 | 敵が行動するたびに、付けた味方の物攻の20%のダメージ |
| やけど | 火の粉、ファイアストーム | 味方ターンの開始時に、付けた味方の属攻の20%のダメージ |
| 毒 | 毒針 | 味方ターンの開始時に、重なった数×付けた味方の物攻の10%のダメージ。そのたびに重なりが1つ減る |
| 凍え | アイスランス、ブリザード | 速度-30% |
| 凍結 | 絶対零度 | 次の行動を1回休む |
| 麻痺 | ライトニングボルト | 与えるダメージ-25% |
| 防御ダウン | 鎧砕き | 受けるダメージ+25% |
| 爆炎の刻印 | 爆炎の刻印 | 次の味方ターンの開始時に爆発し、敵全体に炎属性のダメージ |
| 雷雲 | 雷雲 | 味方ターンの開始時に、敵1体へ雷属性のダメージ |
| 攻撃力アップ | 鬨の声 | 与えるダメージ+25% |
| 速度アップ | 疾風迅雷 | 速度+30% |
| リジェネ | リジェネ | 味方ターンの開始時にHPを回復する |
| 挑発 | 守護の誓い | 敵の単体攻撃を引き受ける |
| 反射 | アイスミラー | 次に受ける単体攻撃を1回、攻撃した敵へはね返す。自分はダメージを受けない |
| 炎の加護 | フレイムエンチャント | 攻撃に炎属性を加え、炎が弱点の敵には弱点の倍率を掛ける |
| プロテクト | プロテクト | 受けるダメージ-25% |
| 無敵 | ディバインシールド | ダメージを受けない |

速度を変える状態（凍え、速度アップ）は、冒険の戦闘では[ターン順](rules.md#ターン順の仮設定)を変える（2026-10-24）。速度を持たない戦闘画面のモックと、行動順を遅らせる影縫いは、名前を表示するだけで行動順を変えない。
聖なる鉄槌の[強化]を消す効果は、敵の技で付いた強化（攻撃力アップ・プロテクト・リジェネ）も消さず、表示だけにとどまる。浄化の光は味方の状態異常を消すが、敵の技はまだ味方に状態異常を付けないため（[敵の行動の仮設定](../combat-enemy-behavior.md)）、消すものがない。
