# 育成と強化の変更と判断の記録

[育成と強化](progression.md)

- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、アクセサリーの枠の開き方、限界突破の呼び名（突破のしるし）、品質強化を決めたことと、強化・合成を実装済みとすることを直した（根拠：client/Assets/Baryonyx/Features/Equipment/Runtime/AccessorySlots.cs、server/src/features/enhancement/、server/src/features/workshop/craft.ts）。
- 2026-10-24：ユーザーの「マスごとに強くなっていくやつは冒険の間だけ有効でいい」により、冒険中のステータスの上昇を冒険限定に決め、未決事項から外した（[冒険で得た強化の保持](progression.md#冒険で得た強化の保持)、[戦闘後の強化](stage-progression/boons.md#戦闘後の強化)）。
- 2026-10-24：ユーザーの指摘「キャラって素早さ低くない？」「攻撃、防御、属攻、属防、素早さは、基本数値は同じくらいにしておいて」「個々のキャラの特色で振れ幅がある感じに」を受け、[自キャラのLv100のステータス](progression.md#自キャラのlv100のステータス)の5項目を、9人の平均が1,400になるよう項目ごとの倍率でそろえ直した（物攻はほぼそのまま、物防は約1.27倍、属攻は約0.85倍、属防は約1.09倍、速度は約2.47倍）。速度だけを上げると敵より2.5倍速くなり連続で動くため、敵の速度にも同じ倍率を掛けて、ターン順の釣り合いを変えなかった。決め方を書き、キャラ設定のスキル（rpg-character-profile）から参照するようにした。
- 2026-10-23：ユーザーの指示「レベル上限は100にしておいて」により、レベルの上限を仮の値30からLv100に改めた。奥の行き先（推奨Lv35・40）に推奨Lvで挑めなかったことが、きっかけである（[推奨Lvより低いパーティの試し](stage-progression/battle-trials.md#推奨lvより低いパーティの試し)）。ステータスはLv100で定義の値に届く。今の費用（Lv nからn+1へn×100ルーン）では、Lv1からLv100まで累計495,000ルーン（1日7,000歩で約71日）かかる。上限の値はサーバーの[定義](../../server/src/features/party/catalog.ts)の `MAX_LEVEL` を正本とし、クライアントの仮データ（`TrainingMockData` の `MaxLevel`）も同じ値にした。
- 2026-10-06：ユーザーの依頼で、編成の育成を、冒険者の一覧から開く1人の個別の画面にした（[ステータスのタブ](screens/adventurers.md#ステータス)。2026-10-26に冒険者のタブの1つにした）。イラストとドット絵、ステータス、固有スキル・パッシブ、装備、スキル、レベルアップを1画面に置き、装備とスキルの枠からそれぞれの付け替えの画面を開く。レベルアップの決まりと重ねて開く画面は変えていない。
- 2026-10-06：ユーザーの指示により、[アクセサリー](equipment.md#アクセサリー)の枠がレベルアップで開くことを加えた。2026-10-05に装備の仕様で採用した合成を、未決事項に反映した（[合成](synthesis.md)）。
- 2026-10-04：ユーザーの決定で、ステータスがLvごとに同じ割合で伸びる形を[確定](progression.md#ステータスの伸び方)した。同じ量ずつ伸ばす形と比べ、Lvの差の効き方がどのLvでも同じになる点を選んだ。あわせて、育成とスキルの画面のモックを、8つの項目とLv100の値・成長率で値を出す形に改めた。
- 2026-10-04：ユーザーの依頼で、味方と敵のステータスをLv100の値で定め、Lvに応じた成長率を掛けて各Lvの値を出す仮設定を置いた（[レベルとステータス](progression.md#レベルとステータス)）。難しさを敵のLvで調整できるよう、Lvの差による強さの差がLvの高さによらず同じになる成長率にした。仮データの9人のLv100の値も定めた。
- 2026-10-04：ユーザーの依頼で、上げたレベルをサーバーに保存し、レベルアップに使うルーンをサーバーの残高から引くようにした。費用はサーバーで計算し、残高と今のレベルを確かめてから、ルーンの減算とレベルの更新を1回の書き込みで行う。上限と費用の式は仮の値のまま、サーバーを正本にした。

- 2026-10-04：酒場の[育成の画面](screens/adventurers.md#ステータス)をモックとして作った。ステータスの項目（HP・ちから・まりょく・まもり・すばやさ）、伸び、スキルの解放Lv、要るルーン（Lv n から n+1 へ n×100）、上限（Lv 30）は画面の確認のための仮の値であり、本ページの未決事項は決めていない。

- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、ルーンによるレベルアップと、レベルアップでのステータス上昇・パッシブスキル・固有スキルの解放を確定事項にした。冒険で得た装備・スキルを負けても保持することを反映し、冒険中のステータス上昇の持続は未決に分けた。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、育成の目的を強敵への再挑戦と探索の進展へ具体化した。毎戦の強化は要求せず、探索記録とゲーム概要を参照する。育成費用や成長曲線は今回確定しない。
