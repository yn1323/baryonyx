# 画面一覧：戦闘のスキルの山札と手札

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## スキルの山札

2026-10-03、ユーザーの依頼で作った[スキルの仮設定](../combat/cards.md#スキルの仮設定)の50枚から、4人に4枚ずつの16枚を山札にした。
最初の6枚は、それまでのカード（斬り払い・ファイア・アイスランス・サンダー・ヒール・ガード）で、テストで配る順に並べたときに開始時の手札になる。

| 使い手 | 山札のカード |
|---|---|
| アリア | 斬り払い・ガード・シールドバッシュ・居合一閃 |
| トーマ | ファイア・アイスランス・火の粉・メテオ |
| ルカ | サンダー・急所突き・チェインライトニング・蛇牙の連撃 |
| ミナ | ヒール・リジェネ・ホーリーライト・プロテクト |

居合一閃（当時コスト5）は、最初のターンのエネルギー（当時5）で使えるカットインの技として入れた。
メテオ（当時コスト9）は、エネルギーが足りないカードの見え方を確かめるために入れた。2026-10-26のエネルギー3固定からは、どちらもコスト3で、居合一閃は保持、メテオは眠り札のカードとして手札に残る・目覚める見え方も確かめられる。
2026-10-18、ユーザーの依頼で、[キーワード](../combat/cards.md#カードのキーワード)の説明札が積み重なる見え方を確かめるため、偵察を外し、キーワードを4つ持つ試作のカード「蛇牙の連撃」を入れた。50枚の外のカードで、挿絵は急所突き、演出は斬り払いのものを使う。
それまでアイスランスのコストを7にしてこの役を持たせていたが、仮設定ではアイスランスを2にしたため、役をメテオへ移した。

カードを使うと、仮設定の効果をモックでも処理する（ダメージ・回復・ブロック・状態・エネルギー・カードを引く・コストを下げる・次のカードを0にする・弱点の開示）。
威力は使い手のステータス（物攻・属攻・物防）の割合で、味方のステータスは各自のLv100の値と仮のLv（トーマ12・ルカ11・アリア10・ミナ10）から出す（[自キャラのLv100のステータス](../progression.md#自キャラのlv100のステータス)）。
ACTで威力が変わるカードは、今日のACTの仮の値（`BattleInspectView` の `TodayAct`、6,000）を使う。
仮設定の決まりは [BattleInspectView.Cards](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.Cards.cs) に置く。

### HPバーとブロック

ブロックは受けたダメージから先に引き、ターンをまたいで残る。量はその味方の最大HPまでである。全滅からの復活で消える。
味方のターンの始めに、残っているブロックは半分になり（[カードの状態の仮設定](../combat/cards.md#カードの状態の仮設定)）、黄色のバーを縮める（2026-10-22）。
ブロックの増減は黄色のバーの伸び縮みだけで見せ、「ブロック +〇」「ブロック -〇」の文字は出さない（2026-11-08、ユーザー決定）。
HPバーは、キャラと同じ1ドット4pxのドット絵として描く（[BattleHpGauge](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleHpGauge.cs)）。
角を1ドット欠いた暗い輪郭で囲み、HPの部分は上の1行を明るく、下の1行を暗くした3段の色に、空いた部分は暗くする。下の行には、4分の1ごとに輪郭と同じ色の目盛りを入れる。
大きさは、味方が30×7ドット（緑）、敵が65×8ドット（赤）である。
HPの長さはドット単位で変わり、HPが少しでも残れば1ドットは塗り、満タンのときだけ全部を塗る。
バーの中央に、今のHPの数値を重ねる（敵・味方とも。最大値は出さない）。数字はダメージの数字と同じDela Gothic Oneで、22pxの白に暗い縁取りと真下への影を付け、後ろに下地は敷かない。ブロックの黄色い帯より手前に描き、ブロックの量は数値にしない。HPが変わると、残像を待たずにすぐ書き換え、0未満にはしない（2026-10-24）。
HPが減ると、HPの部分はすぐに縮み、減った分が残像として残る。残像は0.12秒白く光ってから0.35秒とどまり、0.4秒で縮んで消える。縮む動きもドット単位である。
続けて当たったときは、残像が縮みきる前でも、その位置からとどまり直す。ヒットストップで戦闘が止まっている間は、残像も止まる。
残像の色は味方が赤で、敵は赤いバーと見分けるため薄いクリーム色にする。回復ではすぐに伸び、残像は出さない。
ブロックの量は、HPバーの上に左から黄色の細いバー（1ドットの黄色を暗い縁で囲んだもの）を重ねて表す。黄色のバーはHPバーの上へ1ドットはみ出してHPの明るい行を覆い、その下には緑のHPが見えたまま残る。
長さはHPと同じく最大HPを全体とし、最大HPを超える分はバーいっぱいで止める。数値と盾のアイコンは出さない。
ブロックはHPではないため、回復しても黄色のバーは伸びず、減ったHPの分（暗い部分）だけが回復で埋まる。

### 予告

カードを押して上げている間は、そのカードを使ったときの結果を、対象のHPバーで**予告**する（2026-10-24、[BattleInspectView.Forecast](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.Forecast.cs)）。
タップで使うときは対象を指す前に結果を見られないため、敵1体・味方1体に使うカードでも、選べる相手全員にそれぞれを選んだときの結果を同時に出す。
減るHPの区間を明るい朱色、回復するHPの区間をミント色で塗り、HPが行き着く位置のドットに白っぽい1ドットの縦線を引く。区間は0.9秒の周期で薄くなっては戻る点滅をし、縦線は点けたままにする。1ドットに満たない変化でも、端の1ドットを塗る。
増えるブロックは、黄色い帯の後ろに淡い金色の帯を重ね、増える分だけが帯の先に見えて同じ周期で点滅する。
HPの数値は今の値のまま変えない。カードを手札に戻す、持ち替える、使うと予告は消え、ほかのカードの効果が出ている間に上げたカードは、その時点のHPから予告し直す。
予告は、実際の処理と同じ威力・バフ・デバフ・防御・ブロック・パッシブで計算し、HPや状態は変えない。ただし次のものは入れない。

- まだ開示していない弱点の倍率（予告から弱点が分からないようにするため。実際のダメージは予告より大きくなり、開示の演出が理由を見せる）
- 確率で働くパッシブ（聖火の鉄槌のやけど）
- ランダムに当たるカード（ランダムな敵・跳ねる連鎖）の当たり方。敵ごとに1回当たった分だけを出す
- 状態の付与（予告しない）

停止中の表示の切り替えでは、カードを上げた状態に加えて、「予告（ダメージ）」「予告（回復）」「予告（ブロック）」を確かめられる。

### 状態のアイコン

敵も味方も、HPバーのすぐ下に、付いている状態のアイコンを1列に並べる（2026-11-03、ユーザー決定。[BattleInspectView.StatusIcons](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.StatusIcons.cs)）。
強化も状態異常も同じ列に出し、強化（攻撃・防御・速度の▲）を先に、ほかを後に、決まった順で並べる（[BattleStatusIcons](../../../client/Assets/Baryonyx/Features/Combat/Runtime/Battle/BattleStatusIcons.cs) の `Order`）。
敵も味方も、HPバーの左端から左に寄せて並べる（敵の弱点の列と同じ寄せ方。2026-11-03、ユーザーの指示）。倒れた味方と倒した敵には出さない。
アイコンは16×16ドットを1ドット3pxで出し、弱点のアイコン（12×12ドットを4px）と同じ48pxの高さにする。絵は `Features/Combat/UI/Art/Statuses/` にある。

能力を上げ下げする状態は、能力の絵に、上がるときは緑の上向きの三角、下がるときは赤の下向きの三角を右下に重ねた絵で出す。
上がり幅（+25%・+50%など）では絵を分けず、上がっているか下がっているかだけを示す（2026-11-03、ユーザー決定）。

| 絵 | 状態 |
|---|---|
| 剣と▲ | 攻撃力アップ、敵の力を溜める（次の攻撃が強くなる）、戦闘後の強化の背水・弔い |
| 丸い盾と▲ | プロテクト（防御アップとして扱う） |
| 丸い盾と▼ | 防御ダウン |
| 翼と▲ | 速度アップ、戦闘後の強化の先手 |
| 状態ごとの絵 | 出血、やけど、毒、凍え、凍結、麻痺、呪い、爆炎の刻印 |

麻痺（与えるダメージ-25%）と凍え（速度-30%）も能力を下げるが、▲▼の絵にせず、状態ごとの絵で出す（ユーザー決定）。
翼と▼の絵（`StatusSpeedDown`）は、速度だけを下げる状態を足すときのために置いてあり、今は使わない。
戦闘後の強化（背水・先手・弔い）は状態ではないが、効いている間は上の表のアイコンを出す（2026-11-08、ユーザー決定。効果の `Looks`）。
雷雲・リジェネ・挑発・反射・炎の加護・無敵には、まだアイコンがなく、列に出さない（下の状態の一覧には出る）。
敵の怒り（5ターン目から決まった技が強くなる）は技ごとの変化のため、アイコンを置かない。
味方の名前の札（カードを上げている間に出る）は、アイコンの列の上に重なる。

### 状態の一覧

カードを押していないときに敵か味方をタップすると、画面の上の中央（行動順の下）に、その**状態の一覧**を出す（2026-10-24、[BattleInspectView.StatusList](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.StatusList.cs)）。
一覧は、カードのキーワードの説明札と同じ札（幅520px、最大8枚）を縦に重ねたもので、1枚目に名前と「HP 480 / 801」のように今のHPと最大HPを、2枚目から状態を1つずつ書く。
状態の札は、見出しに状態の名前と残り（「残り2ターン」、毒は「×3」、凍結と反射は「1回」）を状態の色で書き、本文に効果を書く。効果の文は、キーワードの説明があればそれを使い、なければ状態ごとの短い文を使う（[CardRules](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CardRules.cs) の `StatusNote`）。状態がなければ「状態なし」と書く。アイコンは付けない。
同じキャラをもう一度タップするか、だれもいない場所（一覧の上を含む）をタップすると閉じる。別のキャラをタップすると、そのキャラの一覧に替わる。カードを押すと閉じる。
開いている間は、HPや状態が変わるたびに書き直し、その敵を倒すと閉じる。敵のターンの間も開ける。
タップは、カードを上げているときと同じ戦場のタップの受け皿（`TapArea`）が受ける。受け皿はカードを押している間だけ止め、操作（手札・ターン終了）より奥にあるため、操作のタップは奪わない。
停止中の表示の切り替えの「状態の一覧」では、狼に見本の状態（凍え・防御ダウン・毒）を付けて一覧を出す。

### 状態と浮かぶ文字

やけど・毒・リジェネ・爆炎の刻印・雷雲は、敵のターンが終わって味方のターンが始まるときに働く。
状態を付けると、その名前を**状態の帯**に書いて対象の上に出す（2026-11-03、ユーザー決定。[BattleStatusNotes](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleStatusNotes.cs)）。
帯は黒っぽい半透明の角の丸い板に、24pxの名前を状態の色で書いたもので、名前の左右に30pxの余白を取り、幅は132pxより狭くしない。
ダメージの数字の0.2秒あとに対象の真ん中から出て、右斜め上へ一定の速さ（毎秒160px、横には縦の0.35倍）で昇り、0.75秒で消える。出始めと終わりは透けている。
同じ対象に続けて付けたときは、0.25秒おきに1本ずつ出す（出血・毒・防御ダウンを同時に付けたときなど）。どれも同じ速さで昇るため、帯どうしは重ならない。
ターンの始まりの帯（「味方のターン」など）が出ている間は出さず、帯が消えてから0.2秒あとに、同じ順と間隔で出す（2026-11-08、ユーザーの指摘。ターンの始めに効き始めた背水の帯が、ターンの帯に重なっていた）。
状態が効かなかったとき（「効かなかった」）、凍結で行動を失ったとき（「凍結で動けない」）、行動を遅らせたとき（「行動が遅れる」）も同じ帯で出す。
攻撃や状態を止める効果（無敵・浄めの誓い・敵のすり抜けと身かわし）が働いたときは、止めた相手の上に「効かなかった」を出す（効果の `Resists`）。
戦闘後の強化が効き始めたとき（弔いは上がり幅が増えたときも）と、敵が次の攻撃を強めたときは、アイコンと同じ状態の名前（「攻撃力アップ」「速度アップ」）を帯で出す。
以前は状態の名前もダメージの数字の下へ1行ずつ積んで浮かべていたが、続けて付けると縦に長く積もって手札まで垂れ、読めなかったため帯に替えた。

同じ対象に続けて当たったダメージの数字は、1発ごとに場所を変えて出す（[BattleNumberScatter](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleNumberScatter.cs)）。
1発目は数字の出る位置に、2発目はその右上（右へ76px・上へ16px）、3発目は左下（左へ76px・下へ20px）、4発目は真下（下へ50px）に、それぞれ12pxまでのばらつきを付けて出し、5発目からはくり返す。会心の数字は大きいぶん、ずらす幅も大きさに合わせて広げる。上に別のキャラのHPバーがあると数字はその下に収まって上へずれないため、横か下へずらして前の数字に重ねない。少しの重なりは許す。合計の数字は出さない（2026-11-03、ユーザー決定）。
数字と状態の帯のほかに、浮かぶ文字は出さない（2026-11-08、ユーザー決定）。
パッシブ・装備・敵の技の効果の名前、ブロックの増減、エネルギー・引く枚数・コストの変化、弱点の開示、浄化、合体、2回発動、敵の激化と力を溜めている残りターンは、数字・HPバー・手札・アイコンの変わり方で伝わるため、文字にしない。
技はどれも仮のため、文字の代わりの専用の演出はまだ作らない。

## カードと手札を見ながら調整する

カードの見た目と手札の並びは、Unity Editor上で見ながら調整できる。
画面の生成（`Baryonyx > App > Create Battle Lab Scene`）は、次の2つが無いときだけ作り、あれば上書きしない。

| 調整したいもの | 開くもの | 内容 |
|---|---|---|
| カード1枚の見た目（挿絵・使い手・名前・種類と対象・説明・コスト・属性のアイコン・帯の位置や大きさ） | `Features/Combat/UI/BattleInspectCard.prefab` | Prefabを開いて子の位置・大きさ・文字の大きさを変える。手札の6枚すべてに反映される |
| 手札の並びと動き（カードの倍率、使えないカードの不透明度、押したときの倍率と画面中央からの上下のずれ、扇の角度・両端の角度の差の上限・半径・沈み方・高さ、配る枚数（開始時・毎ターン）と手札の上限、配る間隔と飛ぶ時間、山札を出るときの大きさと傾き、スワイプ量、タップとみなす動きの幅、当たり判定の余白、行動するキャラが出る距離と時間・効果のあとの待ち・敵の行動の間、ターンの始まりの帯を出しておく時間と現れて消える時間、ばねの強さ） | `Features/Combat/UI/BattleInspectHandSettings.asset` | Inspectorで値を変える。Play中に変えるとその場で反映され、アセットなのでPlayを止めても値が残る |

Play前の画面で並びを確かめるときは、シーンの `BattleInspectScreen` の `BattleInspectView` を右クリックし、「手札の並びを設定に合わせる」を選ぶ。
カードのPrefabを初期状態に戻すときは、`Baryonyx > Combat > Reset Battle Card Prefab` を実行する（手で加えた変更は消える）。
カードごとの文字・挿絵・枠・属性のアイコン・コストの数字・帯の幅は、画面の生成時にPrefabへ上書きして入れる。

このモックの行動順の並び（味方→狼→スライム→味方→味方→守り手の繰り返し）は、連続ターンの見た目を確かめるための固定の値である。
冒険の戦闘（`Battle`）では、2026-10-22から、行動順を敵と味方の速度で決める（[ターン順の仮設定](../combat/rules.md#ターン順の仮設定)）。表示の形は同じで、味方のターンのあとに、その回に動く敵が速い順に並ぶ。

### 絵とダメージの数字

背景・味方・敵・カードの挿絵は、Codex CLIの画像生成で作った。
[ドット絵の制作規格](../../art/direction.md#ドット絵の制作規格)の寸法（味方64×64で立ち姿48ドット、敵は小64・中96・大128、カードの挿絵32×32）へ縮小し、32色へ減色して1ドット4pxで表示する。
味方4人の見た目はホームのアリア・トーマ・ルカ・ミナに合わせたが、正式なキャラ設定・敵の定義ではないため、[データ索引](../../catalog/README.md)には登録していない。
画像は機能内の `Features/Combat/UI/Art/` に置く。
背景（`BattleBackground.png`）は256色を超えるため、PNGのままにしている。
2026-09-30のカードの作り直しで、挿絵を64×58ドットにした。
カードの枠（`CardFrame<属性>`、70×98）、コストの札（`CardCostFrame`、11×11）と数字（`CardCostDigits`、5×7を10個）も同日にPythonのスクリプトで描き直した（`output/card-redesign/final_art.py`、Git対象外）。
弱点のアイコン（属性の6つは `Shared/Art/Attributes/`、未開示の「？」は `Art/Elements/`）、カードの部品（属性ごとの枠 `CardFrame<属性>`・`CardCostFrame`・`CardCostDigits`）、エネルギーの宝石（`EnergyGem`）、ターン終了の枠（`EndTurnFrame`）は、2026-09-29にPythonのスクリプトで1ドットずつ描き、インデックスカラーの `.aseprite` へ変換した。
打と貫の属性のアイコン（`ElementBlunt`・`ElementPierce`、12×12ドット）と、カードの枠（`CardFrameBlunt`・`CardFramePierce`、70×98ドット）は、2026-10-03にほかの属性と同じスクリプトで描いた（`output/card-skills/new_elements.py`、Git対象外）。打は青銅の地に槌、貫は青緑の地に槍の穂先である。
2026-11-02に、属性の印とコストの数字をドット絵からなめらかな印（PNG）へ替え、コストの札（`CardCostFrame`）をなくしたが、2026-11-03にユーザーの指示「ドット絵の方がいいかも」で、上のドット絵の `.aseprite` に戻した（[属性とコストの印](../../rules/ui-design.md#属性とコストの印)）。
対象を選ぶときのカーソル（`TargetCursor`、11×7ドット）と、引っぱるときに並べる点（`AimDot`、5×5ドット）は、2026-09-30に同じ方法で描いて `.aseprite` へ変換し、1ドット4pxで表示する。
使い手の足元の輪（`CasterRing`、38×10ドット、4色）は、2026-10-01に同じ方法で描いて `.aseprite` へ変換し、1ドット4pxで表示する。左上からの光に合わせて奥の左側を明るく、手前の右側を暗くし、内側はディザで薄くしている。
カードの裏面（`CardBack`、70×98ドット。紺の地に菱形の格子、くすんだ金の縁、中央に水色のルーンの星）と山札の絵（`DeckIcon`、15×19ドット。裏面を3枚、右下へずらして重ねた絵）は、2026-09-30に同じ方法で描いて `.aseprite` へ変換した。裏面は1ドット3px、山札の絵は1ドット4pxで表示する。
対象のキャラを白く光らせる表示は、専用のUIシェーダー（`UI/Shaders/UiFlash.shader`）で絵の色を白へ近づけている。

ダメージと回復の数字は、2026-09-30にユーザーの依頼で、DotGothic16から極太のゴシック体のDela Gothic Oneへ変えた。
ドット絵の上に滑らかな文字を重ね、上から下へのグラデーション、暗い縁取り、真下に落とす影の3つで立体感を出している。
色は、通常が白からベージュ、弱点が橙から赤、会心が薄い黄から金、回復が緑である。弱点に会心が当たったときは会心の色で出す。大きさは会心、弱点、通常、回復の順に小さくする。
会心も弱点も、文字（「会心！」など）は添えず、数字の色と大きさだけで伝える（2026-11-03、ユーザー決定）。
数字は出るときに1.3倍からなめらかに縮んで止まり、1秒で消える。縁取りは、HPの数字より細くしている。
2026-11-03に、ユーザーの指摘「ちょっとポップすぎる」で、弾ける大きさを1.8倍から1.3倍に、縁取りを細くした。
同じ日に、色だけに頼らないよう、弱点の印を光らせる・数字の後ろに星形の光や集中線を出す・属性の色の台や残像を重ねる、といった文字なしの印を足す5案を見せたが、ユーザーが「全部ダサい」として、色と大きさだけで分ける今の形を続けることにした。
フォントとマテリアルは `Features/Combat/UI/Fonts/`（[フォントの出典](../../../client/Assets/Baryonyx/Features/Combat/UI/Fonts/README.md)）に置き、[DamageNumberAssets](../../../client/Assets/Baryonyx/Features/Combat/Editor/DamageNumberAssets.cs) が画面の生成時に作る。
ブロックの文字は、ゲーム全体と同じKiwi Maruにしている。
