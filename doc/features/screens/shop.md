# 画面一覧：商会

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 商会

商会では、装備・スキル・素材の売り買いと合成、持ち物の強化を扱う。
合成できる物（武器・防具・アクセサリー・カスタムスキル）と決まりは[合成](../synthesis.md)に従う。

メニューは「買う」「売る」「合成」「品質強化」「スキル覚醒」の5つである（2026-10-24。「強化」を足したあと、同じ日に品質強化とスキル覚醒の2つに分けた）。
売買にはルーンを使うことを、ユーザーが決めた（[ルーンの用途](../economy.md#ルーンの用途)）。

### 画面の形

メニューで項目を押すと、案内人を隠して、画面いっぱいの[枠つきの表示](guide.md#枠つきの表示)で開く（2026-10-24、ユーザーの依頼）。
ヘッダーの下を、左端のタブの列（横256まで）、一覧の面、右の面（横1160から）の3つの透ける面に分け、間に金の2本線を引く。
タブの列には分類のタブを縦に並べ、一覧の面に品物や対象を並べ、右の面に選んだ物を大きく出して、右下に決めるボタンを置く（2026-10-31、ユーザーの「タブが押しづらい」「右半分が大きすぎる」を受けて。それまでは一覧の上に横のタブを置き、合成・品質強化・スキル覚醒は右の面を横800から取っていた）。
タブは[分類の切り替え](../../rules/ui-design.md#分類の切り替え)の縦の分類（`GuideFrameAssets.SideTabs`）にする。
一覧の面の上には、選んでいる分類の名前（金のひし形の見出し）と、並べた数（「12件」。読めないうちは「-」）の段を置く。ライブラリの一覧と同じ段で、買う・売るは格子と詳細、合成・品質強化は行と詳細、スキル覚醒は全幅の一覧のテンプレートから作る（2026-11-01、[画面の型](../../rules/ui-design.md#画面の型)）。
右の面の幅は5つの項目でそろえる。
「もどる」でメニューに戻ると、案内人が戻る。
参考画像はCodex CLIの画像生成で作り、ユーザーが「大部分はあってます」とした。

| 項目 | タブの列と一覧の面 | 右の面 |
|---|---|---|
| 買う | 武器・防具・アクセサリー・スキルのタブ。品物を4列の札で並べる | 品質の1行、絵を大きく、名前、☆、効果、持っている数を、上下中央にまとめて並べる（スキルは絵・名前・効果の代わりにデッキのカード）。下に値段と「買う」 |
| 売る | 武器・防具・アクセサリー・スキル・アイテムのタブ。持ち物を、買うと同じ形の札で4列に並べる | 選んだ物の行（装備は効果も）と、合計。下に「売る」 |
| 合成 | 武器・防具・アクセサリー・スキルのタブ（2026-10-31）。作れる物を行で並べる | 出来上がる物の絵・名前・☆・効果と出来上がる品質、材料の札（4列）、費用と「合成」 |
| 品質強化 | スキル・装備・固有スキルのタブ。対象を行で並べる | 名前、強化する前と後のカード（装備は品質の色の縁の札）と品質、品質のゲージ、磨き石と使う数、その下に費用と足りない物の1行、「強化」（[商会の強化](../enhancement.md#強化の画面)） |
| スキル覚醒 | タブの列と右の面を置かず、見出し「覚醒できる固有スキル」の下に、まだ覚醒できるスキルを画面の幅いっぱいの1本の一覧にする（[スキル覚醒](#スキル覚醒)） | なし。行を押すと覚醒の場面を重ねる |

買う・合成・品質強化は、右の面が空にならないよう、開いたときとタブを替えたときに一覧の先頭の物を選んでおく（品質強化は2026-10-24、買う・合成は2026-10-26、ユーザーの指示）。
一覧が空のときだけ、右の面に何も出さない。
売るは、開いたときに何も選ばない。
押した札がそのまま売る物に加わり、選んだ物をまとめて売る画面のため、勝手に選ぶと気づかずに売ってしまうおそれがあるからである。

### 買う

「買う」では、これまでに手に入れたスキル・武器・防具・アクセサリーを、品質の最低（品質C・×1.00）で何度でも買える（2026-10-24、ユーザーの指示）。
これまでに手に入れた物とは、[ライブラリ](../library.md)の見つけた記録に載っている物で、売ったり合成に使ったりして手元になくても買える。
アイテム（道具・素材）は並べない。

| 項目 | 決まり |
|---|---|
| 並べ方 | タブの分類の品物を、安い順（同じ値段は定義の順）に並べる。開くたびにサーバーから見つけた記録を読み直し、初めて開いて読むまでは「読み込み中…」を出す。開き直したときは、前に読んだ記録の品物をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)） |
| 札 | 左上に品質の文字（いつもC。品質の色、背景なし。売るの札と同じ位置）、種類の絵、名前、☆、ルーンのアイコンと値段 |
| 値段 | ☆1が1,000ルーンで、☆が1つ増えるごとに倍にする（☆2 2,000、☆3 4,000、☆4 8,000、☆5 16,000）。品質を選べない代わりに、[行商人](../stage-progression/rooms.md#マスの中身仮)の品質Cの値段（☆1で1,500）より安くした。仮の値で、2026-10-26に5倍にした（[ルーン経済の記録](../economy.md#変更と判断の記録)） |
| 右の面 | 上から、品質の1行、選んだ品物の絵、名前、☆、効果、装備の[属性](../equipment.md#装備の属性)のアイコン、持っている数を書き、まとめて右の面の上下中央に置く。属性のアイコンは効果のすぐ下に左右中央にそろえて並べ、属性なしの装備とスキルでは行ごと出さない（2026-11-03、ユーザーの指示）。左の札には属性を出さない。品質の1行は、絵（スキルはカード）の真上に、品質の文字（C）を品質の色で大きく（120px）、横に倍率「×1.00」を書く。「品質」とは書かず、装備もスキルも同じ位置・同じ形にする。分類はタブでわかるため書かない（2026-10-31、ユーザーの指示。品質の置き方は、Codexへの相談と画面の調べものから作った装備・スキル共通の5案からユーザーが選んだ）。スキルは、絵・名前・効果の代わりに、戦闘と同じデッキのカード（70×98ドットを4倍）を品質C・×1.00で出す（2026-10-24、ユーザーの指示「スキルを買う時、右側の画面にはカードを表示してほしい」）。所持ルーンが足りなければ「ルーンが 〇〇 足りません」と書き、「買う」を押せなくする |
| 買い方 | 札を選んで右下の「買う」を押す。確認のダイアログは出さず、選ぶ・押すの2回の操作で確かめる。押すとすぐ[買ったときの演出](#買ったときの演出)を流し、値段を右上の所持ルーンから引いて見せ、裏でサーバーに保存する（[楽観的更新](../../rules/data-storage.md#サーバーに置くときの作り方)）。通知の帯は出さない（2026-11-02、ユーザーの指示）。選んだまま押し直せば、同じ物をもう1つ買える |
| 保存できなかったとき | 引いた値段を所持ルーンへ、先に足した持っている数を元の数へ戻し、通知の帯で「買えませんでした」と知らせる。画面を閉じたあとでも、開いている案内人の画面かホームで知らせる |
| 持ち物 | 買った物は1つずつ倍率×1.00で持ち物に入り、編成の[装備](loadout.md#装備)・[スキル](loadout.md#スキル)で付けられる |

### 売る

持ち物を、同じ種類でも1つずつ別の札で並べる。
スキル・装備は1つずつ品質が違うため、「×3」のようにまとめない（2026-10-24、ユーザーの指示）。
品質を持たないアイテムだけは、種類ごとに1枚の札にして数を書く。

| 項目 | 決まり |
|---|---|
| 札 | 買うの札と同じく、種類の絵、名前、☆、ルーンのアイコンと売値を出す。左上に品質の文字（品質の色、背景なし。アイテムは出さない）、アイテムは絵の右下に数。付けている物・デッキに入れている物は右上に「E」を出し、選べなくする（2026-10-31、ユーザーの指示「買うの画面のカードと同じような感じに」） |
| 選び方 | 札を押すたびに選ぶ・やめるを切り替え、いくつでも選べる。右の面に、選んだ物の行（絵・名前・品質・値段）と合計を出す。行の品質は、買うと同じく「品質」と書かずに、品質の文字を品質の色で大きめに書き、横に倍率を書く。値段はルーンのアイコンと数で書く（2026-10-31、ユーザーの指示）。装備の行は、右上（名前の行）に[属性](../equipment.md#装備の属性)のアイコンを並べ、値段を右下（品質・効果の行）へ下げる。左の札には属性を出さない（2026-11-03、ユーザーの指示）。装備の行は、品質の横に、その倍率での効果（「物攻の125%」など）を書く（2026-10-24、ユーザーの指示「装備を売るときに、その装備のステータスも見れるようにして」）。右の行を押しても選ぶのをやめる。「選びなおす」のボタンは、札をもう一度押せばやめられるため置かない（2026-10-31、ユーザーの指示）。選んだ札は、チェックボックスの役を示すため、金の縁と光に加えて地もうすく金色にする（ほかの画面の選んだ札は縁と光だけ、2026-11-02、ユーザー） |
| 値段 | 仮の値。スキル・装備は買う値段の20分の1に倍率を掛けて四捨五入し（2026-10-26に買う値段を5倍にしたとき、売値の額が変わらないよう4分の1から改めた）、アイテムは☆1の10ルーンから☆ごとに倍にして数を掛ける。サーバーが同じ式で決める |
| 決定 | 確認のダイアログは出さず、「売る」を押すと選んだ物をまとめてサーバーで売る。答えが届いたら[売ったときの演出](#売ったときの演出)を流し、売った物を一覧から外して、残高を得た後の値にする。通知の帯は出さない（2026-11-02、ユーザーの指示）。売れなければ「売れませんでした」と知らせて持ち物を読み直す。1回で売れるのは50点まで |
| 売れる物 | キャラに付けている装備、デッキに入れているスキル・アイテムは売れない。アイテムは種類ごとに持っている数をすべて売る |

### 買ったときの演出

「買う」を押すと、画面全体を紺に沈め、買った物が中央で弾けて光り、暗転と一緒にその場で消える（2026-11-02、ユーザーが画像の案から「合成の最後と同じ現れ方」を選び、同じ日に「右の物が中央へ移動して戻る演出は不要」とした）。
[合成の演出](../synthesis.md#合成の演出)（光の渦）と同じ部品で、材料と渦を除いた終わりだけを流す。
右の面の絵とデッキのカードは隠さず、動かさない。
絵の上を斜めに走る光（キラン）は、合成では☆4・☆5だけだが、買うではどの☆でも出す。
☆4は金、☆5は淡い虹にし、弾ける前に溜める分と現れたあとに残す分だけ長くする（合成と同じ）。
画面のどこかを押すと、消える所まで飛ばす。

| 時刻（秒） | 拍 | 起きること |
|---|---|---|
| 0〜0.15 | 押した手応え | 「買う」が沈んで戻る。画面全体が紺に沈む（奥の画面を薄く残す） |
| 0.15 | 弾ける | 中央に買った物が現れ、細い光線と品質の色の細い輪が広がる |
| 0.15〜0.6 | 現れる | 中央で少し跳ねて止まり、まわりのきらめきと、キランが残る |
| 0.6〜0.9 | 消える | 買った物が中央のまま薄れ、暗転と一緒に消える |

### 売ったときの演出

サーバーの答えが届くと、左の一覧の売った札と右の面の行が、少し膨らみながら0.28秒で消える（2026-11-02、ユーザーが画像の案から「ホームと同じ」を選んだ）。
同時に、右の面の行から得たルーンが四方へ広がり、右上の所持ルーンへ吸い込まれる。
ルーンの数と動き、所持ルーンの数え上げと光り方、所持ルーンの下に出す「+得た数」は、[ホームのルーン獲得の演出](top-home.md#ルーン獲得の演出)と同じ部品（`RuneGainEffect`）で描く。
違うのはルーンの出どころだけで、右の面の行（行の数で分け合う）から出す。
札と行が消えたら一覧を詰め、右の面を空にする。

### 合成

合成の決まりは[合成](../synthesis.md)に従う。
品物ごとに決まった材料（レシピ）をそろえ、すべて使って作る（2026-10-31）。
下の表は2026-10-31に決めて作った形である（[合成の実装との対応](../synthesis.md#実装との対応)）。

| 項目 | 決まり |
|---|---|
| タブ | 武器・防具・アクセサリー・スキル。アイテムは合成で作らないため、タブを置かない |
| 左の一覧 | [一覧に出す条件](../synthesis.md#レシピ)に当たる物を、☆の低い順に並べる（絵・名前・☆）。まだ手に入れたことのない物は[まだ見つけていない物の見せ方](../synthesis.md#まだ見つけていない物の見せ方)に従う。材料がそろわない物は、暗くしたうえで選べる |
| 右の面 | 出来上がる物の絵・名前・☆・効果と、出来上がる品質（品質の文字を品質の色で大きく）と倍率。買うの右の面と同じく、上の中央に絵、その下に名前、☆と品質の1行、効果を中央に並べる（2026-11-01）。その下に「材料」の見出しと、レシピの材料を1種類ずつ札にして横に並べる（4列）。札には絵と右下に「持っている数/要る数」（足りない数は赤）を出し、札の下に名前を書く（2026-10-31、画面の案からユーザーが選んだ。ライブラリのレシピと同じ形）。まだ手に入れたことのない物と材料は[まだ見つけていない物の見せ方](../synthesis.md#まだ見つけていない物の見せ方)に従う |
| 装備・スキルの材料 | 札の左上に、使う物の品質の文字を品質の色で出す。初めに選んでおく物は[材料の選び方](../synthesis.md#レシピ)に従う。札を押すと[使う物を選ぶ画面](#使う物を選ぶ画面)を開き、品質の違う物に替えられる |
| 足りないとき | 「船乗りのロープが 1 つ足りません」「ルーンが 〇〇 足りません」のように書き、「合成」を押せなくする |
| 合成の仕方 | 確認のダイアログは出さず、選ぶ・押すの操作で確かめる。押すとすぐ、材料を持ち物から消し、出来た物を足し、費用を右上の所持ルーンから引き、裏でサーバーに保存する（[楽観的更新](../../rules/data-storage.md#サーバーに置くときの作り方)。2026-10-31、ユーザーの指示）。出来上がる品質は、サーバーと同じ計算で手元で決めて見せる。まだ手に入れたことのない物は、このとき名前・絵・効果を見せる。出来た物は、サーバーの答えが届くまで、ほかのレシピの材料に使えない。保存できなかったら「合成できませんでした」と知らせ、引いたルーンを戻し、持ち物を読み直す。画面を閉じたあとなら、開いている案内人の画面かホームで知らせる。押したあとは[合成の演出](../synthesis.md#合成の演出)（光の渦）を流し、出来た物が右の面の絵の位置へ戻ったら「〇〇（品質B）を作った」と知らせて絵を大きくして戻す |

#### 使う物を選ぶ画面

装備・カスタムスキルを材料にするレシピで、どの1つを使うかを選ぶ画面である（2026-10-31、ユーザーの「装備は品質違いがあるので、モーダル的に出して変えられるように」）。
同じ種類でも1つずつ品質が違い、使う物の品質で出来上がる品質が変わるためである（[出来上がる品質](../synthesis.md#出来上がる品質)）。
窓の枠や見出しは置かず、画面を薄暗くした上に札だけを並べる（ユーザーの「モーダルは仰々しい」）。

| 項目 | 決まり |
|---|---|
| 開き方 | 合成の右の面で、装備・スキルの材料の札を押す。アイテムの札は押しても開かない |
| 見た目 | 画面全体を薄暗くし、その手前の中央に札を並べる。枠・背景の板・見出しは置かない。札は透けない色で塗る（2026-10-31、ユーザーの指示）。右下に、戦闘のターン終了と同じ丸いチェックを置く |
| 並べる物 | その種類で持っている物を1つずつ、[すりガラスのカード](guide.md#すりガラスのカード)の札で4列に並べる。札には左上に品質の文字（品質の色）、絵、倍率、その倍率での効果（「物攻 +18%」など）を出す。品質の低い順に並べる |
| たくさん持っているとき | 札の並ぶ所は画面の上から下まで使い、その中を上下に動かす。動かせることを示す棒は出さず、画面の下の端で札が切れることでわかるようにする |
| 使っている物 | キャラが付けている装備、デッキに入れているスキルは、右上に「E」を出して暗くし、選べなくする |
| 選び方 | 札を押すと、その札を選ぶ（金の縁と光）。丸いチェックを押すと、選んだ物を使う物にして閉じ、合成の右の面の札の品質と出来上がる品質を変える。札の外の暗い所を押すと、変えずに閉じる |

### 品質強化とスキル覚醒

「品質強化」では磨き石とルーンで品質を上げ、「スキル覚醒」では覚醒の欠片とルーンで固有スキルとスキルを覚醒させる。2つは別の項目・別の画面である（2026-10-24）。選ぶ順・画面の決まりと今の実装は[商会の強化](../enhancement.md)に従う。

### スキル覚醒

まだ覚醒できるスキルを、タブを置かずに1本の一覧にする（2026-10-31、ユーザーが画像の5案から「基本」を選んだ）。
固有スキルとカスタムスキルを分けず、横長のカード1枚を1行にする。
タブで分ける案・種類で並べる案・キャラごとに選ぶ案は、カスタムスキルが数百枚になると探しにくく、「カスタムスキル」という言葉で区別させることになるため、採らなかった。

| 項目 | 決まり |
|---|---|
| 並び | パーティの順にキャラごと、その人の固有スキル（番号の順）、続けてその人のカスタムスキルの枠に入れているスキル（枠の順）。パーティのあとに控えのキャラを同じように並べ、最後に、誰にも付けていないスキルを品質の高い順（同じ品質はスキルの定義の順、同じ種類は倍率の高い順）に並べる |
