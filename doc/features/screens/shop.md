# 画面一覧：商会

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 商会

商会では、装備・スキル・素材の売り買いと合成、持ち物の強化を扱う。
合成できる物（素材・道具・武器・防具・アクセサリー・スキル）と決まりは[合成](../synthesis.md)に従う。
案内人は貴族の少年武具商である。

メニューは「買う」「売る」「合成」「品質強化」「スキル覚醒」の5つである（2026-10-24。「強化」を足したあと、同じ日に品質強化とスキル覚醒の2つに分けた）。
売買にはルーンを使うことを、ユーザーが決めた（[ルーンの用途](../economy.md#ルーンの用途)）。

### 画面の形

メニューで項目を押すと、案内人を隠して、画面いっぱいの[枠つきの表示](guide.md#枠つきの表示)で開く（2026-10-24、ユーザーの依頼）。
ヘッダーの下を、左端のタブの列（横256まで）、一覧の面、右の面（横1160から）の3つの透ける面に分け、間に金の2本線を引く。
タブの列には分類のタブを縦に並べ、一覧の面に品物や対象を並べ、右の面に選んだ物を大きく出して、右下に決めるボタンを置く（2026-10-31、ユーザーの「タブが押しづらい」「右半分が大きすぎる」を受けて。それまでは一覧の上に横のタブを置き、合成・品質強化・スキル覚醒は右の面を横800から取っていた）。
タブは、[冒険者のタブ](adventurers.md#冒険者のタブ)と同じ縦のタブで、選んでいるタブを明るい金の文字と左の金の縦線で示す。
右の面の幅は5つの項目でそろえる。
「もどる」でメニューに戻ると、案内人が戻る。
参考画像はCodex CLIの画像生成で作り、ユーザーが「大部分はあってます」とした。

| 項目 | タブの列と一覧の面 | 右の面 |
|---|---|---|
| 買う | 武器・防具・アクセサリー・スキルのタブ。品物を4列の札で並べる | 品質の1行、絵を大きく、名前、☆、効果、持っている数を、上下中央にまとめて並べる（スキルは絵・名前・効果の代わりにデッキのカード）。下に値段と「買う」 |
| 売る | 武器・防具・アクセサリー・スキル・アイテムのタブ。持ち物を、買うと同じ形の札で4列に並べる | 選んだ物の行（装備は効果も）と、合計。下に「売る」 |
| 合成 | 武器・防具・アクセサリー・スキル・磨き石のタブ（2026-10-31）。作れる物を行で並べる | 出来上がる物の絵・名前・☆・効果と出来上がる品質、材料の札（4列）、費用と「合成」 |
| 品質強化 | スキル・装備・固有スキルのタブ。対象を行で並べる | 名前、強化する前と後のカード（装備は品質の色の縁の札）と品質、品質のゲージ、磨き石と使う数、その下に費用と足りない物の1行、「強化」（[商会の強化](../enhancement.md#強化の画面)） |
| スキル覚醒 | タブの列と右の面を置かず、まだ覚醒できるスキルを画面の幅いっぱいの1本の一覧にする（[スキル覚醒](#スキル覚醒)） | なし。行を押すと覚醒の場面を重ねる |

買う・合成・品質強化は、右の面が空にならないよう、開いたときとタブを替えたときに一覧の先頭の物を選んでおく（品質強化は2026-10-24、買う・合成は2026-10-26、ユーザーの指示）。
一覧が空のときだけ、右の面に何も出さない。
売るは、開いたときに何も選ばない。
押した札がそのまま売る物に加わり、選んだ物をまとめて売る画面のため、勝手に選ぶと気づかずに売ってしまうおそれがあるからである。

### 買う

「買う」では、これまでに手に入れたスキル・武器・防具・アクセサリーを、品質の最低（品質C・×1.00）で何度でも買える（2026-10-24、ユーザーの指示）。
これまでに手に入れた物とは、[ライブラリ](../library.md)の見つけた記録に載っている物で、売ったり合成に使ったりして手元になくても買える。
アイテム（道具・素材）は並べない。

| 項目 | 決まり |
|---|---|
| 並べ方 | タブの分類の品物を、安い順（同じ値段は定義の順）に並べる。開くたびにサーバーから見つけた記録を読み直し、初めて開いて読むまでは「読み込み中…」を出す。開き直したときは、前に読んだ記録の品物をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)） |
| 札 | 左上に品質の文字（いつもC。品質の色、背景なし。売るの札と同じ位置）、種類の絵、名前、☆、ルーンのアイコンと値段 |
| 値段 | ☆1が1,000ルーンで、☆が1つ増えるごとに倍にする（☆2 2,000、☆3 4,000、☆4 8,000、☆5 16,000）。品質を選べない代わりに、[行商人](../stage-progression.md#マスの中身仮)の品質Cの値段（☆1で1,500）より安くした。仮の値で、2026-10-26に5倍にした（[ルーン経済の記録](../economy.md#変更と判断の記録)） |
| 右の面 | 上から、品質の1行、選んだ品物の絵、名前、☆、効果、持っている数を書き、まとめて右の面の上下中央に置く。品質の1行は、絵（スキルはカード）の真上に、品質の文字（C）を品質の色で大きく（120px）、横に倍率「×1.00」を書く。「品質」とは書かず、装備もスキルも同じ位置・同じ形にする。分類はタブでわかるため書かない（2026-10-31、ユーザーの指示。品質の置き方は、Codexへの相談と画面の調べものから作った装備・スキル共通の5案からユーザーが選んだ）。スキルは、絵・名前・効果の代わりに、戦闘と同じデッキのカード（70×98ドットを4倍）を品質C・×1.00で出す（2026-10-24、ユーザーの指示「スキルを買う時、右側の画面にはカードを表示してほしい」）。所持ルーンが足りなければ「ルーンが 〇〇 足りません」と書き、「買う」を押せなくする |
| 買い方 | 札を選んで右下の「買う」を押す。確認のダイアログは出さず、選ぶ・押すの2回の操作で確かめる。押すとすぐ「〇〇を 1,000 ルーンで買った」と知らせ、値段を右上の所持ルーンから引いて見せ、裏でサーバーに保存する（[楽観的更新](../../rules/data-storage.md#サーバーに置くときの作り方)）。選んだまま押し直せば、同じ物をもう1つ買える |
| 保存できなかったとき | 引いた値段を所持ルーンへ、先に足した持っている数を元の数へ戻し、通知の帯で「買えませんでした」と知らせる。画面を閉じたあとでも、開いている案内人の画面かホームで知らせる |
| 持ち物 | 買った物は1つずつ倍率×1.00で持ち物に入り、編成の[装備](loadout.md#装備)・[スキル](loadout.md#スキル)で付けられる |

### 売る

持ち物を、同じ種類でも1つずつ別の札で並べる。
スキル・装備は1つずつ品質が違うため、「×3」のようにまとめない（2026-10-24、ユーザーの指示）。
品質を持たないアイテムだけは、種類ごとに1枚の札にして数を書く。

| 項目 | 決まり |
|---|---|
| 札 | 買うの札と同じく、種類の絵、名前、☆、ルーンのアイコンと売値を出す。左上に品質の文字（品質の色、背景なし。アイテムは出さない）、アイテムは絵の右下に数。付けている物・デッキに入れている物は右上に「E」を出し、選べなくする（2026-10-31、ユーザーの指示「買うの画面のカードと同じような感じに」） |
| 選び方 | 札を押すたびに選ぶ・やめるを切り替え、いくつでも選べる。右の面に、選んだ物の行（絵・名前・品質・値段）と合計を出す。行の品質は、買うと同じく「品質」と書かずに、品質の文字を品質の色で大きめに書き、横に倍率を書く。値段はルーンのアイコンと数で書く（2026-10-31、ユーザーの指示）。装備の行は、品質の横に、その倍率での効果（「物攻の125%」など）を書く（2026-10-24、ユーザーの指示「装備を売るときに、その装備のステータスも見れるようにして」）。右の行を押しても選ぶのをやめる。「選びなおす」のボタンは、札をもう一度押せばやめられるため置かない（2026-10-31、ユーザーの指示） |
| 値段 | 仮の値。スキル・装備は買う値段の20分の1に倍率を掛けて四捨五入し（2026-10-26に買う値段を5倍にしたとき、売値の額が変わらないよう4分の1から改めた）、アイテムは☆1の10ルーンから☆ごとに倍にして数を掛ける。サーバーが同じ式で決める |
| 決定 | 確認のダイアログは出さず、「売る」を押すと選んだ物をまとめてサーバーで売る。答えが届いたら、売った物を一覧から外し、残高を得た後の値にして「N点をMルーンで売った」と知らせる。売れなければ「売れませんでした」と知らせて持ち物を読み直す。1回で売れるのは50点まで |
| 売れる物 | キャラに付けている装備、デッキに入れているスキル・アイテムは売れない。アイテムは種類ごとに持っている数をすべて売る |

### 合成

合成の決まりは[合成](../synthesis.md)に従う。
品物ごとに決まった材料（レシピ）をそろえ、すべて使って作る（2026-10-31）。
下の表は2026-10-31に決めて作った形である（[合成の実装との対応](../synthesis.md#実装との対応)）。

| 項目 | 決まり |
|---|---|
| タブ | 武器・防具・アクセサリー・スキル・磨き石。アイテムは合成で作らないため、タブを置かない。磨き石のタブでは、1つ下の色3個で上の色を作る（[磨き石の合成](../enhancement.md#磨き石の合成)、2026-10-31） |
| 左の一覧 | レシピの材料のどれか1つでも手に入れたことのある物を、☆の低い順に並べる（絵・名前・☆）。まだ手に入れたことのない物は、絵を影にし、名前を「？？？」にする。材料がそろわない物は、暗くしたうえで選べる |
| 右の面 | 出来上がる物の絵・名前・☆・効果と、出来上がる品質（品質の文字を品質の色で大きく）と倍率。まだ手に入れたことのない物は、絵を影にし、名前と効果を「？？？」にして☆だけを出す。その下に「材料」の見出しと、レシピの材料を1種類ずつ札にして横に並べる（4列）。札には絵と右下に「持っている数/要る数」（足りない数は赤）を出し、札の下に名前を書く。まだ手に入れたことのない材料は、絵を影にし名前を「？？？」にする（2026-10-31、画面の案からユーザーが選んだ。ライブラリのレシピと同じ形） |
| 装備・スキルの材料 | 札の左上に、使う物の品質の文字を品質の色で出す。初めは品質の低い物を選んでおく。札を押すと[使う物を選ぶ画面](#使う物を選ぶ画面)を開き、品質の違う物に替えられる |
| 足りないとき | 「船乗りのロープが 1 つ足りません」「ルーンが 〇〇 足りません」のように書き、「合成」を押せなくする |
| 磨き石のタブ | 青・紫・金を行で並べ、作れない色を暗くする。右の面は、作る石の絵・名前・☆・どこまで上げられるか（「ゲージを10%進める（Aまで）」）と持っている数（「×4」）、材料に1つ下の色の札を1枚（持っている数/3）。押すと光の渦を流し、下の色の石3つが渦に飛び込んで上の色の石が現れる。石の数は、サーバーの答えを待ってから書き換える（[商会の強化の実装との対応](../enhancement.md#実装との対応)） |
| 合成の仕方 | 確認のダイアログは出さず、選ぶ・押すの操作で確かめる。押すとすぐ、材料を持ち物から消し、出来た物を足し、費用を右上の所持ルーンから引いて、「〇〇（品質B）を作った」と知らせて絵を大きくして戻し、裏でサーバーに保存する（[楽観的更新](../../rules/data-storage.md#サーバーに置くときの作り方)。2026-10-31、ユーザーの指示）。出来上がる品質は、サーバーと同じ計算で手元で決めて見せる。まだ手に入れたことのない物は、このとき名前・絵・効果を見せる。出来た物は、サーバーの答えが届くまで、ほかのレシピの材料に使えない。保存できなかったら「合成できませんでした」と知らせ、引いたルーンを戻し、持ち物を読み直す。画面を閉じたあとなら、開いている案内人の画面かホームで知らせる。押したあとは[合成の演出](../synthesis.md#合成の演出)（光の渦）を流す |

#### 使う物を選ぶ画面

装備・カスタムスキルを材料にするレシピで、どの1つを使うかを選ぶ画面である（2026-10-31、ユーザーの「装備は品質違いがあるので、モーダル的に出して変えられるように」）。
同じ種類でも1つずつ品質が違い、使う物の品質で出来上がる品質が変わるためである（[出来上がる品質](../synthesis.md#出来上がる品質)）。
窓の枠や見出しは置かず、画面を薄暗くした上に札だけを並べる（ユーザーの「モーダルは仰々しい」）。

| 項目 | 決まり |
|---|---|
| 開き方 | 合成の右の面で、装備・スキルの材料の札を押す。アイテムの札は押しても開かない |
| 見た目 | 画面全体を薄暗くし、その手前の中央に札を並べる。枠・背景の板・見出しは置かない。札は透けない色で塗る（2026-10-31、ユーザーの指示）。右下に、戦闘のターン終了と同じ丸いチェックを置く |
| 並べる物 | その種類で持っている物を1つずつ、[すりガラスのカード](guide.md#すりガラスのカード)の札で4列に並べる。札には左上に品質の文字（品質の色）、絵、倍率、その倍率での効果（「物攻 +18%」など）を出す。品質の低い順に並べる |
| たくさん持っているとき | 札の並ぶ所は画面の上から下まで使い、その中を上下に動かす。動かせることを示す棒は出さず、画面の下の端で札が切れることでわかるようにする |
| 使っている物 | キャラが付けている装備、デッキに入れているスキルは、右上に「E」を出して暗くし、選べなくする |
| 選び方 | 札を押すと、その札を選ぶ（金の縁と光）。丸いチェックを押すと、選んだ物を使う物にして閉じ、合成の右の面の札の品質と出来上がる品質を変える。札の外の暗い所を押すと、変えずに閉じる |

### 品質強化とスキル覚醒

「品質強化」では磨き石とルーンで品質を上げ、「スキル覚醒」では覚醒の欠片とルーンで固有スキルとスキルを覚醒させる。2つは別の項目・別の画面である（2026-10-24）。選ぶ順・画面の決まりと今の実装は[商会の強化](../enhancement.md)に従う。

### スキル覚醒

まだ覚醒できるスキルを、タブを置かずに1本の一覧にする（2026-10-31、ユーザーが画像の5案から「基本」を選んだ）。
固有スキルとカスタムスキルを分けず、横長のカード1枚を1行にする。
タブで分ける案・種類で並べる案・キャラごとに選ぶ案は、カスタムスキルが数百枚になると探しにくく、「カスタムスキル」という言葉で区別させることになるため、採らなかった。

| 項目 | 決まり |
|---|---|
| 並び | パーティの順にキャラごと、その人の固有スキル（番号の順）、続けてその人のカスタムスキルの枠に入れているスキル（枠の順）。パーティのあとに控えのキャラを同じように並べ、最後に、誰にも付けていないスキルを品質の高い順（同じ品質はスキルの定義の順、同じ種類は倍率の高い順）に並べる |
| 出す物 | 覚醒できる段階が残っている固有スキルと、まだ覚醒していないスキルの1枚。覚醒しきった固有スキル、未解放の固有スキル、覚醒したスキルの1枚は出さない |
| 行 | [すりガラスのカード](guide.md#すりガラスのカード)の横長のカード。左の内側にキャラの戦闘のドット絵（2倍）を少し暗い地に置き、金の細い線で区切る。誰にも付けていないスキルは、この所を空ける。その右は[冒険者のスキルの行](loadout.md#スキル)と同じ挿絵（コストと属性）・名前と種類・効果の文。右端に品質の文字（品質の色）と倍率。固有スキルはセットしている段階のカードで出す |
| 区切り | キャラが替わる行（誰にも付けていないスキルの始まりを含む）だけ、上を36空ける |
| 覚醒の場面 | 行を押すと、一覧を暗い幕で覆い、[戦闘中の覚醒](../skill-evolution.md#覚醒のエフェクト)と同じく、カードが行のキャラ（誰にも付けていないスキルは行の挿絵）から浮き上がってひびが入り、上の中央へ移る。戦闘と違い、浮き上がる所の足元に魔法陣や光は置かない（2026-10-31、ユーザーの指摘。一覧の行にはキャラが立っていないため）。その下に[戦闘の覚醒先を選ぶ画面](../skill-evolution.md#覚醒先を選ぶ画面)と同じ光の線と覚醒先のカードを出す。固有スキルは次に進める段階（1〜3）、スキルは2つの枝。別の1枚で取った枝には「取得済み」の札を付ける。覚醒先を選ぶ間と欠片が飛ぶ間だけ、左下の札に、覚醒の欠片の絵と「使う数/持っている数」（「1/2」）、ルーンのアイコンと払う額を出し、足りない数を赤くする（2026-10-31、ユーザーの指示）。足りないときは右下のチェックを押せない |
| 覚醒 | 覚醒先を選んでチェックを押すと、左下の札から欠片が弧を描いてカードへ飛び込む。サーバーの答えを待ってから、戦闘と同じくカードが割れて覚醒した段階が現れ、行のキャラへ飛び込む。通知の帯で「「マナバースト」が「マナバースト・烈」に覚醒した」と知らせ、場面を閉じて一覧を作り直す。失敗したら知らせて読み直す |
| 戻る | 覚醒先を選んでいる間は、ヘッダーの「もどる」と端末の戻るキーで場面を閉じ、一覧に戻る。チェックを押したあとは、演出が終わるまで閉じない |
