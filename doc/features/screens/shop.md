# 画面一覧：商会

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 商会

商会では、装備・スキル・素材の売り買いと合成、持ち物の強化を扱う。
合成できる物（素材・道具・武器・防具・アクセサリー・スキル）と決まりは[合成](../synthesis.md)に従う。
案内人は貴族の少年武具商である。

メニューは「買う」「売る」「合成」「品質強化」「スキル覚醒」の5つである（2026-10-24。「強化」を足したあと、同じ日に品質強化とスキル覚醒の2つに分けた）。
売買にはルーンを使うことを、ユーザーが決めた（[ルーンの用途](../economy.md#ルーンの用途)）。

### 画面の形

メニューで項目を押すと、案内人を隠して、画面いっぱいの[枠つきの表示](guide.md#枠つきの表示)で開く（2026-10-24、ユーザーの依頼）。
ヘッダーの下を左右2つの透ける面に分け、間に金の2本線を引く。
左の面の上に分類のタブ、その下に一覧を置き、右の面に選んだ物を大きく出して、右下に決めるボタンを置く。
「もどる」でメニューに戻ると、案内人が戻る。
参考画像はCodex CLIの画像生成で作り、ユーザーが「大部分はあってます」とした。

| 項目 | 左の面（タブと一覧） | 右の面 |
|---|---|---|
| 買う | 武器・防具・アクセサリー・スキルのタブ。品物を4列の札で並べる（横幅の約6割） | 絵を大きく、名前、☆と品質C、効果、持っている数（スキルは絵・名前・効果の代わりにデッキのカード）。下に値段と「買う」 |
| 売る | 武器・防具・アクセサリー・スキル・アイテムのタブ。持ち物を5列の札で並べる（約6割） | 選んだ物の行（装備は効果も）と、合計。下に「選びなおす」と「売る」 |
| 合成 | 同じ5つのタブ。作れる物を行で並べる（約4割） | 出来上がる物の絵・名前・☆・効果と出来上がる品質、材料の札、費用と「合成」 |
| 品質強化 | スキル・装備・固有スキルのタブ。対象を行で並べる（約4割） | 名前、強化する前と後のカード（装備は品質の色の縁の札）と品質、品質のゲージ、磨き石と使う数、費用と「強化」（[商会の強化](../enhancement.md#強化の画面)） |
| スキル覚醒 | タブの代わりに見出し「覚醒できる固有スキル」。覚醒できる段階を行で並べる（約4割） | 名前、覚醒する前と後の段階のカード、覚醒の欠片、費用と「覚醒」 |

買う・合成・品質強化・スキル覚醒は、右の面が空にならないよう、開いたときとタブを替えたときに一覧の先頭の物を選んでおく（品質強化とスキル覚醒は2026-10-24、買う・合成は2026-10-26、ユーザーの指示）。
一覧が空のときだけ、右の面に何も出さない。
売るは、開いたときに何も選ばない。
押した札がそのまま売る物に加わり、選んだ物をまとめて売る画面のため、勝手に選ぶと気づかずに売ってしまうおそれがあるからである。

### 買う

「買う」では、これまでに手に入れたスキル・武器・防具・アクセサリーを、品質の最低（品質C・×1.00）で何度でも買える（2026-10-24、ユーザーの指示）。
これまでに手に入れた物とは、[ライブラリ](../library.md)の見つけた記録に載っている物で、売ったり合成に使ったりして手元になくても買える。
アイテム（道具・素材）は並べない。

| 項目 | 決まり |
|---|---|
| 並べ方 | タブの分類の品物を、安い順（同じ値段は定義の順）に並べる。開くたびにサーバーから見つけた記録を読み直し、初めて開いて読むまでは「読み込み中…」を出す。開き直したときは、前に読んだ記録の品物をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)） |
| 札 | 種類の絵、名前、☆、ルーンのアイコンと値段 |
| 値段 | ☆1が1,000ルーンで、☆が1つ増えるごとに倍にする（☆2 2,000、☆3 4,000、☆4 8,000、☆5 16,000）。品質を選べない代わりに、[行商人](../stage-progression.md#マスの中身仮)の品質Cの値段（☆1で1,500）より安くした。仮の値で、2026-10-26に5倍にした（[ルーン経済の記録](../economy.md#変更と判断の記録)） |
| 右の面 | 選んだ品物の絵を大きく出し、名前、☆と「品質C（×1.00）」、分類と効果、持っている数を書く。スキルは、絵・名前・効果の代わりに、戦闘と同じデッキのカード（70×98ドットを4倍）を品質C・×1.00で出す（2026-10-24、ユーザーの指示「スキルを買う時、右側の画面にはカードを表示してほしい」）。所持ルーンが足りなければ「ルーンが 〇〇 足りません」と書き、「買う」を押せなくする |
| 買い方 | 札を選んで右下の「買う」を押す。確認のダイアログは出さず、選ぶ・押すの2回の操作で確かめる。押すとすぐ「〇〇を 1,000 ルーンで買った」と知らせ、値段を右上の所持ルーンから引いて見せ、裏でサーバーに保存する（[楽観的更新](../../rules/data-storage.md#サーバーに置くときの作り方)）。選んだまま押し直せば、同じ物をもう1つ買える |
| 保存できなかったとき | 引いた値段を所持ルーンへ、先に足した持っている数を元の数へ戻し、通知の帯で「買えませんでした」と知らせる。画面を閉じたあとでも、開いている案内人の画面かホームで知らせる |
| 持ち物 | 買った物は1つずつ倍率×1.00で持ち物に入り、編成の[装備](loadout.md#装備)・[スキル](loadout.md#スキル)で付けられる |

### 売る

持ち物を、同じ種類でも1つずつ別の札で並べる。
スキル・装備は1つずつ品質が違うため、「×3」のようにまとめない（2026-10-24、ユーザーの指示）。
品質を持たないアイテムだけは、種類ごとに1枚の札にして数を書く。

| 項目 | 決まり |
|---|---|
| 札 | 種類の絵、左上に品質の文字（品質の色）、アイテムは右下に数。付けている物・デッキに入れている物は右上に「E」を出し、選べなくする |
| 選び方 | 札を押すたびに選ぶ・やめるを切り替え、いくつでも選べる。右の面に、選んだ物の行（絵・名前・品質・値段）と合計を出す。装備の行は、品質の下に、その倍率での効果（「物攻の125%」など）を書く（2026-10-24、ユーザーの指示「装備を売るときに、その装備のステータスも見れるようにして」）。右の行を押しても選ぶのをやめる。「選びなおす」で全部やめる |
| 値段 | 仮の値。スキル・装備は買う値段の20分の1に倍率を掛けて四捨五入し（2026-10-26に買う値段を5倍にしたとき、売値の額が変わらないよう4分の1から改めた）、アイテムは☆1の10ルーンから☆ごとに倍にして数を掛ける。サーバーが同じ式で決める |
| 決定 | 確認のダイアログは出さず、「売る」を押すと選んだ物をまとめてサーバーで売る。答えが届いたら、売った物を一覧から外し、残高を得た後の値にして「N点をMルーンで売った」と知らせる。売れなければ「売れませんでした」と知らせて持ち物を読み直す。1回で売れるのは50点まで |
| 売れる物 | キャラに付けている装備、デッキに入れているスキル・アイテムは売れない。アイテムは種類ごとに持っている数をすべて売る |

### 合成

合成の決まり（仮）は[合成](../synthesis.md#仮設定)に従う。
同じ分類で☆が1つ低い物3つとルーンで、見つけた物を1つ作る。

| 項目 | 決まり |
|---|---|
| 左の一覧 | タブの分類の作れる物を、☆の低い順に並べる（絵・名前・☆）。材料が3つそろわない物は、暗くしたうえで選べる |
| 右の面 | 出来上がる物の絵・名前・☆・効果と、選んだ材料から出来上がる品質と倍率。その下に「材料」の見出しと選んだ数（「3 / 3」）、使える材料の札を6列で並べる。開いたときは品質の低い3つを選んでおく |
| 材料の札 | 売るの札と同じ形。押すたびに選ぶ・やめるを切り替え、3つまで選べる。アイテムは1つずつの札にし、同じ種類は3つまで出す |
| 足りないとき | 「☆1の武器が 2 つ足りません」「ルーンが 〇〇 足りません」と書き、「合成」を押せなくする。材料がなければ、札の代わりに「使える材料がありません」と書く |
| 合成の仕方 | 確認のダイアログは出さず、選ぶ・押すの操作で確かめる。押すとサーバーの答えを待ってから、材料を持ち物から消し、出来た物を足し、「〇〇（品質B）を作った」と知らせて絵を大きくして戻す。出来上がる品質をサーバーが決め直すため、楽観的更新にしない。失敗したら「合成できませんでした」と知らせ、読み直す |

### 品質強化とスキル覚醒

「品質強化」では磨き石とルーンで品質を上げ、「スキル覚醒」では覚醒の欠片とルーンで固有スキルを覚醒させる。2つは別の項目・別の画面である（2026-10-24）。選ぶ順・画面の決まりと今の実装は[商会の強化](../enhancement.md)に従う。
