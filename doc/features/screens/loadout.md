# 画面一覧：装備とスキルの付け替え

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 装備の人選び

編成のメニューの「装備」（冒険者の次）を押すと、冒険者を選ぶ画面を開く。
開いている間は左の看板娘を隠し、冒険者の一覧と同じ枠（ぼかした背景・ヘッダーの帯）の中に、見出しを付けずに、持っている全員のカードを3列で並べる。何の画面かはパンくずとカードの武器・防具でわかる。
パンくずは「編成 › 装備」である。

| 場所 | 内容 |
|---|---|
| カード | 冒険者の一覧と同じすりガラスのカード。左に立ち姿（周りの余白を切った48×52を4倍）と足元の影、右に名前、「Lv」とLv、パーティにいる人だけ金の「パーティ」の札、付けている武器・防具の種類のアイコン（24×24を2倍）と名前。付けていない枠は「なし」と書き、アイコンを薄くする |
| 並び | パーティの4枠の順、続けて控えを持っている順。9人は3行で、スクロールせずに収まる |

カードを押すと、その人の[個別の画面](adventurers.md#育成)を開き、そこで武器・防具の枠から[装備](#装備)の付け替えへ進む。
この入口から開いた個別の画面と付け替えの画面は、パンくずを「編成 › 装備 › アリア」「編成 › 装備 › アリア › 装備」とし、個別の画面の「もどる」でこの画面へ戻る。
冒険者の一覧から開いたときは、これまでどおり「冒険者」と出し、一覧へ戻る。

編成と付けている装備は、開くたびにサーバーから読む（[キャラと編成の保存](../party.md#キャラと編成の保存)、[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。
初めて開いて読み込むまでは「読み込み中…」を出してカードを隠し、読めなかったときは「取得できませんでした」と「編成を取得できませんでした」の通知を出す。編成と装備は同時に読み、どちらも前に読んでいれば、すぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
サーバーの接続先がないときは、仮データの編成と、アプリを動かしている間だけの装備（`EquipmentLocalSource`）を使う。

## 装備

[個別の画面](adventurers.md#育成)で武器か防具の枠を押すと、その人とその枠を選んだ装備の付け替えの画面を開く。
メニューには出さない項目（`Hidden`）である。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で、左の透ける面（横800まで）に人と枠、金の2本線の右の透ける面に持っている装備を置く。
枠と装備の行は模様のない[すりガラスのカード](guide.md#すりガラスのカード)で、アクセサリーの枠と「外す」は点線にする。

| 面 | 表示と操作 |
|---|---|
| 左上（人） | 戦闘のドット絵（64×64を2倍）、名前とLvと属性のアイコン。◀▶は置かず、左の面の上で指を左へ動かす（フリックする）と次の人、右へ動かすと前の人に替える。選んでいる枠のまま、パーティの枠の順、続けて控えを持っている順に替え、端から反対の端へ回る。フリックの決まりは[個別の画面](adventurers.md#育成)と同じ |
| 左（人の下） | 選んでいる人のステータス8つ（4列2行）。付けている装備の上昇分を入れた値を出し、上がった項目だけ、値の右に明るい緑の小さな文字で上昇分を添える（「属攻 380 +98」。2026-10-25）。その下に線を引いて枠と分ける |
| 左（5つの枠） | 「武器」「防具」の枠と、アクセサリーの3枠を、面の下端まで縦に並べる。武器・防具の枠には、種類のアイコン（24×24を3倍）、枠の名前、装備の名前、右端にレア度の★を出す。空いた枠は「なし」と書き、アイコンを薄くする。品質がS・Aの装備は、アイコンに種類ごとの光り方の[キラキラ](../../art/direction.md#カードのキラキラ)を重ねる。押した枠を金の枠で囲む。アクセサリーの枠は点線で、開くまで錠前と「Lv 15で解放」、開いたら付けているアクセサリーの名前（空いていれば「なし」）を出す。押すとアクセサリーのタブに移る |
| 右（タブと一覧） | 上に、面の幅いっぱいに「武器」「防具」「アクセサリー」のタブ。選んでいるタブは明るい金の文字と金の下線。タブは左の枠と連動し、左で防具の枠を押すと防具のタブ、タブで防具を押すと左の防具の枠を選ぶ。アクセサリーのタブは、選んでいたアクセサリーの枠（なければ1つ目）を選ぶ。選んだアクセサリーの枠が開いていなければ、一覧を空にして「外す」も出さず、解放するLvだけを出す。開いていれば、持っているアクセサリーを武器・防具と同じ行で並べ、1つも持っていなければ「持っているアクセサリーはありません」とだけ出す（2026-10-25）。1つのアクセサリーは1つの枠にだけ付き、同じ人の別の枠や別の人の枠に付けると、前の枠から外れる。所持数は出さない。持っているその種類の装備を1つ1行で、レア度の高い順（同じなら仮データの順、続けて倍率の高い順、入手の順）に並べる。行には種類のアイコン（品質がS・Aなら[キラキラ](../../art/direction.md#カードのキラキラ)を重ねる）、名前、★と[品質](../inventory.md#品質)の文字（品質の色）、倍率を掛けた効果（「属攻 +20%」）を置き、効果の右に、その行の装備を選んでいる枠に付けたときのステータスの増減を、今の装備と比べて出す（「属攻 ▲43　会心 ▲2」。上がる項目は緑の▲、下がる項目は赤の▼で、変わる項目を最大3つ。付けている行と変わらない行は出さない。2026-10-25）。右上に、選んでいる人が付けていれば「装備中」、ほかの人なら「アリアが装備中」と出す。最後に「外す」の行を置き、選んでいる枠が空いている間は暗くして押せなくする |

左で枠を押してから右の装備を押すと、その場でその枠に付ける。
ほかの人が付けている装備を押した場合は、その人から外して付け替え、その人の枠は空きになる。
「外す」を押すと、選んでいる枠の装備を外す。外した装備は持ち物に残る。
決定ボタンは置かない。
付け替え・外したことは、枠と一覧を見ればわかるため通知しない。
「もどる」と端末の戻るキーは、個別の画面へ、付け替えの画面で最後に見ていた人のまま戻る。

持っている装備と付けている装備は、開くたびにサーバーから読み、付け替えはすぐ画面に出してから裏でサーバーに保存する（[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。保存できなかったときは元に戻して通知の帯で知らせる。
初めて開いて読み込むまでは、右上と名前に「読み込み中…」を出し、枠・装備の行を空けて仮データの中身を見せない。編成と装備は同時に読み、どちらも前に読んでいれば、すぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
読めなかったときは「装備を取得できませんでした」、保存できなかったときは「装備を保存できませんでした」を通知の帯で知らせ、装備は変えない。
保存を待つ間は、続けて押しても受け付けない。
サーバーの接続先がないとき（展示室のプレビューなど）は、仮データの装備から始め、サーバーと同じ決まりで付け替え、変更はアプリを動かしている間だけ残す（`EquipmentLocalSource`）。

装備の種類（武器8つ・防具6つ）の名前・レア度・効果は、装備の画面のモックの仮データを引き継いだ。
装備が1つずつ持つ倍率はサーバーから読み、品質の文字と効果の数字に出す（2026-10-19）。
付け替えると、左のステータスと右の増減がすぐ変わる。上昇分の計算は[装備の効果](../equipment.md#装備の効果)に従う。
アイコンは装備の画面のモックの付け替え・武器・防具のアイコンを、`Features/Equipment/UI/Art/` へ移して使う。
持っている装備が作り込んだ行（8行）より多いときは、開いたときに行を写して増やす。
画面は `Baryonyx > Tavern > Create Screen Assets` で作り直す。

## スキル

[個別の画面](adventurers.md#育成)でカードを押すと、その人とその枠（固有スキルかカスタムスキル）を選んだスキルの付け替えの画面を、**選択モード**で開く。
メニューには出さない項目（`Hidden`）である。
選択モードでは、左に選んでいる枠の今のカードを大きく出し、右の一覧と見比べながら付け替える。右のスキルを押すと、その場で入れ替わる（2026-10-23）。
固有スキルを選んでいるときは、右にその[覚醒ツリー](../skill-evolution.md#覚醒の段階とツリー)を出し、取得した段階を押すとその場でセットする。
左の「戻る」で、選んだ人の6枚を小さなカードで並べた**6枚の一覧**に戻る。6枚の一覧のあいだも右にはスキルの一覧を出すが、押しても何も変わらない。
6枚の一覧の「今のデッキ」で、6枚を効果まで読める大きさで全画面に出す。
パーティにいない仲間も付け替えられる。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で、左の透ける面（横800まで）に人とステータスと枠、金の2本線の右の透ける面にタブとカードの一覧を置く。
左の並び順と右のタブは、[装備](#装備)の付け替えの画面に合わせる。
固有スキル・カスタムスキルの枠、カードの行、覚醒ツリーの段階は模様のない[すりガラスのカード](guide.md#すりガラスのカード)にし、見出し（固有スキル・カスタムスキル）は金のひし形と明るい金の文字にする。見出しに注記は付けない。

| 枠 | 表示と操作 |
|---|---|
| 左上（人） | [装備](#装備)と同じ。左の面のフリックで、選んでいる枠とタブのまま人を替える |
| 左（人の下） | 選んでいる人のステータス8つ（4列2行）。その下に線を引いて枠と分ける。位置は[装備](#装備)と同じ |
| 左（6枚の一覧） | 見出し「固有スキル」の下に固有スキル3枚、見出し「カスタムスキル」の下にカスタムスキル3枚を、[個別の画面](adventurers.md#育成)と同じ小さなカード（3倍）で横に並べる。小さなカードには名前と「攻撃・敵全体」の行も出す。固有スキルは、セットしている覚醒の段階のカードを出し、未解放のものは暗くして錠前と「Lv 40で解放」を重ねる。「固有スキル」の見出しの右端に「今のデッキ」。カードを押すと、その枠の選択モードになる |
| 左（選択モード） | 右上に左向きの金の矢印の「戻る」。その下の左に、6枚の札を2列（左が固有スキル、右がカスタムスキル。見出しと列の名前は付けない）×3段に並べ、右に選んでいる枠のカードを戦闘のカードと同じ大きさ（70×98ドットを5倍）で、効果まで出す。札は128四方の模様のないすりガラスのカードに、挿絵の中央56×56ドットを2倍で出す。未解放の固有スキルの札は暗くして錠前を重ね、空いた枠の札は「＋」にする。選んでいる札は金の枠で囲み、ほかの札を押すとその枠に替わる。効果の数字はステータスの割合（「属攻の100%」）で書く |
| 今のデッキ（全画面） | 上の帯の下を暗くして（後ろの画面はうっすら透ける）、「〇〇のデッキ」と右上の×、固有スキル3枚とカスタムスキル3枚を2段に、戦闘のカードの組み方（4倍）で効果まで出す。段の見出しはカードの左に置く。上の帯の「もどる」・端末の戻るキー・×は、全画面だけを閉じる |
| 右（タブと一覧） | 上に、面の幅いっぱいに「スキル」「アイテム」のタブ。見た目は[装備](#装備)のタブと同じで、選んでいるタブは明るい金の文字と金の下線。開いたときは「スキル」を選ぶ。タブは左の枠と連動しない（どちらの枠にもスキルとアイテムを入れられるため）。スキルのタブでは、タブの下に、選んだ人が付けられる属性のアイコンだけを出し（「付けられる属性」の見出しと「＋属性なし」の文字は付けない）、付けられるスキルを1枚1行で、コストの低い順に並べる。枚数は出さない。行は左の2枚と同じ形で、数字も選んだ人のステータスで出す。その人が付けているスキルには、右上に「1枚目」のように何枚目かを出す。持っているアイテムがなければ、アイテムのタブでは一覧を空にして「持っているアイテムはありません」とだけ出す。アイテムの絵（32×32）はスキルの挿絵（64×58）より小さいため3倍で出し、タブを替えて行の絵を差し替えるたびに大きさを測り直す（2026-10-24、タブを行き来すると絵が小さくなる不具合を直した）。カスタムスキルの枠を選んでいて、その枠に何か入っているときは、一覧の最後に「スキルを外す」（点線のカードに×と文字）を出し、押すと枠を空きにしてサーバーに保存する（2026-10-24、ユーザーの指示） |
| 右（覚醒ツリー） | 左で固有スキルを押したとき、タブと一覧の代わりに出す。上に見出し「マナバーストの覚醒」、その下に7つの段階を1行ずつ縦に並べ、はみ出す分はスクロールする（一覧と同じく上下の縁で薄く消す）。並びは、最初の段階、続けて枝ごとに1段目（1段字下げ）と2段目（2段字下げ）の順である。字下げの手前に縦の線を引き、その段階のカードへ横に線を出す。各段階は左の行と同じ形で、取得した段階は同じ中身を出し、押すとその場でセットする。別の人か別の固有スキルのツリーに替えると、一番上から見せる。セットしている段階は金の枠で囲み、「セット中」を出す。取得していない段階は、名前も効果も出さず、カードの中央に「？」の封印を置いて左右へ鎖を渡した、封じた札にする（押せない）。封印と鎖は背景が透明な生成画像（`StageSeal`・`StageSealChain`、`Features/CardLoadout/UI/Art/`）で、ドット絵ではない。未解放の固有スキルのツリーは見られるが、最初の段階に錠前と「Lv 20で解放」を重ね、どの段階も押せない |

左で枠を押してから右のスキルを押すと、その場でその枠に入れる。
その人のほかの枠にあるスキルを押した場合は、2つの枠の中身を入れ替える。
同じスキルを複数の仲間が付けてもよい（仮）。
決定ボタンや変化を説明する文は置かない。
付け替え・入れ替えたことは、枠を見ればわかるため通知しない。
「もどる」と端末の戻るキーは、個別の画面へ、付け替えの画面で最後に見ていた人のまま戻る。今のデッキを出しているときは、全画面だけを閉じる。

仲間とスキルは、開くたびにサーバーから読み、付け替えはすぐ画面に出してから裏でサーバーに保存する（[キャラと編成の保存](../party.md#キャラと編成の保存)）。保存できなかったときは元に戻して通知の帯で知らせる。
初めて開いて読み込むまでは、一覧の面と名前に「読み込み中…」を出し、固有スキル・カスタムスキル・スキルの行と付けられる属性の行を空けて仮データの中身を見せない。開き直したときは、前に読んだ編成をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
固有スキルの覚醒の段階は、まだサーバーに保存せず、仮データ（トーマのマナバーストだけ、3つの段階を取得済み）から始めてアプリを動かしている間だけ残す（`UniqueSkillSession`）。
読めなかったときは「スキルを取得できませんでした」、保存できなかったときは「スキルを保存できませんでした」を通知の帯で知らせ、スキルは変えない。
サーバーの接続先がないとき（展示室のプレビューなど）だけ、仮データのスキルから始め、変更はアプリを動かしている間だけ残す（`PartySession`）。
[冒険者の一覧](adventurers.md#パーティ)と[個別の画面](adventurers.md#育成)は、付け替えたスキルを表示する。
スキルの効果の威力は、その人のステータスや今日のACTを入れず、ステータスの割合（「属攻の100%」）で書く（[カードの数値の見せ方](../combat.md#カードの数値の見せ方)）。

仲間ごとに付けられる属性は[未決](../party.md#未決事項)のため、仮データで最初に付けているスキルの属性を、その仲間が付けられる属性とした。
持っているスキルの仕組みもまだないため、スキル50枚をすべて持っているものとして扱う（仮）。
スキルを1枚ずつ持ち、1枚ごとに倍率を持つ決まりと、カスタムスキルにアイテムを入れる決まり（2026-10-06、[キャラクターの構成](../party.md#キャラクターの構成)）は、まだ反映していない。
ステータスとLvは、[育成](adventurers.md#育成)の仮データと上げたレベルを使う。
スキルの挿絵は、戦闘画面のモックの画像（`Features/Combat/UI/Art/`）を借りている。
[ゲーム内の対象の画像](../../rules/frontend-design.md#ゲーム内の対象の画像)の決まりでは `Shared/Art/Skills/` へ移すものだが、戦闘と育成の生成処理も同じ場所を読んでいるため、移すのは別の作業とする。
種類の行と説明の数字の色は、戦闘のカードと共有する `Shared/UI/Cards/CardText` で作る。

画面は `Baryonyx > Tavern > Create Screen Assets` で作り直す。
人・6枚・スキルの行は生成時にPrefabへ作り込むので、Prefabを開くと、停止中でも先頭の人のスキルが読める。
停止中の表示の切り替えでは、6枚の一覧のほかに、アイテムのタブ、固有スキルの選択モード（先頭の人の1つ目の固有スキルの覚醒ツリー）、今のデッキを見られる。
