# 画面一覧：編成・商会・神殿・旅の案内所の共通

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 編成・商会・神殿・旅の案内所の画面

ホームの左下のボタン（編成・商会・神殿）と、街道の世界地図の右下のボタン（旅の案内所）から開く画面である。
どの画面にもドット絵の案内人がいて、プレイヤーは案内人のいる場所でやりたいことを選ぶ。案内人は話さない（吹き出しは置かない）。
計画・仮データ・絵の作り方と検証結果は[実装計画](../../plans/2026-09-27-guide-menu-screens.md)に記す。

| 画面（シーン） | 扱う機能 | 案内人 | 右側の内容 |
|---|---|---|---|
| 編成（`Pub`） | パーティ・装備・育成・スキル | 酒場の看板娘 | 冒険者・育成のメニュー（アイコンは名簿、人の上半身と上向きの矢印。縁取りのない白一色の形）。冒険者は[冒険者の一覧](adventurers.md#パーティ)を開き、選んだ人を下の帯の「装備・スキル」で[冒険者のタブ](adventurers.md#冒険者のタブ)（[ステータス](adventurers.md#ステータス)・[装備](loadout.md#装備)・[スキル](loadout.md#スキル)）へ進む。育成は[冒険者を選ぶ画面](loadout.md#育成の人選び)を開き、1人を押すとその人の冒険者のタブへ進む（2026-10-26に「装備」から改めた） |
| 商会（`Shop`） | 装備・スキル・素材の売買と合成 | 老舗の武具店を継いだ貴族の少年 | 買う・売る・合成・強化のメニュー（アイコンは値札、硬貨の山、金床と槌、カットした宝石。縁取りのない白一色の形）。どの項目も、案内人を隠した画面いっぱいの2面で開く。買うは、これまでに手に入れた物を品質Cでサーバーから買う。合成と強化はサーバーで行う。売るは、キャラに付けていない持ち物をサーバーで売ってルーンを得る。[商会](shop.md#商会)を参照 |
| 神殿（`Temple`） | 召喚 | 千年を生きた狐の精霊 | 「召喚」のメニュー（アイコン付き）。押すと全画面の[召喚](temple.md#神殿)を開く |
| 旅の案内所（`TravelOffice`、見出しは「ダンジョン一覧」） | 行き先選び・冒険の出発・行き先のお宝 | なし（2026-10-24に、フクロウ族の老地図師をなくした） | 行き先のリスト。どの行き先からも[冒険に出る](adventure.md#冒険の画面)（[行き先と敵](../stage-progression.md#行き先と敵)）。各行のお宝のボタンから、その行き先で手に入るお宝を見る |

| 領域 | 表示と操作 |
|---|---|
| 左 | 案内人の上半身を、上・左・右が画面から切れないよう画面の高さの約9割で表示する。案内人と右のメニューは[中央の層の部品](../../rules/ui-design.md#画面端の部品と中央の層の部品)で、16:9より横長の画面でも左右の端へ離れず、中央に並ぶ |
| 右 | メニューの各行は[すりガラスのカード](#すりガラスのカード)で、アイコン・項目名・金の矢印を置く。項目名は行の縦の中央に置き、何ができるかの説明は添えない（開いた先の中身で伝える）。メニューを押すと、[枠つきの表示](#枠つきの表示)に切り替わり、案内人の右の透ける面に、見出し（項目名）とすりガラスのカードの行のリストを出す。行を選ぶと金の縁と光になる。右下の決定ボタンは選ぶまで押せず、押すと「〇〇（準備中）」の通知を表示する |
| 右（旅の案内所） | メニューを通さず、開いたときから[枠つきの表示](#枠つきの表示)で、画面の幅いっぱいの透ける面に行き先のリストを表示する（案内人を置かない）。「もどる」は街道の世界地図へ、×はホームへ戻る。見ればわかるため、リストに題名は付けない。各行に、固有名詞の地名と、その土地を短く語るフレーバーテキストを書き、右端に「推奨Lv15」のような推奨Lvを書く。推奨Lvは未踏の地を含むすべての行き先に書く。行を選ぶと金の縁と光になり、右下の「出発」を押せる。行き先は、[街とダンジョン](../stage-progression.md#街とダンジョン仮)の表の12の街の順に、街ごとに並べる。街道でその街に着く（街のマスをクリアする）まで、その街の行き先の行は出さない（2026-10-25）。冒険の8つの行き先（[行き先と敵](../stage-progression.md#行き先と敵)）は、確認を挟まずにすぐ冒険を始めて探索へ移る。推奨Lvは、その行き先の敵のLvと同じにする。中身をまだ作っていない46のダンジョンは、説明の代わりに街の名前を書き、出発すると「出発（準備中）」の通知を表示する。最後に、未踏の地を1つ置く。未踏の地は地名を「？？？」に伏せて説明を出さず、地名と推奨Lvだけを行の縦の中央に置き、行ごと暗くして選べなくする。未踏の地には、お宝のボタンを置かない |
| 右（旅の案内所のお宝） | 冒険の行き先の行の右端に、行の高さいっぱいを押せるお宝のボタンを置き、[すりガラスのカード](#すりガラスのカード)の札に宝箱の絵（探索の宝箱のマスのアイコン）と、その行き先のお宝を見つけた数と全体の数（例：「13/23」）を書く。推奨Lvと説明文は、ボタンの左で切る。ボタンは行を選ばずに、画面の中央にお宝の窓を開く。お宝は、その行き先の[ドロップの一覧](../drops.md#行き先ごとの一覧)の物で、どの行き先でも落ちるACTボーナスは入れない。窓は[枠つきの表示](#枠つきの表示)の窓で、上に見出し「〇〇のお宝」と見つけた数、その左にその行き先をクリアした（最奥の主を倒した）回数（「クリア 2回」。冒険の記録を読むまでは「クリア -回」、2026-10-25）、右上に×を置き、アイテム・アクセサリー・武器・防具・スキルの段ごとに、左に分類の名前、右にお宝の札を並べる（入りきらなければ上下に動かす）。見つけたかどうかは[ライブラリ](../library.md)の見つけた記録で決め、見つけたお宝は絵を、まだのお宝は[ライブラリ](../library.md#まだ見つけていない項目の見せ方)と同じ形だけの影を出し、☆はどちらにも出す。ただしスキルは挿絵が四角く、影にしても形がわからないため、まだのスキルは影の代わりに「？」を出す。最奥の間でだけ落ちる物（主の物）の札には、右上に金の王冠のアイコン（12×12を4倍、[アート方針の例外](../../art/direction.md#例外)）を置く。札を押すと、窓の下に名前・☆と説明を出す。分類は段の名前で、主の物かどうかは王冠でわかるため書かない。まだ見つけていないお宝は、名前を「？？？」に伏せ、☆は出し、説明は書かない。窓の外の暗い幕・×・「もどる」・端末の戻るキーは、窓だけを閉じる。見つけた記録は画面を開くたびに読み、初めて読めるまでは数を「-/23」のように出す。前に読んだ記録があれば、すぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)） |
| 左上 | 「もどる」。Safe Areaの左上の角に余白なしで付けた、[枠つきの表示](#枠つきの表示)のヘッダーの帯と同じ暗い紺のタブの中央に、左向きの矢印（縁取りのない白一色の形を、文字と同じ色で96pxに表示。右上の×と同じ描き方）だけを置き、文字は付けない。タブは右上の×と同じ幅128pxで、上と左へSafe Areaの外まで延ばし、右と下の縁だけを見せる。高さはアイコンの96pxで、その下の枠は上から128pxより下に置く。リストではメニューへ、メニューではホームへ戻る。端末の戻るキーも同じ |
| 上（「もどる」の右） | 今いる場所のパンくず（例：「編成 › 冒険者 › アリア」）。画面名から始め、開いている項目、項目のパネルが出す人の名前や付け替えの種類を「 › 」でつなぐ。すべて同じ大きさ・同じ色の白い文字で、「もどる」と縦の中央をそろえる。メニューと旅の案内所では画面名だけになる。入りきらないときは文字を縮める。押せない |
| 右上の×の左 | 所持ルーン（2倍のルーンのアイコンと数）。Homeの右上と同じく、四方の外側へ向かって薄くなる暗い下地に置く。表示のみ |
| 右上 | 「×」。Safe Areaの右上の角に余白なしで付けた、「もどる」と同じ紺のタブに、×（「もどる」の矢印と同じ描き方）を置く。タブは上と右へSafe Areaの外まで延ばし、左と下の縁だけを見せる。どの深さ（リスト・個別の画面・付け替えの画面・重ねた画面）からでも、いちど押せばホームへ戻る。メニューと旅の案内所では「もどる」と同じ動きになるが、位置を覚えられるよう常に出す。ホームへ戻れない展示室のプレビューでは、メニューへ戻す |

所持ルーンは、Homeや編成の画面がサーバーから読んだ最新の残高を表示し、案内人の画面を開くたびにサーバーから読み直す。
育成でルーンを使うと、その場で数を減らす。
一度も読めていないとき（展示室のプレビューやシーンを単体で開いたときなど）は「--」を出す。
展示室のプレビューで冒険者のステータスのタブを開いたときは、育成の仮データの所持ルーンを出す。

メニューの行・リストの行・決定ボタンは、編成の冒険者の一覧と同じ[すりガラスのカード](#すりガラスのカード)にする。リストの行は文字が左上から始まるため模様を付けない。決定ボタン（「買う」「召喚する」「出発」など）は、模様を付けず、個別の画面の「レベルアップ」と同じ金の縁と光を常に出す。

一覧の内容はすべて仮データであり、キャラ・装備・召喚の方式・地名は確定していない。
召喚の確率は表示しない（[ガチャと課金](../monetization.md#法務メモ)）。

### 停止中の確認

項目のパネル（冒険者の一覧・冒険者のステータス・装備・スキル・突破のタブなど）は、生成時に仮データでPrefabへ作り込んであるが、どれを出すかはPlay Mode中に案内人の画面が切り替える。
停止中は、`Pub` などのシーンで案内人の画面（`PubScreen` など、`GuideMenuView` を持つオブジェクト）を選び、Inspectorのボタンで各項目を開いた見た目へ切り替える（[停止中の表示の切り替え](common.md#停止中の表示の切り替え)）。
押した項目を開いたときと同じ処理で、パネル・枠・パンくずが切り替わる。

### 枠つきの表示

項目のパネルのうち画面いっぱいを使うもの（[冒険者の一覧](adventurers.md#パーティ)・[冒険者を選ぶ画面](loadout.md#育成の人選び)・[冒険者のタブ](adventurers.md#冒険者のタブ)の[ステータス](adventurers.md#ステータス)・[装備](loadout.md#装備)・[スキル](loadout.md#スキル)）を開いている間は、案内人の画面を次の形にする（`GuideFramedPanel`）。
旅の案内所の行き先も、同じ形にする。
これらは案内人を左に残し（ぼかした背景の上に立たせる）、案内人の右（設計座標で横848）に金の2本線を引き、その右に透ける面を置く。
商会の項目（買う・売る・合成・強化）は、案内人を隠し、左右の透ける面を金の2本線で区切った画面いっぱいの形にする（[商会](shop.md#商会)）。
編成・商会・神殿のメニューでは、枠を出さない。
ほかの画面でも同じ見た目にするため、部品は共通にする（[実装との対応](implementation.md#実装との対応)）。

| 部分 | 表示 |
|---|---|
| 背景 | 背景の絵をぼかした写しを重ねる |
| ヘッダー | 上端から高さ112pxの暗い透ける帯。「もどる」と×のタブ、所持ルーンの下地は消し、「もどる」・パンくず・所持ルーン・×の間に金の細い縦線を引く（端に飾りは付けない） |
| ヘッダーの下 | 左右48pxを空けた金の細い線。両端に小さな金のひし形 |
| 面 | パネルが、左（人やパーティ）と右（一覧や詳細）に酒場が透ける同じ色の面を置き、左右と下は画面の端まで延ばす。ヘッダーの帯は面より濃くする。面の間は金の2本線で区切り、ヘッダーの線と交わる所に大きなひし形を置く。16:9より縦長の画面では面と中身を縮めるが、ヘッダーの線を基準に縮め、線と面の上端の間に背景をのぞかせない |
| 見出し | 金のひし形と明るい金の文字（「パーティ」「一覧」など）。見出しの下に線は引かない |

四隅の飾りは置かない（ユーザーの判断）。

枠つきの表示の上に重ねる画面（[レベルアップ](adventurers.md#ステータス)と、探索・戦闘の[確認のダイアログ](adventure.md#冒険の画面)）は、ヘッダーの帯と同じ濃い紺で不透明に塗った窓に、金の細い線の縁と四隅の小さな金のひし形を付け、見出しは面の見出しと同じ金のひし形と明るい金の文字にする（レベルアップには見出しを置かない）。
中のボタン（－・＋・最大・やめる）は模様のないすりガラスのカードにし、決める「レベルアップ」は模様のない金の縁と光のカードにする。
窓を少しでも透かすと、リニア色空間の画面では後ろの文字が読めるほど透けたため、窓は不透明にした。

### すりガラスのカード

押す・長押しするものを並べる共通のカード（`GlassCard`）。

| 部分 | 表示 |
|---|---|
| 地 | うすく透ける角丸（半径22px）の板と、下へずらしたやわらかい影 |
| 縁 | 白い細い縁。左上から光が当たったように、上と左を明るく、下と右を暗くする |
| 模様 | 左上の角から広がり、角から離れるほど消える、ばら窓の4分の1（同心の弧・放射の線・小さな円）を淡い金で描く |
| 選んだとき | 金の縁と外へにじむ金の光、地をうすく金色にする |
| 押したとき | 板が少し沈み、影が縮む。0.5秒押し続けると長押しになり、指を離しても押したことにしない。一覧を動かし始めると取り消す |
| 点線のカード | 空きや「パーティから外す」「外す」のような操作と、アクセサリーの枠は、点線の縁で模様と影を付けない |

模様は、人のカードのように大きなものに付ける。
案内人の画面のメニューの行は、左のアイコンと模様が重なるため、ユーザーの「丸っぽい背景を消して」で付けない。
決定ボタン（リストの「買う」「召喚する」「出発」、レベルアップの画面の「レベルアップ」）には、ユーザーの「Submitボタンにマークは不要」で付けない。
装備の枠・付け替えの一覧の行・固有スキルの行のような小さなものは、ユーザーの判断で模様を付けない。
文字が左上から始まる行（商会の行、旅の案内所の行き先）も、文字が読みにくくなるため模様を付けない。
押せない箱（固有スキル・準備中の枠）は、同じ見た目で押せない板にする。

画面の枠とカードは、[枠つきの表示](#枠つきの表示)（重ねる窓を含む）とこのカードの2つだけにする。案内人の画面のほか、ホームの行き先カード、探索の下の案内の帯と右下の凡例、確認のダイアログの選択肢、デバッグルームのボタンもこのカードにする。透ける面を通さず景色の上に直に置くもの（探索の帯と凡例、デバッグルームのボタン）は、文字が景色に負けないよう、板を面と同じ紺で濃く敷く。段階・ランクのように色で見分ける板は、白い縁をその色にする。2026-10-18に、ドット絵の枠（`GuideFrame`）と角丸の板・輪（`RoundedRect`・`RoundedRing`）を画像とコードごと削除した。新しい枠や板の形は作らず、この2つを使う。
