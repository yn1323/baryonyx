# 画面一覧：パーティと冒険者の個別の画面

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## パーティ

編成のメニューの「冒険者」で、冒険者の一覧を開く。
パーティの入れ替えはこの一覧で行い、1人の装備・スキル・育成は、カードの長押しで開く[個別の画面](#育成)で行う。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で画面いっぱいに使う。
左右の余白は置かず、左（パーティ）と右（一覧）を金の2本線で区切る。

| 面 | 表示と操作 |
|---|---|
| 左（パーティ） | 透ける面に見出し「パーティ」と、4つの枠のカードを縦に並べる |
| 右（一覧） | 左と同じ透ける面に見出し「一覧」と、パーティにいない持っているキャラのカード（持っている順）を2列で並べ、最後に「パーティから外す」を置く。縦にスクロールする |

カードは[共通のすりガラスのカード](guide.md#すりガラスのカード)を使う。
人のカードには、左に立ち姿（周りの余白を切った48×52を4倍）と足元の影、右に名前、その下に「Lv」とLv、付けているスキルの属性のアイコン（12×12を3倍）を出す。
空いたパーティの枠のカードには「空き」とだけ書く。
「パーティから外す」は点線のカードに×と文字で、外せる人を選んでいないときは薄く出す。
「所持 〇人」「控え」の見出し、決定ボタンや変化を説明する文は置かない。

| 操作 | 結果 |
|---|---|
| パーティの枠を押す | その枠を選んで金の縁と光で囲む。空いた枠も選べる。もう一度押すか、別の枠を押すと選び直す |
| 一覧の人を押す | その人を選ぶ。もう一度押すとやめる |
| 枠を選んで一覧の人を押す（逆の順でもよい） | その枠の人と入れ替える。空いた枠なら入れる。入れ替えたあとは何も選んでいない状態に戻る |
| 枠を選んで「パーティから外す」 | 枠を空きにし、外した人は一覧に移る。最後の1人は外せず「パーティには1人以上必要です」と知らせる（1人以上を残す決まりは仮である）。枠を選んでいないか、空いた枠を選んでいるときは「外す人をパーティから選んでください」と知らせる |
| カードを長押し（0.5秒） | その人の個別の画面を開く。押している間はカードが少し沈み、一覧を動かし始めると取り消す |

入れ替え・編成・外したことは、カードを見ればわかるため通知しない。
開いたときは何も選んでいない。

持っているキャラと編成は、開くたびにサーバーから読み、入れ替えはすぐ画面に出してから裏でサーバーに保存する（[キャラと編成の保存](../party.md#キャラと編成の保存)）。保存できなかったときは元に戻して通知の帯で知らせる。
付けている武器・防具は、装備の機能から読む（[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。
初めて開いて読み込むまでは、一覧の面に「読み込み中…」を出し、パーティの枠と一覧を空けて仮データの中身を見せない。開き直したときは、前に読んだ編成をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
読めなかったときは「編成を取得できませんでした」、保存できなかったときは「編成を保存できませんでした」を通知の帯で知らせ、枠は変えない。
保存を待つ間は、続けて押しても受け付けない。
サーバーの接続先がないとき（展示室のプレビューなど）だけ、仮データの4人（トーマ・ルカ・アリア・ミナ）から始め、変更はアプリを動かしている間だけ残す。
ホームに立つ4人、冒険の戦闘の味方とデッキは、この編成を出す（探索の地図と街道の世界地図では、編成によらず木の駒1つで歩く）（[パーティの実装との対応](../party.md#実装との対応)）。単体で開く戦闘画面のモックとデバッグルームは、モックの4人のままである。
Lvは[育成](#育成)で上げたLvを、属性のアイコンは[スキル](loadout.md#スキル)で付け替えたスキルを出し、開くたびに読み直す。
キャラと、Lv・スキルの初期値は仮データで、スキルは戦闘画面のモックのものから選んだ。
絵のある4人は戦闘画面のドット絵を使う。
絵のない5人（アンセルム・グレタ・ルッツ・リタ・リツ）は、4人の絵に色を掛けて左右を反転した仮の絵で見分ける。

## 育成

冒険者の一覧でカードを長押しすると、その人の個別の画面を開く。
メニューには出さない項目（`Hidden`）で、ほかの画面からだけ開く。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で画面いっぱいに使う。
左の面（横640まで）にイラスト、金の2本線の右の透ける面に詳細を置く。
見出し（パッシブ・固有スキル・カスタムスキル・装備）は金のひし形と明るい金の文字にする。

| 区画 | 表示と操作 |
|---|---|
| 左（イラスト） | 縦長の背景付きのイラストを、枠を付けずに左の面いっぱいに敷き（面の大きさに合わせて端を切る）、右端を面の色へなじませる。その右下に戦闘のドット絵（64×64を4倍）を足元の暗いぼかしと影の上に立たせる |
| 右上 | 名前、Lvと使えるスキルの属性のアイコン（12×12を4倍）。右端に「レベルアップ」（模様のない[すりガラスのカード](guide.md#すりガラスのカード)に、選んだときと同じ金の縁と光。1レベル上げるのに要るルーンを添える）、その左に「絆」（同じカードに、灯った段を6つのひし形のしるしで出す。[絆](#絆)）。名前の行が長く「絆」に届くときは、行ごと縮めて収める |
| 右（キャラ自身） | 左にステータス8つ（2列4行。HP・物攻、属攻・速度、会心・物防、属防・幸運）、右に見出し「パッシブ」（板は置かない）。パッシブ2つを1行ずつ、アイコン（24×24を2倍）・名前・効果（2行まで）で出し、未解放のものはアイコンを暗くして錠前を重ね、名前の行の右に「Lv 10で解放」を出す |
| 右（デッキの6枚） | 左に「固有スキル」3枚、縦の線を挟んで右に「カスタムスキル」3枚（中身はスキルかアイテム。見出しに添え書きはしない）を、重ねずに1列に並べる。どれも戦闘のカードを効果の文の上で切った小さなカード（70×66ドットを2.5倍。挿絵と効果の間の点線の手前までと、枠の下端。2026-10-24に2倍から大きくし、6枚が面の幅いっぱいに並ぶよう間を詰めた）で、属性の枠・挿絵・左上のコスト・右上の属性・名前を出す。種類と対象の行と効果の文は出さず、カードを押して開く[スキルの付け替え](loadout.md#スキル)で読む（2026-10-23）。固有スキルは、セットしている覚醒の段階のカードを出す（[固有スキルの覚醒](../skill-evolution.md)）。未解放の固有スキルはカード全体を暗くして、錠前と「Lv 30で解放」のように解放するLvを重ねる。空いたカスタムスキルの枠は、枠を薄くして「空き」を出す |
| 右（装備） | 武器・防具・アクセサリー1〜3の5枠を同じ大きさの模様のないすりガラスのカードで並べる（準備中のアクセサリーは点線）。各枠に、アイコン・枠の名前・☆の数と品質の文字、装備の名前と倍率を掛けた効果を出す。品質がS・Aの装備は、アイコンに種類ごとの光り方の[キラキラ](../../art/direction.md#カードのキラキラ)を重ねる |

画面の上で指を左へ動かす（フリックする）と次のキャラ、右へ動かすと前のキャラに替わる。
パーティの枠の順、続けて控えを持っている順に1人ずつ替え、端から反対の端へ回る。
横へ120（設計座標）以上動かし、縦の動きより大きいときだけ替える。
イラスト・枠・カードのどこから動かしてもよく、動かし始めるとカードや枠のタップは取り消す。
レベルアップの画面を重ねている間は替えない。
どこを動かせるかを示す手がかりは、ユーザーの判断で置かない。
最後に見ていたキャラは、一覧・付け替えの画面と共有し、アプリを動かしている間は開き直しても残る。

武器・防具の枠を押すと、その人とその枠を選んだ[装備の付け替え](loadout.md#装備)を開く。
カスタムスキルのカードを押すと、その人とその枠を選んだ[スキルの付け替え](loadout.md#スキル)を、選択モードで開く。
固有スキルのカードを押すと、その人とその固有スキルを選び、右に[覚醒ツリー](../skill-evolution.md)を出した[スキル](loadout.md#スキル)の付け替えの画面を、選択モードで開く。未解放の固有スキルも開き、ツリーだけを見られる。
付け替えの画面で「もどる」か端末の戻るキーを押すと、この画面へ同じ人のまま戻る。
アクセサリーの3枠は、Lvで開くまで錠前と解放するLv（「Lv 15で解放」）を出し、開いたら付けているアクセサリー（空いていれば「なし」）を出す（2026-10-25）。どの枠も押すと、[装備](loadout.md#装備)の付け替えの画面をアクセサリーのタブで開く。

「レベルアップ」を押すと、詳細の上にレベルアップの画面を重ねて開く。
背面は暗くして押せなくする。
重ねた画面は、[枠つきの表示の上に重ねる窓](guide.md#枠つきの表示)にし、画面の中央に1列で並べる。
見出し・キャラの名前・覚えるスキル・次の解放・所持ルーンと残りは出さない（ユーザーの判断）。

| 部分 | 表示と操作 |
|---|---|
| 上 | 左に今のLvと上げたあとのLv（数字は同じ大きさ）、右に「－」「＋」「最大」。Lvの数字とその間の矢印は、ボタンと上下の中心をそろえる。上げる数そのものは出さない。「－」「＋」で上げる数を1ずつ変え、「最大」で所持ルーンで上げられるだけにする。上限のLvは超えない。1つも上げられないときは1のままにして、足りない量を見せる |
| 中 | ステータス8つの、上げる前・上げたあと・増える量（1行の高さ42、窓の幅いっぱい） |
| 下 | 左に「やめる」、右に「レベルアップ」を窓の幅いっぱいに並べる（高さ132）。使うルーンは「レベルアップ」の文字の下に、右上の所持ルーンと同じ48pxのアイコンと、ステータスの数字と同じ34ptの文字で添える。ルーンが足りないときは使うルーンを赤にし、「レベルアップ」を押せなくする。「やめる」で閉じる |

重ねた画面の「レベルアップ」を押すと、ルーンを使ってレベルを上げ、重ねた画面を閉じる。
上げたことは「トーマが Lv 13 になりました」「トーマが Lv 15 になり、「炎の心得」を覚えました」を[共通の通知の帯](../../rules/ui-design.md#操作を求めない通知)で知らせる。
「もどる」と端末の戻るキーは、重ねた画面を開いているあいだはそれだけを閉じ、個別の画面では開いた入口（冒険者の一覧など）へ戻る。
案内人の画面は、戻る操作を、開いている項目のパネルに先に渡す（`IGuideBackHandler`）。

### 絆

右上の「絆」を押すと、詳細の上に絆の窓を重ねて開く（[キャラが被ったとき](../monetization.md#キャラが被ったとき)）。
レベルアップの窓と同じ形で、背面は暗くして押せなくする。

| 部分 | 表示と操作 |
|---|---|
| 上 | 今の段と深めたあとの段（「絆 2 ▶ 絆 3」。数字の大きさと色はレベルアップのLvと同じ）。上限（6段）では次の段を出さない |
| 段の石 | 6つのひし形の石を横1列に並べる。灯った段は金、まだの段は暗い紺で、次に灯る石を後ろの淡い光で囲む |
| 中 | ステータス8つの、深める前・深めたあと・増える量（レベルアップの窓と同じ表） |
| 下 | 左に「やめる」、右に「絆を深める」。「絆を深める」の文字の下に、その人の戦闘のドット絵を絆のしるしとして添え、「持っている数 / 使う数」（1つで1段）を出す。しるしが足りないときは数を赤にして押せなくする。上限では「絆は上限です」にして押せなくする |

「絆を深める」を押すと、しるしを1つ使って1段上げ、窓を閉じて深めた瞬間の演出を画面全体に重ねる。
演出は、暗い紺の上に、その人のイラスト（縦長、左右と上下を紺へなじませる）と、それを囲む6つの石の弧を出す。
隣の石は細い線でつなぎ、両端が灯った線は金にする。
新しく灯る石は大きく薄い姿から元の大きさへ落ち着き、そこから淡い光が広がる。
続けて右の札に、名前・「絆 3」・上がるステータス（「全ステータス +6%」）を下からせり上げて出す。
画面のどこかを押すか、「もどる」・端末の戻るキーで閉じる。
戻る操作は、演出、絆の窓、レベルアップの窓の順に閉じる。
窓や演出を出している間は、フリックで人を替えない。

絆の段と持っているしるしは、サーバーの編成から読み、「絆を深める」で保存を待たずに演出を出してサーバーで深める（`POST /v1/party/characters/{id}/bond`）。保存できなかったときは演出を閉じて段としるしを戻し、「絆を深められませんでした」を通知の帯で知らせる。サーバーの接続先がないとき（展示室のプレビューなど）だけ、キャラの仮データ（`TrainingMockData` の `Bond`・`BondTokens`）から始め、アプリを動かしている間だけ残す（`TrainingBond`）。
深めた段の効果は、この画面・装備とスキルの付け替えの画面のステータスと、冒険の戦闘のステータスに入る。

キャラのLv・スキルと所持ルーン、付けている武器・防具は、開くたびにサーバーから読む（[キャラと編成の保存](../party.md#キャラと編成の保存)、[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。
初めて開いて読み込むまでは、名前の位置に「読み込み中…」を出し、ボタンを押せなくして仮データの中身を見せない。編成と装備は同時に読み、どちらも前に読んでいれば、すぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
読めなかったときは「キャラを取得できませんでした」を通知の帯で知らせる。
重ねた画面の「レベルアップ」を押すと、保存を待たずに重ねた画面を閉じ、上げたLvと、要るルーンを引いた所持ルーンを出して知らせる。
そのあとで、サーバーが要るルーンを計算し、残高から引いてレベルを上げる。保存を待つ間も、続けてレベルアップできる。
保存を待つ間に右上の所持ルーンを読み直しても、先に引いた分は引いたまま出すので、ホームへ戻っても同じ値を表示する。
保存できなかったときはLvと所持ルーンを戻し、「レベルアップできませんでした」を通知の帯で知らせる。サーバーに断られたとき（別の端末で上げていたなど）は、Lvと所持ルーンを読み直して描き直す。
サーバーの接続先がないとき（展示室のプレビューなど）だけ、仮データのLvと所持ルーン8,450から始め、使ったルーンと上げたLvはアプリを動かしている間だけ残す。

イラストは、Codex CLIで描いた下書き（1024×1536）を `Shared/Art/Characters/Illustrations/<キャラのID>.png` に置き、ぼかして縮める画像として取り込む（Bilinear・ミップマップあり・高品質の圧縮）。
9人ともあり、トーマ・ルカ・アリア・ミナ・リタ・リツの6人は、キャラ設定を作らずに、役割と戦闘のドット絵（4人）から依頼文を作って描いた（依頼文は `output/characters/<キャラID>/illustration-request.md`）。
イラストのないキャラは、枠の中を空けてドット絵だけを出す。
ステータスの伸び、固有スキルの名前・効果・解放するLvは仮データである。
パッシブは、戦闘と同じ定義（[CombatPassives](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatPassives.cs)）の名前・説明文・解放するLvを出す（[パッシブスキル](../passives.md)）。
要るルーン（Lv n から n+1 へ n×100）は仮の値で、上限（Lv 100、2026-10-23）とともにサーバーの値を使う。
ステータスは、9人それぞれのLv100の値に、Lvに応じた成長率を掛けて出す（[自キャラのLv100のステータス](../progression.md#自キャラのlv100のステータス)）。
絵のない5人は、絵を借りたキャラと同じ固有スキルにした。パッシブは9人それぞれに別のものがある。
固有スキルの絵はまだないため、スキルの挿絵（64×58）の中央24×24ドットを仮のアイコンにしている（戦闘画面のモックの画像を借りている）。
パッシブは18個それぞれに24×24ドットのアイコンがある（[パッシブの定義](../../catalog/passives/README.md)、`Features/Combat/UI/Art/Passives/`）。
4:3など横幅の狭い画面では、個別の画面とレベルアップの画面を同じ割合で縮める（`WorldLayerFit`）。

画面は `Baryonyx > Tavern > Create Screen Assets` で作り直す。
仮データは `Features/Training/Data/TrainingMockData.asset` で、生成の処理（`TrainingAssets`）が毎回上書きする。
