# 画面一覧：パーティと冒険者のタブ

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## パーティ

編成のメニューの「パーティー」で、パーティーと控えの画面を開く（2026-11-04に項目の名前を「冒険者」から改めた。ユーザーの指示）。
パーティの入れ替えはこの一覧で行い、1人のステータス・装備・スキルは、選んだ人を下の帯の「装備・スキル」で開く[冒険者のタブ](#冒険者のタブ)で行う。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で画面いっぱいに使う。
左右の余白は置かず、左（パーティ）と右（一覧）を、線を引かずに分ける。
酒場の画面はすべて[線のない形](../../rules/ui-design.md#線のない形)にする（2026-11-04、ユーザーが画面ごとの5つの案から「引き算」を選んだ）。

| 面 | 表示と操作 |
|---|---|
| 左（パーティー） | 透ける面に見出し「パーティー」と、4つの枠のカードを縦に並べる |
| 右（控え） | 左と同じ透ける面に見出し「控え」と、パーティーにいない持っているキャラのカード（持っている順）を2列で並べ、最後に「パーティーから外す」を置く。縦にスクロールする。見出しは、メニューの「一覧」と分けるため、2026-11-04に「一覧」から改めた |
| 下（帯） | 画面の幅いっぱいの、ヘッダーより濃い紺の帯（高さ140、上に金の細い線）。左に選んでいる人の立ち姿（48×52を2倍）・名前・「Lv」とLv・属性のアイコン、右端に金の縁と光の「装備・スキル ▶」。何も選んでいないときは人を出さず、「装備・スキル」も出さない（2026-10-31、ユーザーの指示。それまでは薄くして押せなくしていた） |

カードは[共通のすりガラスのカード](guide.md#すりガラスのカード)を使う。
人のカードには、左に立ち姿（周りの余白を切った48×52を4倍）と足元の影、右に名前、その下に「Lv」とLv、付けているスキルの属性の印（44px。[属性とコストの印](../../rules/ui-design.md#属性とコストの印)）を出す。
カードを押す操作は「選ぶ」だけにし、詳しい画面へは帯のボタン1つから入る（2026-10-26。カードの右端の矢印と長押しで開く形は、押す場所で意味が変わってわかりにくいため、やめた）。
左右の面は、設計座標の横660で分ける。4つの枠のカードは、帯の上まで並ぶ高さにする。
空いたパーティの枠のカードには「空き」とだけ書く。
「パーティから外す」は点線のカードに×と文字で、外せる人を選んでいないときは薄く出す。
「所持 〇人」「控え」の見出し、決定ボタンや変化を説明する文は置かない。

| 操作 | 結果 |
|---|---|
| パーティの枠を押す | その枠を選んで金の縁と光で囲み、その人を帯に出す。空いた枠も選べる（帯には誰も出さない）。もう一度押すか、別の枠を押すと選び直す |
| 一覧の人を押す | その人を選んで帯に出す。もう一度押すとやめる |
| 枠を選んで一覧の人を押す（逆の順でもよい） | その枠の人と入れ替える。空いた枠なら入れる。入れ替えたあとは何も選んでいない状態に戻る |
| 枠を選んで「パーティから外す」 | 枠を空きにし、外した人は一覧に移る。最後の1人は外せず「パーティには1人以上必要です」と知らせる（1人以上を残す決まりは仮である）。枠を選んでいないか、空いた枠を選んでいるときは「外す人をパーティから選んでください」と知らせる |
| 帯の「装備・スキル」を押す | 帯に出している人の[冒険者のタブ](#冒険者のタブ)を、ステータスのタブで開く |

入れ替え・編成・外したことは、カードを見ればわかるため通知しない。
開いたときは何も選んでいない。長押しでは何も開かない。

持っているキャラと編成は、開くたびにサーバーから読み、入れ替えはすぐ画面に出してから裏でサーバーに保存する（[キャラと編成の保存](../party.md#キャラと編成の保存)）。保存できなかったときは元に戻して通知の帯で知らせる。
付けている武器・防具は、装備の機能から読む（[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。
初めて開いて読み込むまでは、一覧の面に「読み込み中…」を出し、パーティの枠と一覧を空けて仮データの中身を見せない。開き直したときは、前に読んだ編成をすぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
読めなかったときは「編成を取得できませんでした」、保存できなかったときは「編成を保存できませんでした」を通知の帯で知らせ、枠は変えない。
保存を待つ間は、続けて押しても受け付けない。
サーバーの接続先がないとき（展示室のプレビューなど）だけ、仮データの4人（トーマ・ルカ・アリア・ミナ）から始め、変更はアプリを動かしている間だけ残す。
ホームに立つ4人、冒険の戦闘の味方とデッキは、この編成を出す（探索の地図と世界地図（冒険の世界地図・街道の世界地図）では、編成によらず木の駒1つで歩く）（[パーティの実装との対応](../party.md#実装との対応)）。単体で開く戦闘画面のモックとデバッグルームは、モックの4人のままである。
Lvは[ステータスのタブ](#ステータス)で上げたLvを、属性のアイコンは[スキルのタブ](loadout.md#スキル)で付け替えたスキルを出し、開くたびに読み直す。
キャラと、Lv・スキルの初期値は仮データで、スキルは戦闘画面のモックのものから選んだ。
絵のある4人は戦闘画面のドット絵を使う。
絵のない5人（アンセルム・グレタ・ルッツ・リタ・リツ）は、4人の絵に色を掛けて左右を反転した仮の絵で見分ける。

## 冒険者のタブ

1人のステータス・装備・スキル・限界突破・強化・覚醒は、6つのタブを切り替える1つの画面で扱う（2026-10-26。それまでは、個別の画面にステータス・パッシブ・デッキの6枚・装備の5枠をまとめ、カードや枠を押して装備とスキルの付け替えの画面へ進む形だった。1画面の情報が多すぎ、付け替えの画面に「6枚の一覧」「選択モード」「今のデッキ」の切り替えがあってわかりにくいため、HTMLとCodexのモックを比べて、ユーザーがこの形を選んだ。2026-11-03に、付けている物の[強化](loadout.md#強化)と[覚醒](loadout.md#覚醒)のタブを突破の下に足した）。
パーティーの画面の帯の「装備・スキル」で開き、編成のメニューの「一覧」で開く[人選び](loadout.md#一覧の人選び)からも、1人を押して開く。どちらもステータスのタブから始める。
タブはそれぞれメニューには出さない項目（`Hidden`）で、ほかの画面からだけ開く。
開いている間は左の看板娘を隠し、[枠つきの表示](guide.md#枠つきの表示)で画面いっぱいに使う。
6つのタブは、左から人の列、タブの列を置き、その右から画面の右端までに各タブの中身を置く（`PartySheet`）。
2026-11-03に、それまで右端に置いていたタブの列を、ユーザーの指示で人の列の右へ移した。左から人・タブ・中身の順に読める。中身の幅（1576）は変えていない。

| 部分 | 表示と操作 |
|---|---|
| 左の列（横160まで） | 持っている全員の札を縦に並べる。上からパーティの枠の順、金の細い線を挟んで控えを持っている順。札は模様のない[すりガラスのカード](guide.md#すりガラスのカード)に、戦闘のドット絵の頭から胸まで（36×32を3倍）を出し、名前は書かない。見ている人の札は選んだときの金の縁と光で囲む。入りきらない分は上下に動かす。札を押すと、そのタブのまま、その人に替える |
| タブの列（横160〜344） | 縦のタブ「ステータス」「装備」「スキル」「突破」「強化」「覚醒」。選んでいるタブは明るい金の文字と、左の金の縦線（横のタブの下線と同じ金）、ほかは白い文字。タブの間に細い線を引く。押すと、見ている人のまま、そのタブを開く |
| 中身（横344から右端まで） | 選んでいるタブの中身。人の列とタブの列、タブの列と中身は、線を引かずに分ける |

パンくずは「編成 › パーティー › アリア」で、どのタブかはタブでわかるため出さない。人選びから開いたときは「編成 › 一覧 › アリア」、冒険中に探索から開いたときは「冒険 › 一覧 › アリア」になる。
「もどる」と端末の戻るキーは、重ねた窓を開いているあいだはそれだけを閉じ、どのタブでも、開いた入口（冒険者の一覧か人選び）へ戻る。
どのタブでも、中身の上で指を左へ動かす（フリックする）と次の人、右へ動かすと前の人に替わる。
左の列の順と同じく、パーティの枠の順、続けて控えを持っている順に1人ずつ替え、端から反対の端へ回る。
横へ120（設計座標）以上動かし、縦の動きより大きいときだけ替える。
動かし始めるとカードや枠のタップは取り消す。
重ねた窓（レベルアップ）や、突破・強化・覚醒の演出を出している間は、フリックでも左の列でも替えない。
どこを動かせるかを示す手がかりは、ユーザーの判断で置かない。
見ている人は、一覧・6つのタブで共有し、アプリを動かしている間は開き直しても残る。

## ステータス

冒険者のタブの「ステータス」。タブの列の右の面（横944まで）にイラスト、右の透ける面に詳細を置く。
見出し（属性・パッシブ）は金のひし形と明るい金の文字にする。

| 区画 | 表示と操作 |
|---|---|
| 左（イラスト） | 縦長の背景付きのイラストを、枠を付けずに左の面いっぱいに敷き（面の大きさに合わせて端を切る）、右端を面の色へなじませる。その右下に戦闘のドット絵（64×64を4倍）を足元の暗いぼかしと影の上に立たせる |
| 右上 | 名前とLv。同じ行の右端に、小さな「レベルアップ」（決めるボタンの青い板、240×112。2026-11-03に、すりガラスのカードから替えた。[決めるボタン](../../rules/ui-design.md#決めるボタン)）。1段目に「レベルアップ」（26pt）、2段目に1レベル上げるのに要るルーンを、右上の所持ルーンと同じアイコンと24ptの数字で出す。Lvを上げるボタンをLvのすぐ横に置き、目立ちすぎないよう金の縁と光は付けない（2026-10-26、ユーザーの「レベルアップが目立ちすぎ」「Lvの横にレベルアップがない」）。上限では「レベル上限」にして押せなくする。名前の行が長く「レベルアップ」に届くときは、行ごと縮めて収める |
| 右（ステータス） | ステータス8つ（2列4行。HP・物攻、属攻・速度、会心・物防、属防・幸運）。付けている装備で上げた値を出す。スキルと装備をほかのタブへ移した分、項目名を28pt、数字を40pt、1行の高さを66にした（2026-10-26に76へ広げ、2026-11-04に属性の段を足すため詰めた）。項目名は左寄せ、数字は1つの項目の枠の中央に置く（2026-10-26、ユーザーの「数値が右寄りになっている」） |
| 右（属性） | 見出し「属性」の下に、使える属性の印（48px。[属性とコストの印](../../rules/ui-design.md#属性とコストの印)）と名前（炎・氷など）を並べ、同じ行の右端に「この属性のスキル・装備を付けられる」と書く。使える属性は付けているスキルから決まり（[装備の属性](../equipment.md#装備の属性)）、まだない人は「なし」と書いて右の文を出さない。2026-11-04に、名前の行の横の小さな印から移した（ユーザーの指摘「属性がステータス画面から分かりにくい」。スキル・装備との関係が分かるように1行を添えた） |
| 右（パッシブ） | 見出し「パッシブ」（板は置かない）と、パッシブ2つを1行ずつ出す（1行の高さ168）。アイコン（24×24を3倍）・名前（36pt）・効果（30pt、2行まで。入りきらない長い説明だけ24ptまで縮める）。未解放のものはアイコンを暗くして錠前を重ね、名前の行の右に「Lv 10で解放」を出す |

デッキの6枚は[スキルのタブ](loadout.md#スキル)、武器・防具・アクセサリーは[装備のタブ](loadout.md#装備)で出す。
キャラが被ったときの段（限界突破）は、タブの列の4つ目の[突破](#突破)で出す。

「レベルアップ」を押すと、詳細の上にレベルアップの画面を重ねて開く。
背面は暗くして押せなくする。
重ねた画面は、[枠つきの表示の上に重ねる窓](guide.md#枠つきの表示)にし、画面の中央に1列で並べる。
見出し・キャラの名前・覚えるスキル・次の解放・所持ルーンと残りは出さない（ユーザーの判断）。

| 部分 | 表示と操作 |
|---|---|
| 上 | 左に今のLvと上げたあとのLv（数字は同じ大きさ）、右に「－」「＋」「最大」。Lvの数字とその間の矢印は、ボタンと上下の中心をそろえる。上げる数そのものは出さない。「－」「＋」で上げる数を1ずつ変え、「最大」で所持ルーンで上げられるだけにする。上限のLvは超えない。1つも上げられないときは1のままにして、足りない量を見せる |
| 中 | ステータス8つの、上げる前・上げたあと・増える量（1行の高さ42、窓の幅いっぱい） |
| 下 | 左に「やめる」、右に「レベルアップ」を窓の幅いっぱいに並べる（高さ132）。使うルーンは「レベルアップ」の文字の下に、右上の所持ルーンと同じ48pxのアイコンと、ステータスの数字と同じ34ptの文字で添える。ルーンが足りないときは使うルーンを赤にし、「レベルアップ」を押せなくして、その上に「ルーンが 〇〇 足りません」を出す（2026-11-03）。「やめる」で閉じる |

重ねた画面の「レベルアップ」を押すと、ルーンを使ってレベルを上げ、重ねた画面を閉じる。
上げたことは「トーマが Lv 13 になりました」「トーマが Lv 15 になり、「炎の心得」を覚えました」を[共通の通知の帯](../../rules/ui-design.md#操作を求めない通知)で知らせる。
あわせて、窓を閉じた直後に、上がったLvとステータスの数字を2回ふくらむように光らせる（[レベルアップしたときの演出](#レベルアップしたときの演出)）。
「もどる」と端末の戻るキーは、重ねた画面を開いているあいだはそれだけを閉じ、閉じていれば開いた入口（冒険者の一覧など）へ戻る。
案内人の画面は、戻る操作を、開いている項目のパネルに先に渡す（`IGuideBackHandler`）。

### レベルアップしたときの演出

レベルアップの窓が閉じた直後に、Lvの数字とステータスの8つの数字が、そろって2回「ボワン、ボワン」と明るくなる（2026-11-02、ユーザーが画像の案から選び、動画を見て1回から2回にした）。
数字の後ろに、淡い金のやわらかい光と、白に近い小さめの光を重ねる。
1回ごとに、光は0.1秒で明るくなりきってから0.28秒で消え、その間に0.8倍から1.25倍へ広がる（芯の光はその半分だけ広がる）。
2回目は1回目の0.36秒後にふくらみ始め、全体は約0.7秒で終わる。
数字の色は変えず、白へ少し寄せて明るさだけを上げる。
イラスト・ドット絵・背景、名前や項目名には演出を出さない。

ユーザーと決めるまでに、イラストやキャラに光を流す案は不要とされ（窓の中で上げるため、上がったことが分かれば足りる）、窓・ボタン・数字だけで見せる控えめな案から、数字が光る方向を選んだ。
その方向の5つ（一斉にひと拍、上から順に、光が数字をなでる、下から入れ替わる、下の線が走る）から、一斉にひと拍が選ばれた。

部品は `TextGlow`（`Shared/UI/`）で、光の形は画像を使わず、コードで作るテクスチャ（`SoftLight`）で描く。
光るのはPlay中だけで、停止中の表示の切り替えでは光らない。

## 突破

冒険者のタブの「突破」。同じキャラが被ったときに手に入るしるしを使い、そのキャラを1段ずつ**限界突破**させる（[キャラが被ったとき](../monetization.md#キャラが被ったとき)）。
2026-10-26に、ユーザーの判断で、それまでの「絆」の呼び名をやめて「限界突破」にし、ステータスのタブの右上の「絆」と重ねて開く窓から、このタブへ移した。コードとサーバーでは `bond` と呼ぶ。
タブの列の右の面（横944まで）に[ステータス](#ステータス)と同じイラストとドット絵、右の透ける面に段の一覧を置く。

| 部分 | 表示と操作 |
|---|---|
| 右上 | 見出し「限界突破」（金のひし形と明るい金の文字） |
| 段の一覧 | 6段を上から縦に、面の幅いっぱいの模様のない[すりガラスのカード](guide.md#すりガラスのカード)で並べる（1枚の高さ112）。左に段の石（11×11ドットを6倍）とその上に段の番号、その右に段の効果の文（28pt。効果が長くなっても読めるよう3行まで折り返し、入りきらないときだけ22ptまで縮める）、突破した段は右端に「突破済み」 |
| 突破した段 | 石を金に灯し、右端に金の小さな文字で「突破済み」 |
| 次の段 | 選んだときと同じ金の縁と光で囲む |
| 右下 | 決めるボタン「限界突破」（青い板）。次の段を突破する。ほかの画面の決めるボタンと同じ位置に置く（2026-11-03、行の中から移した）。しるしがないときや、重ねた画面・演出を出している間は押せず、上限に達したら出さない |
| まだの段 | 石を暗い紺にして、札全体を薄くする（効果の文は読める） |

持っているしるしの数は出さない（ユーザーの判断。突破できるかはボタンでわかる）。
効果は今は仮に、どの段も「全ステータス +2%」（`TrainingBond.EffectOf`）。キャラごとの本番の効果は未決（[限界突破とかけら](../monetization.md#未決事項)）。

「限界突破」を押すと、確かめる窓を挟まずに、しるしを1つ使って1段上げ、突破した瞬間の演出を画面全体に重ねる。
演出は、暗い紺の上に、その人のイラスト（縦長、左右と上下を紺へなじませる）と、それを囲む6つの石の弧を出す。
隣の石は細い線でつなぎ、両端が灯った線は金にする。
新しく灯る石は大きく薄い姿から元の大きさへ落ち着き、そこから淡い光が広がる。
続けて右の札に、名前・「突破 3」・上がるステータス（「全ステータス +6%」）を下からせり上げて出す。
画面のどこかを押すか、「もどる」・端末の戻るキーで閉じる。
戻る操作は、演出を先に閉じる。
演出を出している間は、フリックでも左の列でも人を替えない。

突破の段と持っているしるしは、サーバーの編成から読み、「限界突破」で保存を待たずに演出を出してサーバーで上げる（`POST /v1/party/characters/{id}/bond`）。保存できなかったときは演出を閉じて段としるしを戻し、「限界突破できませんでした」を通知の帯で知らせる。サーバーの接続先がないとき（展示室のプレビューなど）だけ、キャラの仮データ（`TrainingMockData` の `Bond`・`BondTokens`）から始め、アプリを動かしている間だけ残す（`TrainingBond`）。
突破した段の効果は、ステータスと装備のタブのステータスと、冒険の戦闘のステータスに入る。

キャラのLv・スキルと所持ルーン、付けている武器・防具は、開くたびにサーバーから読む（[キャラと編成の保存](../party.md#キャラと編成の保存)、[装備の保存](../equipment.md#持っている装備と付け替えの保存)）。
初めて開いて読み込むまでは、名前の位置に「読み込み中…」を出し、ボタンを押せなくして仮データの中身を見せない。編成と装備は同時に読み、どちらも前に読んでいれば、すぐ出して裏で読み直す（[開き直したときの表示](../../rules/data-storage.md#サーバーに置くときの作り方)）。
読めなかったときは「キャラを取得できませんでした」を通知の帯で知らせる。
重ねた画面の「レベルアップ」を押すと、保存を待たずに重ねた画面を閉じ、上げたLvと、要るルーンを引いた所持ルーンを出して知らせる。
そのあとで、サーバーが要るルーンを計算し、残高から引いてレベルを上げる。保存を待つ間も、続けてレベルアップできる。
保存を待つ間に右上の所持ルーンを読み直しても、先に引いた分は引いたまま出すので、ホームへ戻っても同じ値を表示する。
保存できなかったときはLvと所持ルーンを戻し、「レベルアップできませんでした」を通知の帯で知らせる。サーバーに断られたとき（別の端末で上げていたなど）は、Lvと所持ルーンを読み直して描き直す。
サーバーの接続先がないとき（展示室のプレビューなど）だけ、仮データのLvと所持ルーン8,450から始め、使ったルーンと上げたLvはアプリを動かしている間だけ残す。

イラストは、Codex CLIで描いた下書き（1024×1536）を `Shared/Art/Characters/Illustrations/<キャラのID>.png` に置き、ぼかして縮める画像として取り込む（Bilinear・ミップマップあり・高品質の圧縮）。
9人ともあり、トーマ・ルカ・アリア・ミナ・リタ・リツの6人は、キャラ設定を作らずに、役割と戦闘のドット絵（4人）から依頼文を作って描いた（依頼文は `output/characters/<キャラID>/illustration-request.md`）。
イラストのないキャラは、枠の中を空けてドット絵だけを出す。
ステータスの伸び、固有スキルの名前・効果・解放するLvは仮データである。
パッシブは、戦闘と同じ定義（[CombatPassives](../../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatPassives.cs)）の名前・説明文・解放するLvを出す（[パッシブスキル](../passives.md)）。
要るルーン（Lv n から n+1 へ n×100）は仮の値で、上限（Lv 100、2026-10-23）とともにサーバーの値を使う。
ステータスは、9人それぞれのLv100の値に、Lvに応じた成長率を掛けて出す（[自キャラのLv100のステータス](../progression.md#自キャラのlv100のステータス)）。
絵のない5人は、絵を借りたキャラと同じ固有スキルにした。パッシブは9人それぞれに別のものがある。
パッシブは18個それぞれに24×24ドットのアイコンがある（[パッシブの定義](../../catalog/passives/README.md)、`Features/Combat/UI/Art/Passives/`）。
