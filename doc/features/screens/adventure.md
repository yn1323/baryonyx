# 画面一覧：冒険の画面

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 冒険の画面

Homeから冒険に出て、マスを選んで進み、戦闘と宝箱で報酬を得て、最奥のボスを倒すか負けるかやめるかしてHomeへ戻る1周を、次の画面で遊べる。
決めた事項・作り方・検証結果は[実装計画](../../plans/2026-10-04-adventure-loop.md)に記す。
冒険の状態（道を作る乱数の種、今いるマス、通ったマス、マスの出来事を終えたか、復活の回数、手に入れた報酬）はサーバーに保存し、マスを選んだ時点で残る（[冒険の保存](../stage-progression.md#冒険の中断と再開)）。
探索は森を見下ろす地図で進み、分岐ルートは冒険ごとに作る（[計画](../../plans/2026-10-04-exploration-route-map.md)）。
2026-10-21に、地図を左から右へ進み、行き先ごとの地面と光の道だけで描く形へ作り直すと決めた（[地図の作り直し](../stage-progression.md#地図の作り直し2026-10-21)、2026-10-22に実装）。

```text
Home ──カード（冒険していない）──▶ 街道の世界地図 ──右下のボタン──▶ 旅の案内所（ダンジョン一覧） ──出発──▶ 探索
街道の世界地図 ──戦闘・関所のボスのマス──▶ 戦闘 ──勝利（マスをクリア）・全滅・メニュー──▶ 街道の世界地図
                                              └─全滅──▶ もう一度挑む（同じマスの戦闘を始めから）
街道の世界地図 ──宝箱のマス（初めて）──▶ 宝箱の中身のダイアログ ──先へ進む──▶ 街道の世界地図
Home ◀─カード（冒険の途中）──────────────────────────────▶ 探索
探索 ──戦闘のマス──▶ 戦闘 ──勝利・報酬・戦闘後の強化──▶ 探索（次のマスを選ぶ）
                      ├─全滅──▶ 復活（ルーン）→ 戦闘を続ける ／ 帰還 → 冒険の結果 → Home
                      └─最奥のボスの撃破──▶ 冒険の結果 → Home
探索・戦闘 ──メニュー──▶ 中断してホームへ（選んだマスから再開） ／ 冒険をやめる → 冒険の結果 → Home
```

| 画面 | 作り | 表示と操作 |
|---|---|---|
| 出発 | 旅の案内所 | 行き先を選んで「出発」を押すと、確認を挟まずにサーバーで冒険を始め、探索へ移る。始めている間に続けて押しても、冒険は1回だけ始める。冒険の途中で出発しようとしたときは、ホームから再開するよう知らせる。解放していない行き先や通信の失敗で始められなかったときは「冒険を始められませんでした」と知らせ、押し直せる |
| 探索（`Exploration`） | シーン | 左から右へ進む地図（[地図の作り直し](../stage-progression.md#地図の作り直し2026-10-21)）。行き先ごとの地面（`Shared/Art/Stages/Exploration/Ground<行き先>.png`、512pxごとに並べて敷き、少し暗くする）の上に、冒険の種から作った道を、階を300pxごとに左から右へ並べて描く。マスは5本の列の上に立って同じ階では縦に揃い、道は真っすぐか隣の列への斜めの直線で結ぶ（[冒険の道の作り方](../stage-progression.md#冒険の道の作り方)）。マスは丸い台座に種類のアイコン（次に進めるマスは大きい札で24×24を3倍、ほかは2倍）を載せ、札の地の色がマスの種類を示す（魔物は目立たない青灰色、強い魔物は赤、宝箱は金、最奥の間は紫、休憩は橙、行商人は茶、怪しい宝箱はくすんだ紫、試練は深紅、歩数の扉は緑、覚醒の祭壇は青白い色、「？」は灰青）。次に進めるマスは金の縁と脈打つ光、行ける先の強い魔物は赤い光、最奥の間は紫の光で見せ、通ったマスは薄く、行けなくなったマスは暗く沈める。マスどうしは光の線で結び、次に進める道を金色で脈打たせ、その先の行ける道を淡い青、通った道を暗い金、行けなくなった道を消えかけで描く。パーティ4人（戦闘の姿を1ドット1px）が今いるマスの台に立ち、画面の左から約26%の所に来るよう地図を動かす。1本指で地図を左右に引くと、入口から最奥の間まで見渡せる。右上に行き先と階（例：ミストラ遺跡 第2層）、その下に小さく案内（行商人のマスと、戦闘が始まるときだけ。進む道を選ぶときと、宝箱・怪しい宝箱・歩数の扉・覚醒の祭壇を開けるときは、脈打つ道と札、マスに置いた宝箱で伝えるため出さない）、左上に「メニュー」、下に地図の中の位置を示す細いバー、右下に凡例を開く「？」。凡例は「？」で開き、凡例か「？」を押すと閉じる。端末の戻るキーは、ダイアログ、凡例、メニューの順に受け取る |
| マスの選択と移動 | 探索 | マスの出来事（戦闘・宝箱など）を終えると、次の階の行けるマスを大きい札にし、縁を金色にする。マスの種類は札の色とアイコンと「？」の凡例で伝え、札の横に文字の手掛かりは出さない。札（押せる範囲は150px四方）を押すと、選んだ道を通った道の色に、ほかの道を行けなくなった道の色に変え、パーティの木の駒が0.4秒でそのマスへ跳ね（[マス単位の探索と操作](../stage-progression.md#マス単位の探索と操作)）、地図が0.6秒で駒に追いつく。選ばなかったマスの印は薄れ、選んだマスの印は駒が着くときに消える。歩く間に選んだマスをサーバーに保存し、両方が済むと着いたマスを見せる。保存できなければ「冒険を保存できませんでした」と知らせて読み直す。着いたマスが休憩なら下の「焚き火」を開いて選ばせ、選んだ結果を知らせ、「？」なら中身の種類を「「？」は宝箱だった」のように知らせてからその種類のマスとして続け、行商人なら品物の一覧を開き、試練なら条件を知らせてから戦闘へ移る。宝箱・歩数の扉は、着くと押さなくても開ける。宝箱から覚醒が出たときは、中身を見せたあとに題「宝箱の覚醒」で、覚醒の祭壇と同じ手順（仲間・固有スキル・段階）で選ばせ、選ぶまで閉じない（2026-10-25、[覚醒が起きる場面](../skill-evolution.md#覚醒が起きる場面)）。怪しい宝箱は着くと「開ける」「通り過ぎる」を聞き、覚醒の祭壇は着くと仲間の選択を開く。どちらも閉じたあとは、宝箱の絵を押すと開き直す |
| 焚き火 | 探索に重ねる窓 | 休憩のマスで開く（[休憩の鍛える](../stage-progression.md#休憩の鍛える仮)）。画面を暗い幕で覆い、案内人の画面と同じ枠の窓に、題「焚き火」と、夜の野営地の絵（Homeの3Dの野営地を夜の光で描いた `CampfireNight.png`。上下を少し切って0.82倍で見せる）を置く。絵の上には、今の編成の4人（戦闘のドット絵を4倍。焚き火に照らされた暖かい色に寄せる）と焚き火の薪をHomeと同じ位置に立て、木箱の上に本と羽ペン（32×21を4倍）を置く。押せるのは絵の中の3つで、テントが「休む」、斧の刺さった切り株と薪の山が「鍛える」、木箱の上の本が「研鑽」。それぞれの後ろで淡い光がゆっくり脈打ち、近くにすりガラスの札で名前を出す。ボタンの列は置かない。選ぶまで閉じず、戻るキーでも閉じない |
| 鍛える | 焚き火から開く窓 | 題「鍛える」。4人を淡い台座の上に戦闘のドット絵（4倍）で横に並べ、下に名前。押した仲間の台座を金色にし、その上に「物攻・属攻 +15%」の札を出す。「鍛える」は仲間を選ぶまで押せない。「もどる」と戻るキーで焚き火へ戻る |
| 研鑽 | 焚き火から開く窓 | 題「研鑽」。4人を戦闘のドット絵（3倍）で横に並べ、それぞれの下に、研鑽していないカードスキルを2枚まで戦闘と同じカード（0.74倍）で並べる。押したカードは持ち上がって光り、下の帯に「ファイア → ファイア+　威力 100% → 130%」のように研鑽でどうなるかを出す。「研鑽」はカードを選ぶまで押せない。「もどる」と戻るキーで焚き火へ戻る |
| 宝箱 | 探索 | 宝箱のマスでは、パーティの右手前に宝箱（32×32を3倍）を置き、着くとすぐに開いて報酬を見せる。開けた中身を保存してから、宝箱が中身の品質の色の光を漏らしながら震えて開き、光が弾けて手に入れた物の札を出す（[探索の演出デバッグルーム](debug-rooms.md#探索の演出デバッグルーム)の宝箱）。宝箱の光は中身のうち一番良い品質の色にし、その札から開く。中身が2つ以上なら、1.1秒ずつ次の札に替え、最後の札を閉じてから「宝箱を開けた！」のダイアログを出す |
| 戦闘のマス | 探索 → 戦闘 | 案内に「魔物が現れた！」を出し、パーティの頭の上の「！」・地図の揺れ・帯・左右から閉じる幕の出現の演出（[探索の演出デバッグルーム](debug-rooms.md#探索の演出デバッグルーム)）を再生する。強い魔物のマスは「強い魔物が現れた！」、最奥の間は地図を暗くしてから「最奥の主が現れた！」になる。幕が閉じきったところで、戦闘のシーンを開く |
| 冒険のメニュー | 探索に重ねるダイアログ | 行き先と階だけを書く。中断してホームへ・冒険をやめる・閉じる。ルートは地図そのものに出ているため、ルートの画面は置かない |
| 冒険中の装備 | 探索 → 酒場の[装備の人選び](loadout.md#装備の人選び) | 左上の「メニュー」の下に、同じ形の「装備」ボタン（酒場のメニューの「装備」と同じ付け替えのアイコン）を置く。次のマスを選んでいるときだけ押せ、ダイアログ・焚き火・戦闘後の強化を開いている間は受け付けない。押すと酒場のシーンを装備の人選びから開き、パンくずの最初を「冒険」にする（「冒険 › 装備」）。人選びの「もどる」と右上の×は、メニューを挟まずに探索へ戻る。冒険はサーバーに残っているため、戻った探索は冒険を読み直して同じマスから続ける（2026-10-25） |
| 戦闘（`Battle`） | シーン | [戦闘画面のモック](battle.md#戦闘画面の見た目モック)を、マスの敵の組み合わせと行き先の背景で戦う。開くと、探索から移ってきた幕が開ききるまで敵を暗がりに隠して待ち、開いてから敵が影から1体ずつ歩み出て、赤い帯で「魔物が現れた！」を出してから、「味方のターン」の帯の下で手札を配る。最奥の間ではボスが最後に景色を暗くして歩み出て、帯は「強敵が現れた！」になる。演出の間は手札がなく、ターンを終えられない。敵は[技と行動パターン](../combat-enemy-behavior.md)で動き、大技を溜めた敵の上には「力を溜めている」「あと〇ターン」と2行で出て、当たるまで敵の絵が暖色に明滅する。敵のブロックは、味方と同じ黄色の帯で敵のHPバーに重ねる。激化と後半への切り替えでは「激化！」と出る。敵をすべて倒すと勝利、味方がすべて倒れると全滅で戦闘を終える。右上に「メニュー」（中断してホームへ・冒険をやめる・つづける）。左上は行動順のため右上に置いた |
| 勝利とドロップ | 戦闘 | 金の帯で「勝利！」を出して味方が跳ねて喜び、そのあいだに勝ったマスを保存する。続けてマスのドロップを1つずつ、最後に倒した敵から光の玉が落ちて弾け、画面の上寄りに手に入れた物の札（種類と☆、名前、品質、持ち物に加えた）を開く。札を開いてから0.6秒おいて次のドロップへ進み、最後のドロップのあとに札を閉じて「勝利！」のダイアログを出す。何も落ちなければ札に「何も見つからなかった」を出す。光の大きさ・長さと札は[戦闘の演出デバッグルーム](debug-rooms.md#戦闘の演出デバッグルーム)のとおり。アイテム・アクセサリー・武器・防具は、その物の絵をアイコンにする。アイテムには品質がないため、品質の文字を出さず、札の縁も品質の色にしない |
| 戦闘後の強化 | 戦闘に重ねる窓（再開した探索でも開く） | 最奥の間以外の戦闘に勝ち、最後のドロップの札を閉じると開く（[戦闘後の強化](../stage-progression.md#戦闘後の強化)）。画面を暗い幕で覆い、上に題「強化」、中央に戦闘のカード（1.3倍）を3枚、間を空けて横に並べる。枠は段階で、白は銀の枠（斬の枠）、金は属性のない枠に金の線、虹は属性のない枠を虹にして、段階の名前は出さない。挿絵の窓には段階の色の淡い光を置き、1人の強化はその仲間の戦闘のドット絵（3倍）、全員の強化は4人（2倍）を立てる。名前の帯に仲間の名前（全員なら「全員」）と強化の名前（名前のある強化だけ）、説明の欄に上がる・下がる項目と幅（上がる幅は緑、下がる幅は赤）と、効くとき（強敵との戦いで・勝つたびに・2戦のあいだ）を書く。押したカードは持ち上がって後ろが光り、下の「選ぶ」で決める。「選ぶ」はカードを押すまで押せない。選ぶまで閉じず、戻るキーでも閉じない。選ぶとそのまま探索へ移り、勝利のダイアログは出さない。選ぶ前にアプリが終わったときは、再開した探索で同じ3枚を開く |
| 全滅と復活 | 戦闘 | 景色が暗くなって灰色の帯で「全滅してしまった…」を出し、そのあいだに所持ルーンと復活の費用を読み直してから、復活のダイアログを出す。ルーンで復活すると、倒れた味方の足元から青い光が立って元の色に戻り、HPが満ちて青い帯で「復活！」、続けて「味方のターン」の帯の下で手札を配る |
| 報酬 | 探索・戦闘に重ねるダイアログ | 宝箱は「宝箱を開けた！」、戦闘は「勝利！」（最奥の間と、戦闘後の強化の後に探索へ移れなかったときだけ）だけで、手に入れた物はその前の宝箱の演出や「勝利とドロップ」の札で見せるため本文に書かない。「先へ進む」で探索へ（ボスなら「つぎへ」で冒険の結果へ） |
| 復活 | 戦闘に重ねるダイアログ | 「全滅してしまった…」、手に入れた物は持ち帰れること、復活すると敵の傷はそのままで味方が全快して続けること、所持ルーン（足りなければ不足量）。「ルーンで復活（費用）」と「帰還する」を同じ形で縦に並べ、カウントダウンは付けない（[復活画面](../combat.md#復活画面)）。ルーンが足りなければ復活を押せない |
| 冒険の結果 | 探索・戦闘に重ねるダイアログ | 「踏破！」「冒険の終わり」「帰還」、行き先と着いた階、最深記録（更新したら「最深記録を更新！」）、持ち帰った物。「ホームへ」でHomeへ |

確認・メニュー・報酬・復活・結果は、どれも共通の確認ダイアログ（`GameDialog`）である。
画面全体を暗幕で覆って背面のタップを止め、[枠つきの表示の上に重ねる窓](guide.md#枠つきの表示)と同じ窓（不透明な濃い紺に金の細い縁と四隅のひし形）に、明るい金の題名・絵・本文と、最大5つの選択肢を、模様のない[すりガラスのカード](guide.md#すりガラスのカード)の同じ形で縦に並べる。
選択肢を押すと、次に表示を変えるまで受け付けない（通信の待ち中に二重に送らない）。
端末の戻るキーは、ダイアログを開いていればそれを閉じ（閉じられない結果・報酬などは何もしない）、探索と戦闘ではメニューを開く。
戦闘の途中で中断すると、再開したときはそのマスの戦闘を始めからやり直す。
探索のシーンは、ホームから開いても単体で開いても、開いたときにサーバーから冒険を読み、冒険の途中なら今いるマスの地図を出し、冒険がなければホームへ戻る。
開く演出の途中で読み終えたときは、開き終えてからホームや戦闘へ移る。

宝箱・マスの種類のアイコンは仮の絵で、Codex CLIで描いた（[実装計画の素材](../../plans/2026-10-04-adventure-loop.md#素材)）。
地図の木・下草・岩・最奥の遺跡は、PixelLabで作った候補から選び、32色の共通の色にまとめた（[探索の地図の計画](../../plans/2026-10-04-exploration-route-map.md#素材)）。下草の絵のうち岩の2枚（4・5フレーム目）は、地図の素材の写しに入れず、地図には立てない。
地図の地面は行き先ごとのCodexの生成画像で、2026-10-22に森の木・下草・遺跡の絵を地図に立てるのをやめた（絵は `Shared/Art/Stages/Exploration/` に残している）。
展示室で探索画面のPrefabを選ぶと、決まった種の見本の地図を入口から見た形で並べる。
停止中も、探索画面のPrefabと `Exploration` シーンは同じ見本の地図・印・道・パーティ・文字を表示する。生成のときに一度並べて作り込み、実行中は冒険の地図に並べ直す。
戦闘の味方とデッキは、今の編成の人・Lv・ステータスと、解放済みの固有スキル・カスタムスキルのスキルから作る（[パーティの実装との対応](../party.md#実装との対応)）。装備のステータスと、カスタムスキルに入れたアイテムは、まだ戦闘に反映しない。
探索から装備を変える入口は、2026-10-25に左上の「装備」ボタンとして足した。編成（パーティの入れ替え）を変える入口は、まだない。
画面の案は `output/adventure-equip-mock/`（Git対象外）にある。案では冒険の地図をぼかした背景にしていたが、今は酒場の背景のまま開く。
