# 画面一覧：戦闘画面

[画面一覧](../screens.md) / 根拠：[初期企画](../../game/brief.md)

## 戦闘画面の見た目モック

`BattleLab.unity` は、カードバトルの画面の雰囲気を確かめるモックである。
戦闘のロジックはまだ作らない段階のため、画面構成を決めたものではない。
[カードバトルの画面構成](common.md#未決事項)は未決のままとし、このモックを見て決める材料にする。
[ホーム](top-home.md#ホーム画面の見た目モック)の右下の行き先カード（再開）から開くほか、シーンを単体で開くか、[展示室](../showcase.md)のシーン一覧から開く。
まだHomeへ戻る操作はない。

| 領域 | 表示と操作 |

| 左上 | 行動順（オクトパストラベラー、ロマンシング サガ2 リベンジオブザセブンの行動順の表示を参考にした）。Safe Areaの左上から右へ6コマ並べ、左端が今のターンである。[ターン順](../combat.md#ターン順)は味方の合計の速度で決まるため、味方のターンはパーティの紋章（剣と盾）の1コマ、敵は1体ずつ顔の1コマで表す。コマは24×24ドットの絵を1ドット4pxで表示し、1ドットの枠で囲む。枠は今のターンが金、味方が青、敵が赤で、内側も味方は暗い青、敵は暗い赤にする。味方の2コマ続きが連続ターンに当たる。倒した敵は行動順から消える |
| 左 | 味方4人。右を向いて2列に並ぶ。左の列を半段高くし、上からミナ・トーマ・ルカ・アリアの順にジグザグに置く。それぞれの足元にHPバーを出す |
| 右 | 敵3体（苔スライム・小、苔むした狼・中、森の守り手・大）。狼（奥）とスライム（手前）を同じ列に上下に並べ、その後ろ（右奥）の、狼とスライムの間の高さに守り手を置く。敵は1ドット3pxで表示する（味方は4px）。足元にHPバーを出し、その上に弱点のアイコン（12×12ドットの四角いドット絵）を並べる |
| 下部 | 手札（枚数は[手札](../combat.md#手札)の決まりのとおり）を、手に持ったように扇状に並べる（1枚ごとに7度ずつ傾け、隣と重なってよい。両端の角度の差は42度までとし、枚数が多いときは間隔を詰める）。カードは画面の下からはみ出し、ふだんは挿絵と使い手・名前・種類の行が見える。カードは挿絵が上2/3まで広がるフルアートで、挿絵の下端はディザで本体に溶ける。挿絵の下端に左寄せで、上から使い手、名前、種類と対象（「攻撃・敵単体」のように種類だけ色を変える）の3行を重ね、その後ろにTopの「LOADING...」と同じ暗く透ける帯を、行ごとの文字の長さに合わせて敷く。その下の欄に説明文を書き、威力はステータスの割合（「属攻の100%」。[カードの数値の見せ方](../combat.md#カードの数値の見せ方)）で書いて、本文と同じ大きさで色だけ変え、途中で改行しない（攻撃は黄、回復は緑、防御は青）。説明文の中の[キーワード](../combat.md#カードのキーワード)（凍え・ブロックなど）は、水色の下線付きの文字にし、途中で改行しない。挿絵の左上に小さな数字のコスト、右上に属性のアイコンを重ね、属性は枠の色でも表す（炎は赤、氷は青、雷は黄、斬は銀、属性なしは金。属性なしはアイコンを出さない）。エネルギーが足りないカードは、コストの数字を赤くし、コストも含めたカード全体に黒を70%重ねて暗くする。手札にある間は70%の不透明度で透けさせる（透けさせても黒の濃さは70%のまま）。押して上げたときは説明を読めるよう透けさせない |
| 左下・右下 | G3の配置（2026-10-26、ユーザーが4案から選んだ。下に経緯）。左下は、上にエネルギー（細いひし形の線と、今使える数だけの白い数字。「/3」や見出しは出さない）、その下に山札（裏向きのカードの束の絵と、残りの枚数）。右下の角に、文字のないターン終了（深い紺の地に細い白い線の横長のカプセルと、白い ▶）。その上に、左から消滅（紫の炎の絵と枚数。1枚もないときは出さない）と捨て札（表向きの2枚の絵と枚数）を横に並べる。どれも暗い帯を敷かず、背景の上に直接置く。ターン終了は、押せないとき（敵のターン、払えるカードがないとき）は▶ごと灰色になる |

操作は見た目を確かめるための仮の反応である。
カードを押すと、ばねのように弾みながら真っすぐに起き上がり、2倍に大きくなって、画面の左右中央、上下中央より少し下へ移る。下端は画面の下端から160px上げる（1080pxの画面で、カードの中心が画面の中心より約90px下になる）。
説明文に[キーワード](../combat.md#カードのキーワード)があるカードは、上がっている間、カードの横（端から16px）に、キーワードごとの説明札を上端をそろえて縦に並べる（Slay the Spireと同じ置き方）。札は対象と反対の側に置く。敵（画面の右）に使うカードは左、味方に使うカード（回復・防御・強化・支援）は右に置き、対象をタップするときに札が重ならないようにする。札を合わせた高さがカードより高いときは、札の下端がカードの下端（画面の下端から160px）にそろうまで上へずらし、画面からはみ出さないようにする。札は景色の上に置く[すりガラスのカード](guide.md#すりガラスのカード)（濃い紺の板、模様なし）で、幅340pxに、水色のキーワードと、その意味を書く。高さは文の長さに合わせる。同じキーワードは1枚にまとめ、札は4枚までとする。カードを敵へ向けて引っぱっている間（照準の点が出ている間）は、ねらう相手を隠さないよう札を消す。
上がっているカードもタップを受け、もう一度タップすると対象を選ばずに使う（下の「タップする」を参照）。上がっているカードは手札の扇と重なるため、重なった場所のタップも上がっているカードが受ける。
カードの使い方は、引っぱる方法とタップする方法の2つを用意し、どちらでも使える（Slay the Spireのスマホ版と同じ考え方）。
カードが上がっている間は、そのカードで選べるキャラ全員の頭の上に▼のカーソルを出し、1秒ごとに1ドットずつ上下させる。
あわせて、そのカードの使い手が敵の側へ1歩（64px）出て、足元に金の輪（`CasterRing`）を、HPバーの下に名前の札を出す。名前の札は、カードの使い手の行と同じ色の文字を、Topと同じ暗く透ける帯に重ねたものである。ほかの味方は暗くしない（ブロックのように味方全員が対象のカードもあるため）。使い手が自分を対象にできるカード（ヒール）では、輪と▼が両方付く。カードを手札へ戻すと、使い手は元の場所へ戻り、輪と名前の札は消える。
操作を説明する文は出さない。

- **引っぱる**：押したまま上へ100px以上スワイプすると、指の下の対象が白く光る。カードは上がった位置から動かず、カードの中央から指まで点が曲線に並ぶ（Slay the Spireの矢印に当たる）。点は手札より奥に描くため、カードの裏から伸びて見える。点は、指が対象の上にあるときは明るく、ないときは暗い。敵に使うカードは敵、味方1体に使うカード（ヒール）は味方の上で離すと、エネルギーを払ってそのキャラに使う。スワイプが足りないまま離すか、対象のない場所で離すと、カードは手札へ戻る。
- **タップする**：押した場所から24px以内で離すとタップとして扱い、カードを上げたまま対象のタップを待つ。対象のキャラをタップすると、そのキャラに使う。上がっている同じカードをもう一度タップすると、対象を選ばずに使う。敵単体への攻撃とヒールは、選べる相手からランダムに1体を選び、全体が対象のカード（サンダー・ガード）は全員に使う。何もない場所をタップすると、手札へ戻る。別のカードをタップすると、そちらに持ち替える。ターン終了を押したときも手札へ戻る。

対象の判定は、どちらの方法でも、キャラの絵の周りに72pxの余白を足した範囲で行い、余白が重なる場所では絵に近いキャラを選ぶ。
全体が対象のカード（サンダー・ガード）は、押した時点から対象の全員が白く点滅し、カードが上がっている間は点滅を続ける。上へスワイプするか、タップしたあと対象の側のだれかをタップすれば使え、1体を選ばなくてよい。
使ったカードは手札から消え、残りのカードがばねのように動いて中央へ寄り、空きなく扇に並び直す。
敵は赤く光って揺れ、ダメージの数字が浮かび、HPが減る。
弱点の属性なら[属性と弱点](../combat.md#属性と弱点)の倍率を掛け、数字を大きく、黄色から橙の色で表示する（「弱点！」の文字は出さない）。
回復した味方には、回復量を緑の小さめの数字で表示する（「+」は付けない）。
弱点は1体に複数持てる。開示済みの弱点は属性のアイコン、未開示の弱点は「？」のアイコンで表し、未開示の弱点を突くとその場で開示する（[弱点の開示](../combat.md#弱点の開示)）。
冒険の戦闘では、敵の種類ごとに記録した、前の戦闘までに開示した弱点を最初から見せる（[弱点の開示](../combat.md#弱点の開示)）。
単体で開いたモックは記録を使わず、仮の初期値として狼の氷と守り手の炎だけを開示済みにしている。
開示するときは、弱点のアイコンが光る演出（キラーン）を出す。
当たった瞬間から0.1秒かけて「？」が少しふくらみながら白くなり、光が最も強いときに属性のアイコンへ替わる。
同時に、アイコンの右上の角で四方へ光の伸びる星が光り、回りながら小さくなって消える。左下の角でも、遅れて小さな星が光る。
アイコンは白から元の色へ戻りながら弾むように元の大きさへ戻り、その上を右上がりの光の帯がドット単位で左から右へ抜ける。
演出は約0.55秒で、ヒットストップの間も止まらずに進む。星と周りの光は属性の色を帯び、画面の揺れや閃光は出さない。
アイコンの上の光はアイコン自身の形の内側にだけ描き（`Vfx/Shaders/BattleWeaknessGlint.shader`）、星・周りの光・小さな粒はほかの演出と同じく計算で描く。
開示した当たりで敵を倒した場合は、アイコンだけ替わり、星は出さない。
カードを使うと、エネルギーを払ってカードが手札から消えたあと、使い手の味方が敵の側へ1歩（64px）出て、効果が出てから元の場所へ戻る。カードを上げている間に前へ出ていた使い手は、その位置から動きを続け、いったん戻ってから出直すことはしない。
その間、画面の上部中央（行動順の高さより下）に、Topの「LOADING...」と同じ暗く透ける帯を敷いてスキル名を出し、戻ったら消す。
エネルギーが足りないカードを使おうとすると、カードは手札へ戻り、スキル名と同じ帯に「エネルギー不足」を、足りないコストの数字と同じ赤で0.9秒出す。ほかのカードが行動中なら、そのあとスキル名の表示へ戻す。
続けて何枚か使った場合は、使った順に1枚ずつ動く。
ターン終了を押すと敵のターンになり、行動順で次の味方のターンまでの敵が1体ずつ行動する（今の並びでは狼、スライムの順）。
敵のターンの始まりには、画面の中央より少し上に、スキル名と同じ暗く透ける帯を横長に敷いて「敵のターン」と出し、0.5秒待ってから敵が動き出す。
帯の上下には1ドットの線を引き、行動順のコマに合わせて、敵のターンは赤、味方のターンは青にする。文字も同じ系統の明るい色にする。
帯は、線が中央から左右へ伸びながら0.12秒で現れ、0.12秒で消える。帯はタップを受けない。
行動する敵は、行動順の先頭に来てから味方の側へ1歩出て、スキル名（狼は「かみつき」、スライムは「たいあたり」、守り手は「大地の拳」。仮の名前と威力）を出し、立っている味方1人をランダムに選んで、引いてから踏み込んで攻撃し、戻る（[当たりの瞬間と読みやすさ](battle-effects.md#当たりの瞬間と読みやすさ)）。
攻撃された味方は赤く光って揺れ、ダメージの数字が浮かび、HPが減る。HPが0になった味方は暗くなり、攻撃の対象から外れて行動しなくなる（[倒れた味方](../combat.md#倒れた味方)）。
倒れた瞬間に、その味方のカードは手札・山札・捨て札から消え、枚数も減る。手札のカードは、[敵の撃破](battle-effects.md#スキルの演出と背景)と同じ流れで崩れて消える。カードは白く燃えて0.12秒震え、上から（左右どちらかへ少し寄って）ドット単位でまだらに削れながら0.6秒で36px浮き上がる。削れの先頭のドットは白く光り、削れたドットはそれぞれの色の四角い粒になって舞い上がり、薄れて消える。残りのカードは、使ったときと同じくすぐに詰めて並び直す。
倒れた味方を対象にできるのは復活させるカード（リザレクション）だけで、ヒールなどのほかの回復は、その味方に▼が出ず使えない。復活した味方のカードは、消滅したものも含めて山札のランダムな位置に戻り、そのあと、その味方のカードを山札から2枚引く。
倒した敵は行動しない。敵のターンの間は、カードを押せず、ターン終了も押せない。
手札に今のエネルギーで払えるカードが1枚もなくなると、ターン終了を押さなくても敵のターンになる（[エネルギーとコスト](../combat.md#エネルギーとコスト)）。エネルギーを使い切った場合も、エネルギーが残っていて手札のコストがすべてそれより高い場合も同じで、その時点でターン終了は押せなくなる。使ったカードの効果がすべて出終わってから判定するため、最後のカードでエネルギーが戻った場合は終わらない。引くカードで引いたカードは、着地するまで待ってから判定する。手札にコストが0のカード（コストを下げたカードや、天啓で次のカードが無料のとき）が残っているときも終わらない。
敵のターンの始めに、手札は捨て札へ流れる（保持のカードは残り、霧散のカードは消滅する）。敵がすべて行動し終わると、エネルギーが3に戻って[手札の決まり](../combat.md#手札)どおり5枚を引く。
同時に、帯へ「味方のターン」と、その後ろに小さく「ターン4」のようにターン数を出す。カードを配る動きと重ねて出すため、待ち時間は増えない。戦闘の開始時も同じ帯を出す。
行動順で味方のターンが続き、間に動く敵がいないときは、「敵のターン」を出さずに「連続！ もう一度 味方のターン」と出す。
敵を全滅させてからターン終了を押すと、敵が元に戻る。味方が全滅した場合も、敵のターンの終わりに元に戻り、全員のカードが山札に戻って、空の手札に5枚を引く。
固有スキルの使用は動かない。

2026-09-29、ユーザーの依頼で表示を減らした。
場所の表示、敵の頭上の行動予告（ボスの大技までのターン数を含む）、敵の名前、HPの数値（敵・味方とも）、山札と捨て札の枚数は出さない（山札の枚数は2026-09-30に、HPの数値は2026-10-24に、捨て札と消滅の枚数は2026-10-26に、表示するよう改めた）。
味方のHPは左上の一覧から各キャラの足元へ移した。
エネルギーは、PlayModeでなくても最初のターンの値を表示する（2026-10-17から最初のターンはターン1。それまではターン3）。

同日、続けて左上の一覧（ターン数と、味方の名前・固有スキルの枠）と、行動順の「いま」の表示を外した。
弱点のアイコンとカードの枠・名前の札・コスト・選択時の枠をドット絵で描き直し、カードを扇状に並べた。
その後、エネルギーは「小さな宝石と数字」、ターン終了は「くすんだ金の細い枠」の案をユーザーが選び、画面に入れた。
カードは一時、最初のモックの約1.3倍に大きくした。
ユーザーの確認で、枠と余白が大きすぎ、挿絵より詳細の欄を広く取りたいとなったため、枠を細くし、挿絵を等倍（1ドット4px）に戻して、42×71ドット（168×284px）にした。
効果の文字も1段階小さくした。長い名前や効果は欄に収まるよう自動で縮む。
その後、エネルギーを左下、ターン終了を右下へ移して手札の横幅に余裕ができたため、カードを1.25倍（1ドット5px）で表示した。
縦に細長いというユーザーの指摘で、ポケモンカードやマジック：ザ・ギャザリングと同じ63×88mm（約5:7）に合わせ、42×59ドット（210×295px）にした。
手札は、ユーザーの依頼で名前と挿絵に加えて効果の行が少し見える高さまで上げた（設定アセットの `RestBottom` を-62px）。
説明文を書く欄を取るため、挿絵を横長の窓（32×20ドット）にし、下の欄を効果・説明文・対象の3段にした。
挿絵は、はじめ32×32の中央を切り出して表示していたが、ユーザーの依頼で横長の構図として描き直した（後述）。説明文（「炎の玉で敵1体を焼く。」など）は仮の文である。
敵は大きすぎたため、1ドット3pxで表示した。
味方と敵は、カードを大きくしたときに画面の上へ20px寄せ、その後ユーザーの依頼でさらに60px上げた。
さらにユーザーの依頼で味方と敵の間を広げ、味方を左へ80px、スライムを右へ50px、狼を右へ40px動かした。
枠は、ユーザーが選んだ属性の色の細い枠（デザイン案D）にした。カード上のコストは、数字までドット絵で描いた案からユーザーが選んだ「菱形の台座」（14×14ドットの金の縁の菱形に、暗い縁取りの4×6ドットの琥珀色の数字）にした。左下のエネルギーの宝石も、同じ金の菱形に琥珀の石をはめた絵にそろえた。菱形の枠（`CardCostFrame`）と数字（`CardCostDigits`、0〜9を横に並べた1枚）は別の絵にし、Unityで数字を枠の中央に重ねる。数字の幅（4ドット＋縁取り）に合わせて枠を偶数の14ドットにしており、中央に置いても半ドットずれない。
2026-09-30、ユーザーの依頼で、コストをカードの左上の角からはみ出す位置から、挿絵の左上の角に重ねる位置へ移した。ドット数はそのままで、1ドット5pxから4pxに下げて一回り小さくした（台座は70pxから56px）。

同日、ユーザーの依頼でカードのデザインを作り直した。
Slay the Spire、Magic: The Gathering、Hearthstone、Marvel SNAPのカードの構成を参考に、試作を7回重ねてユーザーが選んだ（試作とスクリプトは `output/card-redesign/`、Git対象外）。
ドットを細かくして拡大率を下げてよいという判断により、カードを70×98ドットにし、1ドット3pxで表示する（画面上の大きさは210×294pxで、ほぼ変わらない）。
ユーザーの判断で次のようにした。

- 挿絵を大きく見せるフルアートにする。アーチ形の窓は挿絵を作りづらいため使わない。
- 種類（攻撃・回復・防御）、対象（単体・全体）、使い手を必ず見せる。「種類」「使い手」のような見出しと、使い手の顔は出さない。使い手の名前は長くなるため、専用の1行を取る。
- 種類と対象は、札にせず色付きの文字の1行にする。ボタンのように見える板や札は使わない。
- 使い手と名前は挿絵に重ねたうえで、Topと同じ暗く透ける帯を敷いて読みやすくする。帯は、行ごとの文字の長さまでにする。
- 威力の数字は本文と同じ大きさにし、色だけ変える。説明文は威力を含む1文にした（「炎の玉で敵1体を焼き、318ダメージ。」など。仮の文）。
- コストは、数を石の数で表すと多いときに困るため数字で表す。目立ちすぎないよう、11×11ドットの暗い札に琥珀の細い縁と5×7ドットの数字を重ねる。

帯は `BattleInspectCardBand` が描く。Topの帯の画像の中央の列を縦に使い、上下の透け方をそのまま保つ。行ごとに、文字の終わりの6px先から27pxで透明になる。
帯の幅は、カードに文字を入れるときに文字の実際の長さから決める。

同日、ユーザーの依頼で、山札から手札を配る動きを加えた。
山札は16枚で、PlayModeの開始時に切り混ぜる。
2026-10-03から、山札は[スキルの仮設定](../combat.md#スキルの仮設定)の50枚のうち、4人に4枚ずつの16枚にした（下の「スキルの山札」）。それまでは6種類のカードを順に繰り返した16枚だった。
`アイスランス` は、エネルギーが足りないカードの見た目を確かめるため、コストを仮に7にしている（エネルギーの最大は開始時5）。
PlayModeでは手札が空の状態で始まり、0.3秒後から0.12秒ごとに1枚ずつ、山札の枠（絵と残りの枚数）の右端から小さく傾いた裏向きのカードが飛び出す。
はじめは山札の絵の中心から出していたが、出たばかりのカードが枚数の数字に重なって読みにくいというユーザーの指摘で、枠の右端に改めた。
カードは0.35秒で手札の位置まで飛び、途中で横幅を縮めて裏から表へ返る。
1枚出るたびに、山札の残りの枚数を1つ減らす。
配り始める前に配り終えたときの並びを決め、1枚目を一番右に置き、以後はその左隣へ順に置く（右詰め）。
着地したカードはその後動かず、飛ぶカードは山札から右へ進むだけで、置き済みのカードの上を横切らない。
エネルギーで払えないカードも、下げた位置へそのまま飛んで着地し、着地したあとに沈まない。暗く透けさせるのは着地してからにする。
はじめは1枚ごとに扇を中央へ寄せ直していたが、先に置いたカードと飛ぶカードが左へ動いて不自然だというユーザーの指摘で、この形にした。
ターン終了で引くカードも同じく左端（山札の側）に入り、手持ちのカードは配り始めに1度だけ右へ寄る。
配っている間は、カードを押せず、ターン終了も押せない。
PlayModeでないときは、最初の5枚が並んだ状態を表示する。開始時のエネルギー（3）で払えないカードは、Play中と同じく暗く透けさせる。
捨てる操作とゴミ箱のボタンは、ユーザーと相談して作らないことにした（[手札](../combat.md#手札)）。

2026-10-01、ユーザーの依頼で次の3点を変えた。

- 山札が尽きたら、はじめの16枚をすべて切り混ぜて新しい山札にする（[手札](../combat.md#手札)）。手札と同じカードが重なることがあるため、山札の16枚はデータとして持ち、引いたカードの中身を、手札にない表示用のカードへ入れて表示する。
- 選んだカードを、それまでの1.5倍から2.25倍（その1.5倍）に大きくし、画面の中央に出す。中央のスライムがカードに隠れるため、隠れたキャラもタップで選べるよう、上がっているカードはタップを受けないようにした。（同日、もう一度のタップでカードを使うようにしたため、タップを受けるように戻した）
- エネルギーが足りないカードを半透明にするのをやめ、全体を少し暗くしてコストの数字を赤くした。暗くする黒い膜はコストの下に重ね、赤い数字は暗くしない。

同日、2.25倍では大きすぎるというユーザーの指摘で、選んだカードを1.6倍にし、画面の上下左右の中央から、左右中央の下寄せ（下端から24px）に改めた。
このカードに重ならないよう、味方を左へ60px寄せた。
敵は、はじめ右へずらしたが窮屈で、狼の尻尾が守り手の弱点アイコンにかかった。そこでユーザーの提案で、狼（奥）とスライム（手前）を同じ列に上下に並べ、その後ろに守り手を置く配置にした。
引っぱるときの点は、カードの上端からカードの中央へ出どころを移し、手札より奥に描いて、カードの裏から伸びるように見せる。

同日、ユーザーと相談して行動順の見た目と位置を改めた。
比べた案と試作は `output/turn-order/`（Git対象外）に置いた。

- 味方のコマはアリアの顔だとアリア1人のターンに見えるため、パーティの紋章にした。4人の顔を並べた横長のコマ、4人の顔を重ねたコマ、顔を順に入れ替えるコマ、紋章の下に4人の色の点を並べるコマも比べたが、ユーザーの判断で紋章だけにした。紋章は、剣と盾・翼の盾・旗・王冠と盾・羅針盤の星の5案から、剣と盾を使っている（ユーザーの選択は未確定）。
- 味方と敵を枠の色で分け、今のターンは金の枠のままにした。味方を線の上、敵を線の下に並べる案は、横長のスマホでは縦の余裕がなく、行動順が守り手の頭まで下がるため採らなかった。
- コマは、ユーザーの判断でUIアイコンの規格どおり24×24ドットにした（前は顔を12×12または16×16ドットで切り出していた）。
- 位置は上部中央から左上へ移した。倒した敵が抜けても今のターンの位置が動かず、画面を読み始める左上から「今→先」の順に読めるためである。20:9ではSafe Areaの左端へ寄る。
- 16:9では行動順の右端がスキル名の帯の左端にかかったため、スキル名の帯を46px下げ、行動順との間を12px空けた。

2026-10-26、エネルギー3固定と捨て札のルール（[手札](../combat.md#手札)）に合わせて、山札・捨て札・消滅とエネルギー、ターン終了の見せ方を作り直した。
Codexで今の画面をもとにイメージを作り、ユーザーと4回やり取りして決めた。左右に分ける・左下にまとめる・床に置いた束・画面の下端の流れの線の4案から流れの線の案（D）を土台に選び、宝珠や砂時計などの絵で表す案と、文字を模様で飾る案は「イメージが違う」とされた。
ユーザーの条件は、エネルギーは今の数だけを出して見出しを付けない、場所は左下か扇の下、アプリのUIのように平らで控えめにする、ターン終了は文字のない記号のボタンで右下に置く、押せないときの見た目を用意する、である。
これに合わせた4案（G1〜G4）から、ユーザーはG3（左下のひし形と数字、カプセルの ▶、その上に消滅と捨て札）を選んだ。下端の金色の流れの線は、まだ入れていない。
部品の絵は、ドット絵ではなく平らな画像（[UI/Art](../../../client/Assets/Baryonyx/Features/Combat/UI/Art) の `EnergyDiamond`・`EndTurnCapsule`・`EndTurnArrow`・`DiscardIcon`・`ExhaustIcon`）で、生成の手順は[戦闘画面の生成](../../../client/Assets/Baryonyx/Features/Combat/Editor/BattleInspectAssets.cs)の `BuildEnergy`・`BuildEndTurn`・`BuildDiscard` にある。
効果で手札を捨てるときは手札を押して選び、捨て札から拾うときは捨て札の新しいほうから最大9枚を画面の中央に1列に並べて押して選ぶ。選ぶ間は帯に「捨てるカードを選ぶ」「手札に加えるカードを選ぶ」と出す。

### 山札と捨て札の一覧

山札・捨て札・消滅の絵と枚数を押すと、その札置き場のカードを一覧で見られる。
押せる範囲は、絵と枚数の枠より上下左右に16px広い。
消滅は1枚もないときは枠ごと出ないため、押せない。

- 画面全体を暗くし、上に札置き場の絵・名前・枚数と閉じる×を、その下にカードを手札と同じ見た目の1.05倍で1段に6枚ずつ並べる。見出しとカードはまとめて画面の中央に置き、画面に収まらない枚数は縦にスクロールする。
- 山札はコストの小さい順、同じコストは名前の順に並べる。山札の順のまま見せると、次に引くカードが分かってしまうためである。捨て札と消滅は新しいものから並べる。
- コストはパッシブで下がった値を、眠り札は目覚めた段を、手札と同じく出す。
- 開いている間は、後ろの手札・ターン終了・戦場を押せない。×か画面のどこかを押すと閉じる。スクロールの指の動きでは閉じない。
- カードを上げている間に押すと、カードを手札へ戻してから開く。状態の一覧も閉じる。覚醒先を選ぶ画面の間と、勝って手札を片付けたあとは開かない。開いている間に札置き場のカードが動くと、一覧もそれに合わせて変わる。

部品は [BattlePileList](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattlePileList.cs) で、生成の手順は [BattlePileListAssets](../../../client/Assets/Baryonyx/Features/Combat/Editor/BattlePileListAssets.cs) にある。

### 勝ったあとの手札

勝敗で終わる戦闘（冒険・街道）で敵をすべて倒すと、勝利の演出の始めに手札を片付ける。
手札は0.35秒で360px沈みながら消え、エネルギー・山札・捨て札・消滅の数とターン終了も同時に薄れて消える。
片付けたあとは、ドロップの札、戦闘後の強化、勝利のダイアログの間も出さず、タップも受けない。
全滅したときは片付けず、ルーンで復活すると今までどおり配り直す。
勝利の演出は[勝利の演出](battle-effects.md#勝利の演出)にある。

#### 変更と判断の記録

手札を操作するための数とターン終了も、戦闘が終われば使わないため、手札と一緒に消した。

## 戦闘の背景を選べる戦闘シーン

`Battle.unity` は、戦闘の背景を10種類から選べる戦闘シーンである。
画面は[戦闘画面の見た目モック](#戦闘画面の見た目モック)と同じで、背景の3Dの舞台だけを、夕暮れの高原と10種類（草原の街道、朝霧の森、坑道、水晶の洞窟、海辺の岩場、霧の沼地、雪原、火山、夜の墓地、古城の大広間）から選ぶ。
シーンの `BattleStages` を選び、Inspectorの「Stage」のドロップダウンで背景を変える。停止中のGameビューでも、選んだ時点で背景・光・色調が切り替わる。
[ホーム](top-home.md#ホーム画面の見た目モック)の右上の[デバッグルームの一覧](top-home.md#デバッグルームの一覧)から開くほか、シーンを単体で開くか、[展示室](../showcase.md)のシーン一覧から開く。このシーンは[冒険の戦闘](adventure.md#冒険の画面)も兼ね、冒険から開いたときは行き先の背景を自動で選ぶ。単体で開いたときは、Inspectorで選んだ背景の戦闘画面のモックになる。
背景の一覧、配置、光は[3Dの舞台の戦闘の背景](../../art/hd2d-stage.md#戦闘の背景)を正本とする。
