# 装備生成と厳選

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)と2026-09-15のユーザー提示仕様

## 確定している方針

- 同じ装備でも、レア度・付与効果・数値幅をランダムにする。
- 探索中も装備を変更でき、獲得した装備をその場で使えるようにする。
- 装備・パッシブ・スキル・パーティ構成のシナジーを作る。
- 倍率が積み重なって数字が伸びるハクスラの成長感を狙う。

## 設計方針

### 戦い方を変える装備更新

HPダメージを伸ばす、必要なダウン値に届かせる、仲間との連携を成立させるなど、装備更新を戦い方の変化につなげる。
育成・装備の更新によって、以前勝てなかった敵や未踏の深部に挑めるようにする。

「ダウン役1人・火力2人・回復1人」などを唯一の正解にはしない。
ダウン寄り、火力寄り、追撃寄りなど、得意な勝ち方を変えられるようにする。
追撃に関わる具体的な効果は、[追撃の詳細](combat.md#追撃と連携の範囲)を決めてから設計する。

## 変更と判断の記録

- 2026-09-19：参照会話と実装指示により、探索中の装備変更と獲得直後の比較・変更導線を追加した。サンプルの共通武器を完成版の職業適性や装備枠として扱わない。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に基づき、ダウンや連携を含む戦い方の変化を装備厳選の目的へ加えた。編成を唯一の役割分担へ固定せず、具体的な装備効果は未確定とする。パーティ・戦闘・育成・MVPへ反映する。
