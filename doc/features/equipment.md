# 装備生成と厳選

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- 同じ装備でも、レア度・付与効果・数値幅をランダムにする。
- 装備・パッシブ・スキル・パーティ構成のシナジーを作る。
- 倍率が積み重なって数字が伸びるハクスラの成長感を狙う。
