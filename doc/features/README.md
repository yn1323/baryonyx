## 一覧の更新

機能を追加するときは、次の項目を一覧に記載し、詳細文書へリンクする。

| 項目 | 記載内容 |
|---|---|
| 機能名 | 利用者の操作や処理の目的が分かる名称 |
| 概要 | 何ができるか、どの条件で動くか |
| クライアントの入口 | 関連コードのパス。画面がなければ「なし」 |
| サーバーの入口 | 関連コードのパス。サーバー処理がなければ「なし」 |
| 実装状況 | 未実装、一部実装、実装済みと、残る条件 |

実環境への反映状況は、コードの実装状況と区別して記録する。
