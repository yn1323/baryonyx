# 機能仕様の索引

[全体索引](../README.md) → 機能仕様

機能ごとの要求・動作・制約・実装の入口を、1機能1文書で記す。
個別の値と見た目は[データ索引](../catalog/README.md)、ゲーム全体の体験は[ゲーム概要](../game/overview.md)で管理する。
各文書の節（確定している方針・設計方針・仮設定・候補・未決事項・確認待ち）の意味は[文書管理方針](../rules/documentation-policy.md#mdの形式と状態)に従う。
候補や未決欄があることは、機能の採用や実装を意味しない。
実装の状況と入口は、各文書の「実装との対応」に記す。

## 機能を追加・変更するとき

仕様に動作・制約・未決事項を記し、この索引の該当する分野の表へ1行で加える。
実装したら、その文書の「実装との対応」に実装の入口と、企画で決めたことと実装したことの差を記す。
既存の仕様と矛盾するときは[仕様追加時の矛盾の扱い](../rules/documentation-policy.md#仕様追加時の矛盾の扱い)に従う。
