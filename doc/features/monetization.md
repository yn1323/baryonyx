# ガチャと課金の検討項目

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

課金しないと進めない設計にはしない。
課金方式とガチャ仕様の採用は未決である。

2026-09-24、ユーザーはゲーム内でのガチャの呼び名を「召喚」とし、召喚からキャラクターと装備が出る可能性があると示した。
ホームの左下に入口のボタンだけを置いており、抽選の内容と画面は未実装である（[ホーム画面](screens.md#ホーム画面の見た目モック)）。
ルーンを購入できるようにして有償の抽選になる場合は、購入の前に、購入する場所の近くで各アイテムの確率を表示する（[Google Playの決済ポリシー](https://support.google.com/googleplay/android-developer/answer/9858738?hl=ja)）。

## 候補と例

キャラクターガチャ、武器ガチャ、ルーン購入、目標達成などの報酬倍率上昇、追加キャラクター等を候補とする。
候補を列挙したことは販売やガチャ実装の決定を意味しない。
