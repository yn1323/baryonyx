# ガチャと課金の検討項目

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

課金しないと進めない設計にはしない。
課金方式とガチャ仕様の採用は未決である。

## 候補と例

キャラクターガチャ、武器ガチャ、ルーン購入、目標達成などの報酬倍率上昇、追加キャラクター等を候補とする。
候補を列挙したことは販売やガチャ実装の決定を意味しない。
