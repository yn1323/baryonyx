# ガチャと課金の検討項目

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)、[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

## 確定している方針

課金しないと進めない設計にはしない。
ルーンは販売しない。

2026-09-24、ユーザーはゲーム内でのガチャの呼び名を「召喚」とし、召喚からキャラクターと装備が出る可能性があると示した。
ホームの左下の入口から、神殿（狐の精霊が案内する召喚の画面のモック）を開ける（[案内人がいる画面](screens.md#酒場工房神殿旅の案内所の画面)）。
一覧は仮データで、抽選の内容と召喚の処理は未実装である。

### 「5,000ワット分運動したことにする」チケット

「5,000ワット分運動したことにする」チケットを販売する予定である（旧称：ズル休みチケット）。
使っても**ルーンは増えず**、その日の[ワットボーナス](step-bonus.md)だけが得られる。
Health Connectには書き込まず、ゲーム内だけで扱う。

## 候補と例

キャラクターガチャ、武器ガチャ、追加キャラクター等を候補とする。
候補を列挙したことは販売やガチャ実装の決定を意味しない。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| チケットの5,000ワットの扱い | その日の実際のワットへの**上乗せ型**か、5,000ワット未満を5,000ワットとして扱う**底上げ型**か |
| チケットの名称 | 候補：おやすみ券、雨の日チケット |
| チケットの使い方 | 1日の使用上限、週次ボーナスの条件に算入するか、無料配布の有無 |
| 召喚の方式・確率・天井 | 未決。重複時の扱い・保証・持ち越し、提供期間・更新方法も未決 |
| チケット以外に採用する商品と価格 | 未決 |
| 購入の確定・失敗・保留・復元・返金対応 | 未決 |
| 提供地域・対象年齢に応じた表示・運用条件 | 未決 |
| ゲーム内入手とのバランス・無課金の進行経路 | 未決 |

## 法務メモ

見直しの資料に、開発者とClaude（chat）の検討時の法務メモとして次の4点がある。
いずれも要専門家確認であり、一次資料での確認も未実施である。

- コンプガチャ（特定の組み合わせを揃えると別アイテム）は景品表示法で禁止。
- 表示確率と実確率の不一致は景品表示法違反（優良誤認）になりうる。確率は[Google Playの決済ポリシー](https://support.google.com/googleplay/android-developer/answer/9858738?hl=ja)に従い、購入場所の近くに表示する。
- ルーンを課金で得られないため、召喚は無償通貨のみのガチャになる。
- 販売するチケット自体が資金決済法の前払式支払手段に当たるかは確認が必要。

## 変更と判断の記録

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位を「歩」から「ワット」（1歩＝1ワット）へ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位ワット)）。チケットの仮称を「5,000歩歩いたことにする」から「5,000ワット分運動したことにする」へ改め、正式な名称は引き続き未決とした。

- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、ルーンを販売しないことと、「5,000歩歩いたことにする」チケットの販売予定を反映した。チケットの型・名称・使用条件と召喚の方式は未決とし、法務メモは要専門家確認として記録した。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| ルーン購入を収益化の候補とする。ルーンを購入できて有償の抽選になる場合は、購入の前に確率を表示する | ルーンは販売しない |
| 目標達成などの報酬倍率上昇を収益化の候補とする | 運動目標の廃止に伴い、候補から外す |
