# 画面一覧と操作

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

2026-09-15のユーザー提示仕様で決めた探索・戦闘・運動目標の操作と表示は、次の正本を参照する。
RPG全体の画面構成・遷移と、個々の画面の詳細は引き続き未決である。

| 対象 | 操作・表示の正本 |
|---|---|
| 探索の入口・移動・短いヒント | [部屋単位の探索と操作](stage-progression.md#部屋単位の探索と操作) |
| 行き先を選ぶための敵・報酬・未探索情報 | [行き先を選ぶ情報](stage-progression.md#行き先を選ぶ情報) |
| キャラ・スキル・標的の選択と強スロー | [基本操作](combat.md#基本操作と共通の戦闘時間) |
| 敵HP・ダウン残量・成立表示 | [HPバーとダウンリング](combat.md#hpバーとダウンリング) |
| 標的・大技予告・スキル性能などの優先順位 | [戦闘中の情報](combat.md#戦闘中の情報の優先順位) |
| 無料再戦・ルーン復活と確認画面 | [再戦と復活](combat.md#無料再戦とルーン復活) |
| 進展と過去の記録の表示方針 | [成長の記録](stage-progression.md#成長の記録) |
| 運動目標の設定、条件の要約、倍率の表示、選べない条件 | [目標設定画面](goals.md#設定画面) |
| 任意の目標枠、基準・目標量・時間帯の選択 | [目標枠](goals.md#目標枠と任意設定)・[設定の流れ](goals.md#設定の流れと判定基準) |
| 目標の進捗・達成後・未設定・データ未確認・過去の履歴 | [進捗と履歴の表示](goals.md#進捗と履歴の表示) |
| 目標の変更予約・取り消し・再設定 | [編集・削除・再設定](goals.md#編集削除再設定) |

## 変更と判断の記録

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に基づき、操作と表示の確定事項を各正本へ接続した。具体的な画面遷移やタップ順を推測で確定せず、ダウンリングなどの決定済みの表示とは区別する。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、任意の目標設定、条件の要約、進捗・達成済み・変更予約・過去履歴の表示を目標仕様へ接続した。未設定枠やデータ未確認を警告・未達へ置き換えず、具体的なレイアウトは未決とする。
