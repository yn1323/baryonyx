## 確定している方針

2026-09-15のユーザー提示仕様で決めた探索・戦闘・運動目標の操作と表示は、次の正本を参照する。
2026-09-18の参照会話に基づく画面構成・遷移は、[操作ワイヤー](game-wireframe.md)で確認する。
縦持ち、探索中の仲間・装備変更、左右の戦場、上部の敵予告、下部のHP・スキルを採用する。
個々の寸法と最終デザインはワイヤーの評価後に決める。

2026-09-19のワイヤー評価に基づき、ダンジョン内の探索は部屋・通路とパーティを表示し、見えている入口をタップして進む方針とする。
出発前の「冒険先」選択と、入った後の「探索」の操作を区別する。
具体的な表示要件と未確定事項は、下表の探索仕様を正本とする。

## ホーム画面の見た目モック

2026-09-24、ユーザーはデザインモックのA2案（TOPの広間で焚き火を囲む「野営地」）を採用した。
横長の画面の余白は、キャラクターの立ち絵ではなく背景の世界とパーティ全員で埋める。
TOPの全面押下で遷移し、実データには接続しない。
計画と判断の経緯は[実装計画](../plans/2026-09-24-home-camp-mock.md)に記す。

| 領域 | 表示と操作 |
|---|---|
| 中央 | TOPと同じ広間、焚き火、パーティ4人（名前なし）、光る奥の門。4人は「パーティ」と同じ操作。門の上に文字は置かない |
| 左上 | 今日の歩み。歩数、今日の目標とゲージ、残り歩数、今週の目標。縁をぼかした暗い下地に置き、下地全体で「ルーンを取得」 |
| 右上 | 所持ルーン（表示のみ、画面端へ向かって暗くなる下地）と設定（丸い影） |
| 左下 | パーティ、装備、召喚（魔法陣のアイコン）、目標。台を置かず、影の上にドット絵のアイコンと文字を置く。4つ並べてもパーティと重ならないよう、各ボタンは幅128px（設計座標）にする |
| 右下 | 探索の途中は、行き先カード（今いるダンジョンの絵に「森の遺跡 B3F」と「再開」を直接書く）と、その上のワールドマップ（寒色の丸いボタン、ドット絵のコンパス） |

2026-09-24、ユーザーは枠の見直しで次を選んだ。
四角い白い枠は使わず、濃淡の下地で読ませる。
パーティ・装備・目標はアイコンだけのボタンにする。
「冒険へ」と「行き先を選ぶ」はドット絵調にせず、探索の途中は行き先カードで再開する。
「行き先を選ぶ」は今いるダンジョンを出る意味になるため、表記を「ワールドマップ」とする。
検討した案は[デザインモック](https://claude.ai/artifact/37YmCN3jjXE5j3Cwhx9Vp9)の「探索の途中（確定）」に残す。
探索していないときの表示（「冒険へ」でワールドマップを開く案）は未確定であり、今回は実装しない。

歩数は「途中」「達成」「未連携」の3状態を表示する。
値は[仮データ](../../client/Assets/Baryonyx/Features/Home/Data/HomeMockData.asset)から表示し、Inspectorで変えると状態を確認できる。
行き先カードはワイヤー画面（`Main`）へ遷移し、連打しても1回だけ遷移する。
その他の操作は「〇〇（準備中）」の通知だけを表示する。
召喚の画面は未実装で、ボタンの押下は「召喚（準備中）」の通知だけを表示する。
主要な操作のタップ領域は、48dpに相当する約128px（設計座標）以上を確保する。
4:3など1920より狭い画面では、中央の世界を縮めて四隅のボタンと重ねない。

## 変更と判断の記録

- 2026-09-24：ユーザーの指示で、装備ボタンの新着バッジを削除し、召喚のアイコンを魔法陣にした。
- 2026-09-24：ユーザーの指示で、左下に召喚の入口を追加し、歩数の枠の案内を「タップでルーンを取得」に短くした。
- 2026-09-24：枠の見直しとして、白い枠をやめて濃淡の下地にし、左下をアイコンのボタン、右下を行き先カードとワールドマップに変えた。門の上の「つづき」表示を削除した。
- 2026-09-24：ユーザーがホーム画面の野営地案（A2）を採用した。名前を表示せず、左下は「装備」とする。実データを使わないモックとしてHomeシーンに実装し、TOPの遷移先をHomeへ変えた。

- 2026-09-19：探索の選択を文字だけで伝える現行ワイヤーへの指摘を受け、ダンジョン内の空間・現在地・入口を使う表示要件を探索仕様へ接続した。現行ワイヤーへの反映は未実施。

- 2026-09-19：参照会話と実装指示に基づき、専用ワイヤーと操作導線を追加した。ダウンリングを表示せず、敵の濃淡と状態表示へ変更する。戻り先・配置・タップ手順はワイヤーで評価する。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に基づき、操作と表示の確定事項を各正本へ接続した。具体的な画面遷移やタップ順を推測で確定せず、ダウンリングなどの決定済みの表示とは区別する。

- 2026-09-15：ユーザー提示の運動目標設定仕様に合わせ、任意の目標設定、条件の要約、進捗・達成済み・変更予約・過去履歴の表示を目標仕様へ接続した。未設定枠やデータ未確認を警告・未達へ置き換えず、具体的なレイアウトは未決とする。
