# 初回体験とチュートリアル

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

運動しないと遊べないゲームにはしない。
初回体験の具体的な構成は未決である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 短い初回プレイで体験させる流れと中断の区切り | 未決。[15分の連続プレイは要求しない](../game/overview.md#短いプレイの積み重ね) |
| 最初のパーティ・装備・資源の渡し方 | 未決 |
| 運動データがまだない人への初回の資源 | 運動目標の初回設定にあった固定ルーンの配布を残すかは[確認待ち](economy.md#確認待ち) |
| 権限を許可しない人の開始・継続 | Topの連携モーダルで「あとで」を選べば、運動データなしで開始できる（[起動時の同期](startup-sync.md#top画面の流れ)）。その後の継続の扱いは未決 |
| 運動データ利用とGoogle接続を案内する時点 | 運動データの連携はTopの起動時と開始時に、未連携の場合だけ案内する。Google接続を案内する時点は未決 |
| カードバトル・装備・ワットボーナスを教える順序 | 未決 |
| スキップ・再表示・途中再開 | 未決 |
| 次回起動・翌日へつなぐ導線 | 未決 |

## 変更と判断の記録

- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)で運動目標を廃止したため、目標設定のスキップと取得済み実績の反映を削除した。初回にデータがない場合の固定ルーンは目標の初回設定に紐づいていたため、扱いを[ルーン経済の確認待ち](economy.md#確認待ち)に移した。

- 2026-09-24：ユーザーの依頼により、未連携の人へTopで連携モーダルを表示し、「あとで」で運動データなしに開始できるようにした。「運動しないと遊べないゲームにはしない」方針に合わせた。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に合わせ、初回体験を15分の固定枠として扱わない記述へ変更した。具体的な案内の流れは引き続き未決とする。

- 2026-09-15：ユーザー提示の運動目標設定仕様を根拠に、両目標のスキップ、取得済み実績の反映、初回固定ルーンと締め切りの案内を追加した。固定ルーンの量・回数や端数期間の評価を推測で決めない。
