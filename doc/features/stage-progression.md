# 探索とダンジョンの進行

[機能索引](README.md) / [ゲーム概要](../game/overview.md) / [戦闘システム](combat.md)

2026-09-15にユーザーが提示した「てくてくダンジョン｜探索・進行・戦闘仕様」の探索と進行を管理する。
2026-09-19のワイヤー評価を受け、ダンジョン内の部屋・通路を見て行き先を選ぶ方針を具体化した。
[仕様の確度](README.md#仕様の確度)を区別し、[初期企画](../game/brief.md)にあった危険度選択中心の進行は現行ルールへ混ぜない。

## 確定している方針

### 依頼を前提にしない探索

依頼システムは入れず、受注・報告・再受注を冒険の前提にしない。
「欲しい装備がある」「今なら強敵に勝てそう」「まだ見ていない奥へ進みたい」を行き先を選ぶ理由にする。
特定のボスで行き詰まっても、別の場所で育成・装備集めができる自由を残す。
冒険のスタミナ・挑戦回数制限は設けない。

### 行き先を選ぶ情報

「1-1」「1-2」などのステージ番号を前面に出さず、場所の名前と情報から行き先を選ぶ。
番号を隠すだけでなく、選択に目的を持たせる。

| 見せる情報 | 選ぶ理由 |
|---|---|
| 敵の傾向・弱点 | 今の編成で挑むか判断する |
| 狙える装備・報酬の種類 | 必要な装備を探す |
| 未探索・さらに深く進む方向 | 探索を進める |
| 発見済みの強敵 | 以前の相手に再挑戦する |

具体的なドロップ品や未踏の先のすべてを確定表示するわけではない。
情報の開示範囲は未確定とする。

### ダンジョン内の見た目による行き先選択

ダンジョンに入った後の探索画面では、部屋・通路とパーティを描き、今いる場所と次に進める入口を見て分かるようにする。
プレイヤーは、画面内に見えている扉や通路などの入口をタップして行き先を選ぶ。
これはダンジョン内の操作であり、出発前に森・坑道などの冒険先を選ぶ画面とは分ける。

| 表示するもの | 伝えること |
|---|---|
| 現在の部屋・通路と、その中にいるパーティ | 自分たちが今どこにいるか |
| 次の部屋につながる扉・通路などの入口 | どこを選べば、どちらへ進むか |
| 入口やその先の見た目と短いヒント | 敵・お宝・先の様子など、行き先を選ぶ手掛かり |
| 選んだ入口への移動と次の部屋の表示 | 選択した場所へ進んだこと |

行き先の説明文だけを並べた二択を、探索画面の完成形にはしない。
短いテキストは見た目を補う情報として入口の近くに置く。
分岐が2本の場合も、部屋の中の異なる入口として選べるようにする。
入口の数を常に2つに固定する仕様ではない。

「部屋の奥に扉があり、右側には暗い通路がある」は会話で挙がった表示例であり、全室共通の配置や確定した部屋データではない。
視点・カメラ・一画面に見せる範囲は未確定とする。

### 部屋単位の探索と操作

行きたい入口をタップすると、4人パーティが自動でその入口へ歩き、次の部屋へ進む。
自由移動、移動スティック、長い移動待ちは入れない。
移動は短い雰囲気づくりの演出とする。

毎回ヒントを聞きに行く操作は前提にしない。

参考イメージは、ユーザーが挙げた『ポケットモンスター エメラルド』のバトルチューブ風の分岐・部屋単位探索である。
原作の運要素・連戦ルールを丸ごと採用する意味ではない。

### 終点と進捗の持ち越し

ダンジョンには、いつか踏破できる終点を設ける。
完全な無限ダンジョンにはしない。
巨大なダンジョンの進捗を持ち越し、短い冒険を積み重ねる形とする。
毎回1階から潜り直し、限界まで続ける案は採用しない。

初めて入るときは入口から探索する。
部屋の区切りで中断すると進捗を保存し、次回は続きから再開する。
戦闘中にアプリを閉じた場合の保存・再開方法は、この中断とは分けて未確定とする。
帰還後の再出発と周回の開始方法は[候補](#中断再出発周回の候補)で管理する。

### 敗北後の行き先

獲得済みの成果を保護し、無料再戦・編成変更・別の行き先・帰還を選べるようにする。
成果の範囲、再戦とルーン復活の状態は[戦闘終了の仕様](combat.md#敗北と成果の保護)を正本とする。
報酬の抽選・確定・受け取りタイミングは未確定である。

## 設計方針

### 長期目標と段階的な解放

終点はあるが、果てしなく遠く感じる規模を目指す。
近い目標は以前の強敵の撃破や次の区間への進行、中期の目標は新しい場所や装備の発見、長期の目標は踏破とする。

「冒険団の成長によって行き先が段階的に増える」方向は支持済みである。
ランク・最深到達・中継地点発見がそれぞれ何を解放するかは未確定とする。
ダンジョン数、最終深度、分岐構造も未確定である。

### 成長の記録

最深到達の更新、前回遊んだ時点からの進展、以前勝てなかった敵の撃破を見せる。
必要に応じて、前回記録と自己ベストを区別する。
「今回の一潜りで何階まで行けたか」の競争より、「前回より冒険が進んだ」「以前の相手が楽になった」を中心にする。
深度・階層の表記方法と、比較記録の具体的な単位は未確定とする。

### アセットを増やしすぎない構成

エリア共通の分岐背景・戦闘背景に、扉・階段・宝箱などの差分を組み合わせる方向とする。
大きな自由移動マップを前提にしない。

同じ素材でも、敵の編成、報酬、選ぶ理由に違いを作る。
深い地域で背景を変えるなど、新しい場所へ到達した節目を演出する。
必要アセット数や地域数は未確定である。

## 中断・再出発・周回の候補

| 状況 | 現行の候補 | 確定していない部分 |
|---|---|---|
| 帰還後に再出発する | 解放済みの野営地・中継地点から出発する案が有力 | 採否、解放間隔、開始地点の選択方法 |
| 同じ敵・場所を周回する | リザルトから直接再挑戦できる案 | 採否と操作。毎回同じ道の移動や雑魚戦を強制しない方向 |

部屋の区切りからの再開、帰還後の再出発、同じ敵の周回、敗北後の無料再戦は区別する。
候補の操作方法を確定済みとして実装しない。

## 未確定事項

| 領域 | 決める項目 |
|---|---|
| ダンジョン構造 | ダンジョン数、最終深度、部屋・分岐構造、区間の分け方、敵編成とボス出現 |
| 解放 | ランクと探索進捗の関係、中継地点の解放間隔、各解放条件 |
| 情報 | 入口や場所選択での開示範囲、深度・階層の表記、成長を比較する記録単位 |
| 探索画面 | 視点・カメラ・一画面に見せる部屋や通路の範囲、入口の見せ方とタップ範囲。ミニマップ・通過経路の表示・未探索部分を段階的に見せる演出の採否 |
| 中断・再出発 | 戦闘中の保存・再開、帰還後の開始地点、攻略済み経路の移動、周回への直行方法 |
| 報酬 | 抽選・確定・受け取りタイミングと、撤退・敗北・中断時の未確定報酬の扱い |
| 個別コンテンツ | 通常敵・ボスの行動、狙える装備、地域数と必要アセット数 |

## 実装との対応

本ページは企画上の要求・設計方針・未確定事項を記す。
2026-09-19時点の[操作ワイヤー](game-wireframe.md)では、文字のボタンから戦闘・獲得へ進み、実行中の探索位置を保持する。
現在地は場所名と区間、パーティは名前の一覧で表示しており、部屋・通路内の配置や入口まで歩く演出は未実装である。
今回追加した見た目による行き先選択、探索の本進行、永続保存は今後の実装対象である。
現在の実装入口は[機能索引の実装欄](README.md#現在の実装)で確認する。

## 変更と判断の記録

2026-09-19：ユーザーのワイヤー評価を受け、ダンジョン内で現在地と進める入口を見て選ぶ方針を追加した。
従来の入口タップ・短い自動移動を具体化し、文字の二択だけでは場所や進行を捉えにくいという課題を記録した。
画面仕様・アート方針・ワイヤーの評価課題へ反映し、地図上の冒険先選択や自由移動とは区別した。

2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、情報を見て進路を選び、短い冒険の進捗を持ち越す進行へ更新した。
ゲーム概要、用語集、MVP、画面、保存要件、データ定義の記入欄へ反映した。

| 過去の案 | 現在の扱い |
|---|---|
| 危険度を数段階から選ぶことが進行の中心 | 探索先の情報を見て選び、奥へ進む構造へ変更。旧案の敵・報酬・高レア率の倍率を現行仕様の前提にしない |
| 毎回1階から出発し、超早送りで限界まで潜る | 進捗を持ち越して短い冒険を積み重ねる。超早送りを必須前提にせず、早送りの採否・倍率は戦闘UIの未確定事項とする |
| 依頼を受注・報告して進む | 依頼システムを入れない |
