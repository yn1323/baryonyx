# 探索とダンジョンの進行

[機能索引](README.md) / [ゲーム概要](../game/overview.md) / [戦闘システム](combat.md) / 根拠：[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

2026-09-15にユーザーが提示した「てくてくダンジョン｜探索・進行・戦闘仕様」の探索と進行を基に、2026-09-27の企画見直しでSlay the Spireのような分岐ルートの冒険へ変更した。
負けたら1階からやり直す構成になり、進捗を持ち越す旧方針は[変更と判断の記録](stage-progression-history.md)へ移した。
[節の区分](../rules/documentation-policy.md#mdの形式と状態)を区別し、[初期企画](../game/brief.md)にあった危険度選択中心の進行は現行ルールへ混ぜない。

## 確定している方針

### 分岐ルートを選んで進む冒険

1階から深奥のボスを目指す1回の挑戦を**冒険**と呼ぶ。
冒険では、Slay the Spireのような分岐ルートを選んで進む。
リスクを取って強敵などに挑み、スキル・装備・アイテムを獲得する。
アイテム（道具・素材）は、敵のドロップと宝箱から見つかる（[アイテム](items.md#入手)）。
固有スキルは、冒険中の戦闘と宝箱で覚醒する（[固有スキルの覚醒](skill-evolution.md#覚醒が起きる場面)）。
キャラのステータス〇％アップなどを重ね、深奥のボスを倒す。
ダンジョンには深奥のボスという終点があり、完全な無限ダンジョンにはしない。

### 冒険の終了と獲得物の保持

負けたら冒険は終了し、次の冒険は1階からやり直す。
負けても、それまでに獲得した装備・スキルなどは保持する。
固有スキルの覚醒も残る（[取得した段階とセット](skill-evolution.md#取得した段階とセット)）。
失うのは、その先のボスの報酬などを得る機会であり、これを負けるリスクとする。
ルーンを使えば復活して、続きから再開できる（[ルーン復活](combat.md#敗北とルーン復活)）。

### 冒険の中断と再開

2026-10-04、ユーザーは次を決めた。

- 冒険は、探索でも戦闘の途中でも中断してホームへ戻れ、ホームの行き先カードから再開できる。
- 戦闘中にアプリが終わった場合や戦闘の途中で中断した場合は、直前の分岐でマスを選んだ状態から再開する。そのマスの戦闘は始めからやり直す。
- 自分から冒険をやめられる（戦闘の途中でも）。負けたときと同じく冒険は終わり、手に入れた物は残る。

マスを選んだ時点で、その選択をサーバーに保存する（[画面と遷移](screens/adventure.md#冒険の画面)）。
戦闘を始めからやり直せることと、[無料再戦の廃止](combat.md#確認待ち)との関係は、[確認待ち](#確認待ち)に記録する。

### 依頼を前提にしない探索

依頼システムは入れず、受注・報告・再受注を冒険の前提にしない。
「欲しい装備がある」「今なら強敵に勝てそう」「まだ見ていない奥へ進みたい」を行き先を選ぶ理由にする。
特定のボスで行き詰まっても、別の場所で育成・装備集めができる自由を残す。
冒険のスタミナ・挑戦回数制限は設けない。

### 行き先を選ぶ情報

「1-1」「1-2」などのステージ番号を前面に出さず、場所の名前と情報から行き先を選ぶ。
番号を隠すだけでなく、選択に目的を持たせる。

| 見せる情報 | 選ぶ理由 |
|---|---|
| 敵の傾向・弱点 | 今の編成で挑むか判断する |
| 狙える装備・報酬の種類 | 必要な装備を探す |
| 未探索・さらに深く進む方向 | 探索を進める |
| 発見済みの強敵 | 以前の相手に再挑戦する |

具体的なドロップ品や未踏の先のすべてを確定表示するわけではない。
敵の弱点は、戦闘で[開示した](combat.md#弱点の開示)ものだけを見せる。
それ以外の情報の開示範囲は未決とする。

### ダンジョン内の見た目による行き先選択

ダンジョンに入った後の探索画面では、今いる場所と次に進める行き先を見て分かるようにする。
これはダンジョン内の操作であり、出発前に森・坑道などの冒険先を選ぶ画面とは分ける。

2026-10-04、ユーザーは、探索画面を森を斜め上から見下ろす地図にし、分岐ルートを俯瞰しながら進むと決めた（[計画](../plans/2026-10-04-exploration-route-map.md)）。
同日の先の決定（分岐ルートのマップを独立させず部屋の画面だけで進み、ルート全体は冒険のメニューの地図で見る）は改めた。
地図では、マスとマスを森の中の道で結び、パーティが今いるマスと、次に進めるマスを描く。

| 表示するもの | 伝えること |
|---|---|
| 地図の上の今いるマスと、そこに立つパーティ | 自分たちが今どこにいるか |
| 今いるマスから次のマスへ続く道 | どこを選べば、どちらへ進むか |
| マスの種類の色の札とアイコン、画面の端の凡例 | 敵・お宝・出来事など、行き先を選ぶ手掛かり |
| 最奥までのマスの印（遠いほど小さく、遠くは種類の色の点） | どこに宝箱や強い魔物があり、どの道を通りたいか |
| 選んだ道を歩く移動と、着いたマス | 選択した場所へ進んだこと |

行き先の説明文だけを並べた二択を、探索画面の完成形にはしない。
マスの種類は札の色とアイコンで見せ、文字は画面の端の凡例にまとめる。行き先のマスの近くには文字を置かない（2026-10-18、地図がごちゃごちゃして見づらいとのユーザーの評価を受けて改めた）。
次に進めるマスの数を、常に2つに固定する仕様ではない。

先のマスは最奥まで全部、種類が分かる形で見せ、1本指で地図を動かして道の先を見渡せるようにする。どこに宝箱や強い魔物があり、どの道を通るかを考えられるようにするためである。
霧は遠さを表す見た目で、マスを隠さない。カメラに近いマスほど大きく、遠いマスほど小さく見せる（[冒険の画面](screens/adventure.md#冒険の画面)）。
2026-10-06、ユーザーは、地図の見下ろす角度が浅くて見づらいとして、もっと上から見下ろす角度にすると決めた。同日、道が詰まって見えるとして、道を縦に長くすると決めた。入口から最奥の間までは1画面に収まらず、最奥の間は近づくか地図を動かして先を見ると見える（[冒険の画面](screens/adventure.md#冒険の画面)）。
地図のカメラの動きと描き方は[未決](#未決事項)とする。

#### 地図の作り直し（2026-10-21）

ユーザーは、森の木が道とマスにかぶって見づらく、画面がごちゃごちゃしているとして、地図を次の形に作り直すと決めた。
Codexで作った3案（草地の道・すごろく盤・遺跡の床と光の道）の画面イメージから、ユーザーが遺跡の床と光の道の案の道を選んだ。画面イメージは `output/exploration-tiles/v2/`（Git対象外）にある。

- 進む向きを、奥へ向かう形から左から右へ変える。左端が入口、右端の先が最奥の間で、地図を左右に動かして先を見る。
- 木・茂み・岩などの障害物を置かず、地面だけにする。
- マスは丸い魔法陣の台座にし、上に種類のアイコンを載せる。マスどうしを淡い光の線で結び、進める道だけを明るく光らせ、通った道の光は消す。
- 地面は行き先ごとに変える（ユーザー）。森の行き先は苔のある遺跡の石の床で、8つの行き先それぞれに地面を作った（2026-10-22、[ドット絵の規格の例外](../art/direction.md#例外)）。
- 道は網の目にする（[冒険の道の作り方](#冒険の道の作り方)）。2026-10-24からは、マスを5本の決まった列の上に並べ、道は真っすぐか隣の列への斜めだけにする。
- 画面に常に出すUIは、左上のメニュー、右上の行き先の名前と層、右下の凡例を開く「？」、下端の地図の位置を示す細いバーだけにする（仮）。今の画面の上のボタンの帯、下の案内の帯、凡例の常時表示はやめる。

画面イメージでは同じ列のマスを縦に結ぶ線があるが、同じ階の中を移る道は作らず、線はすべて右の階へだけつなぐ。

### マス単位の探索と操作

行きたいマスをタップすると、パーティを表す木の駒が自動でそのマスまで跳ねて移り、マスの出来事（戦闘・宝箱など）が始まる。
宝箱と歩数の扉のマスでは、着くと押さなくても開ける（2026-10-24、ユーザーの依頼）。選ぶことがある怪しい宝箱と覚醒の祭壇は、着くと選択を開く。
2026-10-25、ユーザーは、探索の地図と街道の世界地図で歩くパーティを、4人のドット絵からチェスのポーンのような駒1つに替えると決めた。駒はCodexで作ったなめらかな絵（ドット絵ではない）で、6案からユーザーが木のすごろくの駒に赤いリボンを結んだ案を選んだ（画像は `output/pawn-concepts/`、Git対象外）。駒は編成によらず同じ絵で、戦闘・ホームの野営地・休憩の焚き火・祭壇では、これまでどおり編成の4人を出す。
2026-10-26、ユーザーは、駒が道を滑るように動くのをやめ、生き物のようにピョンと跳ねて次のマスへ移ると決めた。動画で7案を見比べ、ためずにすぐ跳ぶ短い跳躍を選んだ。駒は押すとすぐ少し縦に伸びて跳び、空中で進む向きへ傾き、0.4秒で次のマスに着いて0.2秒つぶれて戻る。跳ぶ高さは設計座標で70、高いほど影が小さく薄くなる。空中は一定の速さで進む。探索の地図では1回跳び、地図は0.6秒で駒に追いつく。街道の世界地図では通るマスごとに1回ずつ跳び、途中のマスで0.1秒置いてから次へ跳ぶ（`MapPawnHop`）。
自由移動、移動スティック、長い移動待ちは入れない。
移動は短い雰囲気づくりの演出とする。

毎回ヒントを聞きに行く操作は前提にしない。

参考イメージは、当初はユーザーが挙げた『ポケットモンスター エメラルド』のバトルチューブ風の分岐・部屋単位探索で、2026-10-04からは、あみだくじのように分岐する道を森の地図で俯瞰する形（[計画](../plans/2026-10-04-exploration-route-map.md#比べた案)の案B）である。2026-10-24、ユーザーは、あみだくじのような道が分かりにくいとして、『カオスゼロナイトメア』を参考に、直線で分かりやすい道にすると決めた（[冒険の道の作り方](#冒険の道の作り方)）。
原作の運要素・連戦ルールを丸ごと採用する意味ではない。

### 冒険の道とマスの数

2026-10-04、ユーザーは次を決めた。

- 冒険の道は、冒険を始めるたびにランダムに作る。
- 入口から最奥の間までに通るマスの数は、ダンジョンごとのサーバーの設定値にし、あとから変えられるようにする。
- 最初のダンジョンは、道中のマスを8つ通った先に最奥の間を置く。深いダンジョンは、道中のマスを10〜12に延ばす。

1階ごとに1マスを通る。
最初のダンジョンでは、入口（第1層）の次の第2層から第9層までが道中のマスで、最奥の間は第10層になる。
画面では、階を入口から数えて「第1層」「第2層」と表す。

1回の冒険の長さは15〜20分を目安とし、最初のダンジョンで約15分、道中12マスの深いダンジョンで約20分と見積もった。
見積もりは[戦闘の長さ](combat.md#戦闘の長さ)の目安を前提とし、前提と計算は[計画の方針](../plans/2026-10-04-exploration-route-map.md#方針)に置いた。
戦闘と移動の時間はまだ実測していない。

### マスの種類

2026-10-21、ユーザーは、魔物・宝箱・主だけでは少ないとして、次のマスを足すと決めた。
数値と出し方は[マスの中身](#マスの中身仮)と[道の決まり](#道の決まり仮)の仮の値で始め、遊んで直す。

| マス（ID） | 中身 | 決めたこと |
|---|---|---|
| 魔物（`battle`） | 戦闘 | 既存 |
| 強い魔物（`elite`） | 強い戦闘 | 既存 |
| 宝箱（`treasure`） | ドロップと、固有スキルの覚醒 | 既存 |
| 最奥の間（`boss`） | 最奥の主との戦闘 | 既存 |
| 休憩（`rest`） | HPを回復する | 必要（ユーザー） |
| 行商人（`merchant`） | スキルと装備を買う | 交換ではなく購入でよい。Homeの商会と違う品ぞろえで、毎回変わる（ユーザー） |
| 怪しい宝箱（`shady-chest`） | ミミックかもしれない宝箱 | 危険に見合う大きな報酬にする（ユーザー） |
| 試練（`trial`） | 条件つきの戦闘 | 危険に見合う大きな報酬にする（ユーザー） |
| 歩数の扉（`step-door`） | 今日の歩数が多いほど報酬が増える | 採用（ユーザー） |
| 覚醒の祭壇（`altar`） | 固有スキルを1段覚醒させる | めったに出ないマスにし、冒険を始めたときに5%の確率で地図に1つ置く（ユーザー） |
| 「？」（`mystery`） | 入るまで中身が分からない。魔物・宝箱・行商人・休憩のどれか | 採用（2026-10-24、ユーザー） |

行商人は、以前に挙げた「商人」を兼ねる。
2026-10-24、ユーザーは「？」を入れ、休憩で休むか鍛えるかを選べるようにすると決めた。
「出来事」（選択肢のある短い話）と「見通しの泉」（先のマスの中身を見せる）は入れていない（[未決事項](#未決事項)）。

### HPの持ち越し

2026-10-21、ユーザーは、HPをマスの間で持ち越すと決めた。
冒険を始めるときは全員のHPが満タンで、戦闘を終えたときのHPのまま次の戦闘に入る。
HPを戻せるのは、休憩のマスと[ルーン復活](combat.md#敗北とルーン復活)である。
倒れた味方は、倒れたまま次の戦闘に入り、そのカードは山札に入らない（仮。[倒れた味方](combat.md#倒れた味方)の決まりを戦闘の外へ延ばした）。
持ち越すのはHPと倒れているかだけで、バフ・デバフ・ブロックは戦闘ごとに消える（仮）。

### 戦闘後の強化

2026-10-24、ユーザーは、ダンジョンの敵がだんだん強くなるのに合わせ、休憩の[鍛える](#休憩の鍛える仮)に加えて、戦闘に勝つたびに仲間を強くできるようにすると決めた。

- 戦闘に勝つと強化の候補を3つ見せ、プレイヤーがそのうち1つを選ぶ。
- 強化はその冒険のあいだだけ効き、冒険が終わると消える。固有スキルとカスタムスキルの覚醒は、これまでどおり冒険が終わっても残る。
- 候補は、「〇〇の物攻アップ」のように1人を上げる強化と、「全員5%アップ」のように全員を低めに上げる強化を中心にする。
- 中身はステータスの上昇だけにする。同じ項目を同じ幅で上げるだけにせず、上がり方に種類を持たせる。
- デメリットがある代わりに大きく上がる強化を、少しだけ混ぜる。
- 選ばずに飛ばすことは、ひとまずできないようにする。
- 強い敵に勝ったときほど、強い強化が出やすくする。

中身と出る割合は、[戦闘後の強化の中身](#戦闘後の強化の中身仮)の仮の値で始め、遊んで直す。

### 街道とダンジョン

2026-10-23、ユーザーは、冒険を2つの遊び方に分ける構想を決めた。
細部はこれから詰める（[未決事項](#未決事項)）。

- **街道**：世界地図に並んだ固定のマスを1つずつクリアして先へ進み、新しい街を解放していく。
- **ダンジョン**：解放した街にあるダンジョンに入り、物を集めて育てる（ハクスラ）。これまでの行き先（[行き先と敵](#行き先と敵)）がダンジョンで、この文書のほかの節の冒険（[分岐ルートを選んで進む冒険](#分岐ルートを選んで進む冒険)など）はダンジョンの遊び方である。

| | 街道 | ダンジョン |
|---|---|---|
| 地図 | 世界地図に、固定のマスを線で結んで並べた網。いつも同じ形 | 冒険ごとにランダムに作る（今のまま） |
| 役割 | 世界を広げる・新しい敵の初登場・物語 | 物を集めて育てる・周回 |
| 進み方 | マスを1つずつクリアして、先のマスを開く。クリアしたマスは残り、開いた所は自由に行き来できる | 分岐を選んで一方通行で進み、引き返せない |
| 負けたとき | そのマスに挑み直す。クリアしたマスは戻らない | 冒険が終わり、次は1階から |
| 数 | ダンジョンよりずっと少ない | 多い |
| クリアしたあと | 街のマスに着くと、その街にあるダンジョンが解放される | [クリア回数の報酬](#ダンジョンのクリア回数の報酬)をもらう |

街道は、次のように進む。

- 世界地図は、マスと線だけでできた網である。方角を4つに決めず、最初の街から道が分かれながら自由に広がる。
- マスには、戦闘・ボス・街などがある。ダンジョンの入口のマスは置かない。ダンジョンは、特定の街に着いたときに解放される。
- ボスのマスは、先へ進むのを止める関所にする。倒すと、その先のマスへの道が開く。
- クリアしたマスの上は自由に通れる。クリアしたマスで戦い直して報酬を得る仕組みは持たせない。
- 最初の街から遠いほど敵を強くし、「この先は推奨Lv○○」のように、今の強さでどこへ向かうかを選ばせる。どこへ行っても同じ強さにすると、行き先を選ぶ意味が薄れるためである。値は未決とする。
- マスの台座と線は、ダンジョンの探索の地図（[地図の作り直し](#地図の作り直し2026-10-21)の魔法陣の台座と光の線）を使い回す方向とする。地面や建物を置くかは後で決める（ユーザー）。

同じ日の初めの案では、街を中心に四方へ道が伸び、道の中は一方通行で、負けたらその道の最初からやり直すとしていた。
ユーザーの「固定のマスが自由に並んでる感じでもいいかも」を受け、世界地図そのものを固定のマスの網にする形（クリアしたマスが残る）に改めた。
ダンジョンとは、地図の作り方・進み方・負けたときの扱いが正反対になる。

#### 街道のマスと移動（2026-10-24）

2026-10-24、ユーザーは次を決めた。

- マスは、戦闘・関所のボス・街に、1回だけ開ける宝箱と物語のマスを少し足す。
- 何もないマスを多く置く。全部のマスに意味があると疲れるためであり、あとで中身を足す余地にもする（ユーザー）。
- HPはマスの間で持ち越さず、1マスで完結させる。
- 街道の戦闘は手で組んだ決まった敵にする。新しい敵はまず街道で出し、そのあとダンジョンにも出す。
- 先へ進む条件は、関所のボスと推奨Lvの2つだけにする。前の街のダンジョンのクリアなどは条件にしない。

#### 街道のマスの戦闘（2026-10-24）

ユーザーの「マスに沿ったイベントが起きるようにしてください。戦闘とかですかね」を受け、戦闘と関所のボスのマスで戦闘が起きるようにした。

- 挑めるマスに着くと、そのマスの戦闘を開く。クリアしたマスの上を通るだけでは戦わない。
- 戦闘は全員のHPが満タンで始める（[街道のマスと移動](#街道のマスと移動2026-10-24)）。冒険の強化（休憩・戦闘後の強化）は効かない。
- 勝つとマスをクリアし、そのマスに立った世界地図へ戻る。関所のボスを倒すと、先のマスが見えるようになる。
- 全滅すると、「もう一度挑む」（同じマスの戦闘を始めから）か「地図へ戻る」を選ぶ。マスはクリアにならず、パーティは元のマスに戻る。ルーン復活はない。
- 戦闘のメニューからも地図へ戻れる。戦闘の途中でアプリが終わったときも、マスはクリアにならない。
- 勝っても報酬は出さない。弱点の開示は、ダンジョンの戦闘と同じく記録する。

マスごとの敵・Lv・戦闘の背景は、こちらで決めた仮の値で、[WorldMapEncounters](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapEncounters.cs) が持つ。
敵は、近くの街のダンジョンの魔物（[行き先と敵](#行き先と敵)）から選び、戦闘は小さな敵と中くらいの敵の2体、関所のボスはその奥にダンジョンの最奥の主を置く。
Lvは、ポルタのまわりの10から、区間の推奨Lvまで上げる。強さの倍率は、戦闘がダンジョンの魔物、関所のボスがダンジョンの最奥の主と同じにした。自動対戦での試しはしていない。
物語のマスは、中身を決めていないため、着くとそのままクリアにする（[未決事項](#未決事項)）。
宝箱のマスは、着くと中身を見せてクリアにする（[街道の宝箱と街](#街道の宝箱と街2026-10-25)）。
クリアしたマスは、街を除いて何もないマスの台に変え、着いても出来事が起きないことを見た目で分かるようにする（2026-10-25、戦闘や宝箱の絵のまま何も起きないマスがあったため）。

### ダンジョンのクリア回数の報酬

2026-10-23、ユーザーは、ダンジョンのクリア報酬を次の形にすると決めた。
最奥の主を倒して冒険を終えることを、ダンジョンの**クリア**と呼ぶ。

- 初回クリアでは、周回のドロップより良い報酬をもらう。報酬は、そのダンジョンで落ちる物でなくてもよい。
- 2回目から5回目まで、クリアのたびに報酬をもらう。5回目は、キャラや品質の高いスキルなど、特にうれしい報酬にする。
- 各回の報酬は抽選にせず、ダンジョンごとに決まった物にする。中身は、ダンジョンを作るときにユーザーと決める。
- 5回目の報酬のキャラは、ダンジョンでしか手に入らないキャラにする予定である。もし持っているキャラと被ったら、召喚と同じ[被ったときの決まり](monetization.md#キャラが被ったとき)で扱う。
- 何回クリアしたか（進み具合）は、旅の案内所のお宝の窓に一緒に出す（[旅の案内所のお宝](screens/guide.md#編成商会神殿旅の案内所の画面)）。2026-10-25に、回数（サーバーの `adventure_records.clears`）を窓の見出しに出した。報酬はまだない。
- 6回目以降のクリアでは、通常のドロップだけをもらう。

## 設計方針

### 冒険の道の作り方

2026-10-04に、次の形で実装した（[計画](../plans/2026-10-04-exploration-route-map.md#実装したこと)）。
階ごとの決まりと見える距離は、遊んで確かめるための仮の値である。

- 冒険を始めると、サーバーが道を作る乱数の種を決め、冒険と一緒に保存する。端末は、種とマスの数から毎回同じ道を作り、道そのものはどこにも保存しない。中断して再開しても、別の端末でも、同じ道になる。
- 道の進み具合（今いるマス・通ったマス・出来事を終えたか）は、これまでどおりサーバーに保存する。マスを選ぶと、端末はそのマスの階と種類をサーバーへ送り、サーバーは1階ずつ進むことと、最奥の階にだけボスがいることを確かめる。
- 2026-10-04の実装では、道はあみだくじの形で、平行な3〜4本の道が蛇行しながら奥へ進み、隣の道の次の階へ移る横道でつながる。横道は交差させず、マスの札が重ならないよう道同士の間隔に下限を設ける。
- 2026-10-21、ユーザーは、平行な3本の道では単純すぎるとして、スクロールが必要なくらい複雑にすると決めた。入口から2〜3本に分かれ、枝分かれと合流をくり返して、多い階では5〜6本の道筋が並ぶ網の目にする（仮）。階ごとのマスの数は2〜6で変わり、行き止まりは作らない。道は交差させない。画面に入るのは5〜6階ぶんで、地図を左右に動かして先を見る（[地図のレイアウト](#ダンジョン内の見た目による行き先選択)は案を比べている途中）。
- 2026-10-24、ユーザーは、あみだくじのような道が分かりにくいとして、直線で分かりやすくすると決めた。マスは地図を左から右へ走る5本の列の上に立ち、同じ階のマスは縦に揃える。入口と最奥の間は真ん中の列に置く。入口の次の階は真ん中の両隣の2列か、真ん中と両隣の3列である。そこから先の道は、同じ列を真っすぐ進むか、隣の列へ斜めに移るか、両隣の列へ2つに分かれ、同じ列に着いた道は合流する。列を飛ばす道と交差する道は作らない。階ごとのマスの数は2〜4にした（仮。真っすぐ・斜め・分かれるの重みは5:3.2:1.8）。
- 階ごとのマスの種類は[道の決まり](#道の決まり仮)に従う。2026-10-04の実装では、マスの種類は魔物・強い魔物・宝箱・最奥の間の4つだった。

道のマスの種類は端末が作るため、端末を書き換えれば、選ぶマスの種類（ドロップの数・☆・品質の重み）を変えられてしまう。
ユーザーが「途中の進捗はUnity内に保存する形でOK」としたため、サーバーで道を作り直して確かめる処理は入れていない（[確認待ち](#確認待ち)）。

### 道の決まり（仮）

2026-10-21、ユーザーの「マスの種類と道の決まりを…ルール化よろ」を受けて決めた仮の値である。
道は冒険の種から端末が作るため、決まりはclientの [AdventureRouteMap](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureRouteMap.cs) が持ち、サーバーは受け取ったマスの種類が[置ける階](#置ける階)にあることを確かめる。
階は、道中の最初の階（第2層）を1つ目、最奥の直前の階を最後と数える。
道中の階の数を`N`とすると、最初のダンジョン（N=8）では、1つ目が第2層、真ん中（`N/2`つ目の次、5つ目）が第6層、最後が第9層である。

#### 決まった階

| 階 | その階のマスはすべて | 理由 |
|---|---|---|
| 1つ目（第2層） | 魔物 | 最初の戦闘で手札と流れを見せる |
| 真ん中（第6層） | 宝箱 | 道中の折り返しで必ず報酬を得る（Slay the Spireも幕の中ほどに宝箱を置く） |
| 最後（第9層） | 休憩 | HPを持ち越すため、主の前で立て直せるようにする（Slay the Spireも主の前に休憩を置く） |

#### 置ける階

決まった階以外の階では、次の重みでマスを選ぶ。
置けない階では、そのマスの重みを0にする。

| マス | 重み | 置ける階 |
|---|---|---|
| 魔物 | 45 | 2つ目から |
| 強い魔物 | 15 | 3つ目から |
| 宝箱 | 8 | 2つ目から |
| 怪しい宝箱 | 8 | 3つ目から |
| 試練 | 7 | 4つ目から |
| 休憩 | 6 | 4つ目から |
| 行商人 | 6 | 3つ目から |
| 歩数の扉 | 5 | 3つ目から |
| 「？」 | 10 | 3つ目から |

#### 道全体の決まり

- 道でつながった2つのマスに、魔物以外の同じ種類を続けない。強い魔物と試練も続けない（どちらも重い戦闘のため）。
- 真ん中の宝箱の階と最後の休憩の階の隣の階には、宝箱と休憩を置かない。
- 強い魔物を地図全体で2つ以上置く（道中が6マス以上のとき。既存の決まり）。
- 行商人と歩数の扉は、それぞれ地図全体で1〜2つにする。足りなければ、3つ目以降の魔物を置き換え、多ければ魔物に戻す。
- 強い魔物・行商人・歩数の扉が足りず、並びの決まりを守って置き換えられる魔物のマスがないときは、宝箱・怪しい宝箱・休憩・試練・「？」のマスを置き換える（2026-10-24、階ごとのマスを2〜4に減らして、魔物のマスだけでは足りない地図が出たため）。
- 覚醒の祭壇は、冒険を始めたとき（道を作るとき）に5%の確率で、地図に1つだけ置く。置くときは、決まった階以外の道中のマスを1つ選んで置き換える。強い魔物・行商人・歩数の扉が足りなくなる置き換えはしない（2026-10-22、ユーザーの「ダンジョンに入ったときに５%の確率で１つ生成にして」による。マス1つごとに5%とした前日の読み方では、約7割の冒険で地図に出ていた）。
- 横道の決まり（交差させない、間隔の下限）は[冒険の道の作り方](#冒険の道の作り方)のとおりとする。

### マスの中身（仮）

報酬の重みは[冒険のドロップ](drops.md#仮設定)の表の行を借りる。
「強い報酬」は強い魔物・宝箱の行、「最大の報酬」は最奥の間の行を指す（主の物は最奥の間でだけ落ちるため、最大の報酬にも入れない）。

| マス | 入ったときに起きること | 報酬 |
|---|---|---|
| 休憩 | 「休む」「鍛える」「研鑽」から選ぶ。選ぶまで先へ進めない。休むと、全員のHPを最大HPの40%回復し、倒れた味方は最大HPの40%で起き上がる。鍛えると研鑽は下の[休憩の鍛える](#休憩の鍛える仮) | なし |
| 「？」 | 入ったときにサーバーが中身を魔物45%・宝箱25%・行商人15%・休憩15%から選び、そのマスとして起きる。着くと中身の種類を知らせる | 中身の種類のとおり |
| 行商人 | 品物の一覧を開く。何個でも買え、買わずに出てもよい | 買った物 |
| 怪しい宝箱 | 開けるか、開けずに通り過ぎるかを選ぶ。開けると半分の確率で宝箱ミミックとの戦闘になる | ミミックなら勝つと最大の報酬。本物なら強い報酬で、落ちる数を1つ増やす。通り過ぎると何もない |
| 試練 | 条件を1つ見せてから戦う。敵は強い魔物と同じ強さ | 条件を満たして勝つと最大の報酬。満たさずに勝つと魔物の報酬 |
| 歩数の扉 | 今日の歩数で、扉の向こうの報酬が決まる | 下の表 |
| 覚醒の祭壇 | パーティの固有スキル8枚から1枚を選び、1段覚醒させる（[宝箱の覚醒](skill-evolution.md#覚醒が起きる場面)と同じ手順） | 覚醒。進められる固有スキルがなければ、宝箱と同じドロップ |

- 怪しい宝箱がミミックかどうかと、試練の条件は、冒険の種とマスから決め、同じ冒険なら中断して再開しても変わらない。
- ミミックは、敵の[宝箱ミミック](../catalog/enemies/enemy-chest-mimic.md)に、行き先の小さな敵1体を加え、強い魔物と同じ強さにする。
- 試練の条件の候補は、「6ターン以内に勝つ」「誰も倒れずに勝つ」「HPを全員半分以上残して勝つ」の3つとする。
- 行商人の品ぞろえは、その行き先の[ドロップの一覧](drops.md#行き先ごとの一覧)から、スキル3つと装備（武器・防具・アクセサリー）2つを、冒険の種とマスから選ぶ。☆と品質は強い報酬の重みで選ぶ。Homeの[商会](screens/shop.md#商会)の品物とは別の一覧で、冒険ごとに変わる。値段はルーンで払い、額は未決とする（[ルーンの用途](economy.md#ルーンの用途)）。

#### 休憩の鍛える（仮）

2026-10-24、ユーザーは、休憩で回復の代わりに選べるものを「鍛える」にし、仲間とカードの両方を鍛えられるようにすると決めた（Slay the Spireの休憩所の「鍛える」を参考にした）。
鍛えた効果はその冒険のあいだだけ続き、冒険が終わると消える。育成の手応えを、冒険の外の成長と分けるためである。

同じ日にユーザーは、仲間の成長とカードの強化が1つの「鍛える」に混ざっているとして、休憩の選択肢を「休む」「鍛える」（仲間）「研鑽」（カード）の3つに分けると決めた。

| 選ぶもの | 効果 | 決まり |
|---|---|---|
| 休む | 全員のHPを最大HPの40%回復し、倒れた味方も起き上がる | これまでの休憩と同じ |
| 鍛える | 仲間1人の物攻・属攻を15%上げる | 休憩のたびに重ねられる（2回で30%） |
| 研鑽 | 仲間1人のカードスキル1枚の威力（ダメージ・回復・ブロックの割合）を30%上げ、名前に「+」を付ける | 1枚につき1回まで。コストと回数は変えない。固有スキルは戦闘中に覚醒して別の段階に変わるため、研鑽できない |

数値は仮の値で、遊んで直す。
同じカードスキルを同じ仲間が2枚持つときは、どちらも研鑽したカードになる。
選ぶ画面は文字だけのダイアログにせず、絵で選ぶ（ユーザー）。見た目と操作は[冒険の画面](screens/adventure.md#冒険の画面)の焚き火に書く。画面の案は `output/rest-ui-concepts/`（Git対象外）にある。

#### 戦闘後の強化の中身（仮）

[戦闘後の強化](#戦闘後の強化)の中身と割合として、こちらで決めた仮の値である。
自動対戦での試しはしていない。

魔物・強い魔物・試練・怪しい宝箱のミミックの戦闘に勝ち、ドロップの札を見せ終えたあとに、候補を3つ開く。
「？」の中身が魔物だったときも、魔物として出す。
最奥の間では出さない（勝つと冒険が終わるため）。
焚き火と同じく、選ぶまで先へ進めない。
候補を開く前に勝った戦闘を終えたと保存するため、選ぶ前にアプリが終わったときは、再開した探索で同じ候補を開き直す。

画面は、Codexで作った4案からユーザーが選んだ「3枚のカード」の形にする（2026-10-24）。
戦闘のカードと同じ形の札を3枚並べ、枠の色で段階を、挿絵の窓に対象の仲間（全員なら4人）を、名前の帯に仲間の名前と強化の名前を、説明の欄に上がる・下がる項目と幅を出す。
押したカードを持ち上げて光らせ、「選ぶ」で決める。見た目と操作は[冒険の画面](screens/adventure.md#冒険の画面)の戦闘後の強化に書く。
倒れている仲間も候補の対象に入れる。倒れている間は効かず、起き上がると効く。

ステータスのうち、会心と幸運は候補に入れない。会心と幸運は2026-10-25に戦闘の計算に使うようにした（[会心の一撃](combat.md#会心の一撃)、[状態異常のかかりやすさ](combat.md#状態異常のかかりやすさ)）が、強化の候補に入れるかは決めていない。
速度は、立っている味方の平均でターン順を決めるため（[ターン順の仮設定](combat.md#ターン順の仮設定)）、1人の速度だけを上げても効き目が4分の1になる。そのため速度は、全員を上げる強化と組み合わせの強化で扱う。

##### 段階

強化には3つの段階があり、カードの枠の色で白っぽい・金色・虹色に分ける（文書では白・金・虹と呼ぶ）。
画面には段階の名前を出さず、どれが良い強化かは枠の色と光り方だけで伝える（2026-10-24、ユーザー）。
1人を上げる強化は、全員を上げる強化の約2.5倍の幅にする。4人で割ると全員の強化より小さいが、1人に集めて主力を作る選び方を残すためである。
休憩の鍛える（1人の物攻・属攻+15%）は回復をあきらめて選ぶため、白の強化はそれより少し小さくした。

| 段階 | 1人の1つの項目 | 全員の1つの項目 | 1人の2つの項目（組み合わせ） |
|---|---|---|---|
| 白 | +12% | +5% | それぞれ+7% |
| 金 | +20% | +8% | それぞれ+12% |
| 虹 | +30% | +12% | それぞれ+18% |

##### 強化の系統

上がり方ごとに、次の7つの系統に分ける。
重みは、3つの候補のそれぞれで系統を選ぶときの重みで、その段階に出ない系統は0にする。

| 系統 | 中身 | 出る段階 | 重み |
|---|---|---|---|
| まっすぐ | 1人の1つの項目を上げる。項目は攻撃・最大HP・物防・属防 | 白・金・虹 | 30 |
| 全員 | 全員の1つの項目を上げる。項目は攻撃（物攻と属攻の両方）・最大HP・守り（物防と属防の両方）・速度 | 白・金・虹 | 25 |
| 組み合わせ | 1人の2つの項目を上げる。「勇猛」は攻撃と最大HP、「堅守」は物防と属防、「身軽」は攻撃と速度 | 白・金・虹 | 20 |
| 状況で上がる | 条件を満たす間だけ上がる（下の表） | 金・虹 | 10 |
| 育つ | 選んだあと、戦闘に勝つたびに少しずつ上がる（下の表） | 金・虹 | 8 |
| 代償つき | 1つの項目が大きく上がり、別の項目が下がる（下の表） | 金・虹 | 5 |
| 修行 | 選んでから2回の戦闘は下がり、そのあとは大きく上がる（下の表） | 金・虹 | 2 |

1人を上げる強化の「攻撃」は、その仲間に合うほうを出す。
デッキに入るその仲間のカードのうち、物攻を使う威力が多ければ物攻、属攻を使う威力が多ければ属攻にし、同じ数なら物攻にする。ステータスで決めないのは、選んだ強化で上がったステータスで候補が変わらないようにするためである。
使わないほうの攻撃を上げる候補は、選ぶ意味がないためである。

状況で上がる・育つ・代償つき・修行の強化は、次の表のとおりとする。
代償つきと修行は、下がる分を補うため、同じ段階のほかの強化の約1.5倍の幅にした。
修行は、はじめの数戦は弱くなり、そのあとずっと強くなる形で、Hades IIのカオスの恩恵（はじめの数回の戦闘はデメリットが続き、そのあとはメリットになる）を参考にした。

| 系統 | 名前（仮） | 対象 | 金 | 虹 |
|---|---|---|---|---|
| 状況で上がる | 背水 | 1人 | HPが最大HPの半分以下の間、物攻・属攻+30% | +50% |
| 状況で上がる | 先手 | 全員 | 戦闘の最初の2ターンの間、速度+25% | +40% |
| 状況で上がる | 強敵狩り | 1人 | 強い魔物・試練・ミミック・最奥の間の戦闘で、物攻・属攻+25% | +40% |
| 状況で上がる | 弔い | 全員 | 倒れている仲間1人につき、物攻・属攻+10% | +15% |
| 育つ | 場数 | 1人 | 選んだあと戦闘に勝つたびに攻撃+4%（最大+20%） | +6%（最大+30%） |
| 代償つき | 捨て身 | 1人 | 攻撃+30%、物防・属防-20% | 攻撃+45%、物防・属防-25% |
| 代償つき | ガラスの刃 | 1人 | 攻撃+40%、最大HP-25% | 攻撃+60%、最大HP-30% |
| 代償つき | 重装 | 1人 | 物防・属防+30%、速度-20% | 物防・属防+45%、速度-25% |
| 代償つき | 早駆け | 全員 | 速度+12%、最大HP-8% | 速度+18%、最大HP-10% |
| 修行 | 修行 | 1人 | 選んでから2回の戦闘は物防・属防-20%、そのあと攻撃+30% | 攻撃+45% |

名前は仮で、画面に出す名前は画面を作るときに決める。
強敵狩りは戦闘を始める時点で効くかが決まるため、ほかの強化と同じく戦闘の前に掛ける。
背水・先手・弔いは戦闘の途中で効いたり外れたりするため、戦闘の前には掛けず、戦闘の中で条件を見て掛ける。
効いている間の上がり幅は、戦闘の前に掛けた同じ項目の%に足して、強化の前のステータスから1回掛ける（[重ね方](#重ね方)と同じ）。
条件を満たして効き始めたとき（弔いは倒れた仲間が増えて上がり幅が増えたときも）、その仲間の上に強化の名前を出す。パッシブスキルが働いたときと同じ出し方である（[働いたことを見せる](passives.md#働いたことを見せる)）。

##### 候補の並べ方

- 3つの候補は、別々の仲間を指すようにする。全員の強化は、どの仲間も指さないとみなす。仲間が3人に満たないときは、同じ仲間を2回まで指してよい。
- 同じ系統・同じ項目の候補を、3つの中に重ねない。
- 代償つきと修行の候補は、3つの中に合わせて1つまでにする。
- 3つの候補の段階は、それぞれ下の割合で別々に選ぶ。

##### 敵の強さで変える割合

| 勝った戦闘 | 白 | 金 | 虹 | 決まり |
|---|---|---|---|---|
| 魔物（真ん中の宝箱の階より前） | 70% | 25% | 5% | |
| 魔物（真ん中の宝箱の階より後） | 60% | 32% | 8% | 道中の敵が階ごとに強くなるのに合わせる |
| 強い魔物・ミミック | 20% | 55% | 25% | 3つのうち1つは金以上にする |
| 試練（条件を満たして勝つ） | 0% | 50% | 50% | 3つのうち1つは虹にする |
| 試練（条件を満たさずに勝つ） | 魔物と同じ | | | |

候補に虹が1つも出なかったときは、その冒険の次の候補の虹の割合を3%ずつ足していき、虹が出たら元に戻す（白の割合から引く）。
これはSlay the Spireのカードの報酬で、レアが出ないほどレアが出やすくなる仕組みと同じ考え方である（[Card Rewards](https://slay-the-spire.fandom.com/wiki/Card_Rewards)、2026-10-24確認）。

##### 重ね方

同じ項目の上昇と低下は足し算でまとめ、休憩の鍛えると合わせて、戦闘の前に1回だけ掛ける。
たとえば物攻+12%・+20%を取って鍛えたら、物攻は1.47倍になる。
どの項目も、元の値の50%より下げない。
最大HPを上げ下げしたときも、持ち越すHPは最大HPに対する割合のままとする（[HPの持ち越し](#hpの持ち越し)）。そのため最大HPを上げると、今のHPも同じ割合で増える。

##### 強さの見込み

最初のダンジョン（道中8マス）では、最奥の間の前に勝つ戦闘は4〜5回で、強い魔物は2回以上ある。
この割合で選ぶと、最奥の間の前にパーティの平均で30〜35%ほど強くなる見込みである。
道中の敵は最初の階の0.85倍から最奥の直前の階の1.15倍まで強くなるため、おおむね釣り合う。
最奥の主の倍率は強化なしの戦闘で決めたため（[育てる前提の強化](#育てる前提の強化2026-10-24)）、強化を入れたあとは自動対戦で決め直す。

#### 歩数の扉の報酬

今日の歩数は、サーバーが持つその日の歩数（[起動時の連携と歩数の同期](startup-sync.md)）を使い、扉のマスを終えたときにサーバーが判定する。
段の歩数は、廃止した[ACTボーナス](../archive/step-bonus.md)の段階の候補に合わせて決めた。
歩いていなくても扉は開き、少ない報酬を得る（[運動しないと遊べないゲームにはしない](../game/overview.md#確定している方針)）。

| 今日の歩数 | 報酬 |
|---|---|
| 3,000歩未満 | 魔物の報酬 |
| 3,000〜4,999歩 | 強い報酬 |
| 5,000〜7,999歩 | 強い報酬で、落ちる数を1つ増やす |
| 8,000歩以上 | 最大の報酬 |

### 冒険中の状態の保存先

2026-10-21、ユーザーの「保存先はClientでいいかな」を受け、[保存先の決め方](../rules/data-storage.md#判断の基準)に当てはめて次のように分けた。

| データ | 置き場所 | 理由 |
|---|---|---|
| 冒険中のHPと倒れているか | 端末（冒険ごと） | 冒険が終われば要らない。ユーザーは途中の進捗を端末に置くことを認めている。アプリのデータを消すか別の端末で再開すると、満タンに戻る |
| 休憩で鍛えた仲間と研鑽したカード | 端末（冒険ごと） | HPと同じ理由で、HPと一緒に置く（2026-10-24）。アプリのデータを消すか別の端末で再開すると、鍛えていない状態に戻る |
| 戦闘後の強化で選んだもの、まだ選んでいない候補のマス、虹の割合に足した分 | 端末（冒険ごと） | 鍛えると同じ理由で、HPと一緒に置く（2026-10-24、未実装）。3つの候補は、冒険の乱数の種とマスから端末が決めるため、中断して再開しても同じ候補になる |
| 「？」のマスの中身の種類 | サーバー（冒険ごと） | 端末が決めると選び直せてしまうため、入ったときにサーバーが決め、そのマスの種類として保存する（2026-10-24） |
| 怪しい宝箱の結果・試練の条件・行商人の品ぞろえ・歩数の扉で読んだ歩数 | サーバー（冒険ごと） | 2026-10-22の実装で、端末が作るとミミックかどうかや品ぞろえを選び直せてしまうため、そのマスに入った・開けたときにサーバーが決めて保存した。次のマスへ進むと消す |
| 行商人で買った物と、払ったルーン | サーバー | 持ち物とルーンはサーバーに置く決まり（[置き場所の一覧](../rules/data-storage.md#サーバーに置くもの)）。行商人の一覧に買った印を付けるのも、サーバーの記録から作る |
| 今いるマス・通ったマス・各マスで落ちた物・歩数の扉の判定 | サーバー | これまでどおり。歩数はサーバーにしかない |

### 行き先と敵

2026-10-20、ユーザーの依頼で、行ける行き先を8つに増やし、行き先ごとに出る敵を増やした（仮）。
行き先は近い順に並べ、奥ほど敵のLvが高く、道中のマスが多い。
マスで落ちる物は行き先ごとの一覧から選び、奥の行き先ほど強い物が落ちる（[冒険のドロップ](drops.md)）。
どの行き先も、旅の案内所からすぐ出発できる。
敵は、[敵の定義](../catalog/enemies/README.md)の生息地に合わせて割り振り、53体すべてがどこかの行き先に出る。

| 行き先（ID） | 戦闘の背景 | 敵のLv | 道中のマス | 小さな敵 | 中くらいの敵 | 最奥の主 |
|---|---|---|---|---|---|---|

#### 戦闘の試し

強い魔物と最奥の間の強さは、勝ったときに「危なかったが勝てた」と感じる強さを狙って決めた（2026-10-20、仮）。
2026-10-22に、ターン順を速度から決め、敵が技と行動パターンで動くようにしたため、[決め直した](#2026-10-22の試し直し)。
次の4段落と表は、2026-10-20の試しの記録である。
決め方は2段階である。

初めに、戦闘の決まり（Lvの成長率・防御・弱点の1.5倍・エネルギー・手札）だけを数値で何度も回す試算で、行き先ごとの差を見た。
試算では、どの行き先も魔物のマスは約3ターンで終わり、強さの差は最奥の主の攻撃の強さで決まった。
攻撃の強い主（岩肌トロル・骨背の大ワニなど）が、もっとも手ごわい。

次に、実際の戦闘画面で、戦闘画面のモックの4人（Lv10〜12）と山札16枚に、カードを自動で使わせて戦わせた。
自動で使うカードは、HPの減った味方がいれば回復・防御、いなければコストの高い攻撃から選ぶ。
ブロック・受けるダメージの軽減・回復・状態異常が効くため、実際の戦闘は試算よりかなり楽だった。
初めの仮設定（強い魔物はLv+4・HP1.3倍、最奥の主はLv+2・HP1.0倍）では、最奥の主にもHPを9割以上残して勝ち、緊張のない戦いになった。
HPだけを2.6倍にしても、ターンが延びるだけで、残るHPはほとんど減らなかった。
敵の攻撃が、ブロックと回復で受け止められていたためである。
そこで、強い魔物と最奥の主は、HPに加えて攻撃も強くした。

森の行き先と同じLvで、各行き先の最奥の主とも戦わせた結果は次のとおりである（Lvを同じにすれば、ステータスはすべて同じ割合で伸びるため、行き先どうしの強さを比べられる）。

| マス | 設定 | 勝つまでのターン | 勝った後に残るHP | [戦闘の長さ](combat.md#戦闘の長さ)の目安 |
|---|---|---|---|---|
| 魔物の気配 | 行き先のLv | 3〜4 | 82〜91% | 3〜4ターン |
| 強い魔物の気配 | Lv+8、HP3.2倍、攻撃2.2倍 | 5〜9 | 72〜82% | 8〜10ターン |
| 最奥の間 | Lv+2、HP2倍、攻撃2.6倍 | 6〜14 | 24〜80% | 12〜15ターン |

最奥の間は、7体の主すべてに勝った。
骨背の大ワニ（残りHP24%）・砂鮫（28%）・黒曜石の巨像（30%、14ターン）が手ごわく、霜の大猿人と死霊の魔導師は残りHPが6割を超える。
強い魔物のマスは、目安より短いが、HPが2〜3割減り、☆の多い物と高い品質も落ちやすい（[冒険のドロップ](drops.md#仮設定)）。
自動で使うカードは人より下手な場面も上手な場面もあるため、実機で遊んで、ターン数と残りHPの感じを確かめ直す。
敵の行動はまだ攻撃1つだけで、[ボスの歯ごたえ](combat.md#ボスの歯ごたえ)にある溜めと大技は未実装である。
この試しの戦闘は、モックの固定の順番で動いていたため、主のいない戦闘では、敵は味方の3ターンに1回しか動いていなかった。

##### 2026-10-22の試し直し

[ターン順](combat.md#ターン順の仮設定)を速度から決めると、敵は味方のターンごとに動く。
[敵の行動](combat-enemy-behavior.md)も、敵の定義の技と行動パターン（溜めと大技、全体攻撃、守り、回復など）になった。
そこで、同じ方法で倍率を決め直した（[記録](../plans/2026-10-22-enemy-skills-turn-order.md#戦闘の試し)）。

- 戦闘画面に、編成の仮データの4人（Lv10〜12、パッシブあり）と山札を入れ、カードを自動で使わせた。演出は出さないため、固有スキルの覚醒は起きない。
- 自動で使うカードは、HPが半分を切った味方がいれば回復・防御、いなければコストの高い攻撃、そのあとほかのカードとし、敵単体の攻撃はHPの最も少ない敵へ使う。
- 行き先どうしを比べるため、どの行き先の敵も森と同じLvで戦わせ、8つの行き先の魔物・強い魔物・最奥の間を、敵の組み合わせを変えて2回ずつ戦わせた。

古い倍率のまま新しいターン順と技で戦わせると、魔物と強い魔物はまだ楽で、最奥の間は負けが多くなった。
魔物は2〜3ターンでHPが92〜100%残り、強い魔物はHPが平均81%残った。
最奥の間は、試した5戦のうち2戦で負け、勝った3戦も残りHPが3〜29%だった。
倍率を変えて試し、次の値にした。

| マス | 設定 | 勝つまでのターン | 勝った後に残るHP |
|---|---|---|---|
| 魔物の気配 | 行き先のLv、HP1.3倍、攻撃1.8倍 | 2〜4 | 76〜100%（平均約90%） |
| 強い魔物の気配 | Lv+8、HP3.2倍、攻撃3.0倍 | 5〜14 | 2〜100%（平均約61%）。倒れる味方が0〜3人 |
| 最奥の間 | Lv+2、HP1.8倍、攻撃2.0倍 | 9〜25 | 16戦のうち15戦に勝ち、残りHPは13〜76%（平均約50%） |

最奥の主では、骨背の大ワニ（しじまの沼）が最も手ごわく、2戦のうち1戦で負け、勝った戦いも残りHPが13%だった。
強い魔物は、敵の組み合わせで差が大きい。
自動で使うカードは回復を早めに使うため、残りHPより多くを受けている。受けたHPを数えた試し（しじまの沼の2回目より後）では、強い魔物でパーティの最大HPの2〜12割、最奥の間で8〜15割を受けていた。

同じ試しでは、長い戦闘ほど、味方のブロックがパーティの最大HPの6割から満タン近くまで貯まっていた。
ブロックを戦闘中ずっと残す決まりが、敵の攻撃をほとんど受け止めた戦闘もある（白嶺ネーヴェの強い魔物で14ターン、受けたのは最大HPの17%）。

同じ日の最初の自動対戦（装備なし、会心と状態異常は種でそろえていない）では、強い魔物が勝率92%・平均7.2ターン（3〜14）、最奥の間が勝率93%・平均10.5ターン（7〜13）だった。

会心なし・必ず付くでは平均8.3ターン（7〜10）・1ターンの与ダメ708、確率どおりでは平均7.3ターン（6〜8）・799で、会心の分だけ与ダメが1割ほど増え、1ターンほど短い。

### クリア回数の報酬の例

2026-10-23の相談で、[クリア回数の報酬](#ダンジョンのクリア回数の報酬)の例として次の表を挙げ、ユーザーは方向はよいとした。
各回の中身は、ダンジョンを作るときにユーザーと決めるため、この表は採用した値ではない。
一般に、毎回同じ物がもらえるより、節目で確定の良い物がもらえるほうが周回の動機になるとされる。

| 回数 | 報酬の例 |
|---|---|
| 1回目（初回クリア） | ☆の多い装備を確定、またはまとまったルーン |
| 2回目 | 素材・アイテムのまとまった数 |
| 3回目 | 品質A以上が確定のスキル |
| 4回目 | アクセサリー |
| 5回目 | キャラ、または品質Sが確定のスキル |
ダンジョンの規模と長期目標の置き方は、旧方針との関係を[確認待ち](#確認待ち)に記録する。

### 成長の記録

最深到達の更新、前回遊んだ時点からの進展、以前勝てなかった敵の撃破を見せる。
必要に応じて、前回記録と自己ベストを区別する。
他者との競争より、「前回より深く進めた」「以前の相手が楽になった」を中心にする。
深度・階層の表記方法と、比較記録の具体的な単位は未決とする。

### アセットを増やしすぎない構成

エリア共通の分岐背景・戦闘背景に、扉・階段・宝箱などの差分を組み合わせる方向とする。
大きな自由移動マップを前提にしない。

同じ素材でも、敵の編成、報酬、選ぶ理由に違いを作る。
深い地域で背景を変えるなど、新しい場所へ到達した節目を演出する。
必要アセット数や地域数は未決である。

同じ日に、残りのマスの中身と[地図の作り直し](#地図の作り直し2026-10-21)を実装した。
- 怪しい宝箱：押すと「開ける」「通り過ぎる」を選ぶ。開けると、サーバーが半分の確率でミミックかを決めて保存する（`POST /v1/adventure/open`）。ミミックなら宝箱ミミックと行き先の小さな敵の戦闘になり、勝つと最大の報酬（主の物を除く）。本物ならその場で強い報酬を1つ多く落とす。通り過ぎると何も落とさずに終える（`clear` の `pass`）。
- 試練：マスに入るとサーバーが条件を選んで保存し、探索と戦闘の始めに知らせる。勝ったときに端末が判定し（倒れた味方がいるか、その戦闘で復活したら「誰かが倒れた」とみなす）、`clear` の `trialMet` で伝える。サーバーは判定せず、端末を信じる。
- 歩数の扉：押すとサーバーが今日の歩数（[起動時の連携と歩数の同期](startup-sync.md)で送った、その日の歩数）を読んで報酬の段を決め、「今日の歩数 N歩：扉が〜」と知らせてから中身を見せる。その日の歩数をまだ同期していなければ0歩として扱う。
- 行商人：着くと品物の一覧を開く。値段は☆1が300ルーン、☆が1つ増えるごとに倍にし、品質の倍率（C1.0・B1.25・A1.5・S2.0）を掛けて10の位で丸める（仮。ユーザーが「おまかせ」とした。Lv10→11の費用1,000ルーンに合わせた）。買うと確かめてから買い、持ち物に入れる（`POST /v1/adventure/buy`）。立ち去るとマスを終える。正本はサーバーの [merchant.ts](../../server/src/features/adventure/merchant.ts)。
- 覚醒の祭壇：押すと、仲間・固有スキル・覚醒先（セットしている段階の次の段階）の順に選び、確かめてから覚醒させる（[AdventureAltar](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureAltar.cs)）。先にマスを終えたこと（`clear` の `evolved`）を保存し、保存できてから、取得した段階をセットして編成のAPIで保存する（[固有スキルの覚醒](skill-evolution.md#覚醒の保存)の `PartyUniqueSkills.Evolve`）。覚醒させたら物を落とさない。進められる固有スキルが1つもなければ、宝箱と同じに開けて宝箱と同じ物を落とす。

宝箱の中身は、サーバーの [catalog.ts](../../server/src/features/world-map/catalog.ts) の `CHESTS` とクライアントの [WorldMapChests](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapChests.cs) が同じ値を持つ。
宝箱のマスをクリアした移動（`POST /v1/world-map/move`）で、サーバーはクリアしたマスの行に受け取りの印（`world_map_squares.grant_id`）を付けて書き、その行を書けたときだけ中身を持ち物に足す。
送り直しでは行を書けないため、二重には足さない。
応答には中身を添える（`chest`）。
地図は、宝箱のマスに着くとクリアを保存し、保存できてから中身をダイアログで見せる（[AdventureDialogs](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureDialogs.cs) の宝箱と同じ形）。
ダイアログを閉じるまでは、マスを押しても歩かない。

同じ日に、歩数の関所のマスの種類（`StepGate`）と台の絵をなくした。
2026-10-24に、[戦闘後の強化](#戦闘後の強化)を実装した。強化の種類・候補の作り方・ステータスへの掛け方は [AdventureBoons](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureBoons.cs)、3枚のカードの窓は [AdventureBoonPicker](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureBoonPicker.cs)（組み立ては [AdventureBoonPickerAssets](../../client/Assets/Baryonyx/Features/Adventure/Editor/AdventureBoonPickerAssets.cs)）、選んだ強化・虹の出ない回数・選んでいない強化のマスの保存は [AdventureVitals](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureVitals.cs) にある。勝った戦闘は、勝ったことを保存する前に選ぶ強化を待つマスを端末に残し、ドロップの札を見せたあとに3枚を開く（[BattleAdventureFlow](../../client/Assets/Baryonyx/Features/Adventure/Runtime/BattleAdventureFlow.cs)）。再開した探索は、今いるマスが終わっていて強化を待っていれば、同じ3枚を開く（[ExplorationFlow](../../client/Assets/Baryonyx/Features/Adventure/Runtime/ExplorationFlow.cs)）。選んだ強化は、休憩の鍛えると足し合わせて、戦闘の前にステータスへ掛ける（`AdventureParty.Hone`）。背水・先手・弔いは、戦闘で味方のステータスを読む所（カードの威力、パッシブの切り返しと帯電の盾、ターン順の速度、受けるダメージの防御）で、その時のHP・ターン・倒れた仲間の数から掛け直す（[BattleStatBoosts](../../client/Assets/Baryonyx/Features/Combat/Runtime/BattleStatBoosts.cs)、[BattleInspectView.Boosts](../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleInspectView.Boosts.cs)）。数値は自動対戦で試していない。
