# ステージ進行と危険度

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- ステージを選び、戦闘で装備・素材を獲得し、強化してより高難度へ挑む。
- 雑魚複数戦・単体ボス戦を用意し、基本のクリア条件は敵全滅とする。
- 危険度を設定でき、高いほど敵の強化、報酬量上昇、高レア装備率上昇につながる。
- スタミナ・挑戦回数制限は設けない。
- 敗北時のルーン減少・装備ロスト・挑戦回数減少は設けない。
