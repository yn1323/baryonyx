# 入れ子の地図（世界地図と地域のエリアマップ）

[機能索引](README.md) / [探索とダンジョンの進行の街道](stage-progression.md#街道を開くルーンと日週月の出来事2026-10-27) / 経緯：[計画](../plans/2026-10-27-world-map-rune-squares.md)

世界地図で駒を進めて地域のマスに止まると、その地域の細かい地図（**エリアマップ**）へ入り、エリアマップの入口に止まると世界地図へ戻る、入れ子の地図の試作である。
今の街道（[探索とダンジョンの進行](stage-progression.md#街道とダンジョン)）とは別のシーン（`WorldAtlas`）として作り、Homeのデバッグルームの一覧から開く。
マスにはまだ出来事もルーンもなく、町や名所のドット絵も置いていない。

## 確定している方針

2026-10-27に、ユーザーとの相談で決めた。

- 世界地図の地域のマスに止まると、その地域のエリアマップへ切り替わる。エリアマップで世界地図へ戻るマスに止まると、世界地図へ戻る。切り替えにはアニメーションを付ける。
- 世界地図とエリアマップは、同じ地形の背景を使う。エリアマップは、世界地図と同じ地形だと分かれば、木・岩・道を細かく描き込んでよい。
- 背景は、建物や名所を描かない地形だけの絵にし、町や名所を置く所は平らな空き地にする。町や名所は、あとで別のドット絵で背景のすぐ手前に置く。
- 世界地図の背景は5倍の大きさ（7680×5120）で作り、スマホではASTC 6×6で圧縮する。
- 画像生成の依頼には「細碎な点状テクスチャが多すぎるので抑える」を入れる（[AGENTS.md](../../AGENTS.md#作業の基本)）。
- 世界地図の道は網の目にし、寄り道を置く。
- 地域の名前は次のとおりにする（仮）。

| キー | 名前 | 町 |
|---|---|---|
| `verde` | ヴェルデ平原 | 門前町ポルタ・宿場町ブリーザ |
| `marina` | マリーナ海岸 | 港町ポルトリア |
| `gelo` | ジェーロ連峰 | 宿場町ピーノ・氷室村フレッダ・宿場町アルバ・山小屋チーマ |
| `bosco` | ボスコ大森林 | 鐘の町カンパネラ |
| `fiamma` | フィアンマ火山帯 | 鍛冶町フォルジャ |
| `nebbia` | ネッビア湿原 | 渡し町パルーデ |
| `oro` | オーロ砂漠 | 宿場町サッビア・砂の町ドゥーナ |

町のID（`porta` など）と名前は、今の街道（[WorldMapCatalog](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapCatalog.cs) の `Towns`）と同じである。

## 設計方針

### 進み方

- 世界地図では、はじめはヴェルデ平原の地域のマスだけが開いている。今の街道と同じく、開けたマスの隣のマスへ1つずつ進み、開けたマスの上は自由に歩ける。
- 地域のマスに止まるか、立っている地域のマスを押すと、その地域のエリアマップの中心の町（ヴェルデ平原はポルタ、ジェーロ連峰はピーノ、オーロ砂漠はサッビア、ほかは地域にある1つの町）に入る。配置のJSONで、中心の町を先頭に置いている。
- エリアマップでも、立っているマスの隣へ1つずつ進む。
- エリアマップの入口に止まるか、立っている入口を押すか、左上のもどるを押すと、世界地図のその地域のマスへ戻る。世界地図には、もどるを出さない。
- 開けたマスは、地図ごとにアプリを閉じるまで残る。サーバーにも端末にも保存しない。

### 切り替えの演出

片道0.5秒で、ゲームの時間の速さによらずに動く（[WorldAtlasNavigator](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldAtlasNavigator.cs)）。
切り替えの間は、地図を押せない。

| 向き | 出ていく地図 | 入ってくる地図 |
|---|---|---|
| 地域へ入る | 駒を中心に2.4倍まで近づきながら暗くなる | 開いたときの拡大率の約1.8倍から、引きながら明るくなって落ち着く |
| 世界地図へ戻る | 駒を中心に0.55倍まで引きながら暗くなる | 開いたときの拡大率の1.8倍から、引きながら明るくなって落ち着く |

### 見た目の数値（仮）

大きさは設計座標（1920×1080）で、地図の拡大率が1のときの大きさである。

| | 世界地図 | エリアマップ |
|---|---|---|
| 背景の1画素の大きさ | 0.5 | 1 |
| マスの台 | 50 | 56 |
| 地域のマス・町 | 88 | 92 |
| 入口 | なし | 76 |
| 道の縁・地の太さ | 12・6 | 10・5 |
| 駒（今の街道の駒に対する倍率） | 0.5倍 | 0.55倍 |
| 開いたときの拡大率 | 1.3倍 | 1.15倍 |

マスは、あとで出来事のアイコンを描き込めるくらいの大きさにし、駒はマスより少し大きい程度にした。
2本指の拡大・縮小は、今の街道と同じ上限（2倍）と下限（地図が画面を埋めるところ）にする。
入口の台は、町の台の金色の縁を青緑にした絵（`WorldNodeGate.png`）である。

### 地図とマス（仮）

| 地図 | 背景の大きさ | マス | 町 | 入口 | 線 | つながる地域 |
|---|---|---|---|---|---|---|
| 世界地図 | 7680×5120 | 299 | 地域のマス7 | なし | 344 | すべて |
| ヴェルデ平原 | 3840×3072 | 140 | 2 | 5 | 156 | マリーナ・ジェーロ・ボスコ・ネッビア・オーロ |
| マリーナ海岸 | 2304×3584 | 87 | 1 | 2 | 94 | ヴェルデ・ネッビア |
| ジェーロ連峰 | 6144×3072 | 169 | 4 | 2 | 187 | ヴェルデ・ボスコ |
| ボスコ大森林 | 4608×5120 | 281 | 1 | 4 | 309 | ヴェルデ・ジェーロ・フィアンマ・オーロ |
| フィアンマ火山帯 | 3072×5120 | 209 | 1 | 1 | 237 | ボスコ |
| ネッビア湿原 | 3840×4096 | 147 | 1 | 3 | 161 | ヴェルデ・マリーナ・オーロ |
| オーロ砂漠 | 6144×3072 | 310 | 2 | 3 | 345 | ヴェルデ・ネッビア・ボスコ |

マスの数は、町・入口・地域のマスを除いた数である。
入口のIDは `gate-<地域>-<地域>`（地域のキーを辞書順に並べる）で、つなぐ2つの地域のエリアマップの、元の背景の同じ場所に置く。
世界地図では、入口でつながる2つの地域が、ほかの地域を通らない道でつながる。

- **世界地図**：陸の上に約165画素（元の背景、1536×1024）おきに道の分かれ目を置き、近くどうしを網の目に結んだ。網の目の外の陸地へ、行き止まりの寄り道を18本足した。道は地形に沿って曲がり、マスは道に沿って約45画素おきに置いた。
- **エリアマップ**：地域の中に約560画素（エリアマップの背景）おきに道の分かれ目を置いて網の目に結び、マスは約125画素おきに置いた。
- **地域の境**：オーロ砂漠は、草原・森・沼・東の島々を外すよう手で引いた。ほかの6地域は、地域ごとに置いた目印からいちばん近い地域を選んだ仮の線である。
- **入口の場所**：オーロ砂漠の3か所は手で決めた。ほかの7か所は、隣り合う2つの地域の境の上で、2つの地域の町の中ほどにいちばん近い陸地に置いた（[gates.json](../../client/ArtSource/WorldMap/Atlas/gates.json)、元の背景の座標）。

### 背景の作り方

1. 今の世界地図の背景（1536×1024）から、建物・名所・小道を取り除き、町や名所を置く所を平らな空き地にした地形だけの絵を作る（[依頼文](../../client/ArtSource/WorldMap/Atlas/requests/terrain_common.txt)・[空き地の指示](../../client/ArtSource/WorldMap/Atlas/requests/terrain_clearings.txt)）。
2. 世界地図は、1の絵を5倍に引き伸ばして、半分ずつ重なる1536×1024の区画（縦横9つずつで81枚）に分け、区画ごとに下絵として渡して描き直す（[依頼文](../../client/ArtSource/WorldMap/Atlas/requests/world_tile.txt)）。
3. エリアマップは、地域の範囲を5倍の背景から切り出し、マスを置く道筋を土色の線で描き込んだ下絵を作って、同じく区画ごとに描き直す（地域ごとの依頼文は [requests/](../../client/ArtSource/WorldMap/Atlas/requests/) の `area_<地域>.txt`）。下絵に道を描くのは、背景に描かれる道とマスの道をそろえるためである。
4. 区画は、重なりの中で色をそろえ、2枚の差がいちばん小さい線でつなぐ。
5. 並行で生成すると、別の区画の絵を拾うことがあるため、区画ごとに下絵との差を測り、外れた区画を作り直す。3回作り直しても外れるときは、目で見て決める（ジェーロ連峰の右下の区画は、雪の地域の依頼に引かれて草地を雪で描いたため、草地として描く依頼で作り直した）。

使った道具と依頼文は [client/ArtSource/WorldMap/Atlas/](../../client/ArtSource/WorldMap/Atlas/) に置いた。道具の中のパスは作業したときのもので、生成した区画と途中の画像は `output/world-map-bg/`（Git対象外）にある。

| 道具 | 役割 |
|---|---|
| `regions.py` | 地域の境を決め、地域の分け方の図を描く |
| `organic.py` | 地形の通りにくさから道を作り、道に沿ってマスを置く（共通の部品） |
| `world_layout.py` | 世界地図の網の目の道と寄り道とマスを作り、配置を書き出す |
| `area_all.py`・`area2.py` | エリアマップの道とマスと下絵を作る（`area2.py` はオーロ砂漠） |
| `run_tiles.sh`・`gen_generic.sh`・`verify_generic.py` | 区画を5枚ずつ並行で生成し、下絵との差で確かめて作り直す |
| `stitch.py` | 区画をつないで1枚にする |
| `to_unity.py` | 配置のJSONと、分けた背景のJPEGをUnityへ書き出す |

### Unityでの置き場所

| 置き場所 | 中身 |
|---|---|
| `Atlas/Layouts/<キー>.json` | 地図ごとのマスと線（[WorldAtlasLayout](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldAtlasLayout.cs)、背景の左上からの画素） |
| `Atlas/Art/<キー>_<行><列>.jpg` | 背景を1辺4096以下に分けたJPEG（品質90）。Android・iOSではASTC 6×6。ミップマップを使うとASTCに圧縮されずにRGBA32のまま入る（世界地図の1枚が50MBになった）ため、どの地図もミップマップを使わない |
| `Atlas/Resources/WorldAtlas/<キー>.prefab` | 地図ごとの画面。見ている地図だけを読み込み、切り替えたら前の地図の背景をメモリーから外す |
| `Atlas/WorldAtlas.prefab` | 地図を切り替えるナビ |

`Atlas/` は `client/Assets/Baryonyx/Features/WorldMap/Atlas/` である。
画面とシーンは、Unityのメニュー `Baryonyx > World Map > Create Atlas Assets` で作る（[WorldAtlasAssets](../../client/Assets/Baryonyx/Features/WorldMap/Editor/WorldAtlasAssets.cs)）。

背景のJPEGの容量は、世界地図が約20MB（4枚）、オーロ砂漠が約10MB（2枚）である。
ASTC 6×6で取り込んだときのゲームの中の容量は、世界地図で約17.5MBである。2026-10-27のDev向けAPKは、入れ子の地図の背景（APKの中で約66MB）を入れて、246MBから304MBになった。

## 変更と判断の記録

- 2026-10-27：世界地図の背景をミップマップ付きで取り込んだら、ASTCに圧縮されずRGBA32のまま入り、APKの中で1枚50MBになったため、ミップマップを外した。Unityの増分ビルドで、APKに前のビルドの空き（約137MB）が残り441MBになったため、Gradleが出力したAPK（`Library/Bee/Android/Prj/IL2CPP/Gradle/launcher/build/outputs/apk/debug/launcher-debug.apk`）を消してビルドし直した。
- 2026-10-27：ユーザーとの相談で、入れ子の地図の試作を作った。網の目の道、地形だけの背景、5倍の背景、エリアマップの細かい背景、マスの大きさ、切り替えの演出、デバッグルームからの入口の経緯は[計画](../plans/2026-10-27-world-map-rune-squares.md)に記した。
