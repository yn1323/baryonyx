# 入れ子の地図（世界地図と地域のエリアマップ）

[機能索引](README.md) / [前の街道を開くルーン](stage-progression-world-map.md#街道を開くルーンと日週月の出来事2026-10-27) / 経緯：[計画](../plans/2026-10-27-world-map-rune-squares.md)

世界地図で駒を進めて地域のマスに止まると、その地域の細かい地図（**エリアマップ**）へ入り、エリアマップの入口に止まると世界地図へ戻る、入れ子の地図の試作である。
2026-10-28から、冒険していないときのHomeの行き先カードは、前の街道（[探索とダンジョンの進行](stage-progression/destinations.md#街道とダンジョン)）の代わりに、この地図のシーン（`World`）を開く。
試作のシーン（`WorldAtlas`）は、デバッグ用にHomeのデバッグルームの一覧に残す。前の街道の世界地図（`WorldMap`）は、2026-10-29にユーザーの「前の街道のLabは不要」で一覧から外した。
世界地図とマリーナ海岸のエリアマップには、出来事を試しに置いた（[マスに置いた出来事](world-atlas/square-events.md#マスに置いた出来事)）。世界地図には7種類の出来事がすべてある。
マスの出来事は、[地図エディター](screens/debug-rooms.md#地図エディター)で一覧から開いて確かめられる。ほかの地図のマスには出来事がなく、町や名所のドット絵も置いていない。
どの地図でも、まだ入っていないマスに入るにはルーンを払う（[マスを開くルーン](world-atlas/maps.md#マスを開くルーン)）。

仕様は、次のファイルに分けて置く（2026-11-02に分けた。読むときは、必要なファイルだけを開く）。

| ファイル | 主な内容 |
|---|---|
| [地図と進み方](world-atlas/maps.md) | 確定している方針（地域の名前と町）、進み方、切り替えの演出、マスを開くルーン、見た目の数値、地図とマス、背景の作り方、Unityでの置き場所 |
| [マスの出来事](world-atlas/square-events.md) | マスに置いた出来事と世界地図の割り当て、マスの付け替え、戦闘の設定、各環境への反映、出来事の台、出来事の見本と賭けの遊び方、出来事を足す・変える・消すとき |
| [未決事項と実装との対応](world-atlas/status.md) | 未決事項、実装との対応 |
