# ルーン経済と資源

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)、[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

## 確定している方針

- 運動量（ACT）から得るゲーム内の主軸資源を「ルーン」とする。
- ルーンは課金で販売しない。
- 運動しないと遊べない、課金しないと進めない設計にはしない。

運動と育成・攻略のつながりは[ゲーム概要](../game/overview.md#コアループ)を参照する。

### ルーンの入手

歩数を1歩＝1ACTで換算し、ACTを1ACT＝1ルーンで変換する。
1日の上限は設けず、1万ACTを超えても得られる。
未変換分はHomeのACTパネルを押す明示の操作で受け取り（起動時の同期では受け取らない）、初回はサーバーに保存された過去7日分を対象にする。
ゲーム起動後のリアルタイム監視や定期ポーリングは行わない。
歩数が後から減っても、付与済みのルーンは取り消さない。
変換の詳細は[運動データとルーン換算](exercise-rewards.md#actのルーン変換)を正本とする。

商会で装備・スキル・素材を売ると、ルーンを得る（2026-10-05、ユーザー決定）。売値は2026-10-24に仮の値で実装した（[売る](screens/shop.md#売る)）。
ダンジョンの1〜5回目のクリアでは、決まった物と一緒に300ルーンをもらう（2026-11-01、[クリア回数の報酬](stage-progression/destinations.md#ダンジョンのクリア回数の報酬)）。

### ルーンの用途

| 用途 | 状態 |
|---|---|
| キャラのレベルアップ | 確定（[育成](progression.md)）。サーバーで費用を計算し、サーバーの残高から引く（実装済み） |
| 敗北時の復活 | 確定。[消費の選択と再開](combat/rules.md#敗北とルーン復活)は戦闘仕様を正本とする。サーバーで費用を計算し、残高から引く（2026-10-04に仮の費用で実装）。ルーンの代わりに広告を見て復活する形も設ける（[月パスと報酬つきの広告](monetization.md#月パスと報酬つきの広告)、2026-10-25。未実装） |
| 召喚 | 確定（2026-10-24、ユーザー決定）。1回300ルーン、10回3,000ルーン（[召喚](monetization.md#召喚)）。見直しの資料の法務メモは、召喚をルーンで引く無償通貨のみのガチャとして整理している。サーバーが引いて残高から引く（2026-10-24に実装、[召喚の保存](monetization.md#召喚の保存)）。1日1回、広告を見るとルーンを払わずに10回引ける形も設ける（[月パスと報酬つきの広告](monetization.md#月パスと報酬つきの広告)、2026-10-25。未実装） |
| 商会での購入 | 確定（2026-10-05、ユーザー決定）。[商会](screens/shop.md#商会)の「買う」で、これまでに手に入れたスキル・武器・防具・アクセサリーを品質C（×1.00）で買う（2026-10-24に実装）。値段は☆1の1,000ルーンから☆ごとに倍にする仮の値（☆5で16,000）で、サーバーが決めて残高から引く。素材の購入は未決 |
| 商会での合成 | 出来上がる物の☆で200〜1,600ルーンを払う仮の値で、2026-10-31に実装した（[費用](synthesis.md#費用)） |
| 商会での強化 | 確定（2026-10-24、ユーザー決定）。[商会の強化](enhancement.md)で、強化素材と一緒にルーンを払う。額は仮の値（石1個100ルーン、覚醒は1,000・2,000ルーン）で、2026-10-24に実装した（[磨き石の上げ幅と使う数](enhancement.md#磨き石の上げ幅と使う数)・[覚醒の欠片の落ち方と費用](enhancement.md#覚醒の欠片の落ち方と費用)） |
| 行商人での購入 | 冒険の行商人のマスで、☆と品質で決まる仮の値段で買う（[マスの中身](stage-progression/rooms.md#マスの中身仮)、実装済み） |
| 街道のマスを開く | 確定（2026-10-27、ユーザー決定）。街道で、まだ入ったことがないマスと、日・週・月に復活したマスに入るときに払う。開けたマスはタダで通れる（[街道を開くルーン](stage-progression-world-map.md#街道を開くルーンと日週月の出来事2026-10-27)）。値段は仮の値で、入れ子の地図でまだ入っていないマスに入るときに払う形を2026-10-29に実装した（[マスを開くルーン](world-atlas/maps.md#マスを開くルーン)）。日・週・月の復活は未実装 |

育成費用、復活費用、上限などの経済数値は本ページで別途設計する。

## 候補と例

ルーンの用途の表にない、ほかの成長要素（装備の進化・再抽選など、[育成の未決事項](progression.md#未決事項)）への利用を想定する。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 用途ごとの必要量 | レベルアップ・復活の費用と、商会の値段は未決（商会の値段は2026-10-24に仮の値で実装）。召喚は1回300・10回3,000ルーンに決めた（2026-10-24） |
| 運動しない日の入手・成長経路と開始時の資源 | 未決 |
| 1日・1セッションの想定収支と育成速度 | 未決 |
| 上限・所持桁数・端数・失効の有無 | ACT変換の日次上限は設けない。所持上限、失効、消費時の扱いは未決 |
| 他の通貨・素材との変換・売却 | 装備・スキル・素材の売買はルーンで行う（2026-10-05）。売値は仮の値で実装した（2026-10-24、[売る](screens/shop.md#売る)）。値段の確定と、ほかの通貨を設けるかは未決 |
| 探索報酬・課金効果の適用対象と重複 | 未決。旧危険度選択による倍率は現行仕様の前提にしない |
| 報酬付与・消費の確定、再送・中断時の整合 | ACT変換は日別チェックポイントとルーン台帳で再送時の二重付与を防ぐ。消費はレベルアップ・冒険の復活・行商人と商会の購入・商会の合成・品質強化と覚醒・召喚・入れ子の地図のマスを開くことを実装し、どれも要求IDで再送時の二重消費を防ぐ。消費はレベルアップの記録（`party_level_ups`）・復活の記録（`adventure_revives`）・購入の記録（`adventure_purchases`・`workshop_purchases`）・合成の記録（`workshop_crafts`）・強化の記録（`enhancement_records`）・召喚の記録（`summon_pulls`）・開けたマスの記録（`world_atlas_squares`）に残し、増える分の台帳とは分けている。商会の売却で得た分は、要求IDで二重の付与を防ぎ、売却の記録（`workshop_sales`）に残す |

## 確認待ち

既存の仕様と今回の内容のどちらを採るか、開発者の判断が必要な事項である。
回答を得るまで、ほかの仕様や実装へ波及させない。

| 項目 | 既存・旧仕様 | 今回の内容 | 影響する範囲 |
|---|---|---|---|
| ACTログインボーナス | 運動目標とは別に、運動量によるログインボーナスを用意する。目標を設定しない場合も利用できる。条件と量は未決だった | 運動目標を廃止し、[日次のACTボーナス](../archive/step-bonus.md)（2026-10-24に廃止）が目標の役割を担う。ログインボーナスへの言及はない | ACTボーナスへ統合するか、別に残すか |
| 初回の固定ルーン | 運動目標の初回設定で、当日・今週のデータがない場合に固定ルーンを配布する（配布量・回数は未決） | 運動目標を廃止。初回の配布への言及はない | 運動データがない人への初回の資源、[初回体験](onboarding.md) |

## 実装との対応

本ページは企画上の要求・未決事項を記す。
ルーンの付与は[運動報酬](exercise-rewards.md#実装との対応)、レベルアップでの消費は[キャラと編成の保存](party.md#キャラと編成の保存)、ルーン復活での消費は[探索と進行](stage-progression/status.md#実装との対応)、商会の購入での消費と売却での付与は[商会](screens/shop.md#商会)（[API](../../server/src/features/workshop/routes.ts)）で実装した。
商会の合成・品質強化と覚醒・召喚・行商人・入れ子の地図での消費は、[合成](synthesis.md#実装との対応)・[商会の強化](enhancement.md#実装との対応)・[召喚の保存](monetization.md#召喚の保存)・[探索と進行](stage-progression/status.md#実装との対応)・[マスを開くルーン](world-atlas/maps.md#マスを開くルーン)に記す。
ルーンの残高と増減の記録はサーバーに置く（[置き場所の一覧](../rules/data-storage.md#置き場所の一覧)）。
