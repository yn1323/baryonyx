# ルーン経済と資源

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)、[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

## 確定している方針

- 運動量（ワット）から得るゲーム内の主軸資源を「ルーン」とする。
- ルーンは課金で販売しない。
- 運動しないと遊べない、課金しないと進めない設計にはしない。

運動と育成・攻略のつながりは[ゲーム概要](../game/overview.md#コアループ)を参照する。

### ルーンの入手

歩数を1歩＝1ワットで換算し、ワットを1ワット1ルーンで変換する。
1日の上限は設けず、1万ワットを超えても得られる。
ゲーム起動時の自動処理と画面上の明示操作で未変換分を受け取り、初回はサーバーに保存された過去7日分を対象にする。
ゲーム起動後のリアルタイム監視や定期ポーリングは行わない。
歩数が後から減っても、付与済みのルーンは取り消さない。
変換の詳細は[運動データとルーン換算](exercise-rewards.md#ワットのルーン変換)を正本とする。

[ワットボーナス](step-bonus.md)と、販売予定の[チケット](monetization.md#5000ワット分運動したことにするチケット)はルーンを増やさない。

### ルーンの用途

| 用途 | 状態 |
|---|---|
| キャラのレベルアップ | 確定（[育成](progression.md)） |
| 敗北時の復活 | 確定。[消費の選択と再開](combat.md#敗北とルーン復活)は戦闘仕様を正本とする |
| 召喚 | 見直しの資料の法務メモは、召喚をルーンで引く無償通貨のみのガチャとして整理している（[課金](monetization.md)）。召喚の方式は未決 |

育成費用、復活費用、上限などの経済数値は本ページで別途設計する。

## 候補と例

装備・素材など、その他の成長要素への利用を想定する。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 用途ごとの必要量 | レベルアップ・復活・召喚の費用は未決 |
| 運動しない日の入手・成長経路と開始時の資源 | 未決 |
| 1日・1セッションの想定収支と育成速度 | 未決 |
| 上限・所持桁数・端数・失効の有無 | ワット変換の日次上限は設けない。所持上限、失効、消費時の扱いは未決 |
| 他の通貨・素材との変換・売却 | 未決 |
| 探索報酬・ワットボーナス・課金効果の適用対象と重複 | 未決。旧危険度選択による倍率は現行仕様の前提にしない |
| 報酬付与・消費の確定、再送・中断時の整合 | ワット変換は日別チェックポイントとルーン台帳で再送時の二重付与を防ぐ。消費側は未実装 |

## 確認待ち

既存の仕様と今回の内容のどちらを採るか、開発者の判断が必要な事項である。
回答を得るまで、ほかの仕様や実装へ波及させない。

| 項目 | 既存・旧仕様 | 今回の内容 | 影響する範囲 |
|---|---|---|---|
| ワットログインボーナス | 運動目標とは別に、運動量によるログインボーナスを用意する。目標を設定しない場合も利用できる。条件と量は未決だった | 運動目標を廃止し、[日次のワットボーナス](step-bonus.md)が目標の役割を担う。ログインボーナスへの言及はない | ワットボーナスへ統合するか、別に残すか |
| 初回の固定ルーン | 運動目標の初回設定で、当日・今週のデータがない場合に固定ルーンを配布する（配布量・回数は未決） | 運動目標を廃止。初回の配布への言及はない | 運動データがない人への初回の資源、[初回体験](onboarding.md) |

## 変更と判断の記録

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位を「歩」から「ワット」（1歩＝1ワット）へ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位ワット)）。ルーンは1ワット1ルーンとし、変換量は変えない。歩数ログインボーナスはワットログインボーナスへ改名した。

- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、ルーンを販売しないこと、レベルアップにルーンを使うことを確定した。運動目標の廃止に伴い、目標報酬の倍率を外し、歩数ログインボーナスと初回の固定ルーンの扱いを確認待ちとした。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| ルーン購入を収益化の候補とする | ルーンは販売しない |
| 目標報酬に難易度倍率と継続倍率を掛ける | 運動目標とともに廃止 |
| 無料再戦とルーン復活を選べる | 復活だけにルーンを使う。無料再戦の廃止は[開発者の最終確認待ち](combat.md#確認待ち) |

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、任意のルーン復活への利用を明記した。消費の操作と再開状態は戦闘仕様へ集約し、費用・収支は未確定のまま残す。旧危険度選択の倍率を経済計算の前提から外した。

- 2026-09-15：ユーザー提示の運動目標設定仕様に基づき、歩数ログインボーナス、初回固定ルーン、難易度と継続倍率を報酬設計へ接続した。日次・週次の進捗への重複反映と報酬の重複計算を区別し、具体値と遡及・差額処理を未決として残す。

- 2026-09-20：ユーザー確認により、歩数変換を1歩1ルーン、日次上限なし、端末タイムゾーン単位、過去7日分の初回請求、起動時と明示操作の両対応として確定した。目標報酬の倍率やルーン消費の費用とは分けて扱う。
