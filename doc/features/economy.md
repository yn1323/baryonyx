# ルーン経済と資源

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- 現実活動から得るゲーム内の主軸資源を「ルーン」とする。
- 育成など複数の成長要素に使う汎用資源とする方向である。
- 運動しないと遊べない、課金しないと進めない設計にはしない。

## 候補と例

キャラクター育成、装備・素材、ガチャ、その他の成長要素への利用を想定する。
ルーン購入は収益化の候補であり、採用は未決である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| ルーンの入手先・消費先と用途ごとの必要量 | 未決 |
| 運動しない日の入手・成長経路と開始時の資源 | 未決 |
| 1日・1セッションの想定収支と育成速度 | 未決 |
| 上限・所持桁数・端数・失効の有無 | 未決 |
| 有償・無償資源を区別するかと消費順 | 未決 |
| 他の通貨・素材との変換・売却 | 未決 |
| 目標倍率、危険度、課金効果の適用対象と重複 | 未決 |
| 報酬付与・消費の確定、再送・中断時の整合 | 未決 |
