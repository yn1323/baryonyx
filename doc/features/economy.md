# ルーン経済と資源

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- 現実活動から得るゲーム内の主軸資源を「ルーン」とする。
- 育成など複数の成長要素に使う汎用資源とする方向である。
- 運動しないと遊べない、課金しないと進めない設計にはしない。
- 任意の戦闘復活にもルーンを使う。[消費の選択と敵・味方の状態](combat.md#無料再戦とルーン復活)は戦闘仕様を正本とする。

運動と育成・攻略のつながりは[ゲーム概要](../game/overview.md#コアループ)を参照する。
探索・進行・戦闘仕様は、運動の換算式、報酬倍率の具体値、育成費用、復活費用、上限などの経済数値を確定するものではない。
換算は[運動報酬](exercise-rewards.md)、目標条件は[運動目標](goals.md)、用途別の収支は本ページで別途設計する。

### 目標報酬と歩数ログインボーナス

目標とは別に、歩数によるログインボーナスを用意する。
目標を設定しない場合も利用できる。
歩数をルーンへ変換する基本値は1歩1ルーンで、1日の上限は設けない。
ゲーム起動時の自動処理と画面上の明示操作で未変換分を受け取り、初回はサーバーに保存された過去7日分を対象にする。
ゲーム起動後のリアルタイム監視や定期ポーリングは行わない。
歩数が後から減っても、付与済みのルーンは取り消さない。

この歩数変換の基本値は、日次・週次の目標報酬に適用する倍率を確定するものではない。

目標報酬の倍率は、[難易度と継続倍率](goals.md#倍率の構成)を分ける。
継続倍率が上がった場合は今回獲得するルーンから適用する方針とし、倍率の対象となるルーン、歩数ログインボーナスとの関係、日次・週次の報酬の組み合わせは別途設計する。
同じ運動が日次・週次の両方へ反映されても、両目標の倍率を掛け合わせる仕様が確定したことにはならない。

初回にデータがない場合は[固定ルーンを配布する](goals.md#初回設定)。
配布量・対象条件・回数の単位・重複配布防止・達成実績への扱いは未確定とする。

## 候補と例

キャラクター育成、装備・素材、ガチャ、その他の成長要素への利用を想定する。
ルーン購入は収益化の候補であり、採用は未決である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| ルーンの具体的な入手先・消費先と用途ごとの必要量 | 歩数変換の基本値は確定。目標報酬、初回固定ルーン、任意の戦闘復活の費用・回数制限は未決 |
| 運動しない日の入手・成長経路と開始時の資源 | 詳細は未決。初回にデータがない場合の固定ルーンは[目標仕様](goals.md#初回設定)に従う |
| 1日・1セッションの想定収支と育成速度 | 未決 |
| 上限・所持桁数・端数・失効の有無 | 歩数変換の日次上限は設けない。所持上限、失効、消費時の扱いは未決 |
| 有償・無償資源を区別するかと消費順 | 未決 |
| 他の通貨・素材との変換・売却 | 未決 |
| 目標倍率、探索報酬、課金効果の適用対象と重複 | 未決。旧危険度選択による倍率は現行仕様の前提にしない |
| 目標報酬の倍率と受け取り | 日次・週次の報酬計算、両目標の倍率の関係、歩数変換への適用、既受領分への遡及・遅延訂正の差額処理は未決 |
| 報酬付与・消費の確定、再送・中断時の整合 | 歩数変換は日別チェックポイントとルーン台帳を使い、再送時の二重付与を防ぐ計画。消費側は未実装 |

## 変更と判断の記録

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、任意のルーン復活への利用を明記した。消費の操作と再開状態は戦闘仕様へ集約し、費用・収支は未確定のまま残す。旧危険度選択の倍率を経済計算の前提から外した。

- 2026-09-15：ユーザー提示の運動目標設定仕様に基づき、歩数ログインボーナス、初回固定ルーン、難易度と継続倍率を報酬設計へ接続した。日次・週次の進捗への重複反映と報酬の重複計算を区別し、具体値と遡及・差額処理を未決として残す。

- 2026-09-20：ユーザー確認により、歩数変換を1歩1ルーン、日次上限なし、端末タイムゾーン単位、過去7日分の初回請求、起動時と明示操作の両対応として確定した。目標報酬の倍率やルーン消費の費用とは分けて扱う。
