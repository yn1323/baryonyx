# サーバーの疎通確認

HonoアプリがHTTPリクエストに応答できることを確認する機能である。
実装とWindowsでのローカル動作確認は完了している。
実環境へのデプロイは行っていない。

## 動作と制約

`GET /health` に正常応答を返す。
接続先のDBや外部サービスの状態は確認しない。
認証や環境変数の設定は不要である。

実際のステータスと応答内容は [ルート定義](../../server/src/app.ts) と [応答テスト](../../server/src/app.test.ts) で管理する。
未定義のパスにはHono標準の404応答を返す。

現在は同じPCからの確認を想定し、`127.0.0.1:3000` で待ち受ける。
Android実機など、別端末からの接続には対応していない。
