# 固有スキルの覚醒の変更と判断の記録

[固有スキルの覚醒](skill-evolution.md)

- 2026-10-26：ユーザーの依頼「更新したVFXの作り方を利用して、VFXの更新をお願いします」で、固有スキルの12のツリーの演出と段階の層、覚醒の前触れのひびと割れる瞬間を作り直した（[段階ごとのエフェクト](skill-evolution.md#段階ごとのエフェクト)・[覚醒のエフェクト](skill-evolution.md#覚醒のエフェクト)）。主役を透け方と時間の違う層に分け、代表のマナバーストで作り方を固めてから広げた。3つ目の4つのツリーは、カードスキルの演出を借りるのをやめて専用の演出にした。ひびは、育つ光の線から、一段ずつ一気に広がる細い線に変えた（[昇る・割れる現象は細い線と一瞬の変化で組む](../../.agents/skills/vfx-authoring/references/lessons.md#昇る割れる現象は細い線と一瞬の変化で組む)）。途中の確認はユーザーの依頼で省いた。
- 2026-10-25：ユーザーの指摘「覚醒先が1つのときは一瞬しか表示されず、どういった効果か分からずに覚醒してしまう」で、候補が1枚のときの自動の決定（0.9秒）をやめた。候補が1枚でも、2枚以上のときと同じく、カードをタップして選び「この覚醒にする」で決める。
- 2026-10-24：ユーザーの相談「カードの覚醒をいろいろなところに波及させたい」を受け、カオスゼロナイトメアのひらめき（[Game8](https://game8.co/games/Chaos-Zero-Nightmare/archives/560629)・[GameWith](https://gamewith.net/chaoszeronightmare/70805)）を調べて案を示した。ユーザーは、覚醒の予兆を採り、抽選を使ったときから引いたときへ移して、当たったカードを光らせる案を選んだ（[覚醒の予兆](skill-evolution.md#覚醒の予兆)）。スキルのカードに共通の効果を1つ付ける案（Slay the Spire 2のエンチャントに当たる）は、ややこしいとして採らなかった。光り方（金の光・縁の光の線・右上の星、表を向いたときの瞬き）と、戦闘の初めの予告を作らないこと、確率の値を変えないことは、こちらで決めた。
- 2026-10-24：ユーザーの依頼で商会に[強化](enhancement.md)を足すのに合わせ、ユーザーが「進化」の呼び名を「覚醒」に改めた。文書と画面の文言を覚醒にし、コードの識別子（`SkillEvolution`・`evolve` など）とAPIは変えない。あわせて、商会で覚醒の欠片を使って覚醒させることをユーザーが認め、覚醒が冒険の中だけで起きる決まりを改めた（[覚醒が起きる場面](skill-evolution.md#覚醒が起きる場面)）。以下の記録は、当時の呼び名の「進化」のまま残す。

- 2026-10-23：ユーザーの指示で固有スキルを1人3つにした（[キャラクターの構成](party.md#キャラクターの構成)）。3つ目の中身は、7段階まで作る・最初の段階だけ作る・ユーザーが指定する、の3案から、ユーザーが7段階まで作る案を選び、解放のLvはLv40を選んだ。4系統の3つ目を、今の2つと役割が重ならないように作った（[今のツリー](skill-evolution.md#今のツリー仮データ)）。専用の挿絵とエフェクトは後の作業とし、近いカードスキルのものを借りた。
- 2026-10-22：ユーザーの依頼「冒険の中でスキルを進化させてください。戦闘も抽選もサーバー実装もお願いします」で、冒険の戦闘での抽選と進化、進み具合のサーバーへの保存を作った。保存先は、この仕様の[進化の保存](skill-evolution.md#覚醒の保存)の決定どおりサーバーにした。冒険の結果を送るAPIは別の作業で書き換え中だったため、進化は編成のAPIとして分け、マスの戦闘を終えたときに送る形にした。試練の部屋の確率は強い魔物と同じにした（仮）。宝箱からの進化は残した。
- 2026-10-22：ユーザーの問い「進化先が1つだけの場合は選択するモーションが出ないようになっているか」に、出ていてボタンを押すまで待つ作りだと答えた。「画面を飛ばす」と「一瞬見せて自動で進む」の2案から、ユーザーは一瞬見せる形を選んだ。候補が1枚のときは、0.9秒見せてから自動で決め、決定のボタンを出さないようにした。
- 2026-10-22：ユーザーの依頼「下段のカードはもっと大きく。選択中の霧もおかしい」で、Codexに案A「縁から立ちのぼる光の霧」と案B「足元に流れる霧と光の縁」の絵を作らせ、ユーザーが案Aを選んだ。さらに大きくした絵からユーザーが戦闘のカードの約2.1倍を選び、候補を2.1倍、進化前のカードを0.6倍にした。前の霧は、暗い煙のための通常合成の形を淡い金にしていたため茶色い土ぼこりに見えていた。加算で光る炎の舌の形を幅広く使い、縁から立ちのぼる形に作り直した。
- 2026-10-22：ユーザーの指摘「上のカードを小さくして、下を見やすく。選択中のカードは背景色変更だけだとのっぺりしすぎ。霧みたいな感じで選択中を表現して」で、上のカードを1倍から0.72倍に、候補を1.2倍から1.3倍にし、選択中の金の板を、縁を巡る霧と柔らかい光と昇る光の粒に替えた。
- 2026-10-22：ユーザーの指摘「固有スキルを選ぶと毎回進化するのか。そこはトグルにしてほしかった」を受け、デバッグルームの「進化」を初めは切にした。続く依頼「進化時にどのスキルにするか選択する画面もほしい」で、Codexの2案からユーザーが枝を伸ばす案を選び、[進化先を選ぶ画面](skill-evolution.md#覚醒先を選ぶ画面)を作った。あわせて、デバッグルームの進化を、選んだ段階を手前の段階から進化させる形から、選んだ段階を使って進化先を選ぶ形に改めた。
- 2026-10-21：ユーザーの依頼「エフェクトとかもかっこよくしたいので、Unityで実現できる範囲でCodexを利用してエフェクト、レイアウトを考えて」で、Codex CLIに設計案と、前触れ・選択の2案・確定の場面の絵を作らせた。ユーザーは前触れと確定の絵を選び、「魔法陣で浮いて、パリーンって感じで進化」と決めた。続く依頼「まずはエフェクトを実装。Labで見れるようにして」で、[進化のエフェクト](skill-evolution.md#覚醒のエフェクト)を作り、スキルのデバッグルームで再生できるようにした。選択の画面は未実装のまま残した。
- 2026-10-21：ユーザーの相談「どういった確率で発生させるのがよさそうか」に、1回の冒険で進化が3回前後起きる頻度から逆算した案を示した。ユーザーの依頼で、固有スキルを使うたびに抽選し、魔物の気配4%・強い魔物の気配8%・最奥の間10%、推奨Lvより1高いごとに1割下げて下限2割とする値を、[仮設定](skill-evolution.md#確率の仮設定)として書いた。参考作（ロマンシング サガの閃き・カオスゼロナイトメアのカードのひらめき）の確率は公開されておらず、値は参考にしていない。
- 2026-10-20：カードスキルのコストを0〜9で配り直したのに合わせ（[スキルの仮設定](combat.md#スキルの仮設定)）、固有スキルの各段階のコストを下げ、4以上の段階を56段階中12にした。マナバースト・極と一閃・散華は威力も上げた。
- 2026-10-19：ユーザーの依頼「これらのエフェクトも個々にパワーアップさせて。より強いものはより脳汁出る感じで」で、固有スキルの全56段階に、ツリー・枝ごとのエフェクトと、段階が進むほど重なる強化の層を作った（[設計方針](skill-evolution.md#設計方針)）。それまでの固有スキルは、斬り払いのエフェクトで代わりに再生されていた。
- 2026-10-19：ユーザーの依頼「固有スキルの進化系も考えてほしい。画像はCodexも利用して」で、8つの固有スキルの残りの45段階を仮に作り、全56段階に専用の挿絵を付けた（[今のツリー](skill-evolution.md#今のツリー仮データ)）。キャラ1人ずつ作る方針は、ユーザーの依頼で今回は採らなかった。2段目を数値だけ上げるか効果を変えるかの未決は、枝ごとに決める形で仮に作った。
- 2026-10-18：ユーザーの依頼で、[スキルの付け替え](screens/loadout.md#スキル)の画面で固有スキルを押すと右に進化ツリーを出し、取得した段階を押してセットできるようにした。取得していない段階は形だけの影にした。サーバーへの保存はまだで、アプリを動かしている間だけ残す。
- 2026-10-18：ユーザーの相談を受けて、この文書を作った。ユーザーはカオスゼロナイトメアの「カードのひらめき」を参考に挙げ、カードが増える「戦闘員のひらめき」は採らなかった。
  - 進化の結果を残す範囲として、冒険の間だけ、ずっと残す、冒険の終わりに1つだけ持ち帰る、の3案を示したところ、ユーザーはずっと残す案を選んだ。
  - 進化の型をキャラ共通にする案ではなく、キャラごとに作る案を選んだ。ツリーは当初の「A→A2→A3、A→B1→B2、B1→C1」から、制作量を抑えるため、3つの枝がそれぞれもう1段進む7段階に改めた。
  - どの枝へ進むかをランダムにする案ではなく、プレイヤーが選ぶ案を選んだ。一度進むと戻れない決まりへの対応として、Homeの編成で手前の段階にセットし直す形をユーザーが示した。
  - 確率をマスの種類とLvの差で決める案、1回の戦闘で1枚1段まで、天井なし、宝箱からその場で進める形を、ユーザーが採った。
  - 次の段階がすべて取得済みのときに進化しない案を示したところ、ユーザーは未取得のときと同じく進化する形を選んだ。
  - 名前は、「ひらめき」がロマンシング サガと重なるため改めた。芽吹き・開眼などの案は分かりにくいとされ、「進化」にした。
