# キャラクターとパーティ編成の変更と判断の記録

[キャラクターとパーティ編成](party.md)


- 2026-10-23：ユーザーの指示「MAX6枚入れられるようにしたい。固有スキルをもう1つ、カスタムスキルを1つほしい。固有スキルのみレベルで解放」「枚数の選択は特になしで固定。カスタムスキルのみ0枚でもOK。レベルが低いうちは枚数が少なくなるけどOK」により、固有スキルを3つ、カスタムスキルを3枠にした（[キャラクターの構成](party.md#キャラクターの構成)）。戦闘で1人だけ残ると同じカードばかり引く問題（[戦闘の未決事項](combat.md#未決事項)）から始まった変更である。3つ目の固有スキルはLv40で解放する（ユーザーの選択）。4系統の3つ目の固有スキルの効果は[固有スキルの進化](skill-evolution.md)に置いた。カスタムスキルを外す操作は足していない。新しい3枠目は空きのまま始まる。
- 2026-10-21：ユーザーの依頼「各キャラの設定、レベル、設定したスキルを冒険時にも反映してほしい」「Homeで表示されるキャラとかも今の編成がいい」により、冒険の戦闘・冒険の地図・Homeに今の編成を出すことにした（[実装との対応](party.md#実装との対応)）。Homeの4人は、ユーザーの了承を得て戦闘のドット絵に揃えた。解放前の固有スキルを戦闘のデッキに入れないことと、空いた枠の位置を戦闘で隠すことは、実装上の仮の判断である。
- 2026-10-18：ユーザーの依頼で、パーティの入れ替え・スキルの付け替え・レベルアップを楽観的更新にした（[キャラと編成の保存](party.md#キャラと編成の保存)）。保存を待たずに画面に出し、失敗したら戻して知らせる。サーバーの読み書きと決まりは変えていない。
- 2026-10-18：ユーザーとの相談で、固有スキルが冒険の中で進化し、取得した段階のどれを使うかを編成で選ぶことにした（[固有スキルの進化](skill-evolution.md)）。キャラの構成の固有スキルの行に加えた。
- 2026-10-18：ユーザーの依頼で、冒険者の一覧の入れ替えを、パーティの枠と一覧の人を順に押す操作に変えた（[画面一覧](screens/adventurers.md#パーティ)）。枠を選んで「パーティから外す」で外し、長押しで個別の画面を開く。入れ替え・編成・外した通知はやめた。サーバーの読み書きと入れ替えの決まり（1人以上を残すなど）は変えていない。
- 2026-10-07：ユーザーの指示により、スキルかアイテムを入れる2枠を「カスタムスキル」と呼ぶことにした（[キャラクターの構成](party.md#キャラクターの構成)）。同日、ユーザーの選択で、編成とサーバーのスキルの枠を、自由に入れる4枠からカスタムスキルの2枠に作り替えた。初期データは、各キャラの4枚から属性の違う2枚を残した。固有スキル2枚はクライアントの仮データから出し、冒険者の個別の画面とスキルの付け替えの画面に表示する（[育成](screens/adventurers.md#育成)・[スキル](screens/loadout.md#スキル)）。未リリースのため、DBにある3・4枚目は移行せずに消す（マイグレーション `0009_custom_skill_slots`）。
- 2026-10-06：ユーザーの依頼で、編成のパーティ・装備・育成・スキルを「冒険者」にまとめた（[画面一覧](screens/adventurers.md#パーティ)）。パーティの入れ替えは冒険者の一覧で、選んだ人の「パーティから外す」「パーティに入れる」と、空きがないときにパーティの4枠から入れ替える相手を選ぶ操作で行う。サーバーの読み書きと入れ替えの決まり（1人以上を残すなど）は変えていない。9人に縦長のイラストを加え、仮データ（`PartyMockData`）にイラストとスキルの挿絵を持たせた。
- 2026-10-06：デッキの枚数の確認待ちに対し、ユーザーは「アイテム or スキルで合計2枚」「固有のスキルも2つあるので、一人4枚x4人で16枚のまま」とした。これにより、1人の4枚を、固有スキル2枚と、スキルかアイテムを入れる2枠に分けた（[キャラクターの構成](party.md#キャラクターの構成)）。固有スキルを手札の外から使う決まりと、スキルを1人4枚とした2026-09-30の決まりを改めた。デッキは16枚のままである。
- 2026-10-06：ユーザーの指示により、スキルを武器・防具と同じく1枚ずつ持ち、1枚ごとに倍率を持つことにした（[持っているスキル](party.md#持っているスキル)）。キャラの構成にアクセサリー（最大3つ、初めは0枠）とアイテムの2枠を加え、アイテムもデッキのカードになることにした。アイテムを加えるとデッキが16枚を超えるため、枚数を[確認待ち](combat.md#確認待ち)に置いた。未決事項の「持っている枚数の数え方」は1枚ずつと決まったため外した。同日、付け方として3案を示したところ、ユーザーは、1枚は1人の1つの枠にだけ付けられ、同じ種類を2枚持てば1人に2枚とも入れられる形を選んだ。
- 2026-10-05：ユーザーの依頼で、酒場と装備の画面をまとめて「編成」にした（[画面一覧](screens/guide.md#編成商会神殿旅の案内所の画面)）。パーティの入れ替えはメニューの「パーティ」、武器・防具の付け替えは「装備」から開く。
- 2026-10-04：ユーザーの指示により、育成・スキル・戦闘画面のモックとカードの仮設定が使っていた仮の項目（ちから・まりょく・まもり・すばやさ）を、8つの項目（物攻・属攻・物防・速度ほか）に置き換えた。値は[Lv100の値と成長率](progression.md#自キャラのlv100のステータス)から出す。
- 2026-10-04：ユーザーの決定で、物防・属防を受けるダメージを減らす項目に、会心を会心の一撃の出やすさに、幸運を状態異常のかかりやすさ・かかりにくさに確定した（[ステータスの項目](party.md#ステータスの項目)）。防御の式と付与率は[戦闘仕様](combat.md#ダメージと防御)に置いた。
- 2026-10-04：ユーザーの指示により、[ステータスの項目](party.md#ステータスの項目)をHP・物攻・物防・属攻・属防・速度・会心・幸運の8つに決め、味方と敵で同じ項目にした。各項目の使い道は名前からの候補として書き、計算式と値の尺度は未決のままとした。育成と戦闘画面のモックは仮の項目のままである。
- 2026-10-04：ユーザーの指示により、「カードスキル」の呼び名を「スキル」に改めた（[用語集](../game/glossary.md)）。酒場・育成の画面では、付け替える対象を「カード」ではなく「スキル」と書く。戦闘の手札・山札は「カード」のままとする。
- 2026-10-04：ユーザーの依頼で、持っているキャラ・Lv・カードスキル・編成をユーザーごとにサーバーのDBへ保存するようにした（[計画](../plans/2026-10-04-tavern-party-save.md)）。レベルアップに使うルーンもサーバーの残高から引く。初期データには仮データの9人を付与し、カードの属性の判定はサーバーでは行わないことをユーザーが決めた。

- 2026-10-04：ユーザーの依頼で、酒場に[カードスキル](screens/loadout.md#スキル)の画面を作った。パーティにいない仲間も含め、キャラごとの4枚を付け替えられる。付け替えたカードは編成・レベルと同じく、アプリを動かしている間だけ残す。
- 2026-10-04：ユーザーの依頼で、酒場に[編成](screens/adventurers.md#パーティ)の画面を作った。左の4つの枠と右の仲間で入れ替え、ユーザーの指示で仲間の最後に置いた「外す」で枠を空けられる。空きを許すと4人に満たないパーティができるため、冒険に出られる最低の人数を未決事項に加えた。画面では仮に1人以上を残す。編成はアプリを動かしている間だけ残り、保存はしない。
- 2026-09-30：ユーザーと相談し、デッキを12枚から16枚に増やし、カードスキルをキャラごとに4枚にした。毎ターン3枚を引く決まり（[手札](combat.md#手札)）と合わせて、5ターン前後で山札が一巡する枚数にした。
- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、キャラの構成（レベル、ステータス、パッシブスキル×2、固有スキル×2、武器・防具、カードスキル×3）と、12枚のデッキ、ルーンによるレベルアップを反映した。装備は基本的にどのキャラでも付けられるとし、職業による装備適性の制限を置き換えた。新しい構成に職業がないため、職業そのものの扱いは確認待ちとした。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| 職業に応じて武器・防具の装備適性を制限する | 装備は基本的にどのキャラでも付けられる。キャラごとの違いは、装備できるカードの属性で表す |
| 各キャラが固定職業・固有スキル・固有パッシブを持ち、転職は設けない | 固有スキル2つとパッシブスキル2つをレベルで解放する。職業の扱いは確認待ち |
| 最初から自由にスキルを付け替える構成は前提にしない | キャラごとに3枚のスキルを、装備できる属性の範囲で付け替える |
| 試作では各キャラのアクティブスキルを2つとする | スキル3枚と固有スキル2つの構成へ変更 |

- 2026-09-19：参照会話と実装指示により、探索中の仲間変更と獲得直後の編成導線を追加した。ワイヤーのサンプルと本番の加入・編成ルールを区別する。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、前衛・後衛なし、固定職業による装備適性、固有スキルを中心とする編成を明記した。完成版のスキル構成を試作の数と区別し、MVP・装備・戦闘から参照する。
