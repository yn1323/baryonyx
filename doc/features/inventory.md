# 持ち物の分類とレア度

[機能索引](README.md) / 根拠：2026-10-06のユーザーの指示

冒険や商会で手に入れて持っておく物を、ここでは**持ち物**と呼ぶ。
この文書は、持ち物の分類と、分類をまたいで共通にする決まり（レア度と、1つずつ持つ倍率）を記す。
分類ごとの入手・使い方・保存は、各分類の仕様を正本とする。

## 確定している方針

### 持ち物の分類

持ち物は次の分類に分ける（2026-10-06）。

| 分類 | 付ける場所 | 同じ種類を複数持てるか | 正本 |
|---|---|---|---|
| 武器・防具 | キャラごとに武器と防具の枠 | 持てる。1つずつ別に持つ | [装備](equipment.md) |
| アクセサリー | キャラごとに最大3つ。初めは0枠で、レベルアップで枠が開く | 持てる。1つずつ別に持つ | [アクセサリー](equipment.md#アクセサリー) |
| スキル | キャラごとの2枠（アイテムと共有）。戦闘ではデッキのカードになる | 持てる。1枚ずつ別に持つ | [キャラクターの構成](party.md#キャラクターの構成) |
| アイテム（道具・素材） | キャラごとの2枠（スキルと共有）。戦闘ではデッキのカードになる | 持てる。種類ごとに個数で数える | [アイテム](items.md) |
| ACTボーナス | ACTの段階ごとの枠 | 持てない。1種類につき1つだけ持つ | [ACTボーナス](step-bonus.md#ボーナスの入手とレア度) |

武器・防具・アクセサリーをまとめて**装備**と呼ぶ。
素材・道具・武器・防具・アクセサリー・スキルは、合成でより良い物にできる（[合成](synthesis.md)）。
画面での見た目は、どの分類もスキルのカードに近づけていく（[画面の方針](screens.md#持ち物のカード風の見た目)）。

### レア度

どの分類も、**レア度**を☆1〜☆5の5段階で表す（2026-10-06）。
☆が多いほど手に入りにくく、☆5がもっとも珍しい。
画面では星の数で見せる。

ACTボーナスのランク（S〜E）も☆へ置き換え、Eをなくして、D・C・B・A・Sをそれぞれ☆1〜☆5に当てる（[レア度と効果量](step-bonus.md#レア度と効果量)）。

### 1つずつ持つ倍率

スキルと装備（武器・防具・アクセサリー）は、手に入れるたびに、その1つだけの**倍率**を持つ（2026-10-06）。
同じ種類のスキルや装備でも、倍率が違えば効果量が違う。
倍率は、[威力の決め方](combat.md#威力の決め方)で求めた効果量に掛ける。
たとえば同じ「ファイア」でも、倍率が×1.10の1枚は、×0.95の1枚より威力が大きい（数値は説明のための例）。
アイテムは倍率を持たず、同じ種類なら同じ効果である（[数え方](items.md#数え方)）。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 倍率の幅と決まり方 | 入手したときの倍率の範囲と出やすさ、レア度によって範囲が変わるか、合成で倍率がどう変わるか |
| レア度の付き方 | 種類ごとに決まるか、手に入れるたびに決まるか。アイテムは見つかりやすさを表し（[入手](items.md#入手)）、装備は同じ種類でも入手ごとにランダムとしている（[装備](equipment.md#確定している方針)）。スキルは未決 |
| スキルの付与効果 | 装備の付与効果（[Affix](../catalog/affixes/README.md)）のように、スキルにも1枚ごとに違う効果を付けるか |
| 所持上限 | 分類ごとの上限と、上限に届いたときの扱い |

## 実装との対応

この文書の決まりは未実装であり、今の実装には次の差がある。

| 対象 | 今の実装 |
|---|---|
| レア度 | 装備は仮データのレア度を★の数で表示する（[装備](screens.md#装備)）。ACTボーナスはランク（S〜E）でサーバーに保存する（[実装との対応](step-bonus.md#実装との対応)） |
| スキル | 持っているスキルの仕組みがなく、50枚すべてを持っている扱いである。サーバーはキャラの枠ごとにスキルのIDだけを保存する（[実装との対応](party.md#実装との対応)） |
| 倍率 | スキルにも装備にもない |
| アクセサリー・アイテム | ない |

## 変更と判断の記録

- 2026-10-06：ユーザーの指示により、持ち物の分類にアクセサリーとアイテム（道具・素材）を加え、分類をまたぐ決まりをまとめるためにこの文書を作った。スキルは入手ごとに倍率が違うため、武器・防具と同じく1枚ずつ持つことにした。倍率の決め方として、レア度ごとに固定する案、幅の中でばらつかせる案、両方を組み合わせる案を示したところ、ユーザーは「スキルそのものに倍率を付け、装備も同じ」とした。レア度の呼び方は、SSR・SR・Rの案も挙がったが、ユーザーが「S〜Eよりも☆の方がわかりやすい」として☆1〜☆5にそろえ、ほかの文書も☆にするよう指示した。同日、アイテムは種類ごとに個数で数え、倍率を持たないことをユーザーが選んだ。
