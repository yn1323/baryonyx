# 持ち物の分類、レア度と品質

[機能索引](README.md) / 根拠：2026-10-06・2026-10-19のユーザーの指示

冒険や商会で手に入れて持っておく物を、ここでは**持ち物**と呼ぶ。
この文書は、持ち物の分類と、分類をまたいで共通にする決まり（レア度と品質）を記す。
分類ごとの入手・使い方・保存は、各分類の仕様を正本とする。

## 確定している方針

### 持ち物の分類

持ち物は次の分類に分ける（2026-10-06）。

| 分類 | 付ける場所 | 同じ種類を複数持てるか | 正本 |
|---|---|---|---|
| 武器・防具 | キャラごとに武器と防具の枠 | 持てる。1つずつ別に持つ | [装備](equipment.md) |
| アクセサリー | キャラごとに最大3つ。枠はレベルアップで開く（[アクセサリー](equipment.md#アクセサリー)） | 持てる。1つずつ別に持つ | [アクセサリー](equipment.md#アクセサリー) |
| スキル | キャラごとの3枠（アイテムと共有）。戦闘ではデッキのカードになる | 持てる。1枚ずつ別に持つ | [キャラクターの構成](party.md#キャラクターの構成) |
| アイテム（道具・素材） | キャラごとの3枠（スキルと共有）。戦闘ではデッキのカードになる | 持てる。種類ごとに個数で数える | [アイテム](items.md) |
| 強化素材（磨き石・覚醒の欠片） | 付けない。商会の強化で使う | 持てる。種類ごとに個数で数える | [商会の強化](enhancement.md#強化素材) |

武器・防具・アクセサリーをまとめて**装備**と呼ぶ。
武器・防具・アクセサリー・カスタムスキルは、品物ごとに決まった材料（主にアイテム）をすべて使って合成で作れる（[合成](synthesis.md)）。
画面での見た目は、[画面の方針](screens/common.md#持ち物のカード風の見た目)に従う。

### レア度

武器・防具・アクセサリー・スキル・アイテム・強化素材は、**レア度**を☆1〜☆5の5段階で持つ（2026-10-06）。
☆が多いほど手に入りにくく、☆5がもっとも珍しい。
画面では星の数で見せる。

レア度は種類ごとに決まり、同じ種類なら手に入れるたびに変わらない（2026-10-19）。
レア度は手に入りにくさだけを表し、強さを表さない。
☆5でも、Lv 30程度で使う弱い物がある。
強さは、種類ごとの基本の効果量と、1つずつ違う[品質](#品質)で決まる。

固有スキルは、拾って手に入れる物ではないため、レア度を持たない（2026-10-19）。

### 品質

スキル・装備（武器・防具・アクセサリー）は、手に入れるたびに、その1つだけの**倍率**を持つ（2026-10-06）。
倍率は種類ごとに決めた幅の中で決まり、幅の中のどこに当たったかを**品質**（S・A・B・C）で表す（2026-10-19）。
同じ種類でも、倍率が違えば効果量が違う。
アイテムは品質も倍率も持たず、同じ種類なら同じ効果である（[数え方](items.md#数え方)）。

倍率の幅は、次のように決める。

- 下限は×1.00とし、種類の基本の効果量をそのまま使う。基本より弱くなることはない。
- 上限は種類ごとに倍率で決める（例：×2.4）。基本の割合が属攻の100%なら最大240%、200%なら最大480%になる。
- 全種類に共通の上限は置かない。スキル・装備は種類ごとに×1.5〜×3.0とする（[上限の決め方](#上限の決め方)、2026-10-20）。

品質は、幅の中の位置で次のように分ける。
同じ品質の中でも倍率は1つずつ違うため、画面には品質の文字の横に倍率を「C ×1.00」の形で出す（2026-11-03）。
格子の札だけは、品質の文字だけを出す（[装備の見せ方](../rules/ui-design.md#装備の見せ方)）。
境目ちょうどの倍率は、上の品質に入れる。

| 品質 | 幅の中の位置 | 上限×2.4の例 | [キラキラ](../art/direction.md#カードのキラキラ) |
|---|---|---|---|
| S | 上位10% | ×2.26〜×2.40 | 出す |
| A | 上位10〜30% | ×1.98〜×2.25 | 少し出す |
| B | 上位30〜60% | ×1.56〜×1.97 | 出さない |
| C | 上位60〜100% | ×1.00〜×1.55 | 出さない |

倍率は、[威力の決め方](combat/rules.md#威力の決め方)で求めた効果量だけでなく、効果の数値のすべてに掛ける（2026-10-19）。
ダメージ・回復量・ブロック・ステータスの増減量に加え、回数・持続ターン・確率・コストも変わる。
どの数値も、品質が高いほど持ち主に有利な向きへ動かす。

| 数値 | 掛け方 |
|---|---|
| ダメージ・回復量・ブロック・ステータスの増減量 | 倍率を掛ける |
| 回数・持続ターン | 倍率を掛けて四捨五入する。1回×1.5なら2回になる |
| 確率 | 倍率を掛け、100%で止める |
| コスト | 倍率の伸び1.0ごとに1下げる（四捨五入。×1.5で1、×2.5で2下がる）。1以上のコストは1を下回らない |
| 自分が受ける不利な量（失うHPなど） | 倍率で割る |
| 効く条件のしきい値（「HPが50%以下のとき」など） | 変えない。品質ごとに条件が変わると説明文が読みにくくなるため |

ダメージと回数の両方に倍率が掛かるため、回数のある効果は品質による差が大きくなる。
たとえば「属攻の100%を2回」の上限が×1.8なら、上限の1枚は「180%を4回」になり、合計は3.6倍になる。
回数のある種類は、上限の倍率を小さめに決める。

コストを倍率で割らないのは、上限を大きくすると大技が大技でなくなるためである（2026-10-20）。
割る決まりのままでは、上限×3.0のメテオ（コスト9）が上限の1枚でコスト3になり、溜めてから撃つ流れが消える。
伸び1.0ごとに1下げる決まりなら、上限の1枚でもコスト7にとどまる。

#### 上限の決め方

上限の倍率は、種類の役割で次のように決めた（2026-10-20、仮）。
値の正本は、スキルが [CardSkills](../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkills.cs)、固有スキルが [UniqueSkillTrees](../../client/Assets/Baryonyx/Features/SkillEvolution/Runtime/UniqueSkillTrees.cs)、装備がサーバーの[定義](../../server/src/features/equipment/catalog.ts)（クライアントの[仮データ](../../client/Assets/Baryonyx/Features/Equipment/Runtime/EquipmentCatalog.cs)にも同じ値を置く）である。

| 種類 | 上限 | 決め方 |
|---|---|---|
| コスト7〜9の大技 | ×2.4〜×3.0 | 溜めて撃つ手間に見合う伸びにする。メテオ（コスト9）は×3.0 |
| 1回だけ当てる攻撃・回復・ブロック | ×2.0〜×2.8 | 基本の型。コストの高い単体の大技ほど高い |
| 回数のある攻撃 | ×1.6〜×1.8 | 回数も伸びるため低め |
| 無敵・反射など、持続1ターンの強い守り | ×1.6 | 1ターンが2ターンになる品質だけを、当たりとして残す |
| エネルギーを増やすカード | ×1.5 | 増える量がそのまま次のカードに使えるため低め |
| 固有スキル | ×1.7〜×2.6 | 固有スキルごとに1つ。覚醒しても同じ上限を使う |
| 武器・防具・アクセサリー | ×1.8〜×2.6 | 回数のある炎のダガーと、木・革の素朴な装備は低め、尖った性能の装備は高め |

カードの説明文は、倍率を掛けた後の値で書く（例：属攻の137%）（[カードの数値の見せ方](combat/cards.md#カードの数値の見せ方)）。

固有スキルは、品質C・倍率×1.00で始まる（2026-10-19）。
商会の[品質強化](enhancement.md#品質強化)で倍率を上げられるようにするため、固有スキルにも種類ごとに上限の倍率を決める。
[覚醒](skill-evolution.md)しても倍率と品質を引き継ぐ。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 倍率の出やすさ | 幅の中での出やすさ（均等にするか、上を出にくくするか）。均等なら、Sは10回に1回出る。上限の倍率は2026-10-20に種類ごとに決めた（[上限の決め方](#上限の決め方)、仮） |
| 品質を上げる手段 | 磨き石の[品質強化](enhancement.md#品質強化)（2026-10-24）と、合成の[出来上がる品質](synthesis.md#出来上がる品質)（2026-10-31）で決めた |
| スキルの付与効果 | 装備の付与効果（[Affix](../catalog/affixes/README.md)）のように、スキルにも1枚ごとに違う効果を付けるか |
| 所持上限 | 分類ごとの上限と、上限に届いたときの扱い |

## 実装との対応

品質の決まりは、2026-10-19に次のとおり実装した。
上限の倍率は、2026-10-20に種類ごとの値にした（[上限の決め方](#上限の決め方)）。

| 対象 | 今の実装 |
|---|---|
| 品質の計算 | サーバー（[quality.ts](../../server/src/shared/quality.ts)）とクライアント（[ItemQuality.cs](../../client/Assets/Baryonyx/Features/Inventory/Runtime/ItemQuality.cs)）が同じ決まりを持つ。倍率は百分率の整数（×1.37なら137）で比べ、境目ちょうどは上の品質に入れる |
| 装備（武器・防具・アクセサリー） | サーバーが1つずつ倍率を持ち、APIが倍率と品質を返す（[持っている装備と付け替えの保存](equipment.md#持っている装備と付け替えの保存)）。初めの装備は×1.00。画面は名前のすぐ右に★と品質・倍率（「★★ C ×1.00」）を出し、説明の数字に倍率を掛ける（[装備の見せ方](../rules/ui-design.md#装備の見せ方)） |
| スキル | 持っているスキルは1枚ずつ倍率を持ち、サーバーの `skill_cards` に保存する（[パーティの実装との対応](party.md#実装との対応)）。カードは倍率と品質を持ち、倍率を掛けたカードを作れる（[CardSkillQuality](../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkillQuality.cs)）。冒険の戦闘のデッキは1枚ごとの倍率を掛ける |
| 固有スキル | 品質C・×1.00で始まる。サーバーは固有スキルごとに倍率を持ち、商会の[品質強化](enhancement.md#実装との対応)で上げられる（2026-10-24）。戦闘のカードは、その倍率を掛けたものになる |
| キラキラ | 品質で層を変える（[カードのキラキラ](../art/direction.md#カードのキラキラ)） |
| 確かめる場所 | [品質のデバッグルーム](screens/debug-rooms.md#品質のデバッグルーム)で、どの物も倍率と上限を動かして、品質の文字・キラキラ・光り方・効果の数字を見られる。[持ち物のデバッグルーム](screens/debug-rooms.md#持ち物のデバッグルーム)で、どの種類も選んだ品質と数でサーバーの持ち物へ足せる |
| アイテム | アイテムは品質を持たない |
