# 装備生成と厳選の変更と判断の記録

[装備生成と厳選](equipment.md)

- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、アクセサリーの効果の未決の範囲、限界突破の呼び名とレベルアップの窓、上限の倍率をドロップなどの抽選に使うことを直した（根拠：client/Assets/Baryonyx/Features/Equipment/Runtime/EquipmentCatalog.cs、server/src/features/adventure/drops.ts の `rollDrops`、server/src/shared/quality.ts の `rollMultiplierPercent`、冒険者の突破のタブ）。
- 2026-10-26：ユーザーの依頼「ミナの初期武器は変えといてほしいです」を受け、ミナの初期の武器を戦鎚（物攻）から樫の杖（属攻）へ替えた。ミナのカード（ヒール・聖なる鉄槌）は属攻で威力が決まり、戦鎚では強くならなかったためである（[戦闘の試し](stage-progression/battle-trials.md#自動対戦の仕組みでの測り直し2026-10-25)）。トーマと同じ樫の杖を2本配るため、サーバーの初期の付与（`STARTER_PIECES`）とローカルの仮データを、同じ種類を複数持てる形にした。
- 2026-10-25：ユーザーの指示で、装備の効果を、付けたキャラのステータスに割合で足す形に決め、戦闘と画面に入れた（[装備の効果](equipment.md#装備の効果)）。カードにはしない。「2回攻撃」のような効果は、戦闘で使ったスキルが2回発動する形に改めた。画面は、左のステータスに上昇分、右の一覧に今の装備と比べた増減を出す（ユーザーが案から選んだ）。
- 2026-10-24：ユーザーの指示で、アクセサリーの枠を開くレベルを仮のLv 15・20・25から、Lv 1（初めから開く）・20・40に改めた。
- 2026-10-24：ユーザーの依頼「売るで実際に装備を売って、ルーン獲得できるようにして」を受け、商会で装備を売れるようにした（[売る](screens/shop.md#売る)）。付けている装備を売れなくすることは、こちらで決めた。
- 2026-10-20：ユーザーの指示により、装備の上限の仮の×1.5（炎のダガーは×1.3）をやめ、種類ごとに×1.8〜×2.6の上限を持たせた。初期データの倍率は、品質S〜Cがそろうよう、各装備の上限の中の同じ位置へ置き直した。
- 2026-10-19：ユーザーの指示「サーバー側のDBスキーマ、コードも更新」により、持っている装備に倍率の列（`multiplier_percent`）を加え（[0012_item_quality.sql](../../server/migrations/0012_item_quality.sql)）、APIが倍率と品質を返すようにした。既にある装備は×1.00にした。
- 2026-10-19：ユーザーの指示により、レア度（☆）を装備の種類ごとに決まる手に入りにくさとし、入手ごとにランダムに決まる強さを品質（S〜C）と倍率で表すことにした（[品質](inventory.md#品質)）。「同じ装備でもレア度をランダムにする」を「品質をランダムにする」に改めた。
- 2026-10-18：ユーザーの依頼で、装備の付け替えを楽観的更新にした（[保存](equipment.md#持っている装備と付け替えの保存)）。保存を待たずに画面に出し、失敗したら戻して知らせる。サーバーのAPIは変えていない。
- 2026-10-06：ユーザーの依頼で、編成の装備を、冒険者の個別の画面から開く付け替えの画面にした（[装備](screens/loadout.md#装備)）。仲間のタブをやめて◀▶で枠を選んだまま人を替え、左にステータスと準備中のアクセサリー3枠を出す。付け替えと保存の決まりは変えていない。
- 2026-10-06：ユーザーの指示により、[アクセサリー](equipment.md#アクセサリー)を加えた。1人に最大3つ付けられ、初めは0枠で、レベルアップで枠が開く。装備は1つずつ倍率を持ち、レア度を☆1〜☆5で表すことにした（[持ち物の分類](inventory.md)）。合成の決まりは[合成](synthesis.md)へまとめた。
- 2026-10-05：ユーザーの依頼で、装備の付け替えを編成の「装備」へ移し、装備の画面を商会（装備・スキル・素材の売買と合成）に作り替えた（[画面一覧](screens/guide.md#編成商会神殿旅の案内所の画面)）。編成で付け替えるのは武器と防具の両方、売買の通貨はルーン、付け替えは最初からサーバーに保存することを、ユーザーが決めた。[保存](equipment.md#持っている装備と付け替えの保存)は、装備を1つずつの行にし、キャラごとに武器1つ・防具1つの枠を持つ形で作った（枠の数とほかのキャラから外す決まりは仮）。合成と売却を採用したことを未決事項に反映した。
- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、装備を基本的にどのキャラでも付けられるものとし、効果量をキャラのステータスの％で決めることにした。冒険で得た装備を負けても保持することと、付け替え時の差分表示を反映した。ダウンの廃止に伴い、戦い方の例からダウン値と追撃を外した。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| 職業ごとに武器・防具の装備適性を制限する | 基本的にどのキャラでも付けられる |
| HPダメージを伸ばす、必要なダウン値に届かせる、追撃を成立させるなど、ダウン寄り・火力寄り・追撃寄りの勝ち方を変える | カードの威力の伸びと戦い方の変化につなげる。ダウンは廃止、追撃の採否は未決 |

- 2026-09-19：参照会話と実装指示により、探索中の装備変更と獲得直後の比較・変更導線を追加した。サンプルの共通武器を完成版の職業適性や装備枠として扱わない。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様に基づき、ダウンや連携を含む戦い方の変化を装備厳選の目的へ加えた。編成を唯一の役割分担へ固定せず、具体的な装備効果は未確定とする。パーティ・戦闘・育成・MVPへ反映する。
