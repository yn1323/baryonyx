# 運動目標と達成報酬

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- ユーザー自身が運動目標を設定する。
- 単純な運動量より、目標を立てて達成することを重視する。
- 未達成のペナルティを設けない。
- 基本運動報酬より、目標設定・達成を伴う報酬が大きくなるバランスを狙う。

## 候補と例

1日8,000歩、週20kmの歩行、30分ランニング、19〜21時の運動、週3回の運動は目標の例であり、初期値・必須条件ではない。
達成時のルーン倍率上昇・ボーナス報酬を想定する。
簡単すぎる目標の係数を下げるなど、難易度との連動は検討中である。
