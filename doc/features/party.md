# キャラクターとパーティ編成

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)と2026-09-15のユーザー提示仕様

## 確定している方針

- パーティは4人固定とする。
- 探索中も仲間を入れ替え、獲得した仲間をすぐに編成できるようにする。
- 前衛・後衛の配置システムは設けない。
- 各キャラクターは固定職業、固有スキル、固有パッシブ、装備可能な武器・防具を持つ。
- 職業に応じて武器・防具の装備適性を制限し、転職は設けない。
- 最初から自由にスキルを付け替える構成は前提にせず、キャラの組み合わせと装備で戦い方を変える。
- 装備・パッシブ・スキル・パーティ構成の組み合わせでシナジーを作る。

## 仮設定と設計方針

初期企画では各キャラ2〜3アクティブを想定していた。
完成版の構成はキャラ設計で詰め、試作時のアクティブ・固有パッシブ数は[最初に作る戦闘試作](../game/mvp.md#最初に作る戦闘試作)に従う。
編成を唯一の役割分担へ固定しない方針は[装備更新と戦い方](equipment.md#戦い方を変える装備更新)で管理する。
