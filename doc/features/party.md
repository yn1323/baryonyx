# キャラクターとパーティ編成

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- パーティは4人固定とする。
- 各キャラクターは固定職業、固有スキル、固有パッシブ、装備可能な武器・防具を持つ。
- 転職システムは今のところ入れない。
- 装備・パッシブ・スキル・パーティ構成の組み合わせでシナジーを作る。
