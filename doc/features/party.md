# キャラクターとパーティ編成

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)、2026-09-15のユーザー提示仕様、[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

## 確定している方針

- パーティは4人固定とする。編成では4つの枠からキャラを外して空きにもできる（2026-10-04、[編成](screens.md#編成)）。
- 探索中も仲間を入れ替え、獲得した仲間をすぐに編成できるようにする。
- 前衛・後衛の配置システムは設けない。
- 装備・パッシブスキル・カードスキル・パーティ構成の組み合わせでシナジーを作る。

### キャラクターの構成

各キャラは次の要素を持つ。

| 要素 | 内容 |
|---|---|
| レベル | ルーンを使ってレベルアップし、ステータスが上がる。パッシブスキルと固有スキルも解放する（[育成](progression.md)） |
| ステータス | キャラ固有の値を持つ。項目は未決 |
| パッシブスキル | 2つ |
| 固有スキル | 2つ。手札とは別に、エネルギーを払っていつでも使える（[戦闘仕様](combat.md#固有スキル)） |
| 装備 | 武器・防具。基本的にどのキャラでも装備できる（[装備](equipment.md)） |
| カードスキル | 4枚。キャラごとに装備できる属性が異なる |

4人のカードスキルを合わせた4人×4枚＝16枚が、戦闘のデッキになる。
属性の種類とカードの使い方は[戦闘仕様](combat.md#属性と弱点)を正本とする。

## 設計方針

決まった役割分担を唯一の正解にしない方針は[装備更新と戦い方](equipment.md#戦い方を変える装備更新)で管理する。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| ステータスの項目 | 未決。すばやさ（[ターン順](combat.md#ターン順)）を持つことだけが決まっている |
| レベルの上限、必要ルーン、パッシブ・固有スキルを解放するレベル | 未決 |
| キャラごとに装備できるカードの属性の組み合わせ | 未決 |
| 装備を「基本的に」どのキャラでも付けられるとした例外の有無 | 未決 |
| カードスキルの入手方法 | 冒険でスキルを獲得できる（[探索と進行](stage-progression.md#分岐ルートを選んで進む冒険)）。ほかの入手方法は未決 |
| キャラの具体的な構成と加入方法 | 未決。召喚からキャラが出る可能性がある（[召喚](monetization.md)） |
| 初期メンバー、未所持枠の扱い | 未決 |
| 同じキャラを複数編成できるか | 未決 |
| 入れ替え・装備変更が可能なタイミング | 探索中に変更できる。戦闘中の変更と、復活画面から変更できるかは未決 |
| 控えメンバーの有無 | 未決 |
| 4人に満たないパーティで冒険に出られるか、最低の人数 | 未決。[編成](screens.md#編成)では仮に1人以上を残し、最後の1人は外せない |

## 確認待ち

既存の仕様と今回の内容のどちらを採るか、開発者の判断が必要な事項である。
回答を得るまで、ほかの仕様や実装へ波及させない。

| 項目 | 既存・旧仕様 | 今回の内容 | 影響する範囲 |
|---|---|---|---|
| 職業の扱い | 各キャラが固定職業を持ち、転職は設けない。職業ごとの役割・得意不得意を定義する | キャラの構成に職業がない。装備は基本的にどのキャラでも付けられ、キャラごとの違いは装備できるカードの属性で表す | 職業を残すか廃止するか。残す場合の役割（カードの属性の組み合わせを職業で決めるかなど）。[職業定義](../catalog/classes/README.md)、[キャラ定義](../catalog/characters/README.md) |

## 変更と判断の記録

- 2026-10-04：ユーザーの依頼で、酒場に[編成](screens.md#編成)の画面を作った。左の4つの枠と右の仲間で入れ替え、ユーザーの指示で仲間の最後に置いた「外す」で枠を空けられる。空きを許すと4人に満たないパーティができるため、冒険に出られる最低の人数を未決事項に加えた。画面では仮に1人以上を残す。編成はアプリを動かしている間だけ残り、保存はしない。
- 2026-09-30：ユーザーと相談し、デッキを12枚から16枚に増やし、カードスキルをキャラごとに4枚にした。毎ターン3枚を引く決まり（[手札](combat.md#手札)）と合わせて、5ターン前後で山札が一巡する枚数にした。
- 2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、キャラの構成（レベル、ステータス、パッシブスキル×2、固有スキル×2、武器・防具、カードスキル×3）と、12枚のデッキ、ルーンによるレベルアップを反映した。装備は基本的にどのキャラでも付けられるとし、職業による装備適性の制限を置き換えた。新しい構成に職業がないため、職業そのものの扱いは確認待ちとした。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| 職業に応じて武器・防具の装備適性を制限する | 装備は基本的にどのキャラでも付けられる。キャラごとの違いは、装備できるカードの属性で表す |
| 各キャラが固定職業・固有スキル・固有パッシブを持ち、転職は設けない | 固有スキル2つとパッシブスキル2つをレベルで解放する。職業の扱いは確認待ち |
| 最初から自由にスキルを付け替える構成は前提にしない | キャラごとに3枚のカードスキルを、装備できる属性の範囲で付け替える |
| 試作では各キャラのアクティブスキルを2つとする | カードスキル3枚と固有スキル2つの構成へ変更 |

- 2026-09-19：参照会話と実装指示により、探索中の仲間変更と獲得直後の編成導線を追加した。ワイヤーのサンプルと本番の加入・編成ルールを区別する。

- 2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、前衛・後衛なし、固定職業による装備適性、固有スキルを中心とする編成を明記した。完成版のスキル構成を試作の数と区別し、MVP・装備・戦闘から参照する。
