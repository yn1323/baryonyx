# 冒険のドロップ

[機能索引](README.md) / [探索とダンジョンの進行](stage-progression.md) / [持ち物の分類、レア度と品質](inventory.md)

冒険で出来事（戦闘・宝箱）を終えたマスでは、物が落ちる。
この文書は、何がどこで・いくつ・どの☆と品質で落ちるかの決まりを記す。
☆（レア度）と品質の意味は[持ち物の分類、レア度と品質](inventory.md)が正本である。

## 確定している方針

2026-10-20、ユーザーとの相談で次を決めた。

### 行き先ごとの一覧

- ドロップは行き先（ダンジョン）ごとに決める。敵ごとには決めない。
- 行き先ごとに、落ちる物の一覧を持つ。一覧の物は、その行き先でしか落ちない。Lv 10の行き先にしかない☆の多い物があり、その品質Sも、その行き先で落ちる。
- 物の強さ（有用性）は、出る行き先のLvに比例させる。奥の行き先の物ほど、基本の効果量が大きい。
- 強い敵のマスと最奥の主のマスは、その行き先の☆の多い物が落ちやすい。最奥の主のマスは☆3〜5だけが落ちる。
- 強化素材（磨き石・覚醒の欠片）は、この抽選とは別に、出来事を終えたマスごとに抽選する（[磨き石の落ち方](enhancement.md#磨き石の落ち方)、2026-10-24）。
- 落ちやすさは、アイテム＞アクセサリー＞武器＝防具＞スキルの順にする。
- 1回に落ちる数にも、ばらつきを入れる。

### 道中でもまれに出る☆4・☆5と品質S

道中の魔物のマスと強い魔物のマスでも、ごくまれに☆4・☆5と品質Sが落ちる。
☆と品質は、行き先ではなくマスの種類で重みを変える。
以前は奥の行き先ほど品質Sの重みを増やしていた（報酬の上がり方）が、物の強さを行き先のLvで決めたため、この補正をやめた。
浅い行き先だけ品質Sを出にくくすると、その行き先にしかない物の品質Sだけが遠くなるためである。

### 持ち物への入れ方

- スキル・武器・防具・アクセサリーは、同じ種類でも1つずつ持ち物に足す。品質が違うため、重なっても捨てない。
- アイテムは、種類ごとの数を1つ増やす。アイテムは品質を持たず、☆だけを持つ（[アイテム](items.md#数え方)）。
- 冒険者は、今の初期データのカスタムスキル2枚（品質C）を持った状態で始める。武器・防具も、初めの4人が付けている8つだけを最初に持ち、ほかは冒険で手に入れる。
- 武器・防具・アクセサリーは、カードの形にせず、今の装備の画面と同じアイコンの形で見せる。アイテムはカードとして戦闘で使う（[アイテム](items.md#戦闘での使い方)）。

## 仮設定

数値はどれも、遊んで確かめるための仮の値である。
正本はサーバーの [drops.ts](../../server/src/features/adventure/drops.ts) で、クライアントの [AdventureDrops](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureDrops.cs) が同じ値を持つ。

### 抽選の順序

出来事を終えると、サーバーが次の順に選ぶ。

1. マスの種類の重みで、落ちる数を選ぶ。
2. 1つずつ、分類を選ぶ。そのマスで落ちうる物がない分類は除き、残りの重みで選ぶ。
3. 分類の中から、物を選ぶ。物1つの重みは、その物の☆に対するマスの重みである。
4. アイテム以外は、マスの重みで品質を選び、その品質の幅から倍率を均等に選ぶ（[品質](inventory.md#品質)）。

### ☆ごとの重み

物1つあたりの重み（千分率）である。
同じ分類に☆1の物が多いほど、☆1が出やすくなる。

| マス | ☆1 | ☆2 | ☆3 | ☆4 | ☆5 |
|---|---|---|---|---|---|
| 魔物 | 550 | 300 | 130 | 17 | 3 |
| 強い魔物・宝箱 | 300 | 380 | 260 | 50 | 10 |
| 最奥の間 | 0 | 0 | 650 | 280 | 70 |

一覧の物には、最奥の間でだけ落ちる物（**主の物**）を置ける。
どの行き先にも、アイテムとアクセサリーの主の物を1つずつ置いた（下の行き先ごとの一覧の表で「（主）」と書いた物）。

### 行き先ごとの一覧

8つの行き先のすべてで、アイテム・アクセサリー・武器・防具・スキルをそろえた。
スキル50枚は強さで8つの行き先へ分け、初めにあった武器・防具14種は浅い3か所へ置いた。
グラシエラ氷窟より奥の6か所は、各行き先にアイテム5つ（☆1×2・☆2・☆3・主の物）、アクセサリー3つ（☆1か☆2・☆3・主の物☆5）、武器2つと防具2つ（☆2〜☆4）を置いた。
グラシエラ氷窟の武器は、初めからある雷鳴の槍・氷晶のワンドを使う。
物の名前と効果は、その行き先の敵（[敵の一覧](../catalog/enemies/README.md)）に合わせた。
効果量は行き先のLvに合わせて大きくした（例：☆1の回復のアイテムは、Lv 10の薬草が属攻の50%、Lv 40の雪割り草が125%）。
2026-10-25に足した70種の値は、遊んで確かめる前の仮の値である。

## 実装との対応

| 項目 | 実装 |

| 絵 | ミストラ遺跡・港町ポルトリアのアイテム・アクセサリーと、初めからある武器・防具の絵がある。Codex CLIで1つずつ描かせ、背景を抜いて32×32・32色に縮め、外周にセルアウトの輪郭を描き直して `.aseprite` にした（[アイテム](../art/direction.md#画面と寸法)の寸法）。縮めるときは区画で一番多い色を使い、平均で色が濁らないようにした |
| 旅の案内所のお宝 | 行き先の一覧を、旅の案内所の行き先ごとのお宝の窓に並べ、ライブラリの見つけた記録で見つけた数を数える（[旅の案内所のお宝](screens/guide.md#編成商会神殿旅の案内所の画面)、[TravelTreasures](../../client/Assets/Baryonyx/Features/TravelOffice/Runtime/TravelTreasures.cs)） |
| 持ち物を編成で使う | 落ちたスキルとアイテムは、編成のカスタムスキルの枠に入れられる（[実装との対応](party.md#実装との対応)）。`GET /v1/party` が持っているスキルとアイテムを返す |
| 1つずつの絵 | 種類のIDから絵を引くデータ（[ItemArt](../../client/Assets/Baryonyx/Features/Inventory/Presentation/ItemArt.cs)、生成は [ItemArtAssets](../../client/Assets/Baryonyx/Features/Inventory/Editor/ItemArtAssets.cs)）を、装備の画面・育成の装備の欄・編成のスキルの画面のアイテム・ライブラリ・宝箱のダイアログ・戦闘の勝利で落ちた物を見せる札が使う。スキルは、戦闘のカードの挿絵（`Combat/UI/Art/Card<ID>.aseprite`）を同じデータに入れ、落ちた物を見せる札と宝箱のダイアログに出す。絵は整数倍で出す（[PixelIcon](../../client/Assets/Baryonyx/Shared/UI/PixelIcon/PixelIcon.cs)。装備の行の72pxの枠では2倍の64px） |
| 絵のない物 | 絵の `.aseprite` がない種類は、ItemArtの生成で飛ばされ、絵を引くと null が返る。どの画面も null を受けて絵の欄を隠すか分類のアイコンに替え、名前・☆・効果はふつうに出す。落ちた物を見せる札と編成のスキルの画面のアイテムは、絵の欄が空になる。宝箱のダイアログの絵は、落ちた物のうち絵のある一番☆の多い物になり、どれにも絵がなければ出ない。装備の画面と育成の装備の欄は、武器・防具の枠のアイコンを出す（育成のアクセサリーの欄は空）。ライブラリと商会の行は、アイテムの絵が空、武器は武器のアイコン、防具とアクセサリーは防具のアイコンになる |
| 生成し直すもの | ライブラリの見つけた記録の一覧（LibraryData）と旅の案内所のお宝の窓は、Editorのメニューで生成したデータを使う。足した種類をライブラリ・商会の買う・合成・お宝の窓に出すには、`Baryonyx > Library > Create Screen Assets` と `Baryonyx > Travel Office > Create Screen Assets` で作り直す。作り直すまで、お宝の窓の見つけた数（例：0/21）は足した物を数えるが、並ぶ札は前のままになる |
| 付けること・戦闘で使うこと | 2026-10-25から、アクセサリーは装備の3つの枠に付けられ（[持っている装備と付け替えの保存](equipment.md#持っている装備と付け替えの保存)）、アイテムはカスタムスキルの枠から戦闘のデッキに入る（[アイテム](items.md#実装との対応)） |

## 変更と判断の記録

- 2026-10-25：ユーザーの依頼で、グラシエラ氷窟より奥の6か所に、アイテム・アクセサリー・武器・防具を作って一覧に入れた。行き先ごとの数（アイテム5つ・アクセサリー3つ・武器2つ・防具2つと、それぞれの☆）・名前・効果・上限の倍率は、行き先の敵とLvに合わせてこちらで決めた仮の値である。
