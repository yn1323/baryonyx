# 冒険のドロップ

[機能索引](README.md) / [探索とダンジョンの進行](stage-progression.md) / [持ち物の分類、レア度と品質](inventory.md)

冒険で出来事（戦闘・宝箱）を終えたマスでは、物が落ちる。
この文書は、何がどこで・いくつ・どの☆と品質で落ちるかの決まりを記す。
☆（レア度）と品質の意味は[持ち物の分類、レア度と品質](inventory.md)が正本である。

## 確定している方針

2026-10-20、ユーザーとの相談で次を決めた。

### 行き先ごとの一覧

- ドロップは行き先（ダンジョン）ごとに決める。敵ごとには決めない。
- 行き先ごとに、落ちる物の一覧を持つ。一覧の物は、その行き先でしか落ちない。Lv 10の行き先にしかない☆の多い物があり、その品質Sも、その行き先で落ちる。
- 物の強さ（有用性）は、出る行き先のLvに比例させる。奥の行き先の物ほど、基本の効果量が大きい。
- 強い敵のマスと最奥の主のマスは、その行き先の☆の多い物が落ちやすい。最奥の主のマスは☆3〜5だけが落ちる。
- ACTボーナスだけは、どの行き先でも落ちる。ただし出にくくする。
- 落ちやすさは、アイテム＞アクセサリー＞武器＝防具＞スキル＞ACTボーナスの順にする。
- 1回に落ちる数にも、ばらつきを入れる。

### 道中でもまれに出る☆4・☆5と品質S

道中の魔物のマスと強い魔物のマスでも、ごくまれに☆4・☆5と品質Sが落ちる。
☆と品質は、行き先ではなくマスの種類で重みを変える。
以前は奥の行き先ほど品質Sの重みを増やしていた（報酬の上がり方）が、物の強さを行き先のLvで決めたため、この補正をやめた。
浅い行き先だけ品質Sを出にくくすると、その行き先にしかない物の品質Sだけが遠くなるためである。

### 持ち物への入れ方

- スキル・武器・防具・アクセサリーは、同じ種類でも1つずつ持ち物に足す。品質が違うため、重なっても捨てない。
- アイテムは、種類ごとの数を1つ増やす。アイテムは品質を持たず、☆だけを持つ（[アイテム](items.md#数え方)）。
- ACTボーナスは、1種類につき1つだけ持ち、倍率の高いほうを残す（[ACTボーナス](step-bonus.md#ボーナスの入手レア度と品質)）。
- 冒険者は、今の初期データのカスタムスキル2枚（品質C）を持った状態で始める。武器・防具も、初めの4人が付けている8つだけを最初に持ち、ほかは冒険で手に入れる。
- 武器・防具・アクセサリーは、カードの形にせず、今の装備の画面と同じアイコンの形で見せる。アイテムはカードとして戦闘で使う（[アイテム](items.md#戦闘での使い方)）。

## 仮設定

数値はどれも、遊んで確かめるための仮の値である。
正本はサーバーの [drops.ts](../../server/src/features/adventure/drops.ts) で、クライアントの [AdventureDrops](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureDrops.cs) が同じ値を持つ。

### 抽選の順序

出来事を終えると、サーバーが次の順に選ぶ。

1. マスの種類の重みで、落ちる数を選ぶ。
2. 1つずつ、分類を選ぶ。そのマスで落ちうる物がない分類は除き、残りの重みで選ぶ。
3. 分類の中から、物を選ぶ。物1つの重みは、その物の☆に対するマスの重みである。
4. アイテム以外は、マスの重みで品質を選び、その品質の幅から倍率を均等に選ぶ（[品質](inventory.md#品質)）。

### ☆ごとの重み

物1つあたりの重み（千分率）である。
同じ分類に☆1の物が多いほど、☆1が出やすくなる。

| マス | ☆1 | ☆2 | ☆3 | ☆4 | ☆5 |
|---|---|---|---|---|---|
| 魔物 | 550 | 300 | 130 | 17 | 3 |
| 強い魔物・宝箱 | 300 | 380 | 260 | 50 | 10 |
| 最奥の間 | 0 | 0 | 650 | 280 | 70 |

一覧の物には、最奥の間でだけ落ちる物（**主の物**）を置ける。
ミストラ遺跡の守り手の種・守り手の葉冠、港町ポルトリアの海賊のラム酒・大ダコの黒真珠が主の物である。

### 品質の重み

千分率である。アイテムは品質を持たない。

| 強い魔物・宝箱 | 400 | 350 | 210 | 40 |

### 行き先ごとの一覧

まず、ミストラ遺跡と港町ポルトリアの2か所で、アイテム・アクセサリー・武器・防具・スキルをそろえた。
遊んで確かめてから、残りの6か所へ広げる。
スキル50枚は強さで8つの行き先へ分け、武器・防具は今ある14種を浅い3か所へ置いた。
残りの行き先は、アイテム・アクセサリーと、グラシエラ氷窟より奥の武器・防具がまだない。
落ちうる物がない分類は抽選から除くため、その行き先ではスキルとACTボーナスが落ちる（グラシエラ氷窟は武器も落ちる）。

## 実装との対応

| 項目 | 実装 |
|---|---|
| マスの種類と報酬の行 | 2026-10-22に足したマス（休憩・行商人・怪しい宝箱・試練・歩数の扉・進化の祭壇）は、[落ちる数](#落ちる数)などの表の行を借りる。どの行を借りるかと、中身を作るまでの仮の扱いは[マスの中身](stage-progression.md#マスの中身仮)と[実装との対応](stage-progression.md#実装との対応)に記す（`rewardOf`） |
| 抽選と一覧 | サーバーの [drops.ts](../../server/src/features/adventure/drops.ts)。マスを終える処理（[repository.ts](../../server/src/features/adventure/repository.ts) の `clear`）が抽選し、落ちた物の記録・持ち物への追加・ライブラリの見つけた記録を1回のbatchで書く |
| 落ちた物の記録 | `adventure_drops`（[0013_drops.sql](../../server/migrations/0013_drops.sql)）。1つのマスに落ちた数だけ行を持つ |
| 持ち物 | スキルは `skill_cards`（1枚ずつ、倍率つき）、アイテムは `item_holdings`（種類ごとの数）、アクセサリーは武器・防具と同じ `equipment_items` |
| API | `POST /v1/adventure/clear` は、そのマスの `drops`（分類・ID・倍率・品質・outcome）を返す。冒険と結果の `drops` は、その冒険で落ちた物すべてである。アイテムは倍率と品質の項目を持たない |
| クライアント | 勝利・宝箱のダイアログは落ちた物を1行ずつ（☆・名前・分類・品質）並べ、結果は分類ごとの数と、☆4以上か品質Sの物を「目玉」として出す（[AdventureTexts](../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureTexts.cs)）。サーバーなしの冒険（AdventureLocalSource）も同じ抽選を使う |
| 絵 | Codex CLIで1つずつ描かせ、背景を抜いて32×32・32色に縮め、外周にセルアウトの輪郭を描き直して `.aseprite` にした（[アイテム](../art/direction.md#画面と寸法)の寸法）。縮めるときは区画で一番多い色を使い、平均で色が濁らないようにした |
| 旅の案内所のお宝 | 行き先の一覧（ACTボーナスを除く）を、旅の案内所の行き先ごとのお宝の窓に並べ、ライブラリの見つけた記録で見つけた数を数える（[旅の案内所のお宝](screens.md#編成商会神殿旅の案内所の画面)、[TravelTreasures](../../client/Assets/Baryonyx/Features/TravelOffice/Runtime/TravelTreasures.cs)） |
| 持ち物を編成で使う | 落ちたスキルとアイテムは、編成のカスタムスキルの枠に入れられる（[実装との対応](party.md#実装との対応)）。`GET /v1/party` が持っているスキルとアイテムを返す |
| 1つずつの絵 | 種類のIDから絵を引くデータ（[ItemArt](../../client/Assets/Baryonyx/Features/Inventory/Presentation/ItemArt.cs)、生成は [ItemArtAssets](../../client/Assets/Baryonyx/Features/Inventory/Editor/ItemArtAssets.cs)）を、装備の画面・育成の装備の欄・編成のスキルの画面のアイテム・ライブラリ・宝箱のダイアログ・戦闘の勝利で落ちた物を見せる札が使う。絵は整数倍で出す（[PixelIcon](../../client/Assets/Baryonyx/Shared/UI/PixelIcon/PixelIcon.cs)。装備の行の72pxの枠では2倍の64px） |

## 変更と判断の記録

- 2026-10-20：ユーザーの依頼「ドロップ周りを整備したい」から、敵とダンジョンで☆と品質をどう扱うかを相談した。ユーザーは「敵ごとはやりすぎ」として行き先ごとの一覧を選び、強い敵と主のマスの物は決めておきたい、Lvとスキルの有用性は比例させたい、Lv 10の行き先にしか出ない☆の多い物とそのSがあってよい、ほかの行き先ではそれを出さない、とした。道中・強敵でも極まれに☆4・5と品質Sが出ること、主のマスは☆3〜5、行き先による品質の補正をやめること、落ちやすさの順、ACTボーナスはどこでも出るが出にくいこと、重なったスキルも持ち物に足すこと、アイテムは品質なしで☆ありのカードとして戦闘で使うこと、1回に落ちる数にばらつきを入れること、武器・防具・アクセサリーはカードの形にしないことも、ユーザーが決めた。数値と一覧の中身は、提案した仮の値である。
