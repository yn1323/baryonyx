# 探索とダンジョンの進行：道とマスの種類・中身

[探索とダンジョンの進行](../stage-progression.md)

## 確定している方針

### マスの種類

2026-10-21、ユーザーは、魔物・宝箱・主だけでは少ないとして、次のマスを足すと決めた。
数値と出し方は[マスの中身](#マスの中身仮)と[道の決まり](#道の決まり仮)の仮の値で始め、遊んで直す。

| マス（ID） | 中身 | 決めたこと |
|---|---|---|
| 魔物（`battle`） | 戦闘 | 既存 |
| 強い魔物（`elite`） | 強い戦闘 | 既存 |
| 宝箱（`treasure`） | ドロップと、固有スキルの覚醒 | 既存 |
| 最奥の間（`boss`） | 最奥の主との戦闘 | 既存 |
| 休憩（`rest`） | HPを回復する | 必要（ユーザー） |
| 行商人（`merchant`） | スキルと装備を買う | 交換ではなく購入でよい。Homeの商会と違う品ぞろえで、毎回変わる（ユーザー） |
| 怪しい宝箱（`shady-chest`） | ミミックかもしれない宝箱 | 危険に見合う大きな報酬にする（ユーザー） |
| 試練（`trial`） | 条件つきの戦闘 | 危険に見合う大きな報酬にする（ユーザー） |
| 歩数の扉（`step-door`） | 今日の歩数が多いほど報酬が増える | 採用（ユーザー） |
| 覚醒の祭壇（`altar`） | 固有スキルを1段覚醒させる | めったに出ないマスにし、冒険を始めたときに5%の確率で地図に1つ置く（ユーザー） |
| 「？」（`mystery`） | 入るまで中身が分からない。魔物・宝箱・行商人・休憩のどれか | 採用（2026-10-24、ユーザー） |

行商人は、以前に挙げた「商人」を兼ねる。
2026-10-24、ユーザーは「？」を入れ、休憩で休むか鍛えるかを選べるようにすると決めた。
「出来事」（選択肢のある短い話）と「見通しの泉」（先のマスの中身を見せる）は入れていない（[未決事項](status.md#未決事項)）。

## 設計方針

### 冒険の道の作り方

2026-10-04に、次の形で実装した（[計画](../../plans/2026-10-04-exploration-route-map.md#実装したこと)）。
階ごとの決まりと見える距離は、遊んで確かめるための仮の値である。

- 冒険を始めると、サーバーが道を作る乱数の種を決め、冒険と一緒に保存する。端末は、種とマスの数から毎回同じ道を作り、道そのものはどこにも保存しない。中断して再開しても、別の端末でも、同じ道になる。
- 道の進み具合（今いるマス・通ったマス・出来事を終えたか）は、これまでどおりサーバーに保存する。マスを選ぶと、端末はそのマスの階と種類をサーバーへ送り、サーバーは1階ずつ進むことと、最奥の階にだけボスがいることを確かめる。
- 2026-10-04の実装では、道はあみだくじの形で、平行な3〜4本の道が蛇行しながら奥へ進み、隣の道の次の階へ移る横道でつながる。横道は交差させず、マスの札が重ならないよう道同士の間隔に下限を設ける。
- 2026-10-21、ユーザーは、平行な3本の道では単純すぎるとして、スクロールが必要なくらい複雑にすると決めた。入口から2〜3本に分かれ、枝分かれと合流をくり返して、多い階では5〜6本の道筋が並ぶ網の目にする（仮）。階ごとのマスの数は2〜6で変わり、行き止まりは作らない。道は交差させない。画面に入るのは5〜6階ぶんで、地図を左右に動かして先を見る（地図のレイアウトは同じ日に[地図の作り直し](run.md#地図の作り直し2026-10-21)のとおり決めた）。
- 2026-10-24、ユーザーは、あみだくじのような道が分かりにくいとして、直線で分かりやすくすると決めた。マスは地図を左から右へ走る5本の列の上に立ち、同じ階のマスは縦に揃える。入口と最奥の間は真ん中の列に置く。入口の次の階は真ん中の両隣の2列か、真ん中と両隣の3列である。そこから先の道は、同じ列を真っすぐ進むか、隣の列へ斜めに移るか、両隣の列へ2つに分かれ、同じ列に着いた道は合流する。列を飛ばす道と交差する道は作らない。階ごとのマスの数は2〜4にした（仮。真っすぐ・斜め・分かれるの重みは5:3.2:1.8）。
- 階ごとのマスの種類は[道の決まり](#道の決まり仮)に従う。2026-10-04の実装では、マスの種類は魔物・強い魔物・宝箱・最奥の間の4つだった。

道のマスの種類は端末が作るため、端末を書き換えれば、選ぶマスの種類（ドロップの数・☆・品質の重み）を変えられてしまう。
ユーザーが「途中の進捗はUnity内に保存する形でOK」としたため、サーバーで道を作り直して確かめる処理は入れていない（[確認待ち](status.md#確認待ち)）。

### 道の決まり（仮）

2026-10-21、ユーザーの「マスの種類と道の決まりを…ルール化よろ」を受けて決めた仮の値である。
道は冒険の種から端末が作るため、決まりはclientの [AdventureRouteMap](../../../client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureRouteMap.cs) が持ち、サーバーは受け取ったマスの種類が[置ける階](#置ける階)にあることを確かめる。
階は、道中の最初の階（第2層）を1つ目、最奥の直前の階を最後と数える。
道中の階の数を`N`とすると、最初のダンジョン（N=8）では、1つ目が第2層、真ん中（`N/2`つ目の次、5つ目）が第6層、最後が第9層である。

#### 決まった階

| 階 | その階のマスはすべて | 理由 |
|---|---|---|
| 1つ目（第2層） | 魔物 | 最初の戦闘で手札と流れを見せる |
| 真ん中（第6層） | 宝箱 | 道中の折り返しで必ず報酬を得る（Slay the Spireも幕の中ほどに宝箱を置く） |
| 最後（第9層） | 休憩 | HPを持ち越すため、主の前で立て直せるようにする（Slay the Spireも主の前に休憩を置く） |

#### 置ける階

決まった階以外の階では、次の重みでマスを選ぶ。
置けない階では、そのマスの重みを0にする。

| マス | 重み | 置ける階 |
|---|---|---|
| 魔物 | 45 | 2つ目から |
| 強い魔物 | 15 | 3つ目から |
| 宝箱 | 8 | 2つ目から |
| 怪しい宝箱 | 8 | 3つ目から |
| 試練 | 7 | 4つ目から |
| 休憩 | 6 | 4つ目から |
| 行商人 | 6 | 3つ目から |
| 歩数の扉 | 5 | 3つ目から |
| 「？」 | 10 | 3つ目から |

#### 道全体の決まり

- 道でつながった2つのマスに、魔物以外の同じ種類を続けない。強い魔物と試練も続けない（どちらも重い戦闘のため）。
- 真ん中の宝箱の階と最後の休憩の階の隣の階には、宝箱と休憩を置かない。
- 強い魔物を地図全体で2つ以上置く（道中が6マス以上のとき。既存の決まり）。
- 行商人と歩数の扉は、それぞれ地図全体で1〜2つにする。足りなければ、3つ目以降の魔物を置き換え、多ければ魔物に戻す。
- 強い魔物・行商人・歩数の扉が足りず、並びの決まりを守って置き換えられる魔物のマスがないときは、宝箱・怪しい宝箱・休憩・試練・「？」のマスを置き換える（2026-10-24、階ごとのマスを2〜4に減らして、魔物のマスだけでは足りない地図が出たため）。
- 覚醒の祭壇は、冒険を始めたとき（道を作るとき）に5%の確率で、地図に1つだけ置く。置くときは、決まった階以外の道中のマスを1つ選んで置き換える。強い魔物・行商人・歩数の扉が足りなくなる置き換えはしない（2026-10-22、ユーザーの「ダンジョンに入ったときに５%の確率で１つ生成にして」による。マス1つごとに5%とした前日の読み方では、約7割の冒険で地図に出ていた）。
- 横道の決まり（交差させない、間隔の下限）は[冒険の道の作り方](#冒険の道の作り方)のとおりとする。

### マスの中身（仮）

報酬の重みは[冒険のドロップ](../drops.md#仮設定)の表の行を借りる。
「強い報酬」は強い魔物・宝箱の行、「最大の報酬」は最奥の間の行を指す（主の物は最奥の間でだけ落ちるため、最大の報酬にも入れない）。

| マス | 入ったときに起きること | 報酬 |
|---|---|---|
| 休憩 | 「休む」「鍛える」「研鑽」から選ぶ。選ぶまで先へ進めない。休むと、全員のHPを最大HPの40%回復し、倒れた味方は最大HPの40%で起き上がる。鍛えると研鑽は下の[休憩の鍛える](#休憩の鍛える仮) | なし |
| 「？」 | 入ったときにサーバーが中身を魔物45%・宝箱25%・行商人15%・休憩15%から選び、そのマスとして起きる。着くと中身の種類を知らせる | 中身の種類のとおり |
| 行商人 | 品物の一覧を開く。何個でも買え、買わずに出てもよい | 買った物 |
| 怪しい宝箱 | 開けるか、開けずに通り過ぎるかを選ぶ。開けると半分の確率で宝箱ミミックとの戦闘になる | ミミックなら勝つと最大の報酬。本物なら強い報酬で、落ちる数を1つ増やす。通り過ぎると何もない |
| 試練 | 条件を1つ見せてから戦う。敵は強い魔物と同じ強さ | 条件を満たして勝つと最大の報酬。満たさずに勝つと魔物の報酬 |
| 歩数の扉 | 今日の歩数で、扉の向こうの報酬が決まる | 下の表 |
| 覚醒の祭壇 | パーティの固有スキル8枚から1枚を選び、1段覚醒させる（[宝箱の覚醒](../skill-evolution/rules.md#覚醒が起きる場面)と同じ手順） | 覚醒。進められる固有スキルがなければ、宝箱と同じドロップ |

- 怪しい宝箱がミミックかどうかと、試練の条件は、そのマスを開けた・入ったときにサーバーが決めて冒険に保存し、中断して再開しても変わらない（[冒険中の状態の保存先](run.md#冒険中の状態の保存先)）。
- ミミックは、敵の[宝箱ミミック](../../catalog/enemies/enemy-chest-mimic.md)に、行き先の小さな敵1体を加え、強い魔物と同じ強さにする。
- 試練の条件の候補は、「6ターン以内に勝つ」「誰も倒れずに勝つ」「HPを全員半分以上残して勝つ」の3つとする。
- 行商人の品ぞろえは、その行き先の[ドロップの一覧](../drops.md#行き先ごとの一覧)から、スキル3つと装備（武器・防具・アクセサリー）2つを、マスに入ったときにサーバーが選んで保存する。☆と品質は強い報酬の重みで選ぶ。Homeの[商会](../screens/shop.md#商会)の品物とは別の一覧で、冒険ごとに変わる。値段はルーンで払い、額は仮の値とする（[実装との対応](status.md#実装との対応)の行商人、[ルーンの用途](../economy.md#ルーンの用途)）。

#### 休憩の鍛える（仮）

2026-10-24、ユーザーは、休憩で回復の代わりに選べるものを「鍛える」にし、仲間とカードの両方を鍛えられるようにすると決めた（Slay the Spireの休憩所の「鍛える」を参考にした）。
鍛えた効果はその冒険のあいだだけ続き、冒険が終わると消える。育成の手応えを、冒険の外の成長と分けるためである。

同じ日にユーザーは、仲間の成長とカードの強化が1つの「鍛える」に混ざっているとして、休憩の選択肢を「休む」「鍛える」（仲間）「研鑽」（カード）の3つに分けると決めた。

| 選ぶもの | 効果 | 決まり |
|---|---|---|
| 休む | 全員のHPを最大HPの40%回復し、倒れた味方も起き上がる | これまでの休憩と同じ |
| 鍛える | 仲間1人の物攻・属攻を15%上げる | 休憩のたびに重ねられる（2回で30%） |
| 研鑽 | 仲間1人のカードスキル1枚の威力（ダメージ・回復・ブロックの割合）を30%上げ、名前に「+」を付ける | 1枚につき1回まで。コストと回数は変えない。固有スキルは戦闘中に覚醒して別の段階に変わるため、研鑽できない |

数値は仮の値で、遊んで直す。
同じカードスキルを同じ仲間が2枚持つときは、どちらも研鑽したカードになる。
選ぶ画面は文字だけのダイアログにせず、絵で選ぶ（ユーザー）。見た目と操作は[冒険の画面](../screens/adventure.md#冒険の画面)の焚き火に書く。画面の案は `output/rest-ui-concepts/`（Git対象外）にある。

#### 歩数の扉の報酬

今日の歩数は、サーバーが持つその日の歩数（[起動時の連携と歩数の同期](../startup-sync.md)）を使い、扉のマスを終えたときにサーバーが判定する。
段の歩数は、廃止した[ACTボーナス](../../archive/step-bonus.md)の段階の候補に合わせて決めた。
歩いていなくても扉は開き、少ない報酬を得る（[運動しないと遊べないゲームにはしない](../../game/overview.md#確定している方針)）。

| 今日の歩数 | 報酬 |
|---|---|
| 3,000歩未満 | 魔物の報酬 |
| 3,000〜4,999歩 | 強い報酬 |
| 5,000〜7,999歩 | 強い報酬で、落ちる数を1つ増やす |
| 8,000歩以上 | 最大の報酬 |
