# クライアントアセット展示室：横画面と戦闘・デバッグルームの確かめ方

[クライアントアセット展示室](../showcase.md)

## 横画面UIの確認

横画面のレスポンシブ対応は、`HomeScreen` Prefabを選び、背景が比率を保って表示されることを確認する。
タイトル画面はシーンカテゴリの `Top` を開き、`TopCanvas > TopScreen > TopSafeArea` 配下のタイトルと開始操作が画面端から離れていることを確認する。
展示室のカタログには `HomeScreen` Prefab、Health Connectの連携モーダル `HealthLinkModal` Prefab、`Top` シーンを登録済みである。
連携モーダルは、未許可の状態の文言を表示する。
戦闘画面のモックは、シーンカテゴリの `BattleLab`、`BattleInspectScreen` Prefab、味方4人と敵3体の画像で確認する。
2026-10-19に試作した敵50体の絵（`DewSlime` など、`Features/Combat/UI/Art/Enemies/`）も、戦闘のモックの敵3体と同じく一覧に並ぶ。名前と弱点は[敵の定義](../../catalog/enemies/README.md)にある。
冒険の戦闘で敵を入れ替えるための、53体の絵・狙える範囲・顔の表（`BattleEnemyLooks`）は、戦闘画面の生成（`Baryonyx > Combat > Create Battle Inspect Assets`）が作る。行き先ごとの敵は[行き先と敵](../stage-progression/destinations.md#行き先と敵)にある。
カードの挿絵の手前に重ねる[キラキラ](../../art/direction.md#カードのキラキラ)は、`CardFoil`（シェーダーとマテリアル、`Shared/UI/Cards/`）、枠の光は `CardFrameFoil` で、効果は `BattleCardGallery` Prefabで確かめる。ギャラリーは50枚を品質S・A・B・Cの順にくり返して、それぞれの品質の中ほどの倍率で並べ、Sは強く光って枠が虹、Aは少し光って枠の外側の線が金、B・Cは光らない（[品質](../inventory.md#品質)）。光り方（模様と色）はカードごとに違う。装備の光り方は、[品質のデバッグルーム](../screens/debug-rooms.md#品質のデバッグルーム)で確かめる。装備（`Equipment`・`Training`）の仮データは倍率×1.00（品質C）だけのため、Prefabのままでは光らない。光は時間で動くため、停止中のプレビューではSceneビューの描画が進むときだけ動く。
カードを上げたときに横に出す[キーワード](../combat/cards.md#カードのキーワード)の説明札は、`BattleInspectScreen` Prefabのプレビューで「キーワードの説明札」（敵向けのカードで左に出す）か「キーワードの説明札（味方向け）」（右に出す）を選ぶか、展示室から `BattleLab` シーンを開き、説明文に水色の下線の語があるカード（アイスランスなど）を押して確かめる。
味方と敵のドット絵のHPバーは、`BattleInspectScreen` Prefabのプレビューで確認する。HPが減るときの残像と、HPバーに重ねるブロックの黄色のバーは、プレイ中にしか出ないため、プレビューには映らない。展示室から `BattleLab` シーンを開き、残像は攻撃のカードで敵を攻撃するかターン終了で敵の攻撃を受けて、味方のブロックはガードかシールドバッシュを使って確かめる。敵のHPバーのブロック（2026-10-22に足した、敵の技の身を固めるなど）は、`EnemyLab` で森の守り手を選んで「技」を押し続けるか、「大技（溜め）」を押して確かめる。
味方が倒れたときに、その味方の手札のカードが崩れて消える演出（[倒れた味方](../combat/rules.md#倒れた味方)）も、プレイ中にしか出ない。展示室から `BattleLab` シーンを開き、ターン終了をくり返して敵の攻撃で味方を倒して確かめる。崩れる絵と粒はコードがその場で作るため、展示室に増えるアセットはない。
ターンの終わりに残った手札が光の玉になって捨て札へ飛ぶ演出（[手札が捨て札へ流れる演出](../screens/battle-effects.md#手札が捨て札へ流れる演出)）も、プレイ中にしか出ない。展示室から `BattleLab` シーンを開き、カードを残したままターン終了を押して確かめる。光の形はコードがその場で作るため、展示室に増えるアセットはない。
カードの使い手の足元に出す金の輪は、`CasterRing` で確認する。輪と名前の札はカードを上げている間だけ出るため、`BattleInspectScreen` Prefabのプレビューには映らない。動きは展示室から `BattleLab` シーンを開き、カードを押して確かめる。
山札・捨て札・消滅を押して開く[カードの一覧](../screens/battle.md#山札と捨て札の一覧)は、`BattleInspectScreen` Prefabのプレビューで「山札の一覧」を選んで確かめる（初めの手札に配られていない11枚をコスト順に並べた1コマ）。カードを押したときの拡大は「山札の一覧（カードを拡大）」で、1枚目を中央に大きくした止まった1コマを見る。覚醒が当たったカードの光は「山札の一覧（覚醒するカード）」で、1枚目を光らせた1コマを見る。山札にそのカードがあるときの山札の札のキラーンは「山札のキラーン（覚醒するカードがある）」で、大きい星が最も大きくなった1コマを見る。捨て札と消滅の一覧、見出しを固定したスクロールと閉じる操作、拡大の動きはプレイ中にしか出ないため、展示室から `BattleLab` シーンを開き、ターン終了で捨て札を作ってから押して確かめる。一覧は戦闘のカードのPrefabを複製して並べるため、展示室に増えるアセットはない。
ターンの始まりに画面の中央へ出す帯（`TurnBanner`）も `BattleInspectScreen` Prefabに入っているが、ターンが切り替わるときだけ出るため、プレビューには映らない。展示室から `BattleLab` シーンを開き、戦闘の開始時と、ターン終了を押したときに確かめる。ターン終了を2回押すと、連続ターンの「もう一度 味方のターン」も出る。
ダメージ・弱点・会心・回復の数字と状態の帯は、プレイ中に浮かんで消えるだけで `BattleInspectScreen` には映らないため、戦闘の背景の上に並べた `BattleDamageNumbers` Prefabで確認する。上の段に通常・弱点・会心・弱点＋会心・回復の数字、下の段に状態の帯（出血・毒×2・防御ダウン・やけど・凍結で動けない）を並べる。
カードを使ったときのスキルの演出は、`BattleSkillVfxPreview` Prefabで確認する。戦闘の背景に味方と敵を並べ、[スキルの仮設定](../combat/cards.md#スキルの仮設定)の50枚の演出を、それぞれの使い手と対象で順に繰り返し再生する（2周目ごとに弱点の当たりとして大きく出す）。画面の上に、再生中のカードの番号と名前を出す。やけど・毒・出血・リジェネ・爆炎の刻印・雷雲は、続けて働くときの演出も再生する。1枚だけを見るときは、Play中に `BattleSkillVfxDemo` の `Only` にカードのID（`Meteor` など）を入れ、途中から見るときは `First` に番号を入れる。
好きなスキルを一覧から選んで再生するときは、シーンのカテゴリから `CardSkillLab` を開く（[スキルのデバッグルーム](../screens/debug-rooms.md#スキルのデバッグルーム)）。戦闘と同じ3Dの舞台とポストプロセスで再生するため、Bloomも映る。右上を「覚醒：入」にして固有スキルの最初の段階か1段目を選ぶと、カードが魔法陣で浮いてひびが入り、[覚醒先を選ぶ画面](../skill-evolution/effects.md#覚醒先を選ぶ画面)で選んだ段階に割れて覚醒する（[覚醒のエフェクト](../skill-evolution/effects.md#覚醒のエフェクト)）。覚醒のエフェクトは計算で描く形と、戦闘のカードのPrefabの複製だけで作るため、展示室に増えるアセットはない。選択画面は `CardSkillLabScreen` の中にあり、開いていないときは何も表示しない。選んだ候補の後ろの白金の後光の靄は、シェーダー `BattleCardAura` とマテリアル `VfxCardAura`（`Features/Combat/Vfx/`）で描く。靄は時間で形が変わるため、揺らぎはPlay Modeの選択画面で確かめる。決めるボタンのチェックの絵（`ConfirmCheck`、`Features/Combat/UI/Art/`）も一覧に並ぶ。同じ選択画面は戦闘画面のPrefab `BattleInspectScreen` にも入っており、冒険の戦闘で固有スキルが覚醒するときに開く。冒険の外の `BattleLab` では抽選しないため開かない。
引いたときに当たったカードの手札の光（[覚醒の予兆](../skill-evolution/rules.md#覚醒の予兆)）は、`BattleInspectScreen` Prefabのプレビューで、停止中の表示の切り替えの「覚醒の予兆（光るカード）」を選んで確かめる（初めの手札の1枚を光らせた1コマ）。光はコードがその場で作るため、展示室に増えるアセットはない。息づく光と瞬き・表を向いたときの瞬きは、冒険の戦闘でしか出ない。同じ画面のPrefab `CardSkillLabScreen` も一覧に並ぶ。スキルの[覚醒版](../skill-awakening.md#演出)の100の段階は、一覧の「覚醒版」のタブから選んで再生する（停止中は「一覧を開いた（覚醒版）」で並びを確かめる）。演出は計算で描く形だけで作るため、展示室に増えるアセットはない。
スキル・固有スキル・武器・防具・アクセサリーの倍率を動かして、品質の文字・キラキラ・効果の数字を確かめるときは、シーンのカテゴリから `QualityLab` を開く（[品質のデバッグルーム](../screens/debug-rooms.md#品質のデバッグルーム)）。同じ画面のPrefab `QualityLabScreen` は、停止中の表示の切り替えでスキル・武器・ボーナスを品質ごとに見られる。ホームの設定の下の、[デバッグルームの一覧](../screens/top-home.md#デバッグルームの一覧)を出すボタンのアイコン（`IconDebugRooms`、`Features/Home/UI/Art/`）も一覧に並ぶ。
[持ち物のデバッグルーム](../screens/debug-rooms.md#持ち物のデバッグルーム)と[冒険のデバッグルーム](../screens/debug-rooms.md#冒険のデバッグルーム)は、シーンのカテゴリから `InventoryLab`・`AdventureLab` を開く。画面のPrefab `InventoryLabScreen` と操作盤 `AdventureLabPanel` も一覧に並ぶ。展示室から開いた持ち物のデバッグルームは、サーバーの接続を作らないため持ち物を足せない。
[ドロップエディター](../screens/debug-rooms.md#ドロップエディター)は、シーンのカテゴリから `DropLab` を開き、画面のPrefab `DropLabScreen` でミストラ遺跡の一覧と5回分の報酬を停止中のまま確かめる。
聞かれたことを仮に組んで撮影した試作は、シーンのカテゴリから `TempLab` を開いて見る（[TempLab](../screens/debug-rooms.md#templab)）。試作がないときは、戦闘と同じ夕暮れの高原の舞台だけが写る。
敵の攻撃・被弾・撃破・状態が付いたときの行動・技と行動パターン・大技の溜め・敵のターンは、シーンのカテゴリから `EnemyLab` を開き、敵と行動を選んで確かめる（[敵の挙動デバッグルーム](../screens/debug-rooms.md#敵の挙動デバッグルーム)）。操作盤のPrefab `EnemyLabPanel` は一覧に並ぶが、操作する戦闘画面がないため、単体のプレビューでは押しても敵は動かない。
魔物の出現・ターンの帯・勝利・ドロップ・全滅・ルーン復活の演出は、シーンのカテゴリから `BattleMomentLab` を開き、ボタンを押して確かめる（[戦闘の演出デバッグルーム](../screens/debug-rooms.md#戦闘の演出デバッグルーム)）。操作盤とドロップの札のPrefab `BattleMomentLabPanel` は一覧に並ぶが、演出を再生する戦闘画面がないため、単体のプレビューでは押しても何も起きない。ドロップの光の柱や出現の土煙は計算で描くエフェクトで、専用のPrefabやマテリアルを足していないため、展示室に増えるアセットはない。
探索の魔物の出現・宝箱・マスへ進む演出は、シーンのカテゴリから `ExplorationMomentLab` を開いて確かめる（[探索の演出デバッグルーム](../screens/debug-rooms.md#探索の演出デバッグルーム)）。操作盤のPrefab `ExplorationMomentLabPanel` は一覧に並ぶが、演出を重ねる探索画面がないため、単体のプレビューでは押しても何も起きない。演出の部品は探索画面のPrefab `ExplorationScreen` の中にあり、演出を再生していないときは何も表示しない。宝箱の光のシェーダーとマテリアル（どちらも `ExplorationLight`）は一覧に並ぶが、形と色は演出のコードが渡すため、プレビューでは光らない。
撃破で敵の絵をドットごとに削るシェーダー（`BattleDefeat`）とマテリアル（`VfxDefeat`）も一覧に並ぶ。マテリアルは敵の絵と削る順番を持たないため、プレビューでは崩れる様子が見えない。崩れる動きは `EnemyLab` の「撃破」で確かめる。
50枚のカードの見た目（挿絵・枠・属性のアイコン・使い手・名前・種類と対象・説明文・コスト）は、`BattleCardGallery` Prefabで、10枚×5段に並べて確認する。戦闘画面のモックの山札に入るのは、このうち16枚だけである。形を計算するシェーダー（`BattleVfxShape`）と、形ごとのマテリアル（`Features/Combat/Vfx/Materials/` の `VfxShape〈形の名前〉`。撃破で舞う粒の `VfxShapeMote` を含む）も一覧に並ぶ。演出の内容は[スキルの演出と背景](../screens/battle-effects.md#スキルの演出と背景)に記す。
弱点を開示するときの光（[戦闘画面の見た目モック](../screens/battle.md#戦闘画面の見た目モック)）は、初めて弱点を突いたときにしか出ないため、`BattleWeaknessRevealPreview` Prefabで確認する。炎・氷・雷・斬の「？」を拡大して並べ、1つずつ開示してから全部を「？」へ戻す動きを繰り返す。アイコンの上の光のシェーダー（`BattleWeaknessGlint`）とマテリアル（`VfxWeaknessGlint`）も一覧に並ぶ。
展示室のプレビューはポストプロセスを掛けないカメラで描くため、戦闘で掛かるBloomは映らない。光のにじみまで確かめるときは、展示室から `BattleLab` シーンを開いてカードを使う。
カメラの中心がゆっくり円を描く動き（[カメラの中心のゆっくりした円運動](../screens/battle-effects.md#カメラの中心のゆっくりした円運動)）はPlay Mode中だけ動くため、Play Modeの展示室で `BattleInspectScreen` Prefabのプレビューを選ぶか、`BattleLab` シーンを開いて確認する。半径12pxを40秒で1周するほど小さな動きのため、Hierarchyで `StageDrift` を選び、`Period` を短くすると見分けやすい。戦場のドット絵を画素の端数の位置でも滑らかに描くマテリアル `StagePixelArt` とシェーダー `UI Pixel Art`（`Features/Combat/UI/`）も一覧に並ぶ。
シーンを作るメニューは、作ったシーンをBuild Settingsへ足すため、デバッグルーム（`App/Scenes/Debug/`）・案内人の画面（`App/Scenes/Guide/`）・冒険と地図のシーンも、展示室のシーンのカテゴリから開ける。
プレビュー用のCanvasはカメラへ接続するため、ドット絵を整数倍に保つ `PixelPerfectRawImage` は、画面直描き（Screen Space - Overlay）のCanvasでだけ画面のピクセルへ合わせる。
それ以外のCanvasでは設計上の大きさ（1ドット4単位）で表示する。
2026-09-27まではプレビューで縮尺を誤り、HomeScreenのトーマや戦闘画面のキャラが画面を覆うほど大きく表示されていた。
実機のノッチ・非対称Safe AreaはUnity EditorのGameビューだけでは確定できないため、端末確認時に追加で確認する。
