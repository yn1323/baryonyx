# 起動時の連携と歩数の同期の変更と判断の記録

[起動時の連携と歩数の同期](startup-sync.md)

- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、APKの接続先で `local` やほかの環境名はビルドを止めること、失敗の知らせを通知の帯で出すこと、確認状況（EditorからDevへの接続は通っている）を直し、連携モーダルの窓の説明を共通の部品へのリンクにした（根拠：client/Assets/Baryonyx/Editor/CI/ServerBuildEndpoint.cs、Features/Home/Editor/HomeScreenAssets.cs、Features/Health/Editor/HealthLinkModalAssets.cs、doc/rules/data-storage.md の2026-10-22の記録）。
- 2026-11-01：ユーザーの「タップでルーン獲得が重い」を受け、ACTパネルを押したときのサーバーとの通信を、版の発行・7日分の保存・ルーンの請求・今日の歩数の読み直しの4回から、`POST /v1/exercise/rewards/sync` の1回にした。今日の歩数は端末で読んだ値を使う。Devでは1回の通信に約250msかかるため（2026-10-22の計測）、演出が始まるまでの待ちが約0.75秒短くなる見込み。端末では測っていない。

- 2026-10-05：文書の整理で、`client/AGENTS.md` にあった接続先のURL・選び方の表と、接続設定アセットの生成手順を[実行環境と接続先](startup-sync.md#実行環境と接続先)へ移し、この文書を正本にした。付与量が0のときの知らせを、2026-10-04に共通の通知の帯へそろえた画面の動作に合わせて直した。

- 2026-10-04：ユーザーの指示により、運動量の単位の名前を「UPT」から「ACT」（読みはアクト、画面の表記はACT）へ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位act)）。換算は1歩＝1ACT、1ACT＝1ルーンで変えない。Homeの左上の単位をACTへ改め、UPTパネルをACTパネルへ改名した。

- 2026-10-03：ユーザーの依頼により、UPTパネルで仮データの固定量を足す仕組み（「MockRuneGain」）を削除し、押すと常にサーバーへ請求するようにした。前回の請求から増えたUPTだけを1UPT＝1ルーンで変換し、付与したルーンはサーバーに保存する。

- 2026-09-28：ユーザーの指示により、Homeの左上の単位を「ワット」から「UPT」へ改め、ワットパネルをUPTパネルへ改名した（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位act)）。

- 2026-09-27：ユーザーの指示により、Homeの左上を歩数からワット（1歩＝1ワット）の表示に改め、歩数パネルをワットパネルへ改名した。Health Connectとの連携・同期は歩数のまま扱う（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位act)）。

- 2026-09-27：ユーザーの指示で、Homeの歩数パネルを押して同期している間の案内を「同期中…」から「Loading...」に変えた。
- 2026-09-26：ユーザーの依頼により、Homeの歩数パネルの同期にルーンの請求を加え、所持ルーンをサーバーの残高で表示するようにした。押したときだけ請求し、起動時の自動請求は行わない。
- 2026-09-24：PR #9 の自動レビューの指摘を受け、連携の判定を「いずれかの記録を許可」から「歩数を許可」に改め、日ごとの歩数の集計失敗を同期の失敗として扱うようにした。ほかの記録だけを許可した状態で0歩を保存し、歩数の許可を案内しなくなるのを防ぐ。あわせて、起動時の同期で要求する権限と読み取る記録を歩数に限った。起動時の同期は歩数だけを保存するため、ほかの健康記録の権限を求めたり読み取ったりする理由がない。Homeでは、取得前・取得失敗時にモックの歩数を表示しないようにし、取得した歩数の日付に表示の日付を合わせるようにした。
- 2026-09-24：設定アセットのURLを手で切り替える運用をやめ、環境の名前で接続先を選ぶ形にした（ユーザー承認）。PreviewのAPKは当面Devへ接続する（ユーザー決定）。Prod環境は未公開のため `ProdServerUrl` は空とし、Prod向けのビルドはURLの設定まで止める。
- 2026-09-24：ユーザーの依頼により、Topでの接続・連携確認・同期、連携モーダル、LOADING表示、通信失敗時の再試行、右上の設定ボタン、Homeの歩数パネルの同期を追加した。Googleログインは任意とし、ゲストで始める方針をユーザーが決めた。サーバーにデータがあるかどうかではモーダルを出さず、未連携の場合だけ出す。
