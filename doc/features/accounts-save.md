# アカウントとセーブ

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

ゲーム進行のアカウント・保存方式は、以下で確定した要求を除き未決である。
保存する体験上の要求として、2026-09-15のユーザー提示仕様にある[部屋の区切りでの中断と進捗の持ち越し](stage-progression.md#終点と進捗の持ち越し)、[敗北時の成果保護](combat.md#敗北と成果の保護)を満たす。
戦闘中の保存・再開は、部屋の区切りでの中断と分けて決める。

運動目標の実績・履歴はサーバーに保存する方針とする。
必要な情報は[目標仕様の保存要件](goals.md#サーバーに保存する実績と履歴)を正本とし、当時の条件で履歴を保ち、遅れて届く記録で実績・達成状況を訂正する。
この保存先の決定は、元データの保存範囲・期間・粒度や、端末とサーバーの計算処理の分担を確定するものではない。

| キャラ・装備・資源・進行・設定の保存項目 | 未決 |
| 目標の実績・履歴の具体的な保存設計 | 必要な情報とサーバー保存の方針は[目標仕様](goals.md#サーバーに保存する実績と履歴)で確定。保存粒度・期間・元データの範囲・処理分担は未決 |

| 探索進捗・確定報酬・ルーン復活の消費を整合させる方法 | 未決。再戦と復活の状態は[戦闘仕様](combat.md#無料再戦とルーン復活)を参照 |
| 引き継ぎ、再インストール、複数端末、競合解決 | 未決 |
| オフラインで許可する操作と再接続時の整合 | 未決 |
| アカウント削除、退会、ゲーム・健康データの保持期間 | 未決 |
| 健康データの保存・送信範囲、同意・撤回 | 目標の実績・履歴表示と継続計算の用途は確定。元データの範囲や同意の具体的な方法は未決 |
| 問い合わせ、復旧に必要な識別子と操作 | 未決 |
