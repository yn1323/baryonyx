# 戦闘システムの変更と判断の記録

[戦闘システム](combat.md)


- 2026-10-26：ユーザーの指示で、エネルギー3固定と捨て札のルール、キーワード、作り直したカードと固有スキルを実装した（[計画](../plans/2026-10-25-fixed-energy-cards.md)）。画面はユーザーが選んだG3の配置にした。重複を避ける基準に当たった5つの覚醒版の段階を変え、説明文が欄に収まらないカードはユーザーの判断で当面そのままにした。
- 2026-10-25：クライアントのテストの整理で、戦闘画面（`BattleInspectView`）にあった山札（引く・尽きたら作り直す・倒れた味方のカードの出し入れ）、運に任せるところの乱数、敵の一撃の弱め方と狙い（麻痺・ブロック・挑発）を、[BattleDeck](../../client/Assets/Baryonyx/Features/Combat/Runtime/BattleDeck.cs)・[BattleDice](../../client/Assets/Baryonyx/Features/Combat/Runtime/BattleDice.cs)・[BattleBlows](../../client/Assets/Baryonyx/Features/Combat/Runtime/BattleBlows.cs) へ出し、EditModeで確かめるようにした。乱数を引く順番は変えていないため、同じ種の自動対戦は同じ結果になる（森の遺跡の強い魔物20組×3回で、前後とも勝率85%・平均7.2ターン）。倒れた味方にも挑発が残り、立っている味方に挑発がいないとき1人目の味方が倒れたまま挑発を持っていれば敵がその味方を狙う、という今の動きもそのまま写した。不具合の疑いとして、直すかは別に決める。
- 2026-10-25：ユーザーの相談「エネルギーが増えてくると、やることを全部使う感じになりがちで面白くない」を受け、エネルギーを毎ターン3に固定し、毎ターン5枚を引いてターンの終わりに手札を捨て札へ流す形に決めた（ユーザー決定）。捨て札・山札の作り直し・消滅・保持・霧散・初手・捨てる・眠り札・歩み・合体・連携のキーワード、復活とルーン復活の配り直しを[エネルギーとコスト](combat.md#エネルギーとコスト)・[手札](combat.md#手札)・[カードのキーワード](combat.md#カードのキーワード)・[倒れた味方](combat.md#倒れた味方)・[敗北とルーン復活](combat.md#敗北とルーン復活)に書いた。Slay the Spireの交互のターンと常に出す予告も比べたが、ユーザーはターン制を今のままにした。50枚と覚醒版、固有スキルの全段階のコストを0〜3にして効果を作り直し、[コストと威力の目安](combat.md#コストと威力の目安)を置いた。全滅からのルーン復活は、ターンを最初からやり直して5枚を配り直し、ターン数と敵の激化も1ターン目から数え直すとした（ユーザー決定）。実装はまだ（[計画](../plans/2026-10-25-fixed-energy-cards.md)）。
- 2026-10-25：クライアントのテストの整理で、旧仕様（リアルタイムのセミオート戦闘、ダウン、無料再戦）の試作の計算 `CombatEncounter`・`CombatPrototype`・`CombatModel` と、そのテスト `CombatEncounterTests` を削除した。現行の戦闘から使われていなかった。動作の記録は[遊べる試作の画面と操作](../archive/game-wireframe.md#戦闘と再戦)へ移した。
- 2026-10-25：ユーザーの依頼「会心幸運に関しては、クリティカルヒットが出やすくなるもの」「状態異常のかかりやすさは、必ずかかるではなく割合を決めて提案して」を受けて案を出し、ユーザーが案どおりに決めた。会心を[会心の一撃](combat.md#会心の一撃)の確率に使い、状態異常に[基本確率](combat.md#状態異常の付与率の仮設定)と、凍結が続けてかからない決まりを入れた。案では麻痺を凍結と同じ40%にしていたが、麻痺は行動を止めない状態のため60%にした。
- 2026-10-25：ユーザーの依頼で、ダンジョンで全滅したときに広告を見て復活できる形を[敗北とルーン復活](combat.md#敗北とルーン復活)に加えた。回数と、ルーンの復活の費用との数え方は[月パスと報酬つきの広告](monetization.md#月パスと報酬つきの広告)の未決事項に置いた。
- 2026-10-24：ユーザーの「バトルで速度アップしたときの恩恵がない」「今表示中の順序も変更してもらえると」「速度が劣っているときは、敵のターンから開始でもOK」を受け、[ターン順](combat.md#ターン順の仮設定)を、パーティより速い敵は味方のターンより前に動く形に改め、速度アップと凍えを速度に掛けて、順番の表示をその場で変えるようにした。表示の並べ替えに動きは付けていない。
- 2026-10-24：ユーザーの「ブロックが強すぎる」「回復も強すぎる。基本の割合を減らしてほしい」を受け、カード・固有スキル・アイテムのブロックの割合を0.55倍、回復とリジェネの割合を0.8倍にして5の位で丸めた（例：ガード 物防60%→35%、ヒール 属攻90%→70%）。同時に味方の物防が約1.27倍、属攻が約0.85倍になったため（[自キャラのLv100のステータス](progression.md#自キャラのlv100のステータス)）、実際の量はどちらも今までの約7割になる。続けて「敵が力を貯める、ブロックみたいな行動が多いかも。もっとガシガシ攻撃してきてほしい」を受け、[敵の行動](combat-enemy-behavior.md)の割合で選ぶ技のうち攻撃しない技の重みを4割にした。倍率はこちらで決めた仮の値である。
- 2026-10-23：ユーザーが戦闘の問題として「エネルギーが上がるほどカードを使い切ってしまう。でも引けるのは毎回3枚」「キャラが1人のみになると、引けるカードが毎回同じ」を挙げた。1つ目は、3枚を引いても手札が5枚に満たなければ5枚まで引く案をユーザーが選んだ（[手札](combat.md#手札)）。ほかに比べた案は、ターンが進むと引く枚数を増やす、余ったエネルギーで引く、エネルギーの伸びを抑える、の3つである。2つ目について、1人4枚は少ないかとの問いを受け、ユーザーは1人の枚数を6枚（固有スキル3つ・カスタムスキル3枠）に増やし、枚数をプレイヤーが選ぶ形にはしないと決めた（[キャラクターの構成](party.md#キャラクターの構成)）。カスタムスキルは空けておけ、固有スキルはLvで解放するため、Lvが低いうちは枚数が少ない。1人だけ残ったときの対策は、この変更を試遊で確かめてから決めることにした（[未決事項](combat.md#未決事項)）。
- 2026-10-22：自動対戦で、ブロックを戦闘中ずっと残す決まりのため、長い戦闘ではブロックがパーティの最大HPの満タン近くまで貯まり、敵の攻撃をほとんど受け止めることが分かった。ユーザーに5つの案（半分に減る、上限を下げる、Slay the Spire式に毎ターン消す、残るブロックと1ターンのブロックの2種類にする、敵の対抗手段を増やす）を比べて示し、ユーザーが「半分に減る」案を選んだ。味方のターンの始めに、残っているブロックを半分にした（[カードの状態の仮設定](combat.md#カードの状態の仮設定)）。2026-10-21の「ターンをまたいで残す」は保ち、貯まり続けることだけを止めた。毎ターン消す案は、敵の次の行動を常に出さない（2026-09-29の決定）ため、守るときが読めず運に寄るとして採らなかった。
- 2026-10-22：ユーザーの「ダンジョンの歯ごたえがない。なぜ？」への回答（行動順が固定で、主のいない戦闘では味方が3ターン動くあいだに敵が1回しか動かない／敵が単体攻撃1種類しか使わない）に対し、ユーザーが「1、2を改善してほしい」と依頼した。冒険の戦闘のターン順を速度から決め（[ターン順の仮設定](combat.md#ターン順の仮設定)）、敵が敵の定義の技と行動パターンで動くようにした（[敵の行動の仮設定](combat-enemy-behavior.md)）。作り方は、ユーザーが「文書の技と行動パターン」と「大技の溜めだけ知らせる」を選んだ。味方への状態異常などまだ戦闘にない効果は入れず、攻撃だけを残した。強い魔物と最奥の主の攻撃の倍率は、敵が動く回数が増えたため調整し直した（[戦闘の試し](stage-progression.md#戦闘の試し)）。単体で開く戦闘画面のモックは、固定の順番と単体攻撃のままとした。
- 2026-10-21：ユーザーの指示「戦闘中にHPがつきたキャラも動けてしまう。HPがつきたら動けなくして」「HPがつきたキャラのスキルはその瞬間に手札、デッキ、両方から削除して」により、倒れた味方は行動せず、そのカードを手札と山札から取り除くことにした（[倒れた味方](combat.md#倒れた味方)）。回復で倒れた味方が起き上がると、取り除いたカードの扱いと食い違うため、倒れた味方を対象にできるのは復活させるカードだけにし、復活した味方のカードは山札へ戻すことにした。
- 2026-10-21：ユーザーの指示「コストが余っていても使えるカードがなければボタンをdisabledにして、自動でターン終了して」により、ターンが自動で終わる条件を、エネルギーを使い切ったときから、手札に払えるカードが1枚もないときへ広げた（[エネルギーとコスト](combat.md#エネルギーとコスト)）。
- 2026-10-21：ユーザーの指示「シールドを、そのターンだけじゃなくて永続化できますか？ただ、最大はそのキャラのHP分としたい」により、味方のブロックを次の味方ターンの開始時に消すのをやめ、ターンをまたいで残すことにした（[カードの状態の仮設定](combat.md#カードの状態の仮設定)）。量は付いた味方の最大HPを上限とし、戦闘の終わりと全滅からの復活で消す。毎ターンのガードで貯め続けられるため、ブロックがあると強くなるカード（ギガントインパクトなど）と、敵のブロックを消す・削る技の強さは試遊で確かめる。
- 2026-10-20：ユーザーの指示「基本0〜3、MAX9あってもいい。9はめちゃ強い感じに。0は少なめ、1〜3はまぁまぁ、4〜9は少なく、9はめちゃ少なく」により、カードスキル50枚と固有スキルのコストを配り直した（[スキルの仮設定](combat.md#スキルの仮設定)の「コスト」）。インフレしてよいとされたため、コストを上げた大技は威力も上げ、メテオ（9）は敵全体に属攻の450%・やけど中は2倍とした。カットインはコスト5以上のままとし、8枚になった。冒険の戦闘に行き先ごとの敵を出すため、魔法で攻める敵の攻撃を属防で受けるようにした。
