# アイテム（道具・素材）の変更と判断の記録

[アイテム（道具・素材）](items.md)

- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、カスタムスキルの枠の数（3つ）を直し、実装済みのドロップ・売却・保存先・枠に入れる画面を未決事項から外した（根拠：server/src/features/party/db-schema.ts の枠0〜2、server/src/features/adventure/drops.ts、server/src/features/workshop/catalog.ts の `sellItemPrice`、server/src/features/items/db-schema.ts の `item_holdings`、編成のスキルの画面のアイテムのタブ）。
- 2026-10-07：ユーザーの指示により、スキルかアイテムを入れる2枠を「カスタムスキル」と呼ぶことにした（[キャラクターの構成](party.md#キャラクターの構成)）。
- 2026-10-06：ユーザーの指示により、持ち物の分類にアイテム（道具・素材）を加え、この文書を作った。戦闘での使い方として、固有スキルのように手札の外から使って1個減らす案、減らさずに回数で制限する案、デッキに入れる案を示したところ、ユーザーは、スキルと同じくデッキに入れ、使うと手札からなくなっても山札を作り直すとまた現れ、持っている量は減らない形を選んだ。同日、数え方として、種類ごとに個数で数える案と、1つずつ倍率を持つ案を示したところ、ユーザーは種類ごとに個数で数える案を選んだ。さらに同日、アイテムの枠をスキルと共有の2枠とし、固有スキル2枚と合わせて1人4枚、デッキ16枚のままとした（[キャラクターの構成](party.md#キャラクターの構成)）。
