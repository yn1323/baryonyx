# 合成と合成の記録

[機能索引](README.md) / [持ち物の分類](inventory.md) / 根拠：2026-10-05・2026-10-06のユーザーの指示

**合成**は、持ち物を材料にして、より良い持ち物を作ることである。
冒険で集めた素材や、使わなくなった装備・スキルを、強い持ち物に変える手段になる。

## 確定している方針

### 合成できる物

素材・道具・武器・防具・アクセサリー・スキルを合成できる。
合成すると、より良い素材・道具・武器・防具・アクセサリー・スキルになる（2026-10-06）。
合成は[商会](screens.md#商会)で行う（2026-10-05）。

## 設計方針

### 合成の記録

合成の結果を、あとから記録として見られるようにする（2026-10-06のユーザーの意向。作る時期は未定）。
記録の形（作った組み合わせを図鑑のように集めるか、合成した履歴を並べるか）と、見る場所は未決である。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 組み合わせ | 決まった組み合わせ（レシピ）で作るか、材料から結果を抽選するか。分類をまたぐ組み合わせ（素材と武器で武器を作るなど）を認めるか |
| 結果の決まり方 | 出来上がる物の[レア度](inventory.md#レア度)と[倍率](inventory.md#1つずつ持つ倍率)の決まり方、材料のレア度や倍率を引き継ぐか、失敗の有無 |
| 費用 | ルーンを使うか、その量（[ルーン経済](economy.md)） |
| 材料の扱い | 材料にした物がなくなるか、キャラが付けている物を材料にできるか |
| 合成の記録 | 記録の形、見る画面、保存先（案はサーバー。[保存先の決め方の置き場所の一覧](../rules/data-storage.md#置き場所の一覧)） |
| 強化・進化・再抽選 | 合成とは別に設けるか（[育成の未決事項](progression.md#未決事項)） |

## 実装との対応

合成は未実装である。
商会の「合成」は仮の一覧を開き、決定すると準備中の通知を出すだけである（[商会](screens.md#商会)）。

## 変更と判断の記録

- 2026-10-06：ユーザーの指示により、合成できる物を素材・道具・武器・防具・アクセサリーに広げ、合成の結果を将来は記録として見られるようにする意向を加えた。2026-10-05に決めた「素材から装備・スキルを作る」との関係を確かめたところ、ユーザーはスキルも合成できるままとした。合成の決まりを1か所にまとめるため、[装備](equipment.md)の未決事項にあった合成の記述をこの文書へ移した。
- 2026-10-05：ユーザーの指示により、合成を採用し、商会で素材から装備・スキルを作ることにした（[装備の変更記録](equipment.md#変更と判断の記録)）。
