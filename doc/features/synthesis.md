# 合成と合成の記録

[機能索引](README.md) / [持ち物の分類](inventory.md) / 根拠：2026-10-05・2026-10-06・2026-10-31のユーザーの指示

**合成**は、品物ごとに決まった材料（レシピ）をそろえ、すべて使って、その品物を作ることである。
冒険で集めたアイテムを、武器・防具・アクセサリー・カスタムスキルに変える手段になる。

## 確定している方針

2026-10-31に、ユーザーとの相談で次を決めた。
それまでの「同じ分類で☆が1つ低い物なら何でも3つ」で作る決まり（2026-10-24の仮設定）は、材料を選び放題で作れてしまうため改めた。

### 合成できる物

武器・防具・アクセサリー・カスタムスキルを合成できる。
スキルはカスタムスキルだけで、固有スキルは作らず、材料にもしない。
アイテム（道具・素材）は材料にするだけで、合成では作らない（2026-10-31。2026-10-06の「素材・道具も合成でより良い物にできる」はやめた）。
合成は[商会](screens/shop.md#合成)で行う（2026-10-05）。

### レシピ

作れる物ごとに、材料と数が決まっている。
材料はアイテムを基本にし、同じアイテムを何個か、違うアイテムを1個ずつ、2種類を組み合わせて片方を2個、のようにいくつかの形がある。
特別な場合には、決まった武器・防具・アクセサリー・カスタムスキルも材料にする。
レシピの中身は[レシピの一覧](#レシピの一覧)の文書が正本である。

| 項目 | 決まり |
|---|---|
| 一覧に出す条件 | そのレシピの材料のどれか1つでも、手に入れたことがある（[ライブラリ](library.md)の見つけた記録）。今持っているかは問わない |
| 合成できる条件 | 材料がすべてそろい、ルーンが足りること。足りない材料があっても一覧には出し、足りない物を書いて「合成」を押せなくする |
| 材料の扱い | 合成すると、材料をすべて使う。アイテムは数が減り、0になった種類は消える |
| 使えない材料 | キャラが付けている武器・防具・アクセサリー、デッキに入れているスキル。アイテムは、デッキに入れている枠の数を残す |
| 同じ装備・スキル | 1つのレシピで使う同じ種類の装備・カスタムスキルは1つまでにする（2026-10-31、ユーザーの指示。選び方がややこしくならないため）。アイテムは同じ種類を何個でも使える |
| 材料の選び方 | 装備・スキルの材料は、同じ種類を何枚も持っていれば、どれを使うかを選べる。初めは品質の低い物を選んでおき、材料の札を押して開く窓で品質の違う物に替える（[使う物を選ぶ画面](screens/shop.md#使う物を選ぶ画面)） |
| 失敗 | ない |

### 出来上がる品質

材料のうち、品質を持つ物（武器・防具・アクセサリー・スキル）の品質の平均で決める。
アイテムは品質を持たないため、平均に入れない。
アイテムだけのレシピは、品質C（×1.00）で出来上がる（2026-10-31、ユーザーの指示「アイテムに品質がないので、一旦出来上がるのは基本Cランク」）。

平均は、材料それぞれの倍率の幅（×1.00から種類ごとの上限まで）の中の位置を平均し、出来上がる物の幅に当てはめる。
百分率の整数に四捨五入する。
材料と出来上がる物とで倍率の上限が違うため、倍率そのものではなく位置を平均する。
倍率そのものを平均すると、上限の低い材料（×1.8まで）の品質Sが、上限の高い物（×3.0まで）では品質Cになってしまう。

### まだ見つけていない物の見せ方

一覧には、まだ手に入れたことのない物も出る。
その物は、絵を影にして出し、名前と効果は「？？？」で伏せ、☆だけを見せる（2026-10-31、ユーザーの指示「影みたいな感じで表示」）。
材料のうち、まだ手に入れたことのない物も、同じく影にする。
合成して手に入れると、ライブラリの見つけた記録に載り、名前・絵・効果が見えるようになる。

### 合成の演出

「合成」を押すと、画面全体を暗く沈め、材料が画面の中央で渦を巻いて光の球になり、弾けて出来た物が現れる演出（光の渦）を流す（2026-10-31、ユーザーが絵コンテの10案から選んだ）。
結果は押した瞬間に持ち物へ反映し（楽観的更新）、演出はその上で流す。
画面のどこかを押すと、出来た物が右上の絵へ戻る所まで飛ばす。

現象として、水が排水口へ吸い込まれる渦を元にする。
外側はゆっくり、中心に近いほど速く回り（角速度は半径に反比例）、吸い込まれる物は螺旋を描く。
一点に押し込まれた光は、輪と光線になって弾ける。
感覚の言葉は「吸い込まれる」「加速する」「詰まる」「弾ける」である。

全体は約1.5秒にする（2026-10-31、ユーザーの指示。最初に作った約2.5秒は長かった）。
次の表は☆3以下の時刻で、☆4・☆5は弾ける前に溜める分と、現れたあとに残す分だけ後ろへずれる。

| 時刻（秒） | 拍 | 起きること |
|---|---|---|
| 0〜0.15 | 押した手応え | 「合成」が沈んで戻る。画面全体が紺に沈む（真っ黒にせず、奥の画面を薄く残す） |
| 0.03〜0.3 | 材料が飛ぶ | 材料の札の絵が浮き上がり、細い光の尾を引いて、画面の中央の周りの軌道へ弧を描いて飛ぶ |
| 0.27〜0.9 | 渦 | 材料が中央の周りを回りながら近づき、近づくほど速くなる。後ろに細い螺旋の光の線が伸び、火の粉が外へ飛ぶ。中央の光が育つ |
| 0.78〜0.92 | 詰まる | 材料が白くなって中央へ消え、中央が白い光の球になる。螺旋が締まって消える |
| 0.92 | 弾ける | 光の球が弾け、細い光線と、出来上がる品質の色の細い輪が広がる。暗転を一瞬だけ緩める |
| 0.92〜1.2 | 現れる | 出来た物の絵が中央に大きく現れ、きらめきが残る |
| 1.2〜1.5 | 戻る | 出来た物が右上の絵の位置へ縮みながら戻り、暗転が解ける。着いたら絵を大きくして戻す |

作る物の☆が4・5のときは、少し豪華にする（2026-10-31、ユーザーの指示。絵コンテをユーザーが選んだ）。

| ☆ | 長さ | 足すもの |
|---|---|---|
| 3以下 | 約1.5秒 | 上の表のとおり。輪と光線は出来上がる品質の色 |
| 4（金） | 約1.6秒（溜め0.06秒、残り0.04秒） | 渦の線を金にして腕を6本から8本に増やし、腕に沿って金のきらめきを瞬かせる。弾ける前に、画面の端から中央へ金の細い線が吸い込まれる。光線を倍にし、金と白の2重の輪にする。金箔の小片が弾けて舞い落ち、出来た物の上を光が走る |
| 5（虹） | 約1.8秒（溜め0.18秒、残り0.1秒） | 渦の線に腕ごとに淡い虹をまとわせ（濃くしない。芯は白）、腕を8本にする。溜める間は画面をもう一段暗くし、光の球を脈打たせ、淡い虹の細い線を画面の端から吸い込む。白い輪に淡い3色の輪を重ね、小片ときらめきを画面いっぱいに散らす。出来た物の後ろで淡い虹の細い輪が回り、上を光が走る |

| 層 | 役割と形 | 透け方 |
|---|---|---|
| 暗転 | 画面全体を紺に沈める | 通常合成。奥を薄く残す |
| 渦のにじみ | 螺旋の線の周りの光った空気。金と薄紅 | 加算。薄く広い |
| 渦の線 | 幅3〜5画素の螺旋。先頭だけ白い芯で、尾は途切れながら薄れる | 加算 |
| 材料 | 材料の絵と、その後ろの光、飛ぶ間の光の筋 | 絵は通常合成、光と筋は加算 |
| 火の粉 | 渦から外へ飛ぶ粒 | 加算 |
| 光の球 | 中央の広い光と、白い芯 | 加算 |
| 溜め（☆4・☆5） | 画面の端から中央へ吸い込まれる細い線 | 加算 |
| 弾け | 細い光線と、品質の色の輪（☆4・☆5は重ねる輪と、舞い落ちる小片） | 加算 |
| 出来た物 | 絵と、その後ろの光ときらめき（☆4・☆5は上を走る光、☆5は後ろで回る虹の輪） | 絵は通常合成、光は加算 |

## 仮設定

### 作れる物の範囲

☆2以上の武器・防具・アクセサリー・カスタムスキルを作れる。
☆1の物はどの行き先でもよく落ちるため、レシピを持たない。
最奥の間でだけ落ちる物（主の物）は作れず、主のアイテムは☆4・☆5のレシピの材料にする。
今の品物では、☆5の装備はすべて主の物のため、作れる☆5はカスタムスキルだけである。

### レシピの決め方

2026-10-31に、ユーザーから組み合わせを任され、次の目安でこちらで決めた。

| 項目 | 目安 |
|---|---|
| 材料の行き先 | 作る物と同じ行き先で落ちるアイテムを使う。その行き先に通うと作れる物が増える |
| ☆2 | アイテム3個 |
| ☆3 | アイテム4個。☆2か☆3のアイテムを混ぜる |
| ☆4 | アイテム5個（☆3のアイテムか主のアイテムを含む）か、特別な材料1つとアイテム3〜4個 |
| ☆5 | 特別な材料1つと、主のアイテム1個を含むアイテム5〜6個 |
| 特別な材料 | 一部の☆4と☆5だけに使う。作る物の元になりそうな、☆の低い武器・防具やカスタムスキル（例：ヒールからリザレクション、ブリザードから絶対零度）。ほかの行き先の物でもよい |

特別な材料のあるレシピは、その材料を手に入れていれば一覧に出る。
初めのデッキのカード（ヒール・アイスランスなど）と初めの装備（鉄の剣・樫の杖など）は、初めから見つけた記録にある。
そのため、それを特別な材料にするレシピ（リザレクション・アイスミラー・炎のダガー・氷河の大剣・月影の杖）は、初めから影で一覧に出る。

### 費用

出来上がる物の☆で、☆2 200、☆3 400、☆4 800、☆5 1,600ルーン（[商会](screens/shop.md#商会)の買う値段の半分）。
2026-10-24の仮設定の額をそのまま使う。

## 設計方針

### 合成の記録

合成の結果を、あとから記録として見られるようにする（2026-10-06のユーザーの意向。作る時期は未定）。
記録の形（作った組み合わせを図鑑のように集めるか、合成した履歴を並べるか）と、見る場所は未決である。

## 実装との対応

2026-10-31に、レシピの合成をサーバーとクライアントで作った。

| 対象 | 今の実装 |
|---|---|
| レシピ | サーバーは [recipes.ts](../../server/src/features/workshop/recipes.ts)、クライアントは [WorkshopRecipes](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopRecipes.cs)。どちらも作る物の定義の文書（[レシピの一覧](#レシピの一覧)）の写しで、同じ値にする。文書を直したら両方を直す |
| API | `POST /v1/workshop/craft`（`requestId`・`category`・`id`・`materialIds`）。アイテムの材料はレシピで決まるため送らず、特別な材料（装備・スキル）の持ち物の行のIDだけを送る。レシピのない物・☆1・主の物は `goods_not_found`、材料がレシピに合わない・足りない・使っている物は `invalid_materials`、ルーン不足は `insufficient_runes` で拒む。作る物を手に入れたことがなくても作れ、作った物はライブラリの見つけた記録に足す（[craft.ts](../../server/src/features/workshop/craft.ts)・[値](../../server/src/features/workshop/catalog.ts)） |
| 合成の確定 | 記録（`workshop_crafts`）・ルーンの減算・材料の削除（アイテムは減算）・出来た物の追加と見つけた記録を、残高と材料の状態を条件にした1回のbatchで行う。要求IDで再送を見分け、二重に使わない |
| 画面 | [商会](screens/shop.md#合成)の「合成」（[WorkshopCraftView](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopCraftView.cs)、生成は [WorkshopCraftAssets](../../client/Assets/Baryonyx/Features/Workshop/Editor/WorkshopCraftAssets.cs)）と、使う物を選ぶ画面（[WorkshopMaterialPicker](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopMaterialPicker.cs)）。決まりは [WorkshopCraft](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopCraft.cs) にサーバーと同じ計算で持ち、押す前に出来上がる品質を見せる。押すとすぐ持ち物の表示を変え、裏でサーバーに保存する（楽観的更新。2026-10-31、ユーザーの指示）。出来た物は仮の行IDで足し、答えが届いたらサーバーの行IDに替える。保存できなければ、知らせて読み直す |
| ライブラリ | 見つけた武器・防具・アクセサリー・スキルの個別の画面に、レシピの札を出す（[ライブラリの合成のレシピ](library.md#合成のレシピ)、[LibraryCatalogView](../../client/Assets/Baryonyx/Features/Library/Runtime/LibraryCatalogView.cs)） |
| サーバーがないとき | 展示室などでは、仮の持ち物（[WorkshopStock](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopStock.cs) の `Mock`）・ライブラリの仮の記録・仮の残高で試せる。仮の持ち物には、鉄の剣を作れ、炎のダガーは海賊のラム酒が足りない材料を入れてある |
| テスト | サーバーは [routes.test.ts](../../server/src/features/workshop/routes.test.ts)、クライアントは [WorkshopCraftTests（EditMode）](../../client/Assets/Baryonyx/Features/Workshop/Tests/EditMode/WorkshopCraftTests.cs) と [WorkshopCraftTests（PlayMode）](../../client/Assets/Baryonyx/App/Tests/PlayMode/WorkshopCraftTests.cs) |
| 演出 | [WorkshopCraftSwirl](../../client/Assets/Baryonyx/Features/Workshop/Runtime/WorkshopCraftSwirl.cs) が押してからの時刻で全部の層を描き、合成の画面が押した瞬間に流す。渦の線は専用のシェーダー（[WorkshopCraftSwirl.shader](../../client/Assets/Baryonyx/Features/Workshop/Vfx/Shaders/WorkshopCraftSwirl.shader)、2つの層を通常・金・虹の3つの見た目で、6つのマテリアル）、光の球・光線・輪・火の粉・光の筋・きらめきは戦闘の形のシェーダー（BattleVfxShape）のマテリアルを使う。商会の画面はポストプロセスを通らない（Bloomが掛からない）ため、光のにじみは各形のにじみの層で描く |

合成の記録を見る画面は、まだない。

## 変更と判断の記録

- 2026-10-31：ユーザーの「長さはもう少し短く、1.5秒ぐらい」「星4、5は少し豪華にしたい」を受け、光の渦を約1.5秒に縮め、☆4（金）・☆5（虹）の豪華な版を足した。豪華さの中身は、実装したコマにCodex CLIで描き足した絵コンテを見せ、ユーザーが「これでいきたい」とした。☆4・☆5を少しずつ長くすることは、こちらで決めて絵コンテに書いた。
