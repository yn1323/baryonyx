# 戦闘システム

[機能索引](README.md) / [探索と進行](stage-progression.md) / [パーティ](party.md) / 根拠：[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

2026-09-27の企画見直しで、戦闘をSlay the Spireを参考にしたターン制のカードバトルへ変更した。
リアルタイムのセミオート戦闘、スロー、キャストタイム、ダウン、無料再戦などの旧仕様は[変更と判断の記録](#変更と判断の記録)へ移し、現行ルールへ混ぜない。
確定・設計方針・仮設定・未決は[仕様の確度](README.md#仕様の確度)に従って区別する。

## 確定している方針

### 戦闘の形式

[4人パーティ](party.md)で、ターン制のカードバトルを行う。
4人が装備したカードスキルを合わせた16枚が**デッキ**になる（[キャラクターの構成](party.md#キャラクターの構成)）。
プレイヤーは手札のカードにエネルギーを払って使う。
雑魚複数戦と単体ボス戦の両方を用意し、基本のクリア条件は敵全滅とする。
移動・回避やタイミング入力を前提とする操作は入れない。

標的が誰かを明確に表示する。
敵のHPは横バーで表示する。

### ターン順

味方パーティの合計すばやさと、敵のすばやさを比べてターン順を決める。
差が大きい場合は、同じ側が連続でターンを得る（例：味方が2ターン連続）。
連続ターンになるしきい値は未決とする。

### エネルギーとコスト

**エネルギー**は、カードと固有スキルに払う戦闘中の資源である。
シャドウバースと同じく、初期値の3からターンごとに最大値が1増え、上限は9とする。
各カードに**コスト**があり、使うとその分のエネルギーを消費する。
ダンジョン内で、エネルギーを次の戦闘へ持ち越さない。

### 手札

手札はシャドウバースと同じく次のターンへ持ち越す。
戦闘の開始時に山札から6枚を配り、2ターン目からはターンの開始時に3枚ずつ引く。
手札の上限は9枚とし、引く途中で上限に届いたら、残りは引かずに山札に残す（Marvel Snapと同じ扱い）。
山札が尽きたときに引く場合は、はじめの16枚をすべて切り混ぜて新しい山札にする。
手札に残っているカードも新しい山札に入るため、同じカードが手札に重なることがある。
使ったカードは捨て札として残さない。

手札のカードを手動で捨てる操作は設けない。
その代わりに、どのカードもいつでも使えるようにし、「HPが減った味方がいるときだけ」のような使用条件を付けない。
使えないカードが手札に残り続けると、捨てる手段がないため上限の枠を塞ぎ続けるからである。
コストの高いカードと低いカードの配分は、プレイヤーのデッキ編成に任せる。

### カードの種類と流れ

カードには、攻撃、バフ、デバフ、回復、エネルギーコスト軽減、数ターン持続する攻撃などの種類がある。
対象は単体と全体がある。
序盤は仕込みのカードで準備し、終盤に高コストの大技を使う流れにする。

UPTで威力が変わるカードを入れる。
デッキに入れるかどうかはプレイヤーが選ぶ。
参照するUPTと威力の変え方は未決とする（[UPTボーナス](step-bonus.md)とは別の仕組み）。

### 威力の決め方

攻撃・回復のカードと装備は、固定値を持たない。
効果量は「装備したキャラのステータス〇〇の〇％」で決まる。
参照するステータスと割合は、カードや装備ごとに決める。

### 属性と弱点

| 分類 | 属性 |
|---|---|
| 魔法 | 炎・氷・雷 |
| 物理 | 斬・打・貫 |

キャラごとに装備できる属性が異なる（[キャラクターの構成](party.md#キャラクターの構成)）。
属性はカード効果の対象にもなる（例：手札の斬属性カードのコストをすべて1下げる）。

敵ごとに弱点の属性を持ち、カードの属性が一致するとダメージを1.5倍にする。
属性による耐性（軽減・無効）は設けない。
属性同士の相性表や部位別HPは入れない。

### 弱点の開示

敵の弱点は、初めて戦うときは画面に表示しない。
味方の誰かがカードで弱点を突くと、その弱点をその場で**開示**し、画面に表示する。
同じ戦闘にいる同じ種類の敵にも、同時に表示する。

開示は敵の種類ごとにプレイヤーの記録として残す。
以後はその種類の敵と戦うたびに、開示した弱点を最初から表示する。
冒険の終了やルーン復活でも、開示した弱点を伏せ直さない。

### 防御と敵の激化

ダウンは廃止した。
敵の激しい攻撃には、防御を上げるなどして備える。
防御の具体的な形式は未決とする。

敵は「〇ターン以降」のように、ターンの経過に応じて攻撃を激しくする。

### 固有スキル

各キャラの[固有スキル](party.md#キャラクターの構成)は、手札とは別の、いつでも使える枠に置く。
使うとエネルギーを消費し、再使用までの**クールターン**がある。

### 敗北とルーン復活

味方が全滅すると、[冒険は終了する](stage-progression.md#冒険の終了と獲得物の保持)。
それまでに獲得した装備・スキルなどは失わない。
敗北による資源の自動徴収、装備ロスト、挑戦回数の消費は設けない。

ルーンを使えば復活して、冒険を続きから再開できる。
ルーンは復活を明示的に選んだときだけ消費する。
旧仕様で確定していた「その戦闘で削った敵HPを維持し、味方は全快して再開する」は、今回の内容と両立するため維持する。
再開時のターン数・エネルギー・手札・激化の扱いは未決とする。

戦闘単位の無料再戦は廃止する。
見直しの資料で開発者の最終確認が必要とされているため、[確認待ち](#確認待ち)に記録する。

## 設計方針

### カードの数値の見せ方

カードの威力・回復量は、装備画面の時点で実数値（例：243ダメージ）を表示する。
カードや装備を付け替えるときは、差分（例：243 → 281 ▲38）を表示する。
戦闘中は、バフと開示した弱点を反映した現在値を表示する。
未開示の弱点は現在値に反映しない（数値の変化で弱点が分かってしまうため）。
実際のダメージは、未開示でも弱点に一致すれば1.5倍になる。

### 固有スキルの位置づけ

固有スキルはコストを軽め（1〜2程度）、効果を控えめにする。
クールターンで連打を防ぎ、残りクールターンをボタンに表示する。

### 戦闘中の情報の優先順位

標的、開示した敵の弱点、敵の次の行動の予告を、攻撃エフェクトやダメージ数字で隠さない。
予告では、特に激化ターンの大技を見せる。
[探索情報](stage-progression.md#行き先を選ぶ情報)も短く読み取れる形にする。

### 爽快感と入力の手応え

長い演出で毎回操作を止めず、命中音、短い衝撃演出、敵の反応、HPが大きく減る動きで爽快感を出す。
弱点に当たったときは、ダメージ数字の色と大きさを変えて強調する。

### ボスの歯ごたえ

HPを増やすだけで戦闘を長くしない。

### 復活画面

復活画面では、帰還もルーン復活と同じ普通の選択肢として並べ、ルーン復活だけを強く押し出さない。
成果が残ることと消費量を明示し、選択を急かすカウントダウンを付けない。

## 仮設定

仮設定は、試作で遊び心地と見た目を確かめるために置いた内容で、決定済みとして扱わない。
数値は[未決事項](#未決事項)の数値の決定に合わせて見直す。

### カードスキルの仮設定

2026-10-03、ユーザーの依頼で、カードスキルを50枚作った。
1枚ごとの意図・演出・挿絵は[技・カードの定義](../catalog/skills/README.md)に記録し、効果と数値の実行上の正本は [CardSkills](../../client/Assets/Baryonyx/Features/Combat/Runtime/CardSkills.cs) に置く。
キャラごとに装備できる属性は未決のため、使い手は戦闘画面のモックの4人に仮に割り当てた。

| 項目 | 仮設定 |
|---|---|
| 枚数と使い手 | 50枚。アリア13枚、トーマ13枚、ルカ13枚、ミナ11枚 |
| 属性 | 斬5枚、打6枚、貫6枚、炎7枚、氷5枚、雷6枚、属性なし15枚 |
| 種類 | 攻撃28枚、回復5枚、防御5枚、強化3枚、弱体4枚、支援5枚。カードには「攻撃・敵単体」のように種類と対象を並べて書く |
| 対象 | 敵単体、敵全体、敵ランダム（当たるたびに敵を選び直すもの、当てた敵から別の敵へ跳ねるもの）、味方単体、味方全体、自分、人以外（手札・山札・エネルギー・次のカード） |
| コスト | 1〜9。1が13枚、2が13枚、3が9枚、4が5枚、5〜9が10枚。序盤の仕込みと終盤の大技の流れ（[カードの種類と流れ](#カードの種類と流れ)）に合わせ、低いコストを多くした |
| 威力 | 使い手のステータスの割合。ステータスは仮に、ちから（物理の打撃）、まりょく（魔法と回復）、まもり（ブロックと盾の打撃）の3つとする |
| 条件で強くなるカード | 弱点を突いたとき、やけど中の敵、HPが半分以下の敵に対して威力が上がるカードがある。[手札](#手札)の方針に合わせ、使う条件は付けない |
| UPTで威力が変わるカード | 健脚の一撃と万歩の祈り。今日のUPT1,000ごとに威力を10%上げ、上限は100%とする |
| 重複を避ける基準 | 属性・対象・行う効果（種類・相手・状態・回数・条件）の組み合わせが同じカードを作らない。同じ効果で威力とコストだけが違うカードも作らない。EditModeテストの `CardSkillsTests` で検査する |
| 挿絵 | 1枚ずつ別のモチーフを描く。最初の6枚は戦闘画面のモックの挿絵を使い、残りの44枚はCodex CLIの画像生成で作った（[戦闘画面の見た目モック](screens.md#戦闘画面の見た目モック)） |
| 演出 | 1枚ずつ別の演出にする。どれも溜め・発生・余韻の3拍で組み立て、画像を貼らずに形をシェーダーで計算して描く（[スキルの演出と背景](screens.md#スキルの演出と背景)） |
| カットイン | コスト5以上の10枚（居合一閃・千刃乱舞・ギガントインパクト・メテオ・ブリザード・絶対零度・シャドウスナイプ・雷雲・雷神の槍・リザレクション）。[長い演出で毎回操作を止めない](#爽快感と入力の手応え)ため、大技に絞った |

### カードの状態の仮設定

カードが付ける状態と、その効果を次のように仮に定める。
持続ターンは味方ターンの開始ごとに1減り、0で消える。
凍結と反射は使われるまで、毒は重なった数が尽きるまで残る。
[防御](#防御と敵の激化)は、候補のSlay the Spire式のブロックを仮に使い、受けたダメージをブロックから先に引いて、次の味方ターンの開始時に消す。

| 状態 | 付けるカード | 効果 |
|---|---|---|
| 出血 | 旋風斬 | 敵が行動するたびに、付けた味方のちからの20%のダメージ |
| やけど | 火の粉、ファイアストーム | 味方ターンの開始時に、付けた味方のまりょくの20%のダメージ |
| 毒 | 毒針 | 味方ターンの開始時に、重なった数×付けた味方のちからの10%のダメージ。そのたびに重なりが1つ減る |
| 凍え | アイスランス、ブリザード | すばやさ-30% |
| 凍結 | 絶対零度 | 次の行動を1回休む |
| 麻痺 | ライトニングボルト | 与えるダメージ-25% |
| 防御ダウン | 鎧砕き | 受けるダメージ+25% |
| 爆炎の刻印 | 爆炎の刻印 | 次の味方ターンの開始時に爆発し、敵全体に炎属性のダメージ |
| 雷雲 | 雷雲 | 味方ターンの開始時に、敵1体へ雷属性のダメージ |
| 攻撃力アップ | 鬨の声 | 与えるダメージ+25% |
| すばやさアップ | 疾風迅雷 | すばやさ+30% |
| リジェネ | リジェネ | 味方ターンの開始時にHPを回復する |
| 挑発 | 守護の誓い | 敵の単体攻撃を引き受ける |
| 反射 | アイスミラー | 次に受ける単体攻撃を1回、攻撃した敵へはね返す。自分はダメージを受けない |
| 炎の加護 | フレイムエンチャント | 攻撃に炎属性を加え、炎が弱点の敵には弱点の倍率を掛ける |
| プロテクト | プロテクト | 受けるダメージ-25% |
| 無敵 | ディバインシールド | ダメージを受けない |

すばやさを変える状態（凍え、すばやさアップ）と、行動順を遅らせる影縫いは、ターン順のしきい値が[未決](#未決事項)のため、戦闘画面のモックでは名前を表示するだけで行動順を変えない。
敵の強化と味方の状態異常はモックの敵・味方に設けていないため、聖なる鉄槌の強化の解除と浄化の光の状態異常の解除も、表示だけにとどまる。

## 未決事項

未決は採用候補や調整・確認待ちを指し、決定済みとして扱わない。

| 領域 | 決める項目 |
|---|---|
| ターン順 | 連続ターンになるしきい値（TODO）、敵が複数いる場合のすばやさの比べ方 |
| 手札 | 手動で捨てる操作を加えるか（試遊で手札が詰まる場合に再検討する。候補：1ターン1枚まで無料） |
| カードの使用 | 1ターンに使えるカード枚数の制限の有無、エネルギー以外の制約 |
| 防御 | 具体的な形式（候補：Slay the Spire式の「ブロック」。そのターンだけ有効な盾） |
| 属性 | 物理属性ごとのクセ（候補：斬＝全体・連続、打＝一撃が重い、貫＝ブロックを一部無視） |
| 弱点の開示 | 未開示の弱点の見せ方（「？」の枠を出すか、何も出さないか）、開示したときの演出、1体に複数の弱点を持たせるか、亜種と開示を共有するか、突く以外に開示する手段を設けるか |
| 数値 | ステータスの項目、カード・装備が参照するステータスと割合、ダメージ・回復・防御の計算式、バフ・デバフの重ね方と持続ターン |
| UPTで威力が変わるカード | 参照するUPTと威力の変え方 |
| 敵 | 行動と予告の内容、激化するターンと変化の内容 |
| 戦闘をまたぐ状態 | HP・戦闘不能・バフ・デバフ・固有スキルのクールターンを次の戦闘へ持ち越すか。旧仕様では「戦闘ごとに全回復して始める」が候補だった |
| ルーン復活 | 費用と回数制限（候補：2回目以降はコスト上昇、または1回まで）、再開時のターン数・エネルギー・手札・激化の扱い、復活画面から編成・装備を変えられるか |
| 中断 | 戦闘中の保存・再開、アプリ終了・背面移行・通信断への対応。部屋の区切りでの中断とは分けて決める |
| 個別コンテンツ | 初期キャラのカードスキル・固有スキル・パッシブスキル、通常敵とボスの行動 |

残っているコードの動作は次のとおりである。

| 項目 | 旧仕様の試作の動作 |

| 回復・防護 | 生存中でHP割合が最も低い味方を回復。防護は味方全員の被ダメージを6秒間45%へ軽減 |
| パッシブ | 守り手の15%軽減、魔法使いの威力+2、斥候の短い攻撃間隔、回復量+10、戦士のダウン値+3 |
| 勝敗 | 敵全滅で勝利、味方全滅で敗北。通常戦120ルーン、ボス300ルーン。結果は一度だけ反映 |
| 無料再戦 | 現在の編成・装備から全状態を作り直す。次の戦闘も全快で開始 |

## 変更と判断の記録

- 2026-10-03：ユーザーの依頼で、カードスキルを重複のないよう50枚作り、効果・演出・挿絵を付けた（[カードスキルの仮設定](#カードスキルの仮設定)、[カードの状態の仮設定](#カードの状態の仮設定)）。属性に打と貫のカードを加え、カードの種類に強化・弱体・支援を加えた。ステータスの項目は未決のまま、ちから・まりょく・まもりを仮に置いた。大技が増えたため、カットインを出すコストを3以上から5以上へ引き上げた。
- 2026-10-01：ユーザーの指示により、山札が尽きたら使ったカードを切り直すのをやめ、はじめの16枚をすべて切り混ぜて新しい山札にすることにした。手札のカードと重なってもよい。
- 2026-09-30：ユーザーと相談し、手札の決まりを定めた。デッキを16枚（4人×4枚）にし、開始時に6枚、2ターン目から毎ターン3枚を引き、上限は9枚とする。上限で引けない分は山札に残し、山札が尽きたら捨て札を切り直す。当初は「上限に満たない分を補充」と「手動で捨てられる」としていたが、捨てる操作を無制限に無料にすると弱いカードを捨て続けて強いカードだけを引けてしまう。制限付きで残す案（Balatroのように回数で縛るなど）も比べたうえで、どのカードもいつでも使えるようにして捨てる操作は設けないことにした。
- 2026-09-29：ユーザーの指示により、敵の弱点を常に表示する方針を改めた。初めて戦うときは弱点を伏せ、味方の誰かが突いたら開示し、以後はその種類の敵で常に表示する（[弱点の開示](#弱点の開示)）。未開示の弱点がカードの数値から分からないよう、現在値には開示した弱点だけを反映する。[探索の行き先の情報](stage-progression.md#行き先を選ぶ情報)、[セーブ](accounts-save.md)、[用語集](../game/glossary.md)、[戦闘画面のモック](screens.md#戦闘画面の見た目モック)の説明へ反映した。モックの画面は、弱点を最初から表示したまま変えていない。
- 2026-09-28：ユーザーの指示により、運動量の単位の名前を「ワット」から「UPT」へ改め、ワットで威力が変わるカードをUPTで威力が変わるカードへ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位upt)）。

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位を「歩」から「ワット」（1歩＝1ワット）へ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位upt)）。歩数で威力が変わるカードを、ワットで威力が変わるカードへ改めた。

2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、戦闘をターン制のカードバトルへ置き換えた。
