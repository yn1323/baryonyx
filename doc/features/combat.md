# 戦闘システム

[機能索引](README.md) / [探索と進行](stage-progression.md) / [試作と評価基準](../game/mvp.md)

2026-09-15にユーザーが提示した「てくてくダンジョン｜探索・進行・戦闘仕様」の戦闘部分を管理する。
[初期企画](../game/brief.md)から変更した案は末尾に記録し、現行ルールへ混ぜない。
確定・設計方針・仮設定・未確定は[仕様の確度](README.md#仕様の確度)に従って区別する。
運動データ連携、運動目標、通貨経済、ガチャ・課金、世界観・シナリオの詳細は別設計とする。

## 確定している方針

### 基本操作と共通の戦闘時間

[4人パーティ](party.md)で行うリアルタイムのセミオート戦闘とする。
通常攻撃は自動、アクティブスキルはプレイヤーが手動で使う。
雑魚複数戦と単体ボス戦の両方を用意し、基本のクリア条件は敵全滅とする。
プレイヤーによる戦闘中の移動・回避、通常攻撃の連打、タイミング入力の成功を前提とする操作は入れない。

キャラを選択すると強スローになり、使うスキルを選ぶ。
使用を確定して選択画面を閉じると、元の戦闘速度へ戻る。
標的が誰かを明確に表示する。
キャラ・スキル・標的を選ぶ順序とタップ回数はUI設計で詰める。

通常攻撃、キャストタイム、クールダウン、敵の予告、ダウンの残り時間は、共通の戦闘時間に従う。
スロー中はすべて同じ割合で遅くする。
自分のクールダウンだけを実時間で回復させるなど、選択画面を開いて待つことが有利になる構造は作らない。

### 通常攻撃と素早さ

通常攻撃のテンポは素早さに依存し、素早いキャラほど攻撃間隔が短く、手数が増える。
通常攻撃もHPとダウン残量の両方を削る。
ダウン専用スキルがなくても、攻撃を続ければダウンを狙える。

### アクティブスキルと個別クールダウン

スキルには、HPダメージに関する性能、ダウン値、武器種・属性、対象、個別クールダウン、キャストタイム、追加効果などを持たせる。
HPへの威力とダウン値は「小・中・大」ではなく、具体的な数値で示す。
実ダメージの予測か基礎威力などのパラメーターかは、ダメージ式と合わせて決める。
各キャラのスキル構成は[パーティ仕様](party.md)、試作時の数は[試作範囲](../game/mvp.md#最初に作る戦闘試作)で管理する。

スキルは使用後に個別のクールダウンへ入り、回復すると再使用できる。
時間は個々のスキルで異なる。
共通スキルゲージ、MP、必殺技ゲージなどの追加消費ゲージは使わない。
クールダウンを使用確定・効果発生・動作終了のどこから数えるかは未確定とする。

### キャストタイムの定義

スキルの使用確定から、最初のダメージ・回復・防護効果が発生するまでを**キャストタイム**とする。
演出全体の長さとは分け、各スキルの内部パラメーターとして持たせる。
プレイヤーに秒数の確認・暗記を要求せず、スキル説明へ常時「発動0.8秒」と表示しない。
技の構えや詠唱で違いを伝える。

ダウンはボタンを押した時点では成立しない。
実際にダウン値が適用され、敵の残量を削り切った時点で成立する。

### ダウンの名称と基本ルール

| 用途 | 正式な名称・扱い |
|---|---|
| 仕組み・成立 | **ダウン** |
| スキルの削る性能 | **ダウン値** |
| 成立中の状態 | **ダウン中** |
| 敵側の残量 | **ダウンゲージ**。内部の呼び方で、表示はリング |

旧称の「ブレイク」「崩し」「体勢」「隙あり」を正式用語として混在させない。

敵はHPとは別にダウン残量を持ち、攻撃で残量を減らしてゼロにするとダウンする。
HPがゼロになれば倒せるため、ダウンは撃破の必須条件ではない。
スキルごとにHPへの威力とダウン値を変える。

ダウン中は敵の行動が停止し、受けるHPダメージが増える。
予告・準備中の大技はキャンセルされる。
大技を中断できるのはダウンが成立したときだけで、ダウン値の高い技の命中、弱点への一致、リングの一部減少だけでは中断しない。
別の専用中断スキルを前提にしない。
防護は大技を止めずに耐える手段、回復は受けた被害を立て直す手段とする。

ダウン終了後、敵のダウンゲージは満タンへ戻る。
ダウン中の値処理、持続時間、補正などは[候補](#ダウンと戦闘前後の状態処理の候補)と[未確定事項](#未確定事項)で管理する。

### 敵の弱点属性と弱点武器

敵ごとに弱点属性・弱点武器を設定し、一致はHPダメージとダウン値の両方に影響する。
どの攻撃でもダウンを狙え、弱点は削る効率を変える。

特定属性・武器でしかダウン値を与えられない制限、属性同士・武器同士の複雑な相性表、部位別HP・部位別ダウンゲージは入れない。
これは[職業による装備適性](party.md)とは別のルールである。
倍率と、属性・武器の両方に一致した場合の扱いは仮設定とする。

### HPバーとダウンリング

敵のHPは横バー、ダウン残量はHPバー左側のドーナツ型リングで表示する。
HPの下にもう一本の横バーは置かない。

| 残量 | リングの見え方 |
|---|---|
| 満タン | 全周が黄色 |
| 減少中 | 黄色い円弧が減り、黒い部分が増える |
| ゼロ | 全周の黄色がなくなり、ダウン成立を演出する |

色はグラデーションにせず、黄色と黒の境界が明確なドーナツグラフ型にする。
中央に現在残量の数字や％を置かない。
黒い部分も暗い背景で輪郭が分かるようにする。
リングが満タンであることは、内部最大値が100点であることを意味しない。
最大値は敵ごとに未確定である。

ダウン成立時は、短い「ダウン！」表示と敵の姿勢・反応で攻撃チャンスを伝える。
空のリングだけで済ませない。
ダウン中の状態アイコンへの置換と残り時間の見せ方は未確定とする。

### 戦闘中の情報の優先順位

標的、ダウンリング、大技予告、ダウン成立表示を、攻撃エフェクトやダメージ数字で隠さない。
スキル詳細ではHPへの威力とダウン値を数値で比較できるようにし、敵側の現在残量はリングで判断する。
弱点・狙える報酬などの[探索情報](stage-progression.md#行き先を選ぶ情報)も短く読み取れる形にする。

### 敗北と成果の保護

敗北しても、獲得済みのルーン・装備・探索成果を失わない。
敗北による資源の自動徴収、装備ロスト、挑戦回数の消費は設けない。
失敗した戦闘の未獲得報酬を付与する意味ではなく、報酬の確定タイミングは別途定義する。

無料で再戦でき、編成変更、別の道の選択、帰還へ進めるようにする。
再挑戦のために長い序盤をやり直させない。

### 無料再戦とルーン復活

| 選択 | 敵の状態 | 味方の状態 |
|---|---|---|
| 無料で再戦 | HP最大・ダウンゲージ満タンに戻し、戦闘を最初からやり直す | 全快して開始 |
| ルーン復活 | その戦闘で削ったHPとダウンゲージを維持し、戦闘を続ける | 全快して再開 |

ルーンは復活を明示的に選んだときだけ消費する。
敵HPに加えて、ダウン残量も維持する点は確定である。
味方のクールダウン、状態異常・バフ・デバフ、敵のダウン中状態や予告をどう扱うかは別途決める。

復活画面では、無料再戦・編成変更・戻るを普通の選択肢として見せ、ルーン復活だけを強く押し出さない。
成果が残ることと消費量を明示し、選択を急かすカウントダウンを付けない。
確認中は戦闘時間を停止する。
復活直後に状況が分からないまま全滅する再開を避ける方針とし、再開前の猶予や予告の扱いは未確定とする。

## 設計方針

### スキルを使うか温存するかの判断

「使える技を今使うか、あとに温存するか」を判断の中心にする。
ダウンが近ければ火力技を待ち、敵の大技に備えるならダウン値の高い技を残す。
ダウンが難しければ防護で受け、回復で立て直す。
すべて温存することも、使える順に全部押すことも、常に正解になる構造は避ける。

### 通常攻撃と素早さの調整

現段階では、素早さをスキルのキャストタイムやクールダウンには連動させない方向とする。
通常攻撃の手数だけでもHP・ダウン双方へ効くため、素早さだけを伸ばすのが最適にならないようにする。
育成後も攻撃演出が潰れるほど速くならないよう、攻撃間隔に下限を設ける方向とする。
計算式と最短間隔は未確定である。

### キャスト中の反応と仲間の行動

使用確定直後から構え・詠唱・ボタン表示を変え、入力に即座に反応する。
効果が出るまで入力を無視されたように見せない。

使用キャラだけが通常攻撃を止めて準備し、ほかの仲間は通常攻撃を続ける。
別キャラへのスキル指示も行える方向とし、使用キャラはスキル動作後に通常攻撃へ戻る。
通常の被弾ではキャストを中断しない方向とする。
戦闘不能になった場合は停止する。
対象が発動前に倒された場合の切り替えは、候補として扱う。

### キャストタイムによる選択

大きく削るが発動の遅い技と、削る量は少ないが素早く当たる技を分ける。
敵の大技に間に合わせるには速い技、余裕があるときは強い技を選べるようにする。

ダウンさせてから長い技を選んでも、落ち着いてご褒美の一撃を入れられる余裕を確保する。
ダウン直前の先読み詠唱を基本操作として要求しない。

### ダウンと編成のバランス

ダウン重視技でもHPを削り、火力重視技でもある程度ダウン値を与える方向とする。
完全な専用役しか機能しない形を避ける。
編成と装備による得意な勝ち方の違いは[装備厳選の目的](equipment.md#戦い方を変える装備更新)で扱う。

ダウンは強くて気持ちよいが、全戦闘の必須手順にはしない。
弱い敵はダウンする前に倒せてよい。
強敵の大技も、毎回ダウンさせなければ全滅する設計を基本にしない。
ダウンが続いて敵がほぼ動けない状態や、必ず同じ手順を踏むだけの戦闘になっていないかを検証する。

### 追撃と連携の範囲

追撃は、特定のスキルまたはパッシブとして、一部キャラ・装備に追加する方向とする。
全員に共通の追加操作は要求しない。
「スキルを使うと仲間が追撃する」「ダウン成立に反応して追撃する」は候補例であり、採用済みのスキルではない。

発動条件、対象、追撃側のダウン値、発動回数、クールダウン、追撃から追撃への再帰連鎖は、ユーザーの指定により議論を保留する。
詳細を決めてから、試作に最小の例を加える。

仕込み・起爆は将来のキャラ固有候補とする。
スキルの連携予約、全員共通の印ゲージ、専用の連携ゲージは現行基本ルールに追加しない。
「溜めて大ダメージ」の楽しさは、まずクールダウンが終わったスキルを温存し、ダウン中に集中して使うことで狙う。
連撃・追撃の楽しさは、キャラと装備の追加効果で広げる。

### 爽快感と入力の手応え

長い必殺技映像で毎回操作を止めず、命中音、短い衝撃演出、敵の反応、HPが大きく減る動き、仲間の連続行動で爽快感を出す。
クールダウン完了を過剰に点滅させ、毎回使うように急かさない。
ダウン後に慌てて連打させず、スローを使って落ち着いて判断できるようにする。

### ボスの歯ごたえ

HPを増やすだけで戦闘を長くしない。
大技をダウンで止めるか、防護で受けるか、ダウン中に火力を集中するか、終盤に温存をやめて倒し切るかを判断できるようにする。
通常のボス戦が3分を超える場合は、同じ展開を繰り返しすぎていないかを確認する。
3分で強制終了する制限ではない。

## 仮設定と候補

### 通常攻撃間隔の仮例

| 素早さの水準 | 通常攻撃間隔 |
|---|---:|
| 低め | 2.4秒 |
| 標準 | 2.0秒 |
| 高め | 1.6秒 |

テンポを比較するための仮設定であり、素早さからの計算式ではない。

### クールダウンの仮例

| 役割の例 | クールダウン |
|---|---:|
| HPダメージ重視の攻撃 | 12秒 |
| ダウン値重視の攻撃 | 18秒 |
| 全体防護 | 24秒 |

役割ごとの固定値ではなく、個別スキルを試すための仮設定である。

### キャストタイムの仮例

| 内部区分の例 | キャストタイム |
|---|---:|
| 短 | 0.3秒 |
| 中 | 0.8秒 |
| 長 | 1.5秒 |

区分名と秒数は仮設定である。
全スキルを厳密に3値へ固定するか、後に個別調整を許すかは未確定とする。
スキル選択画面へ秒数を表示するための区分ではない。

### 弱点倍率の仮案

| 条件 | HPダメージ | ダウン値 |
|---|---:|---:|
| 弱点に一致しない | ×1.0 | ×1.0 |
| 弱点属性または弱点武器に一致 | ×1.5 | ×1.5 |
| 両方に一致 | ×1.5 | ×1.5 |

1.5倍と両方一致時の非重複は試作用の候補であり、確定値ではない。
HPとダウンで同じ倍率にするかも最終調整事項とする。
追撃の弱点判定には、発動元ではなく追撃自身の属性・武器を使う案があるが、追撃の詳細とともに未確定とする。

### ダウンと戦闘前後の状態処理の候補

| 項目 | 候補・現時点の方向 | 未確定の部分 |
|---|---|---|
| ダウン中の値処理 | 次回分のダウン値を先行蓄積しない案を基本のたたき台とする | 採否と細部を最終確認する |
| 追加のダウン耐性・無効時間 | まず入れず、必要値・持続時間などで調整する方向 | 実装必須とは決めていない |
| 次戦の味方 | 戦闘ごとにHP・戦闘不能・状態異常を回復し、万全で始める案 | 戦闘後の全回復は個別仕様としての最終確認対象 |
| 味方のクールダウン | 次戦・無料再戦・ルーン復活でリセットする案 | すべて確定扱いにしない |

戦闘後の全回復案では、回復役を一戦の中で立て直す役として成立させる。
無料再戦・ルーン復活の「全快」と、勝利後の全回復・状態異常等の回復範囲を混同しない。

### 対象切り替えとUIの候補

| 項目 | 候補 | 未確定の部分 |
|---|---|---|
| 発動前に対象が倒された場合 | 有効な別対象へ切り替えて空振りを減らす | 切り替え条件などの詳細 |
| ダウン中のリング | 状態アイコンへ置き換える | 採否と残り時間の表示 |
| ダウン成立の予測 | 「この技でダウンできる」と予告する | 採否と追撃を含む予測範囲 |

### 戦闘時間の仮目標

適正な育成・編成で初めて攻略するときの目安とする。
スキル選択中のスローと演出を含む実時間で測り、リザルトと装備選びは含めない。

| 戦闘 | 目標時間 |
|---|---:|
| 通常の敵 | 20〜40秒 |
| 寄り道の強敵 | 45〜75秒 |
| ボス | 90〜150秒 |

すべて仮設定であり、強化後の再訪は短くなってよい。
最低戦闘時間を保証するための長い無敵時間や強制演出は入れない。

初回ボス攻略では、2〜3回程度のダウン・勝負どころがある展開を試作の目標候補にする。
そのダウン回数を達成しないと勝てないルールではない。
HP50％から大技の対象を変える程度の単純な後半変化も、個別ボスの候補とする。
全ボス共通の仕様にはしない。

### スキル性能の数値サンプル

役割比較用の仮例であり、最終的なスキル名・威力・ダメージ式・クールダウン・採用キャラを確定するものではない。

| 仮の攻撃 | HPダメージの比較値 | ダウン値 |
|---|---:|---:|
| 通常攻撃 | 100 | 10 |
| 砕き斬り〈剣〉 | 120 | 40 |
| 大火球〈炎〉 | 300 | 10 |
| 援護射撃〈弓・追撃例〉 | 60 | 10 |
| 速突き〈短キャスト例〉 | 90 | 20 |
| 砕き打ち〈長キャスト例〉 | 150 | 60 |

キャスト比較の例では、速突きを0.3秒、砕き打ちを1.5秒としている。
スキル欄にキャスト秒数を表示する意味ではない。

弱点倍率の仮案1.5倍を使うと、砕き斬りはHPダメージ120→180、ダウン値40→60となる。
敵の残量60なら、その攻撃でダウンできる例になる。
実戦表示は「残量60」という数字ではなくリングとする。

## 未確定事項

未確定は採用候補や調整・確認待ちを指し、決定済みとして扱わない。

| 領域 | 決める項目 |
|---|---|
| 素早さ・通常攻撃 | 攻撃間隔の計算式と最短間隔、通常攻撃の標的選択 |
| スキル | 個別性能、クールダウンの起算点・短縮、同一キャラへの連続指示、キャスト中の通常攻撃タイマー、対象消失時の切り替え条件、操作のキャンセル |
| 戦闘計算 | ダメージ・回復・防御・耐性・クリティカル、加算・乗算・上書き・上限・丸め・発動順 |
| ダウン | 敵ごとの最大値、持続時間、被HPダメージ補正、通常時の自然回復の有無、ダウン中の値処理、復帰後の次の行動のタイミング |
| 弱点 | 倍率、属性と武器が両方一致した場合の扱い、HPとダウンに同じ倍率を使うか |
| 追撃 | 発動条件・対象・ダウン値・回数・クールダウン・再帰連鎖・追撃自身の弱点判定。今は議論を保留 |
| UI・速度 | キャラ・技・標的の入力手順、スロー倍率、ダウン中のリング・残り時間・成立予測、早送りの採否と倍率 |
| 敵と状態異常 | 敵AI、予告時間、状態異常の重複・持続・解除・ボス耐性、戦闘不能・蘇生・敗北の詳細判定 |
| 戦闘前後 | 勝利後の全回復ルールの最終明文化、戦闘開始・次戦・無料再戦・復活時のクールダウン、報酬確定タイミング |
| ルーン復活 | 費用・回数制限、味方の状態異常・バフ・デバフ、敵の予告・準備中の大技・ダウン中状態と残り時間、再開前の猶予 |
| 中断 | 戦闘中の保存・再開、アプリ終了・背面移行・通信断への対応。部屋の区切りでの中断とは分けて決める |
| 個別コンテンツ | 初期4人のスキル・パッシブ、通常敵とボスの行動、装備効果、最終的な戦闘時間 |

## 変更と判断の記録

2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、初期企画の戦闘ルールを更新した。
操作・計算・表示・再戦・試作の基準を揃えるため、パーティ、装備、経済、画面、セーブ、用語集、MVP、個別データの記入欄へ反映した。

| 過去の案 | 現在の扱い |
|---|---|
| 共通スキルゲージ＋クールダウン | スキルごとのクールダウンのみ |
| 「ブレイク」「崩し」「体勢」「隙あり」などの正式用語 | 「ダウン」「ダウン値」「ダウン中」に統一 |
| HPの下に2本目のバー | HP左側の黄／黒ドーナツリング |
| 敵のダウン残量を数字で表示 | リングで表し、残量数字・％を常設しない |
| キャスト時間をスキル欄へ秒数で常設 | 内部パラメーターとして持ち、動作で伝える |
| タイミング入力・移動回避を必須にする | 現行の基本操作には入れない |
| 1戦2〜4分を全戦闘の目安にする | 通常敵・強敵・ボスで分けた仮目標へ更新 |
