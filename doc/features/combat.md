# 戦闘システム

[機能索引](README.md) / [探索と進行](stage-progression.md) / [パーティ](party.md) / 根拠：[2026-09-27の企画見直し](../game/redesign-2026-09-27.md)

2026-09-27の企画見直しで、戦闘をSlay the Spireを参考にしたターン制のカードバトルへ変更した。
リアルタイムのセミオート戦闘、スロー、キャストタイム、ダウン、無料再戦などの旧仕様は[変更と判断の記録](#変更と判断の記録)へ移し、現行ルールへ混ぜない。
確定・設計方針・仮設定・未決は[仕様の確度](README.md#仕様の確度)に従って区別する。

## 確定している方針

### 戦闘の形式

[4人パーティ](party.md)で、ターン制のカードバトルを行う。
4人が装備したカードスキルを合わせた12枚が**デッキ**になる（[キャラクターの構成](party.md#キャラクターの構成)）。
プレイヤーは手札のカードにエネルギーを払って使う。
雑魚複数戦と単体ボス戦の両方を用意し、基本のクリア条件は敵全滅とする。
移動・回避やタイミング入力を前提とする操作は入れない。

標的が誰かを明確に表示する。
敵のHPは横バーで表示する。

### ターン順

味方パーティの合計すばやさと、敵のすばやさを比べてターン順を決める。
差が大きい場合は、同じ側が連続でターンを得る（例：味方が2ターン連続）。
連続ターンになるしきい値は未決とする。

### エネルギーとコスト

**エネルギー**は、カードと固有スキルに払う戦闘中の資源である。
シャドウバースと同じく、初期値の3からターンごとに最大値が1増え、上限は9とする。
各カードに**コスト**があり、使うとその分のエネルギーを消費する。
ダンジョン内で、エネルギーを次の戦闘へ持ち越さない。

### 手札

手札はシャドウバースと同じく次のターンへ持ち越す。
毎ターン、手札の上限に満たない分だけ補充する。
プレイヤーは手札のカードを手動で捨てられる。
手札の上限枚数と、捨てる操作の制限は未決とする。

### カードの種類と流れ

カードには、攻撃、バフ、デバフ、回復、エネルギーコスト軽減、数ターン持続する攻撃などの種類がある。
対象は単体と全体がある。
序盤は仕込みのカードで準備し、終盤に高コストの大技を使う流れにする。

UPTで威力が変わるカードを入れる。
デッキに入れるかどうかはプレイヤーが選ぶ。
参照するUPTと威力の変え方は未決とする（[UPTボーナス](step-bonus.md)とは別の仕組み）。

### 威力の決め方

攻撃・回復のカードと装備は、固定値を持たない。
効果量は「装備したキャラのステータス〇〇の〇％」で決まる。
参照するステータスと割合は、カードや装備ごとに決める。

### 属性と弱点

| 分類 | 属性 |
|---|---|
| 魔法 | 炎・氷・雷 |
| 物理 | 斬・打・貫 |

キャラごとに装備できる属性が異なる（[キャラクターの構成](party.md#キャラクターの構成)）。
属性はカード効果の対象にもなる（例：手札の斬属性カードのコストをすべて1下げる）。

敵ごとに弱点の属性を持ち、カードの属性が一致するとダメージを1.5倍にする。
属性による耐性（軽減・無効）は設けない。
属性同士の相性表や部位別HPは入れない。

### 弱点の開示

敵の弱点は、初めて戦うときは画面に表示しない。
味方の誰かがカードで弱点を突くと、その弱点をその場で**開示**し、画面に表示する。
同じ戦闘にいる同じ種類の敵にも、同時に表示する。

開示は敵の種類ごとにプレイヤーの記録として残す。
以後はその種類の敵と戦うたびに、開示した弱点を最初から表示する。
冒険の終了やルーン復活でも、開示した弱点を伏せ直さない。

### 防御と敵の激化

ダウンは廃止した。
敵の激しい攻撃には、防御を上げるなどして備える。
防御の具体的な形式は未決とする。

敵は「〇ターン以降」のように、ターンの経過に応じて攻撃を激しくする。

### 固有スキル

各キャラの[固有スキル](party.md#キャラクターの構成)は、手札とは別の、いつでも使える枠に置く。
使うとエネルギーを消費し、再使用までの**クールターン**がある。

### 敗北とルーン復活

味方が全滅すると、[冒険は終了する](stage-progression.md#冒険の終了と獲得物の保持)。
それまでに獲得した装備・スキルなどは失わない。
敗北による資源の自動徴収、装備ロスト、挑戦回数の消費は設けない。

ルーンを使えば復活して、冒険を続きから再開できる。
ルーンは復活を明示的に選んだときだけ消費する。
旧仕様で確定していた「その戦闘で削った敵HPを維持し、味方は全快して再開する」は、今回の内容と両立するため維持する。
再開時のターン数・エネルギー・手札・激化の扱いは未決とする。

戦闘単位の無料再戦は廃止する。
見直しの資料で開発者の最終確認が必要とされているため、[確認待ち](#確認待ち)に記録する。

## 設計方針

### カードの数値の見せ方

カードの威力・回復量は、装備画面の時点で実数値（例：243ダメージ）を表示する。
カードや装備を付け替えるときは、差分（例：243 → 281 ▲38）を表示する。
戦闘中は、バフと開示した弱点を反映した現在値を表示する。
未開示の弱点は現在値に反映しない（数値の変化で弱点が分かってしまうため）。
実際のダメージは、未開示でも弱点に一致すれば1.5倍になる。

### 固有スキルの位置づけ

固有スキルはコストを軽め（1〜2程度）、効果を控えめにする。
クールターンで連打を防ぎ、残りクールターンをボタンに表示する。

### 戦闘中の情報の優先順位

標的、開示した敵の弱点、敵の次の行動の予告を、攻撃エフェクトやダメージ数字で隠さない。
予告では、特に激化ターンの大技を見せる。
[探索情報](stage-progression.md#行き先を選ぶ情報)も短く読み取れる形にする。

### 爽快感と入力の手応え

長い演出で毎回操作を止めず、命中音、短い衝撃演出、敵の反応、HPが大きく減る動きで爽快感を出す。
弱点に当たったときは、ダメージ数字の色と大きさを変えて強調する。

### ボスの歯ごたえ

HPを増やすだけで戦闘を長くしない。

### 復活画面

復活画面では、帰還もルーン復活と同じ普通の選択肢として並べ、ルーン復活だけを強く押し出さない。
成果が残ることと消費量を明示し、選択を急かすカウントダウンを付けない。

## 実装との対応

本ページは企画上の要求・設計方針・未決事項を記す。
カードバトルは未実装である。

2026-09-19に[操作試作](game-wireframe.md)へ接続した戦闘計算が、画面を削除した後もコードに残っている。
計算は[CombatEncounter](../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatEncounter.cs)、個別性能は[CombatPrototype](../../client/Assets/Baryonyx/Features/Combat/Runtime/CombatPrototype.cs)にある。
これは旧仕様（リアルタイムのセミオート戦闘、ダウン、無料再戦）の試作であり、現行の企画と一致しない。
残す・作り直す・削除するかは、開発者と相談して決める。

残っているコードの動作は次のとおりである。

| 項目 | 旧仕様の試作の動作 |
|---|---|
| 共通時計 | 1/60秒刻み。選択中は0.12倍。すべての攻撃、詠唱、予告、クールダウン、ダウン時間に適用 |
| 通常攻撃 | 選択中の生存敵へ自動攻撃。標的が倒れたら先頭の生存敵へ切り替える |
| スキル | 各キャラ2つ。確定時から個別クールダウンを開始し、詠唱完了時に命中。同じ味方へ詠唱中の再指示は不可 |
| 詠唱 | 0.3・0.8・1.5秒。詠唱中は通常攻撃の待ち時間を停止。倒れた味方の詠唱は中止 |
| ダメージ | 通常攻撃は装備に由来する威力。攻撃スキルはスキル威力＋味方威力。整数へ丸めてHPから引く |
| 弱点 | 属性または武器の一致でHPとダウン値を1.5倍。両方一致しても重ねない |
| ダウン | 通常時の自然回復なし。0で5秒間停止し、予告を解除。ダウン中のHPダメージ1.5倍。終了時に最大残量へ戻す |
| 敵の予告 | 通常敵は単体への3秒予告、ボスは全員への4秒予告。予告中の通常攻撃は停止。部分的なダウン値減少では止まらない |
| 回復・防護 | 生存中でHP割合が最も低い味方を回復。防護は味方全員の被ダメージを6秒間45%へ軽減 |
| パッシブ | 守り手の15%軽減、魔法使いの威力+2、斥候の短い攻撃間隔、回復量+10、戦士のダウン値+3 |
| 勝敗 | 敵全滅で勝利、味方全滅で敗北。通常戦120ルーン、ボス300ルーン。結果は一度だけ反映 |
| 無料再戦 | 現在の編成・装備から全状態を作り直す。次の戦闘も全快で開始 |
| 復活 | 100ルーン。味方HPとクールダウンを初期化し、敵HPとダウン状態を保持。敵の予告を解除 |
| 背面移行 | 戦闘を停止し、復帰時に経過分を消化しない。終了後の再開保存は未実装 |

現在の実装入口は[機能索引の実装欄](README.md#現在の実装)で確認する。

## 変更と判断の記録

- 2026-09-29：ユーザーの指示により、敵の弱点を常に表示する方針を改めた。初めて戦うときは弱点を伏せ、味方の誰かが突いたら開示し、以後はその種類の敵で常に表示する（[弱点の開示](#弱点の開示)）。未開示の弱点がカードの数値から分からないよう、現在値には開示した弱点だけを反映する。[探索の行き先の情報](stage-progression.md#行き先を選ぶ情報)、[セーブ](accounts-save.md)、[用語集](../game/glossary.md)、[戦闘画面のモック](screens.md#戦闘画面の見た目モック)の説明へ反映した。モックの画面は、弱点を最初から表示したまま変えていない。
- 2026-09-28：ユーザーの指示により、運動量の単位の名前を「ワット」から「UPT」へ改め、ワットで威力が変わるカードをUPTで威力が変わるカードへ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位upt)）。

- 2026-09-27：ユーザーの指示により、ゲーム内の運動量の単位を「歩」から「ワット」（1歩＝1ワット）へ改めた（[ゲーム共通の単位](exercise-rewards.md#ゲーム共通の単位upt)）。歩数で威力が変わるカードを、ワットで威力が変わるカードへ改めた。

2026-09-27：ユーザーが提示した[企画見直し](../game/redesign-2026-09-27.md)により、戦闘をターン制のカードバトルへ置き換えた。
エネルギー・手札・属性と弱点・激化・固有スキル・冒険終了とルーン復活を確定事項として反映し、資料の未決・候補は未決事項に分けた。
無料再戦の廃止は反映したうえで、資料の付記に従い開発者の最終確認を待つ。
旧戦闘の試作コードは現行の企画と一致しないことを明記し、扱いは開発者との相談に回した。
パーティ、育成、装備、探索、画面、用語集、MVP、個別データの記入欄へ反映した。

| 過去の案 | 2026-09-27時点の扱い |
|---|---|
| リアルタイムのセミオート戦闘。通常攻撃は自動、スキルは手動。キャラ選択で強スロー、共通の戦闘時間 | ターン制のカードバトル |
| スキルごとの個別クールダウンのみ。共通スキルゲージ・MP・必殺技ゲージは使わない | エネルギー（初期3、毎ターン最大値+1、上限9）とカードのコスト。固有スキルだけクールターンを持つ |
| キャストタイム（使用確定から最初の効果までの内部時間） | 廃止 |
| ダウン／ダウン値／ダウン中／ダウンゲージ。ダウンで大技を中断し、濃淡で残量を表す | 廃止。激しい攻撃は防御で受ける |
| 素早さで通常攻撃の間隔が変わる | すばやさでターン順と連続ターンを決める |
| 弱点属性と弱点武器。一致でHPとダウン値を1.5倍（仮案） | 属性（炎・氷・雷・斬・打・貫）の弱点。一致で1.5倍。常に表示し、耐性は設けない |
| スキルのHP威力とダウン値を具体的な数値で持つ | カードと装備は固定値を持たず、キャラのステータスの％で決める。装備画面で実数値を表示する |
| 無料再戦＋ルーン復活。無料再戦は戦闘を最初から、復活は削った状態を保って続ける | ルーン復活のみ。負けたら冒険終了。無料再戦の廃止は開発者の最終確認待ち |
| 使える技を今使うか温存するかを判断の中心にする | 序盤は仕込みのカードで準備し、終盤に高コストの大技を使う流れにする |
| 追撃は一部キャラ・装備の技やパッシブとして追加する方向（詳細は保留） | カードバトルの仕様には含めていない。採否は未決 |
| 戦闘時間の仮目標（通常の敵20〜40秒など）、スキル性能の数値サンプル | 旧戦闘の試作値として使わない |

2026-09-15：ユーザー提示の探索・進行・戦闘仕様を根拠に、初期企画の戦闘ルールを更新した。
