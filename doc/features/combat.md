# 戦闘と効果の計算

[機能索引](README.md) / 根拠：[初期企画](../game/brief.md)

## 確定している方針

- リアルタイム＋セミオート。通常攻撃は自動、スキルはプレイヤー操作とする。
- 各キャラのアクティブスキルは2〜3個とする方針である。
- パーティ共通スキルゲージと、スキル個別のクールダウンを使う。
- 別の必殺技ゲージは設けない。
- スキル選択中は時間が強くスローになる。
- 敵の次の行動予告を表示し、防御・回復・妨害やバフのタイミングを判断する。
- 雑魚複数戦と単体ボス戦を用意し、基本のクリア条件は敵全滅とする。
- 敗北によるルーン減少、装備ロスト、挑戦回数減少を設けない。
