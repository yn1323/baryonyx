# パッシブスキル

[機能索引](README.md) / [キャラクターとパーティ編成](party.md) / [戦闘システム](combat.md) / [パッシブの定義](../catalog/passives/README.md)

**パッシブスキル**は、キャラが持ち、戦闘中に操作なしで働く効果である。
デッキのカードにはならず、条件がそろうと自動で働く。
このページは、パッシブを考えるときの方針と、仮データの9人に割り当てた仮の18個をまとめる。
1つずつの意図・数値・組み合わせは[パッシブの定義](../catalog/passives/README.md)に1個1ファイルで書く。

## 確定している方針

- 各キャラはパッシブスキルを2つ持つ（[キャラクターの構成](party.md#キャラクターの構成)）。
- パッシブはレベルアップで解放する（[育成と強化](progression.md)）。
- 装備・パッシブスキル・スキル・パーティ構成の組み合わせでシナジーを作る（[パーティ](party.md#確定している方針)）。

## 設計方針

2026-10-21、ユーザーの依頼「パッシブスキルをまじめに考えてほしい」を受けて定めた方針である。
パッシブを足す・直すときは、この節を満たしているかを確かめる。

### パッシブが担う役割

デッキ（最大24枚）は4人のカードが混ざるため、カードだけでは「このキャラがいると戦い方が変わる」という手応えが出にくい。
パッシブは、このキャラらしい戦い方を、戦闘の決まりとして表す。
カードは毎回プレイヤーが選んで使うが、パッシブは編成した時点で効き続ける。
そのため、パッシブはパーティに誰を入れるかを決める一番の材料になる。

アクセサリーも、付けたキャラのステータスの底上げや、ちょっとした効果を与える（[アクセサリー](equipment.md#アクセサリー)）。
役割が重ならないよう、ステータスをそのまま上げる効果（「物攻+10%」「速度+10%」）はアクセサリーに任せ、パッシブにしない。
パッシブは「どんなときに」（きっかけ・条件）と「何が起きるか」（働き）の組で作る。

### キャラの見立てから作る

パッシブを考える前に、キャラごとに次の3つを1行ずつ決める。
Hearthstoneは職業の個性を、職業らしさ（ファンタジー）・得意なこと・苦手なことの3つで定めている（[Classes](https://hearthstone.wiki.gg/wiki/Classes)、2026-10-21確認）。

| 観点 | 決めること |
|---|---|
| らしさ | 設定と見た目から、そのキャラが戦闘で何をしていると気持ちいいか |
| 得意 | パッシブで伸ばす戦い方。パーティの中で何を引き受けるか |
| 苦手 | パッシブで補わないこと。苦手があることで、ほかのキャラと組む理由が生まれる |

キャラの正式な設定が決まっていないときは、[自キャラのLv100のステータス](progression.md#自キャラのlv100のステータス)の役割の見立てを手がかりにする。
見立てから作ったパッシブは候補として扱い、キャラの設定が決まったら見直す。

### 2つのパッシブの分担

1人の2つのパッシブは、解放する順に役割を分ける。

| | 1つ目（早く解放する） | 2つ目（後で解放する） |
|---|---|---|
| 狙い | そのキャラの戦い方を、最初の戦闘から教える | 組み合わせで大きく伸びる。編成とデッキを組む理由になる |
| 働く回数 | ほぼ毎戦闘、毎ターン働く | 条件がそろったときに強く働く |
| 説明文 | 1行で、読めばすぐ得が分かる | 2行まで。ほかのキャラのカード・固有スキルの覚醒の枝・状態とつながる |

Slay the Spireの初期レリックは、そのキャラの仕組みを1ターン目から見せる（例：Cracked Coreは戦闘の始めにオーブを1つ出し、オーブを使う戦い方へ導く。[Relics List](https://slaythespire.wiki.gg/wiki/Relics_List)、2026-10-21確認）。
1つ目のパッシブは、これと同じ役目を持つ。

### 見た目は単純、使い込むと深い

説明文は初めて遊ぶ人がそのまま得をできる単純さにし、慣れた人には並べ方や組み合わせを考える余地を残す。
Magic: The Gatheringの開発は、初心者には単純に、上級者には複雑に見えるカードを「レンティキュラー・デザイン」と呼び、目指している（[Lenticular Design](https://magic.wizards.com/en/news/making-magic/lenticular-design-2014-12-15)、2026-10-21確認）。
例えば、ミナの[あふれる祈り](../catalog/passives/passive-overflowing-prayer.md)は、初めての人には「回復が無駄にならない」と読め、慣れた人は敵の大技の予告に合わせて満タンの味方へ回復してブロックを貯める。

### パーティとつなぐ

1人の2つのうち少なくとも1つは、ほかの味方に触れるものにする。
触れるとは、ほかの味方のカード・状態・HPを条件や対象にするか、パーティで共有するエネルギーや手札を動かすことである。
初期企画の「装備×パッシブ×スキル×パーティ構成でシナジーを作り、倍率が積み重なって数字が伸びる気持ちよさ」（[初期企画](../game/brief.md)）を、パッシブ同士のつながりで作る。

同じ仕掛け（きっかけと働きの組）を、2人のキャラに持たせない。
Hearthstoneの開発は、職業同士が同じ振る舞いを持ちすぎると個性が失われるとして、重なりを適度に抑えている（[Class](https://hearthstone.wiki.gg/wiki/Class)、2026-10-21確認）。
新しいパッシブは、[仮の18個](#仮データの9人のパッシブ)の「仕掛け」の列と見比べてから決める。

### 値打ちを見積もる

パッシブの値打ちは、1回の効果の大きさと、働く回数の掛け算で決まる。
Skyweaverの開発は、パッシブの値打ちが働く回数に左右され、数値だけで比べにくいと述べている（[Some Thoughts on Hero Abilities](https://www.skyweaver.net/news/some-thoughts-hero-abilities)、2026-10-21確認）。

働く回数は、[戦闘の長さ](combat.md#戦闘の長さ)（通常の戦闘3〜4ターン、強敵8〜10ターン、最奥のボス12〜15ターン）と、敵の数で見積もる。
18個を、通常の戦闘で強いもの、長い戦闘で強いもの、相手によって強さが変わるものに散らし、行き先の敵を見てパーティを選ぶ判断を作る。
記録が埋まる・ツリーを取りきるなど、遊び進めるといずれ働かなくなるパッシブは作らない。

強さは少し控えめにする。
Skyweaverの開発は、能力を少し弱めにして、ほかの選択肢を押し出さないようにしている（同上）。
パッシブ1つが強すぎると、そのキャラを外す理由がなくなり、編成の選択が狭まる。

### 戦闘の決まりを壊さない

- [手札](combat.md#手札)の方針を守る。カードに使う条件を付けるパッシブや、手札を詰まらせるパッシブは作らない。
- 説明文は、カードと同じ決まりで書く（[カードの説明文に書くこと](combat.md#カードの説明文に書くこと)・[カードの数値の見せ方](combat.md#カードの数値の見せ方)）。量はステータスの割合で書き、状態の名前はキーワードにする。
- 状態を付けるパッシブは、[状態異常のかかりやすさ](combat.md#状態異常のかかりやすさ)に従い、攻撃のおまけと同じ基本確率を使う（[付与率の仮設定](combat.md#状態異常の付与率の仮設定)）。
- ダメージは[ダメージと防御](combat.md#ダメージと防御)の式を通す。
- ACTを参照するパッシブは、[ACTで威力が変わるカード](combat.md#スキルの仮設定)と同じ参照の仕方にし、上限を設ける。歩くことが強さになるこのゲームの柱だが、その日の歩数で戦力が大きく揺れないようにする。
- 倒れた味方のパッシブは働かない。復活すると、また働く。
- パッシブは1つずつ持つ物ではないため、[品質](inventory.md#品質)の倍率を掛けない。

### 働いたことを見せる

パッシブが働いたら、そのキャラの近くにパッシブの名前を短く出す。
働いたことが見えないパッシブは、プレイヤーが編成の理由にできない。
Overwatchの開発も、目に見えないパッシブを少なく保つ方針をとっている（[PC Gamer](https://www.pcgamer.com/au/overwatch-2s-roles-may-come-with-extra-passive-abilities/)、2026-10-21確認）。
見せ方の詳細は[未決](#未決事項)とする。

## 仮設定

### 解放するレベル

1つ目をLv 1、2つ目をLv 10で解放する。
2026-10-24に固有スキルもLv 1・10・30で解放することになったため、Lv 1とLv 10ではパッシブと固有スキルが同時に開く。
初めの案のLv 15は、アクセサリーの1つ目の枠が開くレベル（[アクセサリー](equipment.md#アクセサリー)）と重なるため、固有スキル（Lv 5・Lv 20、2026-10-23からLv 40も）・アクセサリー（Lv 15・20・25）と散らし、上がるたびに何かが増えるようにした。
確定は[育成の未決事項](progression.md#未決事項)で決める（レベルの上限は2026-10-23にLv100に決めた）。

### パッシブ同士のつながり

組み合わせで伸びる主なつながりを挙げる。
どれも、片方だけでも働き、そろうと大きくなる。

| つながり | 起きること |
|---|---|
| [聖火の鉄槌](../catalog/passives/passive-holy-flame-hammer.md)＋[寒暖の理](../catalog/passives/passive-thermal-shock.md) | アンセルムの打撃でやけどを付け、氷のカードで凍えを足すと、味方全員のダメージが上がる。メテオ（やけど中は2倍）にもつながる |
| [あふれる祈り](../catalog/passives/passive-overflowing-prayer.md)＋[帯電の盾](../catalog/passives/passive-charged-shield.md) | 満タンのルッツを回復すると、あふれた分がブロックになり、雷のダメージが出る |
| [魔力の盾](../catalog/passives/passive-mana-shield.md)＋[帯電の盾](../catalog/passives/passive-charged-shield.md) | ルッツの雷の攻撃がブロックになり、そのブロックで雷のダメージがもう1回出る。ルッツ1人で回る |

## 未決事項

| 項目 | 決める内容 |
|---|---|
| 解放するレベル | 仮のLv 1・Lv 10で確定するか（[育成の未決事項](progression.md#未決事項)） |
| 数値 | 18個の効果量・上限・確率。試遊で、通常の戦闘と強敵で働いた回数を数えて直す |
| パッシブのダメージと弱点 | 属性を持つパッシブのダメージ（帯電の盾・切り返し）は、仮に雷雲・爆炎の刻印と同じく弱点の1.5倍を掛け、弱点を開示する（[実装での仮の扱い](#実装での仮の扱い)）。カードで突いたときだけ開示するかは未決 |
| 重ね方 | パッシブ同士、パッシブとカードの状態・アクセサリーの効果を足すか掛けるか（[戦闘の未決事項](combat.md#未決事項)の補正の重ね方と合わせる） |
| 同じパッシブの重複 | 同じキャラを2人編成できる場合の扱い（[パーティの未決事項](party.md#未決事項)） |
| 働いたことの見せ方 | 仮に名前を浮かぶ文字で出す。位置・長さ・音、アイコンを添えるか。働く回数の多いパッシブ（帯電の盾など）で画面がうるさくならないか |
| 説明の見せ方 | 育成の画面ではキーワードを強調せずに出す。キーワードの説明札を出すか |
| 浄めの誓い | 戦闘のモックの敵は味方に状態異常を付けないため、今は働く場面がない（[敵の行動の仮設定](combat.md#敵の行動の仮設定)の実装を待つ） |
| 固有スキルとの対応 | 仮データでは、9人の固有スキルを4人分の固有スキルで使い回している（例：リタはミナの癒しの風・蘇生）。キャラごとの固有スキルが決まったら、2つ目のパッシブのつながりを見直す |

## 実装との対応

2026-10-21から、18個すべてが冒険の戦闘で働く。
冒険の戦闘は、編成の4人それぞれのLvで解放したパッシブを持って始まる（[冒険の戦闘](party.md#実装との対応)）。
単体で開いた戦闘画面のモック（`BattleLab`）の4人はパッシブを持たない。

| 対象 | 入口 |

### 実装での仮の扱い

説明文だけでは決まらない点を、実装では次のように仮に決めた。

| 点 | 仮の扱い |
|---|---|
| 働いたことの見せ方 | 持ち主の上に、パッシブの名前を薄紫の浮かぶ文字で出す。量のあるものは「星図の計算 +1」「あふれる祈り ブロック +120」のように添える。1枚のカードの中で何度も働くもの（寒暖の理など）は1回だけ出す |
| 1ターンに1回 | 味方のターンの始めに数え直す。かばう・浄めの誓いは、その間の敵の行動にまたがって1回 |
| 星図の計算 | ターン終了を押したとき、または払えるカードがなくなってターンが終わったときに残りを数える。次のターンのエネルギーは上限の9を超えてよい |
| 寒暖の理 | カードのダメージと、帯電の盾・切り返しのダメージに掛ける。やけど・毒・出血・雷雲・爆炎の刻印のダメージには掛けない |
| 居合の型 | ダメージを与える斬属性のカードを、そのターンで最初に使ったときに働く。連続攻撃のカードはすべての回に掛かる |
| 連ね矢 | 「×回数」のダメージ（回数が2以上）の回数を増やす。品質の倍率で増えた回数に、さらに1を足す |
| あふれる祈り・歩み手の加護 | ミナのカードの回復と、ミナが付けたリジェネの回復に効く。蘇生には効かない。今日のACTは戦闘のモックの仮の値（6,000）を使う |
| 聖火の鉄槌 | 打属性のカードが当たり、敵が倒れなかったときに付ける |
| 影の一刺し | 増えたエネルギーも上限の9を超えない |
| 帯電の盾 | ブロックが実際に増えたとき（最大HPまで貯まっていて増えないときは働かない）。雷雲と同じ雷の演出で、ランダムな敵に当てる |
| 魔力の盾 | 1枚のカードで与えたダメージを合計し、カードの最後にまとめてブロックにする |
| かばう | 挑発で向きが決まった攻撃でも、向かった先のHPが30%以下なら代わりに受ける |
| 切り返し・傷口を開く | 切り返しはリタが倒れずに攻撃を受けたときに働く。切り返しも「リタの攻撃」として傷口を開くが働く |
| 見よう見まね・独り立ち | ほかの味方のカードを使ったとき（効果が出る前）に数える。独り立ちのコストは、手札にあるカードと、その後に引いたカードに付く |
