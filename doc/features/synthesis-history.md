# 合成と合成の記録の変更と判断の記録

[合成と合成の記録](synthesis.md)

- 2026-11-02：ユーザーの判断で、レシピの正本をサーバーの recipes.ts とクライアントの WorkshopRecipes にし、武器・防具・アクセサリー・スキルの定義のレシピの表と行は、その写しだと明記した（影響先：[レシピ](synthesis.md#レシピ)・[実装との対応](synthesis.md#実装との対応)・各定義の「合成のレシピ」と「合成の材料」・[ライブラリの合成のレシピ](library.md#合成のレシピ)）。
- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、費用と買う値段の関係（買う値段は5倍にしたが、合成の費用は変えていない）と、未決の強化の項目名を直した（根拠：server/src/features/workshop/catalog.ts の `WORKSHOP_STAR_PRICES`・`CRAFT_STAR_RUNES`、商会のメニュー）。
- 2026-10-31：ユーザーの「長さはもう少し短く、1.5秒ぐらい」「星4、5は少し豪華にしたい」を受け、光の渦を約1.5秒に縮め、☆4（金）・☆5（虹）の豪華な版を足した。豪華さの中身は、実装したコマにCodex CLIで描き足した絵コンテを見せ、ユーザーが「これでいきたい」とした。☆4・☆5を少しずつ長くすることは、こちらで決めて絵コンテに書いた。
- 2026-10-31：合成したときの演出を、画面の一部で見せる5案と画面全体で見せる5案の絵コンテ（Codex CLIの画像生成で、今の合成画面に描き足した）から、ユーザーが「画面全体に出てくるもの」を好み、光の渦を選んだ（[合成の演出](synthesis.md#合成の演出)）。時刻と層の分け方、画面を押すと飛ばせることは、こちらで決めた。
- 2026-10-31：ユーザーの指示「サーバーはオプティミスティックアップデートで」を受け、合成を、サーバーの答えを待たずに出来た物を見せる形にした。出来上がる品質は手元にサーバーと同じ計算を持っているため、答えを待つ理由がないことによる。答えを待つ間の出来た物をほかのレシピの材料に使えなくすることは、こちらで決めた。
- 2026-10-31：ユーザーの「今だとランダムで適当に選んで合成できちゃうので困る」を受け、相談して[確定している方針](synthesis.md#確定している方針)を決めた。品物ごとに決まった材料（レシピ）をそろえてすべて使う形、材料のどれかを手に入れたことがあれば一覧に出すこと、材料は基本はアイテムで特別な場合に決まった装備・カスタムスキルを使うこと、品質は材料の平均で、アイテムは品質を持たないため平均から除き、アイテムだけなら品質Cにすること、まだ見つけていない物を影で出すこと、アイテムを作れる物から外すこと、レシピを作る物の定義の文書に書くことは、ユーザーが決めた。レシピの組み合わせはユーザーから任され、[レシピの決め方](synthesis.md#レシピの決め方)の目安でこちらで決めた。作れる物を☆2以上にし主の物を除くこと、名前と効果を「？？？」で伏せて☆だけ見せること、装備・スキルの材料を初めは品質の低い物にすることも、こちらで決めた。
- 2026-10-24：ユーザーの「合成についても考えて実装しちゃって」を受け、同じ分類で☆が1つ低い物3つとルーンで、見つけた物を1つ作る仮の決まりをこちらで決めて実装した。作る物を選んでから材料を選ぶ形は、ユーザーが「大部分はあってます」とした参考画像（作れる物の一覧と、材料の枠）に合わせた。決まったレシピを種類ごとに書く形は、アイテムが2つの行き先の分しかなく、組み合わせを用意しきれないため採らなかった（2026-10-31にレシピの形へ改めた）。デッキの複数の枠に同じアイテムを入れられるため、アイテムは入れている枠の数を残すことにした。
- 2026-10-06：ユーザーの指示により、合成できる物を素材・道具・武器・防具・アクセサリーに広げ、合成の結果を将来は記録として見られるようにする意向を加えた。2026-10-05に決めた「素材から装備・スキルを作る」との関係を確かめたところ、ユーザーはスキルも合成できるままとした。合成の決まりを1か所にまとめるため、[装備](equipment.md)の未決事項にあった合成の記述をこの文書へ移した（素材・道具を作れる物にすることは、2026-10-31にやめた）。
- 2026-10-05：ユーザーの指示により、合成を採用し、商会で素材から装備・スキルを作ることにした（[装備の変更記録](equipment.md#変更と判断の記録)）。
