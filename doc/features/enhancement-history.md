# 商会の強化（品質強化と覚醒）の変更と判断の記録

- 2026-11-02：スキルとdocの整理で、今のコードに合わせて、クリア報酬の磨き石の数の分け方（近い4つと残りの4つ）、強化素材の手に入れ方、画面の形、未決の絵の欄、実装との対応（冒険の強化素材の表示とサーバーなしの抽選、冒険の結果の札、札の短い名前、記録の列名、スキル1枚の覚醒の本文）を直した（根拠：server/src/features/adventure/clear-rewards.ts、server/src/features/world-map/catalog.ts、server/src/features/enhancement/db-schema.ts・schema.ts、client/Assets/Baryonyx/Features/Adventure/Runtime/AdventureDrops.cs・AdventureDropItems.cs、client/Assets/Baryonyx/Features/Enhancement/Runtime/EnhancementMaterials.cs、Shared/Art/Materials/）。
- 2026-11-02：ユーザーの「品質強化で磨き石を持っている以上に追加、選択できてしまう」を受け、足りない色を下の色から自動で変換する仕様が原因だと示した。ユーザーは変換を残したまま分かりやすくする見せ方を求め、こちらは他のゲームの例（Factorioの3色の数、モンハンNowのジェムでの補充など）を調べて、札の見せ方を5案の画像で示した。ユーザーは「全部わかりづらい」とし、石を1種類にする案を出した。品質が上がるほど1段階に使う石を増やせば、色ごとの上限と同じく安い石の数押しを防げることを示し、ユーザーは「白だけで大丈夫」と決めた。色ごとの上限・磨き石の合成・足りない石の変換をなくし、段階で上げる形にした。1段階に使う数（C1・B2・A3・S6）、1段階を幅の5%とすること、深さごとの落ちる数（浅い1周約3.6個から奥約6個）、クリア報酬（10個・20個）と街道の宝箱（6個・8個）の数、一度に落ちた石を1枚の札にまとめることは、こちらで決めた。上限×2.0の物をCから上限まで上げる石は44個で、以前の4色を白に直した重さ（約53個）より少し軽い。
- 2026-11-01：ユーザーの「品質強化するときも何らかのアニメーション演出が欲しい。合成やスキル覚醒を参考に」を受け、今の画面に描き足した絵コンテを、右の面だけの2案と画面全体の3案、続けてカードが画面の中央へ寄る5案で示した。ユーザーは「裏返して現れる」を選び、強化のたびに流して、金や虹になるときに光を足す3段階（普通・Aに上がる・Sになる。Sのままの強化もSと同じ）を指示した（[品質強化の演出](enhancement.md#品質強化の演出)）。時刻・層の分け方・溜めの長さ・画面を押すと飛ばせることは、こちらで決めた。ユーザーの「普通の強化でも、上がったあとの輪を大きくパーンと」を受け、普通の輪を大きくして2本目を足した（色は変えていない）。最初に作った、回る間のカードのまわりの輪は、ユーザーが「不自然」とした。原因（奥側もカードの手前に描いていた、輪が流れず止まっていた、衝撃波の形を平たく潰して線の太さがそろわなかった、傾きと高さがばらばらだった、カードに面の向きの明暗がなかった）を示し、ユーザーが作り直しを選んだので、カードを囲む光の軌跡と、面の向きの影に替えた。続けて、ユーザーの「軌跡を斜めにして数を多く」を受け、軌跡を1本ずつ傾けて増やした。さらに「回る半径を変えて、大きくワイドに回るものも小さく回るものも。もっと盛り上げて」を受け、半径をばらけさせて本数を増やし、表を向くまで回り続けて外へ弾けるようにし、どの段階にも飛び散る火花を足し、金にも溜める間の吸い込む線を足した（色は変えていない）。ユーザーの「パーンとなったあとに少し止まってほしい。虹ぐらい止まってもいい」を受け、表を向いたあとに中央で止まる時間を、普通は0.22秒から0.5秒、金は0.42秒から虹と同じ0.55秒に延ばした。
- 2026-11-01：ユーザーの「磨き石4つが左に寄りすぎ。右端まで使っていいので4等分で幅広く」「×ボタンが押しづらい。カードの右上か内側に」を受け、磨き石の札を右の面の右端までの4等分にし、×を札の内側の右上に収めた。×を、暗い縁の赤い丸に白い×を描いたボタンの形にすることは、こちらで決めた。
- 2026-10-31：ユーザーの指示「足りなくても合成できれば、モーダルを出して自動で錬成して使えるように」「そんなにガッツリ合成っぽく見せなくていい。矢印と一文のイメージ」「石を複数利用できるように。押すたびに利用個数が増えてまとめて使える」「プラス・マイナスはなくてOK、キャンセルは欲しい。磨き石アイコンの右上に赤いバツマーク」を受け、足りない石の変換の確かめの画面と、札を押して色ごとの数を増やす選び方にした。作る向きは、仕様にある下の色から上の色だけとした。まとめた石を低い色から使うこと、初めは0個にすること、×でその色を0個に戻すこと、変換を合成のAPIで先に行ってから強化を色ごとに送ること、札に「3/8」と使う数を書くことは、こちらで決めた。
- 2026-10-31：ユーザーの「しょぼい石でも数打てばSまで持っていけてしまう」を受け、色ごとに上げられる上限を決めた。ユーザーは白をC帯だけ、青をC・B帯で使える形と、上限を越えて突破できないことを示し、「石を組み合わせる前提」が成り立たなくなること、固有スキルの育成が難しくなることを認めた。下の色3個で上の色1個にする合成もユーザーが決めた。上限を品質の入口の倍率で止める形（今の品質で使えるかを決めると、Bの手前の白でBの中まで入り込むため）、紫をSの入口まで・金を上限までにすること、合成のルーン（100・300・900）、合成を商会の「合成」の「磨き石」のタブに置くこと、ゲージの見せ方、合成の演出に光の渦を使うことは、こちらで決めた。ドロップ数（1周で約1.8個）は変えていない。今のドロップでは、合成を使えば1つの物をCからSにする周回数は浅いダンジョンで約7.3周から約8.2周とほとんど変わらないことを示し、ユーザーはこの形でよいとした。
- 2026-10-31：ユーザーの「磨き石も出過ぎてる気がする」を受け、示した3案から「1周で約1.8個」が選ばれた。[磨き石の落ち方](enhancement.md#磨き石の落ち方)の落ちる確率を、魔物30→10%、強い魔物・宝箱60→20%、最奥の間100→60%に下げた。色の重みは変えていない。
- 2026-10-24：ユーザーの指示「商会のメニューリストから強化（ラベルは品質強化にして）、スキル覚醒でメニュー、レイアウトを分けてほしい」を受け、「強化」を「品質強化」と「スキル覚醒」の2つの項目に分け、それぞれ別の画面にした。スキル覚醒のアイコン（星と下の光の筋）はこちらで描いた。
- 2026-10-24：ユーザーの指示「低レベルダンジョンは白の割合を増やして。金はレアにして」「高レベルでも金、紫は今よりもレアに」を受け、[磨き石の落ち方](enhancement.md#磨き石の落ち方)の色の重みを、行き先の深さ（浅い・中ほど・奥）で分けた。落ちる確率は変えていない。深さの分け方と重みは、こちらで決めた仮の値である（[定義](../../server/src/features/enhancement/catalog.ts)・[抽選](../../server/src/features/adventure/drops.ts)）。
- 2026-10-24：ユーザーの指示「強化は必ず右側になにか表示されていてほしい」「磨き石の数字は改行して」「品質を上げたあと、どのような変化があるか。カード形式でBefore, Afterを見せてほしい」を受け、先頭の行を選んでおくこと、磨き石の札の数を絵の下に置くこと、強化する前と後をカードで並べることにした。装備はデッキのカードを持たないため、品質の色の縁の札にすることと、覚醒も前と後の段階のカードで並べることは、こちらで決めた。

- 2026-10-24：ユーザーの依頼「shopのリストに強化を増やしたい」を受けて仕様案を示し、ユーザーの回答で次を決めた。品質を上げる石と覚醒の素材は別に持つ。石は色で上げ幅が変わり、上げ幅は倍率の幅に対する割合とする。石とルーンの両方を払う。ACTボーナスは対象外とする。強化素材はレアな物として商会では売らず、ダンジョンでは白が1周で2〜3個出る程度に落とす。覚醒の欠片は1・2段目で共通の1個とする。商会での覚醒を認め、固有スキルが冒険の中だけで進む決まりを改めた。あわせて、ほかのゲームの用語と重ならないよう、固有スキルの「進化」を「覚醒」と呼ぶことにした（[固有スキルの覚醒](skill-evolution-history.md)）。
