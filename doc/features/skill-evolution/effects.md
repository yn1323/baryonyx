# 固有スキルの覚醒：演出と覚醒先を選ぶ画面

[固有スキルの覚醒](../skill-evolution.md)

## 設計方針

### 段階ごとのエフェクト

2026-10-26に、改訂した[VFXの作り方](../../../.agents/skills/vfx-authoring/SKILL.md)に合わせて、12のツリーの演出と段階の層を作り直した。
どのツリーも、現実ならその現象が何から成り、どう動き、何を残すかから主役の形・動き・材質を決め、主役を透け方と時間の違う4つ前後の層に分ける。
枝は色替えにせず、動き・対象・形のどれかを変える。
3つ目の4つのツリー（魔眼・速射・鼓舞・裁きの光）も、カードスキルの演出を借りるのをやめ、専用の演出にした。

#### 段階の層

1段目と2段目が、主な当たりのたびに重ねる層である（[BattleSkillVfx.Unique](../../../client/Assets/Baryonyx/Features/Combat/Presentation/BattleSkillVfx.Unique.cs) の `Empower`）。
秒は当たった瞬間からで、層ごとに出る・消える時刻をずらす。

| 層 | 置き場所と合成 | 時間 |
|---|---|---|
| にじみ（標的のまわりの光った空気） | 標的の奥、加算 | 0.03秒で立ち上がり、1段目は0.5秒、2段目は0.65秒かけて消える。いちばん長い |
| 床の光だまり | 足元の床に寝かせる、加算 | 0.3〜0.5秒 |
| 芯（白い星） | 標的の手前、加算でBloomに掛ける | 0.14秒。いちばん短い |
| 残像（段階の色の火花） | 手前、加算 | 0.1〜0.36秒。外へ飛んで落ちる |
| 土ぼこり | 標的の前後の床、通常合成 | 0.45〜0.75秒。床を外へ走る |
| 余韻の粒 | 手前、加算 | 0.08〜0.3秒遅れて昇る |

何度も当たる段階（星降りの6発など）は、にじみの明るさを当たりの回数の平方根で割り、床の光だまりも小さくして、重なった光で標的を白く隠さない。
2段目の山場は、主な当たりの最後の波で一度だけ、閃光・ヒットストップ・スロー・寄りと細い光の筋の放射を出し、0.16秒後に、1回目より弱く広い2回目の炸裂（段階の色の光の殻・広いにじみ・長い筋）を重ねる。
味方への回復・守りには打撃の層を出さず、床の光だまり、体の奥の柔らかい光、体のまわりから昇る幅3〜5画素の光の線、遅れて昇る粒を出す（`Uplift`）。

#### マナバーストの演出

マナバーストを、ほかのツリーを作る前の代表として作った。
現象は、押し縮めた魔力の球が飛び、いったん縮んでからはじける形にした。現実の近い物はプラズマの球と爆発の閃光で、白い芯・色の光の棘・まわりの光った空気・はがれる光の粒からなる。

| 時間 | 何が起きるか |
|---|---|
| 0〜0.3秒（予兆） | 球が使い手から敵の上へ弧を描いて飛ぶ。手元から大きくなり、細かく脈打ち、光の粒と小さな放電を後ろに残す |
| 0.3〜0.42秒（圧縮） | 球が0.6倍まで縮み、芯が白く明るくなる。まわりから光の輪と粒が吸い込まれる |
| 0.42秒（発動） | 芯が白く光って0.12秒で消え、細い光の筋が放射し、小さな衝撃の輪が弧に割れて消える。球の光の棘は一気に伸びてから中心へ削れる。敵それぞれに当たる |
| 0.42〜1.2秒（余韻） | 奥の紫のにじみが0.8秒かけて消え、使い切った魔力のかけらがゆっくり沈みながら消える。床の光だまりが薄れる |

| 層 | 形 | 合成 | 時間 |
|---|---|---|---|
| にじみ | 球の2.6倍の柔らかい光。炸裂のあとは標的の奥の光（画面全体を染めない大きさ） | 加算 | 飛ぶ間ずっと。炸裂後0.8秒 |
| 本体 | 回りながら震える光の棘（星形）。泡やガラス玉に見える縁の線は描かない | 加算 | 飛ぶ間ずっと。炸裂で一気に伸び、0.32秒かけて中心へ削れる |
| 芯 | 白く熱い小さな光 | 加算、Bloom | 炸裂の0.12秒で消える |
| 残像と粒 | 飛ぶ間にはがれる粒と放電、炸裂後に沈むかけら | 加算 | 0.25〜1.1秒。それぞれ寿命をばらつかせる |

烈・極は大きく白くし、極は上へ光の柱を抜く。
散・嵐は小さな球に分けて、ランダムな敵へ1つずつ落とし、嵐は使い手のまわりの渦から散らす。
環・還流は、炸裂のあとに使った魔力が金の光の筋になって使い手へ戻り、輪になって収まる。

### 覚醒のエフェクト

[戦闘中の覚醒](rules.md#戦闘中の覚醒)のエフェクトは、「魔法陣で浮いて、パリーンと割れて覚醒する」形にした（2026-10-21、ユーザーの依頼）。
Codex CLIの画像生成で前触れ・選択・確定の場面の絵を作り、ユーザーが前触れと確定の絵を選んだ。
2026-10-21にスキルのデバッグルームで0.1秒刻みのコマを撮って確かめ、破片が小さく灰色に見えた点と、割れた瞬間にカードがそのまま替わり割れた感じが弱かった点を直した。
狙う感覚は、前触れが「力が集まって目覚める」、割れる瞬間が「殻を破る」である。

2026-11-02に、[商会での覚醒](../screens/shop.md#スキル覚醒)と一緒に作り直した（ユーザーの依頼）。
商会の覚醒をコマで撮ると、左上の隅で始まる、選ぶ間に覚醒前のカードが小さな丸になる、割れる所が画面の上端で切れる、覚醒後のカードを見せずに消える、という課題があった。
Codex CLIで作った5案（ガラスが割れる、裏返る、封印がほどける、光にほどけて組み直る、星座がつながる）から、ユーザーが「ガラスが割れる」を選んだ。
色は金をやめ、カードの挿絵から取る（ユーザーの依頼）。挿絵を初めて使うときに32×32へ縮めて読み、白・灰・暗い所を除いた中でいちばん多い鮮やかな色相を、明るい光の色にして覚えておく（[CardArtColor](../../../client/Assets/Baryonyx/Features/Combat/Presentation/CardArtColor.cs)）。溜める所は覚醒前のカードの挿絵、割れたあとは覚醒後の挿絵の色を使う。挿絵がないときや、鮮やかな色がないときは、スキルごとの色（[枝ごとの色](rules.md#設計方針)）を使う。
割れる所は、カードの絵そのものが破片になって派手に飛び散る形にした（ユーザーの指摘。光と小さな破片だけでは割れて見えず、白い閃光に隠れて、割れる前に新しいカードへ入れ替わったように見えた）。割れたカードを一瞬見せ、破片が中央を離れてから、新しいカードを2回目の閃光とともに出す。割れる瞬間は、カードの真ん中から白く光って爆発するのではなく、カードの形のまま全体にひびが入ってガラス板のように割れる（ユーザーの指摘）。
魔法陣は、線を一周なぞって描く出し方をやめ、全体を淡く少し大きめに出して明るくしながら収める（ユーザーの指摘。描き進む境目がくっきりして不自然だった）。
覚醒後の段階の名前を書く1行は出さない（ユーザーの判断）。

| 拍 | 時間 | 見せ方 |
|---|---|---|
| 前触れ | 約1.05秒（2段目への覚醒は1.2秒） | 背景を夜の青へ暗くする。使ったカードが使い手から浮き上がり、敵の側へ寄った使い手と同じ高さで1.6倍になる（商会では画面の中央）。画面の上端（戦闘では行動順）からは150px離す。カードの後ろに挿絵の色の魔法陣が、全体が淡く少し大きめに現れて明るくなりながら収まり（線を一周なぞって描かない）、回る。その外にもう1重、淡い輪が逆向きに回る。使い手の足元にも魔法陣と光だまりが出る（商会では出さない）。画面の下から、細い光の線が次々に昇ってカードへ集まり（1秒に最大46本）、結晶の破片がカードのまわりを傾いた輪を描いて回る（手前と奥に半分ずつ）。ひびはまだ入れない。最後にカードの右上の角で星が光る（ひらめきの印） |
| 選択 | 決まっていない | カードは0.35秒で画面の上の端（上から36px）へ移り、0.6倍に縮む。魔法陣・結晶・光もカードについていき、昇る光の線は少なくなって続く。カードはゆっくり上下し、細かく震えたまま、[覚醒先を選ぶ画面](#覚醒先を選ぶ画面)で選ばれるのを待つ |
| 戻る | 約0.24秒 | 決めると、カードが前触れの場所へ1.6倍に戻る |
| ひび | 約0.45秒（2段目への覚醒は0.57秒） | 戻ったカードに、中心から外へ細いひびが「ぴき、ぴき」と4段で一気に広がる（0.11秒・0.09秒・0.1秒おき）。ひびは画面で1〜2.5画素の白い芯と細い色のにじみで描き、割れたばかりの区間だけが一瞬白く光る。ひびはカードの枠の内側だけに走り、外へはみ出さない。割れるたびにカードが1ドット揺れ、光の小さなかけらが飛ぶ。ひびは、覚醒先を選んで中央へ戻ってから入れる（2026-11-02、ユーザーの判断。前触れで入れると、選ぶ間の小さなカードでひびが粗く見えた） |
| 割れる | 約0.42秒 | カードが一瞬縮んでから、その瞬間の画面に写ったカードの姿のまま、カード全体に散らした24個の点（横4・縦6の升目の中でずらす）で分けた多角形の破片になる。破片の割れ口だけが細く白く光り、真ん中からの閃光や星は出さない。破片は0.18秒、ひびに沿って少しだけ離れて止まり（割れたカードを見せる）、そのあと回転し裏返りながら四方へ遠くまで飛んで落ち、1秒で消える。割れた瞬間は揺れ・画面の閃光・衝撃の輪だけにし、透けるガラスの破片と挿絵の色の大きな結晶は、カード全体から、破片と一緒に0.18秒後に飛ばす。魔法陣は0.16秒で消える |
| 見せる | 約0.42秒＋戦闘0.85秒（商会1.6秒） | 割れてから0.42秒は破片と光だけにし、そのあと覚醒後のカードが、星・閃光・2重の輪・光線・火花の2回目の炸裂とともに弾んで大きく現れる（戦闘は1.9倍、商会は2.5倍で、説明文まで読める大きさ）。後ろで覚醒後の色の細い光の筋が9本、ゆっくり回り、まわりを透けるガラスの破片が漂って落ちる |
| 使い手へ | 約0.26秒 | 覚醒後のカードが光の尾を引いて使い手（商会では行のキャラ）へ飛び込み、使い手の体で星が光る。そのあと覚醒後の段階の演出が始まる |

2段目への覚醒では、魔法陣を3重にし、ひびを2回（0.15秒ずらし、同じ大きさで別の模様を重ねて）走らせ、割れた0.16秒後にもう一度、輪と火花を広げる。
画面全体の閃光は、ほかの演出と同じ間隔と濃さの上限を守る（[スキルの演出と背景](../screens/battle-effects.md#スキルの演出と背景)）。

### 覚醒先を選ぶ画面

覚醒先は、浮かんだ覚醒前のカードの下に候補を並べて選ぶ（2026-10-22、ユーザーの選択）。
Codex CLIで作った2つの案（ひびの入ったカードから枝を伸ばす案と、候補を大きく横一列に並べる案）から、ユーザーが枝を伸ばす案を選んだ。
前触れから同じカードが画面に残り続けるため、流れが切れない。

| 部分 | 見せ方と操作 |
|---|---|
| 覚醒前のカード | 画面の上の中央に、光ったまま浮かぶ（ひびは選んだあとに入る。[覚醒のエフェクト](#覚醒のエフェクト)）。後ろで挿絵の色の魔法陣が回る |
| 光の枝 | 覚醒前のカードの下端から、各候補のカードの上端へ、金の光の線を引く。候補が現れるのに合わせて伸び、伸びきったあとも光が流れ続ける。選んだ候補への枝は太く明るく、ほかは薄くする |
| 候補 | [覚醒の候補](rules.md#覚醒の候補)を、戦闘のカードの2.45倍（約515×720px）で、画面の中央から下に横に並べる。3枚なら左・中・右に560px間隔で、傾けずにまっすぐ同じ高さに置く（説明文を読み比べやすくするため）。1枚なら中央に置く。右端の候補の右下の角は、決めるボタンの丸の左上にわずかにかかるが、ボタンを手前に描くため、チェックの印は隠れない。候補は0.08秒ずつ遅れて下から現れる。カードには、名前・効果・コストをそのまま見せる |
| 取得済み | 取得済みの段階の候補には、カードの右上に「取得済み」の札を付ける。取得済みでも同じように選べる |
