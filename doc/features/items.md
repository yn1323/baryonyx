# アイテム（道具・素材）

[機能索引](README.md) / [持ち物の分類](inventory.md) / 根拠：2026-10-06のユーザーの指示

**アイテム**は、冒険で見つかる道具や素材などの持ち物である。
素材には、狼の牙のように敵から取れる物がある。
戦闘ではスキルと同じくカードとして使い、合成の材料にもなる。

## 確定している方針

### 入手

アイテムは、冒険の中で、敵のドロップと宝箱から見つかる。
見つかりやすさは[レア度](inventory.md#レア度)（☆1〜☆5）で表し、☆が多いほど見つかりにくい。

### 数え方

アイテムは種類ごとに個数で数える（例：狼の牙×12、2026-10-06）。
同じ種類のアイテムは同じ効果を持ち、スキルや装備のような1つずつの[倍率](inventory.md#1つずつ持つ倍率)は持たない。

### 効果と枠

アイテムは、スキルと同じく効果を持ち、戦闘中に使える。
道具も素材も同じ扱いとする。
各キャラは、スキルとアイテムのどちらかを入れるカスタムスキルの枠を2つ持つ（[キャラクターの構成](party.md#キャラクターの構成)）。
アイテムは、スキルの代わりにこの枠へ入れる。

### 戦闘での使い方

枠に入れたアイテムは、スキルと同じくデッキのカードになり、山札から引いて手札から使う（[手札](combat.md#手札)）。
使ったカードは手札からなくなり、山札が尽きて切り混ぜ直すと、また山札に入る。
使っても、持っているアイテムは減らない。
スキルも同じで、戦闘でカードを使っても、冒険者が持っている物は減らない。

### 合成

素材と道具は、合成の材料にでき、合成でより良い素材・道具にもできる（[合成](synthesis.md)）。

## 未決事項

| 決める項目 | 状態 |
|---|---|
| 道具・素材以外の種類 | 未決 |
| 道具と素材の違い | 戦闘での効果の傾向や、合成での使われ方を分けるか |
| 個別の効果・対象・コスト | 未決。効果量に、枠に入れたキャラのステータスを使うか（[威力の決め方](combat.md#威力の決め方)）を含む |
| 枠の決まり | 同じ種類のアイテムを1人の2枠や複数のキャラに入れられるか（持っている個数までか） |
| ドロップと宝箱 | 敵・宝箱ごとの抽選対象と確率（[報酬・ドロップテーブル](../catalog/loot-tables/README.md)）、ACTボーナスのドロップ率アップとの関係 |
| 合成の材料にしたとき | 材料にしたアイテムが減るか、枠に入れているアイテムを材料にできるか（[合成の未決事項](synthesis.md#未決事項)） |
| 売買・所持上限 | 商会で売り買いするか、所持上限 |
| 保存先 | 案はサーバー（[保存先の決め方の置き場所の一覧](../rules/data-storage.md#置き場所の一覧)） |
| 枠に入れる画面 | 編成のどこで入れるか（[画面の未決事項](screens.md#未決事項)） |

## 実装との対応

アイテムは未実装で、カスタムスキルの枠には今はスキルだけを入れられる（[実装との対応](party.md#実装との対応)）。
冒険の部屋で手に入るのは、今はACTボーナスだけである（[実装との対応](stage-progression.md#実装との対応)）。

## 変更と判断の記録

- 2026-10-07：ユーザーの指示により、スキルかアイテムを入れる2枠を「カスタムスキル」と呼ぶことにした（[キャラクターの構成](party.md#キャラクターの構成)）。
- 2026-10-06：ユーザーの指示により、持ち物の分類にアイテム（道具・素材）を加え、この文書を作った。戦闘での使い方として、固有スキルのように手札の外から使って1個減らす案、減らさずに回数で制限する案、デッキに入れる案を示したところ、ユーザーは、スキルと同じくデッキに入れ、使うと手札からなくなっても山札を作り直すとまた現れ、持っている量は減らない形を選んだ。同日、数え方として、種類ごとに個数で数える案と、1つずつ倍率を持つ案を示したところ、ユーザーは種類ごとに個数で数える案を選んだ。さらに同日、アイテムの枠をスキルと共有の2枠とし、固有スキル2枚と合わせて1人4枚、デッキ16枚のままとした（[キャラクターの構成](party.md#キャラクターの構成)）。
