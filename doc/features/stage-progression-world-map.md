# 前の街道の世界地図

[機能索引](README.md) / [探索とダンジョンの進行](stage-progression/destinations.md#街道とダンジョン) / 今の世界地図：[入れ子の地図](world-atlas.md)

前の街道の世界地図（`WorldMap`）は、2026-10-29にデバッグルームの一覧から外し、今は開く入口がない。冒険していないときのHomeの行き先カードは、2026-10-28から[入れ子の地図](world-atlas.md)を開く。
廃止するかは決めていないため、街道の構想・決めたこと・試作の記述を[探索とダンジョンの進行](stage-progression.md)から移して残した（2026-11-02）。街道を開くルーンの決定は、入れ子の地図で作った（[マスを開くルーン](world-atlas/maps.md#マスを開くルーン)）。
コードとシーン（`WorldMap.unity`、`Features/WorldMap/` の街道の部分、`server/src/features/world-map/`）は残っている。ダンジョンの解放は、今もこの街道のクリア記録で決まる（[探索とダンジョンの進行の実装との対応](stage-progression/status.md#実装との対応)）。

## 確定している方針

### 街道とダンジョン

2026-10-23、ユーザーは、冒険を2つの遊び方に分ける構想を決めた。
細部はこれから詰める（[未決事項](#未決事項)）。

- **街道**：世界地図に並んだ固定のマスを1つずつクリアして先へ進み、新しい街を解放していく。
- **ダンジョン**：解放した街にあるダンジョンに入り、物を集めて育てる（ハクスラ）。これまでの行き先（[行き先と敵](stage-progression/destinations.md#行き先と敵)）がダンジョンで、この文書のほかの節の冒険（[分岐ルートを選んで進む冒険](stage-progression/run.md#分岐ルートを選んで進む冒険)など）はダンジョンの遊び方である。

| | 街道 | ダンジョン |
|---|---|---|
| 地図 | 世界地図に、固定のマスを線で結んで並べた網。いつも同じ形 | 冒険ごとにランダムに作る（今のまま） |
| 役割 | 世界を広げる・新しい敵の初登場・物語 | 物を集めて育てる・周回 |
| 進み方 | マスを1つずつクリアして、先のマスを開く。クリアしたマスは残り、開いた所は自由に行き来できる | 分岐を選んで一方通行で進み、引き返せない |
| 負けたとき | そのマスに挑み直す。クリアしたマスは戻らない | 冒険が終わり、次は1階から |
| 数 | ダンジョンよりずっと少ない | 多い |
| クリアしたあと | 街のマスに着くと、その街にあるダンジョンが解放される | [クリア回数の報酬](stage-progression/destinations.md#ダンジョンのクリア回数の報酬)をもらう |

街道は、次のように進む。

- 世界地図は、マスと線だけでできた網である。方角を4つに決めず、最初の街から道が分かれながら自由に広がる。
- マスには、戦闘・ボス・街などがある。ダンジョンの入口のマスは置かない。ダンジョンは、特定の街に着いたときに解放される。
- ボスのマスは、先へ進むのを止める関所にする。倒すと、その先のマスへの道が開く。
- クリアしたマスの上は自由に通れる。クリアしたマスで戦い直して報酬を得る仕組みは持たせない。
- 最初の街から遠いほど敵を強くし、「この先は推奨Lv○○」のように、今の強さでどこへ向かうかを選ばせる。どこへ行っても同じ強さにすると、行き先を選ぶ意味が薄れるためである。値は未決とする。
- マスの台座と線は、ダンジョンの探索の地図（[地図の作り直し](stage-progression/run.md#地図の作り直し2026-10-21)の魔法陣の台座と光の線）を使い回す方向とする。地面や建物を置くかは後で決める（ユーザー）。

同じ日の初めの案では、街を中心に四方へ道が伸び、道の中は一方通行で、負けたらその道の最初からやり直すとしていた。
ユーザーの「固定のマスが自由に並んでる感じでもいいかも」を受け、世界地図そのものを固定のマスの網にする形（クリアしたマスが残る）に改めた。
ダンジョンとは、地図の作り方・進み方・負けたときの扱いが正反対になる。

#### 街道のマスと移動（2026-10-24）

2026-10-24、ユーザーは次を決めた。

- マスは、戦闘・関所のボス・街に、1回だけ開ける宝箱と物語のマスを少し足す。
- 何もないマスを多く置く。全部のマスに意味があると疲れるためであり、あとで中身を足す余地にもする（ユーザー）。2026-10-27に、何もないマスは置かないと改めた（[街道を開くルーンと日・週・月の出来事](#街道を開くルーンと日週月の出来事2026-10-27)）。
- HPはマスの間で持ち越さず、1マスで完結させる。
- 街道の戦闘は手で組んだ決まった敵にする。新しい敵はまず街道で出し、そのあとダンジョンにも出す。
- 先へ進む条件は、関所のボスと推奨Lvの2つだけにする。前の街のダンジョンのクリアなどは条件にしない。
- クリアしたマスの上では、行き先のマスを押すと最短の道を自動で歩く。途中の何もないマスでは止まらない（WalkScapeの、行き先を選ぶと最短の経路を選ぶ移動を参考にした）。
- 関所のボスを倒すと、橋が架かる・霧が晴れるなど、先の道が開いたことが地図の見た目で分かるようにする（『スーパーマリオブラザーズ3』の、クリアで扉が消え橋が下りる地図を参考にした）。
- 推奨Lvは、マスごとではなく、街と街の間の区間ごとに札で出す（『オクトパストラベラー』の、中央から遠いほど高くなる危険度を参考にした）。

着いたマスは端末から受け取る。マスと道の形は端末だけが持ち、サーバーは送られたマスのIDの形だけを確かめて残し、そのマスに行けるか（つながりと関所）は確かめない（2026-11-02、ユーザーの判断で確認待ちから今の作りを確定にした）。

#### 街道の宝箱と街（2026-10-25）

2026-10-25、ユーザーは街道のマスの中身を次のように決めた。

- 宝箱は、マスごとに決まった中身を置く。抽選にせず、そのマスを初めてクリアしたときに1回だけもらう。中身はこちらに任された。
- 街には宿や店を置かない。街に着いて起きることは、その街のダンジョンの解放だけにする（[街とダンジョン](stage-progression/destinations.md#街とダンジョン仮)）。
- 物語のマスの中身は、今は考えない。着くとそのままクリアにする。
- 街道では歩数を使わない。2026-10-24に採った「歩数の関所」と「道のりの表示」はなくした。累計の歩数の数え方が込み入るためである（ユーザー）。2026-10-27に、ゲームのコンセプトと矛盾するとして改め、マスを開くときにルーンを払うことにした（[街道を開くルーンと日・週・月の出来事](#街道を開くルーンと日週月の出来事2026-10-27)）。

宝箱の中身は、こちらで決めた仮の値である。
寄り道の先にあることに見合うよう、その先の区間で役立つ装備かスキルを1つ（品質A）と、強化素材を組み合わせた。
装備とスキルの倍率は、品質Aの幅の下端にする。

| マス | 場所 | 中身 |
|---|---|---|
| `n8-5` | ピーノの西の寄り道 | 氷晶のワンド（武器☆3）、磨き石×6 |
| `n17-7` | 内の輪の東の寄り道 | 水晶の指輪（アクセサリー☆3）、磨き石×8 |
| `n15-15` | サッビアの北の寄り道 | 土くれの鎧（防具☆3）、磨き石×6 |
| `n20-14` | ドゥーナの北の寄り道 | 王墓の鎌剣（武器☆3）、磨き石×8 |
| `n16-18` | サッビアの南の寄り道 | ホーリーライト（スキル☆3）、覚醒の欠片 |

#### 世界地図の形と試作（2026-10-24）

ユーザーは、Codexで作った4案（ドット絵の俯瞰ジオラマ・羊皮紙の古地図・すごろく盤・夜の星図）から、背景はドット絵の俯瞰ジオラマ、マスと道はすごろく風の見やすくポップな形を選んだ。
地図はとても大きく作り、画面にはその一部だけを出して上下左右に動かす（ユーザー）。
道は曲線でなく直線でよい（ユーザー）。
最初の試作では街と街を斜めの直線でつないだが、ユーザーの「もうちょっとまっすぐ蜘蛛の巣状というか、寄り道ありで」を受け、次の形に改めた。

- マスを方眼に置き、道は縦と横の直線だけにする。
- 門前町ポルタを中心に、放射状の道と、それをつなぐ内と外の2つの輪で、蜘蛛の巣の形にする。
- 行き止まりの寄り道を置き、先に宝箱・物語を置く。2026-10-25に歩数の関所をなくし、その3つのマスは何もないマスにした（どれも宝箱の手前にあった）。
- ほかの街へは、外の輪から延びる道の手前に関所のボスを置く。

試作の配置は、方眼の文字の図（[WorldMapCatalog](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapCatalog.cs) の `Rows`）で、マスは89、線は98である。
文字の図は、背景の絵の48画素を方眼の1マスとし、大文字が街、小文字がマスの種類、`-`・`|` が道を表す。

#### 世界地図を開く画面

2026-10-24、ユーザーは、旅の案内所の行き先リストを世界地図に置き換えると決めた。
世界地図のどこかに置いたボタンを押すと、解放したダンジョンの一覧を出す。
旅の案内所の案内人（フクロウ族の老地図師）はなくす（ユーザー）。
ホームの行き先カードは今のままにする。
2026-10-24に、ホームのカードから世界地図を開き、右下のボタンで旅の案内所をダンジョン一覧として開く形にした（[画面一覧](screens/guide.md#編成商会神殿旅の案内所の画面)）。
2026-10-27に、ユーザーの「一瞬初期値にスポーンしてる」を受け、世界地図はサーバーから今いるマスを読むまで暗転したまま待ち、パーティを今いるマスに置いてから、左右のシャッター（0.5秒）で開くようにした。読み込みが3秒を超えたら、待たずに開いて「読み込み中…」を見せる。ホーム・戦闘・ダンジョン一覧のどこから戻っても同じ開き方にする。

#### 街道のマスの戦闘（2026-10-24）

ユーザーの「マスに沿ったイベントが起きるようにしてください。戦闘とかですかね」を受け、戦闘と関所のボスのマスで戦闘が起きるようにした。

- 挑めるマスに着くと、そのマスの戦闘を開く。クリアしたマスの上を通るだけでは戦わない。
- 戦闘は全員のHPが満タンで始める（[街道のマスと移動](#街道のマスと移動2026-10-24)）。冒険の強化（休憩・戦闘後の強化）は効かない。
- 勝つとマスをクリアし、そのマスに立った世界地図へ戻る。関所のボスを倒すと、先のマスが見えるようになる。
- 全滅すると、「もう一度挑む」（同じマスの戦闘を始めから）か「地図へ戻る」を選ぶ。マスはクリアにならず、パーティは元のマスに戻る。ルーン復活はない。
- 戦闘のメニューからも地図へ戻れる。戦闘の途中でアプリが終わったときも、マスはクリアにならない。
- 勝っても報酬は出さない。弱点の開示は、ダンジョンの戦闘と同じく記録する。

マスごとの敵・Lv・戦闘の背景は、こちらで決めた仮の値で、[WorldMapEncounters](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapEncounters.cs) が持つ。
敵は、近くの街のダンジョンの魔物（[行き先と敵](stage-progression/destinations.md#行き先と敵)）から選ぶ。関所のボスは、小さな敵と中くらいの敵の奥にダンジョンの最奥の主を置く。
戦闘のマスは、2026-11-01から、魔物の気配の[編成](stage-progression/destinations.md#戦闘の編成2026-11-01)のどれかでマスごとに手で決め、1体・2体・3体の戦闘が街道に混ざるようにした。強さは、その編成の倍率を掛ける。
負けて挑み直したときに同じ相手と戦えるよう、マスの敵は乱数で変えない。
Lvは、ポルタのまわりの10から、区間の推奨Lvまで上げる。強さの倍率は、戦闘がダンジョンの魔物、関所のボスがダンジョンの最奥の主と同じにした。自動対戦での試しはしていない。
物語のマスは、中身を決めていないため、着くとそのままクリアにする（[未決事項](#未決事項)）。
宝箱のマスは、着くと中身を見せてクリアにする（[街道の宝箱と街](#街道の宝箱と街2026-10-25)）。
クリアしたマスは、街を除いて何もないマスの台に変え、着いても出来事が起きないことを見た目で分かるようにする（2026-10-25、戦闘や宝箱の絵のまま何も起きないマスがあったため）。

#### 街道を開くルーンと日・週・月の出来事（2026-10-27）

2026-10-27、ユーザーは、「運動しないとワールドマップの移動すらできない」というゲームのコンセプトに合わせ、街道を次の形に改めると決めた。
値段・マスの種類・出来事の案と未決事項は、[計画](../plans/2026-10-27-world-map-rune-squares.md)にまとめた。この形は、前の街道ではなく[入れ子の地図](world-atlas.md)で作った。まだ入っていないマスにルーンを払うことは[マスを開くルーン](world-atlas/maps.md#マスを開くルーン)のとおり実装し、何もないマスを置かないことは、2026-10-29に出来事を一部のマスにだけ置く形へ改めた（[入れ子の地図の確定している方針](world-atlas/maps.md#確定している方針)）。日・週・月の復活と「？」のマスは未実装である。

- まだ入ったことがないマスに入るとき、ルーンを払う。値段はマスの種類で変え、珍しいマスと街は高めにする。奥地でも1マスの上限は1,000ルーン程度にする。
- 開けたマスはタダで通れる（今のまま）。
- 何もないマスは置かず、すべてのマスで何かが起きる。
- 地図を今より広くする。背景の絵はそのまま2倍に拡大し、方眼を細かくしてマスを増やす。
- 1回きりの「？」マスを入れる。
- 開けたマスの一部では、日・週・月ごとに出来事が復活する。決まった場所で毎日アイテムがもらえるマス、曜日で品ぞろえが変わる行商人、月に1回覚醒の欠片などがもらえる祠を置く。復活したマスに入るときはまたそのマスのルーンを払い、そこまでの開けた道はタダで通れる。
- 「今日これだけ歩かないと」のように、運動量を条件にする出来事は入れない。
- 値段の目安にする1日の歩数は6,000歩とし、そのうち地図にどれだけ回すかは後で決める。

同じ日に、世界地図から地域のエリアマップへ入る入れ子の地図の試作を作り、2026-10-28に冒険の世界地図をそれに入れ替えた（[入れ子の地図](world-atlas.md)、[実装の記録](../plans/2026-10-27-world-map-rune-squares.md#2026-10-27入れ子の地図の試作)）。前の街道の世界地図（`WorldMap`）は、2026-10-29にデバッグルームの一覧から外し、今は開く入口がない。

## 実装との対応

2026-10-24に、街道の世界地図の試作（`WorldMap.unity`）を作った（[世界地図の形と試作](#世界地図の形と試作2026-10-24)）。背景の絵を3倍で敷き、1本指で上下左右に動かす。2本指で広げると近づき（最大2倍）、狭めると離れる（地図が画面を埋めるところまで）。2本の指の間にあった場所は指の間に残る。Editorではマウスのホイールで同じように近づけ、離せる。開いたときは等倍で、戦闘から戻ると等倍に戻る。クリアしたマスか、その隣の挑めるマスを押すと、パーティの駒がクリアしたマスの上を最短の道で歩き、カメラが追う。挑めるマスはゆっくり大きさを変えて知らせ、倒していない関所の先は灰色の台にして種類を伏せる。区間の推奨Lvの札、右上の今いる場所の名前、左上のホームへ戻るボタン、右下のダンジョン一覧のボタン（今は旅の案内所を開く）を置いた。挑めるマスの戦闘は[街道のマスの戦闘](#街道のマスの戦闘2026-10-24)のとおりである。
同じ日に、ユーザーの依頼で、進み具合（今いるマスとクリアしたマス）をサーバーに保存するようにした（[保存先の決め方](../rules/data-storage.md#サーバーに置くもの)）。地図を開くたびにサーバーから読み、読むまでは右上に「読み込み中…」を出してマスを押せなくする。マスに着くと、着いたマスと、クリアしたならそのマスを、保存を待たずに地図へ映し、書き込みの待ち行列で送る（`POST /v1/world-map/move`）。保存に失敗したら、サーバーに残っている進み具合へ戻し、下の中央に「街道の進み具合を保存できませんでした」と出す。初めて開くユーザーは、ポルタだけをクリアしてポルタにいる。接続先がないとき（展示室など）は、これまでの仮の進み具合（ポルタから西のブリーザと北のピーノまで）で動かし、アプリを動かしている間だけ残す。
同じ日に、冒険していないときのホームの行き先カードから世界地図を開くようにし、旅の案内所を世界地図のダンジョン一覧（案内人なし、「もどる」で世界地図へ戻る）にした（[画面](screens/guide.md#編成商会神殿旅の案内所の画面)）。街ごとの解放は2026-10-25に足した（[街とダンジョン](stage-progression/destinations.md#街とダンジョン仮)）。
2026-10-25に、[街道の宝箱](#街道の宝箱と街2026-10-25)を実装した。
宝箱の中身は、サーバーの [catalog.ts](../../server/src/features/world-map/catalog.ts) の `CHESTS` とクライアントの [WorldMapChests](../../client/Assets/Baryonyx/Features/WorldMap/Runtime/WorldMapChests.cs) が同じ値を持つ。
宝箱のマスをクリアした移動（`POST /v1/world-map/move`）で、サーバーはクリアしたマスの行に受け取りの印（`world_map_squares.grant_id`）を付けて書き、その行を書けたときだけ中身を持ち物に足す。
送り直しでは行を書けないため、二重には足さない。
応答には中身を添える（`chest`）。
地図は、宝箱のマスに着くとクリアを保存し、保存できてから中身を冒険の宝箱と同じ札（`Shared/UI/Reward/RewardReveal`）ですべて一度に見せる。良い物から並べ、1.4秒に2つ目から1つにつき0.5秒を足した間をおいて閉じる（2026-10-29、ユーザーの依頼でダイアログの文字から札にそろえた。札のない地図ではダイアログで見せる）。
札が閉じるまでは、マスを押しても歩かない。
保存に失敗したら、ほかのマスと同じく保存先の進み具合へ戻して知らせる。
接続先がないときは、`WorldMapChests` の中身を見せる。
同じ日に、歩数の関所のマスの種類（`StepGate`）と台の絵をなくした。
