# 固有スキルの覚醒

[機能索引](README.md) / [キャラクターとパーティ編成](party.md) / [戦闘システム](combat.md) / 根拠：2026-10-18・2026-10-24のユーザーとの相談

各キャラの[固有スキル](party.md#キャラクターの構成)は、冒険の中や商会で別の段階のカードに変わる。
カスタムスキルの枠に入れるスキルの覚醒は、[カスタムスキルの覚醒](skill-awakening.md)に従う。
これを**覚醒**と呼ぶ。
覚醒して取得した段階はずっと残り、編成でどの段階を使うかを選べる。
冒険のたびに少しずつ固有スキルが育ち、どの枝へ育てるかをプレイヤーが選ぶ楽しさを作る。

参考にしたのは、カオスゼロナイトメアの「カードのひらめき」である（戦闘でカードを使うと確率で起き、候補から選んでカードを進化させる。[GameWith](https://gamewith.net/chaoszeronightmare/70805)、2026-10-18確認）。

## 確定している方針

### 覚醒の段階とツリー

固有スキルは、最初の段階から3つの枝に分かれ、それぞれの枝がもう1段進む。
最初の段階を含めて、1つの固有スキルは7つの段階を持つ。

```text
最初の段階 ─┬→ 枝1の1段目 → 枝1の2段目
            ├→ 枝2の1段目 → 枝2の2段目
            └→ 枝3の1段目 → 枝3の2段目
```

各段階の効果は、キャラの固有スキルごとに個別に作る。
どの固有スキルにも同じ型（コスト-1など）を当てはめる作り方はしない。

1回の覚醒で、ツリーを1段進む。
進む先は、編成でセットしている段階の次の段階である。
枝分かれでは、どの枝へ進むかをプレイヤーが選ぶ。
ランダムに決まるのは、覚醒が起きるかどうかだけである。

解放前の固有スキル（[レベルアップ](progression.md#レベルアップ)で解放する）は覚醒しない。

### 覚醒が起きる場面

覚醒は、冒険の中の次の場面と、Homeの商会で起きる。

- **戦闘**：固有スキルのカードを手札に引いたとき確率で当たり、当たったカードを使うと覚醒する（[戦闘中の覚醒](#戦闘中の覚醒)）。
- **宝箱**：宝箱の中身として覚醒が出る。その場で、パーティの4人の解放済みの固有スキル（最大12枚）から進める1枚を選び、次に進む段階を選ぶ。進められる固有スキルが1枚もないときは、宝箱から覚醒を出さない。
- **覚醒の祭壇**：まれに出るマスで、パーティの固有スキルから1枚を選び、1段覚醒させる（[マスの中身](stage-progression.md#マスの中身仮)）。
- **商会**：Homeの[商会](screens.md#商会)で、覚醒の欠片とルーンを払って1段覚醒させる。選べる段階と費用は[商会の強化](enhancement.md#覚醒)に従う（2026-10-24）。

### 戦闘中の覚醒

覚醒の抽選は、固有スキルのカードを手札に引いたときに行う（2026-10-24、ユーザー決定）。
当たったカードは手札で光り、使うと覚醒する（[覚醒の予兆](#覚醒の予兆)）。
覚醒は、カードの効果を出す前に起きる。
光ったカードを使うと、次の順に進む（2026-10-21、ユーザー決定。抽選の時点は2026-10-24に改めた）。

1. カードを使い、エネルギーを払う。
2. 効果を出す前に、覚醒の前触れのエフェクトを出す。
3. プレイヤーが[覚醒の候補](#覚醒の候補)から覚醒先を選ぶ。
4. 選んだ覚醒後の段階で、攻撃やスキルの効果を出す。

覚醒したカードは、その使った回から覚醒後の段階になり、その戦闘の中で次に使うときも覚醒後の段階のままである。
その回のコストは、使ったときに払った覚醒前の値のままとし、覚醒後のコストとの差は払わない（仮）。
次に使う回からは、覚醒後のコストを払う。

1回の戦闘で、1枚の固有スキルが覚醒するのは1段までとする。
ツリーは2段しかないため、1回の戦闘で最後の段階まで進むと、育てる手応えが薄くなるからである。

覚醒の確率は、敵の強さで決める。

- マスの種類で基本の確率を決め、魔物、強い魔物、最奥のボスの順に高くする（[マスの種類](stage-progression.md#冒険の道の作り方)）。
- ダンジョンの推奨Lvより、その固有スキルを持つキャラのLvが高いほど、確率を下げる。

覚醒はずっと残るため、Lvの差による補正がないと、弱い敵のマスを何度も通るだけでツリーを取りきれてしまう。
覚醒しない回数に応じて確率を上げる仕組み（天井）は、まず設けずに試し、遊んで不満が出たら足す。
今の値は[確率の仮設定](#確率の仮設定)に書く。

### 覚醒の予兆

引いたときに当たったカードは、手札で光らせて、使えば覚醒することを見せる（2026-10-24、ユーザー決定）。
参考にしたのは、カオスゼロナイトメアの、ひらめきが起きるカードが光る見せ方である（[Game8](https://game8.co/games/Chaos-Zero-Nightmare/archives/558115)、2026-10-24確認）。
使ったときに抽選する形では、光で示せるのが「覚醒しうる」ことだけになり、ほぼすべての固有スキルが光って意味がなくなる。
引いたときに当たりを決めて光らせると、プレイヤーは光ったカードをいつ使うかを考えられる。

| 項目 | 決まり |
|---|---|
| 抽選 | 固有スキルのカードが手札に入るたびに1回行う。次の段階がないカード、この戦闘で覚醒済みのカード、すでに光っているカードは抽選しない |
| 光の続き方 | 当たったカードは、使うまで光り続ける。使わずに山札へ戻り、また引いたときも光ったままで、抽選し直さない。戦闘が終わると消え、次の戦闘へ持ち越さない |
| 上限 | 1回の戦闘で1枚1段までの上限は、光ったカードを使って覚醒した時点で数える |
| 見せ方 | カードの後ろで息づく金の光、縁のすぐ外を流れる金の光の線、右上の角で瞬く星（覚醒の前触れで光る「ひらめきの印」と同じ位置）。裏向きで飛んでくる間は出さず、表を向いたときに一度大きく明るく瞬いてから（0.5秒）落ち着く。演出の格は前触れより控えめにし、手札のほかのカードを読みにくくしない |
| 戦闘の初めの予告 | カオスゼロナイトメアの、デッキが光って「この戦闘で起きる」と知らせる予告は作らない。手札の光だけで足りるかを遊んで確かめる |

### 覚醒の候補

冒険中の覚醒の候補は、セットしている段階の次の段階すべてである。
最初の段階なら3つの枝の1段目、1段目ならその枝の2段目の1つが候補になる。
2段目には次の段階がないため、それ以上は覚醒しない。

すでに取得した段階も候補に出し、「取得済み」と書く。
取得済みの段階を選んだときも、未取得の段階を選んだときと同じく覚醒として扱う。
カードはその段階に変わり、1回の戦闘で1段までの上限にも数える。
そのため、次の段階がすべて取得済みでも覚醒は起きる。

### 取得した段階とセット

覚醒で取得した段階は、ずっと残る。
冒険に負けて終わっても、それまでの覚醒は残る（[冒険の終了と獲得物の保持](stage-progression.md#冒険の終了と獲得物の保持)）。

編成では、固有スキルごとに、取得した段階のどれか1つをセットする。
最初の段階や途中の段階もセットできる。
冒険が終わると、冒険中に覚醒した段階がそのままセットされた状態になる。

冒険中は、覚醒のほかにセットする段階を変える手段はない。
パーティの入れ替えや装備の変更は探索中にもできるが（[パーティの未決事項](party.md#未決事項)）、固有スキルの段階を手前に戻せるのはHomeの編成だけである。
別の枝へ進めたいときは、Homeの編成で手前の段階にセットし直し、次の冒険でそこから覚醒させる。
商会では、セットしている段階によらず、覚醒の欠片で別の枝へ進められる（[覚醒で選べる段階](enhancement.md#覚醒で選べる段階)）。
これを繰り返すと、7つの段階をすべて取得できる。

### 編成での見せ方

編成では、固有スキルごとのツリーを見せる。
取得した段階は名前と効果を見せ、セットする段階として選べる。
取得していない段階は、ツリーの形だけを影として見せ、名前と効果を見せない。

### 覚醒の保存

取得した段階とセットしている段階は、ユーザーごとにゲームサーバーのDBに保存する。

冒険中の覚醒は、そのマスを終えたときにサーバーへ保存する。
戦闘中にアプリが終わると、そのマスの戦闘を始めからやり直すため（[冒険の中断と再開](stage-progression.md#冒険の中断と再開)）、その戦闘の中での覚醒は残らない。
負けて冒険が終わるときは、そのマスでの覚醒も保存する。

2026-10-22の実装では、戦闘の中の覚醒をそのマスの戦闘を終えた時点（勝ったときと、全滅したとき）で残し、1つずつサーバーへ送る。
戦闘を終えずに冒険をやめたり中断したりしたときは、その戦闘の中の覚醒は残さない。
送るのは編成のAPIの「覚醒」（キャラ・固有スキルの番号・覚醒後の段階）で、サーバーは、固有スキルが解放済みで、覚醒後の段階の1つ手前がセットしている段階であることを確かめる。
あわせて、冒険の途中か、踏破・敗北で冒険を終えてから10分以内であることも確かめる。最奥のボスや全滅では、そのマスと一緒に冒険も終わり、覚醒が冒険を終えた知らせと前後して届くためである。途中でやめた（撤退した）冒険の戦闘の覚醒は受け付けない。
同じ覚醒を送り直しても、2回目は何も変えない。
編成でセットする段階を変えたときも、編成のAPIで保存する。
保存は、ほかの保存と同じ待ち行列で順に送り、変更はすぐに画面へ出す。
保存に失敗したら通知の帯で知らせ、次に編成を読んだときにサーバーの進み具合にそろえる。

## 設計方針

覚醒した段階のエフェクトは、覚醒前より派手にし、育った手応えを見て分かるようにする（2026-10-18のユーザーの希望）。

ツリーは、2026-10-18の時点ではキャラ1人ずつ作り、手触りを確かめてから次へ進む方針だった。
2026-10-19、ユーザーの依頼で、仮データの8つの固有スキルの全段階（56段階）の効果と挿絵を、まとめて仮に作った。
続けて、ユーザーの依頼「より強いものはより脳汁出る感じで」で、エフェクトを段階ごとに作った。
ツリーごとに専用の演出（マナバーストは魔力の球の炸裂、星降りは流れ星など）を持ち、枝ごとに色・形・当たり方を変える。
段階が進むほど層を重ねる。1段目は溜めと、当たるたびの衝撃（床を外へ走る土ぼこり）・光・火花を足す（2026-10-23、床に描いた輪から変えた）。2段目は必ずカットインし、暗転とスローの溜め、大きな閃光・ヒットストップ・寄り、0.16秒後の二段目の炸裂、漂う光の粒の余韻まで重ねる。
大きな閃光などの山場は、主な当たりの最後の一撃で一度だけ出し、状態を付けるだけの当たり（やけどの付与など）には強化の層を重ねない。
山場の照り返しは標的の周りに留め、画面全体を属性の色に染めない（2026-10-19、デバッグルームのコマで確かめて調整した）。

枝は、同じ固有スキルを3つの違う方向へ育てる。
威力や回数を上げるだけの枝は1本までにし、残りの枝では状態・属性・対象・手札とエネルギーへの働きを変える。
2段目は1段目の方向を強め、1段目で始めた効果を大きくするか、効果を1つ足す。

### 覚醒のエフェクト

[戦闘中の覚醒](#戦闘中の覚醒)のエフェクトは、「魔法陣で浮いて、パリーンと割れて覚醒する」形にした（2026-10-21、ユーザーの依頼）。
Codex CLIの画像生成で前触れ・選択・確定の場面の絵を作り、ユーザーが前触れと確定の絵を選んだ。
2026-10-21にスキルのデバッグルームで0.1秒刻みのコマを撮って確かめ、破片が小さく灰色に見えた点と、割れた瞬間にカードがそのまま替わり割れた感じが弱かった点を直した。
狙う感覚は、前触れが「力が集まって目覚める」、割れる瞬間が「殻を破る」である。

| 拍 | 時間 | 見せ方 |
|---|---|---|
| 前触れ | 約1.05秒（2段目への覚醒は1.2秒） | 背景を夜の青へ暗くする。使ったカードが使い手から浮き上がり、敵の側へ寄った使い手と同じ高さで1.6倍になる。画面の上端（戦闘では行動順）からは150px離す。カードの後ろに立てた金の魔法陣が回り、使い手の足元にも魔法陣と光だまりが出て、使い手を足元から照らす。四方から光の粒がカードへ集まり、0.55秒からカードの中心から金のひびが走る。最後にカードの右上の角で星が光る（ひらめきの印） |
| 選択 | 決まっていない | カードは0.35秒で画面の上の端へ移り、0.6倍に縮む（下の候補を大きく見せるため）。魔法陣と光もカードについていく。カードはゆっくり上下し、細かく震えたまま、[覚醒先を選ぶ画面](#覚醒先を選ぶ画面)で選ばれるのを待つ |
| 割れる | 約0.62秒（2段目への覚醒は0.77秒） | カードが一瞬縮んでから、ガラスのように割れる。ヒットストップ・揺れ・寄り・閃光と、白い光・星・2重の衝撃の輪を出し、Bloomで光るガラスの破片が四方へ飛んで落ちる。0.07秒はカードを消して破片と光だけにし、そのあと覚醒後のカードが小さい姿から一回り大きく弾んで現れる。光は覚醒後の段階の色（[枝ごとの色](#設計方針)）に変わり、魔法陣もその色で速く回って消える |
| 使い手へ | 約0.26秒 | 覚醒後のカードが光の尾を引いて使い手へ飛び込み、使い手の体で星が光る。そのあと覚醒後の段階の演出が始まる |

2段目への覚醒では、魔法陣を2重にし、ひびを2回走らせ、割れた0.16秒後にもう一度炸裂させる。
画面全体の閃光は、ほかの演出と同じ間隔と濃さの上限を守る（[スキルの演出と背景](screens.md#スキルの演出と背景)）。

### 覚醒先を選ぶ画面

覚醒先は、ひびの入ったカードの下に候補を並べて選ぶ（2026-10-22、ユーザーの選択）。
Codex CLIで作った2つの案（ひびの入ったカードから枝を伸ばす案と、候補を大きく横一列に並べる案）から、ユーザーが枝を伸ばす案を選んだ。
前触れから同じカードが画面に残り続けるため、流れが切れない。

| 部分 | 見せ方と操作 |
|---|---|
| 覚醒前のカード | 画面の上の中央に、ひびが入って光ったまま浮かぶ。後ろで金の魔法陣が回る |
| 光の枝 | 覚醒前のカードの下端から、各候補のカードの上端へ、金の光の線を引く。候補が現れるのに合わせて伸び、伸びきったあとも光が流れ続ける。選んだ候補への枝は太く明るく、ほかは薄くする |
| 候補 | [覚醒の候補](#覚醒の候補)を、戦闘のカードの2.1倍（約441×617px）で、画面の中央から下に横に並べる。3枚なら左・中・右に490px間隔で置き、手札のように少し外へ傾け、両端を少し下げる。隣どうしは少し重なってよく、選んだ候補をいちばん手前に描く。1枚なら中央に置く。候補は0.08秒ずつ遅れて下から現れる。カードには、名前・効果・コストをそのまま見せる |
| 取得済み | 取得済みの段階の候補には、カードの右上に「取得済み」の札を付ける。取得済みでも同じように選べる |
| 選ぶ | 候補をタップすると、その候補が少し浮き、縁から淡い金の光の霧が湯気のように立ちのぼる（Codexの画像の案A「縁から立ちのぼる光の霧」）。霧は加算で光る炎の舌の形を淡い金にした幅の広い揺らめきで、上辺と左右から1本ずつ生まれ、昇りながらふくらんで消え、別の場所から生まれ直す。縁のすぐ外には細い金の光の線が走り、中を光が流れる。後ろに柔らかい光が息づき、下から光の粒が昇る。霧と光はカードより奥に描き、挿絵と説明文には掛けない。ほかの候補は暗くなる。別の候補をタップすると選び直せる。候補が1枚のときは選ぶものがないため、選んだ状態で見せ、開いてから0.9秒で自動で決める |
| 決める | 候補の下の「この覚醒にする」で決める。何も選んでいない間は押せない。押すと選択画面が消え、カードが割れて、選んだ段階になる。候補が1枚のときは、このボタンを出さない |

選んでいる間は戦闘を止めて待ち、時間の制限は設けない。
支払ったエネルギーは戻らないため、覚醒をやめる操作は設けない。
未取得の段階も、選ぶときには名前と効果を見せる（仮）。

### 今のツリー（仮データ）

12の固有スキルの枝の方向は次のとおりである（2026-10-19、3つ目の4つは2026-10-23、仮）。
各段階の効果・コスト・説明文は [UniqueSkillTrees](../../client/Assets/Baryonyx/Features/SkillEvolution/Runtime/UniqueSkillTrees.cs) を正本にする。
コストは、カードスキルと同じ配り方（基本は1〜3、4以上は少なく）で、どの段階も0〜7に収めた（2026-10-20）。
軽くする枝（一閃・瞬はコスト1、雷撃の矢・閃光はコスト0など）は軽いまま、大技の枝（蘇生・不死鳥はコスト7）は重いまま、枝の役割の差を残した。
倍率の上限と光り方は固有スキルごとに1つで、覚醒しても変わらない（[上限の決め方](inventory.md#上限の決め方)・[カードのキラキラ](../art/direction.md#カードのキラキラ)）。

### 確率の仮設定

2026-10-21、ユーザーの依頼で、[戦闘中の覚醒](#戦闘中の覚醒)の確率を次のように仮に決めた。
抽選は、固有スキルのカードを手札に引くたびに1回行う（2026-10-24に、使うたびから改めた）。
そのため、その戦闘で引かなかった固有スキルは覚醒せず、光っても使わなければ覚醒しない。
値は、使うたびに抽選していたときのままにした。手札は次のターンへ持ち越し、引いたカードはたいてい使うため、引く回数と使う回数は近いと見ている。実測して見直す。

| マス | 1回使うごとの基本の確率 | 1回の戦闘で起きる覚醒の回数（見積もり） |
|---|---|---|
| 魔物の気配 | 4% | 約0.2回 |
| 強い魔物の気配 | 8% | 約0.7回 |
| 最奥の間 | 10% | 約1.2回 |

キャラのLvが行き先の推奨Lv（その行き先の敵のLv、[行き先と敵](stage-progression.md#行き先と敵)）より1高いごとに、基本の確率の1割ずつ下げ、下限は基本の確率の2割とする。
式にすると、確率 = 基本の確率 × max(0.2, 1 − 0.1 × (キャラのLv − 推奨Lv)) である。
たとえば、推奨Lvより3高いキャラが最奥の間で使うと、10% × 0.7 = 7% になる。
推奨Lv以下のキャラは、基本の確率のままにする（[推奨Lvより低いとき](#未決事項)は未決）。

値は、確率から決めずに、先に目標の頻度を決めて逆算した。
目標は、推奨Lvで最初のダンジョン（道中の戦闘が6〜7マス、強い魔物が2マス以上、最奥の間）を1周すると、覚醒が3回前後起きることである。
2〜3回の戦闘に1回覚醒し、最奥の間ではたいてい1回は覚醒する頻度になる。
この頻度では、4人の固有スキル8つのツリーを取りきるのに48回の覚醒が要り、約15回の冒険（約4時間）かかる。
2026-10-23に固有スキルを1人3つにしたが、確率と見積もりは2つの時点のまま見直していない。

1回の戦闘で固有スキルを使う回数は、魔物の気配で約5回、強い魔物の気配で約8回、最奥の間で約12回と見積もった。
山札16枚のうち8枚が固有スキルで、1ターンに2〜3枚使い、戦闘が3〜4ターン・5〜9ターン・6〜14ターン続く（[戦闘の試し](stage-progression.md#戦闘の試し)）ことから求めた。
戦闘が長いほど抽選の回数も増えるため、マスごとの確率の差は小さくした。
1回の戦闘で1枚1段までの上限があるため、最奥の間でも覚醒は約1.2回に収まる。

Lvの差による下限を0にしないのは、もう覚醒しない状態がプレイヤーに分かりにくいからである。
行き先の推奨Lvはおおむね4〜5ずつ上がるため、2つ手前の行き先で下限に届き、次の行き先へ進むほうが覚醒しやすくなる。

見積もりは計算だけで求め、固有スキルを使う回数は実測していない。
自動でカードを使わせる戦闘で回数を実測し、目標の頻度に合わせて見直す。
