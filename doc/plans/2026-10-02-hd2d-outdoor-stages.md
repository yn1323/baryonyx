# Topと戦闘画面の屋外の舞台

[計画の索引](README.md) / 仕様の正本：[3Dの舞台](../art/hd2d-stage.md) / 前の計画：[Homeの昼の森と、HD-2Dのレンズ・色調・カメラ](2026-10-02-hd2d-glade-look.md)

状態：完了（Editorでの実装と検証。Android端末での確認は未実施）

## 依頼

2026-10-02、Homeの昼の森を見たユーザーから、TopとBattleInspectも屋外にしたい、Homeとは被らない感じにしたい、と依頼を受けた。

## 判断

Homeは昼の森（緑）なので、時間帯と色で分けた。

| 画面 | 舞台 | 選んだ理由 |
|---|---|---|
| Top | 星空の夜、松明の並ぶ石の道の先に古代の門が建つ山の上 | タイトルの白い文字が暗い空で読みやすい。「ダンジョン」の入口を思わせる門を中央に置ける。月を門の背後に昇らせ、タイトル画面らしい一枚絵にできる |
| BattleInspect | 夕暮れの高原の環状列石 | 苔の緑の敵が、橙と赤紫の背景に埋もれない。明るすぎない夕暮れで、加算の光の演出が映える（演出中は従来どおり画面を暗くする） |

| 決めたこと | 理由 |
|---|---|
| 空と遠景は、光を受けず霧もかけない描いた遠景にする | 時間帯の色を絵に描き込める。霧で遠景の色が消えない |
| 星は白より明るくしてBloomで光らせ、点ごとにずらして瞬かせる。月も白より明るくする | 夜空の主役を光らせる。まわりより明るい1〜2ドットだけを星とみなし、月や雲は瞬かせない |
| 月明かりは門の背後から当て、手前から影のない弱い補助光を当てる | 逆光で崖と門の正面が真っ黒になった。オクトパストラベラーの開発者が述べる「ライティングでのウソ」に当たる |
| 夜空は、減色のときに明るい画素の色を別に確保する | 暗い青が画面の大半を占め、そのまま32色にすると月が平らな灰色になった |
| Topの広間の天井から差していた2Dの光芒を外す | 屋外の夜には出どころがない |
| 広間と森の遺跡の舞台は残す | ダンジョンの中や森の遺跡の場面に使える。使わないと決めたら削除する |

## 実施した内容

1. Codex CLIでテクスチャ15枚（夜空、山並み、草地、石畳、門、崖、岩、松明台、乾いた地面、石舞台、夕暮れの遠景、立石、岩の尖塔、枯れ木、かがり火台）を生成し、32色の `.aseprite` にした。依頼文は [prompts.json](../../client/ArtSource/Stages/prompts.json) に記録した。
2. 描いた遠景のシェーダー `Baryonyx/HD2D/Painted Distance` を作った。
3. 2つの舞台（`StarlitGateStage`・`DuskHighlandStage`）と、そのProfile（`StarlitGateLook`・`DuskHighlandLook`）をコードで組み、Top・BattleInspectのシーンに置いた。
4. テクスチャの変換スクリプトに、明るい画素の色を別に確保する指定（`--bright-colors`）を加えた。
5. 展示室に新しい舞台・テクスチャ・Profile・シェーダーが並び、舞台がプレビューされることを確かめた。
6. スキル（[hd2d-lighting-vfx](../../.agents/skills/hd2d-lighting-vfx/SKILL.md)）に、夜と夕暮れの屋外の作り方とつまずいた点を記録した。
