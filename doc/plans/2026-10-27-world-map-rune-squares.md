# 街道の世界地図をルーンで開き、日・週・月の出来事を起こす

状態：進行中（2026-10-27に、[地図を広げる](#地図を広げる)試作を、マスの中身を置かずに、今の地図と別の画面として作った。ルーンで開くこと、マスの出来事、日・週・月の復活は未着手）

[計画索引](README.md) / [探索とダンジョンの進行の街道](../features/stage-progression.md#街道とダンジョン) / [ルーン経済](../features/economy.md#ルーンの用途) / [日付の区切り](../features/daily-rules.md)

## 目的

街道の世界地図を、歩いて得たルーンを払って1マスずつ開いていく地図にする。
「運動しないと世界地図を移動すらできない」を、このゲームのコンセプトとして地図で体験させる（ユーザー）。
あわせて地図を今より広くし、すべてのマスで何かが起きるようにする。
開けたあとも、決まった場所で日・週・月ごとに出来事が復活し、毎日地図を開く理由を作る。

## 依頼と決定した事項

2026-10-27、ユーザーとの相談で次を決めた。

| 項目 | 決めたこと |
|---|---|
| まだ行ったことがないマス | 入るのにルーンを払う。マスによって値段を変えてよい |
| 何もないマス | 置かない。すべてのマスで何かが起きる（2026-10-24の「何もないマスを多く置く」を改めた） |
| 街道で歩数を使うか | 使う。2026-10-25の「街道では歩数を使わない」は、ゲームのコンセプトと矛盾するため改めた。払うのは累計の歩数ではなく、ルーンの残高である |
| 開けたマス | タダで通れる（今の仕様のまま） |
| 値段の差 | マスの種類で変える。珍しいマスほど高く、街に着くときも高めにする。奥地でも1マスの上限は1,000ルーン程度にする |
| 地図の広さ | 今の地図は狭い。背景の絵はそのままで、マスをずっと増やす。広げ方は、背景を2倍に拡大して方眼を細かくする案（[地図を広げる](#地図を広げる)）で進める |
| 1回きりの「？」マス | 入れる |

| 日・週・月の出来事 | 世界地図を土台に、デイリー・ウィークリー・マンスリーの出来事を起こす |

## 仕様案

### マスを開くルーン

**開く**とは、まだ入ったことがないマスに、初めて入ることを指す。
開けるのは、開けたマスと道でつながったマスだけである。
1回に開けるのは1マスで、離れたマスへ一気に飛ぶことはできない。

1. 開けていないマスを押すと、画面の下にマスの種類・値段・残高を出す。
2. 「進む」を押すとルーンを払い、駒がそのマスへ跳んで、出来事が始まる。
3. 足りないときは「あと1,200歩」のように、足りない分を歩数で出す。1歩＝1ルーンのため、歩数とルーンは同じ数になる。

払ったマスでは、小さくても必ず何かを持ち帰れるようにする。
着く前に払うため、払って何も起きないと、損をした気持ちだけが残るからである。

戦闘と関所のボスのマスは、最初に入るときに1回だけ払う。
負けて挑み直すときは払わない。
払ったのに負けて、もう一度払うのは二重取りに感じられるためである。
先へ進めるのは、戦闘に勝ってマスを**クリア**してからにする。
そのため、マスには「払った（開けた）」と「クリアした」の2つの状態がある。

#### 値段（仮）

マス代 ＝ 区間の基本料 × 種類の倍率

区間の基本料は、街と街の間の区間の推奨Lvから、100 ＋ 推奨Lv × 10 で決める。

| 区間の推奨Lv | 10 | 14 | 22 | 30 | 40 |
|---|---|---|---|---|---|
| 基本料 | 200 | 240 | 320 | 400 | 500 |

| 種類 | 倍率 | Lv10の区間 | Lv40の区間 |
|---|---|---|---|
| 道のマス・戦闘・採取地 | ×1 | 200 | 500 |
| 1回きりの「？」・物語・見晴らし台 | ×1.25 | 250 | 625 |
| 宝箱・行商人 | ×1.5 | 300 | 750 |
| 関所のボス・街・祠・強敵の巣・隠し宝箱 | ×2 | 400 | 1,000 |

いちばん高いマスは、Lv40の区間の×2のマスで1,000ルーンになる。
約260マスをすべて開けると、約10万ルーン（6,000歩の日の約17日分）になる見込みである。
地図だけに使う人はいないため、レベルアップや召喚と分け合って、1〜2か月で地図を埋める計算になる。

次の表は、1日に地図へ回すルーンと、開けるマスの数の目安である。
どれだけ回すかは[未決事項](#未決事項)とする。

| 地図へ回すルーン | Lv10の区間 | Lv22の区間 | Lv40の区間 |
|---|---|---|---|
| 1,500（6,000歩の4分の1） | 7マス | 4〜5マス | 3マス |
| 3,000（6,000歩の半分） | 15マス | 9マス | 6マス |

### 地図を広げる

背景の絵（1536×1024画素）はそのまま使い、画面には2倍に拡大して出す。
方眼を48画素から24画素に細かくし、64×42の方眼にマスを置く。

- マスの数は約260を目安にする（仮）。街と街の間の区間は、今の6〜8マスから15〜25マスに延びる。
- ドット絵の背景は、整数倍の拡大なので、画素の形を保ったまま大きく見える。ただし、画面では今より粗く見える。2本指の拡大の上限（今は2倍）と下限は、試作を見て決め直す。
- マスの台座と駒の大きさは、画面で見た大きさを今と同じにする。地図だけが広がる。
- 道の文字の図（`WorldMapCatalog` の `Rows`）は、64文字×42行になる。手で書き続けられるかは、作るときに確かめる。

道の形は、値段の差を生かして選ぶ理由を作る。

- **近道**：関所や高いマスが続くが、マスの数が少ない道。
- **遠回り**：安い道のマスが多いが、長い道。
- **寄り道**：行き止まりの先に、宝箱・祠・隠し宝箱を置く。

背景の地形（森・平原・山・海辺・砂漠・雪原）に合わせて、道のマスで拾える物を変える（[道のマス](#道のマス)）。

道のマスと「？」は、Civilizationの部族の村のように、同じ種類を近くに固めないよう間を空けて置く。

#### 道のマス

これまでの何もないマスの代わりに置く、いちばん多いマスである。
着くと拾った物を短く見せて、押さなくても3秒ほどで終わる。
疲れないように、選ぶことは何もさせない。

- **地形の拾い物**：森で薬草や木の実、山で鉱石、海辺で貝殻、砂漠で砂金、雪原で氷の結晶など、地形の素材を拾う。少しの確率で磨き石を拾う。
- **石碑の欠片**：区間ごとに3〜5つ置く。区間の欠片をすべて集めると、宝の地図になって隠し宝箱の場所が分かる（Heroes of Might and Magicの、オベリスクを回ると聖杯の場所が分かる仕組みを参考にした）。
- **区間の名物**：区間ごとに1種類の名物（例：ブリーザの風車の羽根、ポルトリアの桜貝）を拾う。ライブラリに集める（ドラクエウォークの地域ごとのおみやげを参考にした）。

#### 1回きりの「？」

着くと短い場面を見せ、2〜3つの選択肢から選ぶ（Slay the Spireの「？」の部屋を参考にした）。
選んだ結果は、開けたときに1回だけ起きる。
編成しているキャラや、カードの属性（炎・氷・雷・斬・打・貫）によって、選択肢が1つ増える出来事を混ぜる（FTLの、特定の種族や装備で選択肢が増える出来事を参考にした）。
キャラを集め、編成を変える理由になる。

HPはマスの間で持ち越さないため、「HPを減らす」代わりの損は、ルーンや持ち物で払う形にする。
どの選択肢を選んでも、何も得られずに終わる結果は作らない。

| 出来事 | 選択肢の例 | 編成で増える選択肢 |
|---|---|---|
| 倒れた荷車 | 素材を1つ渡して直す（お礼に装備） / 積み荷を探る（素材） | 打の属性のカードを持つキャラがいれば、荷車を持ち上げて両方もらう |
| 封印された箱 | こじ開ける（中身は抽選） / 置いていく（小さな拾い物） | 雷の属性のカードを持つキャラがいれば、封印を解いて良い方の中身を選ぶ |
| 迷子の子ども | 街まで送る（次に着く街で、お礼がもらえる） / 道を教える（小さな拾い物） | |
| 古い井戸 | ルーンを100投げ入れる（運試し。返ってくるのは0〜300ルーンか素材） / のぞくだけ（素材） | |
| 腕試しの旅人 | 戦う（勝てば装備） / 断る（旅人の助言で、次の関所のボスの弱点が分かる） | |
| 焚き火の跡 | 日記を読む（物語の断片をライブラリに） / 火を起こす（素材） | |
| 占い師 | 占ってもらう（次の関所のボスの弱点が分かる） / 品物を見る（スキル1つを買える） | 占い師と縁のあるキャラ（キャラごとに決める）がいれば、磨き石ももらえる |
| 石像の謎 | 謎を解く（覚醒の欠片） / 祈る（素材） | 炎・氷・雷の3つの属性がそろっていると、石像が動いて隠し道が開く |

#### 開けたマスの印

クリアしたマスは、今は何もないマスの台に変えている。
この案では、何もないマスがなくなるため、終わったマスは台の色を落とし、アイコンを薄くして、もう何も起きないことを見せる。
復活したマスは、アイコンを光らせて目立たせる。

### 日・週・月の出来事

**復活**とは、一度終えたマスの出来事が、決まった時刻にまた起きるようになることを指す。
復活するマスは、決まった場所に置く（Heroes of Might and Magicの、風車や庭が週に1回資源をくれる仕組みを参考にした）。
決まった場所にすることで、「今日はあの採取地とあの行商人に寄る」という自分の巡回路ができる。

| 区切り | 時刻 | 復活するマス |
|---|---|---|
| 毎日 | 朝4時（[ルーン変換と同じ区切り](../features/daily-rules.md)） | 採取地・行商人 |
| 毎週 | 月曜の朝4時 | 強敵の巣 |
| 毎月 | 毎月1日の朝4時 | 祠 |

復活したマスに入るときは、そのマスの値段をまた払う。
そこまでの開けた道はタダで通れる。
今いるマスが復活したときは、その場で「もう一度」を押して払う。

#### 採取地（毎日）

区間ごとに1つ置き、その地形の素材をもらう。
奥の区間の採取地ほど、良い素材が出る。
少しの確率で、磨き石や覚醒の欠片が出る。

#### 行商人（毎日・曜日で品ぞろえ）

曜日ごとに、売る物の分類を変える（桃太郎電鉄の、売り場ごとに品ぞろえが違う仕組みを参考にした）。
行商人ごとにも品ぞろえを変え、同じ曜日でも場所によって違う物が並ぶ。

| 曜日 | 品ぞろえ（案） |
|---|---|
| 月・木 | スキル |
| 火・金 | 武器・防具 |
| 水・土 | アクセサリー・素材 |
| 日 | 珍品（品質の高い物が1つだけ並ぶ） |

品物は、ダンジョンの行商人と同じくルーンで買う。
値段は[ダンジョンの行商人](../features/stage-progression.md#マスの中身仮)と同じ式を使う。

#### 強敵の巣（毎週）

区間の強い魔物が、週に1回戻ってくる。
勝つと強化素材をもらう。
今の決まり「クリアしたマスで戦い直して報酬を得る仕組みは持たせない」の例外になる（[未決事項](#未決事項)）。

#### 祠（毎月）

月に1回、覚醒の欠片を1つもらう。
祠は地図に4つほど置き、奥の区間ほど多くの祠に手が届く。
祠ごとに月1回もらえるため、置く数で欠片の量を決める。

#### 画面での見せ方

- 世界地図の端に、今日・今週・今月にまだ寄っていない復活のマスの数を出す。
- ホームの世界地図のカードに、寄れる復活のマスがあることを印で出す。
- 復活のマスへは、押すと開けた道を最短で自動で歩く（今の移動と同じ）。

## 進める順序

1. この計画の未決事項を決める。
2. 地図を広げる。背景の2倍表示と24画素の方眼で、マスの配置を試作し、画面イメージをユーザーに見せて決める。
3. ルーンで開く。サーバーに開けたマスと支払いの記録を置き、要求IDで二重の消費を防ぐ（[データの保存先](../rules/data-storage.md)）。値段はサーバーが決める。
4. 道のマス・1回きりの「？」・見晴らし台・隠し宝箱を作る。
5. 採取地・行商人・強敵の巣・祠と、日・週・月の復活を作る。
6. 新しいマスのアイコンと台座を展示室へ登録する。

## 完了条件

- 開けていないマスに入るとルーンが減り、足りないと入れず、足りない歩数が出る。
- 開けたマスの上は、ルーンを払わずに歩ける。
- 何もないマスがなく、どのマスでも何かを持ち帰れる。
- 採取地と行商人は朝4時、強敵の巣は月曜の朝4時、祠は毎月1日の朝4時に復活し、入るとまたルーンが減る。
- 同じ要求を再送しても、ルーンは二重に減らない。
- 新しいマスのアイコンが展示室に並び、プレビューで確かめられる。

- ほかの地域も、同じ作り方でエリアマップを作る。
- 町などのドット絵やイラストは、まだ置かない。背景とその上のマスだけにする。
- 世界地図の地域のマスに着くと、その地域の細かい地図（エリアマップ）へ移る。

作ったもの：

- 世界地図の5倍の背景を、依頼文から細かい点を増やす指示を外して81区画で作り直した。
- 残りの6地域（ヴェルデ平原・マリーナ海岸・ジェーロ連峰・ボスコ大森林・フィアンマ火山帯・ネッビア湿原）のエリアマップを、オーロ砂漠と同じ作り方（道筋を描いた下絵を区画ごとに描き直してつなぐ）で作った。地域の境は、地域ごとに置いた目印からいちばん近い地域を選んだ線のままである。
- 地域どうしの入口を10か所置いた。オーロ砂漠の3か所はこれまでの位置で、ほかの7か所は、隣り合う2つの地域の境の上で、2つの地域の町の中ほどにいちばん近い陸地に置いた。入口は、つなぐ2つの地域のエリアマップの同じ場所にある。
- 世界地図には地域ごとに1つのマスを置いた。ユーザーの「そこに行くまでちょっといろいろマスが欲しい」を受け、入口でつながる地域どうしを、地形に沿って曲がる道（網の目の案と同じ作り方）で結び、道に沿って途中のマスを置いた。寄り道として、地域から名所（灯台・氷の洞窟・火山・ピラミッド・沼の遺跡）へ向かう行き止まりの道も足した。途中のマスは89、線は99である。
  続けてユーザーは、マスをもう少し小さくして網目状にし、寄り道もほしいとした。陸の上に約165画素（元の背景）おきに地点を置いて網の目に結び、網の目の外の陸地に18本の行き止まりの寄り道を足した。マスは約30画素おきで、途中のマスは469、線は514になった。その後、ユーザーの「マスの数が多いかも、3分の2ぐらいに」を受け、道の形は変えずにマスの間隔を約45画素に広げ、途中のマスを299、線を344にした。世界地図のマスの台は設計座標で60（地域のマスは112）、道の太さは16にした。その後、ユーザーの「マスが大きすぎて気持ち悪い」を受け、世界地図のマスを34（地域のマスは72）、道を10に、エリアマップのマスを60から36（町は64、入口は52）、道を8に小さくした。さらにユーザーの「マスは少し大きく、駒を小さく、初期のズーム倍率を調整」を受け、マスにあとで出来事のアイコンを描けるよう、世界地図のマスを50（地域88）、エリアマップのマスを56（町92、入口76）に戻し気味にした。駒は、跳ねる高さごと縮むよう駒全体を縮め、世界地図で0.5倍、エリアマップで0.55倍にした。地図を開いたときの拡大率は、世界地図で1.3倍、エリアマップで1.15倍にした（`WorldMapView.StartZoom`）。
- Unityに、世界地図とエリアマップを行き来する画面を作った（`WorldAtlasNavigator`）。
  - 世界地図の地域のマスに止まるか、立っているマスを押すと、その地域のエリアマップの最初の町に入る。
  - エリアマップの入口に止まるか、立っている入口を押すと、世界地図のその地域のマスへ戻る（2026-10-27、ユーザーの「諸エリアから、ワールドマップのマスに止まったら画面遷移」による。それまでは隣の地域の同じ入口へ移っていた）。左上のもどるでも同じく戻る。世界地図には、もどるを出さない。
  - 切り替えには、地域へ入るときは駒へ近づきながら暗くなり、エリアマップが少し引いた所から落ち着く演出、世界地図へ戻るときは引きながら暗くなり、世界地図が寄った所から引いていく演出を付けた（片道0.5秒ずつ）。
  - マスを開く仕組みは今の街道と同じで、隣のマスへ進むとそのマスが開く。世界地図でも、はじめはヴェルデ平原だけが開いていて、途中のマスを1つずつ進んで地域へ向かう。ルーンはまだ払わない。開けたマスは、アプリを閉じるまでだけ地図ごとに残る。
- 地図ごとのマスと線は、背景と一緒に作ったJSON（`Atlas/Layouts/<地域>.json`）に置いた。背景は1辺4096以下に分けたJPEG（品質90）で `Atlas/Art/` に置き、スマホではASTC 6×6で取り込む。世界地図は半分の大きさで表示し、縮めて見るためにミップマップを使う。エリアマップは等倍で表示する。
- 入口のマスの台は、町の台の金色の縁を青緑に変えた絵（`WorldNodeGate.png`）にした。
- 試しは `WorldAtlas` シーンで行い、Homeのデバッグルームの一覧の「入れ子の地図（試作）」から開く（左下にHomeへ戻るボタンを重ねる）。一覧が11項目になったため、一覧のダイアログを2列6段の12枠にした。今の街道の世界地図（戦闘・宝箱・サーバーへの保存）は、そのまま残し、Homeの行き先カードは今の街道を開く。
- 地図ごとの画面のPrefabは `Atlas/Resources/WorldAtlas/` に置き、今見ている地図だけを読み込む。背景が大きく、全部を同時に読むとメモリーが足りなくなるおそれがあるためである。

### 2026-10-28：マスの出来事の種類

ユーザーとの相談で、マスで起きる出来事を次の7つに絞った。
戦闘だけは戦闘の画面へ切り替え、ほかはマスから開く窓の中で起こす。
この表は、上の[マスの種類](#マスの種類)と[日・週・月の出来事](#日週月の出来事)の案のうち、出来事の種類を決めるものとして優先する。

| 出来事 | 起きること | 復活 |
|---|---|---|
| 出会い | 会話のあと、仲間になる | なし |
| 選択 | 選んだ答えで報酬が変わる | なし |
| 隠し宝箱 | 見つけると中身をもらう | なし |
| 拾い物 | 道で素材を拾う。採取地でも拾う | 採取地は毎日 |
| 行商人 | 曜日で品ぞろえが変わる | 毎日 |
| 賭け | 伏せた札から当たりを引く | 毎日 |
| 戦闘 | 戦闘の画面へ切り替える | 強敵の巣は毎週 |

- 会話だけで終わる出来事（物語・仲間のひと言・吟遊詩人）は置かない。会話は仲間の加入で終える。
- 選択には、どの答えにも報酬を付ける。
- 宝箱は隠し宝箱だけにする。祠・覚醒の祭壇のような「1つを選んで授かる」出来事は置かない。
- 店は行商人だけ、運試しは賭けだけにする。
- 毎日の復活は、ルーンの変換と同じ朝4時の区切りとする。
- 出会いで加わる仲間を、神殿の召喚と同じキャラにするか、街道でしか会えないキャラにするかは未決である。

同じ日に、入れ子の地図の試作で7つの見本を窓に作った（[マスの出来事の見本](../features/world-atlas.md#マスの出来事の見本)）。
